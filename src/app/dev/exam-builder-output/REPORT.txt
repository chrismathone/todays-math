Bridge
- Only window.parent messages with exact origin http://127.0.0.1:3178 are accepted.
  The message listener is installed before exam-concept:ready is posted there.
- exam-concept:open validates subject, title (80 characters), <=120 unique-ID
  questions, <=10 choices each and bounded field lengths / 500,000 total text
  characters. Invalid payloads show a recoverable error; text is not clipped.
- Each valid open loads its latest title/questions, retains print options and
  other form metadata, updates the subject/title metadata and clears the previous
  question bundle's temporary snapshot. No browser storage is used.
- Back button, Escape and authenticated exam-concept:close return
  exam-concept:back with current title and ordered remaining questionIds.
  Before a valid open or after invalid input, back has no payload: the coordinator
  explicitly accepted this as cancellation without changing the parent selection.
