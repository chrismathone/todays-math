# Original MP3 fixtures

All three files contain synthetic sine waves generated for these tests on 2026-10-03. No external recording, speech, answer or licensed teaching material was used. These are real compressed MP3 bitstreams, decoded by the production WASM implementation in the tests.

- `tone.mp3`: one second, mono 44.1 kHz, 440 Hz, PCM amplitude 9000, encoded at 128 kbps with [LAME JS](https://github.com/zhuker/lamejs) (`lame.all.js`, `new lamejs.Mp3Encoder(1,44100,128)`, feed 1152-sample Int16Array blocks, then `flush()`). 16,718 bytes; SHA256 `44331f6cd852d7a187ab7028159a74a53bbc2db30332e3173d6b66666b0552cf`. No gapless information header, so decoded duration includes codec padding (1045 ms).
- `tone-vbr-stereo.mp3`: one second, stereo 48 kHz, 440/660 Hz channels, amplitude 0.25. Encoded independently by libmp3lame through FFmpeg (`-f lavfi -i "aevalsrc=0.25*sin(2*PI*440*t)|0.25*sin(2*PI*660*t):s=48000:d=1" -c:a libmp3lame -q:a 4 -metadata title=SECRET_ANSWER_FROM_TITLE -id3v2_version 3`). Its actual ID3 title is a leak sentinel. Includes Xing/gapless metadata; decoded duration is exactly 1000 ms.
- `tone-mpeg2.mp3`: one second, mono 22.05 kHz, 440 Hz, generated by `-f lavfi -i "sine=frequency=440:sample_rate=22050:duration=1" -c:a libmp3lame -b:a 64k`. Includes information/gapless metadata; decoded duration is exactly 1000 ms.

FFmpeg was an isolated **fixture creation tool only**, obtained through imageio-ffmpeg in the ignored `.qa-artifacts` directory. It is neither a project dependency nor used by production or the test run. Tests additionally inject ID3v2/v1 secrets, corrupt frame headers, truncate full/partial frames, and test metadata-only fake files.
