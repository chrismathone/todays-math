## 1. 끝나는 지점 — 네가 정하지 않는다

```
npx tsx scripts/qa/probe-elem-forms.ts --grade 초N
```

이 자가 소단원마다 여섯을 본다. **「다 했다」는 이 수가 말한다:**

1. 문형이 10개 이상인가
2. 문형 id 가 난이도 이름이 아니고 서로 다른가 (`01`…`10`)
3. **문형이 서로 다른 물음인가** — 소재 이름만 바꾼 것은 같은 것으로 센다
4. 문형마다 변형 3개가 나오는가 (`expandFamily`)
5. 제품 `selectProblems` 로 **10문항·10갈래 시험지가 실제로 조립되는가**
6. 그림이 붙은 문형 수

⚠️ **이 판정기를 고치지 마라.** 네 갈래가 같은 자를 써야 한다.
막히면 고치지 말고 **왜 막혔는지 보고서에 적어라.**

## 2. 가장 중요한 것 — 소재 이름만 바꾼 것은 새 문형이 **아니다**

원장님이 안 2를 버리신 이유가 이것이다. 실측:

```
초4 막대그래프 47틀   "수영과 달리기" / "줄넘기와 수영" / "사과와 배"
초3 그림그래프 41틀   "다 마을의 우유" / "다 반의 우유" / "다 농장의 사과"
```

전부 **같은 문제**다. 이렇게 10을 채우면 판정기가 문다 — 그리고 물지 않더라도
그건 원장님이 「같은 문제가 한 장에 여러 개」라고 부르신 바로 그것이다.

**새 문형은 «묻는 것»이 달라야 한다:**

- 주는 것과 구하는 것을 뒤집기(역산) — 넓이를 주고 한 변을 묻기
- 조건을 겹치기 — 「$60°$보다 크고 $118°$보다 작은」
- 정의·성질을 직접 묻기 — 「가장 긴 선분은 무엇인가」
- 세는 대상을 바꾸기 — 꼭짓점/모서리/면 (**정답이 달라진다**)
- 참·거짓 판정, 잘못 푼 풀이 고치기, 조건에 맞는 것 **모두** 고르기

판정기가 가르는 근거는 **정답**이다 — 낱말 하나만 다른데 정답이 씨앗마다 전부
같으면 같은 물음으로 센다. 「꼭짓점 8」과 「모서리 12」는 정답이 달라 갈린다.

## 3. 그림 — 붙일 수 있는 곳은 최대한 (원장님 지시)

- **이미 있는 kind 를 먼저 찾아라.** 파일럿의 그림 문형은 기존 `cuboid`·
  `circleParts` 를 `fig(...)` 한 줄로 붙인 것이라 **더 비싸지 않았다.**
- 새 kind 를 짜야 하면 `docs/planning/09-figure-engine-guide.md` 를 **먼저 읽어라**
  (D-61 불변식 · 재발 금지 §4). 지면 폭을 안 박으면 같은 유형인데 글자 크기가
  갈린다(CLAUDE.md 2026-08-23).
- **장식으로 붙이지 마라.** 발문만으로 풀리는데 그림을 얹으면 지면만 먹는다.
- 그림이 없어도 10문형은 채워야 한다. 그림은 덤이지 핑계가 아니다.

## 4. 값 검산 시험 — 문형마다 하나

`elemPilotValues.test.ts` 를 본보기로 써라. 핵심은 **발문에서 다시 세는 것**이다 —

## 5. 난이도 — 사다리를 무너뜨리지 마라

문형 id 는 난이도(연산·기본·응용·심화, D-72/D-106)와 **직교**다.
배분은 제품 `defaultRatioFor(10)` = 연산1·기본4·응용4·심화1 이라, 문형도
그 비(1/4/4/1)로 짜면 시험지가 채워진다. 파일럿 세 곳이 그렇게 했다.

## 7. 규율

- **한 소단원을 끝낼 때마다 커밋하라.** 55개를 다 하고 한 번에 커밋하지 마라 —
  다중 세션이라 중간에 죽으면 통째로 잃는다(2026-08-21).
- 커밋 전 **`npx tsc --noEmit`** — 관문(vitest)은 **타입을 안 본다.**
  오늘만 두 번 그렇게 샜다. 기존 오류 2건(`import.test.ts`)은 다른 세션 것이다.
- 새 워크트리에서 **`npx prisma generate`** 를 먼저 돌려라. 안 하면 관문이
  13파일 빨갛게 나오는데 원인이 네 코드처럼 보인다.
- **관문**: `node scripts/qa/run-tests.mjs` — 「N passed」가 아니라 **종료 코드**.
- 보고는 **파일로**: `scratch/REPORT-<학년>-NN.md`. 터미널은 한글이 깨져 내가 못 읽는다.
