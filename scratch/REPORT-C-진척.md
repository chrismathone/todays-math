## 1. 원장님이 정해 주셔야 하는 것 셋

### ⑴ 🔴 main 의 다섯 유형이 지면에 **날 글자**를 싣고 있다 — 제 파일이 아니다

`m2GeoTri.ts`·`m2GeoSim.ts` 의 LaTeX 이 **역슬래시 한 겹**으로 적혀 있다.
TS 템플릿 리터럴에서 `\a` 는 «모르는 이스케이프»라 자바스크립트가 역슬래시를
**그냥 버린다.** 제품 렌더러를 실제로 태워 눈으로 확인했다:

```
원문 : 그림과 같이 $angle C=90^circ$인 직각삼각형 ...
지면 : 그림과 같이 angleC=90circ인 직각삼각형 ABC에서 빗변 AB 위에 overlineAC=overlineAD가 ...
```

| 유형 | 자리 |
|---|---:|
| `2-2\|삼각형의 성질\|08` | 33 |
| `2-2\|삼각형의 성질\|07` | 28 |
| `2-2\|삼각형의 성질\|06` | 18 |
| `2-2\|평행선 사이의 선분의 길이의 비\|08` | 15 |
| `2-2\|삼각형의 성질\|12` | 14 |
| **합계** | **108** |

- **main 에 이미 있다** (제가 만든 것이 아닙니다 — `git show main:` 으로 확인).
- **아무 판정기도 못 봅니다.** tsc 초록 · vitest 초록 · KaTeX 초록(유효한 글자다)
  · 값 검산 초록 · 지면 냄새 판정기도 이 부류는 안 셉니다.
- **제 파일이 아니라 손대지 않았습니다.** B 갈래가 지금 `m2GeoSim.ts` 를 쓰고 있어
  건드리면 충돌합니다. 대신 **찾는 도구를 남겼습니다** —
  `npx tsx scratch/probe-raw-latex.ts` (등록 유형 전량을 돌려 셉니다),
  `npx tsx scratch/render-raw-latex.ts` (제품 렌더러로 지면을 찍어 봅니다).
  고치는 일은 역슬래시를 두 겹으로 되돌리기만 하면 됩니다.

### ⑵ 갈래마다 **유형 번호 구역**을 나눠 주십시오

갈래를 **파일**로 나눴는데 **중단원은 파일을 가로지릅니다.** `도형의 닮음` 이
`m2Center.ts`(제 것)와 `m2GeoSim.ts`(B 것) 둘에 있어서, 앞 세션의 `31~36` 과
B 갈래의 `30~35` 가 **겹쳤습니다**(B 가 15:04 에 먼저 커밋).
제 몫을 `70~75` 로 옮겼고, **갈래 C 는 앞으로 70번대만** 씁니다
(A ~43 · B ~35 · D ~38 과 안 겹칩니다). 다른 갈래도 정해 두지 않으면 병합에서 또 겹칩니다.

### ⑶ `C:/tmp/middle-combo/corpus.json` 을 **누가 언제** 다시 만들지

> **관문 최종 상태**: 단위 시험 **11,430개 전부 통과 · 실패 파일 0**.
> 남은 빨강은 이 항목 **하나뿐**입니다(`등록 920 / live 997`).

`probe-middle-combo.ts` 가 말뭉치를 **저장소 밖** 이 파일에서 읽는데, 네 워크트리가
**한 파일을 같이 씁니다.** 오늘 16:09 에 다른 워크트리가 자기 등록(920유형)으로
다시 만들어 제 워크트리(그때 908)가 빨개졌습니다. 제가 다시 만들면 이번엔 그쪽이
빨개지므로 **건드리지 않았습니다.** 네 갈래를 병합한 뒤 한 번 다시 만들면 풀립니다.

## 2. 이어받은 자리에서 고친 것

### ⑴ 색인 가드가 **확장 유형을 전부** 막고 있었다 — 갈래 넷 공통

`middleTypeCoverage.test.ts` 가 「등록 유형은 RPM 색인 정본에 **글자 그대로** 있어야
한다」를 요구하는데, 130소단원을 10유형으로 올리려면 **RPM 이 안 만든 유형을 지어야**
하므로 정본에 있을 수가 없습니다. 이 갈래만 35건이고 A·B·D 도 같은 자리에서 빨갰습니다.

> 정본 JSON 에 우리가 지은 유형을 적어 넣는 길은 **택하지 않았습니다.** 그러면 그
> 가드가 「우리가 적은 것과 우리가 등록한 것이 같은가」를 묻는 **동어반복**이 됩니다.

가드를 **좁혔습니다**(약화가 아닙니다): 중단원 이름은 **여전히** 정본과 글자 그대로
(이 가드가 실제로 잡은 얇은 공백 U+2009 결함이 그 자리) · 정본에 있는 번호면 제목까지
· 정본 최대를 **넘는** 번호만 확장으로 허용 · 확장인데 제목이 정본과 같으면 빨강.
변이 넷 전부 빨강 확인.

### ⑵ 시험 셋이 남의 확장 유형을 자기 검산표에 들이대고 있었다 (70건)

`middleM2`(36→57) · `middleM2Func`(18→26) · `middleM2Geo`(닮은 도형 4→10).
몫을 「RPM 색인에 있는가」로 한 겹 더 좁혔습니다(`src/__tests__/helpers/rpmCatalog.ts` 한 곳).

### ⑶ **제 유형 19자리도** 역슬래시가 한 겹이었다

셸 heredoc 을 거치며 `\\` 가 `\` 로 줄었습니다. **tsc·vitest 11,371개·KaTeX·값 검산이
전부 초록**이었고, 지면 냄새 판정기가 **다른 이유**(이중 부호 `+-`)로 빨개졌을 때 그
출력에 탭 문자가 찍혀 있어서 드러났습니다. 고치고 **가드를 넣었습니다** — 열쇠는 손
목록이 아니라 «역슬래시 하나 + 영문 두 글자 이상»이라는 **모양**입니다.

## 3. 원장님 지적 건 — 전개도 접는 선 ✅

`FIGURE_TETRA_NET`(삼각뿔 전개도)이 접는 선 AB·BC·CA 를 날개 여섯과 **똑같은 실선**
으로 그리고 있었습니다. 전개도에서 실선은 «자르는 선»이라 그림이 전개도가 아니게 됩니다.

v2 엔진의 `segments.<이름>.dash` 로 고치고 **실제로 렌더해 눈으로 확인**했습니다
(`scratch/tetra-net.png` — line 9개 중 가운데 삼각형 셋만 `stroke-dasharray="5 4"`).
시험은 점선 목록을 다시 읽지 않고 **스펙의 이음새에서 접는 선을 다시 구합니다**
(선분이 셋 이상 닿는 점끼리 이은 변). AB 를 실선으로 되돌리면 빨개집니다.

## 5. 다음 사람이 밟을 함정 넷 (실제로 밟았습니다)

1. **역슬래시가 든 코드는 셸 heredoc 으로 넣지 마십시오.** `\\` 가 `\` 로 줄고,
   **모든 검사가 초록인 채로** 지면만 깨집니다. Write/Edit 도구로 넣으십시오.
2. **이미 객관식인 유형이 있는 소단원은 10개가 아니라 11개**를 지어야 합니다.
   판정기는 시험지를 단답형만으로 조립하므로 그 유형은 풀에 못 들어갑니다
   (`합동` 이 그랬습니다 — 「10유형인데 갈래가 9개」로만 나옵니다).
3. **소단원마다 심화가 하나는 있어야** 시험지가 채워집니다(`합동`·`다각형내외각`이 걸림).
   반대로 기존이 전부 응용·심화면 **기본**을 넣어야 합니다(`유리수의 곱셈`·`이차함수 최대최소`).
4. **판정기는 변형 3개만 뽑습니다.** 「씨앗 200개에 한 번 터지는」 자리를 구조적으로
   못 봅니다(한글 수사 표가 12까지인데 n 을 14까지 뽑고 있었습니다).
   그래서 **씨앗 200 × 변형 3** 훑기를 시험에 넣었습니다.

**그리고 발문을 찍어 눈으로 보십시오** (`npx tsx scratch/print-mine.ts`).
「오각형뿔」·「서로 다른 $1$개의 동전」·「제목은 4의 배수인데 발문은 3·4·5」는
**값이 다 맞아서** 어떤 판정기도 못 봤고, 눈으로 봐서만 나왔습니다.
