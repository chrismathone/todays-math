## 1. 🔴 **리드가 먼저 봐야 할 것 — 갈래를 가로지르는 것 셋**

### ⑴ 앞 세션(갈래 B)이 만든 유형이 **지면에 날 글자로 나가고 있었다**

템플릿 리터럴에서 홑 백슬래시는 JS 가 먹는다. 지면에 이렇게 나갔다:

```
$0.overline{6}+0.overline{2}$를 계산하시오.     ← \overline 이 죽었다
$9<TAB>imes0.overline{8}$                       ← \times → 탭 + "imes"
$4,mathrm{cm}$                                   ← \, 와 \mathrm 이 죽었다
```

**KaTeX 는 이것을 에러로 보지 않는다** — 유효한 글자라 그냥 그린다. 렌더 검사도
잔재 검사도 이 부류를 구조적으로 못 잡는다(CLAUDE.md 2026-08-16 과 같은 자리).

- 내 파일에서 **448자리** 고쳤다(`d679279e`). 그중 **189자리는 main 에 이미 있던 것**
  — `m2GeoTri.ts` 156 · `m2GeoSim.ts` 33, 2026-08-23 `13b40c4a` 가 넣었다.
- **다른 갈래도 같은 자리일 수 있다.** 재는 법은 아래 §3 의 `mid-b-lexer.mjs` 이고,
  이제 `midTypesB.test.ts` 가 **내 8파일**에 대해 회귀를 막는다.
  ⚠️ **A·C·D 파일은 아무도 안 재고 있다** — 리드가 한 번 돌려 보길 권한다.

### ⑵ 색인 가드 — 갈래 C 가 이미 고쳤고, 나는 **그 판을 그대로 가져왔다**
