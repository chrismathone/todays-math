## 4. 공용 후보 (리드가 병합 때 올릴 것 — 공용 파일은 안 고쳤다)

1. **`qAnswer(q: Q)`** — `numAnswer` 의 분수판(0 이면 `Retry`). 두 모듈에 같은 판이 있다 → `pick.ts`.
2. **복소수 오답 짓기 `cChoices`** — 공용 오답 경로는 첫 수만 흔들어 `$3-2i$` 의 보기 다섯의 허수부분이 같아진다.
   켤레 · 부호 · 실수부분↔허수부분 자리 바꿈을 기본으로 채우는 판을 공용에 두면 대수·미적분 복소수 답도 쓴다.
3. **`sgnTerm` · `termIf` · `sumTex`(0 을 맨 앞에 — `+0` 냄새 방지) · `prodTex`(근 0 이면 문자만)** — `h1Identity` 의
   `prodTex`·`termIf` 까지 세 벌이 됐다 → `poly.ts`.
4. **`pm(a, r, d)`** — `surdPmTex` 는 근호가 풀리면(제곱수) 던진다. 오답 후보를 지을 때는 `null` 을 돌려주는 판이
   필요했다 → `numbers.ts`. 유리수 계수 항 `qTerm`·`plusQ` 도 같은 자리.
5. **시험 쪽 식 계산기 `texValue` · 계수 역산 `quadOf` · 이차식 행렬식 `conicDet`** — 두 시험 파일에 같은 판을 두었다
   (helpers 는 리드 소유라 못 옮김). 물결 1 의 방정식·부등식 세션도 쓸 수 있다 → `helpers/highTex.ts` 같은 곳.
6. **지면 냄새 자에 「계수 1 을 괄호 앞에」** — `midPage.pageSmells` 의 `1[a-zA-Z]` 는 `-1(4+4k)` 를 못 본다.
   `/(?<![\d.])1\(/` 를 두 모듈 시험에 두었고, **고치기 전에 빨간 것을 확인했다**(이차방정식 14 꼴 2 의
   `\dfrac{-1(2+\sqrt{5})}{…}` 를 먼저 물었다). 공용 자로 올리면 다른 모듈의 같은 부류도 센다.
