# 브리프 — 전개도의 **접는 선을 점선으로** (초등 그림)

원장님 지적(2026-08-27, `J10504-A05-005`): 「삼각뿔의 전개도라고 했는데, 실제로
접어지는 부분인 AC, AB, BC는 점선으로 표현해야 전개도가 맞을듯. **이런 도형이
제법 많을거같은데 조사가 필요함.**」

## 0. 내가 이미 잰 것 — 다시 조사하지 마라

```
초등 전개도 스펙 (문형 2,300 이 내는 그림 936장 중)
    netCuboid    26      netCylinder  18      prism(net)   5
    → 이 그림들의 stroke-dasharray 요소 수: **0**

적재된 문항 (공유 DB)
    본문에 「전개도」  초등 393 · 중등 35
    그중 그림 붙은 것  **359**
```

**중등 `FIGURE_TETRA_NET`(원장님이 짚으신 그것)은 네 몫이 아니다** —
`src/lib/middle/m1Geo1.ts` 는 mid-types-c 워크트리가 쓰고 있다. 건드리지 마라.

## 1. 왜 결함인가

초5 「직육면체의 전개도」 교과서가 **「접는 선은 점선으로 그립니다」**로 가르친다.
전개도에서
  · **실선 = 자르는 선**(바깥 윤곽)
  · **점선 = 접는 선**(면과 면이 맞닿는 안쪽 선)
이다. 지금은 전부 실선이라 **그림이 전개도가 아니다** — 학생이 어디를 접는지
읽을 수 없고, 「접었을 때」를 묻는 발문과 그림이 어긋난다.

## 2. 네가 할 것

`scripts/figure/elem_advanced.py` 의 전개도 함수들:

```
_net_cuboid    (2478행)   여섯 면을 실선 _rect 로 그린다 — 맞닿는 변이 접는 선
_net_cylinder  (2525행)   옆면 직사각형과 두 원이 만나는 자리가 접는 선
_net_cone      (2610행)   부채꼴과 밑면 원이 만나는 자리가 접는 선
_net_prism     (2253행)   면 사이 세로선이 접는 선. 밑면 붙는 변도
```

**바깥 윤곽은 실선 그대로 두고 안쪽 접는 선만 점선으로.** 지금처럼 면마다
닫힌 `_rect` 를 그리면 안쪽 선과 바깥 윤곽이 **같은 획**이라 못 가른다 —
윤곽(폴리라인 하나)과 접는 선(선분들)을 **따로 그려야** 한다.

## 3. ⚠️ 함정 — 치수 판정기와 색이 겹치면 안 된다

오늘(2026-08-27) `scripts/qa/probe-dim-outside.py` 를 고쳐서 **치수의 지문**으로
고르게 했다. 실측으로 점선은 네 부류이고 지금은 겹치지 않는다:

```
  #000     1.4    "6 4"   치수         ← 판정기가 이것만 센다
  #111111  1~1.2  "5 4"   숨은 모서리
  #111111  0.4    "3 3"   직각·등변 표시
  #c8d7e4  0.7    "4 3"   모눈
```

🔴 **접는 선을 `#000` + `1.4` 로 그리면 치수 판정기가 그것을 «치수»로 세고,
   전개도 안쪽이니 「치수가 도형 안에 있다」로 **거짓 결함이 쏟아진다.**
   접는 선은 **다른 지문**을 쓰라(예: `#111111` `5 4` 계열).
   고친 뒤 반드시 확인:

```
python scripts/qa/probe-dim-outside.py --specs scratch/specs.json
    → 잰 그림 111 · 안쪽 **0** 이 그대로여야 한다
```

**`probe-dim-outside.py` 를 고치지 마라** — 네 성적을 네가 매기게 된다.
부족하면 **왜 부족한지 보고서에 적어라.**

## 4. 판정기를 하나 만들어라

「전개도인데 접는 선이 실선인가」를 재는 자가 **지금 없다.** 없으면 이 결함은
다시 들어온다. `scripts/qa/probe-net-fold.py` 로 만들어라.

- 열쇠는 **손으로 지은 목록이 아니라** 구조에서 나와야 한다. 예: 「같은 좌표를
  두 면이 공유하는 변인가」(= 안쪽 변) — 그 변이 실선이면 결함.
- **눈금 양성·음성을 둘 다** 넣어라(`--selftest`). 양성만 넣으면 재현율만 재고
  지어냄은 구조적으로 0이 된다. 음성에 「바깥 윤곽은 실선이어야 한다」를 꼭 넣어라
  — 그것까지 점선으로 만들면 이번엔 반대로 틀린다.
- **고치기 전에 먼저 돌려 「양성이 실제로 잡히는지」 보라.** 0이면 「깨끗」인지
  「못 셈」인지 안 갈린다.
- 결함이 있으면 종료 코드 1.
