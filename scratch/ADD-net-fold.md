# 덧붙임 — 전개도 접는 선을 점선으로 (원장님 지적 2026-08-27)

**지금 하던 일을 끝낸 뒤에 하라.** 작은 일이다.

## 무엇이 틀렸나

`src/lib/middle/m1Geo1.ts:714` `FIGURE_TETRA_NET` (삼각뿔 전개도)이 접는 선
`AB`·`BC`·`CA` 를 날개(`AD`·`BD`·`BE`·`CE`·`CF`·`AF`)와 **똑같은 실선**으로 그린다.

전개도에서 **접는 선은 점선**이다 — 초5 교과서가 「접는 선은 점선으로 그립니다」로
가르치는 규약이고, 실선이면 「자르는 선」이라 그림이 전개도가 아니게 된다.
원장님이 `J10504-A05-005`·`-006` 화면에서 짚으셨다.

## 어떻게

v2 엔진은 **선분별 점선을 이미 지원한다** — `vendor/figure-engine/core/figure_scene.py:230`
의 `dashed: str | None`. `segments` 항목에 얹으면 된다. 지금 형태가

```ts
segments: { AB: ["A", "B"], ... }
```

이므로, 엔진이 받는 형태(배열 vs 객체 `{ points, dashed }`)를 **먼저 확인하고**
`AB`·`BC`·`CA` 세 개만 점선으로 바꿔라. 날개 여섯은 실선 그대로 둔다
(그 선들은 자르는 선이다).

⚠️ **추측으로 키 이름을 짓지 마라.** `figure_scene.py` 의 `segment(...)` 서명과
   v2 스펙을 읽고 실제로 받는 형태를 확인한 뒤 고쳐라. 렌더해서 **점선이 나오는지
   눈으로 확인**하라 — 안 그러면 조용히 무시되는 키를 넣게 된다.
