원래 세션 `01a1177e-fbb2-7822-a7e2-51c40b39e38f`에서 이어서 작성했다. solverId는 `orca-codex-exam-twin-author-geometry-20261008`이다. 입력은 제공된 학생용 JSON, manifest, brief, 12개 SVG뿐이다. 새 GF15 저자 후보·답·해설·수학 검사·원문 증거를 열지 않았다. 이전 통계 검수에서 본 원래 경상 문항의 답 없는 개념은 별도로 `input-audit.json`에 공개했다. 이것은 새 GF15 정답을 미리 알았다는 뜻이 아니다. 원시 풀이 커밋 전 부모의 private/author/helper 출력 및 원문을 읽지 않았다.

q01–09, q16–21의 15개 부모 문항을 모두 다뤘다. 객관식 12개, 서술형 3개·번호 소문항 9개, 합계 71점이다. **14개 solved, q18 한 개 pending**이며 15개 통과로 세지 않는다. 15개의 수학 답을 계산했다는 사실과 교육과정·자료 복잡성 허용 여부는 구별한다. 저자 답 비교, 최종 검수, 권리·출처·native·적재 승인은 모두 미실시다.

`calculation.py`는 학생 JSON의 기록과 새 도형 조건에서 독립적으로 계산한다. 객관식 다섯 보기 전체를 정확식으로 비교하여 정답 하나와 동치 중복 없음, 존재·유일성·양수 길이·단위·점 순서를 확인했다. 서술형은 `answerParts`의 역할·순서·단위를 수학식으로 검사하며 증명과 선분의 비도 완전한 새 `solution`에 썼다. q19는 실제 길이에 피타고라스 정리를 적용하고, q20은 SSS 합동으로 수직을 먼저 증명한다. q21은 주어진 수선과 두 실제 직각삼각형을 이용한다. 일반 삼각비 항등식, 사인·코사인 법칙, 역삼각함수, 라디안, 원과 비례를 학생 방법으로 쓰지 않았다. q04의 수치 재확인은 보충 계산기 검사이며 학생 풀이에 필요한 방법은 표의 기록과 변의 비다.

15개 70mm 학생 보기 PNG를 실제로 열어 확인했고, 그 안의 SVG 12개와 표·보기·서술형 조건을 모두 확인했다. 렌더링 중 외부 요청·TeX 경고·기록된 가로 넘침은 0이다. 도형은 픽셀 측정 대신 명시된 조건으로 풀었다. q18의 B–F–H–C 순서와 ABFE 회색 영역, q20의 α 정의와 수직 증명 요청, q21의 O–H–Q 내부 조건을 확인했다. `inspection/layout.json`과 각 solve의 실제 관찰·PNG SHA가 이 검사를 연결한다.

7개 학생 표면(본문, 보기, 도형·표, 표기, 답, 새 학생 풀이, 선수지식)에 2015 중3 범위를 적용했다. 사용 성취기준과 제한은 이미 확보한 공식 2015 수학 교육과정 PDF의 해당 문구·페이지·raw SHA를 코드로 대조했다. 학교나 기존 분류만으로 학년을 승인하지 않았다. 이 단계는 독립 학생 방법 제안이지 최종 저자·학년 승인 아니다.

q18은 수학적으로 BF=4cm가 유일하지만 **whole-curriculum material-complexity hold**를 유지한다. 주어진 수선, 특수각의 실제 변 비, 작은 삼각형 넓이, 두 넓이의 합, 역방향 양의 근을 연결한 완전한 풀이를 기록했다. 각 연산이 중학교 범위라는 사실만으로 겹친 도형 전체를 허용하지 않는다. 공식 2015 문서 물리 39쪽/인쇄 35쪽의 복잡하게 변형된 도형 넓이·둘레 문제 제한에 대한 불확실성이 남는다. 답 공개 후 전체 새 목적·자료·학생 순서에 대한 별도의 교육과정·복잡성 검토, 또는 단순화하고 새로 바인딩한 학생 버전이 재개 조건이다. 수학 답·원학교·자신감으로 보류를 해제하지 않는다.

기존 917개 파일은 `preservation.json`의 raw SHA로 확인해 그대로 보존했다. 기존 GS22 중복 보기 및 통계 q13 비학생 메타데이터 부호 발견도 그대로다. 이번 재개 중 수정한 독립 계산 근거와 앞선 파서 실패는 `changes-and-failures.json`에 기록했다. `solve-freeze.json`은 공개 전 UTC, 제공 학생 digest, 입력·그림·코드·출력·원시 풀이·검사 이미지 SHA를 묶는다. 제공 digest를 임의의 Python 객체 해시로 바꾸지 않았다.
