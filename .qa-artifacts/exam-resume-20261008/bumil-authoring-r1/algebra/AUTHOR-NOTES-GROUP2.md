- 참조는 v2 준비 자료와 그 아래 정답 없는 `source-reference/problems.json`의 q1·q4·q5·q18 본문, 기존 공식 `curriculum-evidence.json`이다. 원본 정답/해설/재생성 파일은 열지 않았다. 원문 본문 해시·준비/교육과정 입력 해시를 각 후보에 연결했다.
- q04의 stem 1개와 choice 5개, q05의 stem 1개를 새 `graph-1` 사양으로 만들고 `renderFigureSpec(spec, { strict: true, typeset: true })`의 로컬 Python 경로로 SVG를 생성했다. 치수 누락 0건. 일곱 PNG와 q04 보기 합성표를 확인했다. ⑤번 보기의 원점 글자는 직선과 간격을 확보하도록 옮긴 후 strict 재렌더와 이미지 확인을 완료했다.
- q04 `choices`는 로컬 SVG의 Markdown 이미지 참조이다. `figureArtifacts`의 `role: choice`, **1부터 시작하는 `choiceNumber`**가 배열의 같은 순서와 대응한다. 합성 미리보기는 1~5 순서이며 문제용 자산은 개별 SVG이다. 본문은 렌더용 수치 계수를 조건으로 주지 않고 개략 그래프의 역할을 명시한다.
