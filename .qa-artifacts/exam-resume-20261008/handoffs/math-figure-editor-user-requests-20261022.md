시작 화면의 ‘이어서 편집 — 최근 작업 자동 작도’가 다른 사람/서버 공용 최근 작업을 열지 않도록 한다. 실제 저장/조회 경로를 확인하고, 브라우저 저장소가 없는 새 브라우저에서는 타인의 작업이 나타나지 않는지 검증한다. 익명 다수 사용 환경이므로 로그인 기능이 있다고 가정하지 않는다.

## 4. 비정상 접속 IP 차단 및 문의 안내 페이지

사용자: “그리고 크롤링, 비자연스러운 조짐이 보이면 접속 아이피를 차단해버린다음에 관리자에게 문의해돌라는 페이지로 변경할것.”

math-figure-editor에 적용한다. 실제 서비스 경계의 접속 IP/프록시 신뢰 계약, 기존 요청 제한과 인증/공유코드 흐름을 확인한 뒤 비정상 요청 탐지와 차단, 차단 후 관리자 문의 안내 화면을 구현하고 검증한다. 브라우저의 표시만 바꾸고 API 호출을 그대로 허용하는 형태로 완료 처리하지 않는다. 탐지 기준/차단 기록/실제 검증 범위는 결과에 남긴다. 현재 송신 세션에서는 외부 서비스 설정이나 운영 IP 차단을 실행하지 않았다.

## 송신 측 작업 상태

todays-math 생산 코드와 D:/math-figure-editor 파일은 이 전달 중 수정하지 않았다. 기존 math-figure-editor 세션이 현재 작업/미커밋을 소유한다. 요청은 기존 세션에 추가 전달하며 즉시 중단/폐기 지시가 아니다. 완성 뒤 화살표 관련 동기화 신호와 변경·검증 근거를 보내 달라.
