# r5 q10·q19 새 독립 풀이

솔버: `orca-codex-exam-twin-author-algebra-20261008`. 새 `author-r2-q10`, `author-r2-q19` 학생 입력만으로 다시 풀었다. 두 문항 모두 `solved`이며 보류한 풀이는 없다. 이번 작업은 같은 원문의 수리 개정에 대한 블라인드 풀이 기록이다.

| 문항 | 새 조건으로 구한 결과 | studentDigest |
| --- | --- | --- |
| q10 | ③, 7.0m | `33606d31af0dc51fe06bf158f44101ce7a749c41e643d0ad92ee5327c7c7e934` |
| q19 | 90m | `dc9f646e5897008384c4f3a96a4db3b0bdf253cd491ab719aa4079870a205a75` |

q10은 `CE−AG=12.8−1.6=11.2`와 제공된 `tan 58°=1.6003`을 사용했다. `GE=11.2/1.6003≈6.998687746`을 소수점 아래 둘째 자리에서 반올림했다. 다섯 보기 중 ③만 맞고, 높이·거리·탄젠트는 모두 양수이다. 코드로 삼각비 표 세 열의 네 자리 반올림값도 확인했다.

q19는 내각의 합으로 C의 각이 60°임을 구한 뒤 B에서 AC에 수선을 내렸다. 두 직각삼각형에서 60°·45°의 사인을 써서 `BH=45√2`, `AB=90`을 얻었다. 수선의 발은 AC 내부에 있고 모든 길이가 양수이다. 보조 길이·피타고라스 관계·세 삼각부등식·B의 75° 복원을 코드로 확인했다. 75° 삼각비, 사인법칙, 삼각비 덧셈이나 삼각비 사이의 관계식은 학생 풀이에 쓰지 않았다. 서술형의 `choices=[]`도 확인했다.

현재 인쇄 배치는 부모의 `student-preview-r2/q10.png`, `q19.png`를 직접 보아 확인했다. 각 문항에서 장면이 왼쪽, 관계도가 오른쪽이며 별도 70mm 그림 두 개가 원래 순서로 배치된다. 본문·기록 표·각도·점 이름·보기의 잘림이나 겹침은 보이지 않았다. 이전 쌓인 `student-preview`는 먼저 보았던 역사 기록으로만 남겼다. 배치 갱신 후 학생 JSON 및 네 SVG의 바이트 해시가 그대로인지 다시 확인했다.

`previews/qNN-70mm-proof.svg`는 페이지를 mm 단위로 정의하고 원본 학생 SVG를 각각 정확한 70mm 폭으로 포함한 별도 증거이다. 이 SVG의 렌더와 네 개의 개별 PNG를 실제로 보아 점 이름·각도·q10의 B 직각 표시를 확인했다. 개별 96dpi PNG는 픽셀 정수화로 폭 265px(약 70.115mm)이므로 정확한 물리 폭은 SVG의 70mm 정의에 묶었다. 물리 종이 인쇄를 직접 시험한 기록은 아니다. 장면 래스터는 배경으로만 보았으며 픽셀에서 수학적 사실을 측정하지 않았다.

학생 입력·네 SVG·현재 배치 PNG·로컬 증거 파일의 SHA-256과 코드 계산은 `calculations.json` 및 각 `solve/qNN.json`에 묶었다. 읽은 부모 자료는 r5 블라인드 안내·학생 JSON·학생 그림·명시적으로 허용된 학생 미리보기뿐이다. 저자 r2 답·해설·비공개 스펙·mathbinding·package/private와 원본 답·해설은 열지 않았다. 과거 r1 답·승인을 이번 결과에 재사용하지 않았다.

이 기록은 중3·2015 범위의 독립 풀이와 학생용 시각 확인이다. 최종 수학 검증·학년/난도·Unit/family·권리 승인이나 출고 상태를 부여하지 않는다. 기존 작성·풀이·리뷰 파일은 수정하지 않았고 새 r5 결과만 별도 커밋한다.
