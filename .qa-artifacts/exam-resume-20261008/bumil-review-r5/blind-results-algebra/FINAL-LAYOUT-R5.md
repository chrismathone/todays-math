# 최종 학생용 배치 증거 추가

최종 시각 참조는 부모의 `student-preview-r5`이다. `q10.png`, `q19.png`, `pdf-page-1.png`, `pdf-page-2.png`를 직접 확인했다. q10은 1쪽에서 제목·본문·두 표·각각 70mm인 장면/관계도·①부터 ⑤까지 다섯 보기가 모두 보인다. q19는 제목·본문·기록 표·요구 문장·두 그림이 2쪽에 온전히 있다. 제목만 따로 남거나 보기가 다음 쪽으로 넘어가는 현상, 잘림, 겹침은 보이지 않았다. 장면은 왼쪽, 관계도는 오른쪽이다.

로컬 pypdf로 최종 PDF가 정확히 두 페이지임을 확인했다. 두 페이지 MediaBox는 각각 약 209.889×297.011mm이며 A4의 210×297mm와 0.2mm 이내이다. 제공된 PDF 페이지 PNG의 시각 확인과 페이지 수·크기 검사를 별도로 기록했다. 물리 종이 인쇄 시험이나 생산 렌더러와의 동등성 검증은 하지 않았다. 렌더러/네이티브 프레임 호환 기록은 부모가 별도로 맡는다.

학생 JSON 바이트 SHA-256, 제공된 두 studentDigest, 네 SVG의 SHA-256이 이전 블라인드 입력과 그대로임을 다시 확인했다. 기존 독립 풀이의 답·해설·상태와 모든 파일 바이트를 보존했다. `FINAL-LAYOUT-R5.json`은 학생/그림/풀이 digest와 최종 네 PNG·PDF 해시를 묶은 시각 증거 추가 기록이다. 자체 70mm SVG 증거도 그대로 연결했다.

기존 `solve/qNN.json`, `calculations.json`, `BLIND-SOLVE.md`에 남은 `student-preview-r2` 참조는 역사 기록이다. 그 당시 문항 PNG에 기초한 서술을 최종 PDF 페이지 배치의 근거로 사용하지 않는다. 이전 레이아웃 버전들은 모두 미승인 이력이며 이 추가 기록의 최종 r5 참조가 우선한다. 부모 비공개 자료·저자 답·해설·mathbinding은 열지 않았다. 최종 교육과정·분류·권리 승인을 부여하지 않았다.
