# 추가 지시 6 — 작업 중간 커밋과 원격 체크포인트

사용자가 2026-10-08에 `커밋 푸시 중간중간 실행해`라고 명시했다. 전체 추출/제작이 끝날 때까지 로컬에만 쌓아두지 않고, 검증 가능한 배치·검수 결과·코드 개선이 완성될 때마다 커밋하고 원격 작업 브랜치에 푸시한다.

- 주 작업 브랜치는 `chrismathone/exam-extraction-resume-20261008`이다. 독립 작업자는 본인의 가지에서 완성된 범위만 커밋·푸시하고 주 작업자가 검증해 통합한다.
- 주 작업자는 제작 배치 동결, 독립 검수 수집, 유용한 엔진 코드와 관련 검사 통과를 체크포인트로 삼는다. 재개할 때 이미 검증·커밋한 변경이 원격보다 앞서 있으면 원격 체크포인트를 만든 뒤 계속한다.
- 각 푸시 직전에 대상 원격 가지를 fetch하고 로컬과 비교한다. 원격의 새 커밋은 다른 사람의 변경을 버리지 않고 통합하고, 충돌을 해결한 뒤 관련 검사를 다시 실행한다. 처음 만드는 원격 가지는 부재를 확인하고 생성한다. force-push는 하지 않는다.
- main의 최신 변경도 확인하고 진행 중인 통합에 반영한다. 공유 main 작업트리의 미커밋이나 다른 활성 세션의 파일은 건드리지 않는다.
- 커밋에는 현재 작업자의 소유 파일을 명시한다. 미완성 변경이나 다른 작업자의 수정은 포괄적인 staging으로 끌어오지 않는다. 답 공개 전 풀이·동결 파일·실패/수정 이력을 보존한다.
- 푸시 후 원격 SHA를 확인해 저장 성공과 로컬 작업 잔여를 구분해 기록한다. 제작/수학/학년/내용/권리/적재 단계는 기존대로 구분하고, 중간 커밋·푸시를 전체 승인이나 작업 완료로 세지 않는다.

이 지시는 배포·운영 DB 쓰기·재적재·잠금 해제를 추가로 허용하지 않는다. 기존 82개 잠금과 영구 제외/보정 원장을 유지하며, 주 작업은 원격 저장 뒤 계속 진행한다.
