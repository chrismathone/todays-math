# 정답 그림 읽기 — 그림에 적힌 «번호 → 답»을 글로 옮긴다

교과서 자료의 정답 칸이 그림 한 장으로 되어 있다(«Ⅲ-5 모집단과 표본 / 1 ⑴ 100 ⑵ 4 …»). 그 그림을 읽어 **적힌 그대로** 글로 옮긴다.
**풀지 않는다** — 문제는 주지 않는다. 그림에 적힌 것만 옮긴다. 이 답은 다음 단계에서 다른 검토자가 문제를 직접 풀어 대조한다.

## 받는 것

묶음 파일 `{{BATCH}}`(JSON): `{ "key", "material": 자료 이름, "pictures": [그림 경로…], "numbers": [옮길 문항 번호…], "multiSection": true|false }`

- `pictures` 의 그림을 **전부 Read 로 연다**. 읽어도 되는 파일은 이 지시서 · 묶음 · 그 그림들뿐이다(다른 파일 · 웹 금지).
- `numbers` 가 옮길 번호다. `multiSection` 이 true 면 번호가 `묶음-번호`(«2-3» = 둘째 묶음의 3번)다 — 그림에 «A», «B» 나 두 표가 있으면 차례대로 1, 2 묶음이다.

## 옮기는 꼴

한 줄에 한 문항: `번호: 답`

- 보기 번호 답은 그대로: `③` · 둘이면 `②, ④`
- 값 · 식은 `$…$` 안의 LaTeX 로: `$\frac{8}{9}$` · `$\sqrt{2}$` · `$x=3$` · `$12\,\mathrm{cm}$` · `$\mathrm{E}(X)=2$`
- 소문항이 있으면 그림의 번호 꼴 그대로 한 줄에: `3: ⑴ $\mathrm{E}(X)=2$, $\mathrm{V}(X)=\frac{2}{3}$ ⑵ $\mathrm{E}(\overline{X})=2$, $\mathrm{V}(\overline{X})=\frac{1}{3}$`
  (그림이 `(1)` 이면 `(1)`, `⑴` 이면 `⑴`)
- 글로 된 답은 글 그대로(«풀이 참조» · «해설 참조» 도 그대로 적는다)
- 🔴 **안 보이거나 흐려서 확실하지 않으면 그 번호는 `번호: ?`** — 짐작해 채우지 않는다
- 🔴 그림에 그 번호가 아예 없으면 `번호: ?`
- 그림의 단원 제목 · 머리 글씨는 옮기지 않는다

## 내는 것 · 끝나면

`{{OUT}}` 에 `numbers` 의 차례대로 한 줄씩 쓴다(그 밖의 글은 쓰지 않는다). 🔴 **반드시 Write 도구로** 쓴다(Bash 로 쓰지 않는다 — 역슬래시가 깨진다).
다 쓰면 한 줄만 답한다: `끝 — 번호 N · 옮김 M · ? K`
