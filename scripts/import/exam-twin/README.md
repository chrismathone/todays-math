# 실제 쌍둥이 후보의 로컬 제작·검수

이 경로는 범일중 첫 배치에서 확장한 중3·2015 오프라인 후보 계약이다. DB·네트워크·모델 호출·운영 적재기는 없다. `--apply`를 허용하지 않는다. 기존 원문 추출 loader의 `past_exam`, 원본 그림, 기본 승인 동작을 사용하지 않는다.

1. 저자가 새 본문·분리한 보기·답·학생용 해설·메타데이터·변형 근거와 새 FigureSpec/SVG를 작성한다. `curriculumReview.status=author-proposed`, 새 ID, 독립 검산은 아직 없음.
2. `review-exam-twins.mjs freeze <새폴더> <후보JSON...>`: 문제·답·해설·스펙·그림·생성 기록을 각각 해시로 연결하고 별도 버전에 복사한다.
3. `blind <패키지> <새블라인드폴더>`: 답·해설·사실의 파생값·원문 메타데이터 없이 학생 문제/그림만 제공한다. 다른 작업자가 새 문제만 보고 허용된 학생 방법으로 계산한다.
4. 독립 `solve/qNN.json`을 실제 디스크에서 다시 읽어 정답 기호/풀이 문자와 계산을 확인한 뒤 먼저 커밋한다. `node scripts/import/exam-twin/prepare-sealed-review.mjs <패키지> <블라인드> <봉인커밋SHA> <원시풀이폴더> <새검수폴더>`가 Git 커밋·현재 원시 파일·블라인드 사본을 대조한 뒤 기존 `verify-pack`의 답 공개 자료를 만든다. 읽을 수 없는 정답 기호/대체 문자/미해결 문자는 공개 전에 보류한다. 그 뒤 새 답·해설·그림·변형·학년·Unit/family·난이도/배점을 검수한다. Git 바이트 연결은 검수자의 사전 노출 부재를 증명하지 않으므로 실제 노출 이력도 기록한다.
5. `collect <패키지> <블라인드> <검수> <새결과JSON>`은 변경·자기검수·누락·보류를 차단하며 수학/학년 차원을 따로 집계한다. 출처·분류·권리·유사성·운영 provenance는 별도이고 현재 적재 가능 수는 항상 0이다. `dry-run <패키지>`는 실제 제작 파일/자산의 정합성 검사이며 수학 승인이나 DB 중복 검사가 아니다.

`render-preview.ts <새폴더> student|review <후보JSON...>`는 새 Markdown 표/문단을 보존하며 은행의 전처리와 KaTeX 옵션으로 로컬 지면을 만든다. 이미 구조화된 새 Markdown에 기존 OCR 재흐름을 적용하지 않는다. mathRenderQa의 기존 검사도 실행하지만 표 구조·그림/지면·학생 해설 적합성은 이미지와 독립 보고서로 별도 검수한다. 운영 Markdown/인쇄 경로까지 수정한 것으로 세지 않는다.

`compose-image-figure.mjs <PNG> <엔진SVG> <생성기록JSON> <새SVG> <새스펙> <수학조건JSON>`는 내장 imagegen으로 제작한 픽셀을 수정하지 않고 상황 삽화와 정확한 기존 엔진 도형을 별도 패널로 조합한다. 점/길이/각/해의 근거는 수학 조건이다. 생성 PNG·도구/정확한 프롬프트·스펙·그림 해시를 연결하고 블라인드 자산에도 픽셀을 보존한다. 앱에서 스킬을 직접 호출한다고 가정하지 않으며 운영 보안/serializer/표시/선택 계약을 구현한 상태가 아니다.

검사: `node --test scripts/import/exam-twin/candidatePack.test.mjs scripts/import/exam-twin/reviewWorkflow.test.mjs`. 합성 제어 시험은 실제 문항 독립 검산과 별도다.

봉인 후 원시 풀이의 문자 손상이 발견돼도 저자 답을 본 뒤 원본을 고치지 않는다. 해당 기록과 실패를 보존하고 새 미노출 검수자를 사용한다. `answerPresentation.mjs`는 제한된 소문항/이름/정확 상수/단위/단일 x 계수의 표기만 비교하며 수학·도형·학년 승인을 대신하지 않는다. `prepare-sealed-review.test.mjs`, `answerPresentation.test.mjs`, `constantAnswers.test.mjs`를 검사에 함께 넣는다.

그림을 묶기 전에 스펙을 실제 바이트에서 JSON 객체로 읽고, SVG는 손실 없는 UTF-8 해독과 제어문자/대체문자 검사를 거친다. 읽을 수 있는 SVG 뒤에 손상된 스펙이 있어도 통과하지 않는다. NUL로 채워진 파일이나 손상된 그림은 자동 복구하지 않고 기존 바이트와 실패 기록을 보존한 새 버전으로 처리한다. 정상 한글·BOM·CRLF는 허용하면서 각 파일의 원시 해시를 유지한다. 이 검사는 전송/파일 가독성에 한정되며 전체 XML 안전성, 스펙과 그림의 수학적 동치, 학년 적합성이나 승인까지 증명하지 않는다.

이름 없는 번호별 길이 답도 별도 문법으로 비교한다. 예: `(1) 18 cm; (2) 10 cm`와 `(1) 18cm (2) 10cm`. 각 소문항은 1부터 순서대로 최대 12개이며 ASCII `(1)` 또는 `⑴` 번호, 음이 아닌 정수/유한소수(정수부 최대 12자리·소수부 최대 6자리), 명시적 `cm`/`m`만 허용한다. 공백·선택적 소문항 끝 세미콜론·짝지은 `$`·단위의 `\mathrm`/`\text`·TeX 간격은 표기로 처리하고 cm/m 환산은 정확 유리수로 비교한다. 번호·순서·값·차원은 보존하며 이름 붙인 답과 섞거나 이름을 버리지 않는다. 누락/중복/건너뛴 번호, 설명문·잔여 문자, 단위 생략/다른 단위/면적·부피, 부호·분수·근호·변수·연산식은 이 새 문법에서 미지원이다. 기존 이름 붙인 답의 제한된 상수·관계 비교는 그대로다. 이는 표현 비교만 확장하며 기존 원시 풀이·후보·보고서나 승인 집계를 다시 쓰지 않는다. 실제 검수 집계의 재실행과 내용·그림 수정은 별도 작업이다.

`summarize-reviewed-batch.mjs <현재후보인덱스> <새결과JSON> <검수폴더...>`는 현재 저자 ID와 원본 바이트 해시로 정확히 한 검수를 선택한다. 같은 문항 번호의 이전 버전을 통과 집계에 섞지 않는다. 수집 시에도 블라인드 본문/그림과 답 공개 전 풀이 해시를 재확인한다. 동결 시 바뀐 자산 파일명은 따로 비교하고 내용·그림·자료 바이트는 같아야 한다. 결과는 수학/학년/내용·분류 보류와 전체 승인/적재0을 구분한다.

내용·분류 통과 집계는 보고서 `verified`뿐 아니라 실제 독립 수학·학년과 필수12검수 차원 모두의 통과를 요구한다. `unitFamilyFit=false` 등 하나라도 보류면 내용·분류 보류에 남긴다. 단순 보고서 상태의 수는 `contentReportVerified`로 따로 제공하며 승인 수로 읽지 않는다. 수학·학년의 개별 통과나 source/rights/native 별도 관문은 이 집계 수정으로 올리거나 내리지 않는다.

이름 없는 길이 소문항 사이의 쉼표 하나도 구분자로 허용한다. 완전한 길이와 다음 번호 사이에서만 소비하며, 소수점 대신 쓴 쉼표·이중 구분자·여분 수치·설명문·마지막 답 뒤 쉼표는 거절한다. 실제 봉인 답의 쉼표를 고쳐 쓰지 않는다. 비교기 변경 후에도 과거 실패 보고서는 그대로 보존하고, 같은 현재 입력을 새 버전의 검수/수집 결과로 연결한다.

`rebind-identical-review.mjs <기존검수루트> <현재선택인덱스> <원시풀이봉인커밋> <원시풀이폴더> <새검수루트>`는 동결을 중첩해 실제 저자 파일 대신 이전 패키지를 가리키게 된 경로만 새 버전에서 연결한다. 후보 전체 바이트(답·해설·출처·분류 포함), 학생 본문, 그림, Git 봉인 풀이와 검수 보고서가 모두 같아야 한다. 하나라도 바뀌면 `NEW_REVIEW_REQUIRED`로 중단한다. 기존 보고서의 보류/반려 사유와 수학·학년 집계는 그대로이며 새 승인을 만들지 않는다. 원본 증거를 수정하지 않고 새 작업폴더에만 쓴다. 입력 트리·공유 의존성·Git 내부·정션 경로에는 출력하지 않는다. 검수 파일을 쓰는 다른 작업이 없는 상태에서 실행하고, 실패한 출력 폴더를 덮어쓰지 않는다. 실제 GF14 재연결은 `rebind-identical-review-demo-20261019-r1`에 별도 보존했다.

`render-preview.ts <새폴더> student|review --bank-cap <후보들...>`는 기존 `figurePrintWidthMm`의70mm 상한으로 새 로컬 지면을 검토한다. 저자의 요청 폭/본문/그림 바이트는 보존하며 실제 표시 폭은 별도 기록한다. 그림 전용 선택지는 소유 SVG를 한 번만 배치하고 내부 저자 파일 경로를 문장처럼 렌더하지 않는다. 선택지 그림을3열로 묶어 큰 문제의 본문/보기가 갈라지는 것을 줄인다. 이 로컬 지면은 운영 inlineSVG/API/serializer/인쇄 전체의 호환 승인이 아니다.

`statisticsConditions.mjs`는 새 통계 문제 제작을 위한 정확 계산 지원이다. 도수 자료의 평균·중앙값·최대 도수·분산을 유리수로 계산하고, 평균에서 누락 관측값을 역추론하거나 빈 편차를 구한다. 최빈값 동점과 표준편차 비교의 등호를 유일한 답으로 세지 않는다. 경상 새 통계 7문항에 실제 사용했으며, 별도 전개 자료 방식으로 100개 분포를 대조한 제어 시험이 있다. 저자 계산과 독립 풀이·학년·family·권리·운영 엔진 등록은 별도이다. `statisticsConditions.test.mjs`를 위 검사 명령에 함께 넣는다.
