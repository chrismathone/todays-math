## Findings and attribution

**English OCR is a scope/prompt conflict, not evidence of failed Korean transcription.** `src/lib/dev-ai/tasks.ts:115` identifies Korean math materials and `:118` requires all natural language in Korean, while `:180` requests unchanged transcription. The raw output translated the English instruction; the helper keeps the original strict-transcription failure. Every printed number and all four choices survived. The incomplete-choice warning is generated deterministically by `src/lib/mathgen/ocr.ts:76`–`:106`, which marks any nonempty choice count other than five, rather than a model omission. The approved control uses both Korean and five choices and passes; it tests intended scope but does not isolate the causal effect of language from choice count.

**Page-crop failure is independent of the OCR language issue.** `tasks.ts:166` requires the body and choices; `sourcePrompts.ts:704`–`:706` explicitly requires the crop to end after the last choice, including a fourth choice when there are only four. The first returned normalized box ends at pixel y=229.5, while the printed choice row continues to y=240. It loses **843/3,606** dark source pixels (23.38%). The second box ends at y=499.5, before the printed `Answer:` and blank line ending y=545; it loses **1,118/2,594** pixels (43.10%). This is the author's blank answer space belonging to question 2, not a supplied answer key. Whether unused answer space is retained can be a separate product policy; question 1's mandatory options already establish the failure. This English synthetic page is not a measured error rate on Korean production papers.

**Checker correction is preserved.** The first page checker also used an erroneous x=510 anchor outside the authored text (actual first-question ink ends x=368). That assertion was removed, not relaxed into success. The revised diagnostic counts pixels `<128` in the original authored source bands and requires 99.5% retention. The same unchanged raw response still fails. An independent auditor confirmed source ink bounds and both clipped regions. The initial expectation, wrong anchor, replacement metric and unchanged result are recorded in external `criterion-history.json`; no model call was repeated.

**Wrapper gap is separately guarded.** The actual wrapper rejects incomplete stop reasons, but filters a mixed `tool_use` block if the envelope also says `end_turn` and contains text. The evidence validator independently rejects such blocks and requires assistant/message/model/usage/end_turn, with actual model equal to the captured model. No evaluated raw response used a tool. This is a recorded gap, not a product fix.

The minimum follow-up is a separately scoped product decision on the Korean-only transcription promise and four-choice warning, plus crop-quality handling that protects complete option rows. Preserve these failure fixtures in that work. Do not infer a production regression, change product defaults, or repair stored material automatically from this small evaluation.
