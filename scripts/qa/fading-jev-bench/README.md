# Jev 눈금 실험 — 우리 한국어 수학 문장에서 쓸 만한가

«오늘의 기억» 개편(`docs/planning/srs-overhaul-20261006.md` §9)에서 Jev 를 **오프라인 콘텐츠 검증**(함정 칩이 정말 틀린 답인가)에 쓸 수 있는지 먼저 잰다.
학생 자료는 쓰지 않는다 — 보내는 글은 개념 백지 은행의 우리 문장뿐이다.

## 무엇을 묻는가

개념 백지 은행의 ○× 문항은 참 · 거짓이 이미 붙은 문장이다(전수 검토를 거친 은행의 답이 기준이다).
소단원마다 요청 하나를 보낸다 — state 에 그 소단원의 뜻 문장들을 싣고, ○× 문장마다 «이 문장은 맞는가»를 Noul(예일 확률) 하나씩으로 묻는다.
○× 의 «까닭»은 싣지 않는다(답을 알려 주는 글이다).

| 변형       | state                   | 지시문 |
| ---------- | ----------------------- | ------ |
| `ref-en`   | 소단원 이름 + 뜻 문장들 | 영어   |
| `ref-ko`   | 소단원 이름 + 뜻 문장들 | 한국어 |
| `noref-en` | 소단원 이름만           | 영어   |

소단원을 열쇠의 해시로 둘로 가른다 — `dev`(열에 하나)에서 변형을 고르고, 숫자는 `test`(나머지)에서 고른 변형 하나로 낸다.

## 재기 전에 적는 규칙 (2026-10-06 · 결과를 보기 전에 썼다)

- **R1 거름망으로 쓸 만한가** — 확신 구간(noul ≤ 0.1 또는 ≥ 0.9)의 정확도가 **97% 이상**이고 그 구간이 전체의 **60% 이상**이면, «확신 구간은 기계가 · 나머지는 사람이» 보는 식으로 쓸 수 있다.
- **R2 해로운 틀림** — 은행이 «참»이라 한 문장을 noul ≤ 0.1 로 본 것이 참 문장의 **1% 이하**여야 한다.
  함정 칩 검증에서 이 틀림은 «넣어도 맞는 답을 함정으로 남기는 것»이라 학생이 맞게 풀고 틀렸다는 말을 듣게 된다.
- **R3 기준 문장을 읽고 답하는가** — `ref-en` 이 `noref-en` 보다 정확해야 한다. 차이가 없으면 Jev 는 준 글이 아니라 제 지식으로 답한 것이고, 그때는 «기준 문장에 비추어» 묻는 꼴이 뜻이 없다.
- 실패한 요청과 읽히지 않은 답은 빼지 않고 **«못 잼»**으로 센다.
- 문턱 0.5 의 전체 정확도는 적기만 한다(판정에 안 쓴다).

R1 · R2 둘 다 서야 «쓸 만하다»고 적는다. 하나라도 안 서면 그대로 적고, 문턱을 결과에 맞춰 옮기지 않는다.

## 실행

저장소 뿌리에서. 키는 서버 환경의 `TYPESAFE_API_KEY` 하나만 읽는다(값을 찍지 않는다). 워크트리에는 `.env` 가 없으니 main 의 것을 넘긴다.

```bash
npx tsx scripts/qa/fading-jev-bench/run.ts --dry                       # 보내지 않고 요청 수 · 글자 수만
npx tsx scripts/qa/fading-jev-bench/run.ts --split dev --variant ref-en
npx tsx scripts/qa/fading-jev-bench/run.ts --split test --variant ref-en
npx tsx scripts/qa/fading-jev-bench/run.ts --split test --variant ref-en --report-only
```

원자료(소단원별 답)는 Git 밖 `.qa-artifacts/fading-jev-bench/` 에, 요약은 이 폴더의 `summary-<변형>-<갈래>.json` 에 남는다. 같은 명령을 다시 치면 끝난 소단원은 건너뛴다.

## 결과 (2026-10-06 · `jev-1.13.0` · 한 번 돌림)

`dev`(34 소단원 · 665문장)에서 세 변형을 견줬다. `ref-en` 과 `ref-ko` 는 거의 같았고(정확도 97.1% · 97.3% · 확신 구간 83.2% · 81.7%), 지시문이 짧은 `ref-en` 을 골랐다.
아래는 `test`(326 소단원 · 6,282문장 — 참 3,023 · 거짓 3,259)다. 못 잰 것은 0 이다.

|                           |              `ref-en` |          `noref-en` |
| ------------------------- | --------------------: | ------------------: |
| 문턱 0.5 의 정확도        |                97.47% |              94.38% |
| 확신 구간이 차지하는 몫   |                81.88% |              58.99% |
| 확신 구간의 정확도        |                99.57% |              99.43% |
| 참을 확신하고 거짓이라 함 |            0.36% (11) |               0.30% |
| 거짓을 확신하고 참이라 함 |            0.34% (11) |               0.37% |
| 요청 하나의 중앙 시간     |                0.21초 |              0.20초 |
| 입력 토큰 · 어림 값       | 1,235,612 · 0.052달러 | 811,224 · 0.034달러 |

- **R1 선다** — 확신 구간의 정확도 99.57%(≥ 97%) · 몫 81.88%(≥ 60%).
- **R2 선다** — 참을 확신하고 거짓이라 한 것 0.36%(≤ 1%).
- **R3 선다** — 뜻 문장을 주면 정확도가 3.1%p, 확신 구간이 22.9%p 는다. 뜻 문장 없이는 R1 이 안 선다(몫 58.99%).

갈래별(`ref-en` · test):

|           |  문장 | 정확도 | 확신 구간 | 확신 구간의 정확도 |
| --------- | ----: | -----: | --------: | -----------------: |
| 글만      | 3,465 | 98.33% |    84.07% |             99.79% |
| 수식 있음 | 2,817 | 96.41% |    79.20% |             99.28% |
| 난이도 하 | 2,214 | 98.60% |    86.63% |             99.79% |
| 난이도 중 | 2,083 | 97.50% |    83.05% |             99.60% |
| 난이도 상 | 1,985 | 96.17% |    75.37% |             99.26% |

학년별 정확도는 96.7% ~ 97.9% 로 고르다(중3 이 가장 낮다).

**확신하고 틀린 22문장을 전부 읽었다.** 은행의 답이 틀린 것은 없었다 — 전부 Jev 쪽이 틀렸다. 몰린 자리는 공식 문서가 적은 약점 그대로다.

- 수 · 세기 — «$10000$이 $60$개인 수는 육만이다»를 참으로, «팔각뿔은 구면체이다»를 거짓으로 봤다.
- 낱말 하나로 갈리는 문장 — «최소공배수는 두 수를 모두 **나누어떨어지게 하는** 가장 작은 수»를 참으로, «삼각뿔에는 **각뿔의 꼭짓점**이 4개»를 참으로 봤다.
- 식을 세워야 가려지는 문장 — «$x$가 $y$의 $\frac{3}{4}$이면 $3x=4y$»를 참으로 봤다.

### 이 숫자가 말하지 않는 것

- 잰 것은 **은행의 ○× 문장**이다. 쓰려는 자리(핵심어를 다른 핵심어로 바꿔 넣은 문장)는 꼴이 다르다 — 바꿔 넣은 문장은 말이 어색하거나 반쯤 맞을 수 있다. 그 문장들로 작은 표본을 따로 재야 한다.
- 한 번 돌린 값이다. 같은 요청을 다시 보냈을 때 답이 같은지는 재지 않았다.
- 학생이 쓴 글을 채점하는 일은 재지 않았다.
- 확신 구간에서도 250문장에 하나쯤은 틀린다. 수와 식이 든 문장은 그 두 배쯤이다.
