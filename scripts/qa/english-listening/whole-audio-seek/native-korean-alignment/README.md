# CPU Korean CTC alignment experiment

Completed: two pinned public CTC models, the same 30 native clips, 60 CPU
inferences, independent source/input hash proof, and eight focused tests.
See [RESULTS.md](RESULTS.md) for actual findings and immutable private evidence.
This folder has no admission, database, Storage, or seek-start writing code.

- `prepare_controls.py`: freeze existing 10/10/10 controls; replay exact product
  native PCM, verify full/clip hashes, and reproduce the raw mono 16 kHz input.
- `ctc_core.py`: exact literal spans, recorded numeral/jamo transforms, strict
  vocabulary, standard full CTC Viterbi with repeated-label blank requirements.
- `run_alignment.py`: CPU threads two, offline local public weights, complete
  emissions/token-frame posteriors/word timings, exact execution/model/environment
  hashes, and private code snapshots. No interpolation or ASR timestamp fallback.
- `analyze_results.py`: descriptive paired comparisons; no fitted decision gate.
- `seal_evidence.py`: independently reproduce paths from saved emissions, recheck
  literal/input provenance, run tests, archive code/config for later review.
- `freeze_model.py`: bounded unauthenticated download of the pinned small model.
- `test_ctc_core.py`: meaningful brute-force CTC, missing-text, repetition,
  normalization, provenance, and immutable-output regressions.

The earlier unexecuted Gemini prototype is preserved byte-for-byte in private
`gemini/prior-unexecuted-prototype/`. Successful results came from these new tools.
Negative clips deliberately use their intact pair's existing reliable instruction;
this never claims the negative's ASR heard the supplied text.
