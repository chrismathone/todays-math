`convert-reference.ts` produces `exchange-semantic.json`, a strict TextbookExchange with optional source nodes, and `exchange-base.json`, an explicitly documented compatibility projection. The original board remains a separate node; raw rows carry `textFormat: v15-tex`; speech titles, original question IDs, TeX bodies, public examples and unsolved confirmations are preserved. Source-authored concept1/2/3 diagrams and tables are extracted into the bounded safe fragment contract from the trusted original functions because their content is absent from the manuscript page objects. This extraction does not print or render the ZIP application. Private source trees and raw question records remain in `source-map.json` outside Git. Original chapter PNGs and the sanitized mindmap SVG are hash-verified image assets.

The render harness calls the existing `launchExportBrowser`, `renderTextbookChunk` and `mergeTextbookPdfs`. In `base` mode each original source page is scoped to a separate bounded call because the old continuation policy chains all 36 sections together; this is compatibility evidence, not G0 acceptance. `semantic` mode requires the integrated reference template isolation/renderers. Both outputs use the original U01 source, with answer pagination independent of student pagination and references supplied from verified student chunk pages.

`geometry.py` inventories all PDF pages, fonts, spans, images and horizontal vector operations. Its verification mode requires the matching PDF SHA and complete DOM coverage declarations. It checks 0.5 mm coordinates, row keys and phase-relative page splits, vector write-line width 0.2–0.35 mm, pitch 7±0.5 mm, written line length, thick grey bands, QR placement, dialogue fonts, semantic disabled nodes and student answer fields/roles. It deliberately does not search ordinary prose or choices for matching answer words. PDF spans cannot reveal a glyph clipped before painting; the DOM clipping witness remains required. Filled thin vector rectangles count as vector lines, while raster gradients do not.

The mutation suite proves failures for deliberately broken geometry and semantics; source conservation rejects changed answers and TeX. Those passes establish the QA guards and functional answer handling. They do not establish visual equality, editorial mathematics approval, G0b actual-bank assembly, saved draft/published compatibility, all human page review, or physical printing. Missing anchor/row/semantic DOM evidence is reported as failed coverage, never silently accepted.

Final QA adds original-template computed geometry, inline typed source images, final DOM population accounting, same-region comparison HTML, and read-only real-bank fixtures. `source-computed.ts` measures all 36 original U01 DOM sheets, including all four dialogue sheets while fitting, and runs the exact source alignment/writing/conversation helpers after original fonts and images load. Every rendered source page requires a nonempty matched oracle and its pinned SHA. Optional `allocation-only` saves actual pre/post native writing allocation without duplicating portable HTMLs: direct question order, matched spreads, base/final line counts, offsets, margins, padding, borders and content/footer limits. This measures the original CSS; it never substitutes a ZIP PDF for the pinned reference. Container boxes, text-Range boxes and pinned PDF glyph ink remain distinct.

`dom-witness.ts` extracts print-media DOM roles and geometry from final chunk HTML and reconciles actual block/row/QR/writing/clip populations with the render model and placements. Version 2 PDF checks reject missing population evidence even if all coverage flags claim success. `extract-existing.ts` independently extracts the stored failed baseline without overwriting its original PDFs or witnesses; unavailable historical placement coordinates stay invalid. All private outputs and portable HTMLs remain in Downloads. The source bank fixture retains actual IDs, body/answer/solution/TeX, diagram metadata, source and meaningful `elem:`/`mid:` family pairs; missing descriptive questions remain shortages.

The converter copies native `section_name` exactly and derives question widths from their actual original parent grids. It emits body fragments before and after the native question slot in original order. Nested oral questions remain interleaved with their own following listener prompts and the final rubric, with copied source wrappers. Raw trees, question IDs/types/text/TeX/answers and base lines stay unchanged. A native end note leaves body flow only when the original `fullSheet` does the same relocation. `load-final-dom.ts` substitutes only repeated base64 resource URLs during inspection, serves byte-identical decoded resources on the already permitted origin, and records every resource SHA and both HTML SHAs. Original production HTML remains saved. `recapture-reference.ts` re-extracts the same stored student HTML using verified original chunk placements and the matching PDF hash; it preserves the prior witness.

The native `fullSheet` moves a final direct-child checkbar/study footer/continuation note outside body flow. The adapter mirrors that decision on a copied tree, retaining the original AST/hash separately and placing the exact safe fragment in optional `semantic.sourceFooter` once. Native question headers are separately captured by executing the original function with its actual caller options; `semantic.sourceQuestionHeader` contains only the original header children and exact labels/number. Empty QA-only body blocks are not invented for relocated notes. `inspect-source-questions.ts` compares original portable DOM and stored final DOM CSS without rerendering a book; `inspect-actual-failure.ts` measures actual frozen bank sections with official model/measurement code and verified assets.

`recapture-reference.ts DIRECTORY [SOURCE_GEOMETRY_JSON] [EXTRACTION_LABEL]` saves an independently named witness and binds its source-oracle SHA. Explicit native question/head/number/prompt/work and footer anchors are part of the final comparison. A native public-example question excludes its separate solution; its mapped actual header/question union is measured directly. Coverage flags prove the declared populations, while coordinate equality and all observed omissions remain separate failed checks.

`verify_exports.py` checks every actual PDF page and exports at least three actual PDF images per available variant, selected from observed fractions, figures, written stages, dialogue, memory rows and writing spaces plus page-position samples. Missing actual PDFs fail; an unavailable bank feature is never replaced with synthetic content. Samples remain pending human review. Preserve the failed original 55/60-page files and give every renderer retry a fresh private output directory/run tag.

Whole-run automatic verification requires the writer's final `local-pglite-manifest.json`; `--only` can inspect combinations already recorded as settled in `automatic-summary.json`. This avoids declaring a still-writing answer variant missing. Answer checks compare every actual problem's reference to its final student DOM placement and to the printed label extracted inside its actual PDF answer box. `test_export_references.py RUN --output PRIVATE_JSON` rejects in-memory mutations of the frozen representative exports without changing their PDFs/witnesses. Fraction samples recognize `\\frac`, `\\dfrac`, `\\tfrac` and `\\cfrac` in actual problem nodes. Zero page/ancestor-clipping issues do not prove that adjacent math lines have enough space or that subtitles stay with their next speech; actual PNG reading remains necessary.

`archive-inactive-html.py RUN` archives only completed automatic student/answer pairs; `RUN --source-complete` requires a complete source student/answers pair with matching PDF, export, witness and placement counts. Both modes verify exports whose PDFs and witnesses match their export hashes. It streams each final chunk HTML to gzip, checks original and decoded length/SHA, persists `inactive-html-lossless-archive.json`, and then removes that verified individual uncompressed copy. Active combinations and PDF/PNG/JSON evidence stay untouched. The archived bytes remain readable by `readFinalHtml`.

Final DOM extraction includes those safe-fragment writing containers.
