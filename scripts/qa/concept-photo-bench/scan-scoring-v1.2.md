# 채점 수정 v1.2 — 전체 측정 후 오류 목록 검토

모든 모델 호출이 끝난 뒤, d1-p08 q4.b2의 `60°`를 `60˚`(U+02DA)로 출력한
Opus low / cascade / raw-low / 1회차 1건이 순수 기호 모양 차이로 남아 있음을 발견했다.
손으로 쓴 각도 칸으로 이미 지정한 세 칸에서만, 같은 수치 뒤의 `°`와 `˚`를
채점할 때 동등하게 본다. 숫자가 다르거나 `'`(분 기호로도 쓰임)인 경우는 면제하지 않는다.

사후 수정임을 명시한다. 원래 호출·시행 파일·참값 후보·twice 보류·최종 격자 선정에 쓴
v1.1 점수는 바꾸지 않는다. `summarize`에서만 명시적으로 켜고, v1.1 점수와 면제 1건을
보고서에 함께 남긴다. 전체 확신 오독은 94→93이며 최종 권고는 Opus high / whole /
raw-high로 그대로다. 추가 모델 호출은 하지 않았다.
