# 채점 수정 v1.1 — 최종 모델 격자 실행 전 고정

1단계 중간 오류 목록에서 표기 차이를 흠으로 세는 결함을 발견했다. 최초 사전 등록으로
소급하지 않는다. v1 원점수·원출력·참값 후보 58칸/사람 확인 27칸·twice의 보류 결정은
그대로 보존한다. 공통 normalize()는 바꾸지 않고 **채점 전용 비교**만 추가한다.

- d1-p01 q4.b1은 ‘한 변의 길이를 __ 해서 구한다’는 수치 곱셈 칸이다.
  이 칸에서만 ×4 / x4 / X4 / X 4를 같은 표기로 센다. 전역 x→× 치환은 하지 않는다.
- 한글 문장 끝의 마지막 마침표만 있어도/없어도 같다. 소수점과 숫자 구분자는 유지한다.
- d1-p07 q7.answer의 ‘오른 구간’·‘내린 구간’ 뒤 : / =는 문장 항목의 구분자다.
  이 칸에서만 동등하게 센다. 수학 등식의 =를 바꾸지 않는다.
- d1-p01 q6.b1·q14.b1, d1-p08 q4.b2의 같은 각도 수치에서 °만 빠진 경우는
  **경미한 단위 누락**으로 따로 센다. 엄격 전사 오류에는 남기고, 내용 오독 민감도에서만
  분리한다. 일반적인 단위 삭제·정답 숫자 복원은 하지 않는다.
- 작다/작아, 직사각형/직삼각형, 8,5/8,15, 실제 필기/빈 답, 여백 계산 유입은 면제하지 않는다.

모든 팔·그림·회차에 동일하게 재생한다. ‘v1 엄격 오류 / v1.1 순수 표기 제외 오류 /
경미 단위 누락을 뺀 내용 오독’을 함께 보고하고 면제 내역도 모두 남긴다.
원래 순위와 수정 순위의 상위 두 조합 합집합 및 whole/raw-high 대조군을 최종 세 모델
측정에 포함한다. 순위가 바뀌면 표기에 민감한 결론임을 적는다. 모델 호출·출력을 다시
만들어 과거 시행을 덮어쓰지 않는다. 이 수정은 표본 오류를 보고 만들었으므로 별도 표본
검증이 필요하며 그 한계를 보고서에 명시한다.
