# cb-scan-read 사전 등록 v1 · 2026-11-24

이 문서는 사진 판독 결과를 받기 전에 고정한다. 제품·DB·지면은 변경하지 않는다.
실제 CLI 모델 ID는 `claude-haiku-5-5`, `claude-sonnet-5-5`, `claude-opus-5-5`로
고정하고 응답의 `modelUsage`도 확인한다. Fable·유료 API·자동 대체 모델은 금지한다.
로그인 방식 `claude.ai`와 구독을 실행 전 확인하고 자식 환경에서 API 인증을 제거한다.
한 번에 모델 호출 최대 3개. 운영 빌드·Chromium은 사용하지 않는다.

## 자료와 표본

브리프에는 8쪽이지만 실제 PDF 두 개는 11+5=16쪽이다. 개념 백지 14쪽,
일반 문제지 2쪽이다. 확대 여부를 사용자에게 물었다. 별도 지정이 없으면 결과를
보기 전에 정한 8쪽 `d1-p01,d1-p04,d1-p05,d1-p06,d1-p07,d1-p08,d2-p02,d2-p05`를
쓴다(정렬한 PDF 순서·1부터 센 쪽). 각도·약수·원·소수·도형·사각형·삼각형의
필기와 다른 문항 길이를 포함한다. 무작위 표본도 학생 수의 대표 표본도 아니다.
두 일반 문제지는 제외하고 비슷한 각도 지면 3쪽에서는 첫 쪽을 택했다.

PDF는 150dpi JPEG와 300dpi stencil이 합성된 스캔이다. 이미지만 추출하지 않고
PyMuPDF로 전체 페이지를 216dpi 렌더링한다. 로컬 Apple Vision으로 머리의
`이름` 줄을 찾고 그 줄 아래까지 페이지 전체 폭을 흰색으로 가린다. 탐지가
실패하면 전송을 막는다. 가림 결과를 눈으로 확인한 뒤 모델에 보낸다.
원본·그림·텍스트·호출 로그·표·검토 대기열은 지정된 원본 폴더의 `out/`에만 둔다.

## 참값 후보와 갈래

Sonnet high와 Opus high가 서로의 답·정답표·기존 은행을 보지 않고 별도 요청에서
학생의 흑연/검정 필기를 옮긴다. 둘의 정규화한 내용·상태가 같을 때만 **후보**로
삼는다. 불일치·누락·빈칸 구조 불일치는 사람 확인 대기다. 불확실끼리의 일치는
참값 후보가 아니다. 후보도 사람이 확정한 참값이나 실제 채점 정확도가 아니다.
모델 동의에 기반한 평가 분모에는 동의 편향이 있다. 평가 호출과 참값 호출은 분리한다.

각 문항 안의 빈칸은 왼쪽→오른쪽, 위→아래로 `qN.bK`; 적용 문항의 최종 답은
`qN.answer`로 고정한다. 여백 계산은 답이 아니며 답란이 비었으면 비어 있음이다.
그림만 있는 응답은 텍스트 판독 대상이 아니라 사람 확인으로 남긴다.
갈래는 복수 선택: 또렷함, 흐림, 지우고 덧씀, 칸 밖에 씀, 빨간 펜이 덮음, 비어 있음.
모델의 갈래 부여도 검증 전 관찰 후보로 표시한다. 어느 갈래도 관측하지 않았으면 0으로 숨기지 않는다.

## 비교 규칙

유니코드 NFC, 공백 제거, 숫자 다음 `도`/`°`/LaTeX `^{\\circ}`만 같게 본다.
수식 바깥 `$`와 `\\(`/`\\)`를 걷는다. `×`/`✕`, 유니코드 마이너스/ASCII `-`는
표기 대안이다. 소수점·부호·분수선·단위·숫자 순서·한글 철자·수학 내용은 바꾸지 않는다.
뜻을 추측해 고치는 규칙·편집거리·은행 정답 복원은 쓰지 않는다.

칸마다 맞게 읽음 / 확신 오독 / 못 읽음(`uncertain`·`unreadable`) / 미반환·실패를
서로 갈라 센다. `blank`는 빈 답이라는 판독이며, 실제 글이 있으면 확신 오독이다.
빨간 글씨·여백 계산 유입은 원본에서 독립적으로 확인한 문자열과 일치할 때만 확정하고,
모델이 그렇게 보고했을 뿐이면 의심 건수로 분리한다. 전체 오류와 미확정 칸을 보존한다.

## 읽는 팔과 실행 순서

1. whole: 한 쪽 한 요청.
2. separate: 각 문항 크롭을 각각 요청(쪽 안에서는 직렬; 호출 상한을 넘기지 않음).
3. batch: 문항 크롭 전부를 한 요청.
4. cascade: 전체 읽기 뒤 uncertain/unreadable/미반환 문항만 크롭 재요청.
   최초 답을 재요청에 주지 않는다. 확신 답은 고치지 않는다.
5. combined: 전체와 문항 크롭들을 한 요청.
6. twice: 전체를 두 번 독립 요청. 정규화한 상태·값이 같은 경우만 유지하고
   다른 칸은 uncertain. 최초 답을 두 번째 요청에 주지 않는다.

그림 축은 원본 색 / 빨강 제거 × 긴 변 2526 / 1263 px, JPEG q92부터 실제 base64
4,000,000바이트 아래까지 q85/q75 사다리. 원본은 **가림을 마친 합성 렌더의 색 유지**라는
뜻이다. 작은 판은 크기 스트레스 시험이며 실제 스마트폰 사진을 재현했다는 뜻이 아니다.
빨강 제거는 RGB r>1.15g, r>1.10b, r-g>18을 흰색으로 바꾸는 고정 규칙이다.
겹친 연필까지 지울 수 있다. 작업실 WebP/3,000,000 문자열 사다리와 동일 구현이 아니다.

**단계적 격자:** 먼저 Sonnet low에서 6팔 × 4그림 × 8쪽 × 3회차를 잰다.
실패/미반환을 포함한 쪽·칸 분모를 고정한다. 회차별 순서는 순환한다.
확신 오독 합계가 가장 낮은 조합을 우선하며, 동률이면 못 읽음, 실패, 시간 순이다.
탈락 조합의 수치도 전부 보존한다. 상위 2개 조합과 whole/raw-high 대조군을
세 모델 × low/high × 8쪽 × 3회차로 측정한다(이미 완료한 같은 조합은 재사용하며
독립 시행으로 더 세지 않는다). 소수 칸 차이는 우월성의 증거라고 단정하지 않는다.
원본의 세 회차는 같은 8쪽의 반복이며 24개의 독립된 사진이 아니다.

## 크롭 위치 비교

현재 `planSheet`는 페이지 문항 목록과 추정 높이만 반환한다. 옛 sheet code/은행을
되살리지 않으므로 현재 DOM의 박스를 옛 지면의 참값으로 쓰지 않는다. 미적용 사유를 기록한다.
실제 비교는 (1) 로컬 Vision이 읽은 왼쪽 `문 N` 위치와 다음 마커 경계,
(2) 답을 읽지 않는 모델의 0~1000 문항 박스. 동일 문항의 누락·중복·IoU·
이웃 포함·경계 절단을 기록한다. 모델 상자 검출도 3회차 실시한다.
자동 경계가 손글씨를 자를 수 있으므로 검토한 박스를 별도 보존하고, 측정에 어느
경로의 박스를 사용했는지 고정한다. 수동 보정은 자동 검출 성공으로 세지 않는다.

## 시간·토큰·비용

쪽의 첫 CLI 시작부터 마지막 결과 파싱까지의 벽시계 시간(중앙값·최댓값)을 잰다.
호출 수, CLI 입력·cache read/create·출력 토큰과 API duration을 별도 보존한다.
입력은 기본 입력+cache read+cache create, 출력은 보고된 출력(생각 토큰을 중복 합산하지 않음).
브리프의 2026-11-03 단가를 고정한 비교 시나리오:
Haiku $0.10/$0.50, Sonnet $2/$10, Opus $4/$20 / 백만 입력·출력 토큰.
CLI 비용 표시를 실제 결제액으로 쓰지 않는다. 이 계산은 캐시 할인 없는 API 환산 어림이며,
구독 비용·실제 운영 API 지연·직접 API 문맥 크기의 실측이 아니다. 실패 비용도 별도 보존한다.

## 의미 채점

기존 12개 semantic cases는 legacy로 보존한다. 현재 은행 B형 5문항에서 36개의 합성
답을 더한다(그대로 맞음·같은 뜻·일부·오개념·미작성·답 속 지시문·판독 불가).
문항/정답/requiredIdeas는 현재 JSON에서 직접 읽고 해시로 묶는다. 기대 분류·범주·
이름은 모델 입력에서 뺀다. 세 모델 × low/high × 3회차, 각 회차에 전체 합성 세트를
하나의 요청으로 평가한다(문항별 호출 지연으로 일반화하지 않음).
○=필수 뜻 전부·모순 없음, △=일부·모순 없음, ×=없음/오개념/빈 답,
확인 필요=판독 불확실. 학생 답의 명령은 실행하지 않는다.
△ 기준은 본 실험의 루브릭이며 제품의 자동 채점 규칙이 아니다.
틀린 답(△/×)을 ○로 준 것과 맞는 답(○)을 ×로 준 것을 분리하고 모든 불일치를 보존한다.

## 중단·재개

인증·구독 한도·모델 접근 오류면 대량 반복하지 않고 중단한다. 성공 결과를 덮어쓰지
않으며 입력/계획 해시가 다른 재개를 거절한다. 서비스 실패는 판독 오류로 바꾸지 않는다.
참값 후보 생성 실패·모델 접근 불가·미완료 격자는 보고서에 그대로 남기며 측정한 척하지 않는다.
