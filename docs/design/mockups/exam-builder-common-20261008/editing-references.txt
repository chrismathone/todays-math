공개 자료에서 확인한 동작

1. 매쓰플랫 공식 「학습지 만들기」
https://guide.mathflat.com/guide/teacher/worksheet-create
범위·수량·난이도 조건으로 추천받은 문항을 상세 편집하고, 마지막에 양식을
설정한다. 상세 편집에서 문항 카드/목록 손잡이를 끌어 순서를 바꾸며 화살표도
지원한다. 새 문제 추가와 유사 문제에서 개별 추가·교체가 가능하다.
공개 상세 편집 이미지도 확인했다. 목록/요약과 선택 문항을 나란히 놓는다.
https://guide.mathflat.com/assets/img/teacher/worksheet-create/step2.webp

2. 매쓰홀릭 라이트 공식 「단원별 문제은행」
https://hello-matholiclite.oopy.io/39f53167-4e37-8081-aa3d-d126bbac14d0
공식 제품 페이지의 사용가이드 링크에서 접근한 문서다.
https://lite.matholic.com/main
과정·단원, 난이도, 수량을 정하면 문항을 불러오고 교체·추가·삭제한다.
공개 화면에서 단원 트리와 출제 조건, 선택 문항과 후보 카드들을 함께 확인했다.
단원/난이도 조건이 좁으면 요청 수량보다 적게 나올 수 있다고 명시한다.
제작 끝에는 제목, 템플릿, 단 수, 문제 간 여백을 설정한다.

확인 범위
- 로그인한 운영 화면을 사용한 것은 아니다. 공개 가이드의 본문과 화면 이미지 기준이다.
- 매쓰홀릭 라이트 문서의 기능을 매쓰홀릭 전체 제품의 동일 구현이라고 일반화하지 않는다.
- 타사 난이도 척도·문항·브랜드·화면 이미지는 시안에 복사하지 않았다.

우리 시안에 적용한 설계 판단
- 이미 정해진 수학/영어 맥락 → 범위 선택 → 초안 편집 → 공통 양식 구성 순서 유지.
- A~E 모두 같은 추가 창: 실제 후보의 난이도, 선택 범위, 본문 검색 → 문제별 추가.
- 추가 창을 유지하여 연속으로 담는다. 추가된 카드는 원래 위치에서 ‘추가됨’으로
  바뀌고 중복 입력을 막는다. 난이도 수치는 아직 담지 않은 후보 수다.
- 난이도 명칭은 기존 예시 데이터 그대로 읽는다. A/B의 기본·응용, C/D의 기본·적용,
  E의 기본·보통·심화를 같은 척도로 임의 환산하지 않았다. UI와 필터 동작은 공통이다.
- 12개 단위 후보 페이지와 정확한 무결과 안내. 조건을 몰래 넓히지 않는다.
- ⠿ 손잡이로 마우스/터치 이동, Space/Enter와 방향키로 이동, Escape로 취소.
  기존 화살표와 실행 취소도 유지한다.
- D는 상태 배열 순서로 연속된 단원 묶음을 렌더한다. 다른 단원 사이로 옮겨도
  문항의 소속 단원과 연결 지문은 유지된다. 출력도 같은 순서를 전달한다.
- 데스크톱 좌우 20px, 모바일 16px. 내용에 맞는 추가 창 높이, 한 행에 한 문항,
  편집 지면 최소 높이 제거, 넓은 D 화면의 설정/문항 50:50 배치를 적용했다.
- 실제 출력은 기존 WorksheetEditor가 담당한다. 인쇄용 풀이 공간/쪽 나눔은
  편집 화면 여백 조정과 독립적이다.

검증
- editing-validation.json: 5안 × 수학/영어 × 1440/390px, 20건.
  난이도 조건, 개별/연속 추가, 중복 차단, 무결과, 필터 유지, 키보드 순서, 실행 취소.
- editing-layout-validation.json: 320/760/860/861/1024/1200/1440/1920px의 40건과
  5안의 마우스/실제 터치 입력 10건. 마우스 5건은 공통 양식 화면 왕복까지 확인.
- question-reorder-qa.txt: 독립 모듈의 취소/중첩 지문/격자/다시 렌더/정리 검증.
- 이는 예시 문항을 사용하는 시안 검증이다. 운영 문제은행 연결·대량 데이터 성능·
  실제 단말 브라우저 호환성 전체 검증을 뜻하지 않는다.

D 확정 후 사용자 피드백
- 좌측 설정, 우측 문항만 표시. 모든 검토 목록은 한 행에 한 문항이다.
- 제목과 출력 버튼을 한 행으로, 단원명과 문항 수를 한 행으로 합친다.
  좌우 상단 도구 행은 70px, 그 아래 영역 시작점도 같게 맞춘다.
- 교체 창은 우측 문항 열과 같은 너비로 중앙에 열고 크기 변경 시 다시 측정한다.
  추가 창의 너비와 공통 출력 화면의 양식 설정은 기존 동작을 유지한다.
- 수학/영어 320~1920px의 16개 D 배치에서 동일 열 너비·상하 정렬·가로 넘침을 확인했다.
  교체 창은 두 과목 5개 너비에서 실제 열과 일치, 중앙 배치, 한 열 후보, 교체·무결과를 확인했다.
- 구성 전후 너비: 일반 스크롤바 환경에서 문항 생성 후 스크롤바 15px이 생겨
  좌우 열이 각각 7.5px 줄어드는 현상을 재현했다. D 화면의 루트에 화면 전용
  scrollbar-gutter: stable을 적용해 스크롤바 공간을 처음부터 유지한다.
  두 과목 320~1920px의 16개 배치에서 구성·되돌리기 전후 열 위치와 너비,
  구성표 내부 열 너비가 동일하고 가로 넘침이 없음을 확인했다.
- 드래그 위치 표시는 40px 높이의 옅은 파란 안내 영역과 가운데
  ‘여기로 문제 이동’으로 변경했다. 기존 문항 배치와 이동 위치 계산은 유지한다.
  D 1440px의 마우스 이동, 390px의 실제 터치 이벤트, 키보드 취소와 되돌리기에서
  문항 순서와 표시/숨김을 확인했다.
