사용자 결정
- ‘오늘의 수학’ 또는 ‘오늘의 영어’에서 들어올 때 과목이 이미 결정된다.
- 시험지 만들기에서 과목을 다시 선택하지 않는다. query는 외부 제품 맥락을 모사한다.
- 공통 포맷은 화면 구조와 교체·추가·삭제·순서·출력 조작에 적용한다.
- 몇 개의 단원을 모두 펼친 폼이 아니라, 실제 큰 범위를 탐색하는 흐름이 필요하다.
- DESIGN.md와 docs/design/workspace-ui-rules-20261008.md를 기준으로 제작한다.
- 마지막 단계는 문제 추출의 시험지 구성 화면을 함께 사용한다. 시안마다 별도 출력 폼을 만들지 않는다.

난이도별 추가 · 드래그 이동
- 다섯 안 모두 ‘문항 추가’에서 난이도/선택 범위/본문 검색으로 후보를 좁힌다.
- 원하는 문제의 추가 버튼을 눌러 연속으로 담고 ‘완료’로 돌아온다.
  이미 추가한 문항과 남은 문항 수를 구분하며, 중복 추가와 범위 밖 추가를 막는다.
- 교체도 같은 후보 화면을 사용하며 기존 문항 번호에 반영한다.
- 각 문항의 ⠿ 손잡이를 마우스나 터치로 끌어 원하는 위치에 놓는다.
  키보드는 손잡이에서 Space/Enter → 방향키 → Space/Enter, Escape는 취소다.
- 번호·영어 지문·출력 순서는 문항 순서와 함께 갱신된다. 실행 취소를 지원한다.
- 화면 폭은 문항 카드 열과 편집 작업에 배정하며, 860px 이하는 모바일 배치다.
  인쇄 지면은 공통 출력 컴포넌트의 양식 설정을 따른다.
- 공식 매쓰플랫/매쓰홀릭 라이트 가이드 관찰과 적용 판단은 editing-references.txt 참고.

공통 양식 구성 · 출력
- A~E의 마지막 버튼은 같은 /dev/exam-builder-output 화면을 연다.
- 실제 WorksheetEditor / PrintOptionsPanel / WorksheetPrint를 직접 import한다.
  문제 추출이 UnifiedWorkspace의 export 단계에서 사용하는 동일한 컴포넌트다.
- 평가원·정통·모던·워크북·자습·유형, 제목·기관명, 단 수·글꼴·간격·정답지 등
  기존 화면의 설정과 지면을 재사용한다. 인쇄 지면과 쪽 나눔은 실제 렌더러가 맡는다.
- 검토한 문항의 본문·보기·지문·정답과 순서를 메모리로 전달한다.
  돌아오면 제목·삭제·순서 변경을 반영하며, 재진입해도 양식 설정을 유지한다.
- 개발 전용 화면이다. 계정 저장 없이 임시 작업을 확인하고 브라우저 인쇄를 사용한다.
  서버가 필요한 HWPX/PDF 내보내기는 시안 안내만 표시한다.
- 기존 운영 제작 화면과 인쇄 컴포넌트는 변경하지 않았다.

공통 범위 선택
- 본 화면에는 선택 수와 최대 두 개 범위 + 나머지 수만 요약한다.
- ‘범위 변경’으로 학년·과정 / 자료 필터와 검색을 연다. 필터는 선택을 지우지 않는다.
- 대단원 펼침, 차시 선택, 대단원 전체 선택(부분 선택 상태), 현재 검색 결과 전체 선택.
- 검색은 현재 학년·자료 안에서 작동하며, 무결과에는 조건 초기화를 제공한다.
- 탐색 묶음은 10개, 검색 결과는 30개, 선택 목록은 10개씩 페이지로 표시한다.
- 선택 개별 해제/전체 해제, 적용/취소, Escape와 초점 복귀. 취소는 기존 범위를 보존한다.
- 모바일에서는 탐색 → 선택 목록 순으로 쌓고 적용/취소는 대화상자 하단에 남긴다.
- 이 모달은 긴 범위를 비교하므로 화면 폭에서 데스크톱 40px, 모바일 32px을 뺀 폭을 사용한다.
  DESIGN.md의 색 토큰, 18px dialog 반경, 44px 조작, 16/20px 간격 및 초점 규칙을 적용했다.

데이터와 기능 경계

  총 탐색 행은 수학 738개, 영어 219개다. 기본 선택은 문항 편집 체험을 위한 예시 범위다.

  문항 미연결을 안내하고, 미연결 범위만 선택한 경우 구성할 수 없다.

  표는 선택된 모든 범위를 8개씩 보여주므로 3개 자료를 전제로 한 화면이 아니다.
- 운영 단원·문항 API, 권한, 저장, 실제 자동 출제, 공식 교재 연결은 구현하지 않았다.
- 수학/영어 실제 운영 화면은 수정하지 않았다. 새로고침하면 편집 내용이 초기화된다.
- 인쇄 지면은 workspace 규격의 인쇄 예외를 유지한다. 실물 인쇄는 검증하지 않았다.
