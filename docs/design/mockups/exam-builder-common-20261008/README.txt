2026-10-08

보기
- index.html: 화면 캡처, 다섯 안 비교, PC/모바일 인터랙티브 미리보기.
- 저장소 루트에서 실행: node docs/design/mockups/exam-builder-common-20261008/serve.mjs
- 로컬 주소: http://127.0.0.1:3178/
- 다른 포트가 필요하면 EXAM_MOCKUP_PORT 환경 변수를 지정한다.
- HTML을 직접 열어도 동작한다. 글꼴은 저장소 public/fonts의 Pretendard를 참조한다.

시안
A a-guided.html — 범위/수량, 문항 검토, 출력을 별도 단계로 분리.
B b-workbench.html — 왼쪽의 조건과 오른쪽 초안을 함께 보며 작업.
C c-paper.html — 지면 위에서 읽고 교체/삭제, 옆에서 문항 이동과 출력 설정.
D d-blueprint.html — 단원별 수량을 배분한 뒤 단원 묶음으로 검토.
E e-quick.html — 자주 쓰는 구성 선택, 범위 확인, 초안에서 필요한 부분 수정.

공통 방향
- 범위 선택 → 문항 구성/수정 → 출력.
- 수학/영어/국어/과학/사회가 같은 레이아웃과 작업 순서를 사용한다.
- 과목 전환은 범위와 예시 콘텐츠만 바꾸며 별도의 과목별 제작 UI를 만들지 않는다.
- 교체, 추가, 삭제, 순서 변경, 되돌리기와 제목 편집을 직접 눌러볼 수 있다.
- 문항과 수량은 각 파일의 메모리 데이터에서 나온다. 새로고침하면 초기화된다.
- 구성과 저장/출제 엔진을 구현한 제품 화면이 아니라 구조 비교용 프로토타입이다.
- 예시 학년은 중1이며, 예시 수량은 4/6/8이다. 운영 문항과 계정 API를 연결하지 않았다.
- A/B 출력은 학생용, C/D/E 출력은 정답 포함 여부를 선택할 수 있다.

확인 결과
- A/B: 18개 Playwright 시나리오 그룹. 다섯 과목의 구성/교체/추가/삭제/순서/취소,
  지문 연결, 제목/학생용 출력, 빈 범위/후보 소진, 키보드 대화상자 확인.
- C/D: 다섯 과목의 구성/편집/되돌리기, 단원별 수량과 이동, 후보 범위,
  제목/정답/풀이 공간/출력, 처음 진입과 과목 변경 후 명시적 구성 확인.
- E: 5개 과목 × 1440/390/320px의 15개 편집 시나리오, 부족한 문항과 빈 범위 확인.
- 통합: 5개 시안 × 1440/390/320px의 15개 검토 화면, 갤러리의 다섯 링크/iframe,
  PC·모바일 전환, 다섯 썸네일 로드 확인. 브라우저 오류/실패 HTTP 요청/가로 넘침 0.
- 실제 캡처를 눈으로 확인했다. previews/overview.png가 비교 화면이다.
- E와 통합 검사 기록: .qa-artifacts/exam-concepts/ (로컬, Git 제외).
- A/B와 C/D의 검증 세부사항은 ab-notes.txt, cd-notes.txt에 있다.
- 실제 계정 저장, 운영 데이터, 실물 인쇄, 전체 앱 회귀 검사는 이 시안의 검증 범위가 아니다.

구현 제안
A의 단계 구분과 C의 문항 편집을 결합하는 방향을 첫 후보로 제안한다.
