여러 개 고를 때 «선택됨» 모양 — 다섯 안

지금은 보기를 누르면 면이 아주 옅게 파래지고(#edf3ff) 오른쪽 위 13px 칸에 ✓ 글자가 섭니다. 다섯 안 모두 ✓ 칸을 빼고 단추 자체가 달라집니다. 폰 틀은 제품 CSS 값 그대로, 수식은 제품 KaTeX 로 미리 그렸습니다. 문항은 실제 카드 «항등식»(중1 일차방정식) — 실제 화면과 같은 보기 순서입니다.

여쭐 것

  1. 몇 안으로 할까요. 1 코발트 차오름 · 2 굵은 테두리 + 옅은 면 · 3 번호 동그라미 · 4 내려앉음 · 5 남색 판 — 섞어도 됩니다(예: 4 의 내려앉음 + 2 의 테두리).
  2. 같은 효과를 어디까지 쓸까요. ㉮ 예 모으기만 · ㉯ + 정의 조립에서 고른 조각(지금은 예 모으기와 같은 옅은 면) · ㉰ + 누르면 바로 채점하는 보기(경계 살피기 · 작업실 하나 고르기 — 채점 연출 전 0.1~0.3초 보임) · ㉱ + 작업실 칠하기 칸의 ✓ 글자도 빼기(칸은 이미 파랗게 칠해집니다). 스타일이 한 규칙이라 ㉰까지는 따로 막지 않으면 같이 바뀝니다.
  3. 움직임 길이. ㉮ 안마다 적은 값(누를 때 0.09~0.2초 · 풀 때 0.1~0.14초) · ㉯ 모두 0.1초로 짧게 · ㉰ 움직임 없이 색만. 어느 쪽이든 기기의 «동작 줄이기»에서는 색만 바로 바뀝니다. 위 막대의 «느리게 ×4»로 움직임을 늘려 볼 수 있습니다.
  4. 틀렸을 때 고른 보기의 색. 지금은 확인 뒤 고른 보기를 전부 결과색으로 칠합니다 — 틀리면 맞게 고른 «2(x+1)=2x+2»까지 빨강. 틀린 뒤 정답을 드러내지 않는 규칙이라 보기마다 맞고 틀림은 보일 수 없습니다. ㉮ 지금처럼 전부 결과색 · ㉯ 틀림일 때는 고른 모양을 그대로 두고 결과는 가운데 연출만 말하기. 위 막대의 «틀림 색»으로 둘을 바꿔 볼 수 있습니다(맞음은 둘 다 초록).
폰 움직임 동작 줄이기 틀림 색 이 기기는 «동작 줄이기»가 켜져 있어 켠 채로 둡니다.
