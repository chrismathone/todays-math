공통 동작과 검토 기준

화면 안 단추로 흐름을 확인할 수 있습니다. PC와 폰의 상태는 함께 바뀝니다. 화면 위 상태 단추는 검토 도구입니다.

상황 모든 안의 동작
첫 화면 시작은 ‘오늘 공부 시작’ 하나. 도감은 둘러보기이며 학년·목표 단원 설정은 없음. 순서는 엔진에 맡김.
첫 오답 ‘다시 해 볼까요’와 같은 문제. 보기 값은 그대로, 표시 순서만 바꿈. 답을 공개하지 않음.
두 번째 오답 / 모르겠어요 정답과 풀이를 공개. ‘알겠어요’를 눌러야 이동. 그날 다시 요구하지 않고 다음 복습에 다시 만남.
개념 카드 풀이 뜻만 다시 보여 주지 않음. 예시의 정오, 참거짓의 정답, 카드 설명을 함께 보여 줌.
예습 새 소단원 첫 회차 앞에 개념 → 수학 그림 자리 → 풀어 보인 예 → 따라 풀기. 소수 곱셈은 모눈 넓이 모형 자리.
그림 점선은 제작할 그림의 자리. 수학 그림은 정확한 SVG, 직육면체는 Blender, 캐릭터·보상은 이미지 생성 대상. 이 Wire에는 이미지 생성 결과를 넣지 않음.
기록과 일정 첫 오답을 두 번째 성공으로 덮지 않는 계약은 별도 내부 작업. 이 파일은 서버 호출·저장·일정 계산을 하지 않음.
