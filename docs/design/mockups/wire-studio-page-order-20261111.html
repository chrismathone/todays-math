문제 추출 — 쪽 순서 조정 (Wire 5안)

원장님 2026-11-11 «페이지 순서가 이상하게 되어 있을 때 페이지 순서를 조정할 수 있는 기능». 지금은 쪽 이동 줄에 이전 쪽 · 쪽 선택(1 / 8) · 다음 쪽 · 회전만 있고 쪽 차례를 바꾸는 곳은 없다. 쪽 차례는 자른 문제의 차례 · 시험지에 담기는 차례 · «원본 차례로»를 정하므로, 스캔이 2·1·4·3으로 섞이면 문제 번호도 섞여 담긴다. 점선 상자가 이번에 더하는 자리다.

고르실 것

  • 어느 안의 짜임으로 갈지 (섞어도 된다 — 예: B의 창 + D의 빠른 단추)
  • 공통 동작은 다섯 안이 같다 — 차례를 바꿔도 이미 자른 영역 · 인식 결과 · 해설은 그 쪽을 따라간다(지우지 않는다). 쪽 번호 «3쪽»은 새 차례로 부른다. 원래 번호는 작게 «원본 5쪽».
  • Hi-fi 전에 따로 여쭐 것: 빈 쪽 · 정답표 쪽을 빼기도 같이 넣을지, 파일이 여럿일 때 파일끼리도 차례를 바꿀지

A · 올린 직후 «쪽 순서 확인» 한 장 격자 + 끌어 놓기

PDF를 올리면 ② 영역 지정 전에 쪽 전체를 격자로 한 번 보여 준다. 쪽을 끌어 자리를 바꾸고 «이 순서로 시작». 이상이 없으면 바로 «이 순서로 시작»만 누르면 된다. 나중에 바꾸려면 쪽 이동 줄의 «쪽 순서»로 이 화면을 다시 연다.

좋은 점

  • 섞인 차례를 자르기 전에 잡는다 — 뒤 단계가 다 맞는 차례로 시작
  • 8쪽이 한눈에 — 섞인 곳이 바로 보인다

걸리는 점

  • 매번 한 장이 더 끼어든다(이상 없을 때도 한 번 누름)
  • 끌어 놓기는 노트북 터치패드에서 번거롭다

부품

B · 쪽 이동 줄의 «쪽 순서» 단추 → 목록 창 ↑ ↓ 단추

평소엔 단추 하나만 더 보인다. 누르면 창에 쪽이 한 줄씩 — 작은 그림 · 새 번호 · 원본 번호 · ↑ ↓. 끌기 없이 단추로만 옮긴다. 시연 · 노트북에서도 확실하다.

좋은 점

  • 지금 화면에 단추 하나만 는다 — 평소 흐름은 그대로
  • ↑ ↓ 라 실수가 적고 키보드로도 된다
  • 쪽마다 «문제 4» 처럼 자른 수가 보여 확인이 쉽다

걸리는 점

  • 그림이 작아 «어느 쪽이 먼저인지»를 그림만으로 가리기 어렵다(줄을 누르면 크게)
  • 20쪽 넘으면 ↑ ↓ 를 여러 번 눌러야 한다

부품

  • 창 = PickerDialog를 «차례 바꾸기» 모드로 넓힌다

C · «쪽별 진행» 칩 줄에서 바로 끌기 새 화면 없음

이미 인식 현황 아래에 «쪽별 진행 1 2 3 … 8» 칩이 늘어서 있다. 그 칩을 끌어 자리를 바꾸면 쪽 차례가 바뀐다. 칩에 마우스를 올리면 그 쪽의 작은 그림.

  • 인식 중에도 바로 고칠 수 있다

걸리는 점

  • 칩이 작아 끌기가 어렵고, 그림이 안 보여 «무엇을 끄는지» 확인이 약하다
  • 칩 줄은 인식을 돌려야 생긴다 — 직접 자르는 경우엔 자리가 없다
  • 지금 칩은 «누르면 그 쪽으로 이동» — 누름과 끌기가 겹친다

부품

  • 쪽별 진행(StudioQueueStatus)을 넓힌다

D · 숫자로 차례 입력 + 빠른 단추 양면 스캔 대비

«쪽 순서» 창에 새 차례를 숫자로 적는다(예: 1, 3, 2, 4–8). 흔한 섞임은 단추 하나로 — 거꾸로(뒤에서부터 스캔), 앞뒷면 맞추기(양면을 홀수 쪽 먼저 · 짝수 쪽 나중에 스캔한 것). 아래 띠에서 결과를 바로 본다.
