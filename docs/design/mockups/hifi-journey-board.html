진도판 — 미래 칸에 단원 이름 · 가운데에 나의 진행 · 여백 줄이기

«보드판에 다음 단원을 미리 적어두면 좋겠고, 각 보드판에 여백이 너무 많음.» — «칸마다 적고, 가운데에는 나의 현재 진행 정보를 표기하는 게 좋을 것 같은데?»원장님, 2026-09-27 (운영 화면 캡처와 함께)

정해진 것: 미래 칸마다 단원 하나 · 가운데는 내 진행. 고르실 것: 가운데에 무엇을 얼마나 · 칸 여백을 어떻게 · 예정 칸을 어떻게 흐리게. 판은 운영 CSS 를 그대로 옮겨 실제 크기(폰 390 · PC 판 620)로 그렸고, 단원 이름은 전부 실제 학년 단원입니다.

원장님께 여쭐 것

  1. 네 안 중 어느 것 — A 단원 한 덩이 · B 숫자 세 줄 · C 큰 숫자 하나 · D 카드 다섯 장 안끼리 섞으셔도 됩니다(예: C 의 가운데 + A 의 칸). 추천은 C — 가운데가 위 «오늘의 한 칸» 카드와 겹치지 않고(오늘 분량은 카드에), 판만 보고 «학년에서 어디쯤»을 압니다 · PC 판 높이 약 ⅓ 줄고 폰도 조금 줄며 이름 잘림 0 · 예정 칸은 «면이 없다»로 완료(초록 면)·오늘(파랑 면)과 갈립니다.
  2. 예정 칸 표현 — 흐림(A) · «예정» 표지(B) · 투명 칸(C) · 흐림 + 첫 칸만 «다음»(D) «밀림» 탭에서 사흘 치를 나란히 보실 수 있습니다.
  3. 학년 단원이 끝난 뒤 칸 — 다음 학년 이어서 · 같은 학년 남은 단원 먼저 · 거기서 멈추고 «다음 여정» «학년 끝» 탭.
  4. 초등 칸 하나 — 대단원(«분수의 덧셈과 뺄셈») 인가 소단원(«진분수의 덧셈») 인가 «초등» 탭 — 소단원은 이름이 길어 폰 칸을 세 줄까지 꽉 채웁니다(잘림은 «초등» 탭에 잰 값).
  5. 가운데와 겹치는 것 — 바로 위 «오늘의 한 칸» 카드에 오늘 분량(6 / 15)이, 판 머리에 «N일 학습 완료»가 이미 있습니다. 가운데에 또 둘지 A 는 오늘 분량을 또 두고, B 는 머리의 날 수를 가운데로 옮겼습니다.

알려 드릴 것 — 중등은 단원이 저절로 넘어가지 않습니다. 지금 서버 규칙은 «목표 단원»(학습 설정에서 고름)을 바꾸기 전까지 같은 단원을 냅니다. 중2 연립을 모은 학생은 다음 날 «기억 복습», 그다음 날 «연립일차방정식»을 다시 받습니다. 그래서 중등의 예정 칸은 매일 한 칸씩 밀리기만 합니다(«밀림» 탭은 이 실제 규칙대로 그렸습니다). 단원을 넘기는 규칙은 이 시안과 따로 정할 일입니다.
