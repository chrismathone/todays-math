원장님 2026-11-12 «w1» → «w2도 섞어줘 · 왼쪽 리스트는 w2가 나아 보이네». 바탕은 W1: 형식 표의 열마다 «자동 · 직접». «직접»을 고르면 W2 의 고르기 창이 뜨고, 창 왼쪽은 W2 의 거르기 목록(소단원 · 난이도 · 종류)이다. 네 안 모두 실제로 움직인다. 체크하면 표의 수가 바뀌고, «자동으로 채우기»는 지금 출제 규칙과 같다. 하 · 중 · 상마다 소단원 차례로 돌려 뽑고, 모자라면 범위 전체에 고르게 편다.

세부 질문
  1. 직접과 자동을 한 형식 안에서 섞을까. H1 · H2 · H4 는 «직접이면 고른 것만» 싣고, H3 은 «꼭 넣을 문항 + 나머지는 표의 수대로 자동»이다.
  2. «자동»으로 되돌릴 때 고른 문항을 어떻게 할까. 버린다(H1 · H3)로 할지, 말없이 남겨 두었다 «직접»으로 오면 되살린다(H2)로 할지, 묻는다(H4)로 할지.
  3. «고른 문항» 자리. 창 아래 한 줄 칩(H1 · H3)과 창 오른쪽 칸(H2 · H4) 가운데 어디로 할지.
  4. 목록 한 줄에 답까지 보일까. 문장 + 답 + 난이도(H1 · H3 · H4)로 할지, 문장만 + «답 보기»(H2)로 할지.
  5. 지면 코드가 빠지는 것을 언제 알릴까. 늘 한 줄(H1), 지면 코드 자리에 «없음»(H2), 처음 «직접»을 누를 때 한 번 묻기(H3), «직접» 단추 이름에(H4) 가운데 고르시면 된다.

H1고른 것만 싣기 · 창 아래 칩

«직접»이면 고른 문항만 싣는다. 표의 칸은 «고른 수»로 바뀌고 열 머리 아래에 «직접 고름 8 · 하 3 · 중 3 · 상 2» 한 줄이 붙는다. 창 아래에 고른 문항이 칩으로 줄지어 선다.

  • 목록 한 줄문장 + 답 + 난이도
  • 고른 문항창 아래 칩 한 줄
  • 바닥 단추자동으로 채우기 하 · 중 · 상 → [고른 것 위에 채우기] [새로 채우기]
  • 지면 코드표 아래 늘 한 줄
  • 자동으로 되돌리기«고른 8문항을 버립니다» 확인

좋은 점
  • 규칙이 하나다 — 직접이면 고른 것만.
  • 칩 줄이 낮아 목록 칸이 넓다.
걱정
  • 칩이 열 개를 넘으면 옆으로 밀려 다 안 보인다.

H2오른쪽 «고른 문항» 칸 · 문장만

창이 세 칸이다. 왼쪽은 거르기, 가운데는 목록, 오른쪽은 난이도별로 묶인 «고른 문항»이다. 목록 줄은 문장만 보이고 «답 보기»로 펼친다. 표의 칸에는 고른 수가 파란 칸으로 서고, 지면 코드 자리에는 «없음 — 직접 고른 형식이 있습니다»가 뜬다.

  • 목록 한 줄문장만 · «답 보기»
  • 고른 문항창 오른쪽 칸(하 · 중 · 상 묶음)
  • 바닥 단추[빈 칸만 자동으로] [모두 비우고 자동으로]
  • 지면 코드만들 지면의 코드 자리에 «없음»
  • 자동으로 되돌리기묻지 않음 · 고른 것은 남겨 두고 «직접»으로 오면 되살림

해 보기 — «자동»을 눌렀다가 다시 «직접» — 고른 문항이 그대로 돌아온다

좋은 점
  • 목록이 짧아 훑기 빠르다. 고른 것이 늘 한눈에 보인다.
  • 자동 ↔ 직접을 오가도 잃는 것이 없다.
걱정
  • 창이 넓어야 한다. 좁은 화면에서는 오른쪽 칸이 아래로 내려간다.
  • 답을 보며 고르려면 한 번 더 누른다.

H3꼭 넣을 문항 + 나머지는 자동

«직접»이 표의 수를 없애지 않는다. 고른 문항은 «꼭 넣을 문항»이 되고, 하 · 중 · 상의 남은 자리는 표의 수대로 자동이 채운다. 칸에는 «5 / 꼭 2», 열 머리 아래에는 «꼭 넣을 문항 4 · 나머지 자동»이 붙는다. 목록에서 자동으로 들어갈 문항은 흐린 «자동» 딱지로 미리 보인다.

  • 목록 한 줄문장 + 답 + 난이도 + «꼭 · 자동» 딱지
  • 고른 문항창 아래 칩 한 줄
  • 바닥«나머지 6문항은 표의 수대로 자동으로 채웁니다» (채우기 단추 없음)
  • 지면 코드처음 «직접»을 누를 때 한 번 묻기
  • 자동으로 되돌리기«꼭 넣을 문항 4개를 풉니다» 확인

해 보기 — 표에서 B «중»을 바꾸면 목록의 흐린 «자동»이 따라 바뀐다

좋은 점
  • «이 문제는 꼭» 몇 개만 집으면 된다. 숫자를 다시 셀 일이 없다.
  • 표의 수가 그대로라 지금 화면의 뜻이 바뀌지 않는다.
걱정
  • 자동 몫이 섞이므로 «정확히 이것만»을 원하면 수를 꼭 넣을 문항 수에 맞춰야 한다.

H4자동 결과를 열어 고치기

«직접»을 누르면 창이 지금 자동이 고른 문항을 체크한 채로 열린다. 빼고 더해서 고친다. 줄마다 «자동» · «직접» 딱지가 붙고, 오른쪽 칸에는 난이도마다 «직접 2 · 자동 3»이 선다. «직접» 단추 이름 자체가 «직접 · 코드 없음»이다.

  • 목록 한 줄문장 + 답 + 난이도 + «자동 · 직접» 딱지
  • 고른 문항창 오른쪽 칸(하 · 중 · 상마다 직접 n · 자동 n)
  • 바닥 단추[고른 것 위에 채우기] [새로 채우기]
  • 지면 코드단추 이름 «직접 · 코드 없음»
  • 자동으로 되돌리기[고른 것 두기] [버리기] 둘 중 묻기

걱정
  • «자동 · 직접» 딱지가 섞여 목록이 조금 시끄럽다.
