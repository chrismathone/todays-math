# 확정 D안 시험지 만들기 적용

2026-10-08. 실제 수학 `bank`와 영어 `english-questions` 메뉴에 적용한 소스 기록이다. 운영 배포를 뜻하지 않는다. 디자인 기준은 [DESIGN.md](../../DESIGN.md), 비교 제품의 관찰 근거는 [공식 가이드 검토](mockups/exam-builder-common-20261008/editing-references.txt)다.

## 화면과 데이터

- `src/components/exam-builder/ExamBuilder.tsx`: 과목을 상속하는 공통 3단계, 50:50 구성표/문항, 단일 문항 행, 대량 범위 필터·페이지, 난이도 추가·교체, 삭제·되돌리기, 포인터/키보드 순서 변경. 문항 열과 같은 너비의 교체 창, 40px 이동 위치 안내, 안정된 스크롤바 폭.
- `MathExamBuilder`/`mathSource`: 실제 단원·출력 가능한 문제은행을 연결한다. 계정 초안과 기존 클라우드 저장을 유지한다. 구성 시 선택 범위를 넓히지 않으며 부족한 문항 수를 알린다. 출력 직전 eligibility를 다시 확인한다. 많은 단원 조회는 길어진 URL 대신 크기가 제한된 POST 본문을 사용하고 기존 권한·동일 출처 검사를 거친다.
- `EnglishExamBuilder`/`englishExamSource`: 소유한 저장 세트·native 문항을 연결한다. 실제 원본 난이도를 사용하며 없는 값은 ‘미지정’이다. 기존 출력 누출 분리 묶음·밑줄 검사·미검토 확인·원본 revision resolve를 유지한다. 영어의 임시 작업 저장/JSON 다운로드와 수학 클라우드 초안은 서로 다른 기능이다.
- 마지막 단계는 모두 실제 `WorksheetEditor`다. 여섯 양식·단 수·풀이 공간·정답지·PDF/HWPX 경로를 함께 사용한다. 영어 원문은 수학 문자열로 변환하지 않고 native renderer로 그린다. 출력 직전 비동기 검사가 끝나기 전에 인쇄하거나 내보내지 않으며 도중에 문항/설정이 바뀌면 중단한다.
- `UnifiedWorkspace`는 기존 권한 안에서 수학 홈 진입/시험지 이동 의도에 초안 준비와 화면 코드를 미리 시작한다. `prepare()`는 이미 진행 중인 로딩을 재사용한다.

## 초기 로딩 개선

이전에는 최근 시험지 목록 다음 모든 초안 본문과 이미지를 복원한 뒤 편집기를 열었다. 이제 목록 메타데이터와 현재 초안만 우선 복원하며 다른 초안은 실제 열 때 읽는다. 이미지도 기존 동시 전송 상한 3 안에서 병렬 복원한다. 미전송 변경·원래 revision·계정 격리·실패 시 저장 차단은 유지한다.

고정 지연을 넣은 재현 검사(초안 12개, 각 이미지 3개)에서 준비 시간 **3,430ms → 330ms**, GET **49회 → 5회**였다. 운영 계정의 네트워크 실측값이 아니다. 전체 근거와 남은 비용은 [로딩 개선 보고서](../planning/tracks/reports/exam-loading-perf-20261008.md)에 있다.

## 통합 검증

- 전체 저장소 `tsc --noEmit` 통과.
- 수학 adapter·문제은행 필터·권한/API 검사 61개, 초안 로딩·저장·이미지 복원 회귀 검사 51개 통과.
- 영어 연결·native 출력·출력 직전 검사·내보내기 API 31개, 영어 기존 문제은행·메뉴 권한·공통 출력 설정 회귀 51개 통과.
- 공통 구성 흐름 5개 검사: 대량 범위, 구성, 난이도 추가/교체, 중복 배제, 삭제/되돌리기, 단계 왕복, 오류 상태, 키보드 드래그.
- 기존 개발용 시안→공통 출력 왕복 검사 15개 통과. 인쇄 호출 검사는 새 비동기 출력 사전 검사가 끝날 때까지 기다린다. affordance 검사와 수정한 소스 ESLint 통과(기존 `unifiedPreview`의 `_count` 미사용 경고 1개).
- 실제 수학 개발 경로에서 735개 범위와 실제 문항으로 구성/교체/공통 출력/복귀를 확인했다. 1440·1024·390·320px에서 열 너비 안정, 교체 창 너비, 가로 넘침과 브라우저 오류를 확인했다.
- 영어는 실제 컴포넌트와 계정 접근 없는 작성 fixture로 1440·390·320px 구성/공통 출력/복귀를 확인했다. 여섯 양식의 인쇄 준비, 출력 직전 resolve 후 브라우저 인쇄 호출, 제목 수정의 복귀 반영도 확인했다. 가로 넘침·브라우저 오류 0. 실물 프린터 출력이나 운영 계정에 대한 쓰기를 수행한 검증은 아니다.
- 로컬 캡처와 재현 JSON은 `.qa-artifacts/exam-concepts/applied-*`에 있다. 정적 시안의 앞선 검증 수치와 실제 연결 검증을 합산하지 않는다.
