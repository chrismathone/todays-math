# 오늘의 영어 D — 실제 UI·API 통합 확인

2026-10-07. 선택된 D와 오늘의 수학 공통 작업실 구성을 실제 영어 화면에 적용했다. 초기 비교 HTML의 검토 기록은 `todayenglish-hifi-20261007.md`이며, 이 문서는 이후 제품 코드의 구현·검증 범위를 기록한다.

## 구현한 흐름

- `시험지 만들기`에서 시험별 저장 세트를 문항 단위로 검색한다. 학년·유형·세트 검토 상태·시험 필터와 페이지 이동을 제공한다. 문항의 원문, 정답, 해설, 근거를 확인하고 담기·순서 변경·제거 후 학생용·교사용 인쇄 미리보기로 이동한다.
- `AI 문제 제작`은 전체 화면이다. `AI로 원문부터` 또는 `기존 원문으로` 제작하고, 결과와 형식 검사 내용을 확인·수정한 뒤 명시적으로 초안을 저장한다. 기존 생성 API와 저장 계약을 재사용한다. 원문 복원과 외부 자료 가져오기는 보조 제작 방식으로 유지한다.
- 문제은행은 기존 세트의 원문·문항·인덱스·버전을 보존하는 읽기 전용 조회다. 세트 저장 후 목록을 갱신하며, 원본 세트 편집으로 연결한다. 별도 문제은행 데이터 복제나 마이그레이션은 없다.
- 담은 문제는 최대 80개다. 같은 문항의 최신 버전은 기존 위치를 유지해 교체한다. 미리보기 진입과 인쇄 직전에 서버에서 소유 범위와 최신 버전을 다시 확인한다. 변경·삭제·접근 불가한 문항이 있으면 과거 내용을 그대로 출력하지 않는다.
- 수학 공통 셸에 영어 화면 최대화·복원을 추가했다. 최대화하면 왼쪽 메뉴와 보조 상단 요소가 접히며, 복원 버튼 또는 Esc로 돌아온다. 메뉴 전환 시 제작 상태를 유지한다.
- 데스크톱 검색과 필터는 한 줄이다. 작은 화면에서만 공간에 맞게 줄을 나눈다. HTML D와 비교 갤러리에도 전체 화면 제작·최대화·한 줄 필터를 반영했다.

브라우저 증거와 실행 보고서는 로컬 `.qa-artifacts/english-product/`, `.qa-artifacts/english-hifi/`에 있다. 브라우저 API 응답은 검증용 예시이며 실제 모델·DB 결과가 아니다. 모바일 증거의 하단 임시 메뉴는 검증 하네스의 화면 전환 도구다.

## 남아 있는 범위

- 생성 모델과 실제 DB 왕복은 이 작업에서 호출하지 않았다. 운영 배포·학생 배정·외부 공개도 하지 않았다.
- 자동 검사는 기존의 결정적 형식·구조 검사다. AI 의미 검증, 정답의 타당성 보장, 자동 교사 검토 완료로 표현하지 않는다.
- 문제은행은 현행 V1 저장 세트를 문항 단위로 조회한다. 지원하지 않는 저장 V2 또는 잘못된 문항을 임의 변환하지 않고 충돌로 응답한다.
- 담은 구성은 작업 중 메모리에 유지된다. 새로고침 이후의 영구 시험지 저장, 독립 문항 저장 모델과 자료집 관리, 대량 자동 제작·의미 판단은 후속 구현 범위다.
- 별도의 스키마 변경, 라이브 마이그레이션, 수학/SRS 로직 변경은 없다.
