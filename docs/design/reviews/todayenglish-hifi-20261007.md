# 오늘의 영어 Hi-fi 5안 — 시각·동작 확인

대상은 2026-10-07 디자인 시안이다. 운영 UI, API, 데이터베이스와 분리된 독립 HTML을 검토했다.

## 디자인 차이

| 안 | 화면 구성 | 확인한 작업 |
|---|---|---|
| A 시험 작업대 | 상단 제작 메뉴, 좌측 시험 탐색, 선택 시험의 준비 영역, A4 미리보기 | 시험 전환, 제작, 세트 검토, 은행 담기, 인쇄 대상 전환 |
| B 원문 편집실 | 원문 자료 rail, 문장 단위 원문, 제작·검토 분할 패널 | 원문 선택·수정, 문장 근거 선택, 유형 제작, 답·근거 확인, 은행 보관 |
| C 제작 흐름 보드 | 초안·검토 중·검토 완료 보드와 빠른 검토 pane | 확인 두 항목의 검토 완료 관문, 보드/리스트, 은행 검색·담기, 제작 drawer, 학생용 지면 |
| D 문제 탐색과 조합 | 학년·유형·상태 필터, 문항 목록·상세, 구성 트레이 | 검색·빈 결과, 필터, 다중 선택, 담기·순서 변경·제거, 학생/교사 A4, 제작 drawer |
| E 수업 자료집 | 수업 선택, 표지·목차, 구성 확인, 학생/교사 지면 | 은행 검색·담기·빼기, 정답·근거 검토, 초안 제작·보관, 지면 대상 전환 |

루트와 Orca Codex 작업 세션이 각각 담당 화면을 확인한 뒤 루트에서 통합했다. 루트 캡처는 설치된 Edge의 headless Playwright로 수행했다.

## 시각 확인

- 다섯 초기 화면을 PC 1440×1000과 모바일 390×844에서 렌더링하고 직접 이미지로 확인했다.
- 문서 전체 가로 너비가 화면 너비를 넘지 않는지, 실행 중 JavaScript 오류가 없는지 확인했다.
- A/B는 담당 작업 세션에서 320·768·1024·1440px도 확인했다.
- C의 모바일은 작업 목록과 검토 dialog로 바뀌고, D는 목록·상세·구성을 따로 열 수 있게 바뀐다. E의 목차와 지면은 세로로 이어진다.
- E의 모바일 축소 지면이 미리보기 버튼을 침범하던 부분을 정리했다.

## 주요 동작 확인

- A/B 담당 세션에서 제작 → 검토 → 은행 반영과 모바일 전환을 포함한 동작을 검증했다. 원문을 바꾸었는데 과거 샘플 문항을 새 원문 결과처럼 보여 주지 않도록 처리했고, 검토 체크 해제와 교사용 인쇄 페이지 넘침을 수정했다.
- C는 정답·선택지와 원문 근거·해설의 두 확인 항목을 모두 선택해야 검토 완료가 가능하다. 루트에서도 이 관문, 빈 검색 결과, 제작 초안, 검토 진입, 학생용 지면과 네 메뉴의 모바일 배치를 확인했다.
- D 담당 세션에서 검색·필터·빈 결과·다중 선택·담기·순서 변경·제거·AI drawer·키보드 닫기를 확인했다. 교사용 해설이 A4 높이를 넘던 부분을 한 페이지 한 문항으로 정리했다. 예시 14문항의 학생용 7쪽·교사용 14쪽을 확인했다.
- E 루트에서 어휘 검색 결과, 담은 문항 수 갱신, 검토 완료, 교사용 정답 4개와 학생용 정답 제외, 제작 초안 3개와 은행 보관, 다섯 메뉴의 모바일 너비를 확인했다.
- 듣기에서 음원이 없는데 가짜 시간이 흐르게 만들지 않았다. 음원 선택은 사용자의 기기 파일을 브라우저 플레이어로 연결하는 동작이다.

## 비교 갤러리 확인

다섯 HTML과 썸네일을 `index.html` 안에 내장했다. 개별 페이지 파일 없이도 다섯 안을 열 수 있고, PC·모바일 전환과 개별 HTML 내려받기를 제공한다.

통합 과정에서 HTML을 문자열 치환할 때 JavaScript의 달러 문자가 변형되는 문제를 수정했다. 다섯 안을 연속으로 바꾸면서 각 페이지의 본문과 동적 버튼이 나타나고 실행 오류가 없는지 확인했다. 시안 전환 시 독립된 iframe을 생성하며, 열려 있는 동안 뒤쪽 비교 화면은 키보드 탐색에서 제외된다.

## 범위와 한계

- 실제 생성 모델 호출, DB 왕복·영속 저장, 문제은행 운영 이관, 학생 배정·공개를 검증한 결과가 아니다.
- 제작은 준비된 예시 문항을 보여 준다. 화면 조건이 표시되는 것은 해당 학년·난이도에 대한 실제 모델 성능 검증을 의미하지 않는다.
- 예시 검토 상태·문항 수·학교·교사와 수업은 시안 데이터다. 실제 사용자 기록을 불러오지 않았다.
- 문항 단위 독립 문제은행과 여러 원문의 자료집 구성은 구현 계획에 추가할 기능이다. 현행 시험별 세트 저장이 이미 이를 제공한다고 주장하지 않는다.
- 이번에는 앱 TSX·Next 라우트·API·DB 코드를 변경하지 않았다. 관련 확인은 HTML 동작·반응형·지면·통합에 맞췄다.
