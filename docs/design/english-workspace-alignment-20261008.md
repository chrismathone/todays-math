# 영어 작업실 정렬 — 구현·검증 기록

2026-10-08. [공통 규칙](workspace-ui-rules-20261008.md)과 [DESIGN.md](../../DESIGN.md)를 오늘의수학의 실제 Workroom 셸에 맞춰 적용했다. 외부 참고는 사용자가 지정한 [awesome-design-md](https://github.com/voltagent/awesome-design-md)의 문서 분류이며, 시각 기준은 기존 수학이다.

## 적용

- 공통 상단바의 계정·최대화 행동을 한 영역으로 묶었다. 영어에서 네 번째 자식이 다음 행으로 밀려 제목을 가리던 문제를 해결했다. 좁은 화면은 아이콘과 접근 가능한 이름을 유지한다.
- 오늘의 작업은 자료·최근 세트가 주 영역, 준비 현황·출제 설정이 보조 영역이다. 큰 진행 배너와 세트별 중첩 카드를 줄였다. 학교·시험은 한 맥락 영역에 두며 학교가 네 개 이상이면 선택기를 쓴다.
- 시험지 만들기는 코발트 행동색, 목록·문항 상세 두 열, 접힌 담기 요약을 쓴다. 모바일에서는 한 열로 쌓고 담기 행동을 하단 탐색 위에 둔다. 원본 개정 확인과 인쇄 계약은 유지한다.
- AI 문제 제작은 부모가 외곽 여백을 소유하고, 조건과 결과에 충분한 폭을 배정한다. 내 문제 세트는 정렬된 행 목록이며 편집·정답·해설은 작은 화면에서 쌓인다.
- 자료은행·영어듣기는 공통 페이지 제목과 탭, 필터, 목록·상세 순서를 사용한다. 듣기 독립 화면과 작업실 내부 화면의 여백 소유권을 구분했다.
- 화면 글자는 24/18/14/12px 역할, 조작은 44px와 반경 8px, 작업 면은 반경 12px를 기준으로 정리했다. 인쇄 미리보기 도구도 같은 행동색·조작 크기를 사용하며 A4 지면 규칙은 변경하지 않았다.

## 검증

- Chromium의 실제 UnifiedWorkspace에서 영어 여섯 메뉴를 1920/1280/1050/768/760/390/320px로 확인했다. 총 42개 화면에서 문서 가로 넘침과 페이지 오류가 없었다.
- 자료 상세·듣기 상세·듣기 수정·새 자료 작성은 1440/768/390/320px에서 추가 16개 상태를 확인했다. 가로 넘침과 페이지 오류가 없었다.
- 문항 담기→키보드로 목록 펼치기→순서 변경→메뉴 왕복 후 목록 유지→인쇄 미리보기·Escape 닫기를 확인했다. 인쇄 매체에서 작업실이 숨겨지고 지면이 보였다.
- 최대화·Escape 복원을 1440/1050/768/760/390/320px에서 확인했다. 조작의 높이는 44px이며 상단바 안에 들어간다. 모바일 담기 출력 버튼은 하단 탐색 위에 있다. 수학 홈의 공통 셸도 확인했다.
- 루트의 관련 컴포넌트 검사 38개(영어 홈·보관함·문제은행·메뉴 전환)와 98개(권한·작업실 행동·지면·인쇄)를 통과했다. 분리 작업에서는 제작·편집 96개, 자료은행·듣기 69개 검사를 통과했다. 이 수치는 중복을 포함하므로 합산하지 않는다.
- 전체 TypeScript 검사, 수정 TSX의 ESLint, affordance 검사, 서식·diff 검사를 통과했다.

개발 서버의 `/dev/workspace-alignment#english`에서 재현할 수 있다. 이 경로는 production에서 404이며, 자체 작성 예시와 mock 응답으로 공통 인증 화면 모양을 검증한다. API 요청은 실제 계정으로 전달하지 않고 저장·생성 요청은 차단한다. 실계정 저장, 유료 AI 생성, 실제 음원 품질 검증을 이번 시각 검사 결과로 주장하지 않는다. 워커의 독립 리사이즈 검사에서 공유 AutoGrowTextarea의 일시적 ResizeObserver 알림이 보고됐으나 통합 Chromium 검사에서는 페이지 오류가 없었다.

로컬 캡처·측정값은 `.qa-artifacts/english-ui-20261008/`에 보관한다. 필수 push 관문과 원격 반영 결과는 최종 커밋·작업 보고에서 별도로 확인한다.

## 규격서 보강과 제작 문구 정정

사용자가 루트 DESIGN.md의 구체성이 부족하다고 지적해 공통 규격을 루트 파일로 옮기고 보강했다. 색·대비·타이포·간격·조작과 상태·세 가지 화면 구성·JSX/CSS 예시·dialog·스크롤·키보드·반응형·인쇄·검증을 자체적으로 읽을 수 있다. 기존 상세 문서는 메뉴별 실제 파일·기능 제약·남은 차이만 관리하도록 정리했다. 별도 Codex의 읽기 전용 소스 감사로 최종 CSS override와 가용 컨테이너 기준을 대조했다.

문서의 로컬 링크 52개, 9개 최상위 규격 절, 참조한 learn 토큰과 코드 fence를 확인했다. 불투명 색 조합의 대비 계산은 현재 초점/경계색의 점검 필요성을 드러내는 근거로 기록했으며 전체 접근성 통과를 주장하지 않는다.

학교명만으로 기출 경향을 반영하지 않는다는 사용자 지적에 따라 홈의 `학교 맞춤 문제 만들기`를 `AI 문제 제작`으로 정정했다. 기존 컴포넌트 검사 25개가 통과했다. 학교·시험에 묶인 생성/저장/권한 구조를 분리하는 제품 변경은 이번 문구 정정에 포함하지 않았다.

영어 화면 정렬을 포함한 `a4c0e005b`는 원격 main 반영과 Vercel 성공 상태를 확인했다. 이후 문서·문구 보강의 배포 상태는 해당 커밋으로 별도 확인한다.
