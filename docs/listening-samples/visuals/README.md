# 문항별 그림 시범

2026-10-03 사용자 제안에 따라 연결된 이미지 생성 도구(`image_gen`)로 자체 제작했다. **교사 검토용이며 현재 듣기 학생 화면에 연결하거나 발행한 자료가 아니다.** 유료 API 경로는 사용하지 않았다.

## 첫 묶음: 학교 장소

- 그림: [school-places-v1.png](school-places-v1.png)
- 대응 자료: [기존 자작 샘플](../20261003/samples.json)의 `sample-01`, 2번 문항.
- 발문: 음악 선생님은 지금 어디에 계신가?
- 왼쪽부터 음악실, 체육관, 급식실, 도서관, 정원. 정답과 대본 근거는 **교사용** [제작 기록](school-places-v1.json)에 있다.
- 생성 지시: 실제 보기 다섯 장소를 같은 흑백 선화·크기·시점으로 나란히 표현하고 사람, 정답 강조, 글자, 번호를 넣지 않는다. 전체 프롬프트는 제작 기록의 `generationPrompt`에 보존했다.

도구 결과를 시각적으로 확인했다. 다섯 장소가 구별되고 정답 강조는 없지만 도서관은 체육관보다 선이 조밀하다. 좁은 화면에서의 식별 가능성과 실물 출력은 별도 교사 확인이 필요하다. 번호는 앱에서 붙일 예정이며, 현재 한 장으로 묶인 시범 그림을 개별 보기 파일 다섯 개로 등록했다고 세지 않는다.

소재를 미리 만들더라도 실제 문항에 쓰기 전 대본, 정답, 오답의 조건과 대조한다. 지도·시계·표처럼 수치와 배치가 핵심인 자료는 검증 가능한 코드 도식을 우선한다. 그림을 바꾸면 문항의 관련 검수도 다시 받는다.

`python scripts/content/check-listening-visuals.py`로 2170×725 PNG와 SHA-256을 확인했다. 글/EXIF 청크는 없지만 C2PA 출처 정보인 `caBX` 21,881바이트가 있다. 원본 생성 표지를 보존했으며, 이 검사 통과를 학생 전송 적합 판정으로 쓰지 않는다. 추후 이미지 전달 구현에서 허용 청크와 출처 정보 공개 범위를 정한다.
