- [Kokoro-82M 청취 샘플 3개](./20261003/README.md): 자체 창작 대본·문항, 실제 합성 음원, 운영 사이트의 청취용 초안 등록 완료.
- [EBS 공식 자료 목록 열기](./ebs-catalog-20261003.html): 학년·연도 필터가 있는 로컬 HTML. 로그인이나 서버 실행 없이 열 수 있습니다.
- [EBS 회차별 JSON](./ebs-catalog-20261003.json): 원문 출처, 공식 파일 링크, 이용허락 확인 상태를 저장합니다.
- [공식 출처 7곳 조사](./public-sources-20261003.md): EBS·교육청·평가원의 제공 경로와 이용 조건. 회차별 수집·링크 검증의 추가 결과는 이 문서를 기준으로 합니다.

공식 페이지/공개 목록 응답에 표시된 URL을 수집한 수치입니다. EBS 전체 교재·수능·학력평가를 모두 수집했다는 뜻은 아닙니다. 최신 2026년 2회분의 6개 학년 × 5종 파일과 학년별 가장 오래된 음원 6개, 총 36개에 HEAD 요청을 보내 200 응답과 MIME 종류를 확인했습니다. 원본 본문 다운로드나 전체 파일 내용·재생 검수는 하지 않았습니다.

[EBS 현행 약관](https://sso.ebs.co.kr/policy/termsInfo)은 2026-04-22 시행이며 제12조 제2항, 제21조 제2항에서 사전 동의 없는 영리 이용과 제3자 제공 등을 제한합니다. 별도 재호스팅 허용은 확인되지 않았으므로 **EBS 원본은 오늘의 영어 서버에 업로드하지 않았습니다.** 이 목록은 공식 출처로 이동하기 위한 링크 모음입니다. 개별 이용허락을 받으면 해당 범위·기간·대상 파일을 기록한 뒤 원본 등록 여부를 판단해야 합니다.

목록 생성 스크립트:

```powershell
python scripts/content/build-ebs-listening-catalog.py
```

Python 표준 라이브러리만 사용합니다. `.qa-artifacts/listening-ebs`의 HTML·JSON 캐시를 재사용하며 EBS 음원/PDF/ZIP을 다운로드하지 않습니다. 갱신이 필요하면 해당 캐시 파일만 비운 뒤 다시 실행합니다. 현재 고교 학년 구분은 `targetCd`가 결정하므로 URL 파일명만 보고 학년을 추측하지 않도록 검증합니다.
