# 영어 듣기 자료 초안 — 2026년 10월 3일

[samples.json](./samples.json)은 청취 테스트에 사용할 자체 창작 영어 대본 3개와 한국어 번역, 각 3개의 오지선다 문항을 담고 있습니다. 기존 기출문제나 저작물을 복사하지 않았습니다.

**대본·번역·문항·해설은 AI 초안이며, 음성 청취검수는 미완료입니다.** 실제 음성 생성이나 재생을 수행하지 않았습니다. 발음, 억양, 속도, 화자 구분과 숫자·부정어의 청취 명료도는 생성된 음성을 듣고 별도로 확인해야 합니다. 수준 표시는 목표 수준이며, 실제 학습자에게 난이도를 검증한 결과가 아닙니다.

| 자료 | 목표 수준 | 형식 | 영어 대본 단어 수 | 지정 음성 |
| --- | --- | --- | ---: | --- |
| sample-01 | 중1 · A2 | 학교생활, 2인 대화 | 86 | A: af_heart / B: am_michael |
| sample-02 | 중2~3 · B1 | 일상 의사결정, 2인 대화 | 106 | A: af_heart / B: am_michael |
| sample-03 | 고1~2 · B1–B2 | 학교 안내, 1인 담화 | 126 | A: bf_emma |

단어 수는 각 자료의 `turns[].text`만 공백으로 나누어 계산했습니다. 축약형과 약어는 각각 한 단어로 세며, 화자 표시·제목·번역·문항은 포함하지 않습니다. 대본의 시간·가격·인원은 발음용 영단어로 표기했습니다. sample-03의 여러 턴은 같은 화자의 담화를 문단으로 나눈 것입니다.

## 텍스트 자체 검토

- 자료별 단어 수가 지정 범위에 드는지 확인했습니다.
- 자료마다 문항 3개, 문항마다 한국어 보기 5개와 단일 정답을 갖추었습니다. `answerIndex`와 `evidenceTurnIndices`는 모두 0부터 시작하며, 근거 인덱스는 해당 자료의 `turns`를 가리킵니다.
- 영어 원문과 번역의 의미를 대조하고, 정답과 해설이 지정된 근거 턴에 맞는지 검토했습니다. 다른 문항의 보기만으로 정답이 드러나지 않도록 각 문항이 서로 다른 정보를 묻게 했습니다.
- sample-02는 선택하지 않은 급행버스와 최종 선택한 일반 버스의 출발 시각·요금을 구분했습니다. 한 사람의 요금과 두 사람의 합계도 대본에 각각 명시했습니다. 부정 표현은 운전 선호와 급행버스의 정차 여부에 포함했습니다.
- sample-03은 방송의 목적, 직접 가져올 준비물이라는 세부 정보, 장소 선정의 이유를 각각 묻습니다.

검토는 텍스트 수준의 자체 검토입니다. 위 표의 음성 이름은 생성에 사용할 지정값이며, 연결된 구독 도구에서의 지원 여부나 실제 생성 결과를 확인했다는 뜻은 아닙니다. 이 작업에서는 콘텐츠 파일만 작성했으며 코드 구현, DB 변경, 배포, 유료 API 호출, Docker 실행은 수행하지 않았습니다.
