## 21장 문장

쓴 규칙: 빈칸 둘을 바꿔 넣으면 거짓이거나 말이 안 됨 · **틀린 말을 어느 빈칸에 넣어도 참이 되지 않음** · 빈칸 뒤 조사(을/를 · 이/가 · 으로/로 …)가 정답과 그 자리 틀린 말에 똑같이 붙음(받침 — `supplementCards.test.ts` 가 잠금) ·
예는 맞음 둘 · 틀림 둘(글만) · 느낌표 없음 · 해설은 본 카드 말투(«~야»).

고친 9행 — 둘 다 짚었거나, 한쪽이 짚고 Claude 가 설득돼 2:1:

| 카드 | 문제 | 고침 (누가) |
|---|---|---|
| 변과 꼭짓점(도형) | 틀린 말 «선분»을 빈칸1 에 넣으면 참 · «곧은 선»은 직선 · 반직선까지 든다 | 빈칸1 = 선분 · 틀린 말 곡선 · 각 (둘 다 · grok 안) |
| 직사각형 | 틀린 말 «예각»은 초4 말 · 예에 90° · 평행사변형(초4) | 틀린 말2 «직각이 아닌 각»(codex) · 예는 직각 · 직각삼각형으로(grok) |
| 정사각형 | 같은 까닭 | 틀린 말2 «직각이 아닌 각»(codex) · 맞음 예의 90° → 직각(grok) |
| 밑과 지수 | «곱한 횟수»는 × 개수(2³ 에 × 는 둘)로 읽힘 · 빈칸2 뒤 «라고»가 받침으로 «밑»을 가림 | 등식 꼴로 «곱해진 2의 개수» (둘 다 · codex 안 — 두 걱정을 다 풂) |
| y축에 대하여 대칭 | 해설 «0의 부호» | «x좌표에 −1을 곱해 …»(codex) |
| 점과 직선 사이의 거리 | 맞음 «수선의 발»(이 장에서 처음) · 틀림 «아무 점»에 수선의 발도 듦 | 맞음 «수직으로 내린 선분»(grok) · 틀림 «비스듬히 그은 선분»(codex) |
| 동위각과 엇각 | «엇갈린 위치»만으로는 바깥 각도 엇각 | 엇각은 **두 직선 사이**(둘 다 · grok 안 — 빈칸 유지) · 맞음 둘 교체 |
| 평행선의 성질 | 앞개념에 동위각과 엇각이 없다 | 앞개념 추가(grok) |
| 직각삼각형의 합동 조건 | 세 각이 같은 합동 삼각형도 있어 «합동인 경우»가 모호 | «반드시 합동이 되는 조건» · 틀림 «…만 안다»(codex) |

그대로 12행 — 한쪽만 짚고 2:1 로 유지: 사다리꼴(codex — grok 은 초등 정의 «적어도 한 쌍»대로 맞다) · 대응점 · 대응변 · 대응각 · 밑면과 옆면 · y축 대칭의 뜻 문장(각 codex 1표).
처음 초안에서 걸러 낸 것(합의 전): 누출 검사가 표준 수학 표현 8행 · 흔한 문제 말투 8곳을 잡아 모두 다시 썼다.

## 리드 검토 뒤 — 12가지 채움 전수 (둘째 3자 합의, 2026-09-28)

리드 검토(엔진 · 내용 · 화면 세 갈래)가 **평행선의 성질**에서 오답 둘을 함께 넣은 «두 직선이 교차하면 … 크기가 각각 다르다»가 **참**인 것을 잡았다 —
채점은 자리 그대로라 맞는 답을 틀렸다고 친다. 그래서 21장 × **12가지 채움**(네 말에서 둘을 차례로 — 정답 하나 + 11가지)을 전부 판정했다.
시험 `supplementCards.test.ts` 의 `FILL_AUDIT` 이 252가지 문장과 판정(정답 21 · 거짓 117 · 말이 안 됨 114)을 잠근다 — 문장이 바뀌면 빨개진다.

| 고침 | 무엇을 | 표 |
|---|---|---|
| C1 평행선의 성질 | 둘째 오답 «다르다» → «180°이다»((교차, 다르다)가 참이던 것) | 3:0 |
| C2 직각삼각형의 합동 조건 | 첫 오답 «밑변» → «대각선»((밑변, 예각)이 합동 조건이 되던 것) | 3:0 |
| C3 각 | 함정 → «각 ㄱㄴㄷ의 꼭짓점은 점 ㄱ이다.»(F) — «각의 크기»(초4)를 뺌 | 3:0 |
| C4 밑면과 옆면 | 해설 까닭을 각기둥의 뜻(옆면이 직사각형)으로 | 3:0 |
| C5 밑과 지수 | 오답 «계수 · 차수»(중1 문자와 식) → «곱 · 차» | 3:0 |
| C6 y축에 대하여 대칭 | 좌표 꼴 «y축에 대하여 점 (a, b)와 대칭인 점은 ({−a}, {b})이다.» · 오답 «a · −b» | 2:1(codex 는 «a와 b가 어떤 수이든» 앞말을 붙이자 — 특정 값 반대) |
| R1 직사각형 | «네 각이 모두 {직각}인 {사각형}.» · 오답 «직각이 아닌 각 · 삼각형»(«두 각이 모두 직각»이 참으로 읽힐 여지) | 3:0 |

| R3 밑면과 옆면 | 첫 오답 «수직» → «원»(«수직이면서 평행하게»가 직각기둥 밑면으로 읽힘) | 3:0 |
| R4 동위각과 엇각 | 첫 오답 «마주 보는» → «바깥쪽»(«두 직선 사이에서 마주 보는»이 엇각으로 읽힘) | 3:0 |
| 직선 | «끝없이 뻗는 방향이 {양쪽}인 {곧은} 선.»((한쪽, 곧은)이 «직선도 한쪽으로 뻗는다»로 읽힘 — codex) | 2:1(Claude 가 codex 에 설득됨) |
| 각 | «각은 시작점이 같은 두 {반직선}으로 이루어지며, 그 시작 {점}이 꼭짓점이다.» · 오답 «직선 · 곡선»(«한 직선에서 나간 두 반직선»이 같은 점일 수 있음 — codex) | 2:1(Claude 가 설득됨) |
| 정다각형 | 오답 → «곡선 · 점»((변, 대각선)이 정사각형 · 정오각형에서 참으로 읽힘 — codex. codex 안 «꼭짓점»은 «꼭짓점의 크기 = 각»으로 읽혀 Claude 안) | 2:1 |
| 그대로 | 사다리꼴 «적어도 두 쌍» · 공약수 · 공배수의 특정 수 · y축의 특정 값(a=b 등) — 뜻(일반 정의)으로는 거짓 | 2:1(Claude · grok / codex 1표) |

누출 검사로 더 고친 것: 정사각형 · 변과 꼭짓점의 뜻 문장 한 구절씩(10글자 조각 검사에 걸림 — 내용 파일에선 빈칸 괄호에 가려 안 걸리던 자리.
구절은 여기 옮기지 않는다) · C4 해설 한 줄. 이제 **괄호를 뺀 화면 문장**(채움 252가지)으로도 잰다.
