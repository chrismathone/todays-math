## 애매한 것 — 원장님이 가를 것

### 넣었지만 갈래·포함이 애매한 것

- **올림** (기타, 010쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(곱셈 쪽 여백에서 다시 풀이 — 3-1 곱셈과 같음)
- **나눗셈 세로 표기** (기호, 036쪽) — 이름은 우리가 붙임(교재에 이름 없음) — 나눗셈을 세로로 쓸 때 세 수의 자리를 여백 그림으로 가르침
- **나머지와 나누는 수의 관계** (성질, 042쪽) — 나머지가 늘 나누는 수보다 작다는 관계(이름 붙은 여백 제목)
- **…(몫과 나머지 표기)** (기호, 042쪽) — 몫과 나머지를 말줄임표로 잇는 새 표기(그림 속 식). 이름은 우리가 붙임
- **내림** (기타, 048쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(034쪽부터 소제목, 048쪽 여백에서 남은 수를 다음 자리로 내려 함께 계산한다고 풀이)
- **나눗셈을 맞게 계산했는지 확인하는 방법** (성질, 050쪽) — 검산식(나누는 수×몫+나머지=나누어지는 수). 공식으로 볼 수도 있음
- **원의 성질** (성질, 066쪽) — 지름이 반지름의 두 배라는 항목 — 같은 쪽에 지름이 원을 반으로 나누고 가장 긴 선분이라는 항목도 있음
- **약** (기타, 110쪽) — 어림한 들이·무게 앞에 붙이는 말(3-1 098쪽에서 처음)
- **합계** (기타, 134쪽) — 표 칸 이름 + 화살표 설명 — 뜻을 정하는 이름표는 4-1 106쪽

### 넣지 않은 것

- 018쪽 «곱셈 교환» — 여백의 이름 없는 성질(곱하는 두 수의 순서를 바꿔도 결과가 같음) — 법칙으로 넣을지
- 042쪽 «몫» — 색 글씨로 다시 나오지만 뜻은 3-1 056쪽에서 정함
- 068쪽 «컴퍼스» — 도구 이름
- 116쪽 «무게» — 뜻을 정하는 문장 없음(비교 방법만)
- 134쪽 «표» — 뜻을 정하는 문장 없음
- 088쪽 «한자 풀이(眞 · 假 · 帶)» — «한눈에 용어» 그림
