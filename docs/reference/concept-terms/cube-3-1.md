## 애매한 것 — 원장님이 가를 것

### 넣었지만 갈래·포함이 애매한 것

- **받아올림** (기타, 010쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(여백: 더한 값이 10 이상이면 윗자리로 올리는 과정)
- **받아내림** (기타, 018쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(여백: 받아내린 1이 10을 뜻함)
- **곧은 선** (기타, 034쪽) — 여백 예시 그림으로만 가름(문장 없음)
- **굽은 선** (기타, 034쪽) — 여백 예시 그림으로만 가름(문장 없음)
- **직각 표시** (기호, 036쪽) — 직각의 꼭짓점에 붙이는 표시 — 기호 자체는 그림이라 글자층에 없다
- **직사각형과 정사각형의 관계** (성질, 042쪽) — 정사각형이 직사각형에 든다는 포함 관계. «관계» 소제목을 성질로 넣을지 원장님 판단
- **÷** (기호, 056쪽) — 나눗셈 기호와 읽는 말(나누기)
- **곱셈과 나눗셈의 관계** (성질, 058쪽) — 곱셈식과 나눗셈식을 서로 바꿔 쓰는 관계. «관계» 소제목을 성질로 넣을지 원장님 판단
- **올림** (기타, 080쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(여백: 올린 1이 실제로 나타내는 값)
- **약** (기타, 098쪽) — 어림한 값 앞에 붙이는 말 — 뜻을 정하는 문장이 아니라 쓰는 법

### 넣지 않은 것

- 034쪽 «선분 ㄱㄴ · 반직선 ㄱㄴ · 직선 ㄱㄴ» — 도형 이름 붙이는 법(색 글씨) — 표기로 넣을지
- 036쪽 «각 ㄱㄴㄷ · 변 ㄴㄱ» — 같음 — 여백: 각은 꼭짓점을 가운데 두고 읽음
- 034쪽 «시작점 · 끝점» — 선분 · 반직선 비교 문장에서만 쓰임
- 008쪽 «어림» — 여백 어림 계산 — 뜻 풀이 없음(«약» 은 098쪽에서 넣음)
- 102쪽 «초바늘» — 시계 부품 이름 — 뜻 풀이 없음
- 126쪽 «단위분수 크기 규칙» — 상자 속 이름 없는 성질(분모가 클수록 작다)
- 128쪽 «분모가 같은 분수의 크기 규칙» — 상자 속 이름 없는 성질(분자가 클수록 크다)
- 036쪽 «한자 풀이(角 · 直)» — «한눈에 용어» 그림
