## 카드 뜻 문장과 교재 문장이 어긋나는 것 — 4건

무게: `틀림` 뜻이 다르다 · `범위` 넓이·출발점이 다르다 · `표현` 뜻은 같고 말이 다르다 · `학년` 카드 학년과 교재 학년이 다르다 · `동음이의` 이름만 같고 다른 개념.

| 카드 | 교재 용어 | 무게 | 무엇이 어긋나나 |
|---|---|---|---|
| 미지수가 두 개인 일차방정식 (`g8-two-variable`, 학년 8) «ax+by+c=0에서 a,b가 동시에 0이 아닌 식이며 해를 순서쌍으로 나타낸다.» | 미지수가 2개인 일차방정식 | 틀림 | 카드는 a, b 가 «동시에» 0 이 아니면 된다고 해서 한쪽이 0 인 식도 들어간다. 교재는 a, b 둘 다 0 이 아니어야 한다(한쪽이 0 이면 미지수가 하나뿐). 또 카드는 «식», 교재는 «방정식» |
| 연립방정식 (`g8-simultaneous`, 학년 8) «둘 이상의 방정식을 한데 묶어 공통인 해를 구하는 것.» | 연립방정식 | 틀림 | 카드는 공통인 해를 구하는 일(푸는 행동)로 정의했다. 교재는 방정식 여럿을 한 묶음으로 적은 것 자체를 연립방정식이라 하고, 해를 구하는 일은 따로 «연립방정식을 푼다»(p127)로 정의한다 |
| 지수법칙 (`g8-exponent-law`, 학년 8) «밑이 같은 거듭제곱을 곱할 때 밑은 그대로 두고 지수를 더하며, 거듭제곱의 거듭제곱은 지수를 곱한다.» | 지수법칙 | 범위 | 카드는 ⑴ 곱셈(지수의 합)과 ⑵ 거듭제곱의 거듭제곱(지수의 곱)만 — 교재는 ⑶ 나눗셈(m>n, m=n, m<n)과 ⑷ 곱·몫의 거듭제곱 (ab)ᵐ=aᵐbᵐ 까지 넷 |
| 순환마디 (`g8-repeat-block`, 학년 8) «순환소수에서 되풀이되는 가장 짧은 숫자 배열.» | 순환마디 | 표현 | 카드는 «가장 짧은» 숫자 배열이라 한다 — 교재 정의에는 그 말이 없고, 대신 소수점 아래에서 처음 되풀이되는 부분을 잡으라고 주의로 적는다 |
