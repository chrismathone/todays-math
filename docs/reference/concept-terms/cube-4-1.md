## 애매한 것 — 원장님이 가를 것

### 넣었지만 갈래·포함이 애매한 것

- **일만과 십만, 백만, 천만의 관계** (성질, 010쪽) — 10배마다 0이 하나씩 는다는 관계. «관계» 소제목을 성질로 넣을지 원장님 판단
- **밀기** (기타, 084쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(모양은 그대로, 위치만 바뀜)
- **뒤집기** (기타, 086쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(뒤집는 쪽에 따라 좌우·상하가 바뀜)
- **돌리기** (기타, 090쪽) — 정의 문장 없음 — 소단원 제목과 설명으로 가르침(시계 방향·반대 방향으로 90°·180°·270°·360°)

### 넣지 않은 것

- 008쪽 «다섯 자리 수» — 소단원 이름 — 쓰고 읽기 예만
- 018쪽 «자릿수» — 뜻 풀이 없이 쓰임
- 032쪽 «각도기 · 각도기의 중심 · 밑금 · 안쪽/바깥쪽 눈금» — 도구와 도구 부분 이름
- 058쪽 «(세 자리 수)×(몇십) 계산 방법» — 색 글씨지만 계산 방법(0을 붙이는 규칙)
- 090쪽 «시계 방향 · 시계 반대 방향» — 돌리기 방향 — 뜻 풀이 없음
- 112쪽 «눈금 · 눈금 한 칸의 크기» — 그래프 읽기 말 — 뜻 풀이 없음(탐험 카드 «그래프의 눈금» 은 있다)
- 128쪽 «수 배열표» — 뜻 풀이 없음
- 016쪽 «뛰어 세기» — 2학년 낱말 — 방법만
