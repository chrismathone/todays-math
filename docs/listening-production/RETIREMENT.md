# External listening material retirement

On 2026-10-06 the external assessment library was removed from the active service and the audited local work folders. Three separately authored sets containing nine questions were preserved byte-for-byte at their existing revisions.

Before disposal, all 193 sources and 3,699 questions were processed into [abstract production patterns](../../src/lib/english/listening/creation/assessment-patterns.json). The [production guide](PATTERN-GUIDE.md) explains six grade blueprints, observed and inferred evidence, question formats, generic topic domains, distractor construction and the limits of timing and difficulty proxies. Official question evidence and previous audio-only reconstructions are counted separately. These are persistent generation references; no model weights were trained.

Verified live disposal removed 193 sets, 213 media records, 386 DB transcripts, 853 Storage reference rows and 1,423 related audit rows. All 1,029 reviewed private Storage objects were absent on readback. All 386 provider transcript responses contained deletion tombstones with no original text, words, utterances, translations or summaries. The three retained authored documents and their revisions matched the pre-retirement checksums.

The reviewed local plan removed 13,030 untracked source and verification files totaling 7,829,015,106 bytes. Every planned file was absent afterward. Public pretrained models, their configuration files, virtual environments and separately authored/TTS samples were protected. Obsolete source-based seek tooling, copied dialogue test fixtures, bundled external catalogs and historical source reports were removed from the current checkout. Another 157 source-based files were removed from the active SRS checkout; its unrelated work and two original maintenance edits were preserved in a source-free patch.

The bank lists owned material, and shared provenance checks block retired external material before pagination, composition, publication, student access and media authorization. Normal uploads default to original material. External catalog links and the normal-bank ASR panel were removed. The canceled feedback feature has no live table or current application implementation.

Retained verification receipts contain aggregate counts only. Private corpus packets, source coverage receipts, scoped deletion manifests and temporary source inspection files are disposable inputs and are removed after verification. Source-dependent reproduction is deliberately unavailable afterward; the aggregate loader, deterministic blueprint builder and synthetic tests operate independently of original material.

This records removal from the current service and audited work folders. Git history and service-managed backup retention are outside this disposal operation.
