# 오늘의수학 작업실 전체 디자인 검수

2026-09-13 · 대상: `/dev/unified`의 오늘의 작업, 문제은행, 자료 제작, 시험지·내보내기, 내 시험지, 수업·학생 관리.

기존 작업실 방향을 유지하면서 실제 작업을 방해하는 잘림, 과도한 공간 점유, 읽기 어려운 글자, 불명확한 버튼과 키보드 동작을 수정했다. 빈 화면뿐 아니라 실제 문제를 담은 상태, 긴 제목·파일명, 오류·불러오는 중 상태, 접힌 메뉴와 확대 모드까지 확인했다.

왼쪽 선택선은 추가하지 않았다. 접기 버튼은 메뉴 안에 유지했고, 일반 버튼은 높이 44px·모서리 8px·글자 14px/600을 유지한다. 너비는 동작과 내용에 맞춘다. 수식·로고·인쇄 지면의 비례는 별도다.

## 실제 병합 화면에서 확인한 것

- **화면 크기:** 주요 상태는 1440×900, 1366×768, 820×900, 390×844, 360×740. 공통 메뉴는 1024×600, 크롭은 1050/1100px 경계, 헤더 정렬은 1920px도 추가 확인.
- **정렬:** 데스크톱의 유사 탭 제목 시작점은 (260,68), 본문 시작 y=144로 일치. 상단 동작의 높이 44px, 오른쪽 끝은 화면에서 20px. 좁은 화면은 같은 제목 시작점 아래에 동작을 줄바꿈한다.
- **홈·보관함:** 두 시험지 생성, 80자 제목 저장·검색·초기화, 접기 상태 복원, 잘못된 JSON 오류, 도움말·새 시험지·빠른 검색의 초점과 Esc.
- **문제은행:** 실제 DB 문제 선택, 정답·상세 보기, 학년 필터, 불러오는 중·빈 결과·오류·재시도에서 담은 문제 유지, 검색어 지우기와 담기 취소 후 초점.
- **자료 제작:** 실제 저장소 PDF와 긴 한글 파일명의 12쪽 PDF 가져오기, 12→11쪽 이동, 이미지 가져오기와 잘못된 파일 복구, 키보드·터치 자르기, 좌표 입력, 메뉴·검수 패널 접기, 전체 보기와 확대.
- **화면 간 전환:** 확대 중 Ctrl+K 검색, Esc로 검색만 닫기, 다시 검색해 문제은행으로 이동, 스크롤·메뉴 잠금 해제, 자료 제작 복귀, 검수에서 영역 지정으로 복귀.
- **원문 보존:** 초등 가분수는 화면에서 대분수로 표시하고 저장 원문은 유지. 중등 이상 원문 표시, 같은 크롭 재편집 시 중복 없이 갱신, 저장·복원·시험지 담기 확인.
- **시험지:** 모바일 삭제 후 초점, 한 단의 유동 너비와 두 단의 독립 가로 이동, 빈 제목의 정답지, 문제지·정답지 A4 2쪽 PDF 생성 후 두 페이지를 이미지로 렌더링하여 확인.
- **수업:** 로그인 실패·중복 가입·로그인 성공·빈 반·수업 탭 키보드 전환·긴 반 이름·현황 로딩/오류/재시도는 가짜 응답으로 검수했다. 실제 인증 요청과 DB 쓰기는 수행하지 않았다.
- **코드 검사:** 관련 기존 테스트 7파일 77개 통과. 수정 TSX ESLint 통과. 최종 빌드 결과는 아래에 기록한다.

각 병렬 검수 보고서는 병합 전 근거와 병합 후 확인 항목을 구분한다. 위 통합 확인 목록은 CSS를 임시 주입하지 않은 실제 병합 dev 앱에서 재검증한 결과다. 로컬 실행 기록과 화면 캡처는 `.qa-artifacts/workroom-hifi/`의 `review-*`, `crop-review/`, `bank-teaching/`에 있다.

검수는 Chromium과 가상 화면 크기·합성 터치 기준이다. 실제 iOS/Android 키보드, 스크린리더, 프린터 드라이버별 출력은 별도 확인이 필요하다. 99,128개 문항 전체의 지면을 개별 검수한 것은 아니며, 시험지 화면은 연속 미리보기이므로 실제 인쇄 페이지 나눔은 인쇄 창에서 확인해야 한다.

현재 dev 작업실의 OCR·HWP/HWPX 엔진 연결과 서버 저장은 별도 기능 통합 범위다. 이번 검수는 현재 구현된 검색→크롭→검수→시험지→인쇄 흐름을 대상으로 했다.

## 최종 확인

통합 UI 검증, 관련 테스트 77개, ESLint와 `npm run build` 모두 통과했다. 기존 `dev/tier-bench/g4`의 넓은 파일 추적 경고 2건은 이번 디자인 변경과 무관하게 남아 있다. 변경은 로컬 main에 병합했고 배포·푸시는 하지 않았다.
