# 오늘의 기억 — 기존 코드 연동 MVP

중1 일차방정식을 하루 12문제로 복습한다. 문제은행의 기존 생성기, 수식 표시, 학생 계정, 반 관리, 진도, 개념 강의를 재사용한다.

## 진입 경로

- `/lab/math-srs`: 로그인 없이 사용하는 브라우저 체험판. 기존 로컬 기록을 계속 읽는다.
- `/learn/math-srs`: 기존 학생 계정으로 사용하는 서버 저장 학습 화면. 개념 강의 목록에서 진입한다.
- `/classes/[id]/math-srs`: 기존 반 관리에서 진입하는 교사용 학생별 복습 현황.

학생·교사 경로의 저장 기능은 전용 SRS 테이블을 적용한 환경에서 작동한다. 이번 작업에서는 운영 DB를 변경하지 않는다. 테이블이 없는 경우 준비 중 안내와 재시도를 제공하며, 저장 성공으로 표시하지 않는다.

전체 학년 생성기를 브라우저로 가져오지 않는다. 현재 범위에 해당하는 세 모듈에서 적합한 유형을 모두 연결한다. 신규 학습 기억 모델과 순서·중복 제출 처리는 SRS에 필요한 부분만 추가한다.

## 연결한 문제 유형

총 **87개 기존 유형**: 등식의 성질 8, 두 단계 방정식 4, 괄호 풀기 4, 양변에 문자가 있는 식 7, 분수식 6, 문장제 58.

`src/lib/math-srs/engineCatalog.ts`에 원래 유형 키·제목·소단원·난이도·개념을 기록한다. 가져온 모듈 중 나머지 57개 유형도 제외 이유를 남긴다. 학습 범위 밖 48개, 식 전체·복수 정답·선택형 등 현재 입력 방식과 맞지 않는 9개다. 문제 발문을 임의로 숫자 단답형으로 바꾸지 않는다.

정수·음수·소수·분수 입력을 지원한다. 원래 정답 표기와 단위를 해설에 표시한다. 유형에 없는 난이도를 요청하면 가장 가까운 기존 난이도에서 선택하고, 화면에는 실제 난이도를 표시한다.

## 학습과 저장

워밍업, 짧은 문제, 기억 확인·훈련, 과거 오답 개념 재도전, 마지막 도전으로 12문제를 배열한다. 현재 진도는 학습 맥락 정보이며, 첫 미션은 여섯 개념을 확인하는 진단이다. 진도에 따른 출제 범위 제한을 구현했다고 해석하지 않는다.

미완료 미션은 날짜가 바뀌어도 이어진다. 정오답·힌트·시간·유형·개념·평가를 기록하고, 최근 90회 미션과 누적 개념 기억 상태를 보관한다.

서버 학습에서는 정답·해설·재현용 시드를 미제출 문제 응답에서 제외한다. 서버가 정답과 힌트 사용을 판정하며, 순서가 틀리거나 이미 제출한 내용을 바꾸려는 요청은 거절한다. 동시 요청은 저장 버전으로 충돌을 처리한다. 계정 간 기록은 학생 ID와 기존 권한으로 분리한다.

체험판은 `todays-math:srs:v1`, 제출 전 힌트·시간은 `todays-math:srs:draft:<learnerId>`에 보관한다. 학습자 별명은 최대 12명이다. 저장 불가·공간 부족·손상 상태를 알리고 임시 메모리로 계속할 수 있으며, 손상된 원래 기록은 덮어쓰지 않는다. 체험판 기록을 실제 학생 기록으로 자동 업로드하지 않는다.

## 저장 모델과 적용 경계

반·학생·계정·진도·강의 테이블은 기존 모델을 사용한다. SRS 상태만 학생별 전용 모델에 저장한다. 기존 `TestResult`는 실제 시험과 연결되는 성적이며, `WorkspaceDocument`는 교사의 문제지·추출 초안이므로 반복 학습 기록을 넣지 않는다.

제공한 스키마와 SQL은 개발 결과물이다. 실제 환경 적용 시 연결 대상과 기존 마이그레이션 이력을 확인하고 SRS 변경분을 검토해야 한다. 관련 없는 미적용 변경까지 적용할 수 있는 일괄 마이그레이션 명령을 이 기능 때문에 실행하지 않는다.

SQL: `prisma/migrations/20260923150000_student_srs_state/migration.sql`. 서버 API와 저장 규칙은 [학생 계정 연동 문서](math-srs-server.md)를 참조한다.

## 기억 추정의 의미

시간 유지율은 `exp(log(0.9) × 경과일 / 안정도)`이고, 예상 기억률은 `숙련도 × 시간 유지율`이다. 안정도는 복습 직후 대비 유지율이 90%가 되는 일수다. 같은 표시 함수를 학생·교사·체험판에서 사용한다.

이력이 없는 개념은 ‘측정 전’으로 표시한다. 이 수치는 검증된 성공 확률이나 시험 성취도 평가가 아닌 초기 추정치다. 실제 시험 성적·예측 보고서에 합산하지 않는다.

## 검증

### 학습 화면 개선

체험판 홈은 오늘의 미션, 최근 7일 학습 리듬, 개념 기억, 최근 풀이 순서로 구성한다. 장식용 테두리 없이 여백·배경색·글자 크기로 구분하고, 키보드 사용자를 위한 포커스 표시는 유지한다. 문제 풀이와 피드백·완료 화면은 별도 `PracticeSession` 컴포넌트로 분리했다.

최근 7일 기록은 미션 시작일이 아닌 실제 제출 시각의 한국 날짜로 집계한다. 미완료 미션의 풀이도 포함하며 기록 없는 날짜는 비워 둔다. 개념 기억은 전체/복습 예정 필터와 최근 복습·다음 권장 복습 기록 펼치기를 제공한다. 계정용 교사 화면은 이름 검색과 학습 상태 필터를 함께 적용한다.

화면 개선 후 관련 7개 파일 **88개 테스트**, 전체 타입 검사, 대상 ESLint와 배포용 빌드가 통과했다. 실제 브라우저에서 데스크톱, 390px·320px 모바일, 개념 필터, 입력 오류, 힌트, Enter 제출, 정답 피드백, 미션 완료 화면을 확인했다. 계정 화면의 API 상태별 동작은 모형 응답으로 검증한다.

### 기존 엔진·저장 검증

기존 생성기 원문·정답과의 일치, 반복 가능한 생성, 정답 입력, 한국 시간 경계, 저장 호환성, 순서와 중복 제출, 힌트 상태, 답안 비공개, 학생·교사 권한, 실패 복구를 테스트한다. 서버 검증은 DB 모형을 사용하며 운영 학생 기록을 만들지 않는다.

통합 후 SRS·학생 경로·한국 날짜 관련 11개 파일 **213개 테스트**가 통과했다. 기존 생성기 검증 5개 파일은 1,596개 통과·128개 기존 제외, 기존 강의·반관리와 신규 화면·통신 검증은 86개 통과했다. 기존 유형 87개 × 120개 시드의 출력에서 원문·정답·해설 대응을 확인했다.

전체 타입 검사와 배포용 빌드를 함께 수행한다. 실제 브라우저에서는 체험판의 수식·학습·해설과 모바일 표시를 확인한다. 운영 DB 적용과 실제 계정의 기기 간 저장 확인은 별도 적용 단계다.
