# 오늘의 기억 — Math SRS MVP 0.1

공유 대화의 중1 일차방정식 SRS 아이디어를 기존 오늘의수학 실험실에 구현한 체험용 MVP다.

## 실행과 사용

`npm run dev` 실행 후 `/lab/math-srs`에서 시작한다. `/lab`에도 진입 카드가 있다.

1. 기본 프로필로 시작하거나 학습자 이름/별명을 추가한다(최대 12명).
2. 하루 12문제를 풀고 정답·해설을 확인한다. 정수, 음수, 소수, 분수 입력을 지원한다.
3. 힌트나 ‘아직 모르겠어요’를 사용할 수 있다. 제출한 답은 바로 저장되며 다시 제출할 수 없다.
4. 미완료 미션은 날짜가 바뀌어도 이어진다. 제출 전 힌트 사용과 풀이 시간도 복원한다.
5. 교사용 현황에서 프로필별 개념 기억률과 최근 5개 풀이 기록을 확인한다.

## 구현 범위

- 등식의 성질, 두 단계 방정식, 괄호 풀기, 양변에 x가 있는 식, 분수식, 문장제: 6개 개념, 12개 규칙 템플릿.
- 답을 먼저 정하고 식을 역산하므로 각 문제는 유일한 정수 해를 갖는다. 시드로 문제를 재현할 수 있다.
- 난이도 1–5는 주로 수의 크기와 부호를 조절한다. 교육 현장 검증을 거친 난이도 척도는 아니다.
- 워밍업 → 짧은 문제 → 기억 확인/훈련 → 과거 오답 개념 재도전 → 마지막 도전으로 12문제를 배열한다.
- 과거에 틀린 이력이 있을 때만 재도전 문제를 넣는다. 마지막 도전은 난도를 올린 단일 개념 문제다.
- 정오답, 힌트 사용, 풀이 시간, 템플릿, 개념, 자동 평가를 기록한다. 화면은 자동 평가(다시 익히기/조금 더 연습/스스로 해결)를 사용하며, 엔진은 자격을 제한한 easy 평가도 지원한다.
- 학생별 숙련도와 기억 안정도를 따로 유지하며, 선수 개념에는 작은 가중치만 반영한다.
- 브라우저별 학습 기록은 `todays-math:srs:v1`, 제출 전 진행은 `todays-math:srs:draft:<learnerId>`에 저장한다. 최근 90회 미션만 보존하고 개념별 누적 기억 상태는 유지한다.
- 저장 불가/용량 부족/손상 데이터는 사용자에게 알리고 임시 메모리에서 계속할 수 있다. 손상된 기존 기록은 덮어쓰지 않는다.

## 기억 추정의 의미

엔진의 시간 유지율은 `exp(log(0.9) × 경과일 / 안정도)`이다. 안정도는 복습 직후 대비 유지율이 90%가 되는 일수다.

화면의 예상 기억률은 `숙련도 × 시간 유지율`이다. 틀린 직후에도 100%로 보이는 오해를 피한다. 풀이 이력이 없는 개념은 숫자를 표시하지 않고 ‘측정 전’으로 보인다. 이 수치는 검증된 성공 확률이나 실제 성취도 평가가 아닌 초기 휴리스틱이다.

엔진·저장·학습 흐름 총 103개 테스트. 수식 3,000개를 독립 파서로 검산했다. 학습 흐름 검증은 빈 답/분모 0 거절, 힌트 후 재접속, 프로필 분리, 전날 미션 완료, 저장 공간 부족 중 연속 풀이를 포함한다. 실제 브라우저에서 12문제 완주, 기록 재로딩, 교사용 표와 390px 모바일 배치를 확인했다.

## 다음 단계

현재 실험실은 로그인 없이 접근하는 로컬 체험판이다. 실제 학생 계정, 학원 간 데이터 분리, 서버 저장, 기기 간 동기화와 교사의 원격 조회는 아직 연결하지 않았다. 실시간 AI 생성이나 유료 API도 사용하지 않는다.

운영 확장 시 기존 StudentAccount/학원 소유권에 연결한 서버 제출 API, 원자적·중복 방지 채점, 서버가 보유하는 정답, 마이그레이션과 개인정보 접근 제어를 먼저 구현한다. 이어서 학생 10–20명의 사용으로 난이도/복습 간격을 보정하고 문장제 전략 선택과 계산 탐정 유형을 추가한다.
