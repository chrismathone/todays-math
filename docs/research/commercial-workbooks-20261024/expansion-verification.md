각 팩의 JSON, TSV와 `.coverage.json`은 `data/commercial-workbooks/`에 있다. coverage는 원본 SHA-256, 답안 PDF 쪽, 주소 기대 목록, 검토 렌더의 해시와 제외 사유를 기록한다. [major 11개 원본의 첫 결과](expansion-major.md)는 7개 준비·4개 등록 보류를 구분한다. 해당 4개는 후속 작업에서 검수를 계속하므로 첫 보고서의 보류를 영구 판독 불가로 해석하지 않는다. 현재 최초 확장 대상 33개 원본 중 30개가 준비됐으며 3개는 검수 중이다.

발행연도·교육과정·쇄·ISBN을 확인하지 못한 자료는 그대로 표시한다. 자료실 게시일이나 PDF 조판 날짜를 교재 발행연도로 바꾸지 않았다. 길벗의 2026 개정 교재는 출판사가 표기한 발행일을 보존한다. 블랙라벨은 공식 공개 1쇄 보관본이며 최신 첨부·정오표 대조를 주장하지 않는다. 수경 기하의 의심스러운 원문 답 2개는 등록 전에 null로 보류했다.

## 원본 확보와 실제 등록의 구별

03:08 KST 수집 완료된 이번 공개 링크 조사분의 중복 SHA-256을 제거한 PDF는 **1,650개**, 14개 출판사, 109,104쪽이다. 파일 수는 고유 교재 수가 아니다. 빠른 정답·전체 해설·옛 판본·분할 파일이 각각 있을 수 있으며 전체 웹 조사가 완료됐다는 주장도 아니다.

공식 목록에서 관찰한 링크만 사용했다. 비상·지학사·메가스터디·매스티안 공개 PDF, EBSi 수학 게시물 487개, EBS 초등 만점왕 수학 게시물 204개, 마더텅 게시물 72개를 조사했다. EBSi·메가의 ZIP 35개에서 정답 PDF 72개를 확인했으며 아름다운샘 190개 게시물의 첨부 202개도 수집했다. 이룸이앤비 수학 도서카드 43개의 공개 정답/해설 버튼에서 43개 PDF를 확보했으며, 미리보기·정오표 버튼은 해당 수에 포함하지 않았다. 오래된 EBS 초등 2-2 첨부 4개는 파일 없음 HTML을 반환했고, 메가 한 목록 항목은 실제 다운로드 대신 `#`를 가리켰다. 로그인·접근 제한이 있는 출처를 공개 다운로드로 간주하지 않았다.

신사고의 2026년 공식 문의 답변은 [쎈 연산(4월 30일)](https://children.sinsago.co.kr/center/qna_read.aspx?bulletin_idx=473761&ch=s&page=13&s_cate_idx1=)과 [라이트쎈 중2-2(7월 23일)](https://children.sinsago.co.kr/center/qna_read.aspx?bulletin_idx=474702&ch=c&page=9&s_cate_idx1=)의 정답·해설 PDF를 제공하지 않는다고 안내한다. 이 자료들은 확보·등록 수에 포함하지 않았다. 과거 정답 자료실의 검색 결과는 현재 다운로드 가능성의 증거로 사용하지 않았다. 이번 직접 접속은 타임아웃이었고, 공지 전문을 읽었다고 주장하지 않는다.

원본·텍스트·렌더는 외부 볼륨 `/Volumes/TodayWork/commercial-workbook-sources/`에 보관한다. 이번 증거는 `expansion-20261024/`의 `library-manifest.json`, 검색 가능한 `index.html`, `public-library/acquisition.jsonl`, 출판사별 기록과 ZIP manifest다. 원본 PDF·문제/해설 본문·이미지를 Git이나 앱 문제은행에 추가하지 않았다. 출처 버튼과 공개 provenance에는 지속 가능한 공식 자료 페이지를 사용하고, 만료되는 서명 다운로드 주소는 역사적 파일 증거에만 보존한다.

## 화면과 저장 확인

공개 자료 목록에 교재·출판사 검색과 실제 자료 수를 추가했다. 검색어를 바꾸면 이전 미리보기를 비우고 늦게 도착한 응답을 무시한다. 선택한 교재만 내려받으며 동일 판본과 요청 식별자는 기존 등록본을 다시 연다. 자료 수가 늘어도 중복 팩 ID가 들어가지 않는 검사와 만료 주소가 출처 버튼에 들어가지 않는 검사를 추가했다. 기존 반·학생 권한, 정답 개정 고정, 수동 채점·오답·인쇄 계약은 유지하며 DB 마이그레이션은 없다.

각 운영 등록 직후 전체 주소·키·판본·출처를 재조회하고 정규화한 SHA-256을 로컬 등록 입력과 비교했다. 이번 30개 등록 영수증은 모두 일치한다. 외부 `production-registrations/`에 원본/저장 해시와 저장 ID를 보관했다. 운영 학생의 과제·채점·오답 기록은 생성하지 않았다.

Orca 내부 브라우저의 개발용 메모리 화면에서 새 검색 → 수력충전 확률과 통계 등록 → 첫 2문항을 예시 학생 가에게 배정 → 오답 1·정답 1 저장 → 첫 문항의 오답 선택 → 학생용 A4 1쪽 미리보기를 실제 실행했다. 학생용 지면에 정답이 없음을 확인했다. 이는 서버 영구 저장 검증과 구별한다. `new-pack-browser-flow.txt`, `new-pack-print-preview.png`, `search-mobile.png`가 외부 증거이며 390px 검색 화면의 가로 넘침도 확인했다.
