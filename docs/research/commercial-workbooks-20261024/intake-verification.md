# 공개 정답 첫 전권 묶음 등록

2026-10-24. 이전 [기능 계획](../../planning/commercial-workbook-implementation-20261023.md)의 출판사 공개 정답 공급을 확장한다. 조사에서 확보한 36개 PDF 중 첫 3권을 선택했다. 26개 출판사와 2,094개 자료·목록 행은 조사 규모이며, 이 문서의 실제 등록 규모와 다르다.

소문항은 원래 순서로 한 주소에 함께 표시한다. 모든 주소를 보존했다는 말은 문제 본문 전체를 조사했다거나 모든 정답이 확보되었다는 뜻이 아니다. 그림·풀이 참조·복합 답안 중 확인하지 않은 정답은 null과 사유 원장으로 남긴다. 세 팩의 자세한 출처·판본·검수 증거는 [비상](visang-operation.md), [지학사](jihak-repetition.md), [EBS](ebs-manjeom.md)에 있다. 지학사의 발행연도·쇄·ISBN은 미확인이다.

## 구현

- 출판사 자료 선택 목록과 선택한 파일만 읽는 로딩을 추가했다. 늦게 도착한 이전 선택의 응답이 최신 선택을 바꾸지 않는다.
- ISBN과 제목·출판사·학년·교육과정·판본이 같은 등록본을 연다. ISBN이 같아도 판본이 다르면 별도이며, 같은 요청의 재시도는 기존 등록 영수증을 사용한다.
- 권·단원 필터를 추가했다. 필터를 바꿔도 선택한 문항을 유지하고, 쪽 범위만 초기화한다. 다른 교재를 열 때 저장하지 않은 배정·개정 입력을 보호한다.
- 출처 세부 기록은 필요할 때 펼친다. 기존 수동 채점·오답·인쇄 계약과 서버 권한은 유지하며 DB 마이그레이션은 없다.
- 기존 비상 개념플러스유형 1단원 팩과 저장된 개정은 수정하지 않았다.

## 검증 기록

출판사별 Codex 작업이 원본 이미지를 검토하고 독립적인 쪽·번호 기대 목록, TSV 왕복, null 원장, 분수·근호·단위 사례를 검사했다. 조정자는 비상 PDF 16쪽, EBS 9쪽, 지학사 2·27쪽을 별도로 원문 이미지와 대조했다. 조정자의 이 확인은 전 문항 이중 검수라는 주장이 아니다.

실제 SQL 저장소와 기존 마이그레이션을 사용하는 PGlite 검사에서 각 공개 팩의 전체 주소·정답 왕복, 중복 등록 재시도, 계정 격리, 과제 배정, 오답 생성, 학생용 정답 제외 출력을 검증한다. 화면 검사는 다른 판본 구별, 실패 후 재시도, 늦은 다운로드, 입력 보호, 권 변경 시 선택 유지도 포함한다.

Orca 내부 브라우저의 개발 전용 메모리 화면에서 지학사 팩을 등록하고 첫 단원 1·2번을 예시 학생 가에게 배정했다. 1번 오답·2번 정답을 저장한 뒤 첫 문항의 오답노트와 학생용 A4 1쪽 미리보기를 확인했다. 운영 학생 성적에 쓰지 않았다. 이는 서버 영구 저장 검증과 구별한다.
