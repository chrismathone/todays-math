### Page-address limitation for 수학의 샘 기하

Its source provides **section-start references**, not the individual main-book page of each exercise. Every address therefore uses an explicit string such as `단원 시작 015`, with the exact printed chapter/section/number. The pack label, coverage text, provenance and registration scope all state **“단원 시작 쪽 참조 · 개별 문항 쪽 미확인”**. No row uses bare `015` to imply that every exercise is printed there. This complete solution-scope pack remains useful for number-based reference without inventing page positions. `sourcePage` points to the actual PDF page carrying the short final answer.

Other packs retain printed page ranges where the publisher groups answers by range; individual positions inside a range are not synthesized. Structured subparts are combined beneath their printed main exercise number. Fractions, radicals, signs, units and circled choices are retained using the documented plain-text notation (`sqrt()`, `/`, `vec()` where required).
