# 시중교재 기능 통합 검증

2026-10-23. 구현 계획은 [계획서](../../planning/commercial-workbook-implementation-20261023.md), 자료 범위는 [출판사 조사](publisher-sources.md)를 따른다.

## 자동 검증

- 통합 10개 파일, 81개 테스트 통과: 도메인, 권한, 실제 SQL/PGlite 저장소·트리거, API, 공개 정답 묶음, 화면, 메뉴 접근, 개발 전용 경로, 오류 기록 경로.
- 마지막 화면·개발 경로 변경 후 관련 3개 파일 12개 테스트 재통과. 위 81개에 포함된 검사이며 합산하지 않는다.
- 기존 채점·오답 및 학생 메뉴 관련 4개 파일 87개 테스트 통과.
- 전체 TypeScript 검사, 변경 영역 ESLint, 최종 `npm run build` 통과. 의존성·잠금 파일 변경 없음.
- 독립 검토에서 전출 학생 한 명 때문에 남은 학생의 과제까지 막히는 문제를 발견해 수정했다. 현재 접근 가능한 학생만 응답에 투영하고, 저장된 원본은 유지한다. 검토자가 기존 응답 재시도·노트·혼합 출력까지 두 정책 구현으로 재확인했다.

## 내부 브라우저

운영 DB와 분리한 `/dev/commercial-workbooks`에서 실행했다. 이 경로는 production에서 404이며 메모리 저장소만 사용한다.

1. 공식 비상 정답 묶음을 등록하고 100개 문항 주소·검토 94·미확보 6 표시를 확인했다.
2. 개념책 8쪽 1·2번을 골라 예시 학생 가 한 명에게 `비상 공개 정답 8쪽 실습`을 배정했다.
3. 1번 오답·2번 정답을 저장했다. 저장 요약 1/1, 미채점 0, 이력 1회, 버전 1을 확인했다.
4. 생성된 1번 오답에 교정 메모와 완료 상태를 저장했다. 최초 오답 시각이 유지되며 노트 버전만 1로 바뀌었다.
5. 같은 메모리 저장소를 다시 읽은 뒤 공식 교재가 남아 있음을 확인했다. 이 검사는 서버 영구 저장의 증거가 아니다.
6. 390×844 화면에서 문서 가로 넘침 0, 필터·목록·버튼 배치를 확인했다. 데모 바깥 컨테이너의 너비가 축소되는 문제를 `width: 100%`로 수정했다.
7. 학생용 참조 오답노트 확대 미리보기와 실제 인쇄용 DOM의 A4 크기(794×1123, 넘침 0)를 확인했다. 인쇄 직전 재조회까지 실행하고, 물리 프린터를 호출하지 않도록 로컬 검증에서 `window.print`만 임시 대체했다. 그 순간의 인쇄 DOM을 Orca PDF로 내보내 **A4 1쪽**을 렌더링해 확인했다. 정답·교정 메모는 PDF에 없다. 대체 함수와 검증 DOM은 제거했다. OS 프린터 대화상자·물리 출력은 실행하지 않았다.

로컬 증거는 외부 볼륨 `/Volumes/TodayWork/commercial-workbook-evidence/`에 있다: `student-print.pdf`, `student-print.png`, `print-preview-screen.png`, `mobile-screen.png`, `integrated-tests.log`, `integrated-typecheck.log`, `final-ui-tests.log`, `final-build.log`, `independent-review.md`.

## 데이터베이스

대상은 기존 오늘 수학의 PostgreSQL 17.6이며, 연결된 Supabase 도구에는 해당 프로젝트가 없어 기존 Prisma 직접 연결을 사용했다. 비밀 값은 파일·로그에 복사하지 않았다.

- 사전 읽기: 새 도메인 테이블·마이그레이션 기록 없음.
- 신규 마이그레이션만 트랜잭션 내 적용 후 롤백하는 dry run 통과.
- `20261023110000_commercial_workbooks` 적용 후 별도 읽기 재검증 통과.
- SHA256 `f8913751c9c863cb7452c450fc42aea947e56c22164c1cc8842e7c527cf847c4`.
- 테이블 6, 트리거 10, 함수 6, 제약 48. 모든 테이블 RLS 사용. PUBLIC/anon/authenticated 테이블 권한 0, 브라우저 정책 0. 함수는 invoker 및 고정 search_path, PUBLIC 실행 권한 없음.
- 기존 테이블·학생 성적·SRS 기록을 변경하지 않았다. 다른 미적용 마이그레이션을 함께 실행하지 않았다.

## 남은 범위

공식 PDF 전체 72쪽 중 구조화·검토한 범위는 개념책 1단원 8~26쪽뿐이다. 소문항은 원문 번호를 보존한 한 주소의 답으로 묶어 함께 채점한다. 원문 문제, 자동 수식 채점, 학생 제출, 쌍둥이·유사 문제는 이번 기능에 포함하지 않는다. 교재 카탈로그는 계정별이며 확보된 공통 자료를 각 계정에서 등록할 수 있다.

운영 배포와 실제 계정의 등록·재접속 검증 결과는 배포 후 추가한다.
