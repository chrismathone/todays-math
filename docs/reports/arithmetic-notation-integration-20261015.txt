Implementation
src/lib/arithmetic-v2/presentation/notation.ts is a display-only projection for
arithmetic prose. Geometry has a separate entry point from numerical/algebraic
prose. It reads complete formula chains, units, exact fractions and pi quantities.
The geometry projection distinguishes each occurrence of a segment, line, ray,
arc, angle, triangle, point and scalar variable. It also processes existing TeX
groups while preserving already decorated objects and text commands.
It uses the existing shared tokenizer, MarkdownRenderer and KaTeX. Arc widehat
notation goes through the existing geom-arc-wrap rendering, not a hat substitute.

Examples independently checked:
  AB=AC=22 cm and BC=34 cm: endpoint names carry segment bars; units upright.
  AD perpendicular BC: both segments barred and the perpendicular symbol in math.
  Three parallel lines AD, BE, CF: double arrows; later AB/BC lengths: bars.
  Chord TP and arc TP in one sentence: separate bar and arc roles.
  Tangent PB length: a segment, not an infinite line.
  Line ell parallel m: m remains a line variable, not a metre unit.
  A specified ray: one arrow; no ray is invented for finite bisector connectors.
  Scalar B for base area stays a variable; ABC polygon names are not segments.
  x!=0, negative numbers, percent blanks and variable conditions: explicit math.
  8*pi/3 cubic centimetres: one fraction followed by an upright cubed unit.
  Scale lists 1/10, 1/100, 1/1000 in titles: fractions; list dots unchanged.
  Arithmetic operators in titles and legacy expressions: actual KaTeX.
