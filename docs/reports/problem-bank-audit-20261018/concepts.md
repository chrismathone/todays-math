# 개념 문항은행 검토 결과

초3부터 중3까지 7개 학년의 14개 은행 파일에서 **개념 9,119건, OX 6,947건, 적용 4,400건, 그림 246건**을 검사했다. 계약·ID·질문 데이터 연결에서 보완해야 할 확정 오류는 발견하지 않았다.

| 검사                            | 범위                                                           | 결과                               |
| ------------------------------- | -------------------------------------------------------------- | ---------------------------------- |
| 은행 계약                       | 14개 파일 전체                                                 | 모두 통과                          |
| 문항 ID 중복                    | 네 종류 전체 20,712개                                          | 0                                  |
| JSON과 실행 데이터 대응         | 평가 JSON 14개와 개념 9,119개                                  | 빠진 키·남는 키·내용 불일치 모두 0 |
| 기존 표기 검출기                | 뜻·질문·정답·예·OX·적용·그림 설명                              | 0                                  |

| 지원 학년의 소단원 재고         | 초3 56·초4 62·초5 56·초6 56·중1 52·중2 56·중3 22개, 합계 360개 | 개념·OX·적용 재고 모두 있음        |

형식별 제외는 검토 후 의도적으로 적용한 것이므로 누락된 문항 수로 더하지 않는다. 초1·초2의 130개 소단원은 현재 지원하는 7개 학년 밖에 있다. 그림 문항도 모든 소단원에 반드시 있어야 하는 형식이 아니다.

현재 통과한 구조 검사를 유지하면서 개별 문장의 수학적 의미와 학년 적합성, 유사 개념의 반복량은 내용 검토로 관리해야 한다. 이번 검사는 2026년 10월 8일의 9,119개 개념 복구를 현재 실행 데이터와 다시 대조한 것이며, 공식 성취기준 전부에 대한 정합성 인증이나 학생 학습효과 측정은 아니다.

재현은 `npx tsx scripts/qa/bank/concept-bank-audit.ts --out <출력폴더>`로 한다. [문항 수와 대응 원장](concept-counts.json), [테스트 결과 요약](root-checks.json)에 ID·건수·지문을 남겼다. 학생 기록, ID, 원문 순서와 질문 내용은 변경하지 않았다.
