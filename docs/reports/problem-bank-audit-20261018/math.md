# 수학 문제은행 검토 결과

2026년 10월 18일 09시 38분부터 09시 39분 KST까지 공유 DB의 **117,828행 전부**를 같은 읽기 전용 스냅샷에서 검사했다. 현재 출제 가능한 문항은 **115,383건**이다. 우선 보완할 내용은 **해설 수식 표시 12건**과 **증명 빈칸을 선택지로 잘못 나누는 2건**이다. DB와 출제 허용 상태는 변경하지 않았다.

검수 상태는 승인 117,749건·대기 79건이다. 승인 여부와 출제 잠금은 별개이므로 승인된 수를 곧바로 사용할 수 있는 수로 표시하면 안 된다. 현재 엔진 갈래의 100,974건에는 모두 `elem:` 또는 `mid:` 식별자가 있다. 학년별 재고와 문항 ID는 [전수검사 원장](math-counts.json), 출처 준비도는 [준비도 집계](readiness-counts.json)에 있다.

## 오류로 세지 않은 자동검사 후보

- 정답 문자열이 다른 동일 문항 **28쌍**을 모두 다시 읽었다. 양수 기호, `frac`와 `dfrac`, 분수와 소수, 수량 접미사 등의 차이였으며 **모두 수학적으로 같은 답**이었다.
- 출제 가능한 ‘동일 보기 텍스트’ 후보 **64건**은 전부 `[그림]` 자리였다. 서로 다른 그림 자산과 짝지어져 있어 같은 오답 보기라고 세지 않았다.
- 보기 수가 5개가 아닌 출제 가능 후보 **15건** 중 위 증명 오류 2건 외의 **13건**은 소문항·조건·연결하기의 번호였다. 13건을 5지선다 위반으로 세지 않았다.
- 원문자 정답이 있지만 선택지 파싱은 없는 후보 **5건**은 답칸 번호 또는 틀린 풀이 단계 찾기였다. 선택지 유실로 세지 않았다.
- 형식 미분류 **43건**에는 문자 선택지와 이미지 안 보기가 있다. ‘풀 수 없는 43문항’으로 해석하지 않는다.

## 통과 항목과 검토 범위

- 빈 본문 0, 빈 정답·정답 없음 표식 0, 차시 참조 누락 0, 교과서 자료 연결 누락 0, 원문 없는 변형 0.
- 본문 **117,828개**, 정답 **117,828개**, 해설 **117,822개**를 공통 문자열 수식 렌더러로 검사했다. 본문·정답의 수식 대체 표시 0, 해설 12개다. 해설 없는 6건은 모두 이미 출제 불가다.
- URL 그림이 있는 3,881문항이 참조하는 **4,509개 경로**는 모두 로컬 파일과 CDN 매니페스트에 있다. 그림 치수 결함 0. 그림뿐인 보기의 연결이 불완전한 3건은 모두 이미 출제 불가다.
- 매니페스트 전체 **23,305개 자산·517,274,373바이트**의 크기와 SHA-256이 모두 일치했다. [자산 대조 결과](figure-assets.json)는 로컬 파일 기준이며 원격 CDN 응답과 개별 그림의 수학적 정확성은 별도 검토 대상이다.
- 10월 17일 선택지 갱신 원장의 **47,672행 전부**가 현재 DB와 일치했다. 원장 안의 갱신 전후 발문과 정답이 가리키는 선택지 값도 47,672행 모두 같았다. 이는 갱신 대응 검사이며 독립 검산은 아니다. [최근 갱신 대조](recent-ledger-check.json)
- 누락 역슬래시 검출기, 사적 영역 글리프, `undefined`·`NaN` 등 잔재 검출 후보는 0이다. 이 검출기가 모든 표기 오류를 잡는 것은 아니다.

이 검토는 **모든 행의 구조·연결·표시 검사와 표시된 후보의 재열람**이다. 117,828개를 모두 독립적으로 풀거나 전체 지면을 육안 검수한 결과는 아니다. 정답·해설의 수학적 검산 범위는 [엔진 검토](engine.md)에 별도로 기록했다.

재현 명령은 다음과 같다. 환경 파일에는 DB 접속 정보가 있으므로 값은 출력하지 않는다.

```sh
npx tsx --env-file=<환경파일> scripts/qa/bank/problem-bank-audit.ts --out <출력폴더>
npx tsx --env-file=<환경파일> scripts/qa/bank/bank-readiness-census.ts --out <출력폴더>
```

첫 스크립트는 `RepeatableRead` 트랜잭션의 첫 문장에서 `SET TRANSACTION READ ONLY`를 적용하고, 전체 수와 실제 읽은 수가 다르면 실패한다. 원장에는 본문·정답·해설 원문을 저장하지 않고 ID·건수·지문만 남긴다.
