# 영어 문항과 대본 내용 재검토

영역별 자동검사 후 root가 현재 영어 지문 2개와 **영어 13문항 전부**, 듣기 대본·번역 3개와 **듣기 9문항 전부**를 읽고 선지·저장 정답·해설을 대조했다. 읽기 전용으로 재조회한 개정은 영어 2, 듣기 4이며, 각 문항의 지문은 [재검토 원장](english-text-review.json)에 남겼다.

| 대상                              | 직접 읽은 수 | 내용상 확인                                                                                  |
| --------------------------------- | -----------: | -------------------------------------------------------------------------------------------- |
| 텃밭 지문의 영어 세트 `6c7cec12…` |        5문항 | 주제·내용 일치·어법의 저장 답과 해설에서 추가 오류를 발견하지 않음                           |
| AI 지문의 영어 세트 `15fad5d9…`   |        8문항 | 문장 삽입 6번의 정답·해설 위치 오류 확인. 빈칸 추론 5번은 원문 없이 출력될 때 문맥 보완 필요 |
| 학교 대화 듣기 `a097511d…`        |        3문항 | 대본 기준 목적·장소·가방 부탁의 정답과 해설 일치                                             |
| 주말 대화 듣기 `3e8bdaa9…`        |        3문항 | 대본 기준 선택한 버스의 시각·요금·선택 이유와 정답 일치                                      |
| 교내 방송 듣기 `5208fc63…`        |        3문항 | 대본 기준 방송 목적·준비물·장소 이유와 정답 일치                                             |

## 보완할 내용

- [ ] **문장 삽입 6번의 저장 정답과 해설 번호를 함께 보완한다.** `15fad5d9-c85d-4657-9524-9d40ed7808a6:2:5`는 현재 ③이지만, 문장 내용과 원문 순서가 지지하는 위치는 **②**다. AI의 한계를 설명한 뒤 의사가 결과를 검토한다는 인과관계가 이어져야 한다. 기존 해설도 이 순서를 설명하면서 번호는 뒤쪽의 ③으로 잘못 지목한다. [자동 대조의 EN-01](english.md)과 독립적인 텍스트 독해 결과가 같다.
- [ ] **AI 지문의 빈칸 추론 5번은 실제 출력 묶음에 충분한 맥락을 제공한다.** 저장 답 ④는 원문 결론과 일치한다. 그러나 문항 자체에 남은 영어 문장은 7토큰이며 해당 변형 묶음은 전체 원문을 싣지 않는다. 정답을 고를 근거를 본문에 제공한 뒤 다시 풀어 확인해야 한다. 원문 기준 정답 오류와는 구분한다.

EN-02의 다른 후보인 어법 4번은 짧더라도 복수 주어와 동사의 호응을 판단할 문장이 들어 있다. 이 텍스트 검토에서는 문맥 부족으로 확정하지 않았다. 40토큰 미달이라는 경고만으로 두 문항 모두를 잘못된 문제로 세지 않는다.

서술형 7·8번의 모범 답안은 공백 기준 각각 **25단어·24단어**로, 요구한 25~~35단어·20~~30단어 범위 안에 있다. 내용과 채점 기준도 요구한 이점·한계·사람의 역할 또는 학습 활동을 포함한다. 실제 학생 답안의 인정 범위까지 시험한 것은 아니다.

듣기는 대본·번역·발문·보기·정답·해설 사이에서 추가 내용 충돌을 발견하지 않았다. 실제 음원의 발화·성별·발음·누락·근거 시간 정렬은 청취하지 않았으므로 학생 사용 전 청취 검수 항목을 유지한다. [영어 전체 검사](english.md)의 음원 해시 검사는 가청 품질 검사와 별개다.
