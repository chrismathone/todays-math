## 항목별 수학과 남는 연결

아래 순위는 **검토 후 저작한다면** 제안하는 상대 순서다. 인접 코드 재사용 가능성과 독립 증명 부담을 기준으로 한 감사 판단이며 구현 승인·출제 빈도·실측 학생 난도를 뜻하지 않는다.

### 1. 회전수 백분율 — model.circle-revolution-percentage / 중1

- **필요 수학:** 고정 거리에서 원주가 `πd`, 회전수가 `L/(πd)`임을 연결한다. 지름 배율이 `q`이면 회전수 배율은 `1/q`, 원래 회전수 기준 증가율은 `100(1/q−1)%`다. 지름 감소율을 그대로 회전수 증가율로 쓰면 틀린다. 지정 자리 반올림까지 필요하다. [정의](../../../src/lib/examStudy/requirements.ts#L201), [추상 출처](../math-engine-study-readiness-20261018/source-profiles.json#L137).
- **기존 지원·결손:** [일차방정식 활용 30](../../../src/lib/middle/m1LinearApply.ts#L642)은 톱니 수×회전수 불변, [25](../../../src/lib/middle/m1LinearApply.ts#L580)·[31](../../../src/lib/middle/m1LinearApply.ts#L660)은 백분율·원래 양 역산을 다룬다. 원주 모델→역비례 배율→증가율 기준량→반올림의 한 과제는 없다. 이웃을 그대로 요청해도 대상 매핑으로 전달되지 않는다.
- **최소 저작·독립 증명:** 자체 지름 변화·거리·반올림 규칙을 명시한 유한 영역을 저술한다. 지름/반지름 혼동과 원래/새 회전수 기준 혼동을 구분하고, 유리수로 증가율을 재계산해 반올림 경계 양쪽·정확한 경계를 검사한다. `q>0`, 증가를 묻는 경우 `q<1`을 보장하고 `q=1`·증가가 아닌 입력의 처리도 고정한다. **구조 난점:** 기준량 전환과 역비례의 연쇄. **저작 부담 낮음~중간, 우선 1.**

### 2. 배증 시간차 — model.doubling-time-offset / 중1

- **필요 수학:** 같은 배증 주기 `τ`에서 초기 양의 비가 `2^k`이면 같은 목표에 도달하는 시각은 `kτ`만큼 차이 난다. 어느 쪽이 늦는지 정한 뒤 다른 시간 단위로 표현된 문자 시간에 더하거나 빼야 한다. 일반 선형 증감이나 단순 시간 환산으로 대체할 수 없다. [정의](../../../src/lib/examStudy/requirements.ts#L196), [추상 출처](../math-engine-study-readiness-20261018/source-profiles.json#L77).
- **기존 지원·결손:** [활용 01](../../../src/lib/middle/m1LinearApply.ts#L116)은 고정 배수의 일차식, [26](../../../src/lib/middle/m1LinearApply.ts#L593)은 분 단위 속률이다. [소인수분해 14](../../../src/lib/middle/m1Book1.ts#L320)는 거듭제곱의 지수를 찾지만 배증 횟수차→도달 시각차→단위가 다른 문자식은 생성하지 않는다. 14는 정적 검토만 했고 이번 48개 출력 표본에 포함하지 않았다.
- **최소 저작·독립 증명:** 양의 초기량·공통 주기·동일 목표·시간 원점·문자 시간의 허용 범위를 자작 발문에 고정한다. 중1에서는 로그 대신 반복 두 배 표/역산으로 횟수차를 얻는다. 독립 시간표를 만들어 목표 도달을 다시 대입하고, 초기비 방향 반전·`k=0`·음의 시각 배제·비가 2의 거듭제곱이 아닌 입력의 처리를 확인한다. **구조 난점:** 횟수와 시간의 구분, 시차 부호, 단위. **저작 부담 중간, 우선 2.**

### 3. 계수 재사용 — graph.translated-coefficient-reuse / 중2

- **필요 수학:** 이동 후 직선 복원→두 축절편→그 절편을 다른 직선의 계수로 지정→새 직선의 사분면 성질 판단이다. [정의](../../../src/lib/examStudy/requirements.ts#L119), [중2 추상 출처](../math-engine-study-readiness-20261018/source-profiles.json#L244).
- **기존 지원·결손:** [그래프⑴ 05](../../../src/lib/middle/m2Func.ts#L271)는 수직 이동량을 구한다. [그래프⑵ 02](../../../src/lib/middle/m2Line.ts#L453)는 **이미 다른 식에 계수의 부호를 재사용**한다. 따라서 “계수 재사용이 전혀 없다”는 결론도 틀리다. 다만 02의 수치 없는 부호 그림에는 이동·절편 복원 단계가 없고, 05와 따로 풀어서는 앞 결과가 다음 입력이 되는 과제가 성립하지 않는다.
- **최소 저작·독립 증명:** 자체 이동량·점/그림을 갖춘 직선에서 절편 `α, β`를 복원하고 명시된 새 식으로 넘기는 하나의 과제를 저술한다. 독립 검산은 `g(x)=f(x−h)+v`, 두 축 교점 대입, 새 직선의 사분면 조건을 따로 계산한다. 0 기울기·0 절편을 배제하거나 별도 처리하고, 이동 정보나 절편 재배치를 바꾸면 목표가 변하는 대조를 둔다. **구조 난점:** 표현 전환과 공유 값 의존. **저작 부담 중간, 우선 3.**

### 4. 절편·정수 조건·넓이 — coord.intercept-integer-area / 중2

- **필요 수학:** 직선의 절편을 구한 뒤 **음의 정수 격자 제약으로 가능한 점을 결정**하고 두 삼각형 넓이를 비교한다. 정수 좌표를 생성기가 미리 골라 주는 것과 학생이 제약으로 찾아야 하는 것은 다르다. [정의](../../../src/lib/examStudy/requirements.ts#L175), [추상 출처](../math-engine-study-readiness-20261018/source-profiles.json#L278).
- **기존 지원·결손:** [그래프⑴ 11](../../../src/lib/middle/m2Func.ts#L405)은 정수 절편을 생성하고 직선·두 축이 만드는 **한 삼각형** 넓이를 구한다. [중1 61W](../../../src/lib/middle/m1Top4.ts#L306)는 반비례의 양의 정수 격자점을 열거한다. 어느 쪽도 대상 직선의 음의 정수 점 결정→두 넓이 비교를 완성하지 않는다. 중1 61W는 과정과 곡선도 다르다.
- **최소 저작·독립 증명:** 자체 직선·부호/정수 조건·비교할 두 삼각형을 명시한다. 허용 정수점의 범위가 왜 유한한지 또는 어떤 추가 제한이 필요한지 증명하고 후보 전부를 열거해 점/목표의 유일성을 확인한다. 두 넓이는 절댓값을 포함한 좌표 행렬식으로 별도 재계산한다. 0개·복수 후보·축 위·공선 퇴화와 격자 조건 제거 대조를 확인한다. **구조 난점:** 정수 실행 가능성과 기하량의 의존. **저작 부담 중간~높음, 우선 4.**

### 5. 계수 재사용 — graph.translated-coefficient-reuse / 중3

- **필요 수학:** 첫 포물선의 꼭짓점·점/절편 등에서 계수를 복원하고, 그 계수를 **다른 위치에 배치한 이차함수**의 축·꼭짓점·절편 등 지정 성질을 구한다. 중2 직선과 요구 ID만 같고 수학 과제는 같지 않다. [중3 추상 재분류](../math-engine-study-readiness-20261018/study-structures.json#L1582).
- **기존 지원·결손:** [그래프⑵ 10](../../../src/lib/middle/m3Func.ts#L1777)은 꼭짓점·한 점으로 일반형 복원, [07](../../../src/lib/middle/m3Func.ts#L1623)은 이동·전개 후 계수 결합값까지 제공한다. 새 [parabola-line-chain](../../../src/lib/examStudy/families/advanced/graph.ts#L367)도 복원 계수를 **직선 기울기**에 재사용한다. 그러나 계수 재배치 후 둘째 **이차함수**를 판단하지는 않는다. `a+b−c` 같은 표적값이나 다른 교점을 구하는 것으로 이 결손을 덮을 수 없다.
- **최소 저작·독립 증명:** 계수 위치의 대응을 발문에서 명시하고, 독립 전개로 첫 `(A,B,C)`와 둘째 `(A′,B′,C′)`를 재구성한다. `A′≠0`, 축·꼭짓점 대입과 지정 절편을 확인하며, x절편을 목표로 삼으면 실근 분기도 검사한다. 서로 같은 계수 때문에 재배치가 무의미해지는 표본을 피하고 각 단계의 필요성을 대조한다. 그림을 사용하면 주어진 좌표와 곡선이 실제 일치해야 한다. **구조 난점:** 계수의 역할 전환과 두 함수의 연쇄. **저작 부담 중간~높음, 우선 5.**

### 6. 서로소 잔여류의 문자 합 — number.coprime-symbolic-sum / 중1

- **필요 수학:** 고정 합성수 분모 `D`와 정수 경계 사이에서 기약인 분수를 **빠짐없이** 골라 문자 경계의 합을 일반화한다. `a=Dk+r`, `1≤r<D`, `gcd(r,D)=1`로 완전 잔여류를 나누고 주어진 합 공식을 적용해야 한다. [정의](../../../src/lib/examStudy/requirements.ts#L206), [추상 출처](../math-engine-study-readiness-20261018/source-profiles.json#L150).
- **기존 지원·결손:** [32T](../../../src/lib/middle/m1Top.ts#L272)는 곱이 고정인 서로소 인수쌍을 모두 찾고 합산한다. [61W](../../../src/lib/middle/m1Top4.ts#L306)는 약수 합이다. 인수쌍·약수 집합은 고정 분모의 기약 잔여류와 다르며, 둘 다 문자 구간 전체 합을 생성하지 않는다. 답을 합/개수로 바꾸는 정도의 확장이 아니다.
- **최소 저작·독립 증명:** 자작 합성수 분모와 문자 경계의 정수 범위, 사용할 합 항등식을 제공한다. 각 분자를 유일한 `Dk+r`로 표현함을 보이고, 서로소 잔여류 목록과 `r↔D−r` 짝짓기의 합을 증명한다. 독립 검산은 여러 경계 대입에서 분자 전수를 gcd로 직접 거르는 방법과 문자식을 대조한다. 소수 거듭제곱/여러 소인수, 구간 길이 1, 잘못된 경계·분모를 검사한다. 중1 답안에 설명 없이 고등 정리를 전제하지 않는다. **구조 난점:** 완전성·일반화. **저작 부담 높음, 우선 6.**

### 7. 근호·역함수·외접원 — function.radical-inverse-circle / 공통수학2

- **필요 수학:** 근호함수와 역함수 각각의 입사·정의역, 사선 조건, 삼각형과 외접원 제약을 함께 풀어 직선 매개변수를 결정한다. 대칭인 두 그래프 위 점이라고 해서 자동으로 서로의 좌표를 맞바꾼 한 쌍은 아니다. 비퇴화 삼각형은 원래 외접원이 있으므로 **외접원의 존재만으로 추가 제약을 줬다고 할 수도 없다.** [정의](../../../src/lib/examStudy/requirements.ts#L302), [추상 출처](../math-engine-study-readiness-20261018/source-profiles.json#L414).
- **기존 지원·결손:** [radical-triangle-area](../../../src/lib/examStudy/families/advanced/continuous.ts#L227)는 근호곡선·넓이 최댓값, [finite-bijection-chain](../../../src/lib/examStudy/families/advanced/finite.ts#L103)은 **유한 집합** 역함수다. [two-centers-angle](../../../src/lib/examStudy/families/advanced/geometry.ts#L451)은 중2 중심각 기하다. 세 단어가 나뉘어 존재해도 연속 역함수·사선·외접원 조건의 결합이나 해의 유일성을 보이지 않는다.
- **최소 저작·독립 증명:** 자체 근호함수의 단사 구간·역함수 정의역, 점의 역할, 사선, 비자명한 외접원 조건과 목표를 명시해야 한다. 대칭 반사와 입사식을 별도로 세우고, 제곱 전 부호·정의역을 보존하며 모든 후보를 원식에 재대입한다. 다른 방식의 원 방정식/좌표 행렬식으로 원 조건을 검산하고 중복점·공선·접선·무해·복수해를 확인한다. 역함수 또는 원 조건을 제거하면 목표가 달라지거나 미결정이어야 한다. **구조 난점:** 연속함수의 가지·기하·유일성. **저작 부담 가장 높음, 우선 7.**

공통적으로 향후 `full`에는 [실행 증거 요건](../../../src/lib/examStudy/evidence.ts#L14)에 맞는 독립 해법·필수 조건 검사가 필요하다. 자작 유한 영역의 경계와 오답/조건 삭제 대조를 검증하고, 실제 그림을 넣는 버전은 렌더까지 확인해야 한다. 위 목록은 필요한 검수 설계이며 이번에 구현·증명을 완료했다는 뜻이 아니다. 같은 수학의 객관식/단답형 쌍, seed, 보기 순서, 합/번호 표적을 새 가족으로 세지 않으며, 이번 결과만으로 반드시 새 가족 6개 또는 7개를 만들어야 한다고 결론내리지 않는다.

## 학교 간 재사용과 출처 범위

[프로필](../../../src/lib/examStudy/profiles.ts)은 학교명·과정·선택 요구를 묶는다. 가족은 학교 전용 소유물이 아니므로 같은 과정·동일 요구·지원 형식이면 다른 학교의 일반 연습에도 재사용할 수 있다. 그러나 [프로필 밖 요구와 다른 과정 가족은 거절](../../../src/lib/examStudy/generate.ts#L81)되며, 중2 직선 가족을 중3 포물선 요구의 증거로 이월할 수 없다. 일반 유형을 명시하면 학교명은 [수학 seed에서 제외](../../../src/lib/examStudy/generate.ts#L232)된다. 학교명만 바꾸거나 같은 태그를 붙인 것으로 새 학교 검토·학교 전체 준비가 성립하지 않는다.

- 대륜중 중1은 2025년 1학기 기말 표시 22개 중 노출 19개에서 고른 11요구다. 3개 비노출을 보존한다. 이번 대상은 그중 세 요구다.
- 대륜중 중2는 2025년 1학기 기말 18/18 열람에서 고른 추상 묶음이다. 원 감사의 9묶음 중 마지막 카드가 별개 소문항 둘이어서 현재 프로필은 10요구다. 이번 대상은 두 요구다.
- 경명여중 중3은 이전 22/22 표시 자료의 선택 범위로 현재 4요구, 미확정 1개를 보존한다. 이번 대상은 그중 계수 재사용 하나다. `source-profiles.json`의 신규 프로필 목록이 아니라 `study-structures.json`의 `prior-middle3-focused5`와 현재 프로필이 근거다.
- 경신고 공통수학2는 2025년 2학기 기말 20/20 열람에서 고른 8요구 중 하나다. 원자료의 정답 불일치 경고 3건·미분류 난도는 정답 gold나 난도 교정으로 쓰지 않는다. 경고를 이번 특정 요구에 임의 배정하지 않는다.

범위 근거: [원 감사 메타데이터](../math-engine-study-readiness-20261018/source-profiles.json), [구조 감사](../math-engine-study-readiness-20261018/study-structures.md), [1차 통합 결과](../math-exam-engine-upgrade-20261018/README.md), [프로필 집계 설명](../math-exam-engine-upgrade-20261018/core-implementation.md#L24). 의도적으로 고른 추상 요구이며 무작위 표본·학교 전범위·공식 교육과정 전수 정합성·보정 난도·학습 효과의 증거가 아니다. 이번에는 원사이트를 다시 열지 않았고 원문·원수치·원그림을 복사하거나 저장하지 않았다.
