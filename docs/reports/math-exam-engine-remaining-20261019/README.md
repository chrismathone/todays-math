검사한 다섯 학교·학년 프로필의 잔여 요구는 **학교·학년별 13건, 중복 제거 12개**다. `graph.translated-coefficient-reuse`가 대륜중 중2와 경명여중 중3에 각각 쓰인다. 여섯 고유 요구는 현재 기출 대비 경로에 연결된 생성 문형이 없고, 나머지 여섯은 기존 연습을 생성하지만 완결 대응의 검증을 갖추지 못했다.

문항 수를 늘려도 빠진 수학적 요구가 채워지지는 않는다. 특히 현재 연결된 ‘후보 해 검산’은 일반 방정식 풀기이고, ‘직사각형 변화’는 고정된 길이 차와 넓이 문제다. 이 항목에는 필요한 사고 단계의 저술도 필요하다. 기존 문항의 독립 검증과 새 복합 유형의 저술을 구분해야 한다.

## 기존 연습이 있는 여섯 요구

각 요구에는 하나의 기존 문형이 연결되어 있으며 모두 `component` 의도로 등록되어 있다. 해당 요구를 검사한 실행 증거가 없어 현재 표시값은 `unverified`다. 검증 표지만 추가해서 `full`로 올릴 수 없다.

| 요구 | 실제 생성 내용 | 보완 판단 |
| --- | --- | --- |
| 후보 해 검산 | 소수 계수 일차방정식 한 개 풀기 | 식마다 다른 후보를 대입하고 성립 여부를 판단하는 과제 필요 |
| 등식 진술 | `a=b`에서 다섯 변형의 참 개수 | 비단위 배수 관계 등 선택 원자료의 조건 범위를 확인하고 진술별 항등성 검증 필요 |
| 방정식 분류 | 정리 후 일차방정식인 식의 개수 | 기존 분류 원리를 독립 검증할 대상. 개수·번호 출력 차이만으로 새 유형을 세지 않음 |
| 문장 모델 | 말로 주어진 두 선형 관계를 식으로 세워 풀이 | 원상황 대입 검산을 풀이에 추가하고 문장→식→해·검산을 독립 검증할 필요 |
| 일차식 정리·계수 | 괄호 전개와 동류항 정리 | 정리 결과의 계수·상수항을 읽고 결합하는 단계 필요 |
| 직사각형 변화·정의역 | 고정된 길이 차·넓이에서 두 해와 양의 길이 설명 | 한 변 증가·다른 변 감소의 시간 모델, 초기 시점과 양의 회복 시점 구별 필요 |

중1의 다섯 문형은 객관식·단답형으로 각각 한 문항을 생성했지만, 본래 서술형은 지원하지 않는다. 직사각형 문형은 본래 서술형·채점 기준이 있으며 객관식·단답형은 지원하지 않는다. 형식 선택이나 seed 차이는 새 사고 유형 수에 합산하지 않는다. 다중 표본의 수학 검산과 최소 승격 조건은 [기존 연습 검수](unverified-audit.md)에 기록한다.

객관식 보기의 품질도 보완 대상이다. 이번 실제 API의 방정식 분류 표본은 식 다섯 개 중 해당하는 개수를 묻는데 오답에 `6개`를 제시했다. 정답 자체의 오류와는 구별하지만, 가능한 개수 범위를 벗어난 보기는 생각 없이 지울 수 있어 오답 설계의 질을 낮춘다. 독립 정답 검산 외에 답의 범위·보기의 타당성을 검사해야 한다.

## 보강 우선순위

1. **기존 핵심 연습 검증:** 방정식 분류의 독립 검산·경계 사례, 문장 모델의 원상황 검산 풀이, 개수형 객관식의 가능한 범위 안 오답을 먼저 보완한다.
2. **빠진 사고 단계 연결:** 일차식 정리→계수 해석, 비단위 등식 진술, 식마다 다른 후보 대입, 직사각형의 반대 방향 변화→양의 회복 시점·길이 정의역을 실제 문항·풀이·서술 기준에 담는다.
3. **미지원 복합 요구 저술:** 회전수 백분율·배증 시간차와 그래프 계수 재배치부터, 정수 격자·넓이와 서로소 문자 합, 근호·역함수·외접원의 결합으로 범위를 넓힌다. 중2 직선과 중3 포물선의 계수 재배치는 공유 요구 ID를 쓰더라도 각각의 과정을 검증해야 한다.

우선순위는 기존 코드 재사용과 빠진 사고 단계·검증 부담을 고려한 판단이다. 실제 출제 빈도나 보정 난도에 근거한 순위는 아니다. 새 가족 수는 동일 과제의 형식·seed 변형으로 늘리지 않는다.
