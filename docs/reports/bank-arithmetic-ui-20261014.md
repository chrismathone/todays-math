# 문제은행 P0·연산대장 화면 통합 검증

2026-10-14 · 승인된 Wire A / Hi-fi 1 · 로컬 main 통합. 운영 배포·DB 변경·결제 없음.

## 구현 결과

- 문제은행의 출처/책/자료 조건을 범위 수량·목록·구성에 동일하게 전달한다. 0문항은 선택에서 제외하고 수량 미확인은 0으로 위장하지 않는다. 전체 보유와 현재 출제 가능한 수를 구분한다.
- 교과서 자료 선택기는 책·자료명·단원 검색, 20행 페이지, 보유/출제 가능 수, 기록되지 않은 단원·회차를 표시한다. 자료 안 번호를 포함한 출처 설명을 문항 코드와 함께 보존한다. 지정 복습 슬롯 0/2·1/2·2/2, 같은 학습지에서 원문과 변형을 고른 경우의 재노출 경고, 출력 직전 자격 재확인을 연결했다.
- 연산대장: 자연수 7개 스킬군의 97개 프리셋, 검색·종류별 필터·12개 카드 페이지, 같은 스킬의 서로 다른 조건 동시 선택, 정확한 생성 가능 수, 회차·총량 제한, 생성·다시 만들기, 제목·저장·재열기, 문제지만/정답지만/둘 다 출력이다. 답은 내부 검산하고 해설은 만들거나 출력하지 않는다.
- 새 시드를 써도 모든 숫자가 항상 바뀌지는 않는다. 작은 도메인의 모든 식을 선택하면 순서만 달라질 수 있고 단일 식은 동일하다. 회차 안 중복을 막으며 회차 사이에는 재등장할 수 있다. 웹 UI와 API가 외부 유료 생성 API를 부르지 않는다.
- `내 시험지`와 관리자 미리보기가 새 자료 종류를 읽는다. 저장은 식·답 스냅샷을 보존하며 재열 때 재생성하지 않는다. 저장 전 문서를 바꾸거나 창을 닫을 때 이탈 보호를 적용한다.
- 개인 순위 라벨을 실제 기록으로 붙였다. 문항은 같은 차시 안의 `내 출제`, 유형은 같은 연산 기호의 `내 학습지 사용`이다. 최근 30일·기준 시각·횟수·보유 기록 한계를 툴팁에 표시한다. 5개 이상 기록과 최소 2개 후보가 있을 때 상위 10위·공동 순위를 표시한다. 미리보기/새로고침은 쓰기를 하지 않는다. 화면에 보이는 문항을 최대 100개씩 묶어 읽고, 이전 선택의 늦은 응답을 버린다.
- 제품 표시명은 브랜드 작업을 병합하고 통합 화면의 남은 문자열도 `오늘 수학/오늘 영어`로 바꿨다. 독립 기능명 `오늘의 기억`은 유지한다.

## 운영 전환 순서

저장 쓰기는 `ARITHMETIC_SHEET_WRITE=on`일 때만 열린다. 현재 작업에서는 `20261014190000_workspace_document_arithmetic_sheet` migration을 운영 DB에 적용하지 않았고 flag도 변경하지 않았다.

1. WorkspaceDocument 종류 CHECK 확장을 적용한다.
2. 새 자료 종류를 읽는 서버·보관함·관리자·출력 코드의 배포를 확인한다.
3. 쓰기 gate를 열고 실계정 생성→저장→재열기→정답/PDF를 확인한다. 첫 저장 후 구버전 reader로 돌리지 않는다.

이 보고서는 구현·로컬 검증 결과다. 초3~중3 전체 지원은 아니며 [학년별 공백과 확장 제안](../planning/arithmetic-grade-coverage-20261014.md)을 별도로 유지한다. 기출 적재, 수업 배부·채점 개선 P2, 분수·소수·음수·문자식·근호 생성은 이번 통합의 완료 주장에 포함하지 않는다.
