dimensions use the editor's outside operation. Interior diagonals and heights
may use the editor's supported opposite side when necessary.

target wording, including 밑면 반지름 and 밑면 지름.

Editor and immutable-source contract
The offline adapters call the public addDimension operation. Where its default
layout collides, they record and replay addFigureObject(curve), moveFigureHandle,
addMidLabel and editFigureObject using actual path samples. Actual typesetFigureSvg
supplies the gap masks and attachments. There is no alternative Q constructor,
projected measurement lane, synthetic witness line or hand-edited mask.
Glyph and white-halo coverage are checked against full source stroke width.
Protected polygon/circle boundaries, equality ticks and right-angle marks must
remain visible. Open paths are checked for computed fill=none.
Canonical IDs, source SVG bytes, numerical givens, targets, answers and saved packs
are unchanged. The display adapters require a full canonical source-string match.
Runtime adapters use bounded per-family caches and require no editor, DOM, Python
or MathJax runtime. The shared typography adapter supplies the existing editor font.
