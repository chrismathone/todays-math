Shared integration and fixes
Definitions register through extraGeometry.ts. SVG maps remain separate lazy
enumerable getter records: no eager spreading or rendering all 17,471 assets.
Each new sheet freezes only used, trusted SVGs in a version-2 subset pack;
canonical IDs, exact content, bounded cache and compressed-string checks apply.
Legacy version-1 angle snapshots retain exact bytes and remain reopenable.
Physical units and count units are explicit; unitless ratios use an explicit
empty answerUnit. Text-only geometry still displays its complete visible givens.
Elementary decimal answers are exact; middle-school pi and square roots remain
symbolic. Surds use [coefficient, radicand, denominator]; pi polynomials use
[constant numerator, constant denominator, pi numerator, pi denominator].
Changed elementary answer LaTeX from Unicode superscripts inside text to proper
math superscripts, preventing KaTeX missing-glyph warnings for area and volume.
