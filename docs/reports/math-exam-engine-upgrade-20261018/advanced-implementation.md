Every family supplies the frozen `ExamStudyDraft` shape, stable mathematical parameters, typed requirement mapping, executable evidence and an independent `verify` callback. `full` is an intended maximum; the integrating planner must still check evidence, the callback and strict rendering before delivering that level. A corrupted answer and a deleted essential printed constraint fail verification. Wrong figure coordinates/curves, omitted essential labels, changed center order, missing extensions, non-white excluded disk, and invalid written criteria are negative controls. Numeric families provide short answers; only the quadratic coefficient characterization is declared written.

The new generators import no legacy registry, SRS, bank loader, predictor, database, provider or framework module. Legacy registries and their counts were not changed. The input evidence was the abstract profiles, source-comparison, study-structures/prior27 reclassification, plan and Claude review. No source exam wording, coefficients or figures were read, downloaded or stored.
