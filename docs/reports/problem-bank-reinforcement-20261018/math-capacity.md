# 수학 문제 수 충분성 점검

**초3부터 중3까지 기본 8~10문항 출제에는 재고가 있다. 고등 반복 출제, 초등 단일 차시 20문항, 서술형까지 충분하다고 보기는 어렵다.** 2026년 10월 18일 공유 DB에서 출제 가능한 115,383건을 전수 계산했다. 단순 등록량과 다른 기준으로 충분성을 판단해야 한다.

현재 일반 출제 메뉴가 지원하는 범위는 **초3~중3의 360차시**이며, 모두 기본 8문항을 구성할 수 있다. 초1·초2와 고등은 이 기본 지원 범위와 구분한 확장 재고 점검이다. 반에서 선택할 수 있는 1~30문항 전체, 특정 난이도·형식과 반복 출제를 모두 충족한다는 뜻은 아니다. [제품 규칙과 지원 분모](capacity-policy.md)

## 반복 출제할 여유

**같은 차시에서 8문항씩 5회**, 매번 다른 발문을 내는 조건으로 계산했다. 한 장에 같은 문항류는 하나만 쓰고, 전체 5회 동안 같은 발문·그림을 다시 쓰지 않는 조건이다. 실제 계정의 사용 이력을 예측한 수치는 아니다.

| 범위            | 5회 모두 구성 가능한 차시 | 해석                               |
| --------------- | ------------------------: | ---------------------------------- |
| 초3~초6         |                   226/230 | 초4의 4차시는 고유 변형 보강 필요  |
| 중1~중3         |                   130/130 | 이 반복 시나리오에는 재고 있음     |
| 고등 재고 6과목 |                    52/216 | 대부분 지속적인 반복 출제에는 부족 |

초4 보강 후보는 `정삼각형의 성질`, `삼각형을 두 가지 기준으로 분류하기`, `평행과 평행선`, `사다리꼴`이다. 현재 조건에서 5회에 배정할 수 있는 고유 발문은 각각 36·36·38·32개로, 필요한 40개에 못 미친다. 단순 전체 행 수가 아니라 문항류별로 회차를 배정한 상한이다.

15회 조건에서는 초3부터 초6은 174/230차시, 중1부터 중3은 123/130차시만 8문항을 모두 다른 발문으로 채운다. 10문항씩 15회는 초3부터 초6에서 0/230차시다. 이를 모든 수업이 동일 차시를 15회 반복한다는 요구로 해석하지 않는다.

제품의 최근 중복 제외는 **계정의 최근 14일 시험에 실린 problemId**를 대상으로 한다. 같은 계정의 반·학생을 가로지르고 날짜 양 끝을 포함하므로 매일 출제하면 15개 날짜가 될 수 있다. 실제 조회한 2026년 10월 4~18일의 시험은 **0개**였다. 따라서 현재 재고에서 최근 사용 때문에 줄어든 수는 없지만, 실사용에서 얼마나 빨리 소진되는지는 확인할 이력이 없다. [최근 사용 조회](recent-capacity.json)

## 난이도와 형식

문항 수를 채우는 것과 요청한 난이도대로 채우는 것은 다르다. 기본 8문항의 배분은 연산 1·기본 3·응용 3·심화하 1이며, 자동 출제는 부족한 난이도를 이웃 난이도에서 대체한다. 위 표의 구성 가능 수는 이 대체를 허용한다.

- 초3~초6은 230/230차시에서 기본 난이도 배분을 그대로 채운다.
- 중1~중3은 130차시 중 **66차시**에서만 기본 난이도 배분을 대체 없이 채운다. 특히 중3은 2/22차시다. 나머지를 문항 수 부족과 혼동하지 말고 난이도 대체를 확인해야 한다.
- 현재 서술형으로 분류되는 문항은 전체 **265건**이다. 초3~초6·중3·기하·확률과 통계는 0건이다. 단답형을 많이 보유한 것만으로 서술형 평가 재고가 충분하다고 할 수 없다.
- 같은 유형 안에서 난이도와 형식의 선택 가능 여부가 달라진다. 차시·난이도·형식별 수를 서로 더해 특정 구성의 충족을 보증하지 않는다. 기본 8문항 배분을 모든 고등 과목에 필수로 강제해야 한다는 뜻도 아니다.

## 보강 순서

1. **현재 지원 범위에서는 중3의 유형 다양성과 서술형을 보강한다.** 중3 22차시 중 18차시가 서로 다른 문항류 20개를 채우지 못한다. 전체 중등의 단일 차시 20문항 목표 부족분은 문항류 자리 167개다. 20문항이 필요한 사용 장면에서 우선하며, 서술형은 풀이 기준까지 함께 갖춘다.
2. **초4의 고유 변형 4개 차시를 보강한다.** 그 밖의 초등은 기본 일일 분량에 여유가 있다. 초등 단일 차시 20문항이 꼭 필요하면 230차시에 문항류 자리 2,132개가 더 필요하다. 실제로는 인접 두 차시 이상을 합쳐 20문항을 구성하는 선택도 가능하다.
3. **고등을 확장할 때는 8문항 미달 54차시부터 보강한다.** 현재 재고 6과목 전체를 단일 차시 8문항까지 올리는 데 필요한 문항류 자리의 부족분은 최소 236개다. 기존 유형에 숫자만 바꾼 행을 추가하면 유형 부족은 해결되지 않는다. 교육과정 밖 또는 아직 서비스하지 않을 범위는 먼저 구분한다.
4. **교과서 복습 쌍을 별도 재고로 늘린다.** 지정 변형이 없는 교과서 원문 9,647개는 실제 사용하는 범위부터 검산된 쌍을 공급한다. 이 부족은 일반 문제 행 수를 늘리는 것으로 대체되지 않는다.

## 재현과 범위

`npx tsx --env-file=<환경파일> scripts/qa/bank/math-capacity-census.ts --out <출력폴더>`로 재현한다. 트랜잭션 첫 문장은 `SET TRANSACTION READ ONLY`, 격리 수준은 `RepeatableRead`다. [전수 용량 원장](math-capacity.json)에 735개 차시의 행·고유 발문·문항류·난이도·형식·회차별 수와 가정을 남겼다. 원문과 학생 기록은 저장하지 않았다.

고유 발문 기준은 공백을 정리한 파서의 발문과 정확히 같은 SVG·그림 URL 배열이다. 표현이 다른 동치 문제까지 제거한 의미상 중복 검사는 아니다. 반복 용량은 고유 발문당 1, 문항류당 회차 수를 상한으로 둔 최대 흐름으로 계산했다. 하나의 기본 시험지는 실제 `balanceDifficulty`도 실행해 대체 수와 충족 수를 별도로 기록했다. 실제 인쇄·학생 학습 효과·문항의 전수 수학 검산을 수행한 결과는 아니다.
