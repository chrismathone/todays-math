# 수학 재고 점검과 확정 오류 보강

**현재 일반 출제 범위인 초3~~중3은 360차시 모두 기본 8~~10문항을 구성할 재고가 있다. 반복 출제, 단일 차시 20문항, 서술형과 고등 확장 재고는 부족한 곳이 있다.** 출제 가능한 저장 행 115,383건을 차시·문항류·발문 중복·난이도·형식별로 전수 계산했다.

| 범위            | 출제 가능 행 | 기본 8문항       | 보강할 부분                                                              |
| --------------- | -----------: | ---------------- | ------------------------------------------------------------------------ |
| 초3~초6         |       54,031 | 230/230차시 가능 | 초4의 4차시는 고유 발문 8문항×5회에 미달. 단일 차시 20문항은 문항류 부족 |
| 중1~중3         |       54,834 | 130/130차시 가능 | 중3은 22차시 중 18차시가 서로 다른 문항류 20개에 미달                    |
| 고등 재고 6과목 |        6,518 | 162/216차시 가능 | 54차시가 8문항 미달. 현재 일반 출제 지원 범위와 구분한 확장 점검         |

한 장에 같은 문항류를 하나만 쓰고, 최근 사용 제외가 없는 조건이다. 현재 조회한 14일 창의 시험 이력은 0건이어서 실제 운영에서 재고가 소진되는 속도는 확인하지 못했다. 난이도 부족 시 제품의 대체 규칙을 허용했으며, 정확한 난이도·형식 조합까지 충족한다는 뜻은 아니다. 서술형으로 분류되는 재고는 265건이다.

[수량 판단과 차시별 보강 순서](math-capacity.md), [제품 규칙과 지원 범위](capacity-policy.md), [고등 8문항 미달 54차시](priority-units.json), [전체 용량 원장](math-capacity.json)에 조건과 분모를 남겼다. 새 문항을 일괄 생성하거나 적재하지 않았다. 문항류 부족은 기존 유형에 숫자 변형만 추가하는 것으로 해결되지 않는다.

## 이번에 반영한 오류 수정

- **해설 생성기 3유형:** `\timesx`, `\timest`, `\pmi`가 생기지 않도록 TeX 명령 뒤 경계를 보완했다. 900판의 실제 두 렌더 경로에서 오류가 사라지고 본문·정답·선지·난수 순서는 같았다. [생성기 보강](engine.md)
- **증명 파싱 2문항:** 증명 속 번호를 본문에 보존하고 실제 선택지 5개를 분리했다. 현재 DB 117,828행을 이전 파서와 전수 비교해 이 두 행에서만 결과가 바뀜을 확인했다. [파서 보강](parser.md), [전수 비교](parser-scan.json)
- **저장 해설 12건:** DB에서 `solution`의 수식 명령 뒤에 공백만 넣었다. ID·본문·정답·출처·검수 상태·그림 등 나머지 필드는 동일하며 `updatedAt`만 함께 갱신됐다. 원본 해설과 수정본을 로컬 원장에 먼저 보관하고, 원래 해설·갱신 시각을 조건으로 12건을 한 트랜잭션에서 수정했다. 커밋 후 재조회와 두 렌더 경로도 통과했다. [적용 메타데이터](solution-repair.json)

병합된 코드에서 관련 **21파일 870검사**, TypeScript 전체 검사, 소유 코드 ESLint를 통과했다. 수량은 파서 수정과 저장 해설 교정 후 다시 측정했으며 행·문항류·반복 용량의 결론은 같았다. [최종 검증 원장](root-checks.json)

## 남은 보강 범위

현재 지원 범위에서는 중3 유형 다양성, 초4의 반복 여유가 작은 4차시, 서술형을 먼저 늘릴 필요가 있다. 고등을 확장할 때는 8문항 미달 54차시부터 공급을 갖춘다. 교과서 지정 복습 쌍이 없는 원문 9,647개도 실제 사용하는 범위부터 검산된 쌍을 공급해야 한다.

[기존 감사 체크리스트](../problem-bank-audit-20261018/README.md)의 출력 직전 재검증, 원문 변경과 지정 변형의 상태 전이, 담기 동시 소비, 영어 내용 교정은 이번 수학 수량 점검·표시 오류 수정에 포함하지 않았다. 각 미완료 체크박스는 유지했다.

문항 수와 렌더·파싱 대응에 관한 점검이며, 모든 수학 문제의 독립 풀이·공식 성취기준 전체 대응·학습 효과를 인증한 결과는 아니다. 공유 DB의 해설 12건을 교정했으며 배포·학생 기록 변경은 하지 않았다.
