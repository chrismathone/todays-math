## 유형이 실제보다 많아 보이는 원인

현재 출제 가능한 제품 문항류는 **15,878개**다. 그중 **4,042개·99,376행**은 엔진 문항류, 나머지 **11,836개·16,199행**은 `solo:`로 시작하는 원문별 묶음이다. 원문이 따로 있다는 이유만으로 다른 풀이 유형이 되는 것은 아니다.

전체 보유 문항류 **16,367개**와 현재 생성 등록 목록을 모두 조사했다. 본문·정답·해설·그림·보기 그림 연결까지 정확히 같은 문항이 서로 다른 문항류에 있는 **735묶음**, 이를 공유하는 **452문항류 쌍**을 찾았다. 그중 양쪽 모두 출제 가능하고 같은 차시인 쌍은 **430쌍**이다. 하나의 문항류가 여러 묶음에 반복 등장할 수 있으므로 이 수를 유형 수에서 그대로 빼지 않는다.

수작업으로 재검토한 것은 **51쌍·93문항·91문항류**다. 같은 풀이 **27쌍**, 유지할 차이가 있는 **22쌍**, 판단 보류 **2쌍**으로 정리했다. 이 결과를 전체 후보의 수동 검수 완료나 전역 ‘진짜 유형 수’로 확대하지 않았다.

유사성만으로 합치면 안 되는 사례도 확인했다. 같은 ‘각을 구하라’ 발문에 다각형 내외각, 이등변삼각형, RHS 합동의 다른 조건이 들어 있었다. 각 행의 실제 단원을 다시 대조한 결과 이 문항들의 단원 연결은 맞았고, 통합 대상에서 제외했다. 보기 자체가 조건인 판단형, 무리식 유리화 후 분배가 추가되는 유형, 정답만 쓰는 문제와 오류를 설명하는 서술형도 구분한다.

후속 정리는 **상위 풀이 유형 + 하위 표현/위치/자료 태그 + 출처 묶음**을 나누는 방식이 적절하다. 기존 ID·코드를 유지하고, 통합 후 출제 중복 제한과 가용량을 함께 다시 계산해야 한다. 이번에는 유형을 실제로 병합하지 않았다.

## 유형별로 충분한 수량인가

초3~~중3 **360차시 모두** 실제 기본 난이도 배분에서 8~~10문항을 구성한다. 내용 반복을 제외한 **8문항×5회 재고 용량**도 모두 충족한다. 다만 이는 최근 사용 이력·형식/난이도 할당을 완화한 재고 계산이며 실제 5회 출제 성공을 보장하지 않는다. 20문항 비교에서는 **107/360차시**만 채운다. 20문항은 제품의 기본 요구량이 아니다.

‘유형마다 새 문제 5개’를 비교 기준으로 보면 다음과 같다. 이 5개를 새 운영 정책이나 공식 최소량으로 정한 것은 아니다.

- 처음 발문/그림 기준으로 적게 잡힌 **149문항류** 중 **23개는 보기에 들어 있는 조건을 빠뜨린 오탐**이었다.
- **53문항류**는 생성 관측에서는 5개 이상이 나오지만 저장본은 5개 미만이다. 문형당 5개를 목표로 채우려면 최소 **96개**의 추가 내용이 필요하다. 이는 승인된 적재 계획이 아니다.
- 초등 **53문항류**는 실제 소스가 1~4개 발문·그림만 내는 고정 성질/좁은 영역이다. 복제 적재보다 적용 방향을 넓혀야 한다. 중등도 작은 영역 후보 6개를 별도로 기록했다.
- 다른 브랜치의 별도 초등 보강 **14문항류·42행**은 저장본과 감사 기준 소스의 차이를 기록했다. 현재 저장은 각 3개이며 승인된 이전 보강 108행과 다르다.
- 서술형 재고가 있는 지원 차시는 **84/360**, 합계 **226행**이다. 서술형을 요구하는 구성은 총 문항 수와 별도로 보강할 필요가 있다.

각 문항류의 행 수·다른 발문 수·난이도·형식·최소 해설 길이·출처를 [CSV](type-inventory.csv)에 모두 남겼다. 보기 제외 발문 수와 서로 다른 수학 과제 수는 같지 않으며, 숫자/형식 변형 수를 상위 풀이 유형 수로 세지 않는다.

## 기출·교과서와 비교해서 무엇을 확인했는가

은행의 ‘엔진’은 결정적 생성기를 포함한 `manual` 출처다. 중등은 RPM의 **873개 유형 색인**을 기반으로 확장했지만, 색인 제목 일치가 기출 원문의 모든 사고·난도 재현을 보장하지는 않는다. 실제 기출 **101행은 모두 출제 잠금**이고, 보존 그림을 열어 다시 푼 기출 표본은 3개다. 현 복원·외부 수선 같은 응용이 엔진에도 구현된 점과, 여러 조건을 합성하는 기출 수준 전체를 검증하지 못한 점을 함께 기록했다.

교과서 쪽은 **원문 12,301개·연결 변형 4,437개·35권·1,992자료**를 전수 집계했다. 현재 메타데이터에는 초등·중3 교과서가 없으며, 실제 출판 PDF/정답책을 전부 열어 대조한 검수도 아니다. 같은 차시의 원문/저장 엔진 7쌍과 공통수학1 새 생성 참조 4쌍에서 실제 목표·풀이를 비교했다. 같은 차시라도 식 세우기와 해의 확인, 합동 충분조건과 대응각 찾기는 서로 대체되지 않는다.

지정 복습 변형은 출제 가능한 원문 **11,826개 중 2,179개**에 두 개씩 준비되어 있다. **9,647개는 아직 지정 두 변형이 없다.** 현재 인식 가능한 893쌍·1,786변형은 저장 내용의 대응을 다시 확인하고 별도 SymPy 계산에서도 답 불일치 0이었다. 다른 준비된 1,286쌍은 이번의 새 독립 계산 범위 밖이며 이전 승인 기록과 구분했다.

**기초 연습 재고와 일부 응용 문항은 확보되어 있다. 전체를 학교 시험의 대체재나 기출과 동등한 품질로 승인할 근거는 부족하다.**

## 검사 범위와 후속 순서

전수 범위는 저장 행의 구조/분류/수량/중복 신호, 모든 등록 목록과 생성 경로다. 생성 경로 5,516개에서 16,548관측, 초등 수량 후보 35,840관측, 중등·새 서술형 수량 후보 19,500관측을 수행했다. 이들은 서로 다른 수학 문항 수로 합산하지 않는다. 수동 의미 검토와 독립 풀이·그림 대조의 범위는 각 상세 보고서에 따로 표시했다. 학생 전체의 학습 효과, 공식 성취기준 완전 대응, 전체 문항의 독립 풀이를 입증한 검사는 아니다.

후속 순서는 **확정 내용 결함 수정 → 상위 풀이 유형과 중복 관계 정리 → 통합 후 수량 재계산 → 부족 유형·서술형·교과서 지정 변형 보강 → 유형별 기출/교과서 기준 표본 검수**다. 실제 보강은 기존 승인 원장과 분리한 계획·내용 승인 절차로 진행해야 한다.

검수 산출물에는 ID·메타데이터·수량·해시와 판단 근거를 남겼다. 원문 전체, 비공개 비교 시트·실행 로그·DB 스냅샷은 `.qa-artifacts/math-type-audit-20261018/`에 보관한다. [검증 기록](validation.json)에 검사와 보고서 상호 대조 결과를 정리한다.
