# 유형별 문제 수 점검

초3~중3의 기본 일일 연습을 구성할 재고는 있다. 그러나 저장 행 수를 독립적인 수학 유형 수나 서로 다른 문제 수로 읽으면 공급량을 과대평가한다. 모든 유형에 반복 연습 문제가 충분하다는 판정은 할 수 없다.

## 현재 재고와 출제 조건

기준 시각은 **2026-10-18 13:58 KST**, 제품 소스는 `cd067a49a`다. 한 번의 `RepeatableRead`·`SET TRANSACTION READ ONLY` 조회에서 **118,020행**, 현재 출제 자격을 만족하는 **115,575행**을 확보했다. 학생·계정·응시 기록은 조회하지 않았다.

| 출처                      |     보유 행 | 출제 가능 행 |
| ------------------------- | ----------: | -----------: |
| 엔진 적재가 포함된 manual |     101,166 |       99,376 |
| school_textbook           |      12,301 |       11,826 |
| transformed               |       4,442 |        4,363 |
| past_exam                 |         101 |            0 |
| ai_generated              |          10 |           10 |
| 합계                      | **118,020** |  **115,575** |

현재 출제 가능 엔진 문항은 실제 `source=manual`과 적재기 문항류 규약을 함께 적용해 식별한다. `mid:` 접두어만 보고 엔진이라고 세면 잠긴 기출 원문까지 섞인다. 고등 생성기 168개 등록과 별도 연산지의 생성 영역은 현재 DB 재고에 더하지 않았다.

출제 가능한 제품 문항류는 **15,878개**다. 그중 **4,042개·99,376행**은 엔진 문항류이며, 나머지 **11,836개·16,199행**은 `solo:`로 시작한다. `solo:`는 원문별 묶음이며 풀이 방법을 분류한 유형 체계가 아니다. 따라서 15,878개가 서로 다른 수학 유형이라는 뜻은 아니다.

한 시험지의 같은 문항류 제한은 현행 `familyIdOf(unitId, familyKey)`를 그대로 사용했다. 형식 형제는 보기 제외 발문·그림이 같으면 하나의 발문으로 센다. 동일한 그림은 SVG·URL 배열의 정확 일치로 판정했으며 회전·동치 도형을 의미적으로 합치지는 않았다.

8개×5회는 발문 하나를 한 번만 쓰고, 같은 문항류는 한 장에 한 번만 사용하는 최대유량 계산이다. **난이도·형식 할당과 실제 최근 14일 사용 이력을 완화한 재고 용량**이다. 교사의 실제 5회 출제 성공이나 유형 통합 후의 성공을 보장하지 않는다. 원래 객관식의 수학 조건이 보기에 들어 있는 경우 발문만 세면 보수적으로 과소계산할 수 있다.

지원 차시 360개 중 서술형이 하나라도 있는 곳은 **84개**, 서술형 재고는 **226행**이다. 276차시에는 현행 분류의 서술형이 없다. 서술형을 일정 수 요구하는 시험지에서는 전체 행 수가 충분해도 부족할 수 있다. 모든 차시에 동일한 서술형 최소량이 필요하다고 새로 결정한 것은 아니다.

## 유형별 반복 공급

전체 보유 문항류 16,367개 모두의 수량·난이도·형식·서로 다른 발문 수를 [유형별 CSV](type-inventory.csv)와 [JSON](type-inventory.json)에 기록했다. 보유만 있고 출제 가능 행이 없는 문항류도 빠뜨리지 않았다.

5회에 한 유형씩 새로운 문제를 쓴다는 비교를 위해 ‘유형당 서로 다른 문제 5개’를 살폈다. 이는 **이번 감사의 시나리오이며 공식 최소량이나 새 제품 정책이 아니다.**

1. 발문·그림만으로는 엔진 **149문항류**가 5개 미만이다.
2. 중등·새 서술형 65개 후보를 전부 다시 읽고 19,500개 생성 관측으로 대조했다. 보기 자체가 수학 조건인 **23문항류는 부족 오탐**이었다. 보기 순서만 바뀐 것은 새 문제로 세지 않았다.
3. 나머지 중등·새 서술형 **42개**, 초등 **84개**를 구분해 기록했다. 초등의 추가 14개 진술형은 실제 보기에 조건이 있어 발문 단독 수치보다 문제 내용이 다양하지만, 저장된 전체 문항도 문형당 3개다.

| ---------------------------------------------------- | ------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |

작은 유한 영역과 최근에 2~3개만 승인 적재한 유형은 보강 방식이 다르다. 전자는 새 풀이 방향·자료·판단 과제가 필요할 수 있고, 후자는 검산된 같은 문형의 다른 내용 적재가 가능하다. 숫자만 다르다는 이유로 새로운 상위 유형을 만들 필요는 없다.
