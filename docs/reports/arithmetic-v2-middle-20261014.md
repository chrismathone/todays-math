직접 곱집합은 오른쪽 축이 가장 빨리 변하는 혼합 기수 인덱스를 사용한다. 정수 나눗셈은 `(b,q)`, 단항식 나눗셈은 `(a,e−f,b,f)`, 동류 근호는 `(a,s,b,t,r)`의 곱집합에서 표의 실제 피연산자로 일대일 변환한다. F는 분자 오름차순, 분모 오름차순으로 고정된다. `problemAt`은 비정수·비유한·음수·상한 이상 인덱스를 `RangeError`로 거절한다. 난수, I/O, 재시도, 도메인 전체 순회 없이 인덱스 하나를 계산한다.

각 도메인 안에서 매개변수, text 발문, latex 발문이 각각 유일하다. 교환법칙으로 값이 같아도 피연산자 순서는 문제 정체성에 포함한다. 입력 분수는 기약형만 쓰므로 `1/2`와 `2/4`를 서로 다른 유리수 입력으로 세지 않는다. 근호는 제곱인수를 꺼내기 전 발문이 학습 대상이므로 서로 다른 원래 피제곱수를 유지한다.

**456,360은 선택 전체의 서로 다른 발문 합집합 크기가 아니다.** 상수항이 0인 일차식은 동류항 유형과, 항이 소거된 다항식 곱셈은 단항식 곱셈 유형과 겹칠 수 있다. 공유 엔진은 혼합 선택에서 표시되는 문제 정체성의 중복을 별도로 제거하고 부족을 거절해야 한다. 도메인 수량을 부풀리기 위해 중복으로 채우지 않는다.

## 정답 정규형

저장은 모두 정수 문자열이다. 부호 없는 양수에는 `+`가 없고, 앞자리 0·`-0`·소수점·지수 표기는 허용하지 않는다. 계산은 BigInt와 기약 유리수로 수행한다. 유리수의 분모는 양수, 분자·분모 gcd는 1, 0은 `0/1`이다.

- `integer`: `exact = [value]`.
- `rational`: `exact = [numerator, denominator]`. 결과가 정수여도 kind는 rational, exact의 분모는 `"1"`이며 text/latex는 정수만 표시한다.
- `polynomial`: 변수는 **x 하나**. `exact = [degree, numerator, denominator, ...]`의 평탄한 세 문자열 묶음이다. 차수는 엄격한 내림차순이며 0인 계수는 생략한다. 현재 최대 차수는 6이다. 예: `−2x²+5x+12`는 `["2","-2","1","1","5","1","0","12","1"]`; `−x²/2`는 `["2","-1","2"]`. 상수는 degree `"0"`, 영다항식은 **`[]`**다. 단항식 나눗셈의 답에는 음수 지수·x 분모가 없다. 유리수 계수는 허용하고, 원래 나눗셈 발문의 지시문에 `x ≠ 0`을 표시한다.
- `surd`: `exact = [radicand, numerator, denominator, ...]`의 평탄한 세 문자열 묶음이다. 피제곱수는 양의 제곱인수 없는 정수, 엄격한 오름차순이며 계수 0인 항은 생략한다. 피제곱수 `"1"`은 유리수 항이다. 현재 여섯 유형은 정리 후 최대 한 항이고, 0은 **`[]`**다. 예: `6√2`는 `["2","6","1"]`; `−√2/2`는 `["2","-1","2"]`; `3`은 `["1","3","1"]`.

다항식·근호의 빈 exact 배열은 유효한 0을 뜻하며 text와 latex는 `"0"`이다. 공유 저장 스키마는 이 경우를 거절하면 안 된다. 답의 text/latex는 정답만 포함한다. text에서 분수 계수는 `(3/2)x`처럼 묶어 분모와 변수가 혼동되지 않게 하고, latex는 `\frac{3}{2}x`로 표시한다. 풀이·등식 전개·설명 문장을 정답에 넣지 않는다.

## 독립 검산

`verify`는 `problemAt`과 생성용 `solve`를 호출하지 않는다. 매개변수 길이·정수성·도메인 소속을 검사하고 해당 매개변수가 요구하는 발문 text, latex, 지시문과 일치하는지 확인한다. 정답의 정규형·표시를 검사한 뒤 다음 별도 수학 검사를 수행한다.

- 정수 사칙: 역연산과 정확한 나눗셈 나머지 검사.
- 유리수: 분모를 제거한 교차곱 항등식.
- 거듭제곱: 답을 밑으로 지수만큼 정확히 나누어 1인지 검사.
- 혼합 계산: 곱셈 역연산 후 덧셈 역연산.
- 다항식: 모든 차수의 계수 항등식. 생성용 다항식 덧셈·곱셈 함수를 재사용하지 않으며, 나눗셈은 답에 제수 단항식을 곱해 피제수를 복원한다. 몇 개의 x 값 대입으로 항등성을 추측하지 않는다.
- 근호: 생성은 제곱인수 제거, 검산은 소수별 지수 분해를 사용한다. 곱셈·나눗셈·제곱근은 정규형 확인 후 제곱의 정확한 항등식과 부호를 함께 확인한다. 제곱만 비교해 양·음 부호를 혼동하지 않는다.

표시 포맷터는 공유하되 생성용 수치 풀이 함수는 공유하지 않는다. 시험은 생산 코드의 수학 보조 함수를 가져오지 않고 작은 안전 정수, 별도 약분, 가장 큰 제곱인수 역순 탐색, 명시적 계수식으로 정답을 계산한다. 생성된 text 발문을 다시 읽어 피연산자를 확인하며 latex를 독립적으로 해독해 text와 일치하는지도 전수 검사한다.
