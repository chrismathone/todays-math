# 기출 대비 잔여 요구 구현·검수 — 2026-10-19

미지원 6개 고유 요구와 기존 연습 보강 6개를 완료했다. 중2 직선과 중3 이차함수의 계수 재배치는 별도로 구현하여 **7개 새 생성 문형과 기존 6개 등록의 보강**으로 연결했다. 객관식 개수 보기, 기출 대비 메뉴 권한, 모순된 서술형 채점 안내를 함께 수정했다.

합계 **452개 유한 매개변수 조합**을 검사했다. 이는 452개 독립 사고 유형이나 학교 전체 대응 수가 아니다. 특히 새 근호·역함수·외접원 문형은 유한 조합 7개이므로 무제한 새 문제 공급을 뜻하지 않는다. 기존 방정식 분류와 문장 모델은 별도로 각각 512개 출력 레코드를 표본 검사했으며 전체 영역을 전수 검사했다고 하지 않는다. 중복 seed·보기 순서·응답 형식은 용량으로 합산하지 않는다.

기존 여섯 등록 ID를 유지하여 등록 증가는 0개다. 새 문형 7개는 단답형이며 혼합 요청에 참여한다. 보강한 중1 다섯 문형은 단답형·객관식, 직사각형은 본래 서술형·8점 네 기준을 제공한다. 지원하지 않는 형식은 다른 형식으로 위장하지 않는다. 새 문형은 필요한 조건을 본문에 모두 제시하는 텍스트형이며, 새 그림 독해를 검증했다는 주장은 하지 않는다.

## 객관식·채점·권한 수정

- 개수를 묻는 객관식은 실제 인쇄 항목 수를 읽어 `0..N` 안의 다섯 가지 서로 다른 보기만 만든다. 식이 다섯 개인데 `6개`를 제시하던 실제 EQ06/EQ09 재현 사례를 수정했다. 다섯 보기가 불가능하면 생성하지 않는다.
- 수학 검증은 발문·풀이를 별도 유리수·다항식 계산으로 판독한다. 생성기 정답이나 seed를 정답 근거로 쓰지 않는다. 독립 검수에서 발견한 “시간 조건을 무시하고 t=0을 나중 회복으로 인정” 같은 채점 대안은 승인된 저술 안내의 닫힌 목록으로 제한했다. 네 기준의 대안·오류 문구에 모순을 섞은 480개 변이를 전부 거절하고 정상 60개 문항은 보존했다.
- `/exam/practice`와 그 API는 `bank`, `arithmetic`, `studio`, `library`, `conceptBlank` 중 하나로 열린다. 화면의 출제 버튼도 같은 판정을 사용한다. `export`나 `textbook` 단독으로 이 기능이 열리지는 않는다. 기존 공통 교과서 출력 권한과 상위 `/exam` 정책은 보존했다.
- 화면 구성·CSS·출력 양식은 변경하지 않았다. D-07의 모양 변경 승인 대상은 발생하지 않았다. 이전 통합의 print-check 항목도 수정하지 않았다.
