Behavior
- EYWA_SYNC_AUTO_JSON resolves bindingId = tenantId = targetBranchId from a validated UUID. Explicit EYWA_SYNC_BINDINGS_JSON entries retain priority and reserve their tenant and branch IDs. Rotating automatic keys resolve for receiver processing, account refresh/confirmation, administration and SSO.
- A receiver request verifies HMAC and fixed target origin before source fetch or provisioning. Absent automatic bindings require live identity-matching control with enabled=true, healthy=true, mode=active, a current lease and a nonblank valid tenantName.
- A short advisory-locked transaction rechecks absent binding/mappings/branch UUID, inserts the branch and active binding with sourceEpoch and ownership=true, and records exactly one provisioning audit. No network I/O occurs inside this transaction. Concurrent identical deliveries create once.
- An existing unlinked reserved branch UUID or another persisted mapping conflicts safely. Display names are not identity: distinct tenant UUIDs may have identical names, with separate branches and no adoption or merging. This follows the coordinator's final instruction.
- Existing shadow/retired bindings are returned without activating, renaming or clearing the local operator block. OFF invalidates access and preserves branch, mappings and history; ON reuses stable IDs. Candidate confirmation, local passwords, transfer rules and manual suspension continue through the existing paths.
- New autoProvisionedBranch defaults false. Only atomic creation sets it true. Monotonic fresh control may rename an auto-owned branch only while its current name still matches the prior source name; compare-and-set protects a concurrent local rename. Manual-owned/local-renamed branches remain unchanged and receive an audit review record; admin status shows the name mismatch. Same-named distinct branches are allowed.
- First SSO before the webhook creates only an expiring state/PKCE handoff at start. Callback verifies the source assertion before fetching full live control and provisioning, then enqueues roster reconciliation. A bad assertion creates no branch or binding. The coordinator explicitly approved retaining this tested callback-based approach.
- Automatic trust fences legacy sync and legacy v1 SSO, including before a persisted dynamic binding exists.
- /account/eywa-switch delegates expiry evaluation to a server helper, removing Date.now from React render.
