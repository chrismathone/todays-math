**기출 엔진으로 실제 학교 시험을 공부할 수 있는가 — 2026-10-18**

**일부 유형은 대비 연습이 가능하다. 그러나 현재 웹앱에서 학교를 선택해 만든 결과가 그 학교 시험의 유형·구조적 난도·그림 해석·과정 서술을 충분히 반영한다고 판정할 수는 없다.** 기존 엔진의 긍정적인 능력과, 학교 요구를 실제 출제로 연결하는 기능의 공백을 함께 확인했다.

사용자 질문은 “대륜중학교 문제를 엔진으로 만들었을 때 그 문제로 대륜중 기출을 공부할 수 있는가”다. 경명여중은 별도의 검증 사례이며 전체 엔진을 같은 기준으로 검토했다. 원문을 저장하지 않은 것은 의도된 설계다. 원문 DB가 없다는 이유로 학습 불가라고 판단하거나 원문 복원을 권고한 이전 해석은 철회했다. [확정 검수 기준](OWNER-CRITERIA.md)에 따라 **새 자작 문제에서 학생이 실제로 수행하는 수학**을 보았다.

| 확인 축 | 현재 판정 | 실제 근거와 한계 |
| --- | --- | --- |
| 개념·계산과 일부 추론 | 대비 연습 가능 | 부호 조건→변환 좌표의 사분면, 함수인지 판단, 한 직선의 여러 성질 판단, 해 개수→매개변수, 여러 구간 교차, 부호/경우 선택 등 실제 생성 예제 존재. 모든 엔진이 단순 숫자 대입이라는 평가는 틀림 |
| 복합 기출 전체 과제 | 일부 기초·추론만 확인, 보강/검증 필요 | 그래프와 정사각형/넓이비, 관련된 두 연립방정식, 여러 평행변 경우처럼 **조건을 함께 쓰는 완결 과제**가 대응하는지 추가 확인 필요. 재료 계산의 존재만으로 전체 충족으로 세지 않음 |
| 그림·그래프·자료 | 지원은 존재하나 요구별 대응 제한 | 실제 생성 그림도 있고 일부를 렌더·눈검수함. 좌표를 글로 주는 문제는 그래프를 읽는 연습을 자동으로 대신하지 않음 |
| 과정 서술 | 일부 가능, 학년/요구 폭 보강 필요 | 초4·중3의 자작 루브릭 6가족은 실제 모범답·기준을 갖춤. 중1·중2의 복합 과정 요구와 자동 과정 피드백 전체를 지원하는 증거는 아님 |
| 난도 | 구조 근거의 추가 검토 필요 | 엔진 등급·출처 난도 라벨·배점은 실측 학교 난도가 아님. 미지 조건, 경우 선택, 표현 전환, 제외 조건과 설명 수준을 대조해야 함 |
| 학교 선택→실제 출제 | 연결 보강 필요 | 현 작업실 ‘엔진’은 `manual` 은행 재고 필터. 별도 학교 예측 API는 단원/형식/난도 분포로 기존 행을 조립. 검토된 학교의 수학 요구를 자작 가족 선택에 전달하는 계약과 제품 흐름은 확인되지 않음 |
| 전체 문제 수의 충분성 | 전체 합계로 판정 불가 | 형식 쌍·별칭·같은 과제·유한 가족 중복을 제외하고, 학교/범위별 필수 요구와 적격 고유 재고로 판단해야 함. 모든 학교·학년의 충분성을 승인한 감사가 아님 |

학교별 요구가 다른 두 합성 프로필에 같은 단원·형식·문항 수를 주면, 현재 예측 조립은 구조 차이를 전달받지 못하고 같은 세트를 만든다. 학교의 자체 난도 분포가 달라도 코호트 라벨 때문에 같아질 수 있었다. 이는 **격리된 메모리 재현에서의 현재 코드 동작**이며 운영 저장이나 실제 학생 효과 실험이 아니다. 일반 출제기의 논리 문항·문항류·현재 자격 검사처럼 재사용할 수 있는 강한 경로도 확인했다.

보강은 다음 순서가 적절하다.

1. **원문 없는 학교 요구 프로필→검토된 자작 가족→실제 출제**를 연결한다. 같은 학교명 표시나 같은 단원 태그만으로 대비 충족을 판단하지 않는다.
2. 실제로 부족한 **복합 그래프·도형·조건 의존·여러 경우의 완결 과제**를 보강한다. 이미 지원하는 함수 판단·매개변수 탐색 등은 재사용한다.
3. 중1·중2를 포함해 필요한 **과정 서술과 그림 대응**을 넓히고, 단계·경우·경계에 근거해 난도를 검토한다. 같은 문항의 객관식/단답형을 두 문제로 부풀리지 않는다.

[구체적인 보강 작업과 합격 시나리오](upgrade-plan.md)를 작성했다. 이 감사에서 보강 기능을 구현·운영 반영했다고 보고하지 않는다.
