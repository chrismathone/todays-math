**사용자 확정 검수 기준 — 2026-10-18**

사용자 목표는 ‘웹앱에서 대륜중학교 기출 연습을 선택하고 엔진으로 만든 문제로, 실제 그 학교 기출에 필요한 유형과 난이도를 공부할 수 있는가’다. 대륜중은 구체적 검증 사례이며 전체 학교·학년·문제 엔진의 업그레이드 방향을 판단한다.

기출 원문을 DB에 넣지 않은 것은 저작권을 고려한 의도된 설계다. 원문 DB 부재, 과거 문항 연결 수 0, 원본 시험지 저장 수 등은 학습 대응력의 합격·불합격 기준이 아니다. 원문 복구·재적재를 해결책으로 제안하지 않는다. 기출은 검토 비교의 근거로만 쓰고 새 연습은 자작 생성기의 구조와 자체 수치·문장·그림으로 만든다.

판정은 ‘대비 연습 가능’, ‘기초 요소만 연습 가능’, ‘보강 필요’, ‘미검증’으로 구분한다. 동일한 원문·수치·문항 번호·어휘를 복제할 필요는 없다. 반대로 개별 계산기나 단원 이름 하나가 맞는 것만으로 복합 기출 전체를 대비할 수 있다고 판정하지 않는다. 특정 출력 표적의 사소한 차이를 모두 새로운 수학 유형으로 분리하지 않는다.

생성기 수, 생성 표본 수, 학교명 표시, API의 성공, 100점 조립은 각각 학습 대응력을 자동으로 보장하지 않는다. 실제로 생성된 새 문제·해설·그림과 독립 검산, 추상 요구와의 대응을 근거로 삼는다. 이 검수는 실제 학생의 성적 향상이나 학교별 예측 적중률을 측정한 실험이 아니다.

전체 범위는 초등·중등·고등의 등록 생성기, 연산 엔진, 판정형·결합형·자작 서술형, 학교 조건 출제 경로다. 엔진별 제품 접근, 은행에 실린 자작 재고, CLI 전용, 미구현 카탈로그를 구분한다. 여러 학교·학년·교과서 유형의 대표 표본은 구조적 요구를 비교하기 위한 표본이며 사이트 전체나 공식 교육과정 전수 검증으로 확대 해석하지 않는다.
