**실제 생성 표본이 보여 주는 차이**

모든 아래 예시는 `seed=20261018`이다. 문제은행 계열은 `variant=0`; 연산은 실제 셔플 경로가 선택한 `domainIndex`까지 JSON에 기록했다. 전체 출력과 해시가 로컬 재현 증거에 있다. ‘과제 대비 가능’은 이 **한 과제의 요구**를 연습할 수 있다는 뜻이며 학교 전체 대비 판정이 아니다.

현재 중등·고등의 난이도 표시는 저작된 등급과 [`resolveMiddleTier`](../../../src/lib/middle/tier.ts)의 제한적인 발문 모양 판정이다. 학생 반응으로 보정한 학교별 난이도가 아니다. 초등 `supportedTiers`도 실제 등록된 갈래만 돌려주며 미등록 심화 갈래는 거절한다. **숫자 크기·‘심화’ 표지·카탈로그 제목만으로 실제 시험의 사고 깊이를 대신 판정하면 안 된다.**

**그림·그래프·자료·답변 형식의 경계**

연산 2,211표본 중 그림 ID가 나온 가족은 **248**, 서로 다른 그림 ID는 **714**였다. 도형·각·선분·넓이·입체 등 계산용 그림을 실제로 제공하며, 3개 표본은 `buildArithmeticV2Sheet`의 그림 팩 생성·재열기까지 실행했다. 문제은행 생성기에서도 접은 도형과 둔각 삼각형의 FigureSpec을 확인했다. 따라서 ‘그림 지원 없음’은 맞지 않는다. 다만 이번은 스펙/스냅샷 검증이며 **실제 그림의 인쇄·표시·기하적 정합성을 브라우저에서 새로 승인한 결과가 아니다.**

연산의 함수·자료 경로는 식·좌표·자료·확률 조건을 주고 계산하게 하는 내용이 넓다. 함수 그래프를 눈으로 읽기, 스케치·작도·정성적 상관관계 해석까지 구현했다고 읽으면 안 된다. 은행의 별도 그림/그래프 과제는 구별해야 한다. 고등 보류 2개도 포물선/직선의 그래프 판독, 영역 지도의 인접 관계를 필요로 하기 때문에 보류되어 있다.

문제은행의 객관식과 단답형은 같은 과제의 다른 응답 형식일 수 있다. 새 실행 표본 한 개에서 두 형식이 모두 파생되었지만, 모든 변형에서 객관식이 가능하거나 오답 보기가 좋은 것은 아니다. [`expandFamily`](../../../src/lib/engine/expandEngine.ts)는 객관식 파생 실패를 보고하고, 단답 끝말만 바꿔 서술형을 만들지 않는다. 현재 6개 자작 서술형은 실제 과정·기준을 갖지만 모두 그림 없는 소수 단원이다. 루브릭 존재는 자동 과정 채점이나 실제 학생 답안의 신뢰도 검증을 뜻하지 않는다.

**표본 재현·유한 영역·중복**

이번 focused 실행은 다음 범위다.

- arithmetic-v2 **737가족 × 3시드 = 2,211회**: 생성 예외·스키마/가족 검증 실패 0, 같은 입력 반복 2,211개 모두 동일. 가족 `verify` 통과를 전체 독립 정답 검산으로 바꾸어 말하지 않는다.
- arithmetic v1 **7스킬 × 3시드 = 21표본**: 저장 발문/답의 생성·재열기·결정성, 피연산자에서 별도 계산한 정답 확인.
- 초·중·고·결합·판정·서술 **29개 선택 표본**: 생성 예외 0, 반복 29개 모두 동일. 전수 품질 심사나 학생 효과 실험이 아님.
- 작은 연산 **12가족 146후보 전수**: 발문을 다시 읽는 독립 Python 정수/제곱근·36개 주사위 결과 열거로 답을 확인. 가족 내부 발문 중복 0, 영역 밖 인덱스 거절. 나머지 **725가족의 domainSize는 소스 선언**으로 유지.

영역 선언의 범위는 현재 5부터 98,010,000까지지만, 이를 합쳐 전체 가능 문제 수라고 제시하지 않는다. 실제로 구구단 일반 1가족의 **64문항**은 2~9단의 개별 8가족 합집합 **64문항**과 정확히 같았다. 가족별 선언을 더하면 128슬롯이지만 수학 과제는 64개다. 직각삼각형 정수 빗변 가족은 **7문항**, 주사위 곱의 배수 확률은 **5문항**, 차의 절댓값 경우 세기는 **6문항**으로 독립 확인했다. 시드를 늘리는 것으로 이런 가족의 내용 공간이 늘지는 않는다.

기존 문제 생성기 감사의 **420,300회에서 관측한 297,016**은 정해진 발문/보기/그림 정규화 아래의 **표본 과제 변형 수**였다. 독립 사고 유형, 전체 앱 용량, 품질 승인 수가 아니다. 해당 대규모 캠페인이나 이전 DB 스냅샷은 다시 실행/읽지 않았다. 동일 소스의 기존 작은 유한 가족 59개 증거는 재사용할 수 있지만, 연산의 별도 영역·저장 재고·형식 파생 수를 더하는 근거가 되지는 않는다.
