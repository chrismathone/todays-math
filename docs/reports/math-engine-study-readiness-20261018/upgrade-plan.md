**학교 기출을 공부할 수 있게 만드는 보강 순서 — 2026-10-18**

목표는 사용자가 대륜중 등 학교·학년·시험 범위를 고르면, 그 시험에 필요한 개념·조건 추론·그림 해석·풀이 깊이를 **새로 저작한 문제로 연습**하는 것이다. 원문 저장 수나 생성 시드 수를 늘리는 것을 완료 기준으로 삼지 않는다. 이 문서는 검수 결과에 따른 구현 계획이며, 운영 기능이 이미 추가됐다는 뜻이 아니다.

**P0: 학교 선택이 실제 공부할 내용에 영향을 주게 연결**

| 작업 | 구체적인 산출물 | 완료를 확인할 증거 |
| --- | --- | --- |
| 원문 없는 시험 요구 프로필 | 학교 식별자·학년/과목·시험 범위·관찰 기간과 근거, 개념·조건 관계·표상·경우 선택·풀이 단계·응답 요구의 분포. 관찰/추론/미확인을 구별 | 대륜중 중1·중2 표본처럼 수학 내용을 다시 읽은 검토 기록. 원문 문장·수치·그림 없이 각 요구를 설명할 수 있음 |
| 요구와 기존 자작 가족 대응 | 가족별 지원 개념, 완결 과제 구조, 그림/그래프 유무, 조건 갈래, 응답 형식, 설명·루브릭, 생성/은행/CLI 상태를 검토한 대응표 | 부호→사분면, 함수 판단, 해 개수→매개변수처럼 이미 되는 것은 재사용. 구성 요소만 있는 과제는 완결 대응으로 승격하지 않음 |
| 현재 화면과 서버 연결 | 학교 대비 흐름이 실제로 검토된 프로필을 전달하고, 그 요구를 만족하는 적격 자작 문항을 선택. 프로필이 미검토라면 일반 범위 연습과 근거 상태를 표시 | 같은 범위·문항 수라도 추론/그림/과정 요구가 다른 두 프로필은 해당 차이를 반영. 같은 프로필의 표시 이름만 바꿔서는 문제를 임의로 바꾸지 않음 |
| 출제·저장 조건 일치 | 문제 단위·가족 중복, 범위, 출제 자격, 필요한 형식과 과정 요구를 선택 및 저장 때 모두 확인. 검증되지 않은 대체를 학교 대비 충족으로 표시하지 않음 | 객관식/단답 두 행을 같은 문제로 인식. 서술이 필요한 자리에 풀이 없는 단답형을 넣으면 충족 실패와 부족한 요구를 보여 줌 |

현재 일반 출제기의 문제·가족 구분 및 정확한 조건 선택 기능은 가능한 범위에서 재사용한다. 예측 조립기의 과거 학교 문항 재사용 우선순위를 곧바로 ‘원문 없는 학교 대비 생성’으로 사용하지 않는다. 학교명만 바꾸거나 코호트 분포를 복사한 결과를 그 학교의 출제 특성이 반영된 결과라고 표시하지 않는다.

문제는 한 논리 문항으로 유지하고 객관식·단답·과정 서술은 지원하는 응답 형식으로 다룬다. 형식만 바꿨다고 새 문제를 가산하지 않는다. 실제 과정 과제·모범답·채점 기준이 있어야 서술형 대응으로 인정한다.

**P1: 부족한 완결 과제를 자작 엔진으로 보강**

| 공통 보강 대상 | 이번에 확인한 수요 | 기존 재사용 및 새 저작의 경계 |
| --- | --- | --- |
| 그래프 판독과 복합 판단 | 중1 거리·시간 그래프의 여러 구간/반복 통과/최초 도달을 함께 해석 | 기존 구간 보간과 중2 한 직선의 다중 성질 판정을 재사용. 필요한 그림과 이동거리/방향/공통 조건의 여러 판단이 결합된 미확인 과제를 보강 |
| 좌표·도형 조건 결합 | 비례 그래프와 정사각형·넓이비·동일 길이·사다리꼴, 중2 축절편과 평행변의 모든 경우 | 좌표·넓이·직선 계산기를 재사용하되, 조건에서 식을 세우고 해의 적합성/다른 경우까지 확인하는 완결 가족을 저작 |
| 관계가 있는 식과 모델링 | 해가 이동하는 두 연립방정식, 여러 공식·단위·잔여량·올림을 잇는 상황 | 각각의 식 계산만 이어 붙이지 않고, 중간 결과의 의존 관계와 제외 조건을 문항·해설·검산에 함께 보존 |
| 중1·중2의 실제 서술 | 식 세우기→중간 결과→해석, 오류 진단·이유·가능한 해 설명 | 현재 자작 루브릭 가족은 초4/중3에 집중. 미지원 학년/요구에 새 모범답과 단계별 기준을 저작. 단답 끝말 변경은 사용하지 않음 |
| 고등 함수·논리의 완결 과제 | 공통2의 진리집합 포함/부분집합 수, 제한 정의역·치역, 절댓값 유리함수의 가지·제외점·교점, 유한 대응 제약 | 먼저 전체 자작 은행·교과서 결정적 경로를 대조. 기존 high 색인 0을 전면 부재로 단정하지 않고 미검증 대응을 확인한 뒤 빠진 구조를 추가 |
| 교과서의 그림 의존 문제 | 두 하위 삼각형의 각 관계·서로 다른 중심, 접점·음영 영역 해석 | 같은 단원 태그보다 필요한 학습 행동으로 대응. 그림이 주는 정보가 발문/해설/생성 좌표와 맞는지 눈으로 확인 |

새 가족의 단위는 조건 관계와 필요한 풀이 행동이다. 답을 합·개수·순위로 바꾸거나 숫자·보기·학교명만 바꾼 갈래를 모두 별도 사고 유형으로 늘리지 않는다. 새로운 자작 가족 하나가 여러 학교 프로필의 같은 요구를 충족하도록 설계한다.

**P2: 난도와 반복 연습의 근거 확보**

- 난도는 미지 정보, 조건 의존, 표현 전환, 경우 선택, 제외·경계 검토, 필요한 설명으로 기록한다. 출처의 난도 라벨이나 배점은 관측 자료로 남기며 곧바로 정답 기준으로 삼지 않는다. 대표 새 문항의 교사 검토를 거쳐 등급을 맞추고, 학생 반응으로 보정하기 전에는 실측 난도라고 말하지 않는다.
- 작은 유한 가족과 겹치는 일반/특수 가족의 실제 고유 과제를 구별한다. 같은 논리 문항의 형식 쌍, 보기 순서와 seed 반복을 연습 다양성으로 가산하지 않는다. 필요한 연습 횟수에 비해 적격 재고가 부족한 프로필을 먼저 보강한다.
- 문항 수의 충분성은 전체 합계 대신 프로필의 필수 요구별 완결 대응, 적격 고유 문항, 조건 갈래, 반복 때의 고갈, 서술/그림 대응으로 보고한다. 학생 학습 효과는 별도 검증 과제로 남긴다.

**최소 검증 시나리오**

1. 대륜중 중1·중2와 별도의 중등/고등 요구 프로필을 고정한다. 개념·조건·표상·응답 요구와 미확인을 각각 기록하고, 그 기준에 따라 새 문항을 눈으로 판정한다.
2. 한 프로필의 각 지원 가족에서 서로 다른 시드와 중요한 조건 갈래를 생성한다. 답을 생성기의 정답 필드에 기대지 않고 발문에서 다시 계산하며, 가능한 모든 경우·정의역·경계·단위도 확인한다. 작은 유한 가족은 전수 열거한다.
3. 실제 그래프·도형을 렌더해 표식·접점·영역·보조선과 수학 조건을 확인한다. 같은 단원 계산만 가능하면 ‘기초 요소’로 남긴다.
4. 같은 범위/문항 수의 두 학교 프로필에서 구조 요구만 바꾸는 비교 검사를 한다. 이름만 바꾸는 검사도 함께 넣어 실제 요구가 선택에 반영되는지 구별한다.
5. 실제 출제 화면→서버→선택 결과→저장 전 검사까지 통과시킨다. 필요한 경우·그림·서술이 빠지거나 같은 논리 문항이 중복되면 대비 충족으로 저장하지 않는다. 근거가 없는 학교의 일반 연습을 검토된 학교 대비로 표시하지 않는다.

위 기준을 만족한 **검토 범위**에 대해 대비 연습 가능이라고 판정한다. 시험 적중이나 성적 향상을 보장하는 문구와는 별개다. 현재 감사의 경로 재현·생성·독립 검산 범위는 [통합 결과](README.md)와 각 증거 보고서에 기록한다.
