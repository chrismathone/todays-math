일반 생성기의 4,203개는 독립적인 사고 유형의 수가 아니라 이번 기준의 정본 생성 단위다. 숫자·소재·문장 차이를 의미적으로 모두 합친 수가 아니며, 297,016개는 정해진 100회 표본과 텍스트/도형 동일성 아래의 변형 하한이다. 전체 가능 문제 수·기출 동등성·정답 검수 통과 수·경명여중 맞춤 성공 수로 읽어서는 안 된다. 객관식/단답형 표현과 보기 순서만 다른 것은 용량을 늘리지 않았다.

단순 증량에도 한계가 있다. 소스에서 가능한 내용이 5개 미만이라고 확인한 생성 단위가 59개이고, 현재 적재기 지원 재고가 5문항 미만인 등록 단위는 73개다. 유한 문형은 시드만 늘려 해결할 수 없으며, 재고가 얇지만 생성 영역은 넓은 문형과 구분해 보강해야 한다. 공통수학1 168개와 초등 결합형 1개는 CLI/라이브러리 전용이고, 공통수학2는 등록 생성기 0개다.
