# 실제 학교시험 벤치마크와 수학 엔진의 구조별 간극

> **후속 학습 기준 재평가:** 아래는 당시 문항별 완결 구조 대응 기록이다. 부분 지원 19개가 독립 신규 사고 유형 19개를 뜻하지 않는다. 개수·합·번호 등 사소한 출력 차이와 원문의 표면 재현을 별도 수학 공백으로 세지 않은 [후속 구조 검수](../math-engine-study-readiness-20261018/study-structures.md)와 [전체 결론](../math-engine-study-readiness-20261018/README.md)을 우선한다.

**핵심 계산·조건 탐색·그래프 기반은 이미 넓게 있다. 보강할 부분은 여러 판단의 결합, 그림과 진술의 연결, 다중 출력 서술형, 학교 예측 경로의 구조 선택이다.** 경명여중 2025 중1 1학기 기말의 실제 표시 22문항을 DOM·MathML로 읽고 그림 6개를 직접 확인했다. 아래의 지원 2·부분 19·원자료 미확정 1은 이 표본의 구조 판정이며 엔진 정확도나 학생 성취율이 아니다.

여기서 **지원**은 등록 생성기가 핵심 수학적 행동을 수행한다는 뜻이다. 개수 답과 번호 답 같은 포장 차이는 따로 남겼다. **부분**은 이웃 family가 있으나 조건·의존 관계·표적 또는 native 채점이 더 필요하다는 뜻이다. **원자료 미확정**은 식 손상으로 동일 구조를 확정하지 못했다는 뜻이며 부재 판정이 아니다. 추가 표의 **정확 family 미확인**은 이번 등록부·구현·표본 검토에서 찾지 못했다는 한정 판정이다.

## 생성기와 학교 예측은 현재 다른 경로다

[PREDGEN](../../../src/lib/predictor/generatePredictedPaper.ts#L200)는 승인·직접 사용 가능·정답 존재·범위 단원을 만족하는 기존 DB 문항을 읽는다. 전달하는 후보에는 단원, 난이도, 답 형식, 출처, 원문 관계, 배점만 있다. [PREDCOMPOSE](../../../src/lib/predictor/composePredictedPaper.ts#L275)는 이 칸들과 출처 순위로 문항을 선택한다. **이 경로는 중등·초등·고등 생성기를 즉시 호출하지 않고, 수학적 과제 구조나 family를 매칭하지 않는다.** 등록 family가 많아도 해당 학교의 진술형·그림형·서술형을 골라 낼 수 있다는 증거가 되지 않는다. 실제 적재·승인·출제 가능한 DB 재고는 조회하지 않았다.

[COMBO](../../../src/lib/middle/combo.ts#L516)의 결합형 6개에 중1이 없다는 사실만으로 중1 결합 구조가 전무하다고 결론내려서도 안 된다. 일반 등록인 [P21](../../../src/lib/middle/m1Prop.ts#L1541)가 이미 두 그래프를 만든다. 다만 현재 a 하나 또는 b 하나를 묻는 갈래는 두 개념이 각각 필수인 다중 단계 문항과 다르다. [NATIVE](../../../src/lib/engine/nativeDescriptive20261018.ts#L13)의 native 6개도 초4·중3만 대상으로 한다. [EXPAND](../../../src/lib/engine/expandEngine.ts#L60)는 현재 단답·객관식만 파생하며 단답 발문을 고쳐 서술형으로 세는 방식을 명시적으로 금지한다.

제품 구현은 이번 감사 범위에 포함하지 않았다. 아래 검사는 향후 구현의 최소 수용 기준이다.

### 1. 중등 개념 진술·참인 부분집합 family

**이미 구현:** 초등 31/32의 단일/조합 보기, 중등 등식·방정식의 개수 판별과 계산 판정형의 독립 truthOf 관문이 있다. ([EQ06](../../../src/lib/middle/m1Expr.ts#L1545), [EQ09](../../../src/lib/middle/m1Expr.ts#L1653), [EQ33](../../../src/lib/middle/m1Expr.ts#L354), [ELSTAT](../../../src/lib/elementary/statementForms.ts#L394), [JUDGE](../../../src/lib/middle/judge/registry.ts#L536), [C06](../../../src/lib/middle/m1Book1.ts#L656))

**변경:** 중등 등식·좌표·비례 진술의 의미 데이터와 판정기를 저술하고, 진술 ID 집합을 보존하여 개수 판별과 부분집합 선택을 구분한다. 모든 영역을 일반 문자열 판정에 맡기지 않는다.

**최소 수용 검사:** 등록된 각 새 family에서 결정적 3 seed 이상으로 각 인쇄 진술을 별도 계산기로 판정한다. 오직 한 조합 보기가 참인 ID 집합과 같고, 참 개수가 같아도 ID 집합이 다른 오답은 배제되는지 확인한다. 자연수 0 제외·축 위 점·항등식/일차방정식 구분의 음성 사례도 포함한다.

**원자료 제약:** Q18 태그를 진술/서술 분류의 정답으로 쓰지 않는다. 초등 7개 소단원 등록을 중등 지원 수로 올리지 않는다.

**이미 구현:** 자릿수 모델, 공통 해, 정/반비례 교점, 좌표 넓이와 독립 rubric 계약이 있다. native 등록은 초4·중3에 한정된다. **변경:** 첫 범위는 정/반비례 교점에서 두 계수를 모두 사용하고 원조건을 검산하는 한 native family로 고정한다. 다음으로 자릿수/공통해/두 직선의 점·넓이 모델을 각각 독립 저술한다. 발문 변경만으로 서술형을 만들거나 combo 명부에 없는 것을 자동 승인하지 않는다.

**최소 수용 검사:** 첫 family의 seed/variant별 인쇄 교점으로 두 계수를 각각 재계산하고 표적·모델 답안·기준별 배점 합을 검산한다. 한 계수만 쓰거나 계수 비와 곱을 바꾼 응답은 서로 다른 오류 기준으로 설명되어야 한다. 두 선/넓이 확장 시 점을 각 직선 식에 대입하고 행렬식 넓이와 맞춰 본다.

**원자료 제약:** Q21은 빈 분수 분자와 정답 미정 경고가 해결되기 전 정확 변형의 기준으로 금지한다. Q22는 표시된 정답 불일치 경고를 보존하고 공식 정답을 검증했다고 쓰지 않는다.

### 4. 문자 가격과 판촉 정책 비교

**이미 구현:** 일회 할인 문자식과 연속 증감의 곱셈, 비례 식·대응 값이 있다. ([EX02](../../../src/lib/middle/m1Expr.ts#L614), [L34](../../../src/lib/middle/m1LinearApply.ts#L696), [L35](../../../src/lib/middle/m1LinearApply.ts#L708), [P02](../../../src/lib/middle/m1Prop.ts#L658), [ELSTAT](../../../src/lib/elementary/statementForms.ts#L394))

**변경:** 증정/단일 할인/연속 할인은 별도 정책으로 정의하고 구입 수량·적용 문턱·잔여 단품을 명시한다. 현재 범위는 공통 양의 단가의 문자 계수 비교와 짝 보기까지로 제한한다.

**최소 수용 검사:** 자체 예시에서 수량 1과 할인/증정 경계 전후를 정확한 유리수로 재계산한다. 연속 할인은 두 잔존 비율의 곱으로만 맞아야 하고 합산 할인 오답은 틀려야 한다. 양의 단가에서 최저가와 동률 여부를 독립 계산하여 보기 유일성을 확인한다.

**원자료 제약:** 원자료 표의 학교 문제 문구·수치를 복제하지 않는다. 분수식과 x/y 방향은 MathML/의미 데이터로 읽고 평탄 텍스트로 추정하지 않는다.

### 5. 기존 자연수 조건 집합의 순위·표적 확장

**이미 구현:** EQ17은 자연수 매개변수 집합 자체를 생성한다. 중3 G3RAT는 유리근 조건을 완전히 나열하고 고등에도 자연수 해 탐색이 있다. ([EQ17](../../../src/lib/middle/m1Expr.ts#L1911), [L02](../../../src/lib/middle/m1LinearApply.ts#L136), [L45](../../../src/lib/middle/m1LinearApply.ts#L879), [G3RAT](../../../src/lib/middle/m3Top3.ts#L1203), [HIGHRECIP](../../../src/lib/high/h1Equations.ts#L2103))

**변경:** 가능 집합을 반환하는 내부 결과에 정렬·순위·집합/합/개수 표적을 명시한다. 중1 연속수에는 항 수와 간격을 분리한다. 중3 유리근 탐색을 다시 구현하거나 고등 family를 중1 범위로 이식하지 않는다.

**최소 수용 검사:** 별도 전수 계산이 유한 경계를 조건에서 유도하고 매개변수와 해에서 0을 제외한 집합을 만든 뒤 생성기 집합과 정확히 비교한다. 최소/두 번째/최대 표적 및 짝수 3항의 경계 seed를 검산하고 필요한 순위만큼 해가 없으면 생성을 거절한다.

**원자료 제약:** 어떤 조건 검색도 임의의 스캔 상한으로 참 집합을 잘라서는 안 된다. 정수·유리수·자연수 조건과 집합/합 응답을 구분한다.

## 원자료 품질과 해석 경계

- 현재 편집 화면은 객관식 17·주관식 5로 표시한다. 그러나 중1 18번은 주관식 태그인데 다섯 짝 보기가 있다. 문항 수·태그만으로 형식 비율을 보정하거나 자동 재분류하지 않는다.
- 중1 11번에는 변경 메모가 있다. 표시 학교·연도는 출처 참조이며 수정되지 않은 공식 원본임을 보장하지 않는다.
- 중1 21번은 사이트의 정답 미정 표시와 MathML의 빈 분수 분자가 함께 있다. 평탄 텍스트로 분수 범위를 보충하지 않고 정확 식/답 매핑을 보류한다.
- 중1 22번은 현재 그림과 식의 구조를 읽을 수 있지만 정답 불일치 경고가 있다. 구조 보강 아이디어로만 사용하며 저장된 정답이나 학교 원본 정답을 검증했다고 쓰지 않는다.
- 중1 6·8·10·15·20·22번의 실제 그림은 모두 확인했다. 원본 이미지는 공개 보고서나 제품 자산으로 편입하지 않았다. 새 문항은 자체 구조 데이터와 자체 그림으로 저술해야 한다.
- MathML 분수·지수와 그림의 라벨을 함께 읽었다. 예를 들어 평탄 텍스트의 비례/반비례 구분이나 분수 계수를 그대로 추정하지 않았다.
- 완전한 웹사이트 감사, 공식 교육과정 정합성, 학교 원본 충실도, 학교별 예측 적중, 학생 성적·학습효과를 주장하지 않는다. 추가 고등 시험지나 전체 학교 corpus는 이번 표본에 없다.

## 실행 검증과 재현 근거

- `registeredTypes()` 1,517개(중1 578), `registeredHighTypes()` 168개, `judgementDefinitions()` 15개, 초등 등록 난이도 갈래 1,088개를 seed `20261018`로 실제 호출했다. 총 2,788개가 예외 없이 생성되었다. 고등 보류 2개는 지원 수에서 제외했다. 이는 호출 가능성 검증이며 모든 문항의 수학적 정확성 검증이 아니다.
- 집중 검사는 중1 관련 19 family × seed 3개 × variant 4개 = 228개를 생성했다. 그중 13 family의 156개를 별도 Python `Fraction` 수식 판독기로 다시 읽어 검산했다. 괄호 전개, 진술 개수, 방정식 대입, 공통 해/상수, 자연수 매개변수의 완전 집합, 그래프 계수/넓이가 모두 일치했다.
- EQ17의 자연수 집합/음의 정수 개수 두 모드와 P21의 a/b/대칭 교점 세 갈래를 모두 관측했다. P21에서 ab 합성 출력이 없다는 판정은 코드의 세 분기와 실제 표본이 함께 뒷받침한다.
- 초등 진술 8개를 생성해 5개 보기·조합 구조를 확인했고, 그중 이상/이하 진술 4개는 별도 수치 판정으로 정답을 검산했다. 초등 그래프/표 3개와 native 서술형 6개도 호출했다. 초등·고등 구현을 중1 지원 수로 더하지 않았다.
- 추가 중3 7 family × 3 seed = 21개를 호출했고 G3RAT 3개는 인쇄 식에서 유한 범위와 제곱수 조건을 다시 계산했다. 고등 자연수 순서쌍 family 1개도 인쇄 식의 유한 범위를 독립 유도해 전수 비교했다.
- 전체 호출 catalog와 집중 생성 표본은 재실행 후 파일 SHA-256이 각각 동일했다. 중1 그림 6개에서 읽은 값·좌표·길이 관계도 별도 유리수 계산으로 확인했으며 공식 정답지 검증으로 취급하지 않는다.
- 공개 JSON은 22개 문항별 출처 번호·분류·등록 근거·원자료 제약, 집중 검사 요약과 입력 파일 SHA-256을 담는다. 원문 DOM·MathML·PNG·전체 생성 표본·재현 probe는 코디네이터의 ignored `.qa-artifacts/exam-engine-capacity-20261018/benchmark-recovery-evidence` 및 원자료 폴더에 보존한다.
