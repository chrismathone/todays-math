# 운영 화면 UI/UX 전수 점검

2026-09-23 · 기준: 현재 작업실의 네이비 메뉴, 블루 동작, 흰 표면, 회색 배경.

개발용 경로를 제외한 `src/app/**/page.tsx` 31개와 작업실 내부 탭의 구현을 목록화하고 점검했다. 제작·학습·수업을 독립 작업실에서 수정한 뒤 `main`에 병합했다. 모든 운영 계정으로 모든 상태를 실행했다는 의미는 아니다. 브라우저 검증은 아래 개발 fixture와 모의 API 범위다.

## 화면별 범위

개발용 `*-wire`, `*-hifi`, 비교용 `LegacyUnifiedWorkspace`는 과거 시안 보관본이다. 운영으로 연결되지 않는 비교 시안의 디자인 자체는 다시 만들지 않았다. 지면, 교구의 자리별 색, 출처 배지의 의미색은 화면 조작색과 구별한다.

## 병합 후 추가 발견

- 모바일 공통 헤더가 채점 화면 폭을 밀어내던 문제를 메뉴 줄바꿈으로 해결했다. 390/768/1440px에서 페이지 가로 넘침이 없고, 표는 자기 영역에서 스크롤된다.
- 모달 바깥 클릭의 기본 포인터 처리가 복귀한 초점을 지우는 문제가 있었다. 기본 처리를 취소하고 닫도록 수정해 문제 상세·도형 편집기에서 확인했다.
- 별도 `/problems`는 작업실과 다른 부품을 쓰고 있었다. 필터 폭·글자·버튼과 복구 경로를 총괄 단계에서 추가 보완했다.

## 검증

- 병합 후 변경 관련 27개 테스트 파일 477건 통과. 시험지 저장·순서·인쇄·학습 회귀와 문제 목록 복구를 추가 검사했고, 재검사 결과를 반영한 최종 중복 제외 595건이 통과했다. 집계 기록: `.tmp-srs-course/ui-ux-test-summary.json`.
- 타입 검사, 변경 파일 ESLint, affordance, `git diff --check` 실행. 커밋·푸시 때 저장소 필수 검사도 실행한다.
- 공통 화면: 관리자·계정·검수·헤더·404 등 20개 화면/크기 조합, 1440×960 및 390×960.
- 통합 모달: 문제 상세·도형 편집기 각각 1440/390px에서 `:modal`, 배경 초점 차단, Tab, Esc, 바깥 클릭 및 상세창 초점 복귀.
- 추가 경로: 문제 목록·채점·교사용 랩실을 1440/768/390px에서 확인. API 실패→재조회→실제 문항 표시, 필터 활성화, 가로 넘침 검사.
- 기존 SRS 설정: 1900/1366/390px에서 미설정 학생 계획 저장을 모의 API로 확인.
- 시험지 저장 범위: SRS/홈에서 초안 읽기·저장 미실행, 시험지에서 오류 닫기, 탭 이동 후 내용 보존, SRS에서 Ctrl+S 비활성.
- 학습: 12개 코스 시작 활동, 큐브 13개 단원 진입, 로컬 SRS 기본/대수와 일부 내부 활동을 데스크톱·모바일에서 확인.
- 인쇄 미리보기: 1440/390px에서 문제지·정답지 전환, 시험지 복귀 링크, 가로 넘침 없음 확인. 인쇄 미디어에서는 도구막대가 숨고 A4 크기 793.69×1122.52px가 유지됨을 확인. TestPrint 23건 재검사 통과.
- 임시 QA 경로는 검증 뒤 제거했다. 로컬 기록: `test-results/ui-ux-common/`, `test-results/ui-ux-integrated/`, `test-results/srs-setup/`, `test-results/worksheet-save-scope/`.

새 복구 테스트에서 공용 모의 서버의 검색 미구현, 바구니 핸들러 누락, 검수 대기 문항의 담기 비활성화를 확인해 fixture와 검증 대상을 바로잡았다. 제품의 검색·검수 규칙이나 타임아웃을 바꾸지 않았다.

## 한계

보호된 관리자·교사·학생 화면은 실제 기록을 바꾸지 않고 컴포넌트/API fixtures로 확인했다. 실제 DB의 모든 권한·네트워크 오류 조합, 모든 생성 문항·교구 변형을 실행한 것은 아니다. 인쇄 템플릿은 변경하지 않았으며 실물 출력물을 새로 만들지 않았다.
