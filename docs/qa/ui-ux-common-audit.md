# 공통 화면·관리자 UI/UX 점검 — 2026-09-23

## 기준과 범위

사용자 요청에 따라 현재 작업실(네이비 내비게이션, 블루 동작, 흰 표면, 차가운 회색 배경)을 기준으로 한다. 기존의 베이지 계정 화면·회색 구형 메뉴 체계는 이 기준으로 맞춘다. 문항 출처 배지의 구분색, 수학 교구의 의미색, 시험지 지면과 명조는 별도 역할이므로 유지한다.

`globals.css`의 옛 이름 `--ink`, `--bg`, `--side`, `--blue` 등도 `--learn-*`를 참조한다. 공통 버튼과 입력창은 44px, 8px 모서리, 14px 글자와 초점 표시를 사용한다. 인쇄 시 바깥 배경은 흰색을 유지한다.

## 점검과 수정

| 화면 / 상태                     | 점검 결과와 조치                                                                                                                                                                                         |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 비로그인 홈 `/`                 | 공통 배경·본문·보조색 연결. 소개 일러스트·동영상과 재생 제어는 유지. 데스크톱/모바일 확인.                                                                                                               |
| 로그인 `/login`, 가입 `/signup` | 베이지 배경·입력창·서로 다른 오류/성공색을 공통 토큰으로 연결. 비밀번호 보기, Enter 제출, 오류 안내는 기존 기능 검사로 확인.                                                                             |
| 온보딩 `/onboarding`            | 공통 입력창·선택창·버튼·제목 크기 정리. 학생 추가 성공 후 이름 입력칸으로 초점 복귀, 중복 제출 방지, 오류 알림, 동명이인 목록 키 보완.                                                                   |
| 승인 대기 `/approval-pending`   | 공통 표면·입력·상태색. 승인 새로고침/로그아웃/실패 안내 기존 기능 확인.                                                                                                                                  |
| 관리자 계정 `/admin`            | 배경·표·버튼·입력·글자 통일. 현재 메뉴 표시, 검토 닫기와 Esc, 원래 선택 버튼으로 초점 복귀. 저장하지 않은 권한 변경이 있으면 닫지 않고 저장/취소 안내.                                                   |
| 관리자 자료 `/admin/users/[id]` | 목록/탭/미리보기/활동 기록 스타일 정리. 미리보기 선택 시 해당 영역으로 초점 이동, 닫기/Esc로 목록 복귀, 목록 페이지가 바뀌었으면 제목으로 초점 복귀. 읽기 전용/권한 경로 유지.                           |
| 관리자 SRS `/admin/math-srs`    | 관리자 공통 헤더 연결 및 SRS 현재 메뉴 표시. 내부 과정 설정/현황은 수업 관리 점검 범위.                                                                                                                  |
| 검수 `/review`                  | 표면·버튼·글자·최소 조작 높이 통일. 빠른 대기열 전환 시 이전 요청 취소/늦은 응답 무시, 조회 중/빈 결과/실패 구분, 재시도 버튼. 판정 중 대기열 이동 및 중복 제출 방지. 신고 입력 중 Esc/닫기와 초점 복귀. |
| 공통 구형 헤더 / 로딩           | 구형 굵은 검정 머리선을 현재 얇은 구분선·흰 헤더·네이비 글자로 변경. 실제 화면과 로딩 모두 `오늘의 작업 / 수업·학생 관리 / 시험지 만들기`로 명칭 정리.                                                   |
| 오류 / 없는 주소                | 루트 오류 경계와 404 화면을 추가. Next 16.3의 `retry`를 사용해 다시 시도, 홈 이동 제공. 학생 화면 오류는 `/learn`으로 복귀.                                                                              |

## 검증

- 기존 + 신규 공통 검증 95건 통과. 이후 신고 닫기/온보딩 초점/관리자 내비게이션 변경을 포함한 관련 81건 통과. 중복을 포함한 실행 횟수이므로 합산하지 않는다.
- 타입 검사, 변경 TSX ESLint 통과. 최종 병합 후 통합 검사는 총괄 보고서에 기록한다.
- Playwright: 1440×960, 390×960에서 관리자 계정·자료, 승인 대기, 검수, 로그인·가입, 비로그인 홈, 구형 헤더, 404와 채점 표본 20개 조합. 가로 overflow 없음. 관리자 닫기/Esc/초점 복귀 직접 실행.
- 보호된 관리자 데이터는 개발 전용 임시 렌더링 경로와 API fixtures로 검사했다. 실제 사용자 권한이나 자료는 수정하지 않았다. 임시 경로는 검증 후 제거했다.
- 로컬 스크린샷·결과: `test-results/ui-ux-common/`. 실물 운영 계정의 모든 오류 상태를 의도적으로 발생시킨 검사는 아니다.

## 출처 배지 보호

출처 배지 자체의 색은 변경하지 않았다. 배지끼리와 판정 상태색은 기존 ΔE2000 15 이상 검사, 새 작업실 본문/조작색과는 10 이상 검사로 역할을 구분한다. 흰 배지 글자 4.5:1 이상 대비 검사는 그대로 유지한다. 이전의 본문/버튼 색과 15 이상 떨어지도록 최적화한 구형 팔레트 제약 때문에 새 작업실 블루를 다른 색으로 바꾸지 않는다.
