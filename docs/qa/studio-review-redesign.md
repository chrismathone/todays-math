# 자료 제작 검수 화면 통합 검증 — 2026-09-14

대상은 `/dev/unified#studio`이다.

## 반영한 흐름

- `문제 자르기`에서 문제·도형 영역을 선택, 이동, 크기 조절, 연속 추가, 삭제한다.
  우클릭·Esc는 현재 지정만 취소한다. 자동 인식 중에는 영역 지정 커서를 사용하지 않는다.
- `문자·도형 검수`에서는 왼쪽에 원본 전체 페이지, 오른쪽에 해당 페이지의 수식과
  도형 결과를 표시한다. 이전·다음 문제와 검수 완료 후 다음 이동을 제공한다.
  원시 수식 편집은 `내용 수정`을 열 때만 표시한다.
- 도형 수, 분리된 원본 이미지, 편집한 그림, 원본 비교와 영역 수정·그림 편집을 연결했다.
  Mathgen 원본 커밋 `e8d12aabcb8bbff9f44b4e619ef90af971d7fb9d`의 FigureEditor를
  이식했고, 최초 사용 시 불러온다. 원본 이미지·편집 SVG·출력 이미지를 별도로 유지한다.
- 문자·도형·해설 작업은 페이지 인식과 같은 최대 2개 FIFO 대기열에서 실행된다.
  페이지·문제·작업 탭 이동으로 취소하지 않는다. 재시도는 해당 실패 항목에 한정한다.
  중복 작업과 삭제·수정 후 도착한 오래된 응답을 방지한다.
- 학년은 파일 이름 옆에서 자동 인식 결과를 표시하고 전체 문항에 적용한다.
  신뢰도 높은 근거가 일치할 때만 확정하며, 수동 지정은 유지한다.
- 객관식·단답형·서술형을 문제 박스와 검수 카드에 표시한다. 근거가 부족하면 미확인으로 남긴다.
  문제 없는 현재 페이지는 실패·대기·빈 페이지·미실행 상태에 맞는 안내와 재시도/직접 추가를 제공한다.

## 검증 결과

- 관련 Vitest 13개 파일, **359개 테스트 통과**: 공유 대기열, 개별 취소·재시도,
  오래된 응답 방지, 파일별 학년, 크롭·도형 좌표, 편집 SVG, 저장, AI 응답 검증 등.
- Playwright **8개 시나리오 통과**: 전체 페이지 인식, 원본 이동, 넓은 수식 검수,
  연속 드래그·선택·삭제·취소, 여러 문제 OCR, 모바일, 도형 출력, 실제 편집기 조작.
  마지막 모바일 레이아웃·카드 선택 수정 후 관련 3개 시나리오도 통과했다.
- 실제 Next dev의 1680·1440·1366·1024·390px 화면에서 가로 넘침이 없었다.
  도형 다시 그리기 응답을 대체한 브라우저 검증에서 수동 편집→저장→다시 열기,
  시험지 출력과 저장 후 새로고침 복원을 확인했다. JS 오류는 0개였다.
  모바일에서는 검수 결과가 작은 내부 창에 갇히지 않고 세로로 이어진다.
- 실제 Claude 구독 CLI에서 기출 6쪽 인식, 문자와 도형 동시 인식, SVG 다시 그리기가
  성공했다. 외부 API 키 결제 경로는 사용하지 않았다. Codex 실호출은 로그인 필요로
  추론 전에 거절되었으므로 성공했다고 간주하지 않는다.
- 변경 파일 ESLint와 포맷 검사, `npm run build`의 컴파일·TypeScript·정적 페이지 생성이
  통과했다. 기존 `tier-bench/g4` 파일 추적 경고 2개와 Prisma 설정 폐기 예정 안내는 남아 있다.

브라우저에서 사용한 응답 대체 테스트와 실제 구독 CLI 검증은 별개다.
Vite 테스트 하네스는 실제 앱의 Tailwind 전역 스타일을 포함하지 않으므로 도형 편집기의
화면 스타일은 실제 Next dev에서 별도로 확인했다. 사용자 원본 PDF와 사적 인식 결과는
저장소에 포함하지 않았다.

## 남아 있는 범위와 진단 한계

앞서 발생한 6쪽의 502 두 건은 실제 CLI 재실행에서 재현되지 않았다. 잘못된 JSON과
필드 검증 오류를 구분하고 안전한 필드 경로를 표시하도록 개선했지만, 과거 두 요청의
정확한 원인을 확정한 것은 아니다. [프로토콜 검증 기록](studio-ocr-protocol.md)에
실호출 결과와 재현한 별도 파서 결함을 구분해 기록했다.

위 검증 이후 OCR 후보정·자동 SVG 재작도·디지털 출력 단계를 연결했다. 현재 동작과
검증은 [디지털화 통합 검증](studio-digital-pipeline.md)을 참고한다. 업로드 자체는 AI를
실행하지 않으며, 실행 중 대기열은 새로고침/브라우저 종료 후 복원하지 않는다.
