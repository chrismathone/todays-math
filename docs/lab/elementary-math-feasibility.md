# 인재원 초등 수학 개념 게임: 전 단원 확장 검토

검토일: 2026-09-21 · 범위: 초등 1~6학년, 12개 학기 · 대상: 새 개념 학습과 복습

## 판단

**초등 수학의 주요 단원 전체를 담는 하나의 학습 도구는 설계할 수 있다. 다만 단원마다 다른 조작과 평가가 필요하며, 컴퓨터만으로 모든 성취기준을 달성했다고 판정할 근거는 아직 없다.**

이번에는 71개 주요 단원을 빠짐없이 열거하고 각 단원에 핵심 개념, 학생의 조작, 새로운 상황에서의 이해 확인, 보완할 부분, Blender 활용을 연결했다. 이는 주제별 설계 검토이며, 성취기준 각각을 세부 차시·문항·평가 기준에 대응시킨 완성 교육과정이나 학습 효과 검증은 아니다. 체험판에는 서로 다른 대표 활동 8개를 구현했다. 특정 단원의 체험이 있어도 그 단원 전체 수업이 완성된 것은 아니다.

2022 개정 교육과정은 초등 1·2학년 2024년, 3·4학년 2025년, 5·6학년 2026년부터 적용된다. 따라서 이번 검토는 모두 2022 개정 자료를 기준으로 했다. [교육부 고시 제2022-33호](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&searchTyp=)

71이라는 수는 아래에서 선택한 교과서·출판사 차례와 교육청 평가 계획의 **주요 단원** 개수다. 1학년 1학기 5단원, 나머지 11개 학기 각 6단원이며, 도입·마무리 프로젝트는 제외했다. 국가가 모든 교과서의 단원명과 순서를 하나로 고정했다는 의미가 아니다. 검정 교과서에 따라 편집과 명칭이 다를 수 있다. 학교에서 쓰는 출판사가 정해지면 해당 교과서로 다시 맞춰야 한다.

## 공통 게임과 단원별 활동의 관계

공통으로 공유할 것은 지도, 진도, 짧은 미션, 정답 피드백, 콤보, 복습 일정이다. 실제로 생각하고 조작하는 화면은 수 모형·도형·측정·자료의 성질에 맞춰 달라져야 한다.

| 개념 계열 | 학생이 하는 일 | 개념 조각 → 관계 → 종합 문제 |
|---|---|---|
| 수와 연산 | 묶기, 풀기, 교환, 배열 분해 | 낱개와 묶음 → 자릿값 → 받아올림·받아내림 설명 |
| 분수와 소수 | 같은 전체 나누기, 겹치기, 단위 교환 | 전체와 부분 → 같은 양 → 통분·계산 원리 |
| 평면도형과 넓이 | 회전, 뒤집기, 자르기, 옮기기 | 변·각·높이 → 보존되는 성질 → 도형 분류·넓이 |
| 측정 | 시작점 맞추기, 눈금 읽기, 단위 채우기 | 기준과 단위 → 반복 측정 → 어림·비교·단위 변환 |
| 입체 | 접기, 쌓기, 시점 바꾸기, 층 채우기 | 면·모서리 → 인접·맞은편 → 전개도·투영·부피 |
| 규칙·비·자료 | 대응 만들기, 두 양 함께 바꾸기, 분류·재분배 | 관계의 한 사례 → 공통 규칙 → 새 입력·생활 상황 해석 |
| 가능성 | 예측, 다시 넣고 뽑기, 결과 비교 | 가능한 결과 → 가능성의 크기 → 실제 결과와 가능성 구별 |

영어 SRS의 ‘I / have / a book → I have → I have a book’에 대응하는 수학의 단위는 단순한 문장 조각보다 **행동과 관계**다. 예를 들어 전개도에서는 ‘한 면 찾기 → 이어진 면 찾기 → 접힐 방향 예상하기 → 마주 보는 면 찾기 → 다른 전개도 판단하기’로 합쳐 갈 수 있다. 넓이는 ‘같은 단위 정사각형 → 빈틈없이 덮기 → 자르고 옮겨도 같은 양 → 직사각형으로 변환 → 새 도형에 적용’으로 합쳐 간다.

## 이번에 구현한 대표 활동 8개

| 활동 | 실제 조작 | 이후 확인 | 현재 범위 |
|---|---|---|---|
| 묶음 제작소 | 34개의 낱개를 10개씩 묶거나 다시 풀기 | 십 묶음 4개와 낱개 2개를 수로 표현 | 1-1 ‘50까지의 수’ 일부 |
| 측정 탐정 | 자의 0을 막대 시작에 맞추기 | 0이 아닌 눈금에서 시작한 길이 구하기 | 2-1 ‘길이 재기’ 일부 |
| 거울 공방 | 대칭축 반대쪽 칸 채우기 | 새 점과 축 사이 거리 판단 | 5-2 ‘합동과 대칭’ 중 선대칭 일부 |
| 넓이 수리소 | 평행사변형 조각을 잘라 오른쪽으로 옮기기 | 넓이 보존의 이유와 다른 치수의 넓이 | 5-1 ‘둘레와 넓이’ 중 평행사변형 일부 |
| 입체 조립실 | 맞은편 면 예측 후 전개도 접기·시점 변경 | 펼친 상태에서 다른 면의 맞은편 예측 | 5-2 ‘직육면체와 정육면체’ 중 정육면체 전개도 일부 |
| 규칙 기계 | 여러 입력을 넣어 출력 관찰 | 규칙 선택 후 보지 않은 입력의 출력 예측 | 5-1 ‘대응 관계’ 일부 |
| 평균 배달소 | 세 상자의 블록을 옮겨 고르게 나누기 | 다른 자료의 평균 구하기 | 5-2 ‘평균과 가능성’ 중 평균 일부 |
| 가능성 실험실 | 예측 후 같은 공을 다시 넣고 반복 추출 | 반반과 실제 빈도 구별, 확실한 사건 판단 | 5-2 ‘평균과 가능성’ 중 가능성 일부 |

공통 기능으로 활동 전환, 2단계 확인, 정답 소리 선택, 콤보·XP, 활동별 진행 상태 복구를 넣었다. 같은 체크포인트를 반복해서 눌러도 XP를 다시 주지 않는다. 발견 단계의 보상은 관찰을 완료한 보상이므로 숙련도 점수로 해석하면 안 된다. 저학년과 고학년 활동이 함께 보이는 화면은 교사의 구조 검토를 위한 체험판이며, 실제 학생에게는 자신의 선수 개념과 수준에 맞는 코스만 제공해야 한다.

현재 없는 것: 학년별 전체 차시, 충분한 변형 문항, 실제 학생 계정과 교사 기록 화면, SRS 일정, 적응형 진단, 설명 음성, 실제 사용 시간 측정, 장기 기억·학습 효과 검증. 따라서 이 체험판을 그대로 20분 수업 운영용 완성품으로 보아서는 안 된다.

## Blender의 역할

이 컴퓨터의 Blender 5.2.1 LTS를 백그라운드에서 실행해 정육면체 전개도 장면을 실제 제작했다. 여섯 면과 다섯 접힘 축을 만들고 펼침부터 접힘까지 애니메이션을 넣었다. 원본 `cube-net-lesson.blend`와 웹용 `cube-net-lesson.glb`를 함께 저장했다.

체험판의 전개도는 Blender가 계산한 21개 시점의 꼭짓점 좌표를 이용한다. 접는 정도와 시선 방향은 브라우저에서 조작한다. 이번 미리보기에서 GLB 파일을 직접 불러오지는 않으며, **같은 Blender 장면에서 추출한 기하 데이터를 연결했다.** 내보낸 GLB에는 6개 메시와 5개의 접힘 애니메이션이 있다. 제품에서 GLB를 사용할 때는 다섯 축의 애니메이션을 같은 진행률로 함께 재생해야 한다. 원본 Blender 파일에서는 하나의 타임라인에서 함께 접힌다.

| 적용 후보 | Blender에서 만들 것 | 학생의 핵심 판단 | 개발 우선순위에 대한 판단 |
|---|---|---|---|
| 정육면체·직육면체 전개도 | 면, 접힘 축, 접기 애니메이션 | 겹치는 면·맞은편·유효한 전개도 | 먼저 검증: 이번에 한 종류 구현 |
| 쌓기나무와 여러 방향 보기 | 큐브, 카메라, 가려진 면 | 보이지 않는 큐브와 투영도 해석 | 높음: 2D 정답 입력보다 공간 조작의 이점이 큼 |
| 겉넓이와 부피 | 펼쳐지는 면, 단위 큐브와 층 | 겉을 덮는 양과 속을 채우는 양 구별 | 높음: 공식 전에 단위를 경험시키기 좋음 |
| 각기둥·각뿔·회전체 | 밑면 수를 바꾼 모형, 회전·단면 | 밑면·옆면·모서리의 구조 비교 | 높음: 방향을 바꿔도 성질이 유지됨을 관찰 |
| 들이·무게 | 여러 용기·저울의 시각 자산 | 모양이 달라도 같은 양, 단위 관계 | 보조: 실제 물·용기·저울 경험을 대체하지 못함 |
| 원의 넓이 | 잘게 나눈 부채꼴 조각과 재배열 | 조각을 늘릴수록 직사각형에 가까워지는 관계 | 선택: 2D만으로도 충분히 구현 가능 |
| 캐릭터·보상 연출 | 짧은 동작, 조립 완료, 파티클 자산 | 학습 행동의 결과를 즉시 느끼기 | 개념 활동 뒤에 추가; 연출만 먼저 만들지 않기 |

Blender는 제작 도구이고 학생의 학습 실행은 브라우저에서 담당하는 구성이 적절하다. 정답 판정, 힌트, 선수 개념, 복습 일정은 별도의 학습 로직이 맡는다. 학생마다 Blender를 설치할 필요는 없다. 브라우저에서는 GLB의 장면과 애니메이션을 읽는 도구를 사용할 수 있다. [Three.js GLTFLoader 공식 문서](https://threejs.org/docs/pages/GLTFLoader.html)

물리 시뮬레이션이나 Blender의 모든 제작 기능이 웹에서 자동으로 그대로 실행되는 것은 아니다. 수학 학습에 필요한 면의 관계·정확한 부피·겹침 여부는 별도로 계산하고, 내보내기 가능한 변환 애니메이션이나 사전 계산한 좌표로 표현하는 편이 검증하기 쉽다. 이번 전개도에서는 접힌 여섯 면의 위치와 모든 샘플의 면적 보존을 검사했다. 다른 전개도·비정육면체는 각각 추가 제작과 검증이 필요하다.

## 20분을 채우는 수업안과 검증 방법

다음은 **운영 가설**이며, 이번 체험판에 20분 코스가 구현되거나 학생의 체류 시간이 입증된 것은 아니다.

| 시간 | 활동 | 학습 목적 |
|---|---|---|
| 0~2분 | 짧은 선수 개념 진단·지난 개념 회상 | 이미 아는 내용을 건너뛰고 필요한 도움 선택 |
| 2~6분 | 예측하고 만지는 발견 미션 | 새 개념의 원인과 결과 관찰 |
| 6~10분 | 조건이 달라지는 구성 미션 | 단서를 줄이면서 관계 직접 만들기 |
| 10~13분 | 틀린 예·반례 찾기 | 겉모양으로 외운 규칙과 오개념 구별 |
| 13~17분 | 새로운 상황의 종합 미션 | 여러 개념 조각을 합쳐 적용 |
| 17~19분 | 익숙한 짧은 문제의 리듬 복습 | 속도감·콤보와 인출 연습 |
| 19~20분 | 한 문제 설명·다음 진행 선택 | 이해 근거와 다음 복습 대상 남기기 |

처음 개념을 발견하는 동안에는 빠른 정답을 강요하지 않고, 익숙해진 짧은 문제 구간에서 속도감을 사용한다. ‘클릭할 때 소리가 난다’보다 ‘내가 옮긴 조각이 정확히 맞물린다 → 이유를 알아냈다 → 다음 구성이 열린다’의 연결이 중요하다. 콤보는 조작 횟수보다 의미 있는 확인에 부여한다. 오답 때는 관찰 장면으로 돌아갈 수 있어야 한다.

복습 문항도 같은 숫자만 바꿔 반복하지 않는다. ‘모양 바꾸기 → 표현 바꾸기 → 틀린 이유 찾기 → 그림 단서 빼기’처럼 같은 개념을 다른 형태로 회상하게 한다. 전개도에서 F면을 반복 암기하는 것이 아니라 다른 전개도와 다른 기준 면으로 옮겨 가야 한다.

첫 파일럿은 저·중·고학년을 나누어, 익숙한 개념과 처음 배우는 개념을 각각 관찰하는 것이 적절하다. 인원과 아래 수치는 확정된 연구 결과가 아니라 검증 계획을 세울 때 사용할 기준이다.

- 접속 시간 대신 실제 학습 행동이 있는 시간, 긴 멈춤, 도움 요청, 중도 이탈을 구분해 기록한다.
- 평균만 보지 말고 학생별 20분 도달 여부, 학년·수준별 차이를 본다. 강제 대기 시간을 넣어 목표를 맞추지 않는다.
- 바로 맞힌 비율과 함께, 그림·힌트를 뺀 새 문제와 며칠 뒤 같은 개념의 다른 문제를 확인한다.
- 교사가 알려 준 답과 학생 혼자 낸 답을 분리한다. 틀린 이유를 말하거나 그리게 하는 짧은 확인을 포함한다.
- ‘재미있었다’는 응답과 다시 하려는 선택을 함께 기록한다. 체류 시간만으로 학습 성공을 판정하지 않는다.

## 다음 제작 범위에 대한 제안

전 학년 전체 문항을 한꺼번에 늘리기 전에 다음 세 수업을 각각 실제 20분 분량으로 완성하고 학년별 학생에게 확인하는 편이 적절하다. 이번 검토에서 드러난 위험이 서로 다르기 때문이다.

1. **2학년 길이 재기:** 저학년이 글·조작 도움 없이 진행하는지, 화면 눈금 이해가 실제 자 사용으로 이어지는지 확인한다.
2. **5학년 평행사변형 넓이:** 조각 옮기기가 넓이 보존과 높이 이해로 이어지는지 확인한다. 다른 도형과 잘못된 분해도 포함한다.
3. **5~6학년 공간과 입체:** Blender 전개도 여러 종류와 쌓기나무를 연결해 보이지 않는 면·큐브를 추론하는지 확인한다.

세 수업에서 조작의 재미, 20분 활동, 새로운 문제 적용이 함께 확인되면 공통 도구를 다른 단원으로 확장한다. 모든 단원에 똑같은 게임을 씌우는 방식으로는 이번 목표를 충족하기 어렵다.
