# 초3–초6 전체 학습 과정

`/lab/math-srs`에서 초3부터 초6까지 8개 학기, 48개 대단원, 230개 소단원을 선택해 학습한다. 기존 중1 과정은 `/lab/math-srs/algebra`에서 이어서 사용한다.

## 구성과 교재 참고

사용자가 지정한 `N:\개인\강아\교재자료\큐브수학 개념\큐브수학 개념\진도북`의 초3-1부터 초6-2 진도북 8권을 읽고, 각각 PDF 4–5쪽의 목차를 대조했다. `bookReference.ts`는 단원명과 인쇄 쪽수만 보관한다. PDF 본문·이미지·문제·해설을 서비스에 복제하지 않는다.

- 교육과정과 차시: 기존 `prisma/seed-data/units.ts`를 그대로 사용한다. 교재의 세부 개념은 기존 차시에 묶여 있으므로 책의 세부 목차와 차시 수가 1:1로 같지는 않다.
- 생성: 기존 `src/lib/elementary/generate.ts`의 초3–초6 생성기, 난이도별 실제 문항을 그대로 사용한다.
- 표시: 기존 `ProblemContent`, `MathText`, Python 도형 엔진을 재사용한다. 도형이 필요한 문제는 렌더 실패 시 제출을 막고 재시도를 제공한다.
- 교재와 다른 단원명은 화면의 교재 참고 문구에 함께 표시한다. 초6-2는 책과 기존 엔진에 맞춰 2단원 소수의 나눗셈, 3단원 공간과 입체 순서를 따른다.
- 해당 책의 출판 연도 또는 교육과정 판본을 확정하는 표시는 하지 않는다. 현행 교육과정 인증이나 책의 모든 활동을 대체한다는 의미가 아니다.

## 학습 동작

각 차시는 연산 1문항, 기본 2문항, 응용 2문항으로 구성한다. 종이와 펜을 준비하고 시간 제한 없이 풀며, 틀린 답은 원래 해설과 비교한다. 정수·소수·분수·대분수와 지원하는 단위는 자동 채점한다. 그림 그리기, 설명, 복수 답, 특정 분수 표현을 요구하는 문항은 정답 공개 후 학생이 직접 확인한다. 자기 확인 결과는 자동 채점과 구분해서 기록한다.

완료 차시는 진도이며 숙련도 인증이 아니다. 복습 시점은 정오답·풀이 도움·자기 확인 여부로 정하고 풀이 속도로 낮추지 않는다. 학년·학기를 자유롭게 바꿀 수 있고, 풀던 차시는 최대 16개까지 별도로 보관한다. 원래 차시를 선택하면 원문제·답안·풀이 도움 기록으로 돌아온다. 한 차시 완료 후 다음 단원·학기·학년으로 이어진다.

기존 SRS 학습자 선택을 재사용하되 초등 진도는 `todaymath-elementary-course-v1`에 별도로 저장한다. 중1 기록을 삭제하거나 변환하지 않는다. 브라우저 저장 제한·손상 시 기존 데이터를 덮어쓰지 않고 사용자에게 안내한다. 여러 기기 간 동기화나 인증 학생 계정의 DB 연동은 이 로컬 학습 과정에 포함되지 않는다.

## 서버 경로

- `GET /lab/math-srs/session?sectionId=…&seed=…&mode=learn|review`: 검증된 기존 차시에서 5문항 생성. 초등 생성기 전체를 브라우저 번들로 보내지 않는다.
- `GET /lab/math-srs/figure?sectionId=…&seed=…&tier=…`: 같은 씨앗과 난이도로 도형을 재생성해 기존 서버 렌더러로 처리. 클라이언트가 보낸 SVG나 임의 스펙을 받지 않는다. 동시 렌더 4개, 최근 128개 캐시.

## 검증

전체 차시의 생성 가능 여부뿐 아니라 본문·답·해설·도형이 기존 생성기 결과와 동일한지 검사한다. 분수·큰 수·단위 변환의 정확 채점, 자기 확인 분기, 진도 순서·중복 제출·힌트 보존·학년 전환·저장 손상 및 용량 부족, 도형 실패 시 재시도, 데스크톱·모바일 학습 동선을 검증한다.
