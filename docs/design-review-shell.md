## 확인 범위

- Chromium: 1440×900, 1366×768, 1024×600, 820×900, 390×844, 360×740.
- 홈·빈 보관함·펼친/접힌 메뉴·검색/새 시험지 모달: 가로 넘침 없음. 수정 후 위 크기의 사이드바 버튼 잘림과 이름 없는 버튼 없음.
- 새 시험지 입력, Esc 닫기와 원래 버튼 초점 복원, 본문 건너뛰기, 도움말 전환, 두 시험지 저장, 긴 제목 검색·초기화, 잘못된 JSON 오류를 실제 UI로 확인했다. 네이티브 dialog는 배경 컨트롤로의 초점 이동을 막으며 브라우저 도구 모음 이동은 허용한다.
- 일반 UI 버튼 높이 44px/모서리 8px, 글자 12·14·18·24px 유지. 인쇄·수식·로고 비례는 별도.
- 대비 확인은 단색 배경 위 실제 텍스트의 브라우저 계산값 기준이다. 정식 접근성 인증이나 스크린리더·실기기 전체 시험을 대신하지 않는다.

QA 증거는 로컬 `.qa-artifacts/workroom-hifi/review-*`에 저장한다. 별도 QA 브라우저를 사용했고 사용자의 실제 저장 작업이나 DB는 변경하지 않았다.
