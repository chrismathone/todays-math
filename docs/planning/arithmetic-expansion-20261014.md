# 연산대장 학년 확장 실행 범위

2026-10-14 사용자: 나머지 학년 구현 시작. 이어 실제 연산을 만들 수 있는 학년·영역만 포함하고 억지 연산은 제외하도록 확정했다.

기존 7개 스킬·97개 프리셋과 v1 저장 문서는 보존한다. 새 v2는 실제 사칙 연산·식 정리의 유한 도메인을 규칙으로 생성하며 외부 유료 모델을 호출하지 않는다. 학년을 채우거나 일반 수학 문항을 연산으로 이름 붙이지 않는다.

- 초3~4: 자연수 자릿수 확장과 몫·나머지, 같은 분모 분수 덧셈·뺄셈, 소수 덧셈·뺄셈.
- 초5~6: 자연수 혼합 연산, 다른 분모 분수 덧셈·뺄셈, 분수 곱셈·나눗셈, 소수 곱셈·나눗셈.
- 중1~3: 부호 있는 정수·유리수 사칙 연산, 짧은 거듭제곱 수치식, 동류항·단항식·다항식의 직접 연산, 근호 정리와 사칙 연산.
- 제외: 문장제, 도형, 증명, 공식 선택, 방정식 풀이, 학년별 개수를 채우기 위한 수 변환·비율·약수 나열. 인수분해·순환소수 변환도 이번 직접 연산 범위에 억지로 포함하지 않는다.

공통 타입은 `src/lib/arithmetic-v2/types.ts`. 자연수·분수·소수 구현, 중등 수치·문자식·근호 구현, 버전 계약·저장·API 호환 구현을 Codex 작업 공간에서 병행한다. 루트는 UI·출력·통합 검증을 맡는다. 각 정의에는 정확한 생성 가능량, 결정적인 인덱스 선택, 정수 기반 정답, 생성 함수를 재호출하지 않는 독립 검산이 필요하다. 같은 회차의 중복은 숨기지 않고 부족으로 거절한다.

학년은 검토 문서의 추천 위치이며 학년 전체 수학·성취기준 완성 표시가 아니다. 기존 A 구조와 작업실 디자인을 유지하고 문제지·답만 있는 정답지로 출력한다. v2 저장을 읽는 모든 경로를 먼저 준비하며 운영 DB/쓰기 flag 변경과 배포는 별도로 확인한다.
