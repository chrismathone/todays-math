# 기출 대비 잔여 요구 구현·출시

2026-10-19 원장님 지시: 잔여 미지원 6개 요구, 기존 연습 보강 6개와 객관식 개수 보기 결함을 완료한다. `origin/main`의 `261a5e263`에서 시작하며 로컬 `main`은 수정하지 않는다. 작업자 결과는 이 조정 가지에 통합한 뒤 원격 최신 변경을 다시 반영하고 `HEAD:main`으로 푸시한다.

## 완료 기준

- 대륜중 중1·중2, 경명여중 중1·중3, 경신고 공통수학2의 선택 검토 범위에서 각각 혼합 12문항·문형별 최대 3개를 실제 API로 생성하여 모든 선택 요구가 `full`이고 결과가 `complete`여야 한다. 문항 수만 채워서는 통과하지 않는다.
- 잔여 12개 고유 요구는 학교·학년별로 13건이다. 그래프 계수 재사용은 중2의 직선과 중3의 이차함수에 각각 구현·증명한다.
- 기존 여섯 등록 ID를 유지하고 버전·생성·풀이·독립 검산을 보강한다. 형식별 복제 등록과 seed·보기 순서·소재 교체를 용량으로 합산하지 않는다.
- 유한 저작 영역은 각 인쇄 발문에서 전체 매개변수를 별도로 풀고, 기존 분류·모델 생성 범위는 실제 표본과 강제 경계·오답 변이를 검사한다. 정답·조건·풀이·서술 기준을 바꾼 오염을 실제 검증기가 거절해야 한다.
- 객관식은 다섯 개의 수학적으로 구별되는 보기, 유일한 정답, 인쇄한 항목 수 이내의 개수 보기를 제공한다. 불가능한 조합은 생성하지 않는다.
- 승인된 출력 메뉴(`bank`, `arithmetic`, `studio`, `library`, `conceptBlank`) 중 하나가 있어야 기출 대비 경로가 열린다. `export` 단독은 거절한다. 원격의 `84d58378f`와 `261a5e263` 변경을 보존한다.
- 출제 → 실제 수학·그림 → 응답 표시 → 같은 조건의 출력 전 재확인까지 검증한다. `scripts/deploy/build-next.mjs`와 관련 시험·타입·소유 코드 린트를 통과한 뒤 푸시하고 해당 커밋의 Vercel 상태를 확인한다.

원문 학교 DB·수치·문구·그림은 복원하거나 생성 입력으로 저장하지 않는다. 일반 문제은행·학생 기록·SRS와 기존 원본 엔진은 보존한다. 새 문제의 내용은 기존 수식 표시 규칙을 사용한다. 화면 구성·CSS·출력 양식은 이번 작업에서 변경하지 않으며, 모양 변경이 필요하면 D-07에 따라 원장님 확인을 먼저 받는다.

선택 검토 범위의 완결은 학교 시험 전체의 대응률, 적중률, 보정한 실제 난도나 학습 효과의 측정이 아니다. 기존 미표시·미확정 원자료도 확인된 것으로 바꾸지 않는다.
