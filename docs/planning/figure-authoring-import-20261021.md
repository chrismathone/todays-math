`compile_with_repair`의 성공과 `semantic_inventory_issue(...) is None`은 검수 승인이 아니다.
후자는 전사 문자열의 라벨 목록만 대조한다. 공백·도·제곱근 표기 정규화가 가능하지만 원본 판독,
수학 관계, 범위의 완전성, 존재·유일성이나 학년을 증명하지 않는다. 빈 전사도 증거로 삼지 않는다.
검산 등록 역시 **scope/그림 key의 호출 이력**이다. SVG와 검산식이 대응하는지는 별도 검토해야 한다.
같은 key를 다시 만들었으면 현재 SVG/본문/풀이/검수 해시를 새로 묶는다.

독립 검토에서 추가로 확인한 반례도 수정했다. 각의 `ticks` 별칭은 실제 엔진이 허용하는 1/2만
변환하며 기존 `arcs`와 충돌하면 보류한다. `verify_figure`는 비유한 수/허용오차, 음수·0 길이/반지름,
퇴화 선을 검산 이력에 등록하지 않는다. 같은 key의 검산 재시도가 실패하면 이전 성공 등록을 무효화한다.
이 첫 조정은 2D 검산 함수의 방어였다. 후속 `verify_solid`의 수치/단위 법선/재시도/한 번 순회하는
조건 입력 방어와 피타고라스의 주어진 길이 표시는
[후속 체크포인트](tracks/reports/exam-engine-pytha-solid-20261021.md)에 기록한다.
어느 쪽도 전체 공간 기하·학생 학년·권리 승인은 아니다.
현재 검사·제한은 [체크포인트 보고서](tracks/reports/exam-engine-hangul-import-20261021.md)에 기록한다.

## 실제 제작에 쓰는 순서

1. 인쇄된 조건·선·점선·라벨·표를 판독하고 원본 출처는 내부 메타데이터에만 연결한다.
   학생 필기와 원문 답은 정답 근거로 삼지 않는다.
2. 공유 개념·핵심 풀이를 유지하면서 발문 구조·소재·대수/기하 표현·질문 대상을 바꾼다.
   숫자/학교명 교체만으로 완료시키지 않는다. 순수 수학에 소재를 억지로 붙이지 않는다.
3. 해당 연도·학년 교육과정, 실제 Unit UUID/live family와 선수 개념을 먼저 확인한다.
   본문·보기·그림·표기·답 형식·학생 해설·필수 풀이의 범위 밖 항목은 제외, 불명은 보류한다.
4. 조건에서 좌표를 계산한다. 그래프는 `frame` 등방 좌표, 공간 관계는 투영 전 3D 좌표로 검산한다.
   `verify_figure`/`verify_solid`는 기하 검산에 사용한다. 픽셀을 정답 계산에 쓰지 않는다.
5. FigureSpec을 우선한다. 필요한 덧그림은 `pre`/`post`의 `sh` 변환을 거친다.
   파생 답을 숫자 라벨로 노출하지 않는다. 없는 선을 추가하거나 값이 있는 치수를 삭제해 통과시키지 않는다.
6. 라벨 정자/이탤릭·단위·도·분수·근호, 잘림·겹침·halo 선 지움과 실제 화면/지면을 확인한다.
   검수 예외는 정확한 대상·이유·현재 해시와 함께 기록한다. lint 통과를 전체 완료로 세지 않는다.
7. 우리 조건에 맞는 새 그림을 보관한다. 코드로 재현하기 어려운 삽화는 imagegen 스킬과 내장 도구를 쓴다.
   스킬을 운영 앱에서 직접 부를 수 있다고 가정하지 않고 제작 자산·템플릿과 수학 조건을 연결한다.
8. 새 답/해설을 독립 풀이·검산하고 현재 원본/후보/그림/blind/검수 해시를 연결한다.
   권리/유사성·내용·학년·분류·기술 품질 상태는 분리한다. 미세 변경이 권리 허가라는 판정은 하지 않는다.

빌더의 `width_mm` 기본값(0.17mm/좌표 단위, 상한 68mm)은 **이 제작 도구의 프로필**이다.
앱의 기존 지면/CSS/인쇄 설정에 전역 적용하지 않는다. mm로 측정한 값과 실제 삽입 폭의 일치 여부는
지면 담당 세션의 검토를 거친다. `zs` 같은 비례 과장을 쓰면 이유·3D 실제 조건·투영 배율을 기록한다.
레이아웃 여백만 늘리려고 가짜 수학 점을 추가하는 원본 예시의 우회법은 기본 제작법으로 채택하지 않는다.

실행 가능한 기술 예시:

```powershell
python -B scripts/figure/example_exam_tools.py <새-출력-폴더>
python -B scripts/figure/test_vendor_tools.py
```

예시는 경로를 `engine_path.engine_root()` 한 곳에서 가져온다. 13·14·15 삼각형의 내부 높이 12를
계산·검산하지만 그림에 파생 답으로 넣지 않는다. SVG·PNG·현재 SVG 해시·폭과 `publishable=false`
manifest를 만든다. 기술 교정용이며 문항 작성/학년 검수/권리 승인/문제은행 그림 수에 가산하지 않는다.
