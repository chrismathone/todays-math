# 2-1-1 교재 디자인 재계획과 구현

> 2026-10-05 수용 상태 정정: 아래 기능 구현·발행 검증 기록과 별개로, 기존 2-1-1과 새 출력의 대응 영역 시각 검수는 **미통과**다. 대화·판서, 개념/암기의 공통 행 구조, 필기선, 예제/확인 묶음, 학습 경로와 복습·평가 기록이 원본과 다르다. [대응 영역 검수 결과와 수정 수용 기준](textbook-v15-matching-region-audit-20261005.md)에 실제 페이지 근거를 기록했다. 새로 확인한 차이의 앱 수정은 아직 수행하지 않았다.

사용자가 제공한 `인재원_KaTeX_교재조판기_v15.zip`과 `인재원_수학_2-1-1_수와식_학생용.pdf`를 디자인 기준으로 삼는다. 이전 작업은 생성 오류를 고쳤지만 원본의 지면 구성을 충분히 옮기지 못했다. 이번 작업의 완료 기준은 실제 자동 교재의 미리보기와 학생용·교사용 PDF에 원본의 디자인 체계가 적용되는 것이다.

## 구현 범위

1. 원본 자산과 지면 분석: 표지·단원 삽화와 Noto Sans KR 글꼴을 보존해 가져오고, 원본의 치수·색상·타이포그래피와 각 지면을 기록한다.
2. 공통 조판 디자인: 짙은 초록 표지, 단원 도입, 단계별 제목·옆 탭·진행 표시, 대화, 개념 정의·조건·예·오개념, 개념 암기, 대표예제·연습·평가, 쉬어가기의 지면을 구현한다.
3. 자동 구성 연결: 실제 내용에 따라 학습 단계를 명시하고 단계별 페이지를 구성한다. 대표예제도 개별 토글로 선택한다. 초3~중3의 기존 학년·학기·범위·난이도 선택과 구성 토글, 인물 선택을 유지한다.
4. 출력 검증: 저장된 실제 초3 교재와 중2 표본을 사용해 페이지 이동, 화면 폭 적응, 개념·문제 배치, 그림·수식·QR, 학생 답안 비노출을 확인한다. 실제 PDF를 생성하고 페이지를 이미지로 변환해 원본과 비교한다.
5. 통합과 배포: 독립 작업을 main에 통합하고 관련 테스트·형 검사·배포 빌드를 통과시킨다. 푸시 직전 원격을 가져와 새 커밋을 통합하고 운영 배포의 커밋과 상태를 확인한다.

## 작업 분담

- Orca `textbook-v15-assets`: 원본 디자인 분석과 원본 이미지·글꼴 자산.
- Orca `textbook-v15-render`: 공통 HTML·CSS 지면 구현.
- 기존 `testbook`: 자동 구성의 단계 투영, 페이지 배치, 자산·글꼴 로딩, 통합 검증과 배포.

## 완료 조건

- 표지의 배경·삽화·제목 위계와 본문의 단계 탭·색상·번호·개념 구성·대표예제 구획이 원본에 근거한다.
- 내용이 달라지는 초등 교재도 동일한 디자인 규칙으로 출력된다. 원본 중2 내용을 초등 교재에 복사하지 않는다.
- 기존 초안은 저장된 개념·문제·자산을 수정하지 않고 새 조판으로 볼 수 있다. 이미 발행한 PDF와 기록은 보존한다.
- 모든 글꼴·삽화는 로컬 묶음으로 제공되며 미리보기·PDF·오프라인 HTML이 같은 디자인을 사용한다.
- 내용 누락, 잘림, 겹침, 임의 빈 페이지 삽입, 학생용 문제의 정답 노출이 없다.
- 최종 검증 PDF와 실제 페이지 이미지를 남긴다. 로그인 없이 확인한 부분과 로그인 화면에서 확인한 부분을 구분해 보고한다.

## 진행 기록

- 원본과 이전 검증본의 표지·대화·개념·유형 연습 페이지를 직접 비교해 차이를 확인했다.
- 원본 ZIP을 검증한 로컬 임시 폴더에 풀었다. 원본은 변경하지 않았다.
- 최신 main을 작업 브랜치에 통합하고 두 독립 Orca 작업을 시작했다.
- 원본 표지·단원 삽화·새싹 그림 8개와 Noto Sans KR 400/700, OFL을 원본 바이트 그대로 가져왔다. 표지, 단원 도입, 대화, 개념, 암기, 대표예제, 연습·평가, 쉬어가기의 공통 지면을 구현했다.
- 대표예제와 풀이를 별도 토글로 추가했다. 자동 구성은 18가지 토글이며, 새 화면의 기본 구성에는 대표예제가 포함된다. 기존 요청의 기본 구성은 보존한다.
- 단계 제목·번호·진행 표시와 이어지는 페이지의 옆 탭을 원본 기준으로 연결했다. 기존 초안의 원고·문제 스냅샷을 수정하지 않고 렌더 투영에서만 적용한다.
- 전체 출력에서 발견한 암기 안내 반복과 쉬어가기 분량 문제를 고쳤다. 대화·암기 행의 간격을 원본의 조밀한 리듬에 맞췄으며 32쪽/600블록/시간·파일 제한은 유지했다.
- 긴 중2 대본의 오프라인 HTML에서 초상화 바이트가 반복되는 문제를 수정했다. 큰 이미지는 CSS 이미지로 한 번 저장해 재사용하며, 원래 이미지 출력과 대화 페이지들의 PNG 해시가 일치하는지 검사했다.
- 구성·페이지 배치·학생 답안 비노출·미리보기 이동 등의 12개 테스트 파일에서 153개가 통과했다. 실제 Chromium 출력·발행의 3개 테스트 파일에서 10개가 통과했다(조건부 검사 1개 제외). 전체 TypeScript와 수정 파일 ESLint도 통과했다.
- 격리 DB에서 초3와 중2의 모든 구성 토글, 소단원당 8문항, 실제 원본 PNG를 사용해 생성 → 사전 검사 → QR 예약 → 조판 → 합치기 → 펼침면/오프라인 HTML → 발행 확정과 무결성 검사를 통과했다. 공유 운영 DB에는 쓰지 않았다.
- 운영 DB의 실제 저장 초안을 읽기 전용으로 불러왔다. 16개 구획의 페이지 이동과 화면 폭 1600/820/390px에서 본문이 잘리지 않는지 실제 React 화면으로 확인했다. 운영 사이트의 로그인 상태에서 직접 생성 버튼을 누른 검사는 이번 검증에 포함되지 않는다.
- 검증 파일은 `C:/Users/user/Downloads/교재_디자인_검증_20261004/`에 보관한다. 브라우저 fixture는 비공개 원문·답안을 포함하므로 커밋하거나 최종 공유하지 않는다.
- 최종 저장 초안은 72문항·9개 개념·16개 구획이며 학생용 194쪽, 교사용 177쪽이다. 두 파일의 모든 페이지가 A4인지 검사하고 표지·단원 도입·개념·암기·문제·쉬어가기·마지막 페이지를 이미지로 변환해 직접 검토했다. 최종 간격으로 다시 실행한 실제 React의 16개 구획/3개 화면 폭 검사도 통과했다.
- 모든 구성 토글을 켠 새 초3 표본은 학생용 29쪽/교사용 25쪽, 중2 표본은 학생용 38쪽/교사용 34쪽으로 발행됐다. 이 두 표본은 격리 DB의 검증용 문제와 QR 주소를 사용한 디자인·발행 테스트 자료다.
- 독립 작업을 main에 통합했고 main에서 전체 배포 빌드가 성공했다. 기존 `figureBytes.ts`의 넓은 파일 추적 패턴에 대한 경고 2개가 남지만 컴파일·형 검사·정적 페이지 생성은 완료됐다.
- 마지막 지면 검토에서 확인한 암기 답안 조각의 경계 공백을 보존하도록 수정하고 관련 50개 테스트 및 두 학년의 실제 발행을 다시 통과했다. 병행 작업의 무관한 검토 산출물(`output/**/*.mts`)이 배포 형 검사에 유입된 현상도 확인해 `output`/`tmp` 산출물 폴더를 형 검사에서 제외했다. 앱·테스트·배포 스크립트의 검사는 유지한다.
- 첫 운영 배포 후 쿠키 없는 요청으로 새 이미지·글꼴 주소가 로그인 HTML로 돌아오는 것을 확인했다. 원본 삽화 8개·글꼴 2개·OFL의 정확한 경로에 한해 GET/HEAD를 공개 관문에 연결했다. 새 자산 관문과 기존 역할·학생·오류 처리·교재 렌더 관련 6개 테스트 파일의 87개 검사가 통과했다. 함께 실행한 기존 랩실 검사 중 `/dev/blender-assets/cuboid-fold.glb`의 원장 기대값 1개는 수정 전 운영 커밋 `a13c8642d`에서도 동일하게 실패해 이번 변경과 구분했다.
