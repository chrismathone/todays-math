### 10.1 무엇이 문제였나

- **절반 넘게는 문항이 아니라 형식 하나의 문제다.** 개념 한 장이 형식 넷에 같이 쓰이는데 형식마다 학생에게 찍히는 칸이 다르다 —
  A 는 소단원 이름만, B 는 **용어만**, C 는 **뜻 문장만**, D 는 **용어 + 예 물음만**. 은행 3차가 «난이도별 10개씩»을 채우느라 더한 개념의
  상당수가 «일반 제목 + 구체 계산 한 문장»(«단위가 있는 곱» → `$4\,\mathrm{m}$의 $0.3$배는 {$1.2\,\mathrm{m}$}이다.`)이라, C 로는 멀쩡하지만
  B 에서는 제목만 보고 숨은 수치를 써야 했고 채점 안내는 «굵은 핵심어가 다 들어가야 ○»였다.
  외부 검토의 개념 의견 1,957건 가운데 1,191건이 «원문 뜻 문장을 빈칸으로 찍어라»(= 이미 있는 C)였다.
- 확정 수학 오류 29(불가능한 삼각형 7 · 9 에서의 올림 예외 7 · 거짓 일반화 …) · 이스케이프 손상 1(지면에 «3, mathrmm») ·
  C 에서 답 방향을 못 정하는 문장 10 · D 의 예 물음이 안 보이는 뜻 문장을 가리킴 · 초3 처음 은행의 예 56개가 적용 문항을 옮긴 것 ·
  «금색»으로만 가리키는 그림 27(흑백 프린터) · 그림 속 한 글자 단위가 기울어 찍힘.

### 10.2 합의한 방침 (요지 — 표는 합의문)

| 안건 | 방침 |
|---|---|
| 형식 문제 | 채점 안내를 고친다(«굵은 부분의 뜻이 모두 있어야 ○. 말 · 식 · 단위의 꼴이 달라도 된다») + **용어 칸에 조건을 싣는다**(«$4\,\mathrm{m}$의 $0.3$배 구하기») — 뜻 문장은 그대로라 C 지면이 안 바뀐다. 40자를 넘길 때만 뜻 문장을 일반 진술로 |
| A(완전 백지) | **사례 문항은 A 채점표에 싣지 않는다** — 굵은 답이 용어에 주어진 값으로 정해지는 카드에 표지를 단다(계약 `givenCase` · 보강 파일은 줄 끝 `CASE` · 원래 파일은 파일 끝 `markGivenCases`). 수 자체가 개념인 카드(단위 환산 · 자리값)는 달지 않는다. 줄이 줄어도 채우지 않는다. 화면의 A 최대 문항 수도 표지를 뺀 수다 |
| 굵은 글이 용어뿐인 개념 | 핵심어 표기를 늘리지 않는다. 이름 대기 문장(`…을 {세로셈}이라 한다`)은 두고 B · D 채점 안내가 가른다(«굵은 글이 용어와 같으면 그 이름은 답이 아니다 …» — 그런 줄이 있는 채점표에만). 답이 새는 문장은 빈칸을 옮긴다 |
| 범위 | 핵심어에 숫자가 든 개념 4,317개 전수 판정 — «용어만 보고 굵은 핵심어를 **하나로** 정할 수 있으면 둔다» |
| 예(D) | 80자 안이면 조건을 예 물음에 다시 쓴다. 넘치면 뜻이 보편 진술일 때만 예를 뺀다. 초3 처음 은행의 예 56개는 전부 새로 쓴다 |
| 조건을 붙이는 선 | 문항의 수 · 그림 안에서 반례가 생기거나 ○× 가 갈리면 붙인다. 학년 정의가 이미 막으면 안 붙인다(각기둥 = 직각기둥 · 공정한 주사위 · 0 이 아닌 수로 나눈다) |
| 난이도 | 초4 · 초6 처음 은행은 적용 전부 «상» · ○× 전부 «중»(소단원당 하나) — **이번에는 안 건드린다**(수행 자료 없이 다시 매기면 «10개씩»이 검토자 취향으로 깨진다) |
| 후보 · 선택 개선 | 전부 원문과 대조해 고침 / 둠(까닭)을 원장에 남긴다 — 필수가 먼저 |
| 그림 «금색» | 색 말고 단서가 없는 것만 — 획(굵게 · 점선)과 물음 말을 같이 바꾼다 |
