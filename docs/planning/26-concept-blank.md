## 2. 우리가 정한 것 (리드 — 원장님이 뒤집을 수 있다)

- **문장은 우리 말로 새로 쓴다.** 교재 원문은 저장소 밖(2026-09-28 확정)이라 제품에 못 싣는다. 교재 용어 목록은
  «어떤 개념이 어느 소단원에 있나»를 정하는 **뼈대**로만 쓰고, 문장은 새로 쓴다. 누출 검사:
  `npx tsx scripts/qa/concept-blank/check-leak.ts` — 12글자 창 0(보충 카드와 같은 기준).
- **학년 범위는 초3~중3.** 교재 용어 목록(큐브수학 개념 3-1~6-2 · 개념원리 중학 1-1~3-2, 844개)이 있는 학년이다.
  초1~2 · 고등은 나무에 «준비 중».
- **난이도 뜻**(전 학년 공통):
  - **하** — 그 소단원의 기본 용어 뜻(정의). 교과서가 처음 소개하는 말.
  - **중** — 성질 · 관계 · 기호 · 헷갈리는 두 개념 가르기.
  - **상** — 공식의 까닭 · 여러 조건이 겹치는 성질 · 경계가 헷갈리는 것 · 활용.
- **순서는 고정** — 소단원은 교육과정 순서, 난이도 블록은 하 → 중 → 상, 블록 안은 은행 파일 순서.
- **같은 링크 = 같은 지면** — 고르기를 주소 `?s=`(base64url JSON)에 싣는다. 저장(DB)은 이번에 없다.
- **지면 얼굴**은 확정된 시험지(05 §8.5 — 명조 본문 · 고딕 라벨 · 금색 · 따뜻한 흰 종이 · 배점 없음)와 시안 두 벌.
