## 2. 웹 조사 — **남들의 «리포트»는 실제로 무엇으로 되어 있나**

> 🔴 **근거 세기가 다르다.** 매쓰플랫만 **제품 가이드 문서**(강함)이고, 나머지는 홍보 페이지·블로그(약함)다.
> 19번 문서의 경고를 그대로 물려받는다 — 이 절로 «누가 이기나»를 재면 안 된다.

### 2.1 매쓰플랫 — 유일하게 **항목을 규정한** 소스 (guide.mathflat.com)

- **보고서 = 페이지 조립식 7장**: `표지` · `월간분석`(선생님의견 포함 여부) · `주간분석`(난이도별분석 포함 여부) ·
  `학습내역` · `학습성과` · `진단결과` · `학습평가`. 2단계 마법사(설정 → 상세 편집), 페이지별 on/off, **문구 직접 수정**.
- **정량은 세 축뿐**: `학습량` · `등급` · `정답률` (+ `문제 수`). 진단결과 페이지에 «대표 우수 유형 / 대표 취약 유형».
- **비교군이 설정값이다**: 전국 동일 학년 평균 / 학원 동일 학년 평균 / 학원 동일 반 평균 / **미사용**.
- 🔴 **태도·집중도·참여도를 숫자로 만들지 않는다.** 정성 창구는 **«선생님의견» 한 칸**(직접 작성 또는 AI 작성)뿐이다.
- **출결은 점수가 아니다** — 등·하원 **시각** + 달력의 **초록 점**.
- **숙제는 3상태** — 채점 전 `표시 없음` / 채점 중 `풀이 중` / 채점 완료 `점수`.
- **주간 경계를 못 박는다** — 이번 주 집계는 **월요일 00:00 리셋**, 그래프는 **최근 4주**.
- **전달**: 선생님이 «학부모앱 보고서 공개하기»를 눌러야 앱에 뜬다. 학부모앱에는 **제목 + 요약**이 목록으로,
  누르면 **PDF**. 선생님 쪽에는 `공유`/`인쇄`/`다운로드`/`수정`. 월 1회 **«실시간보고서» 자동 생성** on/off.
- **말하지 않은 것**: 정답률·등급의 척도, 태도 수치화(아예 없다), **영상 시청 지표**(리포트에 들어간다는 서술 없음), 알림톡 발송 스케줄.

### 2.2 그 밖 (약한 근거)

- **에듀밸런스** — `일일학습 현황` / `주간 리포트` / `월간 리포트` 3단. «영역별 학습균형»이 핵심어인데
  **항목이 이미지 한 장**이라 글로는 못 읽었다(2015년 표기의 구형 페이지).
- **페이지콜 블로그**(원장 대상 일반론, 2024-11) — 보고서 주기는 **«주간 또는 월간»**, 성적 향상도·진도를
  **그래프·도표**로, 목표는 **SMART**, 자동 알림 네 가지(진도 지연 · 과제 미제출 · 마감 임박 · **출석 부족 경고**).
- **학원관리 8종 비교**(bati.ai) — 비교 축이 출결/결제/앱 설치 필요 여부/비용이라 **리포트 항목은 하나도 없다.**
  건질 것 하나: 소통 수단이 **문자 / 앱 메신저 / 알림장**으로 갈린다. 「소통 채널이 문자로 한정됨」이 단점으로 적힌다.
- 열지 못한 것: 강남맘 실제 학원 월간보고서(403) · 매쓰플랫 구 가이드(404).

### 2.3 교육 연구가 말하는 것 — **여기가 우리 설계를 실제로 바꾼다**

- **단일 종합 점수를 만들지 마라.** 학부모가 해석할 수 있는 영역 수는 **5~6개**이고, 표준 기반 성적표는
  스무 개 성취기준을 **대여섯 갈래로 묶어서** 보여 준다(Guskey).
- **상세를 점수 «밑»에 두면** 이해도가 올라간다. **«몇 점 만점 중 몇 점»을 같이 적으면** 계산 방식 이해가 올라간다(REL Mid-Atlantic 2021 실험).
- 지표마다 **«이렇게 계산합니다»** 안내를 붙인 주(텍사스)가 이해도가 높았다.

### 2.4 🔴 조사에서 나온 결론 둘

1. **여러 팩터를 하나의 «성취 지수»로 합치지 않는다.** 원장님 말씀의 «종합»은
   **«한 장에 모은다»**로 구현하고 **«한 숫자로 합친다»**로는 구현하지 않는다.
   합치면 가중치를 우리가 지어내야 하는데, 그 가중치를 정당화할 근거가 우리에게 없다.
2. **태도는 숫자가 아니라 문장으로 간다.** 업계 1위가 그렇게 했고(선생님의견 한 칸), 연구도 정성은 서술로 둔다.
   원장님이 «태도»를 팩터로 말씀하신 뜻은 살리되, **별 세 개짜리 점수로 만들지 않는다.**

## 4. 🔴 리포트가 **거짓말을 하게 되는 자리 넷** — 설계가 먼저 막아야 한다

1. **8문항짜리 시험지의 «단원별 정답률»은 통계가 아니다.**
   전 반이 `defaultProblemCount = 8` 이라 단원당 1~2문항이다(19번 §5′ 에서 이미 실측으로 짚었다).
   한 회차를 원 그래프로 그리면 «이 단원 0%»가 **문항 하나 틀린 것**이다.
   → **회차 단위로는 안 그린다. 기간 누적(최소 3회차 또는 12문항 이상)에서만 단원 축을 연다.**
2. **미채점이 만점으로 굳는다.** 「아직 안 봄 / 하나도 안 틀림 / 틀림」 세 상태를
   스키마가 둘로만 담는다. 이미 D-07 §5′ 가 화면 쪽에서 막았지만 **계약·DB 는 아직 안 고쳤다.**
3. **없는 팩터의 빈칸이 0으로 읽힌다.** 숙제·태도·영상 시청은 지금 0행이다.
   → 모든 팩터는 **«데이터 없음»(null)과 «0»을 반드시 구별**하고, 화면은 «아직 기록 없음»으로 적는다.
   칸이 비면 그 영역을 **아예 그리지 않는다.**
4. **비교군을 지어내지 않는다.** 우리는 전국 표본이 없다. 쓸 수 있는 비교는
   **① 본인의 지난 기간 ② 같은 반 평균(반 최대 10명 — 이것도 표본이 얇다)** 둘뿐이고,
   **«미사용»이 기본값**이어야 한다.

## 5. 리포트의 **네 영역** (제안 — 원장님 확정 전)

연구가 말하는 «대여섯 갈래»에 맞추고, 각 영역은 **한 문장 제목 + 근거 숫자 + 만점 표기**를 갖는다.

| 영역 | 무엇을 말하나 | 어디서 오나 | 지금 가능한가 |
|---|---|---|---|
| **① 무엇을 배웠나** | 이 기간에 나간 소단원 이름, 계획 대비 며칠 밀렸는지 | `Progress` · `ProgressPlan` | 🟢 **지금 된다** |
| **② 얼마나 맞았나** | 회차별 점수 추이 · 누적 단원별 정답률 · **난이도 4단 중 어디서 무너지나** · 복습이 필요한 단원 | `TestResult` · `AnalysisReport` | 🟡 **채점 화면이 생기면** |
| **③ 스스로 한 것** | 예습 영상 시청(완료/진행) · 숙제 수행 | `ConceptLectureView` · (숙제는 표 없음) | 🔴 강의 0편 · 숙제 표 없음 |
| **④ 선생님 의견** | 태도·집중·달라진 점을 **문장으로** | 새 칸(원장님이 쓰는 자유 서술) | 🔴 새로 만들어야 |

> **난이도 4단(연산·기본·응용·심화)은 경쟁사에 없는 우리 축이다.** 매쓰플랫도 «난이도별분석»은
> 있지만 우리처럼 **교육과정 소단원 × 4단 사다리**로 낸 문항이 아니다.
> 「기본까지는 되는데 응용에서 무너진다」는 말은 **학부모가 바로 알아듣는 문장**이고, 우리만 댈 수 있다.

## 7. 원장님 확정 — **2026-09-18, 넷 다 추천안** (D-134 ⑺)

| Q | 물음 | 확정 |
|---|---|---|
| **Q1** | 숙제·태도를 어떻게 기록하나 | 🟢 **«안 해온 학생만» 찍는다.** 수업 끝나고 반 명단에서 안 해온 학생만 누른다(보통 0~2명). **태도는 따로 안 찍고** 필요할 때 문장으로 적는다(§2.4 ②와 같은 결) |
| **Q2** | 학부모에게 어떻게 가나 | 🟢 **A4 한 장 인쇄.** 학부모 계정·문자 발송을 만들지 않는다 — 인쇄 자산이 이미 있고, 개인정보를 밖으로 보내지 않는다 |
| **Q3** | 주기 | 🟢 **월 1회** |
| **Q4** | «종합 점수» 하나를 원하시나 | 🟢 **합치지 않는다.** 네 영역을 한 장에 나란히. **성취 지수·가중치 칸을 코드에도 안 둔다** |

### 7.1 🔴 Q1 이 딸고 온 것 — **«안 찍음»이 «했음»으로 굳으면 안 된다**

「안 해온 학생만 누른다」는 **누르지 않은 학생이 전부 «했음»**이라는 뜻이다. 그런데 **아예 확인을
안 한 날**도 똑같이 «전원 했음»으로 보인다 — §4 ②와 정확히 같은 결함이고, 이 저장소가 여러 번 낸 자리다.
→ **반마다 «오늘 확인함»을 같이 받는다.** 확인 표시가 없는 날은 그 반의 숙제 칸이 **«기록 없음»**이고,
수행률의 분모에서 **빠진다**. (19 §5′ 가 채점에서 «전원 응시» 일괄 단추를 금지한 것과 같은 이유다.)

### 7.2 남은 것 둘 — 시안 위에서 여쭌다

- **Q0 (D-07)** — Wire **A·B·C·D** 중 어느 구조로 갈까. 네 안이 갈리는 것은 셋: 빈 영역을 어떻게 다루나 ·
  한 장인가 두 장인가 · 난이도 4단을 그림으로 말하나 문장으로 말하나.
- **Q5** — **«아직 기록 없음»을 학부모 지면에도 보일까.** 지금 실데이터로는 화면의 절반이 점선이다.
  이것이 «정직함»인지 «부실함»인지는 원장님 판단이다.

**그리고 공유 DB** — 트랙 1·4 는 새 칸/새 표가 필요합니다. 지금까지처럼 **마이그레이션은 초안까지만**
만들고, 원장님 확인을 받은 뒤 dry-run → 적용합니다.

## 8. 안 하는 것

- **출결·교육비** — PRD §5.3 범위 밖. 이걸 넣으면 학원관리 플랫폼과 정면으로 붙는다(19번 축 14).
- **학생 앱으로 푸는 채점** — 제품의 사용자가 원장 한 사람이라는 전제(PRD 페르소나)를 바꾸는 일이다.
- **전국 비교 / 석차** — 표본이 없다. 지어내면 리포트 전체의 신뢰가 무너진다.
- **단일 성취 지수** — §2.4.
- **eywa 계약 확장** — 진도 동기화가 보류 중이다(22번).
- **문자·알림톡 발송 계약** — 원장님 결정(Q2) 전에는 손대지 않는다.
