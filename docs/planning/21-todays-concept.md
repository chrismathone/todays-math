> **이 트랙의 SSOT.** 결정은 **D-123**(07 Decision Log). 여기 적은 수치·경로는 2026-09-15 에

## 0. 결정 (D-123 요약)

원장님(2026-09-15): *「오늘의 개념 으로 인강 파트 항목을 새로 파면 어떤가?」* ·
*「원래 기존에 다른 교재 인강을 훔쳐쓰는 정도였는데, 우리가 제작할 수 있으면 더 우리 프로그램에 신뢰도가 상승할듯」*

| 항목 | 확정 | 비고 |
|---|---|---|
| 보는 자리 | **원장님 화면 메뉴** + **학생 로그인 화면** | 시험지 QR·공개 채널은 이번에 안 넣는다 |
| 학생 로그인 범위 | **영상 시청 하나** | 문제 풀기·결과 보기는 이 결정 밖. 넓히려면 새 결정 (D-35 를 좁혀 연 것) |
| 대본 원료 | **우리 것으로 새로** | 2022 성취기준 + 우리 엔진 문항류(D-120)·예제 → AI 초안 → 원장님 검수 |
| 목소리 | **미정** | 원장님 녹음 또는 상업 이용 허락된 유료 TTS. 같은 한 편으로 비교 후 결정 |
| 화면·화풍 | **D-07 절차** | Wire 4~5안 → Hi-fi 4~5안. 메뉴 이름 «오늘의 개념» 은 원장님이 지으셨다 |
| 화면·운영 10가지 | **D-124** — 원장님 화면 B(이번 주 진도 먼저) · 학생 화면 C(목록 → 재생) · 학생 로그인 **아이디 + 비밀번호**(원장님 발급, 한 명씩) · 앞으로 감기 막음 · AI 고지 원장님만 · 시청 기록 모음 · 게시 전 시청 **권장** · 목록 **공용** · 메뉴 «수업 · 학생 관리» 아래 | Wire 5안의 «정할 것»에 보내 주신 답. 색·글꼴은 Hi-fi(05 §8.9) |
| 🔴 **지금 할 일** | **«이전»만** — 생성기(도구) + 수맥의 강의 화면·자료 구조 | 같은 날 좁혔다(D-123 ⑹): *「그냥 이전하고 싶은데, 지금 다 강의 만드는건 아니지?」* **새 강의는 지금 안 만든다.** 기존 8편은 옮기지 않는다. 대본 원료(③)는 멈춤 |

**왜 이 제품에 맞나** — 제품 축이 `진도 → 오늘의 시험지`인데, 같은 차시(`Unit`)에 영상을 붙이면
`진도 → 오늘의 시험지 → 오늘의 개념`이 된다. 예제를 그날 시험지와 **같은 문항류**에서 뽑으면
영상과 시험지가 이어진다.
