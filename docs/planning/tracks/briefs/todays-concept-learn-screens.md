## 1. 만들 것

### 1.1 학생 화면 네 장 (`/learn/**` — 휴대폰이 먼저)

학생은 대개 **휴대폰**으로 본다. 시안의 휴대폰 틀이 기준이고, 넓은 화면에서는 가운데 한 줄로 선다.

| 주소 | 시안 | 부르는 것 |
|---|---|---|
| `/learn/login` | `sLogin` — 로고 · 아이디 · 비밀번호 · «들어가기» · 도움말 · «원장님 로그인 ›»(`/login` 으로) | Auth.js `student` 공급자 (`/api/learn/login`) |
| `/learn/password` | `sPw` — «처음 들어왔습니다» · **받은 번호** · 새 비밀번호 · 한 번 더 · 규칙 · «바꾸고 들어가기» | `POST /api/learn/password` |
| `/learn` | `sList` — 윗줄(이름 · 반 · 나가기) · «오늘의 개념» · **남색 판**(가장 최근 수업) · 흰 카드(지난 수업) | `GET /api/learn/lectures` |
| `/learn/watch/<id>` | `sPlay` — «‹ 목록» · 재생기 · 제목 · 차시 · 상태 · 감기 안내 · 다음 영상 | `GET /api/learn/lectures/{id}` · `POST /api/learn/watch` |

- **비밀번호 칸은 숫자 4자리**(D-125 ⑶) — 시안의 «8자 이상 · 영문과 숫자» 규칙 줄은 시안이 D-125 전에 그려진 것이라
  **`숫자 4자리 · 같은 숫자 반복·연속 숫자 안 됨 · 두 칸이 같음`** 으로 바꾼다(판정은 계약의 `studentNewPinSchema` — 다시 적지 않는다).
  `inputmode="numeric"` · `autocomplete`(로그인 `current-password`, 바꾸기 `new-password`) · 4자에서 멈춤.
- 🔴 **첫 로그인 화면에 «받은 번호» 칸을 둔다**(D-126 ⑹ — 원장님 확정) — 받은 번호 · 새 번호 · 한 번 더, 숫자 4자리 세 칸. 받은 번호 칸이
  맨 위, 이름표 «선생님께 받은 번호». API 는 이미 지금 번호를 요구한다(`currentPassword`) — 서버는 그대로.
  잠금(5회 10분)이 이 칸에도 걸린다는 것을 틀렸을 때의 문구로만 알린다(서버 문구 그대로).
- **목록의 묶음은 수업 날짜다** — 시안은 «9월 15일 오늘» · «9월 12일» 처럼 **그 차시를 수업한 날**로 묶는다. 지금 `GET /api/learn/lectures` 는
  차시·강의만 돌려주고 날짜가 없다 → 차시마다 **그 학생의 반 진도 · 개인 진도에서 그 차시가 기록된 가장 최근 날짜**를 더한다.
  계산은 `loadStudentLectureScope` **한 곳**에서(목록과 기록의 판정이 갈라지지 않게 — `student-auth` §2.5). 계약(`learnUnitSchema`)에 칸 하나.
  남색 판 = 가장 최근 수업 날짜의 차시. **«오늘» 표시는 그 날짜가 오늘(학원 시간 KST)일 때만** — 어제 수업이면 날짜만. 요일은 달력이 정한다
  (시안의 «9월 15일 (월)»은 틀렸다 — 2026-09-15 는 화요일).
- 강의 칸의 그림은 **종이 판서 바탕에 제목**(원장님 판과 같은 모양) — 유튜브 썸네일을 끌어오지 않는다.
- 상태 알약: `새로` · `64% 봄` · `끝까지 봄`(서버가 센 % — `student-auth` §2.5). 학생 화면에 **AI 고지 · 잡 ID 없음**(D-124 ⑹, 이미 DTO 가 뺀다).

### 1.2 재생기 — 🔴 앞으로 감기는 본 곳까지만 (D-124 ⑸)

- 유튜브 **nocookie** + IFrame Player API. 앞으로 감기는 **본 최대 지점까지만**, 뒤로 감기 · 배속은 된다. 한 번 끝까지 본 영상은 어디든.
  시안의 안내 문구 셋(처음 · 보는 중 · 끝까지 본 뒤)을 그대로.
- 막는 규칙은 **순수 함수 한 곳**(예: `clampSeek(target, maxWatched, completed)`)에 두고 시험한다 — 재생기 배선은 그 함수를 부른다.
  우회 방지가 목적은 아니다(D-124 ⑸) — 평범한 학생이 건너뛰지 않게 하는 정도.
- 시청 보고: 재생 중 일정 간격 + 멈춤 · 끝 · 창 닫기(`visibilitychange`/`pagehide`)에 `POST /api/learn/watch`. 서버가 %를 다시 센다.
  보고 간격 상수는 한 곳. 실패는 조용히 다시(다음 보고가 덮는다) — 학생 화면에 오류를 띄우지 않는다.
- 유튜브 API 스크립트는 재생 화면에서만 부른다. 적재 실패(학교 망 차단 등)면 «영상을 불러오지 못했습니다» 한 줄 + 다시 시도.

### 1.3 원장님 발급 칸 (`수업 · 학생 관리` › 학생 — 기존 화면 안의 새 칸)

- 시안 `issue()` 의 두 상태 — **발급 전**(아이디 칸 + «계정 만들기») · **만든 직후**(아이디 · 발급 날짜 · 발급한 사람 · 마지막 로그인 ·
  «초기 비밀번호 — 지금 한 번만 보입니다» 상자 · «비밀번호 다시 발급» · «계정 끄기»).
  기존 명단 `src/components/class/StudentList.tsx`(`ClassManage`) 안에 붙인다 — 한 명씩(D-124 ⑷).
- **아이디는 원장님이 직접 적는다**(D-125 ⑵) — 칸은 비어서 시작하고 자동 제안 없음. 형식 안내 한 줄(영문·숫자·-·_ 4~20자). 겹치면 서버 문구 그대로.
- 초기 비밀번호(숫자 4자리)는 **응답에서 받은 그 화면에만** — `localStorage`·`sessionStorage`·URL·로그 어디에도 남기지 않는다.
  화면을 벗어나면 사라진다(시안 문구 «저장하지 않아 다시 볼 수 없습니다»).
- 끈 계정은 «계정 켜기»(시안에 없는 상태 — 최소한으로, 보고에 적는다). 퇴원한 학생(아래 §1.4)은 칸에 «퇴원 — 로그인 막힘» 한 줄.
- 발급 API 는 `student-auth` 가 만든 `/api/students/[id]/account` · `/password` 를 부른다 — 새로 만들지 않는다.

### 1.4 서버 쪽 작은 고침 둘 (원장님 확정 · 리드 결정)

- 🔴 **퇴원한 학생은 로그인을 막는다**(D-126 ⑺ — 원장님 확정) — `Student.eywaWithdrawnAt` 이 찍힌 학생은 **꺼진 계정과 똑같이** 군다:
  맞는 번호도 «아이디 또는 비밀번호가 맞지 않습니다.», 실패 수에 들고, 이미 들어와 있던 세션은 **다음 요청에서 끊긴다**
  (`auth.ts` 의 학생 토큰 다시 읽기 — `loadStudentAccountForToken` 에 퇴원 칸을 더해 `studentTokenFor` 가 판정). 판정은 **한 함수**
  (예: `studentAccountBlocked(row)` — 꺼짐 ∪ 퇴원)로 두고 로그인 · 토큰 · 비밀번호 바꾸기가 같이 부른다. 변이 시험 대상.
  ⚠️ `auth.ts` 는 학생 갈래의 이 한 곳만 — 원장 갈래는 한 줄도 바꾸지 않는다(`authDirectorUnchanged.test.ts` 가 잠근다).
- **없는 아이디 실패 행 정리**(리드 결정, `student-auth` §8-1) — `student_login_miss` 는 쌓이기만 한다. 없는 아이디 실패를 적을 때
  `updated_at` 이 **하루 넘게 지난 행**을 한 번에 최대 100행 함께 지운다(따로 도는 작업 없이). 경계 시험: 23시간 59분 남김 · 24시간 1분 지움.

## 2. 하지 말 것

- 🔴 **공유 DB 에 쓰지 않는다** — 시험용 학생 계정·강의·시청 기록을 넣지 않는다(원장님 화면에 그대로 보인다). 마이그레이션 명령 금지.
  학생 계정 표(`student_account` · `student_login_miss`)는 **2026-09-15 공유 DB 에 적용됐다**(빈 표) — 그래도 쓰지 않는다. 시험은 대역.
- 스키마 변경 금지(위 §1.4 는 칸을 더하지 않는다 — `Student.eywaWithdrawnAt` 은 이미 있다).
- `proxy.ts`·`studentRouteAccess.ts` 는 **허용 목록에 줄을 더하는 것만** — 학생 화면에 서버 액션을 넣으면 그 페이지 POST 를 적어야 열린다
  (student-auth §2.2). 가능하면 서버 액션 없이 `/api/learn/**` 만 쓴다. 로그아웃도 `POST /api/learn/logout`.
- 시안에 없는 모양을 만들지 않는다(D-07). 까닭이 생기면 멈추고 보고한다. 왼쪽 색 막대 금지. 행 hover·카드 손가락 커서 금지(D-30).
- **푸시 금지** — 리드가 검수 후 병합한다.

  문구 «잠김 — N분 뒤 풀림 · 비밀번호를 다시 발급하면 바로 풀립니다.» 끈 계정 · 퇴원 계정에는 안 보인다(그쪽 줄이 먼저).
  경계 시험: 잠금 끝 1초 전 «1분» · 끝난 뒤 줄 없음 · 다시 발급 뒤 줄 없음.
- **리드 결정 — 퇴원 학생에게는 발급 API 도 막는다**(보고서 §7-3) — `POST /api/students/{id}/account`(발급) · `…/password`(다시 발급) ·
  `PATCH …/account`(켜기)가 퇴원 학생이면 **409** «퇴원한 학생은 계정을 만들 수 없습니다.»(다시 발급 · 켜기는 같은 결의 문구). 끄기는 된다.
  화면은 이미 칸을 안 그린다 — 서버가 **같은 판정**을 한다(`studentAccountBlocked` 의 퇴원 쪽을 부른다 — 새 판정 금지).
