## 1. 만들 것

### 1.1 메뉴와 보기

- `WORKSPACE_MENUS` 에 `오늘의 개념` 을 **«수업 · 학생 관리» 아래**에 더한다(D-124 ⑽). 메뉴 권한(`disabledMenus`)도 다른 메뉴와 같이.
- 첫 화면 = 시안 1안 그대로: 머리(제목 · 날짜 · `전체 차시 735` · `meta.json 으로 등록`) → 요약(이번 주 닿는 차시 수 ·
  게시 · 초안만 · 영상 없음) → **반별 표**(반 · 최근 진도 · 강의 · 다음 차시 · 강의 · 끝까지 본 학생) + **오른쪽 차시 판**
  (강의 목록 · 영상 한 장면 자리 · 게시 조건 · 버튼).
- «이번 주 닿는 차시» = 원장님 소유 반마다 **최근 진도 차시와 그 다음 차시**(`Progress` 최신 행 · `Unit.orderIndex` 다음).
  퇴원 학생·연계 밖 반의 처리는 기존 화면(`TeachingView`·`오늘의 작업`)과 **같은 함수**를 쓴다 — 새로 판정하지 않는다.
- `전체 차시 735` — 학년 › 단원 › 차시로 전부 펼치는 보기(차시마다 강의 상태). 가장 긴 차시 이름에서 줄이 깨지지 않는지.

### 1.2 강의 등록·게시 (관리자만)

- 강의 목록은 **서비스 공용**(D-124 ⑼) — 모든 원장 계정이 같은 강의를 **보고**, 등록·게시·내리기·«끝까지 봤다»는
  **`isAdmin` 만**. 관리자가 아니면 버튼 대신 «관리자만 바꿀 수 있습니다» 한 줄.
- `meta.json 으로 등록` — 붙여넣기 칸 → `lectureMeta` 로 해석 → **초안**. 실패는 해석기가 낸 «왜»를 그대로 보인다.
  차시는 meta 의 `unitCode` → 없으면 지금 고른 차시.
- 게시 조건은 `publishGate` 의 결과를 그대로 그린다 — 막는 것(✗)과 알리는 것(!, «끝까지 보기 — 권장»)을 나눠서.
  «끝까지 보지 않아도 게시할 수 있습니다 — 권장입니다.»(D-124 ⑻)
- 영상 자리: 유튜브 nocookie 임베드(주소가 있을 때). 원장님 쪽 재생기는 **앞으로 감기를 막지 않는다** — 막는 것은 학생 쪽(D-124 ⑸).
- «AI 보충 강의» 고지는 이 화면에만(D-124 ⑹).

### 1.3 끝까지 본 학생 · 안 본 학생 이름 (D-125 ⑹)

- 반 × 강의 → `watchSummary` 의 n/m. 누르면 **아직 안 본 학생 이름**이 펼쳐진다. 원장님 소유 반만, 퇴원 학생 제외.
  n/m 과 이름 목록은 **같은 모집단 함수**에서 나와야 한다(시험으로 못 박는다 — 수가 어긋나면 빨개지게).
- 지금은 학생 로그인이 없어 시청 기록이 비어 있다 — 0/m 이 정상이다. 빈 상태 문구를 둔다.

### 1.4 서버 쪽

- 라우트 핸들러(`/api/concept/**`) 또는 서버 액션 — 기존 관례를 따른다. 모두 세션 확인 + **반 소유 확인**(`Class.userId`) +
  쓰기는 `isAdmin` 확인. 계약은 `src/contracts/` 에 Zod 로.
- 강의·시청 표(`concept_lecture` · `concept_lecture_view`)는 **공유 DB 에 아직 없을 수 있다**(원장님 확인 전 미적용).
  🔴 공유 DB 에 마이그레이션을 적용하지 않는다. 시험은 모킹 + **로컬 DB**(`docker compose up -d` 가 되면)로 한다.
  로컬 DB 도 없으면 E2E 는 건너뛰고 보고에 적는다 — «환경 문제»로 끝내지 말고 무엇을 못 봤는지 적는다.
