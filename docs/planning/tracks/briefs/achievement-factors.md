# 브리프 — 성취 팩터 집계 + 리포트 시안 (D-134 트랙 2)

확정: **23 §3**(팩터 인벤토리 — 무엇이 있고 무엇이 0행인가) · **23 §4**(리포트가 거짓말하는 자리 넷) ·
**23 §5**(네 영역) · **23 §2.3~2.4**(웹·연구 조사 결론 — **단일 지수 금지 · 태도는 문장**) ·
**05 §0-3**(Wire 4~5안 → 선택 → Hi-fi 4~5안). **먼저 읽어라.**

## 0. 왜

「학생이 지금 어디까지 와 있나」를 우리 웹앱의 팩터로 말할 수 있는가 — 원장님 물음이다.
조사해 보니 **팩터 넷 중 숫자를 댈 수 있는 것은 «진도»(722행) 하나**다(23 §1.1).
그래서 이 트랙이 먼저 해야 할 일은 그림이 아니라 **«무엇을 정직하게 말할 수 있는가»를 코드로 못 박는 것**이다.

## 1. 만들 것

### 1.1 팩터 수집 — 순수 함수 (`src/lib/achievement/`)

한 학생 × 한 기간(`from`~`to`)의 팩터를 모은다. **DB 접근은 호출자가**, 이 층은 **순수 함수**로.

| 영역 | 팩터 | 출처 | 🔴 결측 규칙 |
|---|---|---|---|
| ① 무엇을 배웠나 | 이 기간에 나간 소단원 이름 목록 · 차시 수 | `Progress` | 진도 행 0 → `null` |
| | 계획 대비 밀림(일) | `ProgressPlan` vs `Progress` (D-129) | 계획 없음 → `null`(**«0일 밀림»이 아니다**) |
| ② 얼마나 맞았나 | 회차별 점수·만점 | `TestResult`(결시 제외) | 채점 0건 → `null` |
| | **누적** 단원별 정답률 | `AnalysisReport.unitScores` 합산 | **문항 12개 미만인 단원은 내지 않는다** |
| | **난이도 4단별 정답률**(연산·기본·응용·심화) | `difficultyDistribution` 합산 | 4단 중 문항 0인 단은 `null` |
| | 복습이 필요한 단원 | `recommendedUnits` | 없으면 빈 배열(≠ null) |
| ③ 스스로 한 것 | 예습 영상 — 완료 편수 / 대상 편수 · 평균 시청률 | `ConceptLectureView` | **대상 강의 0편 → `null`** |
| | 숙제 | **표가 없다** | 언제나 `null` — 자리만 비워 둔다 |
| ④ 선생님 의견 | 자유 서술 | **아직 칸이 없다** | `null` |

- 🔴 **`null`(기록 없음)과 `0`(기록이 있는데 0)을 절대 섞지 마라.** 타입으로 강제하고,
  **두 경우를 각각 거는 시험을 반드시 써라.** 이 저장소가 여러 번 낸 결함이다
  (20번 «칸이 없다»를 0점으로 채우면 · «가드가 0을 내면 «없다»가 아니라 «못 센다»일 수 있다»).
- 🔴 **최소 표본을 함수가 지킨다.** 전 반이 8문항이라 한 회차의 단원 정답률은 단원당 1~2문항 —
  통계가 아니다(19 §5′ 실측). **누적 문항 12개 미만인 단원 축은 산출물에서 뺀다**(숨기는 게 아니라
  «표본 부족»이라는 값으로 낸다 — 화면이 그 이유를 적을 수 있게).
- 🔴 **팩터를 하나의 점수로 합치지 마라**(23 §2.4). 가중치를 정당화할 근거가 우리에게 없다.
  «종합»은 **한 장에 모으는 것**이지 **한 숫자로 합치는 것**이 아니다.
- **비교군**: 기본값 **«미사용»**. 열어 둘 것은 ① 본인의 지난 같은 길이 기간 ② 같은 반 평균(반 최대 10명 —
  **표본 수를 반드시 같이 낸다**) 둘뿐. **전국·석차는 만들지 마라** — 표본이 없다.
- 기간 경계: **주 시작은 월요일 00:00**(매쓰플랫도 그렇다 — 23 §2.1). 경계 함수 한 벌만 두고 모두가 그것을 쓴다.

### 1.2 API — `GET /api/students/{id}/achievement?from=&to=`

- 계약 `src/contracts/achievement.contract.ts` 를 **먼저** 쓴다(strict). 모든 팩터가 `.nullable()`.
- 소유 범위는 `src/lib/ownerScope.ts` 의 `requireOwnedStudent` 하나만 묻는다(D-130) —
  라우트에서 `isAdmin` 을 새로 읽지 마라.
- 조회는 **학생 한 명당 쿼리 한 묶음**. 단원 이름은 `Unit` 을 한 번에 `in` 으로.
- **마이그레이션 없음** — 이 트랙은 **읽기만** 한다. 공유 DB 에 아무것도 안 쓴다.

### 1.3 🔴 Wire 4~5안 — `/dev/report-wire` (D-07)

원장님께 보여 드릴 **4~5안**. 한 페이지 안에서 탭으로 가른다(`/dev/retry-wire` 관례).
**안마다 반드시 답해야 하는 물음 셋**:

1. **비어 있는 영역을 어떻게 다루나** — 지금 실데이터는 ③④가 통째로 비어 있다.
   빈칸을 0으로 그리면 거짓말이다. «아예 안 그린다» / «아직 기록 없음이라 적는다» / 다른 답 — 안마다 다르게.
2. **한 장인가 두 장인가** — 원장님이 보는 화면과 학부모가 보는 지면은 담는 깊이가 다르다.
3. **난이도 4단을 어떻게 말하나** — 「기본까지는 되는데 응용에서 무너진다」는 **우리만 댈 수 있는 문장**이다
   (경쟁사에 이 축이 없다 — 23 §5). 이것을 그림으로 말할지 문장으로 말할지.

- 🔴 **두 가지 상태를 나란히 보여라.** ⓐ **지금 실데이터**(진도만 있고 나머지 비어 있음) ·
  ⓑ **채점과 영상이 다 찬 뒤**의 모습. ⓑ 는 지어낸 값이므로 **화면에 «예시 데이터»라고 적어라.**
  ⓐ 없이 ⓑ 만 보여 주면 원장님이 «이미 되는 것»으로 읽으신다.
- 실데이터는 **가장 두꺼운 학생**으로 세운다(진도 722행 중 최다 보유 학생). 픽스처를 지어내지 마라
  — 2026-08-19 에 작은 픽스처로 세운 시안이 실제 화면에서 밀렸고 원장님이 스크린샷으로 잡아 주셨다.
- 문구는 **학부모가 읽는다** — 전문용어 금지(「정답률 62%」보다 「10문제 중 6문제」쪽이 가깝다).
  D-08(간결·사무적) 은 그대로. 어포던스 D-30.
- ⚠️ **아무것도 안 바꾼다** — 시안 화면은 읽기 전용이다.

## 2. 안 하는 것

- 🔴 **채점 입력 화면** — 트랙 1(`grading-input`)이 지금 만든다. `TestResult`·`ProblemAnswer` **스키마를 건드리지 마라.**
  트랙 1이 `gradingMode`·`absent` 를 더하고 `score` 를 nullable 로 바꾼다 — 네 계약은 **«결시면 점수가 없다»를
  이미 전제**하고 쓰되, 스키마 파일은 손대지 마라(리드가 병합한다).
- 🔴 **숙제·태도 표 만들기** — 원장님 확정 대기(23 §7 Q1). 자리만 `null` 로 비워 둔다.
- 🔴 **학부모 지면 확정·PDF·발송** — 원장님이 Wire 를 고르신 뒤 Hi-fi 로 간다(23 §7 Q2·Q3).
- **공유 DB 쓰기 · 마이그레이션 · eywa · 인쇄 지면 · 단일 성취 지수.**
- 시안에 없는 모양을 지어내지 마라 — 막히면 **가장 작게** 두고 보고서 ⑥에 적어라.

## 3. 시험 · 검수

- TDD(RED→GREEN). 팩터 함수는 **짝으로** 건다:
  - **«기록 없음»과 «0»** — 진도 0행 vs 0차시, 채점 0건 vs 0점, 강의 0편 vs 시청률 0%. **네 쌍 전부.**
  - **표본 문턱** — 문항 11개인 단원은 안 나오고 12개면 나온다(경계 두 방향).
  - **계획 없음** 이 «0일 밀림»으로 안 샌다.
  - **결시**가 점수 평균·추이에 **안 들어간다.**
  - 주 경계 — 월요일 00:00(일요일 23:59 와 월요일 00:00 이 다른 주).
  - 합산 — 회차 셋의 단원별 정답률이 **회차 평균이 아니라 문항 합산**으로 나온다(가중치가 다르다).
- API 시험 — 계약 strict · 남의 반 학생은 404/403(D-130 짝 시험) · 기간 뒤집힘 400.
- 변이 하네스 `scripts/qa/mutate-achievement.ts` — 관례는 `scripts/qa/mutate-plan-screen.ts`
  (앵커 **정확히 한 번** · `--anchors` 수 · 커밋된 상태에서 · 끝나면 «원본과 일치» 바이트 복원).
  🔴 **`rmSync` 금지.** 새 가드 최소 다섯: null↔0 · 표본 문턱 · 결시 제외 · 주 경계 · 합산 방식.
- 🔴 **실물 브라우저로 한 번** — `/dev/report-wire` 네 탭을 넓은 폭·휴대폰 폭(390)으로 캡처 →
  `scratch/report-wire/`. 원장님께 그대로 보여 드릴 그림이다.
- 관문: `npx prisma generate` → `tsc --noEmit` 0 · 관련 시험 · `npm run lint` · `npm run lint:affordance` · `npm run build`.
