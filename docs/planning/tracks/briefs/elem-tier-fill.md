## 1. 무엇을 만드나

내 학년의 **남은 대단원**에 `심화중`·`심화상` 갈래를 세운다.

```
파일        src/lib/elementary/g{3,4,5,6}.ts        ← 내 학년 것만 고친다
등록        supportedTiers 가 그 갈래를 돌려주게
안 채우면    **비운다** — 근거를 한 줄 남기고. 억지로 세우지 않는다.
```

🔴 **비우는 것은 실패가 아니다.** D-115 ⑹ 이 「비우는 단위는 학년이 아니라 소단원」이라
   못 박았고, 반증 ④ 는 「연산·기본·응용 중 하나라도 이 잣대를 통과하면 그 소단원에서는
   이 축이 난이도를 안 가른다 — **채우지 말고 비운다**」다.
   토대 §3 이 이미 「없다」라 적은 자리가 여럿이다. 그걸 뒤집으려면 **측정**을 대라.

## 2. 잣대 — D-115 를 글자 그대로

```
심화하 (기준선, 안 건드림)  되짚기 사슬의 마디마다 값이 **하나로 굳는다**
심화중                      굳지 않는 마디가 **하나** 있고, **그 소단원의 성질**이 굳힌다
심화상                      성질로 **못 굳혀** 실제로 **만들어 견주어야** 하나가 남고,
                            그 후보를 **발문이 주지 않는다**

⑾ (2026-08-31)  굳히는 성질이 후보를 «끝까지 계산하지 않고» 걸러 내면 **중**,
                 후보를 실제로 **다 계산해 견주어야** 하면 **상**.
                 🔴 **판정의 참은 «해설이 밟는 길»이다** — 생성기가 아니다.
```

### 반증문 여섯 — 하나라도 참이면 그 배정이 틀렸다

```
① 모든 마디가 하나로 굳으면 → 심화하
② 굳지 않는 마디가 소단원 성질 **한 번**으로 굳으면 → 심화중
③ 굳히는 근거가 **그 소단원 개념이 아니면** 그 소단원 문항이 아니다
④ 🔴 같은 소단원의 연산·기본·응용 중 하나라도 이 잣대를 통과하면 → **비운다**
⑤ 「모두 몇 가지」를 지워도 답이 그대로면 그 열거는 등급의 근거가 아니다
⑥ 순방향으로만 적용해 답이 나오면 중·상이 아니다
```

### 🔴 기각된 축 — 다시 꺼내지 마라

**«후보를 열거하는가»** 는 2026-08-30 에 **측정으로 기각됐다**(D-115 ⑵).
열거 축은 갈래를 1.5~2배로만 가르고(초4는 이미 뒤집혔다), 열거형 심화하 76건이
평균 **0.39 걸음**으로 그 소단원의 **연산(0.79)보다도 얕다.**
「모두 몇 가지입니까」로 위 칸을 만들면 **가장 얕은 것을 위로 올리는** 것이다.

## 3. 🔴 겹침 — 적대 검토가 가장 크게 짚은 것

**12묶음 중 여덟이 서로를 모른 채 같은 다섯 문형을 각자 «우리 재료»라 불렀다.**
학생이 보는 것은 대단원이 아니라 **한 장의 시험지**다. 그래서:

```
㉠ 내 대단원에 손대기 전에 **토대 §2 의 내 학년 검토**를 읽고, 거기 적힌
   «가르는 법 / 권고»를 그대로 따른다. 뒤집으려면 측정을 대라.
㉡ 「잘못 …했더니」는 **포장이지 재료가 아니다.** 이미 초4 심화하 62자리 중
   17.7%(11자리)가 그것이다. 위 두 칸에서 다시 쓰지 마라 —
   마디를 여는 방식을 **「무엇을 안 말해 주는가」**로 바꿔라.
㉢ 새 갈래를 세우기 전에 **그 소단원의 심화하 실물을 먼저 뽑아 읽어라.**
   같은 문형이면 낱말만 바뀐 같은 문항이다(D-66⑸).
㉣ 형제 소단원(1-2-4 ↔ 1-2-5 같은 짝)의 발문이 같아지지 않게 하라.
```

## 4. 판정기 — 만들면서 **계속** 돌린다

```bash
# ⑴ 내가 세운 것이 잣대를 지키나
npx tsx scripts/qa/probe-elem-tier-backsolve.ts 초N
npx tsx scripts/qa/probe-elem-tier-enumeration.ts 초N     # 🔴 새 자 (D-115 ⑾)
npx tsx scripts/qa/probe-elem-tier-ladder.ts 초N          # 사다리가 오르나
npx tsx scripts/qa/probe-elem-extending-tiers.ts          # 남은 수 세기

# ⑵ 실데이터 쓸기 — 관문이 부르는 것 전부
node scripts/qa/sweep-elem-probes.mjs

# ⑶ 관문
npm run test
```

### ⚠️ 판정기를 **읽는 법** — 2026-08-31 에 고친 자리

`probe-elem-tier-backsolve` 의 ④ 는 **선별기**다. 과잉 검출하도록 설계됐고
출력이 「채우기 전에 **사람이 본다**」로 끝난다. 그리고 그 자는 아직 **눈이 먼 데가
둘** 있다 — ㉠ 순수 덧뺄셈 ㉡ 나눗셈(허용 꼴이 전부 `a×b…` 라 ÷ 가 통째로 없다).
그래서 판정을 **「진짜 후보」와 「④ 를 못 재는 자리」로 갈라** 찍는다.
**「못 잼」 쪽의 «안 닿는다»는 근거가 아니다.** 거기서는 손으로 읽어라.

`probe-elem-tier-enumeration` 은 **막지 않고 센다.** 심화상에서 늘어놓는 것은 정상
(실측 81.0%)이고, **심화중인데 늘어놓으면** 갈래가 틀렸거나 해설이 먼 길이다 —
기계가 못 정한다. 네 새 갈래가 거기 뜨면 **네가 판단해서 보고서에 적어라.**

## 5. 이 저장소가 데인 자리 — 되풀이하지 마라

```
· **0 은 «깨끗»과 «못 셈»을 안 가른다.** 판정기를 새로 만들면 **일부러 걸리는 입력**을
  넣어 빨개지는 것을 먼저 보아라.
· **가드는 망가뜨려 봐야 가드인 줄 안다.** 변이 순서는 ⑴ 파일이 바뀌었나
  ⑵ **산출물이 바뀌었나** ⑶ 그제서야 시험이 빨개지나.
· **판정이 놀라운 값을 내면 «재는 쪽»을 먼저 의심하라.**
· **역슬래시가 든 코드는 Edit 도구로.** heredoc 이 한 겹 벗긴다(`\times` → 탭).
· **시험은 «축 전체»가 아니라 «그 소단원이 내는 갈래»를 돈다** —
  `src/__tests__/helpers/elemTiers.ts` 의 `tiersOf`·`expectCoreTiers` 를 써라.
  핵심 넷을 손으로 적으면 채운 뒤에 검사가 안 따라온다.
· **새 파일은 만들자마자 커밋하라** — 다중 세션에서 미커밋 새 파일은 되살릴 데가 없다.
· 🔴 **훅을 우회하지 마라** (`--no-verify`). 막히면 그 까닭을 **리드에게 알려라** —
  우회하고 「나중에 손으로 맞췄다」고 적지 마라. 그 말은 검산되지 않으면
  우회한 것과 같은 자리로 돌아간다(2026-08-31 물결 2에서 실제로 한 번 났다.
  그 회차의 보정은 참이었지만, 검산하는 데 리드의 회차가 하나 들었다).
· **DB 에 쓰지 마라** (읽기만). `ALLOW_SHARED_IMPORT` 를 켜지 마라.
  적재는 리드가 전부 끝난 뒤 한 번에 한다.
· 문형(D-114, 10→12)은 **이번 물결에서 안 한다.** 갈래만 세운다.
```
