## 왜 · 무엇을

원장님 2026-10-01: «hifi 시안도 3종 AI들이 눈으로 본 다음에 협의 도출한 방향으로 진행해».
Wire 는 3자 합의로 골랐다(consensus §4): **새 화면(수업 관리의 셋째 탭) · 사유 목록이 주인 · 학생은 한 번씩 · 한 줄 문장 · 펼치면 밀린 · 막힌 카드만 · 5칸 띠 없음 ·
갈래 거르개 없음(학교급과 반만) · 0명 사유 숨김 · 사유 없는 학생은 «기준 아래»로 접어 둠 · 계정 없는 학생은 운영 확인 줄에 학습 사유 딱지 · «오래 쉼»과 «복습이 밀림»은 둘 다 보이고 밀림이 줄의 주인 ·
문턱 v1.1 은 «잠정»이라고 목록 가까이에 기준을 보임 · «봤음» 닫기 없음 · 차례 0 «상한에 닿아 선생님과 확인»은 2단계 빈 자리**.

이 Wire 의 **Hi-fi 4~5안**을 한 HTML 로 만든다 — `docs/design/mockups/hifi-explorers-teacher.html`. 구현이 아니다. 리드 · codex · grok 이 **그림을 눈으로 보고** 고를 재료다.

## 안을 가르는 축 (안마다 적어도 둘이 달라야 한다 — 색만 바꾼 안은 안이 아니다)

1. **사유의 모양** — (가) 한 줄 문장(합의 2:1) (나) 딱지 + 값 + 단원 이름을 칸으로(grok 의 반대안 — 문장 틀이 자료와 따로 산다는 걱정). **두 모양이 다 있어야 한다**(눈으로 가르기로 했다).
2. **위쪽 요약** — 요약 칸 넷(지금 교사 화면과 같게) / 한 줄 요약(폰에서 이름이 먼저 보이게).
3. **목록의 결** — 차례대로 이어진 한 목록 / 앞선 사유가 바뀌는 자리에 얇은 머리(학생은 여전히 한 번씩).
4. **펼침** — 줄 안에서 펼침 / PC 에서만 오른쪽 칸(초등 «오늘의 기억» 상세와 같은 자리) · 폰은 줄 안.
5. **밀도** — 한 학생 블록의 높이(두 줄 / 세 줄). 네 줄은 안 된다.

## 지켜야 하는 것

- **제품의 실제 얼굴로** — 색 · 글꼴 · 테두리 · 단추 · 탭은 `globals.css` 토큰과 지금 교사 화면 CSS 모듈의 값을 그대로 쓴다(새 색 · 새 그림자를 짓지 않는다).
  05 §0 금지 목록(AI 공장식 — 보라 그라데이션 · 유리 효과 · 이모지 · 과한 둥근 모서리 · 카드마다 아이콘 …)을 지킨다. 시안 HTML 에 어떤 토큰 · 어느 파일의 값을 썼는지 주석으로.
- **표본은 실제 크기** — `me-wire` 의 표본(담당 반 3 · 29명 · 학습 개입 7명 · 운영 확인 3명 · 기준 아래 19명)을 그대로 쓰되 더한다: 밀린 카드가 **14장**인 학생 하나(펼침이 길 때) ·
  긴 반 이름(«중1 심화 A(월수금)») · 긴 단원 이름 · 네 글자 이름 · 사유가 둘인 학생 둘 · 계정 없는데 기록 사유가 있는 학생 하나 · 학습 개입이 **0명**인 상태의 화면 한 장(빈 상태 문구).
- 문구는 간결 · 사무적(D-08) — 느낌표 · 이모지 없음. «첫 시도 9 / 15»는 문장 안에서 날짜로 읽힌다 — 문장에서는 «15개 중 9개 맞힘»(me-wire 가 찾은 것).
- 손가락 커서 · hover 는 실제로 누르는 것에만(D-30) — 줄은 안 눌리고 이름 · 펼치기 단추 · 거르개만.
- 문항 글 · 학생 답 · 종합 점수 · 순위 · 백분위 없음. 학생에게 번호를 붙이지 않는다.
- 있는 자료만 — `me-teacher` 출력(`src/contracts/mathExplorersTeacher.contract.ts` 는 main 에 아직 없을 수 있다 — `docs/planning/tracks/reports/me-wire.md` §4.2 와 27 §4.2 의 칸 안에서).

`H{n}-1280-open.png`(밀린 카드 14장인 학생을 펼친 상태, 그 줄이 화면 위쪽에 오게 1280 × 900) · `H{n}-390-first.png`(390 × 844 첫 화면) · `H{n}-390-open.png`(같은 학생을 펼친 390 × 844).

🔴 **긴 전체 쪽 그림을 만들지 않는다** — 모델이 줄여 읽어 글자가 뭉갠다. 전부 위 크기의 화면 한 장씩. deviceScaleFactor 1.

그림마다 스스로 눈으로 보고(잘린 글자 · 겹침 · 줄 높이 · 폰에서 이름이 첫 화면에 몇 명 보이는가) 보고서에 **수치로** 적어라:
안마다 1280 첫 화면에 보이는 학생 수 · 390 첫 화면에 보이는 학생 수 · 한 학생 블록의 높이(px) · 펼친 뒤 다음 학생 이름이 화면에 남는가.
