## 2. Hi-fi 규칙 — 다섯 안이 **전부** 지킨다

1. **A4 실측 — 두 벌로.** ⓐ 실데이터 학생(최근 진도가 가장 두꺼운 학생 — 소단원 17 · 19차시 · 긴 이름)과
   ⓑ **다 찬 예시**(시험·결시·영상·숙제·긴 선생님 의견까지 — §1 #9 처럼 원시 행에서 생성). 둘 다 **인쇄 PDF 를 떠서 1쪽인지 잰다**
   (Playwright `page.pdf({ format: "A4", printBackground: false })` → 쪽수). 대단원별로 묶고 소단원 이름은 한 줄에 이어 적는다.
   **이름 말줄임 금지 · 본문 9pt 미만 금지.** 넘치면 «대단원 + 소단원 수»로 접는 규칙을 **코드로** — 접었으면 지면에
   「소단원 목록을 줄여 적었습니다」처럼 **요약했다는 사실을 밝힌다**.
2. **흑백 · 배경 인쇄 꺼짐.** 크롬 인쇄 기본값은 «배경 그래픽» 꺼짐이라 `background-color` 로 그린 막대는 **종이에서 사라진다**.
   항목명·분자·분모·상태는 **글자로도** 찍힌다. 그래픽은 테두리·SVG 채움으로 그리고, 그 조건의 PDF 를 **흑백으로 바꾼 그림**으로 확인한다.
3. **난이도 4단은 같은 눈금** — 단마다 같은 길이·같은 척도. **미측정과 실제 0 을 글자로 가른다**(`—` 하나로 둘을 같이 쓰지 마라).
4. **문장은 근거가 될 때만** — §1 #3. 단원·밴드 모두 12문항 미만이면 평가 문장 없이 숫자만.
5. **네 상태를 가른다** — 기록 없음 · 표본 부족 · 결시 · 실제 0점. 결시는 **날짜와 함께 한 줄**, 평균에서 뺀다(0점으로 잇지 않는다).
6. **표본 부족 단원** — 학부모 지면에는 목록이 아니라 **개수 한 줄**:
   「문제 수가 적은 3개 단원은 이번 리포트에서 평가를 보류했습니다.」(🔴 «다음 달에 말씀드립니다» 금지 — 다음 달 문항은 보장되지 않고
   집계는 달을 넘겨 누적하지 않는다. «표본»이라는 말도 쓰지 않는다). 단원별 «5문항 / 기준 12문항»은 **원장 화면에**.
7. **숙제 분모는 «오늘 확인함»이 찍힌 날뿐**(23 §7.1). 학부모에게는 「확인한 N번 중 M번 안 해 왔습니다」처럼 **확인 범위와 함께**.
   ⚠️ 숙제 표는 아직 없다(트랙 4) — Hi-fi 는 **예시 ⓑ 에서만** 그린다. 실데이터 ⓐ 에서는 «담지 않은 기록»으로 간다.
8. **기간 = 달력 한 달** (KST 1일 ~ 말일). 비교는 **지난달**. 월 1회 발행과 «최근 4주»는 다르다(4주 창은 1년에 13번 — 달과 어긋나 누락·중복).
   **예습 영상**: 대상 = 이번 달 배운 차시의 강의 중 **월말까지 게시된 것**(§1 #8), 셈 = **완료 시각 < 다음 달 1일 00:00 KST**.
   **아래 경계는 두지 않는다 — 예습은 수업 전에 본다**(지난달 말에 봤을 수 있다). 부분 시청률(`percent`)은 시각이 없어
   과거 달을 다시 뽑으면 바뀌므로 **학부모 지면에는 완료 편수만**: 「이번 달 배운 내용의 영상 6편 중 월말까지 4편을 끝까지 봤습니다.」
9. **문구** — D-08(간결·사무적 · 느낌표·이모지 없음). 전문용어 금지(«정답률 62%»보다 «10문제 중 6문제» — 단, §1 #2 대로 실제 문항 수).
   **단일 종합 점수·등급·석차 없음**(23 §7 Q4).
