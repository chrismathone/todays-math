## 2. 무엇을 채우나

- 내 학년의 **소단원 전부**(`npx tsx scripts/qa/concept-blank/ten-progress.ts --part <e3plus…>` 가 차례대로 찍는다)에서
  **원래 + 보강**이 개념 · ○× · 적용 **각각 하 10 · 중 10 · 상 10** 이 되게 보강한다. **정확히 10** — 넘기지 않는다
  (진행표의 «10 넘은 칸» 0). 그림은 보강하지 않는다.
- 꼴: 소단원마다 `plusSection(열쇠, id머리, { concepts, ox, apply })` 하나. 파일 끝의 표시 줄
  `// ── 새 소단원은 이 줄 위에 교육과정 차례로 더한다 ──` **바로 위**에 Edit 로 끼운다(파일이 수만 줄이 된다 — 통째로 다시 읽지 않는다).
  - 열쇠: `BLANK_SECTIONS` 의 `key` 그대로(진행표가 찍는 글을 복사).
  - id 머리: 그 소단원 **원래 문항 id 의 앞부분**(`e3-1-1-1-c1` → `e3-1-1-1` · `m1-01-03-c2` → `m1-01-03`). id 는 도우미가 `-xc1` · `-xo1` · `-xa1` … 로 낸다.
  - 개념 `[난이도, 용어, 갈래, 뜻문장, [예 물음, 예 답]?]` · ○× `[난이도, 문장, 참거짓, 까닭]` · 적용 `[난이도, 물음, 답]`.
  - 수식이 든 글은 `` r`...` ``(파일 머리에 `const r = String.raw;`) — 역슬래시 하나로 쓴다.
  - 한 번 넣은 문항을 빼야 하면 그 자리에 `RETIRED`(뒤 번호가 밀리지 않게).

```ts
import { joinBanks, plusSection } from "./plus";

/** 수식이 든 글은 `r` 로 쓴다 — 역슬래시를 그대로 둔다. */
const r = String.raw;

export const bank = joinBanks([
  plusSection("중1::1. 소인수분해::소수와 거듭제곱", "m1-01-01", {
    concepts: [
      ["하", "거듭제곱의 밑", "정의", r`$2^3$처럼 나타낼 때 거듭하여 곱한 수 $2$를 {밑}이라 한다.`, [r`$5^4$의 밑은?`, "$5$"]],
      // …
    ],
    ox: [
      ["하", "$1$은 소수이다.", false, "약수가 $1$ 하나뿐이라 소수가 아니다."],
      // …
    ],
    apply: [
      ["하", r`$3\times3\times3\times3$을 거듭제곱으로 나타내시오.`, "$3^4$"],
      // …
    ],
  }),
  // ── 새 소단원은 이 줄 위에 교육과정 차례로 더한다 ──
]);
```

## 3. 난이도 — 같은 개념을 난이도로 나눠도 된다

원장님 «같은 개념이어도 난이도에 따라 구분시켜도 되니까». 한 소단원에 개념이 열 개나 없어도 된다 — **같은 개념을 다른 각도로**
다시 묻는다. 다만 **한 소단원 안에서 같은 글은 두 번 쓰지 않는다**(용어 · 뜻 · ○× 문장 · 적용 물음 — 은행 시험이 막는다).

| | 개념(용어 → 뜻 · 빈칸 · 지도) | ○× | 적용 |
|---|---|---|---|
| **하** | 기본 용어의 뜻 · 처음 배우는 말 · 읽고 쓰는 법 | 뜻을 그대로 확인하는 문장 | 한 단계 — 뜻 · 방법을 바로 쓰는 계산 · 판단 |
| **중** | 성질 · 관계 · 기호 · 헷갈리는 두 개념 가르기 · 방법의 차례 | 성질 · 관계 · 헷갈리는 둘 · 흔한 잘못 | 두 단계 · 성질을 써야 풀린다 · 거꾸로 구하기 |
| **상** | 공식 · 방법의 까닭 · 조건이 겹치는 성질 · 경계가 헷갈리는 것 · 활용 | 경계 사례 · 반례 · 조건이 둘 이상 | 조건이 둘 이상 · 생활 상황 · 오류 찾기 · 어림과 견주기 |

- **용어 칸은 «용어 → 뜻» 지면에 혼자 찍힌다** — 그것만 보고 뜻 문장을 떠올릴 수 있게, 같은 개념이면 각도를 이름에 붙인다
  («받아올림» · «받아올림이 두 번 생길 때» · «받아올림한 수를 빠뜨리는 잘못»). 40자 안.
- 뜻 문장의 핵심어 `{ }` 는 1~4곳 — **학생이 꼭 떠올려야 할 말**만. 빈칸을 빼도 문장이 읽혀야 한다(계약 · 시험).
- ○× 는 난이도마다 참과 거짓을 섞는다(원래 + 보강 10개 가운데 참 4~6). 까닭은 한 줄 — 거짓이면 무엇이 틀렸는지.
- 적용은 **같은 꼴에 수만 바꾼 물음을 한 난이도에 셋까지**. 나머지는 꼴을 바꾼다(상황 · 거꾸로 · 어림 · 오류 찾기 · 비교 · 빈칸 수).
  답은 짧게(수 · 낱말 · 짧은 구 — 80자 안). 답이 여럿이면 다 쓴다.
- 🔴 **학년 · 소단원 밖 내용 금지** — 그 소단원이 2022 개정에서 다루는 것만. 초등에는 문자식 대신 $\square$, 아직 안 배운 수(음수 · 무리수 …) ·
  용어를 쓰지 않는다. 26 §8 에서 뺀 말(초6 전항 · 후항 · 외항 · 내항 · 중1 계급값 · 중2 $0.\dot{9}=1$ 류 · 중3 대푯값)은 쓰지 않는다.
- 초등은 그 학년 말로(짧은 문장 · 쉬운 낱말). 원래 문항(같은 소단원)의 말투를 따른다 — 원래 파일을 **읽기만** 한다.

## 4. 표기 · 글자 — 원래 은행과 같다(cb-pass2 §2)

- **모든 수 · 식 · 단위 · 분수 · 각은 `$...$`**: `$286+153$` · `$7\,\mathrm{cm}$` · `$25\,\mathrm{cm}^2$` · `$\frac{3}{8}$` · `$2\frac{3}{4}$` · `$\angle A=50^\circ$`.
  점 이름은 `\mathrm` 없이(`$\overline{AB}$` · 점 `$A$`) · 단위와 합동 조건(`$\mathrm{SAS}$`)만 `\mathrm`.
- **한 글자 인수도 중괄호**: `\frac{1}{2}`(`\frac12` 금지) · 순환소수 `\dot{3}`(`\dot3` 금지).
- 수식 뒤 조사는 읽는 소리에 맞춘다(`$3$을` · `$\frac{6}{10}$을` · `$2$와` — 자가 잰다). 도형 이름은 한자 수사(팔각형).
- 핵심어가 수 · 식이면 `{$...$}`. 글자 수 상한은 **보이는 글자**(뜻 160 · 용어 40 · ○× 문장 · 까닭 120 · 적용 물음 120 · 답 80 · 예 물음 80 · 예 답 60).
- 🔴 **Bash 로 TeX 가 든 글을 쓰거나 치환하지 않는다** — Bash 도구는 역슬래시를 반으로 줄인다. 파일은 Write/Edit 로만.
- 🔴 **교재 문장을 옮기지 않는다** — 문장은 우리 말로 새로. 교재 용어 목록(`C:\Creative\testautocreator-data\I-개념용어`)은 «무슨 개념이
  있나»만 본다. 누출 검사는 `$...$` 를 빼고 잰다 — 수식 사이 한글이 이어 붙어 창이 생길 수 있으니 고친 뒤에도 다시 돌린다.

## 5. 검산 — 지어낸 답이 가장 큰 위험이다

- 적용의 답과 개념 «예»의 답은 **모두 직접 검산**한다. 수로 끝나는 답은 스크래치 스크립트(내 세션 스크래치 폴더 — 저장소 밖)로
  다시 계산해 맞춘다(사칙 · 분수 · 거듭제곱 · 방정식의 해를 넣어 보기 …). 보고서에 «기계 검산 n개 · 손 검산 n개 · 틀려서 고친 n개».
- ○× 는 까닭이 참거짓과 맞는지 다시 읽는다. 참인 문장에 반례가 없는지(«항상» · «모든» · «만»)를 본다.
- 대단원 하나를 끝낼 때마다 그 대단원 보강에서 **난이도마다 몇 개씩 골라 다시 읽고** 고친다(보고서에 몇 개 봤는지).

## 6. 진행 · 커밋 — 길게 간다

- 차례: 교육과정 차례대로 **대단원 하나씩**. 대단원 하나가 끝나면:
  1. `npx tsx scripts/qa/concept-blank/ten-progress.ts --part <p>` — 그 대단원 소단원이 «끝»인지
  2. `npx tsx scripts/qa/concept-blank/check-notation.ts --part <p>` 0 · `npx tsx scripts/qa/concept-blank/check-leak.ts --part <p>` 0
  3. `npx prettier --write <내 파일>`(이름을 적어서만) · 가지에 **커밋**(`--only <내 파일> <보고서>` — main 에 밀지 않는다)
  4. 보고서의 진행 표에 한 줄(대단원 · 소단원 수 · 넣은 문항 수 · 검산 수)
- 대화가 길어져 요약되면 진행표와 보고서부터 다시 읽고 이어 간다 — 파일 전체를 다시 읽지 않는다.
- 시험은 묶음만, 메모리를 아껴서: `npx vitest run src/__tests__/unit/conceptBlankBank.test.ts src/__tests__/unit/conceptBlankSentence.test.ts --pool=threads --maxWorkers=1`.
  «ten per level» 시험은 학년을 다 채울 때까지 빨갛다(정상) — 나머지는 내내 초록이어야 한다.
