## 1. 🔴 이것은 «채우기»가 아니라 «새로 짓기»다

```
grep -rn "심화중\|심화상" src/lib/middle/     →  0건
```

`resolveMiddleTier(declared, content, hasFigure)` 는 등록값을 **내리기만** 한다
(`기본`→`연산`, D-106). 위 두 칸은 **유형이 `difficulty` 로 스스로 선언**해야 생긴다.

**만들 것**: 자기 학년의 새 모듈 파일 하나 —
`src/lib/middle/m1Top.ts` (또는 `m2Top.ts`·`m3Top.ts`). 그 안에 `TypeEntry` 를 짓고
`generate.ts` 의 `ALL` 에 **spread 한 줄**만 더한다.
그 파일 머리말이 이미 적어 두었다 — 「세션별 소유 모듈을 여기서만 합친다. 병렬 세션은
자기 모듈 파일만 만지므로 이 파일에서 병합 충돌이 나지 않는다」. **그 규약을 지켜라.**

## 2. 무엇이 «중»이고 무엇이 «상»인가 — 저쪽 실물에서 왔다

```
심화(중)   마디 하나가 안 굳고, **그 소단원의 개념**이 굳힌다.
           성질 하나가 후보를 «끝까지 계산하지 않고» 거른다.

심화(상)   성질로 못 굳혀 후보를 **다 만들어 견줘야** 한다.
```

정답률이 이 차례를 떠받친다(132소단원 30,607문항 실측): 심화(하) **65%** ·
심화(중) **56%** · 고난도 **42%**. 이름이 아니라 **측정**이 칸을 가른다.

⚠️ 표본이 얇다(심화중 11 · 고난도 4, 두 대단원). **가설이다.** 자기 학년 실물을 더
보고 싶으면 리드에게 말해라 — 원장님 계정 브라우저로 읽기 API 만 부른다.

### 🚫 저작권 — 경계가 여기다

```
가져오는 것   «꼴» — 무엇을 시키는가의 모양 · 어느 마디가 안 굳는가
안 가져오는 것  문항 본문 · 수치 · 그림. **한 글자도 저장소에 안 넣는다.**
               접촉 시트·화면 갈무리를 **커밋하지 않는다.**
```
원장님의 「우리가 생성해도 된다」는 **꼴에 대한 승인**이다.

## 3. 🔴 초등이 네 물결에 걸쳐 물린 함정 — 그대로 온다

### ㉠ 창을 한쪽 끝만 주면 굳힘이 **장식**이 된다

> 「살아남는 후보는 언제나 목록의 같은 자리(끝)다. 그러면 굳힘 조건의 **값**은
> 유일성에는 필요하지만 «어느 후보인가»를 **한 번도 안 고른다** — 정보는 있고
> **선택력이 0**이다.」

초6 에서 두 갈래가 이것으로 **병합이 막혔다**(각각 23/23 · 672/672 **전수**).
**반드시 재라**: 「굳힘 조건을 **안 읽고** 후보의 최댓값(또는 최솟값)을 집으면 몇 %가
맞나」. 우연 수준(후보가 $k$개면 $1/k$)을 넘으면 그 갈래는 **다시 지어야 한다.**
고침은 **양쪽 창** 또는 **비단조 굳힘**(초6 2-6-3 이 「높이−반지름 $=d$」로 갔다 —
창보다 세다: 창은 «만들고 마지막을 집는» 것이라 ⑾ 의 «중»에 머문다).

### ㉡ 「굳힘이 항등식」 — 조건을 지워도 답이 그대로

굳힘 조건을 **지우고** 같은 씨앗으로 돌려라. 답이 안 바뀌면 그것은 굳힘이 아니라 장식이다.
초등에서 이 검사로만 갈래 넷이 걸렸다.

### ㉢ 갈래끼리 겹침 — **한 시험지에 같이 실린다**

새 갈래가 그 소단원의 `심화하`·`응용` 과 겹치는지 재라. 열쇠 둘을 **같이** 써라:
- «지면 수 + 정답» (작은 집합에서 잘 듣는다)
- **발문 한글 낱말 Jaccard** (심화에서는 이쪽이다 — 진짜 겹침 0.94~0.97 · 무관 0.03~0.06)

⚠️ 「수+정답」에는 **천장**이 있다(심화상에서 자기 자신과도 19.2%). 쌍마다 **천장을
먼저 찍고**, 천장이 낮으면 «겹침 없음»이 아니라 **«판정 불가»** 로 적어라.

### ㉣ 「없는 축은 변이시킬 수 없다」

가드를 세우기 전에 **그 축이 있는지** 먼저 물어라. 그리고 **변이로 확인하라** —
⑴ 파일이 바뀌었나 ⑵ **산출물이 바뀌었나** ⑶ 그제서야 시험이 빨개지나.

## 4. ❌ 하지 마라 — 재고 버린 것들

1. **D-115 의 되짚기 축으로 중등을 재지 마라.** 세 조사와 적대 검토가 **못 뒤집었다**
   — 중등 응용↔심화하를 1.05~1.85배로만 가른다(초등은 22~40배). 그 축은 **지금 우리
   풀에 위 칸이 없다**는 뜻이지 「축이 죽었다」가 아니다. 새 갈래를 세운 **뒤에** 재라.
2. **초등의 열거 자를 그대로 가져오지 마라.** 초등에서도 응용 1.7% = 심화하 1.7% 로
   **그 칸을 안 가른다.** 가르는 칸은 심화중↔심화상이다.
3. **`listedInside` 를 그대로 쓰지 마라** — 중등 단위 `$18\,\mathrm{km}$` 의 `\,` 를
   나열로 읽어 부푼다. 가져가려면 `\,` 를 먼저 지워라.
4. **`연산` 갈래를 손대지 마라** — 원장님이 「당장 급한 거 아님」으로 보류하셨다
   (중등 89소단원 중 42개에 없다).
5. **규모를 키우는 축을 쓰지 마라**(D-115 ⑽③) — 수를 크게 하는 것은 난이도가 아니다.

## 5. 🔴 완료 조건에 **«풀이가 충분한가»** 가 들어간다 (원장님)

```bash
npx tsx scripts/qa/probe-middle-solution-depth.ts --selftest   # 눈금 5건
npx tsx scripts/qa/probe-middle-solution-depth.ts              # 갈래별 분포
```

착수 시점 실측(1,376유형 × 12,384행): 해설 중앙값은 갈래를 따라 늘지만
**「걸음 건너뛰기」는 안 줄어든다** — 연산 6.4% · 기본 14.0% · 응용 13.3% · 심화하 12.7%.

**네가 세우는 갈래는 그 값이 0 이어야 한다.** 「풀면」·「표로 정리하여 세면」 뒤에
중간 결과 없이 답만 오면 안 된다. 나쁜 실례(고치지 말고 보기만) —
`2-2|경우의 수|02` 는 「표로 정리하여 세면 모두 $3$가지이다」인데 **표가 없다.**

⚠️ 그 자는 **생략 표지가 없는 부실**은 못 잡는다(머리말에 적혀 있다). 그러니
**자기가 지은 해설은 눈으로 읽어라** — 0 을 「깨끗」으로 읽지 마라.

## 7. 얼마나 세우나

**수를 목표로 잡지 마라.** 「소단원마다 하나」 같은 할당을 주면 **못 세울 자리에
억지로 세우게 된다** — 초등에서 그렇게 세운 갈래가 적대 검토에 전부 걸렸다.

대신: 자기 학년에서 **⑵ 의 꼴이 실제로 서는 소단원**을 찾아 세우고,
**안 서는 곳은 «왜 안 서는지»를 근거와 함께 비워라.** 비운 것도 산출물이다.
첫 회차는 **대단원 둘~셋**이면 충분하다. 리드가 검수 후 다음 물결을 준다.
