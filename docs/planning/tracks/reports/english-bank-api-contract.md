# English bank API contract — 2026-10-03

Final contract: `src/contracts/englishBank.contract.ts`. Existing V1 `english.contract.ts` adds only `EnglishPassageRef`, optional `meta.passageRef`, and optional generation `passageRef`. No V2 document conversion.

`EnglishBankMakerSeed = {requestId,examId,path:'chatgpt'|'cloze'|'api',passageRef,title,text}`. `EnglishPassageRef = {passageId,textRevision,snapshotHash}`. snapshotHash is SHA-256 of exact UTF-8 revision text. The maker copies the ref into meta; variation uses meta.sourcePassage to prove original input. For cloze the set passage is compared directly (no 24k text in the 18k sourcePassage field). If the teacher edits input, detach the ref and show a reason, retaining the draft. A failed save must preserve its pending draft/clientKey; changed ref with a used clientKey is a conflict.

Bank text max 30,000 UTF-16 code units, cloze max 24,000, ChatGPT/API max 18,000. 24,001–30,000 is storage/read only. Creation/import starts unconfirmed; separate rights command required. generation_input is required on all maker paths, external_model additionally on chatgpt/api. Changes to source or text invalidate confirmation. Source-only edits increment CAS revision, text edits also increment textRevision. Historical text and usage source snapshots never change.

All ordinary responses use `{data}`, paged responses add `{meta:{nextCursor}}`. Writes that detect duplicates only report same-user candidate IDs and never merge direct entries. Same import origin plus exact body deterministically returns the existing entry. Cursor ordering uses creation time + UUID (listening uses updated time + UUID).

Errors use existing `{error:{code,message,details}}`. Malformed input/ref is 400 VALIDATION_ERROR. Bank semantic conflicts are 409 CONFLICT with details.reason: PASSAGE_UNAVAILABLE (identical missing/cross-owner/archived ref response), PASSAGE_TEXT_MISMATCH, RIGHTS_REQUIRED, PASSAGE_TOO_LONG, REVISION_MISMATCH, CLIENT_KEY_CONFLICT, IMPORT_TEXT_UNAVAILABLE, IMPORT_TEXT_TRUNCATED or IMPORT_INVALID_UTF8. Length failure includes limit/length/path. Existing bank-free V1 writes remain compatible; successful same-key replay returns the stored row without creating another use or requiring renewed rights.

Root owns route grants. Passage routes require english-bank. Listening bank/references require both english-bank and the existing listening account/pilot gate; existing `/listening/sets` array shape is unchanged. Backend never receives EBS asset URLs in its public projection.

Official references additionally accept optional year (1900–2200) and round (1–10), via englishListeningReferenceQuerySchema. Own listening bank strictly rejects year/round; it supports q and level only.

New uses/prepare accept only the current textRevision; historical revisions remain readable through stored usage snapshots, and existing same-key saves replay without reauthorization. This prevents confirmation of edited text from authorizing an older original. Imports independently require the original material read menu (school or maker) or set library menu; prepare requires maker. A source-menu denial returns 403 FORBIDDEN with details.reason=SOURCE_ACCESS_DENIED. Bank-linked source/path pairs must be chatgpt/chatgpt, cloze/cloze, or deepseek/api. Revision numbers fit PostgreSQL int32; bank text must contain valid Unicode and no NUL.
