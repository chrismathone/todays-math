# 기출 쌍둥이 중간 집계 v16 — 집계 결함 증거로 보존

이 중간 산출물은 최신 정본으로 사용하지 않는다. 현재 ID115개/그림91개와 독립 수학·학년114개를 묶는 과정에서 기존 집계기가 `report.status=verified`만 보고 내용·분류 통과를 세는 문제를 발견했다. 경신 q4는 수학·학년·그림·문장 검토를 통과했지만 실제 `unitFamilyFit=false`, family 미배정이다. v16의 내용 통과16/보류98을 내용·분류 전체 통과 수로 읽으면 과대 집계다.

원래 v16 JSON/본문·그림·풀이·검수 바이트는 고치지 않는다. 새 집계기는 실제 독립 수학·학년과 필수12검수 차원을 모두 대조하고, 분류 보류를 따로 유지한다. 수정 후 새 [v17 원장·보고서](exam-twin-checkpoint-v17-20261019.md)를 정본으로 사용한다. 이 수정은 새 문제·새 독립 풀이 또는 권리 승인 수를 늘리지 않는다. 전체 승인/적재 가능·운영 쓰기는 두 버전 모두0이다.
