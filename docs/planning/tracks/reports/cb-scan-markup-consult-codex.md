# 개념 백지 사진 위 첨삭 독립 검토 · 2026-11-26

- **첫 출시는 B·C·현재 D·E의 채점 대상에 한정한다.** A·옛 D는 교사 확인을 유지한다.
- 판정은 지금처럼 공개한다. 학생 사진 위에는 **교사가 공개한 ×·△ 첨삭**과 검증된 판정 단위의 ○만 먼저 적용한다.
- **칸 번호와 검증된 빈 영역부터** 구현한다. 줄 수 일치나 글자 수 비례만으로 줄·낱말을 가리키지 않는다.
- 첨삭은 판정과 별도 이력으로 저장하고 학생 응답은 승인된 최신 판정의 공개본으로 구성한다.
- 새 폰 사진의 사람 참값, 공개 경쟁 조건, 유료 응답 복구를 확인한 뒤 제한 운영한다.

## D1~D5 추천

- **D1 · (가).** 11-25 권고와 같이 A·옛 D는 교사 확인으로 남긴다. AI 초안도 어떤 표현을 틀렸다고 가리키는 의미 판단이어서 교사 검수만으로 첫 출시의 참값 부족과 검수 부담이 해소되지는 않는다. A 사진은 형태 확인에 쓸 수 있다. A 초안을 나중에 시험한다면 교사 확정 판정·발행 기준·실제 서술 표본을 바탕으로 교사 전용으로 먼저 재고, 초안의 내용 오류와 채택·수정 시간을 따로 잰다. **원장님 결정 필요**는 A까지 첫 범위를 넓힐 경우다.
- **D2 · ×·△ 첨삭만 승인 후.** 기존 ○△×·확인 필요와 한 줄 까닭은 즉시 공개한다. 새 빨간 주석의 글, 인용, 번호·∧·물결·배치도 함께 숨긴다. ○는 판정 단위에 표시할 수 있다. ✓도 해당 줄·칸의 정답 근거가 별도로 확인된 경우에만 허용한다. B의 표시+까닭처럼 여러 칸을 묶은 ○에서 줄마다 ✓를 유추할 수 없다. 확인 필요는 기존 중립 표시로 둔다. **원장님 결정 필요**는 교사 승인 전까지 빨간 첨삭이 없는 학생 경험과 승인 부담이다.
- **D3 · 학생에게 모범 답 자동 제공 보류.** 같은 지면을 다시 풀 수 있게 학생 공개본은 오류의 까닭과 빠진 근거의 방향을 설명한다. 교사 전용 바른 계산·발행 기준은 승인용으로 둘 수 있다. `fix`만 빼면 `say`·까닭·카드 문장에 답이 남을 수 있으므로 새 학생 문구 전체를 승인할 때 확인한다. 기존 까닭도 답을 드러낼 가능성이 있으므로 기존 공개를 유지하는 범위에서 과거·현재 결과 전체가 답 비공개라고 약속할 수 없다. **원장님 결정 필요**는 재풀이 종료 뒤 명시적 모범 답 공개를 제품 범위에 넣을 경우다.
- **D4 · 선택된 A안 안에서 Hi-fi 4~5안.** 고정 빨강·흰 외곽선·손글씨체·사진 내 표식은 §0 결정대로 간다. 실제 폰 폭, 확대, 글이 꽉 찬 경우, 사진 만료, 폰트 실패의 모습을 함께 확인한다. **원장님 확인**은 완성된 Hi-fi 선택이다.
- **D5 · 상시 오른쪽 카드 생략.** 기존 결과 목록을 번호로 포커스하는 대체 경로로 쓰면 사진이 작거나 없을 때도 공개된 설명을 읽을 수 있다. 교사 화면의 선택 항목에만 저장된 판정 기준을 보여 준다. 학생 전용 추가 카드가 요구되면 **원장님 결정 필요**로 표시하되 §0에서 이미 고른 A안은 그대로 적용한다.

## 설계 지적 · 심각도 순

1. **매우 높음 · 공개와 판정 교체의 경쟁.** 관찰상 학생/교사 결과는 공용 DTO를 쓰고 공개 뒤 판정 이력도 포함한다. 추천은 기존 발행물·학생 권한 확인을 거쳐 서버에서 학생용 허용 필드로 공개본만 직렬화하는 것이다. 학생 경로에는 사용량 원본, 초안, 기준 답, 미공개 인용과 배치, 교사 이력을 넘기지 않는다. 기존 판정 이력과 까닭은 유지하되 신규 초안이 그 필드에 들어가는 경로를 열지 않는다. 교사 전용 편집/공개 경로에서 현재 grade ID·첨삭 리비전을 함께 잠그고 검사한다. 판정 교체 즉시 그 전 판정의 첨삭은 비표시하고 교사가 새 판정을 검토해 다시 공개한다. 이미 공개된 문구를 고치면 마지막 공개본을 편집 중 계속 보여 주고, 승인한 판만 교체한다. 삭제는 즉시 공개본을 숨기는 별도 사건이다. 상세·폴링·작업 응답·오류·캐시에서도 같은 경계를 지킨다.
2. **높음 · 실제 좌표와 추정 좌표.** 관찰상 새 matched 사진은 이미 펴져 있다. 저장 JPEG를 다시 원근 보정할 이유가 없다. 추천은 발행 해시·학생지 쪽·사진 ID/버전/해시·판독 판·배치 알고리즘 판을 고정하고 저장 사진과 같은 픽셀 격자에 기준 영상을 맞추는 것이다. **추측**이지만 프린터 배율·종이 휨·그림자·압축·연필이 룰선에 겹침 때문에 픽셀 단순 차분에는 인쇄 잔상이 남고 가는 필기가 지워질 수 있다. 먼저 답 영역의 인쇄선 마스크와 여유 영역을 이용한 국소 정합·명암 보정을 오프라인으로 비교한다. 스크린샷 재현 또는 국소 대조 실패 시 잉크를 근거로 한 표식을 생략한다.
3. **높음 · 줄 맞춤과 밑줄.** v4 줄바꿈은 후보 단서다. 같은 줄 수라도 줄 합치기와 쪼개기가 상쇄되거나 칸 밖 필기·삽입·옆 계산으로 순서가 틀릴 수 있다. 각 첨삭에 단일 `slotId`를 요구하고, `quote`가 그 칸의 **원 판독**에서 한 줄에 유일하게 나타나며 읽기 상태·국소 정합·글줄 순서가 믿을 만할 때만 줄 끝 표식을 고려한다. 직접 입력은 종이 글의 근거로 쓰지 않는다. 반복·교차 줄·흐림·겹침·다중 열·빈 답·수식 변형은 칸으로 후퇴한다. 맞춤 자체가 불확실하거나 사진 만료·삭제 시에는 좌표 없이 결과 목록으로 간다. **글자 수 비례 밑줄은 내부 시제품까지만** 쓴다. 한글·숫자·공백·분수와 손글씨 폭 차이로 맞는 줄에서도 다른 단어를 지목할 수 있다. 처음에는 칸 번호, 확인된 경우 줄 끝 번호를 쓴다. 빈 자리도 잉크·인쇄·다른 주석과 여백을 포함한 실제 글 상자로 충돌을 검사한다. 자리가 없으면 번호와 목록으로 가며 다른 예 칸으로 글을 밀지 않는다.
4. **높음 · 생성 실패와 유료 복구.** 관찰상 채점은 strict `scanGradeSchema`를 쓰므로 모델 행에 `notes`를 그대로 붙이면 기존 판정까지 실패할 수 있다. 판정과 선택 주석을 분리 검증하고, 잘못된 주석은 버려도 판정 저장·공개는 계속한다. `correct`·`review`에는 신규 교정 문구를 만들지 않고, `missing`의 삽입 위치는 별도로 검증한다. 인용은 여러 칸의 연결 문자열에서 찾지 않는다. 서버에서 plain text로 처리하고 개수·길이·대상 ID를 검증한다. 비용은 16,000 출력 한도를 유지해도 `reservation.ts`가 지시문과 JSON 스키마 바이트를 함께 세므로 **총 예약 상계는 늘 수 있다**. A는 이미 사진 읽기 비용이 있으며 A만 있는 쪽의 모델 **의미 채점 호출**이 현재 없는 것이다. A·크롭 별도 호출을 도입하면 공용 월 $100/UTC 원장과 FIFO에서 호출마다 선예약한다. 첫 출시는 추가 호출 없이 진행한다. 주석까지 같은 응답에 담는다면 판정 잘림·누락과 한 쪽 최대량을 측정한다. `model.ts`의 결과 키가 판·본문·스키마에 의존하므로 대기/저장 복구 중 버전을 바꾸면 종전 유료 결과를 놓칠 수 있다. 작업에 계약 판을 고정하거나 전환 전에 기존 대기를 소진하고 구판 복구를 지원한다.
5. **중간 · 저장 최소화와 배포.** 독립 편집·삭제·공개가 필요하므로 별도 append 표에 동의한다. `evidence`는 판정 근거 ID로 유지한다. 첫 구현은 판정별 첨삭 스냅숏과 명시적 edit/publish/remove 사건이면 충분하다. publish는 승인한 리비전을 가리키고 remove는 빈 글과 구별한다. 동일 제출의 grade/photo를 참조하는지 트랜잭션과 DB 제약으로 보장하고 순번 유일성·재시도 키를 둔다. 주석 부재/실패는 명시적으로 기록해 같은 유료 응답을 반복 소비하지 않도록 한다. 배치 작업이 실패해도 기본 판정이 끝나야 한다. 첨삭 표 미설치 503은 첨삭 경로에만 격리하고 기존 결과 DTO/채점은 유지한다.

| M3 | 두 교사의 개정/공개·중복 클릭·판정 교체 경쟁에서 미공개 또는 구판 주석이 새지 않아야 한다. 학생 본인·다른 학생·교사 권한, 사진 만료·삭제·교체, 구판 제출·DB 미적용, 응답 저장 후 작업 중단·재개를 검사한다. `elementFromPoint`는 클릭 가림 시험으로 쓰고, 정합은 예상 SVG/이미지 경계와 스크린샷을 비교한다. 확대·회전·모바일·어두운 모드·글꼴 실패·키보드에서는 같은 번호의 목록 경로를 확인한다. |
| M4 | 학생 공개는 칸 단위 표식과 공개된 설명으로 별도 통과할 수 있다. 글줄/낱말 기능은 별개로 켠다. 낱말은 사람 참값으로 앵커 정밀도와 커버리지 둘 다 확인한다. 다른 칸·학생 글을 잘못 가리킨 수용 시험은 0건을 권고한다. |
| M5 | 기본 꺼짐과 되돌림을 시험한다. 신규 유료 생성 중단, 대기 호출 복구, 기존 판정/사진 정리, 승인본 표시 정책을 검증한다. 교사 고침률과 함께 검토 시간, 삭제·미공개율, 표식 포기율, 누출/오지목, 예약·실제 정산·대기 시간을 기록한다. |

## 초안과 의견이 다른 곳

- D1은 리드의 (나) 대신 (가). D2는 글뿐 아니라 아직 승인되지 않은 표식·배치까지 잠그고 ✓에 줄 단위 검증을 요구한다.
- F4는 보정 후 저장 사진 좌표이고, F6의 빈 영상은 신규 도출물이다. F5·F7의 운영 수치는 이번 코드 검토로 재현하지 않았다.
- v4와 픽셀 잉크 분리는 실물 검증 과제부터 시작한다. 글자 수 비례 밑줄과 이웃 예 칸으로의 주석 이동은 출시 기준으로 삼지 않는다.
- 별도 append 표에 동의하며, 최신 판정에 대한 공개 사건과 삭제 사건을 구분한다. 학생용 답 공개와 상시 오른쪽 카드는 첫 범위에서 제외를 권한다.
- M4의 학생 표시를 낱말 밑줄과 분리한다. 비용은 출력 한도 외에 입력 상계·판 전환 복구를 재검증한다.

코드·자료 읽기와 Git 이력 대조만 수행했다. 운영 사진·DB 재확인, 모델 호출, 실물 실험은 수행하지 않았다.
