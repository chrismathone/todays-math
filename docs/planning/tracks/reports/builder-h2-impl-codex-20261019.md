# 시험지 만들기 H2 · 1단계 S2 제품 적용

2026-10-19 · `phase/12-builder-wire` · 기준 `b353aff92`.

[구현 지시서](../brief-builder-h2-impl-codex.md)의 H2 검토와 S2 한 열 차례를 제품에 적용했다. **관련 17파일 258시험, 전체 타입 검사, 변경 코드 ESLint, 전체 어포던스 검사가 통과했다. 실제 Chrome의 4개 폭·60장면은 가로 넘침·페이지 오류 0이다.**

커밋·스테이징·push·배포를 하지 않았다. 공유 DB는 검증된 READ ONLY 트랜잭션으로만 읽고 모두 롤백했다. `node_modules` 심볼릭 링크를 변경하거나 스테이징하지 않았다. 기존 3008 개발 서버의 PID 2404를 유지했다.

## 제품 동작

- **1단계 S2:** 처음에는 학년·과정만 그린다. 선택하면 단원 → 차시를 아래에 열고 앞 선택은 요약과 ‘변경’으로 접는다. 상위 선택은 하위 탐색·검색·쪽만 초기화한다. 이미 담은 범위·순서·문항 수·고정은 보존하며 다른 학년까지 누적한다. 차시는 20개씩, 담은 범위는 8개씩 표시한다.
- **출처와 조건:** 출처는 왼쪽 범위 안의 `전체 / 교과서만` 한 줄이다. 실제 책·자료 종류·개별 자료와 엔진·기출 등 기존 제한은 기존 선택 창 및 추가 선택에서 사용한다. 보유 N문항 줄은 제거했다. 오른쪽에 담은 범위와 수·고정·빼기, 여섯 난이도 단계·직접 입력·형식별 수·최근 14일 제외·구성 조건·조건 저장을 둔다. 빠른 총수 입력도 기존 `planComposition`으로 자동 행만 나눈다.
- **2단계 H2:** 왼쪽은 문제 통계와 문항 순서, 오른쪽은 문항이다. 두 목록은 같은 여섯 문항과 전역 번호를 사용한다. 왼쪽 순서표 바로 다음에 작업 중·0문항·출력 권한·총수 불일치·형식별 불일치를 표시하고 다음 버튼의 `aria-describedby`로 연결한다. 총수 부족·초과 수와 지정한 형식 0도 생략하지 않는다.
- **기존 계약:** 실제 출력 권한은 호스트의 `canOutputFrom` 값을 그대로 받는다. 3단계의 실제 `WorksheetEditor`·여섯 양식·출력 전 검증·저장본 보존은 유지했다. 정답·해설은 처음 숨기고 기존 토글로 연다. 교체·되돌리기·범위별 추가·직접 형식 변경도 유지했다.
- **복원과 순서:** 늦게 도착하는 단원 정보로 구 저장 문항의 범위·배분을 한 번 복원하고, 저장한 출제 조건을 적용하면 마지막 범위의 탐색 경로도 복원한다. 둘째 쪽의 이동은 전역 배열 위치를 사용한다. 순서표와 본문은 각각 자기 행의 좌표로 드래그하며 같은 재정렬 훅을 사용한다.

최대 본문 1040px, 직각 구획·16px 내부 여백·수평선을 적용했다. 수학 범위는 유동 목록 + 300px 조건 칸, 검토는 .8:1.2 두 열이며 가용 폭 900px 이하에서 쌓는다. 기존 단계 띠의 860px 분기와 문항 본문 420px 전폭 동작을 유지했다.

영어도 공통 H2 검토를 사용하며, 저장 세트를 고르는 범위 UI는 기존 `ScopePicker`를 유지한다. 연산대장은 `ExamBuilder` 호출자가 아니라 별도 `ArithmeticWorkbench`다. 두 화면의 관련 회귀 시험을 함께 실행했다. 인쇄 CSS와 학생 화면은 수정하지 않았다. 기존 Wire·Hi-fi 시안과 앞선 보고서는 보존했다.

## 공유 DB 읽기와 전후 요청·시간

독립 Orca Codex 세션이 실제 DB의 735차시와 가능 수를 READ ONLY·RepeatableRead 트랜잭션 3회에서 읽었다. `transaction_read_only=on`을 확인했고 모두 의도적으로 롤백했다. 제품 읽기 메서드는 93회이며 SQL 문장 수와 구분한다. 쓰기·트랜잭션 밖 읽기·unsafe raw 등의 보호 검사 10개도 통과했다. 실제 응답은 프로세스 메모리에만 두고 본문·계정·연결 정보는 저장하지 않았다.

기준 `b353aff92`와 최종 제품을 같은 실제 응답으로 실행했다. 첫 회 예열을 제외하고 전후 순서를 번갈아 학년별 7회, 총 588개 DOM 흐름을 측정했다. 전체 출처 13학년·과정, 교과서 8학년·과정의 42개 조합 모두 로컬 단계 합 중앙값이 줄었다. 로더·`mathSource`·최근 제외 요청 형식은 변경하지 않았다.

| 출처 / 진입 | 첫 흐름 요청 수 전→후 | 로컬 단계 합 중앙값 전→후 |
|---|---:|---:|
| 전체 / 단원 메타데이터 전달됨 | 1→1 | 15.005→9.956ms |
| 전체 / 단원 메타데이터 지연 조회 | 2→2 | 14.625→11.204ms |
| 교과서 / 단원 메타데이터 전달됨 | 1→1 | 17.740→11.011ms |
| 교과서 / 단원 메타데이터 지연 조회 | 2→2 | 13.264→10.390ms |

학년·단원·차시 선택 자체의 추가 요청은 전후 모두 0이다. 첫 흐름의 한 요청은 가능 수, 두 요청은 가능 수+bootstrap이다. 제품 소스 36개의 최종 해시가 측정 종료까지 같은지도 확인했다.

**인증된 HTTP 종단 지연은 미측정이다.** 거절된 API 요청도 기존 오류 로거가 DB에 기록할 수 있어 인증 우회나 무인증 HTTP 호출을 하지 않았다. 위 시간은 실제 응답을 메모리에서 전달한 제품 DOM 시간이며 네트워크·인증·Next 컴파일·화면 배치 시간을 포함하지 않는다. 기본 `recent=1` 요청을 검증하되 서버 읽기에는 빈 최근 제외 맥락을 전달했다. 개인 최근 14일 이력과 그 DB 비용은 측정하지 않았다. 실제 HTTP 시간이 줄었다고 확대 해석하지 않는다.

재현:

```sh
TSX_DISABLE_CACHE=1 node node_modules/tsx/dist/cli.mjs scripts/qa/measure-builder-h2-flow.ts --rounds 7 --db-rounds 3 --baseline-from-git
```
