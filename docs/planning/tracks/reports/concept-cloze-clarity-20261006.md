# 개념백지 빈칸의 물음 명료성 — 2026-10-06

## 문제와 범위

사용자가 초6 「2-1 분수의 나눗셈」의 실물 학생지에서 3·4·5·7·8·10번은 무엇을 써야 할지 불분명하다고 지적했다. 지면 코드 `1TER.H56B.D4XS.Q2`를 수정 전 은행으로 풀었을 때 `bankChanged=false`, 내용 지문 `4XSQ`로 사진의 10개 개념·3개 적용을 정확히 재현했다. 소단원은 2-1-4와 2-1-5, C형 개념 하5/중5/상0, 적용 각1이다.

원인은 렌더러가 임의로 말을 지운 것이 아니다. 공용 `definition`의 `{...}` 안에 조건·긴 절차·부정 서술이 들어 있었다. “가분수도 ___ 나눈다”, “___를 ___로 나누면” 같은 학생지로는 답의 범위를 정할 수 없었다. 같은 대단원의 개념 81개를 모두 검토한다. 문항 ID·순서·난이도·소단원 연결과 학생 기록은 유지한다.

## 계획과 교차 검토

Orca run `run_ccc0c45e9612`. 문항 교정과 저장·인쇄·교재 연동 감사는 별도 Codex 워크트리에서 진행했다. Codex 리드의 사전 계획을 Claude에도 독립 검토시켰다. Grok은 두 번 모두 `402 Payment Required: Grok Build usage balance exhausted`로 실패했다. 사용자는 **“Codex·Claude 검토로 이번 수정 진행”**을 명시적으로 승인했다. 3자 합의 완료로 기록하지 않는다.

적용 순서:

1. 사진 선택을 코드로 재현하고 기존 문장·빈칸·ID를 보존한다.
2. 조건은 본문에 제시하고 답은 용어·짧은 수학적 관계로 좁힌다. 긴 설명 자체를 숨기지 않는다.
3. 전체 81개 교정안을 Claude와 별도 Codex가 다시 읽어 반례와 답의 범위를 검사한다.
4. 공용 정의가 A/B/D형에서도 개념 설명으로 성립하는지 확인하고, 새 교재용 고정 대본을 함께 동기화한다.
5. 기존 인쇄 코드 변경 감지·교재 발행본 고정·채점 빈칸 수를 회귀 검사하고 실제 학생지·교사용 지면을 렌더한다.
6. 최신 원격을 다시 확인해 병합·검증 후 정상 훅을 거쳐 푸시한다. 완료한 워크트리는 가지를 보존하고 정리한다.

Claude는 원고 우선 수정에 조건부 찬성했다. 설명의 이유 보존, 빈칸 개수 재산출, 수가 들어갈 수 있는 안내, 같은 뜻의 답 허용, 문항끼리의 답 노출 검토를 요구했다. 학생 안내는 “알맞은 말이나 수”로 고친다. 교사용 안내에는 이미 같은 값·같은 뜻의 다른 꼴도 인정한다고 적혀 있다.

전용 `clozeSentence` 필드를 이번에 도입하지 않는다. 원고를 바로잡아도 설명과 C형 물음이 충돌하는 사례가 남는다면 별도 설계의 근거로 삼는다. 계산형 문제로 전환하거나 긴 답을 정규식으로 잘라내지 않는다. 초6에 새 용어 “역수”를 배웠다고 전제하지 않는다.

## 재검토에서 가른 것

- 확정: 직사각형의 “다른 변”은 맞은편 변까지 포함하므로 가로·세로를 명시한다. `{직사각형}`에 정사각형도 성립하는 문제는 없앤다.
- 수용: 대분수의 일부 분자를 전체 분자로 읽지 않게 진분수·가분수의 표현 범위를 밝힌다. 한 문항 안에서 정답을 그대로 되풀이하는 문장, 지시 대상이 빠진 “두 수”, “전체” 같은 빈칸을 다시 쓴다.
- 검산: 양의 두 분수에서 앞의 분수만 뒤집어 곱한 값이 올바른 몫과 같은 것은 두 수가 같을 때뿐이다. 두 대분수의 자연수 부분끼리·분수 부분끼리 나눈 몫을 더하는 방법은 올바른 나눗셈이 아니다. 피제수만 나누어 같은 제수로 각각 나누는 올바른 분배까지 부정하지 않는다.
- 비채택: Claude의 20개 조합 지적은 소단원 전체가 한 지면에 실린다는 가정이다. 그 이유로 문항을 삭제하거나 선택 순서를 바꾸지 않는다. C 학생지는 개념 소제목을 표시하지 않으므로 소제목에 답이 있다는 별도 13개 지적도 적용하지 않는다. 실제 사진의 선택은 따로 확인한다.

## 저장과 교재 연결

- **내 시험지**는 스냅샷이 아니라 선택을 저장한다. 다시 열거나 `?s=`로 출력하면 새 은행 문장과 빈칸 수로 재구성한다. 이미 인쇄한 종이·PDF는 달라지지 않는다.
- 옛 인쇄 코드는 선택을 되살릴 수 있지만 내용 지문이 달라 `bankChanged=true`가 된다. 코드가 과거 문장을 복원하는 보관소인 것은 아니다.
- 발행 교재는 `frozen.entries`를 사용하므로 당시 문장·정답을 유지한다. 초안의 확정 개념 연결은 원천 해시 변경을 감지하면 재확인이 필요할 수 있다.
- 새 교재의 설명 대본은 커밋된 `scripts/e6.json`을 읽는다. 기본 은행 정의의 설명·확인 답을 동기화하고 `static-corrections.json`에 대사별 이전/이후/출처를 남긴다. 보강 은행은 이 대본 생성의 원천이 아니다.
- 기존 대사 기준 SHA-256은 바꾸지 않는다. `bank-definition` 교정만 현재 은행의 정확한 정의와 일치함을 확인하고, 나머지 교정은 기존 수식 토큰 보존 검사를 유지한다.

## 다른 학년의 감사 상태

전체 14파트의 개념은 9,119개, 빈칸은 12,480개였다. 보이는 답 길이 12자 이상인 **검토 후보**는 798개 카드(808개 키), 16자 이상은 206개 카드(207개 키)다. 수식·정상적인 개념명·명시적으로 조건을 묻는 문장도 포함되므로 결함 수가 아니다. 길이 기준을 출제 제외나 학생 숙달 판정에 사용하지 않는다.
