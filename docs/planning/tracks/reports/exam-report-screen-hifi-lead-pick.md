# 성적표 원장님 화면 Hi-fi — 리드 선택 (codex 추천을 열기 전에 적음 · 2026-10-18)

**선택: H3 «문장 옆에서 쓰기».**

- A 를 고른 까닭이 «쓰는 문장이 지면에 어떻게 들어가는지 보면서 쓴다»였다. H3 만 1440 폭 첫 화면에 목록 · 지면 · 문장 칸 · 확정 단추가 다 들어온다. H1 · H2 · H4 는 지면 아래로 내려가 문장을 쓰는 동안 지면이 위로 밀린다. 미리보기가 쓰는 대로 바뀌는 것은 확인했다(H3 에서 입력 → 지면 글자 일치).
- H2: 점수 · 상태를 열로 맞춘 것은 좋으나 고른 줄이 이름 칸만 상자로 둘러져 «어느 줄을 골랐나»가 H1 보다 약하다. 목록은 H1 의 배지 줄이 낫다.
- H4: 확정이 학생 머리에, 문장 저장이 맨 아래에 있어 «쓰고 → 확정»의 손 움직임이 위아래로 갈린다. 인쇄를 맨 아래로 내린 것도 반 단위 일이 학생 단위 일 밑에 숨는다.
- 남길 것(H3 위에): H1 의 목록 배지 · 위쪽 인쇄 묶음. 좁은 화면에서는 H3 가 문장 칸을 지면 아래로 내리는 것 그대로.

고칠 것(어느 안이든):
1. 문장 상한 180자는 임시값이다 — 실제 H1 지면에 길게 넣어 재고 정한다(지금 «넘침» 표시와 같은 자로).
2. «문장 저장» · «이 학생 확정» 두 단추 — 확정이 저장을 포함하는지 문구로 밝힌다(확정을 누르면 저장도 된다).
3. 미리보기가 작다(1쪽 썸네일 폭 ~260px). 지면 띠의 «크게 보기»가 있으니 충분한지 실물로 본다.
