공유 DB 쓰기·적재·`npm install`·`prisma generate`·푸시는 하지 않는다. 새 작업트리나 하위 작업자를 만들지 않았다. 기존 은행 문형 자체의 수리나 적재는 이 작업에 포함하지 않는다. 기존 첫 출제의 `self-check` 입력을 일괄 바꾸거나 새 수식 입력기를 만들지도 않았다. 추가 재추첨 후보는 기존 자동 채점 계약을 사용한다. 공식 성취기준 전량 대조나 학생 학습효과 실측을 마쳤다는 보고가 아니다.
