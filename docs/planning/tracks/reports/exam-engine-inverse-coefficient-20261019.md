# 계수 합에서 상수 역산 — 실제 코드와 검수 전용 등록

노변 현재 4문항의 [family 의미 감사](../../../../.qa-artifacts/exam-resume-20261008/nobyeon-sem1-current4-family-audit-20261019-r1/report.json)에서 기존 계수 직접 계산 유형과 새 계수 역추론의 목표·조건·매개변수가 다름을 확인했다. 기존 live family에 억지로 배정하는 대신 새 유한 factory `study-middle-inverse-coefficient-sum`과 추상 요구 `algebra.inverse-coefficient-sum`을 구현했다. 다른 세 문항의 새 family 제안까지 구현했다고 주장하지 않는다.

새 factory는 두 일차식의 곱에서 `xy`, `y²`의 계수 합을 조건으로 받아 인수 안 상수 `k`를 구한다. 32개 조합에 음수·0·양수인 답과 역산 계수 −3·−1·1을 포함했다. 역산 계수가 0인 경우는 일치하면 무수히 많은 해, 불일치하면 해 없음이므로 유일한 답을 내지 않는다. 실제 학생 해설은 분배법칙·동류항·계수 해석·수치 일차방정식·원래 식 대입만 사용한다.

정답·매개변수는 인쇄된 인수와 계수 합에서 다시 계산한다. 현재 유한 템플릿과 다른 조건·해설·형식·가짜 보기를 거부하며, seed나 응답 형식을 조합 수에 곱하지 않는다. 단답형만 구현했고 객관식·서술형을 자동 지원으로 표시하지 않았다. 그림이 필요 없는 순수 대수 문항이며 새 수작업 쌍둥이·그림 수에 이 32조합을 더하지 않는다.

중요한 공개 경계는 `studyReleaseHold`다. 이 요구를 포함하면 ID·버전·native 라벨·신뢰도·승인 플래그·component 표시를 바꿔도 생성 전에 차단한다. 목록에서 제외하고 coverage는 unavailable이며 재현 manifest에 별도 release policy 버전을 포함했다. 기존 중1 학년 강제 제외가 이 관문보다 먼저 실행된다. `source=authored`나 올바른 계산은 권리 승인 근거가 아니다.

내부 메타데이터는 실제로 캡처한 다항식 곱셈 Unit UUID `e63d61c6-2b41-4c83-a74b-a605fd343c42`와 캡처 시각·해시, 새 질문 방향·공유 방법·선수를 연결한다. 논리 Unit 키와 DB UUID를 구별하며 `liveFamilyKey=null`, 등록·권리·native 승인 보류를 유지한다. 2025 출처·2026 연습의 2015 교육과정 제안과 2027 중3의 2022 배치 재검토 필요를 명시했다. 이 제안 자체는 승인이 아니다.
