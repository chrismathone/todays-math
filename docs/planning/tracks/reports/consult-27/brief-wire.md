# 협의 요청 2회전 — «도움이 필요한 학생» 교사 화면의 Wire 고르기 (한국어로 · 파일 수정 금지 · 도구 없이 · 마크다운 80줄 이내)

너는 한국 수학 학원 교사가 매일 쓰는 업무 화면을 설계해 본 검토자다. 아래 아홉 줄마다 **하나를 고르고** 근거 2줄 · 가장 큰 위험 1줄을 적어라.
듣기 좋은 말 말고 반대 의견을 우선하라. 그림은 볼 수 없으니 아래 글만으로 판단하고, 글만으로 판단할 수 없는 것은 «판단 불가»라고 써라.
1회전에서 셋(리드 · codex · grok)이 «자리 = 수업 관리 아래 새 화면 · 초 · 중등 한 목록 · 기본 범위는 담당 반»에 합의했다. 이번에는 그 안의 모양이다.
결과는 원장님께 «추천안»으로 올라간다 — 고르는 분은 원장님이다.

## 쓰는 사람과 자료

- 교사 한 사람이 반 2~4개(한 반 8~12명)를 맡는다. 수업 전 몇 분 안에 «오늘 누구와 말할까»를 찾는 것이 이 화면의 일이다. PC 가 주지만 폰으로도 본다.
- 자료는 저장된 개념 카드(탐험) 기록의 **합계뿐**이다: 카드별 단계 · 다음 복습 날 · 마지막 복습 결과 · 세션별 {날짜 · 단원 · 첫 시도 정답 0~15 · 미해결 수 · 별}.
  문항 글 · 학생이 고른 답은 없다. 종합 점수 · 순위 · 백분위는 만들지 않는다(굳은 결정).
- 목록은 둘이다. **학습 개입**(차례 있음): ① 미해결을 남기고 끝냄 ② 최근 복습에서 막힘(카드 2장 이상) ③ 복습이 밀림 ④ 임무가 날을 넘김 ⑤ 오래 쉼(7일).
  **운영 확인**: 시작 전 · 계정 없음. 차례 0 «연장 상한에 닿아 선생님과 확인»은 2단계의 빈 자리다.
- 🔴 운영 자료가 아직 없다(학생 1명 · 기록 0) — 문턱은 짐작이고, 아래 수치는 시안의 지어낸 표본이다: 담당 반 3 · 학생 29명 → 학습 개입 7명(사유 9건) · 운영 확인 3명 · 사유 없음 19명.
- 지금 있는 교사 화면: 중등 «반 수학 복습»(반 하나 · 카드 명단 · 학생 상세 없음) · 초등 «오늘의 기억 · SRS»(전체 학생 표 8열 · 이름을 누르면 오른쪽 상세 탭 다섯).
  두 화면 다 «요약 칸 넷 → 거르개(사람 수) → 명단» 차례이고, 줄은 안 눌리고 이름 단추만 눌린다.

## 시안 다섯

- **A 사유별 묶음** — 사유 다섯이 차례대로 묶음으로 서고, 묶음 안에 학생 · 근거 값(«미해결 3», «6장 · 가장 오래 8일»). 사유가 둘인 학생은 **두 묶음에 나온다**(7명이 9줄).
  학생 이름을 누르면 상세: 모은 카드 수 · 오늘 복습할 카드 · 밀린 카드 · 단원별 5칸 띠(칸마다 모음 / 밀림 / 복습에서 막힘 / 미해결) · 최근 세션 표.
- **B 한 줄 문장** — 학생은 **한 번씩만**. 줄마다 가장 앞선 사유를 문장으로: «김도윤 중1 A — 미해결 3개를 남기고 끝냄. 9/30(수) 일차방정식 · 첫 시도 15개 중 9개 맞힘.»
  둘째 사유는 아래 작은 글 «그 밖 — 복습이 밀림 …». [펼치기]를 누르면 줄 안에서 **밀린 · 막힌 카드만** 표로(카드 · 단계 · 다음 복습 · 밀린 날) + 최근 세션 3건. 상세 칸이 따로 없다.
  걸리는 점: 문장 규칙(사유 일곱 × 값)이 코드에 하나 더 선다 · 안 밀린 카드와 전체 모은 상태는 이 화면에 없다.
- **C 학생 명단 + 딱지** — 지금 초등 표와 같은 8열 표에 **전원**(29줄)이 서고 사유는 줄의 딱지. 거르개 탭으로 좁힌다. 카드는 숫자 요약만. 만드는 품이 가장 작다. 표본에서 29줄 중 19줄이 «없음».
- **D 반 개념 지도** — 반을 하나 골라 학생 × 단원의 5칸 띠를 한 판에. 세로로 읽으면 반이 같이 막힌 단원이 보인다. 사유는 줄의 딱지.
  걸리는 점: 반 끝점이 칸별 상태를 안 준다(끝점을 넓혀야 한다) · «초 · 중등 한 목록»과 어긋난다(반 하나씩) · 단원 세션 하나가 카드 다섯을 한꺼번에 모아 띠가 대개 «다 찼거나 다 비었다».
- **E 대조안 — 지금 화면 둘 안의 구역** — 새 화면 없이 중등 반 현황 · 초등 SRS 현황의 명단 위에 한 구역. 사유는 한 줄 문장. 목록이 화면 두 군데로 갈린다(A~D 와 같이 갈 수 없다).

시안 작업자의 의견(참고): «B 의 목록에 A 의 상세(5칸 띠)»가 가장 덜 읽고 찾는다. 표본을 짓다 보인 것 — «오래 쉼»은 거의 늘 «복습이 밀림»과 같이 선다 ·
«첫 시도 9 / 15»는 문장 안에서 날짜로 읽혀 «15개 중 9개 맞힘»으로 썼다.

## 정할 것 아홉 (줄마다 하나를 골라라)

1. **자리** — 새 화면(A~D) / 지금 화면 안의 구역(E).
2. **첫 화면의 주인** — 사유 목록(A · B) / 학생 명단(C) / 반 개념 지도(D).
3. **사유의 모양** — 사유별 묶음(A) / 한 줄 문장(B) / 줄의 딱지(C · D) / 섞기(어떻게).
4. **카드 230장** — 상세에 단원별 5칸 띠(A) / 펼치면 밀린 · 막힌 것만(B) / 숫자 요약만(C) / 첫 화면에 띠(D) / 섞기.
5. **문턱** — v1.1 그대로 시작 / 더 조인다 / 더 푼다(어느 사유를).
6. **«봤음»으로 닫기** — 1단계에 넣는다(저장 칸이 필요 — 두 번 배포) / 2단계로 미룬다 / 필요 없다.
7. **갈래 거르개의 이름** — «탐험 / 기억» / «임무 / 복습» / 갈래 거르개 없이 학교급만. (옆 메뉴에 이미 «오늘의 기억»이 있다.)
8. **세부** — (가) 0명인 사유 묶음을 보이는가 (나) 사유 없는 학생을 이 화면에 두는가(접어 둠 / 없음 / 펼쳐 둠) (다) 계정 없는 학생에게 기록 사유가 같이 서면 어느 목록에 두는가.
9. **같이 서는 사유** — «오래 쉼»과 «복습이 밀림»이 같이 설 때 둘 다 보이는가 / 하나로 접는가(어느 쪽으로).

리드 초안: 1 새 화면 · 2 사유 목록 · 3 한 줄 문장(B) — 둘째 사유는 «그 밖» 한 줄 · 4 섞기: 줄을 펼치면 밀린 · 막힌 것만(B), 이름을 누르면 상세에 5칸 띠(A) ·
5 v1.1 그대로 · 6 2단계로 · 7 «임무 / 복습» · 8 (가) 안 보인다 (나) 접어 둠 (다) 운영 확인에만 · 9 «오래 쉼»이 설 때는 «복습이 밀림»을 접고 «오래 쉼» 문장에 밀린 장수를 붙인다.
