## 소스와 출력의 연결

- 원본 `app.js`의 `fitConversations`와 `.script-body`는 대화 몸체 단위로 배경과 높이를 다룬다. 현 `src/lib/textbook/render/editorialCss.ts:88`은 각 `.tb-editorial-dialogue.tb-stage-opening`에 회색 배경·패딩을 준다. 각 발화를 블록으로 렌더링하는 경로와 실제 회색 띠가 일치한다.
- `src/lib/textbook/scripts/materialize.ts:116–149`는 원본 `board`를 선생님 설명 발화로 바꾼다. 최종 흰 말풍선에서 판서 위계가 사라진 현상을 설명한다. 이 정보를 생성 원고에서 잃으면 CSS만으로 원본 판서 유형을 안정적으로 복원하기 어렵다.
- 같은 파일의 역할 매핑은 민서·지호를 student1·student2에 연결하지만 본문 전체의 인물 호칭을 선택 인물에 맞게 치환하지 않는다. `src/lib/textbook/scripts/m2.json:115`의 기존 호칭이 출력에 남는 사례를 확인했다.
- `src/lib/textbook/layout/paginate.ts:15`는 `bodyTopMm: 40`을 쓴다. `editorialProjection`의 일반 개념 단계 투영이 안내 지면에도 적용되어 전용 00번 안내와 구분되지 않는다.
- 원본과 새 그림·글꼴 파일이 같은 바이트라는 사실은 자산 보존의 근거다. 패널·제목·행 구조까지 같다는 근거로 확장하지 않는다.

## 수정 수용 기준

1. 대화 몸체와 페이지별 발화 묶음을 표현하고 하나의 배경 안에서 조판한다. 동일한 짧은 원고와 긴 원고를 각각 양쪽 renderer에 넣어 비교해야 한다.
2. 판서 유형을 원고부터 최종 출력까지 유지한다. 요약·수식·설명이 연녹색 판서로 보이고 일반 발화와 구분되어야 한다.
3. 계속 페이지에도 실제 수업 제목·소제목·순번·진행 상태를 유지한다. 내용이 길거나 짧을 때 잘림·겹침 없이 간격을 조절한다.
4. 선택 인물의 이름표와 본문 호칭을 함께 맞춘다. 도현은/다은은 등 한국어 조사도 검증하며 원고의 수학 표현을 손상시키지 않는다.
5. 학습 안내는 고유 00번 지면으로 출력한다. 실제 사용자가 따라갈 순서와 각 활동의 목적을 보여 주며 개념 이해로 오표시하지 않는다.
6. 원본 지면별 머리말·제목·본문 시작점을 따로 측정한다. 고정 40mm를 모든 유형에 적용한 뒤 색만 바꾸는 방식으로 승인하지 않는다.
7. 기존 페이지 제한·내용 무결성·정답 숨김 조건을 유지한 실제 학생용과 답지를 생성해 다시 비교한다. 앞선 기능 테스트 통과를 시각 동등성 검사로 대신하지 않는다.
