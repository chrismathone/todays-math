먼저 [리드·Codex 합의](exam-report-style-consensus-20261019.md), 기존 오답 표 합의, DESIGN.md와 메뉴 구현 맵, 설치된 Next의 서버·클라이언트 가이드를 읽었다. 합의한 **H1(기본) · 편지형 · 정오 격자형 · 장부형**을 구현했다. 커밋·푸시·DB 스키마 변경·공유DB 쓰기·운영 배포는 하지 않았다. `node_modules`는 스테이징하지 않았다.

## 제품에 반영한 것

- 기존 `반 지면 설정`의 `PickerDialog` 안에서 `학생 성적표 구성` 옆에 네 양식의 native radio 선택을 추가했다. 기존 44px 라벨·적용·취소·Esc·저장 중 잠금을 사용하며 좁은 화면에서는 두 그룹을 세로로 놓는다.
- 문의 위치는 시안의 지어낸 연락처로 검수했다. 제품의 끝 문구는 기존 `오늘의수학`을 사용하며 실제 학원 전화번호를 지어내어 넣지 않는다.
- 양식은 기존 반 옵션 JSON의 선택적 `style`에 저장한다. 값이 없으면 H1이다. 구성의 기존 S1/M1 읽기 호환과 새 저장 S1 제약은 유지한다. 개발 비교용 `숫자만` 구성은 제품에 추가하지 않았다.
- 미리보기, 반 인쇄의 미확정 학생, 새 확정 PDF의 `paperHtml`이 `styleReportPages`와 같은 CSS·행 실측을 사용한다. 확정된 학생의 PDF 내려받기와 반 인쇄는 기존 보관 bytes를 그대로 읽는다. 반 전체 정오 집계 C2는 기존 가로 지면을 유지한다.
- 기본 H1은 JSON의 `style` 키를 생략하도록 정규화해 기존 설정·snapshot 지문을 보존한다. 고정 legacy M1 지문 `30570c8edb88127e095e04e9ee5cd6f40c0ab362248aa85c8a283110bdab3cba`와 S1 지문 `287a0f570e6ac53b1bcbc9ffafb5c4e05ab54eccd3ae7013455b5133fb78be21`을 회귀 시험했다. 비기본 양식은 지문에 포함하며 양식 변경·확정 중 변경 충돌을 검사한다. 이전 보관 artifact와 PDF를 덮어쓰지 않는다.
- 증서형·신문형·큰 숫자형은 제품 선택·제품 CSS에 없다. `/dev/exam-report-styles`에는 제외한 이름만 표시하고 네 양식을 비교한다.

## 합의의 조판 수정

공통: 문장·점수·맞힌 수·추이·재시험·문의의 첫 쪽 자리를 먼저 예약하고, 오답 행만 나눈다. 글꼴 적재 후 같은 DOM 측정 함수를 미리보기와 서버 Chromium에서 사용한다. 긴 단원·유형의 줄바꿈을 포함한 행 전체를 옮기며 번호·원래 순서를 보존한다. 문장 자체가 넘치면 최종 경계 검사가 막고 남은 자리를 안내한다. 글자 축소·말줄임으로 맞추지 않는다.

| 양식        | 반영                                                                                                                                          |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| H1          | 점수·맞힌 수를 실제 나란한 한 행으로 계산하고 고정 기록을 첫 쪽에 확보한다.                                                                   |
| 편지형      | 48.8mm의 추정 머리 예약을 없애 자연 높이를 사용한다. 점수와 맞힌 수를 작은 기록 행으로 묶고 점수 크기를 18pt로 유지한다. 문장은 11pt다.       |
| 정오 격자형 | 전체 문항을 원래 번호 위치의 ○·✕·—로 표시한다. 틀린 문항의 단원·유형은 별도 표로 둔다. 정오 칸 선의 굵기를 같게 하고 큰 ✕·밑줄 강조를 없앴다. |
| 장부형      | 오답 표가 이름표 열까지 전체 폭을 쓴다. 문장을 9pt에서 10pt로 넓히고 문의만 다음 쪽으로 나가지 않게 한다.                                     |

시안에 남아 있던 과거 H1의 grid/align CSS가 일부 블록을 내용 폭으로 줄이는 것을 찾아 제거했다. 네 양식은 제품 CSS를 그대로 읽고, 제외 후보의 CSS만 개발 파일에 남긴 상태로 전수 재측정했다.

입력 화면의 강점/보완/다음 행동 구분은 합의의 보류 사항이므로 바꾸지 않았다. 없는 강점이나 내용을 자동으로 작성하지 않는다.
