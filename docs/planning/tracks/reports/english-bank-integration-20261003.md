# 오늘의 영어 자료은행 통합·운영 반영 기록

2026-10-03. 승인된 A안(목록+상세), 기존 화면 스타일, [Claude·Grok 합의](english-bank-consensus-20261003.md)를 적용했다. 교사 진입점은 [오늘의 영어 자료은행](https://today.aywa.co.kr/#english-bank)이다. 앱 배포는 main push에 연결된 Vercel production이며, 실제 배포 결과는 [main 커밋](https://github.com/chrismathone/todays-math/commits/main)의 Vercel 상태로 확인한다.

## 구현

- 시험 없이 지문을 등록·검색·편집·보관 해제한다. 직접 입력/TXT/기존 시험 자료와 문제 세트 가져오기를 지원한다. 기존 자료를 자동 이관하지 않는다.
- 이용 근거를 별도 확인하고 대상 시험·제작 경로를 골라 기존 제작 화면으로 이어진다. 원문 개정과 제작 당시 원문·출처 사본을 보존한다. 수정·취소·저장 실패 시 초안 보호를 유지한다.
- 듣기은행은 자기 자료 검색과 기존 듣기 작업대 열기를 제공한다. EBS 공식 참조 192개를 학년·연도·회차로 검색하며 공식 페이지를 연다. EBS 음원·문서 재업로드가 아니다.
- `english-bank` 권한을 별도로 관리하며 기존 영어 전체 차단·듣기 시범 접근을 보존한다. 수학 모듈의 영어 표 접근 차단 검사에 새 지문 표·모델 네 종류를 추가했다.
- 모바일 목록 높이를 제한해 상세가 긴 목록 아래로 밀리지 않게 했다. 탭 방향키 이동과 입력의 접근성 이름을 확인했다.

## 검증 근거

저장·권한·경합·중복·불변 이력은 [백엔드 보고서](english-bank-backend-20261003.md)의 실제 PostgreSQL 11개 시나리오와 관련 89개 테스트로 검증했다. 공유 DB 대신 `127.0.0.1:55440/english_bank`의 별도 임시 스키마를 사용했다. 제작 트랙 88개, 화면 트랙 14개 테스트를 별도 수행했으며 중복 실행을 합산한 총계로 표시하지 않는다.

통합 후 일반 승인 교사 계정으로 실제 로그인해 다음 흐름을 Playwright로 확인했다. 테스트 환경은 loopback 4303과 별도 DB이며 유료 생성 API를 호출하지 않았다.

1. 독립 지문 등록 → 미확인 상태 보관 → 이용 근거 확인.
2. 대상 시험 선택 → 원문 복원 → 실제 문제 세트 저장 → 은행 사용 이력 왕복.
3. 원문 수정 → 개정 증가·확인 초기화 → 과거 사용 원문 사본 불변.
4. 소유한 시험의 TXT 원문 가져오기.
5. 탭 방향키/포커스 → 자체 듣기 선택 → 기존 듣기 작업대의 해당 초안 열기.
6. EBS 고1 검색 → 공식 EBSi 주소 확인. 데스크톱 1440px·모바일 390px의 가로 넘침 없음, 페이지 오류·API 500 없음.

로컬 증거는 `.qa-artifacts/english-bank/browser-result.json`, `screens/`에 있다. 테스트 전용 계정·원문은 운영에 넣지 않았다. 프로덕션 빌드, TypeScript, 변경 파일 ESLint, 어포던스 검사도 실행했다. 로컬 Next 개발 캐시가 하위 API를 누락하고 생성 타입을 손상한 문제는 캐시를 격리한 후 정상 경로로 재검증했다. 제품 API 우회나 타입 검사 생략은 하지 않았다.

## 운영 DB

2026-10-03 21:31 KST에 프로젝트 `jyaguxwuaxgdnovtulna`에 다음 두 마이그레이션만 적용했다. 실행 전 실제 메뉴 CHECK를 비교하고, 시험 적용 후 rollback으로 원상 복구된 것을 확인했다. 적용 후 별도 읽기 트랜잭션으로 다시 확인했다.

- `20261003150000_english_menu_permissions`: 기존 호환값(`english`, `textbook` 포함)을 보존하며 `english-bank`를 추가.
- `20261003160000_english_passage_bank`: 지문/개정/사용/멱등 수신 표 네 개. RLS 활성, PUBLIC/anon/authenticated 직접 권한 없음, 불변 사본 트리거 세 개.

적용 전후 계정 9, 시험 1, 기존 영어 문제 세트 2, 듣기 세트 3으로 동일했다. 기존 행을 대량 이관·재작성하지 않았다. SQL 자체의 BEGIN/COMMIT은 시험 적용 실행기의 바깥 트랜잭션에 맞춰 제거하고 rollback 후 스키마 복원까지 비교했다. 실제 적용과 마이그레이션 수신 기록은 한 트랜잭션에 넣었다.

앱을 되돌려야 하면 은행 메뉴가 없던 호환 빌드를 배포하고 새 은행 표는 유지한다. 자료가 생긴 표를 삭제하거나 과거 스냅샷을 변경하는 자동 rollback은 하지 않는다.

## 정리와 후속 범위

백엔드·은행 화면·제작 연결의 완료된 Orca 작업은 main에 병합하고 깨끗하고 비활성인 작업용 워크트리를 제거했다. Git 브랜치는 보존했다. 다른 작업의 eywa 워크트리는 별도 소유 작업이므로 임의 제거하지 않았다.

Kokoro 듣기 샘플 3개는 기존 운영 초안을 그대로 사용한다. 학교 장소 보기 시범은 [그림 제작 기록](../../../listening-samples/visuals/README.md)을 따른다. 이미지 문항 저장·학생 발행·인쇄, 사람의 청취/실물 출력 검수는 이번 은행 릴리스에서 완료했다고 주장하지 않는다.
