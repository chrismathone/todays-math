## 2. 검산

- **기계 검산**: 적용 답 · 개념 «예» 답에서 수를 뽑아(단위 · TeX 명령을 걷고 `\frac{a}{b}` → a, b), 물음에서 따로 세운 JS 식의 값과 견준다.
  식은 답 글을 보지 않고 물음에서 세웠다(숫자 카드 → 순열 전수 · $\square$ → 0~9 전수 · 큰 수는 `1e8` · `1e12`). 스크래치 `verify.ts` · `checks.ts`(저장소 밖).

- **손 검산**: 답이 낱말 · 읽기(«삼만 칠백팔») · 기호(`$<$`)인 것.
- ○× 는 참 · 거짓과 까닭이 맞는지, 참인 문장에 반례가 없는지(«언제나» · «모두» · «뿐»)를 다시 읽었다. 난이도마다 원래 + 보강 10개 가운데 참 4~6 (스크래치 자가 잰다).

  도형 전체의 모양 · 크기 · 방향 · 위치, 화살표 · 글자 · 숫자 카드로만 묻는다. 화살표 방향 답은 회전 모의 계산(`rot`)으로 논리 검산했다.
