# Codex 독립 판단 (codex exec · 읽기 전용 · 추론 high · 2026-10-20)

**Q1 — A. 넘치는 답의 번호를 알리고 출력을 멈춘다.**  
교사는 분수·지수·행렬의 작은 기호까지 읽으며 채점한다. 축소율 70%도 원래 글자 크기에 따라 읽기 어려울 수 있으므로, 임의의 하한보다 원래 크기를 지키는 편이 낫다.  
위험: 드문 정답 하나 때문에 수업 직전 문제지 출력까지 지연될 수 있다.

**Q2 — A. 일반 시험지는 둘째 쪽부터 머리를 생략한다.**  
학생의 풀이 공간을 확보하고, 쪽 구분은 기존 바닥글로 유지한다. 첫 쪽만 승인된 상황에서 새 머리를 추가하거나 양식마다 다른 반복 규칙을 만들 근거는 부족하다.  
위험: 종이가 섞이면 제목이 없는 낱장을 구별하기 어렵다.

**Q3 — A. 빈 선택 정보와 빈 개념 상자는 생략한다.**  
학생이 작성해야 하는 인적 사항과 교사가 제공하는 시험 정보·개념 설명은 용도가 다르다. 후자가 비었다고 빈 상자를 남기면 작성 과제로 오해하거나 풀이 공간만 줄어든다.  
위험: 교사가 배부 뒤 직접 정보를 적으려는 경우에는 여백이 부족할 수 있다.

**Q4 — C. 자습 모눈만 2단에도 제공한다.**  
워크북의 좌우 분할은 문항 폭을 지나치게 좁히지만, 자습의 아래 모눈은 문항 폭을 유지하면서 학생이 계산할 자리를 준다. 별도 풀이 공간을 선택했을 때는 기존 우선순위를 유지한다.  
위험: 쪽 수가 늘 수 있으므로, 모눈 높이를 포함해 다시 측정·배치해야 한다.

**Q5 — A. 양식을 바꿔도 선택한 단 수를 유지한다.**  
교사가 풀이 분량에 맞춰 정한 단 수를 양식 변경으로 바꾸면 배부할 쪽 수까지 예상과 달라진다. 입력된 유형·전략과 바닥글의 식별 정보는 유지하되, 자동으로 붙는 «제 1 교시»와 «컴팩트» 같은 부가 표기는 줄인다. 저장값은 보존한다.  
위험: 평가원 1단처럼 시안 표본과 다른 조합을 선택할 수 있다.

원장님께 반드시 다시 여쭐 항목은 없다. 다섯 항목 모두 위임받은 세부 판단 범위에 해당한다.

사실 확인에서 **Q3의 «입력하지 않은 날짜·배점도 생략한다»는 설명은 수정이 필요하다.** 현재 [WorksheetPrint.tsx](/D:/todays-math-srs-e5/src/components/unified/print/WorksheetPrint.tsx:62)는 빈 날짜를 오늘 날짜로, 빈 학년을 선택 문항의 학년으로 보완한다. 배점 총점도 [기본값 100점](/D:/todays-math-srs-e5/src/components/unified/print/types.ts:188)이 있다. Q3의 생략 원칙은 실제로 비어 있는 선택 정보에 적용하고, 이 기본값들을 이번 결정으로 일괄 삭제하지는 않는다.

Q1의 차단 조건과 Q2·Q4·Q5의 현재 동작은 코드와 부합한다. 다만 넓은 정답이 실제로 얼마나 드문지와 운영 배포 여부는 이번 코드 열람만으로 확인하지 않았다.
