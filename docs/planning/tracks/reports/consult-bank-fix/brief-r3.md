# 합의 요청 3회차 — «다른 문제가 된 행»의 처분 하나만 (2026-10-03)

2회차 Q5 에서 codex 는 ㉯(되돌리고 잠근 뒤 새 문제는 새 식별자로), grok 은 ㉰(같은 취지 — 묻는 것이 바뀐 20행까지 포함)였고 리드는 ㉮(유지)였다. 2:1 로 리드가 졌다.
그대로 따르기 전에 **두 분이 못 본 사실 둘과 안 하나**를 놓고 한 번만 더 묻는다. 답이 같으면 그대로 한다.

## 1. 더 잰 것 (두 분이 요구한 검증)

- 갱신 7,103행 가운데 **같은 행이 다른 문제가 된 것은 298행**이다.
  - 수가 다시 뽑히고 정답의 값도 바뀜: 252행(35틀)
  - 수가 다시 뽑혔고 정답의 값은 같지만 다른 문제: 26행 — 원기둥의 전개도 04(6행 · «옆면의 넓이가 125.6» → «옆면의 둘레가 70.8») · 일의 양(8행 · «A 11일, B 11일» → «A 9일, B 6일») · «다음 중 … 인 것의 개수»의 식 다섯이 통째로 바뀐 것(12행)
  - 묻는 것이 바뀜: 20행 — 원기둥의 전개도 01 · 03(12행 · «옆면의 가로 / 넓이» → «옆면의 둘레») · 대관람차(8행 · «100분 후의 높이» → «100분 동안 가장 높은 지점을 몇 번 지나는지»)
  - (같은 문제로 본 22행: «비가 $10:2$» → «$5:1$» 16행 · «1모둠 · 2모둠» → «가 모둠 · 나 모둠» 6행)
- 이 298행을 가리키는 것: 저장된 시험지 0 · 시험지 문항 0 · 담기 바구니 0 · 문항 신고 0 · 검수 기록 0 · 답안 0. 운영 DB 에 저장된 시험지는 **한 장도 없다**(`test` 0행).
- 옛 내용의 성격: 엔진이 8월 말 ~ 9월에 고쳐지면서 같은 씨앗의 산출이 달라진 것이다. 고친 까닭은 대부분 옛 산출의 결함이다 — 퇴화값(«비 $5:5$» · «분속 60 과 60» · «가로 11, 세로 11 인 직사각형» · «A 11일, B 11일»)이나 문항 설계의 수리(전개도 유형이 다른 단원과 겹쳐 «전개도에만 있는 값»을 묻게 바꿈 — 2026-08-31). 다만 난수 차례가 밀려 **성한 옛 문항**이 다른 수로 바뀐 것도 섞여 있다(«$A(-8,-1)$, $B(0,9)$ 의 중점» → «$A(2,-9)$, $B(10,-3)$ 의 중점»). 둘의 비율은 재지 않았다.

## 2. 두 분이 못 본 사실 — 원장의 말

외부 검토 결과를 보고받았을 때 원장이 한 말이다(그대로):

> «해당 문항을 고치는 방향으로 하면 어때? 생성기도 당연히 고치고. 모두 고쳐야겠긴 하겠네»
> «어차피 문제은행은 아직 오픈 전이라 지금 고치면 괜찮음.»

이 말은 **외부 검토가 짚은 결함 문항**을 두고 한 것이다. 그때 원장은 «적재본이 고치기 전부터 엔진과 어긋나 있었다»는 것을 몰랐다 — 그 어긋남까지 제자리에서 맞춘 것은 리드의 판단이었다. 그래서 이 안건을 합의에 올렸다.

## 3. 선택지

- **㉯ 되돌리고 잠근다 + 새로 적재**(2회차의 두 분 안, 298행으로 바로잡음): 298행을 원장의 옛 내용으로 되돌리고 출제에서 뺀다. 지금 엔진의 문항은 새 씨앗 · 새 문항 코드로 따로 적재해 틀마다 수를 채운다.
  - 따르는 일: 잠긴 행 +298(지금 1,778) · 적재 계획 하나 추가 · 문항 코드 298개 새로 · 갱신 도구가 잠긴 행을 견주지 않게 고침 · 되돌린 옛 내용은 그대로 보존된다.
- **㉱ 지금 상태를 «개장 전의 기준선»으로 두고, 앞으로를 막는다**(리드의 새 안): 298행은 그대로 둔다. 대신
  - 298행의 목록(문항 코드 · 앞뒤 내용)을 «개장 전 교체» 기록으로 따로 남긴다(원장에 이미 앞뒤가 있다).
  - 갱신 도구(`refresh-engine-content.ts`)에 **문지기**를 넣는다: 발문의 수 토큰이나 정답의 값이 바뀌는 행은 «다른 문제»로 보고 **제자리 갱신을 거부**한다. 그런 행은 «잠금 + 새 씨앗 적재»만 할 수 있다. 오늘 뒤로는 문항 코드가 가리키는 문제가 바뀌지 않는다.
  - 까닭: 지킬 것은 «코드가 가리키는 문제가 바뀌지 않는다»인데, 그 약속의 상대(저장된 시험지 · 인쇄물 · 기록)가 아직 하나도 없다. 되돌리면 결함 있는 옛 문항 298개를 되살려 잠가 두는 일이 된다.

## 4. 물음

1. ㉯ 와 ㉱ 가운데 하나를 골라 달라. «오픈 전 · 참조 0»이라는 사정과 원장의 말을 보고도 ㉯ 라면 그 까닭을 한두 문장으로.
2. ㉱ 를 고른다면 문지기의 기준(«발문의 수 토큰이 0 · 1 말고 바뀜» 또는 «정답의 값이 바뀜» 또는 «묻는 문장이 바뀌어 정답 값이 바뀜»)에 보탤 것 · 뺄 것.
3. ㉯ 를 고른다면: 되돌린 298행 가운데 **성했던 옛 문항**(퇴화값이 아닌데 난수 차례 탓에 바뀐 것)도 잠그는가, 출제에 그대로 두는가.
