## 1. 일한 방법

- 소단원마다 세 칸(개념 · ○× · 적용)을 한 표로 놓고 읽은 뒤(`dump.ts` — 줄에 선 것과 안 선 것을 같이 찍는다) 고친 글을 문항마다 조각 파일에 직접 쓰고,
  `splice.ts`(TypeScript AST 로 그 id 의 배열 원소만 바꿔 끼움 — 리드 확인: 조건 여섯)로 끼웠다. 첫 소단원은 diff 를 전부 읽어 도구를 확인했다.
  끼울 때마다: 난이도 딱지 그대로 · 원소 수 그대로 · 안 건드린 자리의 글 그대로 · 제어 문자 없음을 도구가 본다.
- 뺀 까닭은 조각의 `RETIRED // 까닭` 에 적고 도구가 원장의 `gone` 으로 옮긴다. 값만 묻는 «예»를 떼는 것은 `NOEX`(글을 새로 쓰지 않고 예 칸만 뗀다).
- 소단원을 닫을 때마다 `review.ts` 로 codex 에 보냈고, 답을 은행에 대어 가려 조각 `…b.frag.ts` 로 반영했다.

- 사례 카드 24장은 모두 보편 진술로 다시 썼다(뺀 것 없음). 예: «$\sqrt{(x-2)^2}$ 간단히 하기» → «근호 안이 식의 제곱일 때 근호 벗기기»(부호에 따라 갈린다) + 예 «$x<2$일 때 … $x-2$가 아닌 까닭».
- 적용은 «값을 구하시오»를 까닭 · 잘못 찾기 · 구별 · 조건을 묻는 물음으로 바꿨다. 예: `$\sqrt{0.16}$의 값` → `$\sqrt{0.16}$을 $0.04$라고 답한 잘못을 소수점 아래 자릿수로 설명`.
- **안 받은 지적 1**: `m3-01-03-a1`(«$\sqrt{3}\times\sqrt{12}$가 자연수가 되는 까닭») — codex 는 `o1` 의 예와 수만 다르다고 했으나, `o1` 을 일반 진술(까닭에 수가 없다)로 바꿔 장면이 겹치지 않고, 처음 은행 문항이라 뺄 수 없다.
- 줄 밖에서 고친 것: 처음 은행 · 보강의 **값만 묻는 예** 30여 장을 뗌(codex «예만 계산형») · 조건이 빠진 카드(`xc13` 자연수 조건 · `c7` 양수 조건 · `xc2` «근호를 벗길 수 있으면 유리수»는 $\sqrt{\pi^2}$ 이 반례) · 수 하나에 묶인 카드(`xc7` 정수 부분 · `xc8` 같은 수를 더한 비교 · `xc13` · `xc18`) · 판단만 묻던 적용(`m3-01-02-xa4`) · 계산뿐이던 줄 밖 적용(`m3-01-01-xa24`).

- «푸시오 → 해» 꼴 적용과 «해는 …이다» ○× 는 풀이 계산이라 대부분 빠졌다. 남긴 것은 풀이 방법을 고르는 까닭 · 해를 버리는 까닭 · 식에 담기지 않은 조건 · 잘못 찾기다.
- 활용 소단원의 사례 카드(«넓이가 $49$인 정사각형» · «합이 $10$인 두 수» …)는 «식을 세우는 원리»로 고쳤다(식에 담기지 않은 조건 · 차가 주어진 두 양 놓기 · 양쪽에서 잘려 $2k$만큼 짧아진다 …). 뺀 개념 카드 4(`03-02-xc18` · `03-03-xc14` · `xc19` · `xc24` — 같은 판단을 다른 카드가 말한다).
- codex 가 짚은 수학 결함(받음): «인수분해가 안 된다»는 «계수가 정수인 일차식의 곱으로는»이어야 한다(`03-01-a3` · `xa7` · `xc20` · `03-02-a1` · `xc24`) · $x^2+ax=0$ 의 해 $0$ 으로는 $a$ 를 못 정한다(`xc7` · `xc17`) · 최고 높이는 한 번만 지난다(`03-03-c4`) · «닿지 못하는 높이»와 «실수인 해가 없다»는 다르다(`xo21`).
- 되살린 것 2(codex «아깝다»): `m3-03-01-xo20`(실수의 제곱은 음수가 될 수 없다는 근거) · `m3-03-02-xa21`(중근 조건의 후보에 양수 조건을 다시 댄다).
- **절반 넘게 뺀 칸**: 세 소단원의 적용(30 → 11 · 11 · 12)과 ○×(30 → 15 · 15 · 15). **3장 아래 칸은 없다**(가장 얇은 칸: «풀이» ○× 하 3 · 적용 중 3 · 상 3 / «근의 공식» 적용 중 3).
