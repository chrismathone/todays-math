# M28 평행사변형의 각 조건과 실제 도형

후속 구현·검증은 [새 각호 직렬화 경로 보고서](exam-engine-m28-inset-20261021.md)를 따른다. 아래 기록은 당시 실행과 보류 근거로 보존한다.

대상은 새로 생성되는 `2-2|평행사변형|15A`이다. 기존 출제·저장 문항이나 운영 DB를 수정하지 않는다.

발문에서 B=(px+q)°, D=(x+s)°, A=C를 주었지만 그림의 B·D는 항상 약 66.50°였다. 이제 발문의 B=D 관계로 얻는 각도에 좌표를 맞춘다. 정답이나 계산한 각도를 그림 라벨에 추가하지 않고, 원래 주어진 A·C의 같은 각 표시는 보존한다. 발문·정답·해설·난수 세 번의 순서는 그대로이다.

첫 좌표 후보는 수학 조건과 렌더 성공만으로 충분하지 않았다. 실제 그림에서 B=9°, 16°일 때 A·C 각호가 반대 변 밖으로 나가므로 반려했다. 두 번째 후보는 맞춤 좌표에서 두 높이를 계산하여 각호의 반지름을 제한한다. 9°~72°의 실제 SVG 64개, 각호 128개를 경계선·원호 벡터로 검사했다. 원호 끝점의 출력 반올림을 고려한 0.15px 허용치를 명시했으며, 그림 픽셀을 수학적 정답 근거로 쓰지 않았다. 선택한 9°·16°·72° PNG도 직접 확인했다.

생성 가능한 x=4~15, p=2~4, q=1~12의 432조합에서 발문으로 방정식을 다시 세웠다. p−1>0으로 해는 유일하며 B=D는 9°~72°, A=C는 108°~171°이다. 실제 좌표 각과의 최대 오차는 약 0.00391°이다. 사각형의 네 변과 A/B/C/D, A/C 각호를 유지한다. 같은 도형 함수를 쓰는 기존 `08`은 32개 입력에서 전체 출력이 바이트 기준으로 같았다. 이 432조합과 렌더는 기술 검증이며 새 저작·독립 풀이·승인 문항 수가 아니다.

독립 검수자가 실제 현재 API를 532회(실제 seed 100회와 원래 handler에 입력을 고정한 432회) 호출하고 네이티브 SVG 64개를 별도로 그렸다. 발문에서 독립 풀이한 정답·유일성·각·볼록성·대변 평행·표시 보존을 통과했다. 후보 렌더 기록을 독립 실행 횟수로 복사하지 않았으며, 실제 호출 출력과 최초 import 의존성의 실행 전후 해시를 묶었다.

독립 검수는 추가 한계도 찾았다. 실제 SVG 경계선은 소수 셋째 자리, 각호 끝점은 첫째 자리로 출력되어 64개 중 60개에 인접 변 기준 최대 약 0.060782 SVG 단위의 미세한 중심선 돌출이 있다. 반대편 변에 대한 여유는 모두 양수(최소 약 3.882268)이다. 앞의 0.15px 허용치를 적용한 기술 검사를 엄격한 완전 내부 배치 승인으로 확대하지 않는다. 물리 인쇄·픽셀 가독성 영향은 측정하지 않았다. 독립 원장 위치는 `.qa-artifacts/exam-resume-20261008/m28-current-api-audit-20261021-r1/`이다.

현재 적용 뒤 공개 회귀 4파일 139개가 통과했다. 프로젝트 옵션을 읽은 변경 3파일의 타입 검사도 오류 0이었다(전체 프로젝트 타입 검사라는 뜻은 아니다). 실행 전에 메모리 기준으로 중단한 이전 시도와 실행하지 못한 RED는 통과로 세지 않는다. 후보 렌더 기록과 실제 적용 뒤 검증은 각각의 소스 해시에 묶는다.

기출 연습 어댑터의 이 갈래 버전을 `20261021-input-angle-and-contained-marks-r1`로 올린다. 기존 일반 엔진 ID나 저장 문항을 자동 갱신하는 작업은 포함하지 않는다. 내부 좌표 계산에 쓰는 sin/cos는 학생 풀이에 요구하지 않는다. 전체 학년·선수학습·Unit/live family·권리·내용·출제 가능 승인은 별도이며, 운영 적재는 0이다.

근거 폴더는 `.qa-artifacts/exam-resume-20261008/engine-upgrade-20261019/m28-figure-preview-20261021-r1/`, `…/m28-figure-preview-20261021-r2/`이다. 반려한 R1과 원래 증거도 보존한다.

별도 공식 교육과정 조사는 `.qa-artifacts/exam-resume-20261008/m2-pytha-curriculum-evidence-20261021-r1/`에 보존했다. 2025 중2의 2015 개정과 2026 중2의 2022 개정 적용을 확인했지만, 학년군 기준만으로 실제 중2의 직접 근호 표기나 선수학습 완료를 승인하지 않았다. 근호 없는 유한 10조합 풀이 제안은 QA 자료이며 생산 코드에 적용하지 않았다.

다음 요청은 읽기 전용 `D:/math-figure-editor/docs/export/todays-math/README.md`의 편집기·모눈 개선을 검토하여 가져오는 작업이다. 학교 원문이나 이미 출제된 문항의 전수검수 범위로 확장하지 않는다.

푸시 전 추가 main `a4494fe0f`의 SRS 변경도 보존 통합했다. 이후 메모리 기준 미충족으로 전체 Vitest 재실행은 시작하지 않았다. 대신 API의 최초 import 104파일과 네이티브 5파일 해시가 이전 실제 호출 당시와 같음을 확인하고, 현재 렌더러로 SVG 64개를 다시 컴파일·정제하여 이전 출력과 바이트 일치를 확인했다. 보존된 532개 발문도 다시 검산했으며, 이를 새 API 호출이나 새 독립 문항으로 세지 않는다. 재실행 범위·남은 시험은 `m28-post-main-20261021-r1/checkpoint-validation.json`에 구분한다.

후속 Python 독립 검수 `m28-strict-precision-audit-20261021-r1`은 실제 직렬화된 SVG 원호의 원 중심·끝점·극값을 네 변의 반평면에 대조했다. 64개 현재 명세를 세 방식으로 실제 렌더해 총 192회 계산했다. 현재 기본은 엄격한 중심선 내부 배치 4/64, 끝점 소수 여섯 자리만 늘린 사본은 0/64(최악 돌출 약 0.000538), 경계선과 같은 좌표에 맞춰 각호 양끝을 안으로 줄인 QA 사본은 64/64였다. 허용오차로 음수 거리를 통과시키지 않았다. 단순 정밀도 변경으로 해결됐다고 주장하지 않으며, 끝점이 바뀌는 사본은 기본 렌더·충돌 검사의 일치와 표시 의미·인쇄 검토가 더 필요해 생산 코드에 적용하지 않았다. 08·6종 바이트 계약의 후보 회귀도 이 검수에서는 미실행이다. 이 192회는 새 TypeScript/API 호출이나 학생용 독립 풀이가 아니다. 관련 78파일 해시는 불변이며 M28 엄격한 직렬화 경계 보류는 유지한다.
