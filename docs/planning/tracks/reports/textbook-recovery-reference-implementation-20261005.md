[geometry.py](../../../../scripts/qa/textbook/recovery/geometry.py) is independent Python/PyMuPDF code. It handles embedded required fonts, A4 dimensions, PDF span/image bounds, DOM clipping bounds, 0.5 mm anchor and common-row coordinates, row-key/order/page-split correspondence, vector write lines including thin filled border rectangles, 0.2–0.35 mm thickness, 7±0.5 mm pitch, ≥95% written line length, thick grey bands, QR outside write boxes, dialogue 9.2–10.5 pt/0.1 pt steps/common unit size, deterministic numbers, continuation labels, disabled typed activities/references, and answer field/node leaks. Ordinary prose and choices are never searched for incidental matching answer words.

The mutation suite passes **28 tests**: one valid control with ordinary answer words/choices and an allowed public example, plus 27 deliberate failures covering geometry, a physically clipped PDF image, font requirements, semantics, answers, numbers, continuation and incomplete coverage.
