# 교과서 변형의 Codex 구독 전환

2026-10-11 사용자의 “코덱스 내부요금제로 돌려” 지시 이후 새 유료 DeepSeek/TypeSafe
호출을 멈추고 저장된 ChatGPT 인증의 Codex CLI를 사용했다. 인증 파일을 읽거나 토큰으로
직접 API를 구성하지 않았다. 앱의 기존 AI 기본값은 유지했다.

실제 CLI 0.162.1 구조화 응답·PNG 입력을 먼저 확인하고, 정답을 숨긴 풀이, 해설의 모든
단계 점검, 같은 학습 목표·수준·완결성과 실제 숫자/조건 변경 검토를 각각 독립 세션에서
수행했다. 모델명은 CLI에서 확인되지 않아 null로 기록했다. 실제 thread·usage·종료 코드와
입력/그림/스키마/출력/영수증 지문은 각 실행의 파일에 남겼다. boolean을 Noul 확률이나
사람 승인으로 바꾸지 않았다.

첫 5쌍과 다음 14쌍의 실제 검토·네 지면 검사가 통과했다. 19쌍 38문항을 소유한 공유
대기 행으로 적재하고 원자적으로 승인했다. 기존 904쌍과 합쳐 923쌍이다. 원문 12,301개,
사용 가능 11,826개, 보류 475개를 보존하며 전체 완료를 주장하지 않는다. 909쌍 시점의
DB census는 원문/교재/단원 전체와 기존 변형 1,865개의 불변, 모든 실제 retry 계획의
정확한 두 슬롯, 새 대기 문항 0개를 확인했다. 뒤의 cohort는 추가 적재 뒤 새 census로 확인한다.

별도 Codex Orca 세션은 답을 보지 않고 10쌍의 원문·변형 30문항을 풀고 SymPy로 확인했다.
한 미적재 초안의 짝수 제곱근 표현이 모호해, 원문은 그대로 두고 초안에 주근 기호를
명시했다. 바뀐 전체 후보 지문을 새로 묶어 독립 검산했다. 소문항·±·복수 근·객관식
번호/값의 표기 차이는 모든 근, 소문항 순서, 단위와 변수 정체성을 보존하는 규칙으로만
비교한다. 숫자 변경은 두 슬롯 모두 허용한다.

확인: 새 승인 경계와 구독/기존 검토 회귀 206개 테스트, CLI 실행/생성 29개 테스트,
대상 ESLint, 전체 TypeScript 검사 통과. 검산 테스트는 주입한 응답만 사용한다. 실제 문항
검산과 가짜 테스트 fixture를 구분하며, 실제 CLI 파일 지문을 재확인하는 실행기가 DB에 쓴다.
생성 checkpoint의 기존 DeepSeek token 이력은 새 API 호출이 아니다. 이 전환 뒤 추가 유료
호출은 0개, 사람 검토 로그 추가는 0개다.

현재 증거: `.qa-artifacts/textbook-codex-plan-20261011/`의 첫/둘째 review, render,
qualify receipt, 독립 풀이와 909쌍 census. 독립 풀이 출력 SHA-256은
`027461c5a058618511213236c763a634e914aedcb01d6d47e8cee4f5a0528c7e`다.
별도 데이터 디렉터리에 검증한 사본을 보존했다. 코드는 로컬 main에 통합하며 push·배포는
수행하지 않았다. 남은 미적재 초안과 1만여 원문의 묶음 생성/검토를 이어서 처리한다.
