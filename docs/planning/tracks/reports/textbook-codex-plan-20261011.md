직접 API를 구성하지 않았다. 앱의 기존 AI 기본값은 유지했다.

입력/그림/스키마/출력/영수증 지문은 각 실행의 파일에 남겼다. boolean을 Noul 확률이나
사람 승인으로 바꾸지 않았다.

첫 5쌍과 다음 14쌍의 실제 검토·네 지면 검사가 통과했다. 19쌍 38문항을 소유한 공유

세션의 그룹 프롬프트·스키마·원문별 결과·PNG 지문·원시 출력·영수증을 보존한다.

있어도 실제 세 단계가 통과한 원문 쌍만 선택해 승인한다. 공유 영수증을 단일 문항

첫 묶음 4쌍과 둘째 묶음의 3쌍이 실제 검산·네 지면·DB 저장·원자적 승인까지

묶음 승인 경계는 실제 영수증·출력·스키마 파일을 다시 읽고, 전체 묶음의 현재 입력
