## 5. 필요한 수정과 재검수 합격 조건

1. **자동 단원 도입을 항상 짝수 왼쪽·홀수 오른쪽의 두 쪽으로 묶는다.** S의 p5 타이틀이 짝수 쪽으로 옮겨지고 다음 홀수 쪽에 경로가 오도록 시작 정책과 두 쪽 보장을 자동 도입에도 적용한다. M의 이번 p4–5 통과만으로 종료하지 말고 앞 안내 페이지 수가 달라지는 출력도 확인한다. 빈 쪽을 넣더라도 차례/경로의 목적 쪽수는 최종 pagination 결과로 다시 계산해야 한다.
2. **학습 경로를 별도 구조로 만든다.** 실제 학습 목표 체크행, 개념 번호·명칭·실제 목적 쪽수, 앞/현재/다음 3열 연결, 시작 전 점검, 첫 학습일/다시 설명한 날을 출력한다. 소단원 목록을 목표 대신 쓰지 않는다. 원본의 상대 기준은 헤더 top 10mm, 목표 40mm, 경로 83mm, 연결 173mm, 준비 점검 216mm, 날짜 250mm이며 모두 단원 content 원점 기준이다. 개념 수가 다르면 행 수를 조정하되 기능 영역은 유지한다. 필요한 실제 교육 정보가 없으면 공급 부족을 표시하고, 기준본의 다른 단원 내용을 채워 넣지 않는다.
3. **단원 타이틀의 공통 문구를 단원별 역할 필드로 분리한다.** 질문·설명 문단·핵심 문구를 각 단원의 실제 정보로 출력한다. 번호는 원본 76pt 위계, 제목과 삽화는 단원 body 시작선에 정렬하고 현재의 추가 7mm 들여쓰기를 재검토한다. 원본의 한 줄/두 줄 제목 분기와 contain 배치를 적용하여 M에서 보인 삽화 너비 약 7.7% 축소를 해소한다. 전체 펼침면을 다시 렌더링해 제본 여백을 확인한다.
4. **표지는 제목 적응과 고정 영역을 함께 유지한다.** 현재 제목·학년·코드를 보존하면서 제목 영역의 높이를 확보해 코드가 제목 길이에 따라 약 12mm 위로 이동하지 않도록 한다. 표지 그림 컨테이너의 원본 top 128mm/height 116mm, 수식 띠 bottom 34mm, 브랜드 bottom 19mm를 기준으로 배치한다. 원본의 수식 두 개+연결선 역할을 해당 교재에 맞는 수식으로 복원한다. 중등 공식 자체를 초등 표지에 강제로 복사하지 않는다. 실제 긴 제목으로 전체 표지를 다시 보고 텍스트/삽화 간 침범을 확인한다.
5. **개념 지면의 큰 제목은 실제 개념명으로 쓴다.** `개념 이해`는 kicker/진도 역할로 두고 본문 제목과 부제의 중복을 정리한다. 개념별 헤더 원점을 원본의 compact running band/여백에 맞춰 재측정한다. R p14 큰 제목 윗점 28.43mm와 현재 44.86mm의 차이를 해소한다. 일률적인 bodyTop 40mm를 그대로 둔 채 글꼴만 바꾸는 수정으로는 합격할 수 없다.
6. **긴 개념은 의미 단위별로 분할한다.** 정의 전체→예시 전체의 분할을 각 하위 개념의 정의→조건/이유→예시/비교→주의/설명→확인 순서로 바꾼다. 페이지 수를 R과 강제로 같게 만들 필요는 없다. 동일 주제인 유리수 분류, 유한소수의 약분 조건, 자릿수 원리, 배수 조건에서 설명과 예가 붙는지 확인한다. 분류 도식·좌우 비교·풀이 단계·번호 있는 확인문항/작성 공간은 실제 원고가 공급하는 구조를 렌더링해야 한다. S에는 덧셈의 구조를 쓰고 유리수 도식을 넣지 않는다.
7. **계속 페이지에 개념 식별 정보를 반복한다.** S p13–14/M p20–22 같은 출력에 실제 개념명·계속 표시·현재 진도 띠를 다시 출력하고 그 높이를 pagination에서 측정한다. `정의와 성질` 또는 `예로 확인`만으로 새 페이지를 시작하지 않는다. 주의·반례·확인 요소는 필요한 교육 정보가 제공되는지와 최종 출력되는지를 구분해 검증한다. 현재 PDF에서 안 보이는 요소의 원인을 CSS 부재로 일괄 처리하지 않는다.

이 수정은 조판 구조, 목적 페이지 계산, 높이 측정, 홀짝 정책 등 결정적 구현 항목이다. 이번 작업에서 AI 판단 통합을 설계하거나 변경하지 않았다. 재검수 때에는 동일 의미의 실제 원고를 선택하여 PDF 전체 페이지를 내보내고, 위 대응표의 각 역할 영역을 다시 비교해야 한다. 삽화 파일 일치, 단색 토큰 일치, PNG 일부의 유사도, 서로 다른 학년의 페이지 총수는 최종 합격 증거가 아니다.
