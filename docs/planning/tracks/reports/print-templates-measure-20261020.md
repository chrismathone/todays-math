여섯 모두 직접 한글 텍스트를 가진 잎 요소에서 CDP로 **Batang, 로컬 설치 글꼴(isCustomFont=false)**을 확인했다. 빈 wrapper에서 나온 `fonts=[]`를 글꼴 증거로 쓰지 않았다. 서버 PDF·다른 OS에서 같은 폰트를 사용한다는 주장은 아니다.

text-y는 실제 텍스트 fragment의 top을 0.5px 단위로 모은 값으로, KaTeX 접근성 텍스트는 제외한다. 분수 위아래 조각도 포함하므로 순수 산문 줄 수가 아니다. 같은 문제 번호끼리 비교하면 평가원·정통·모던·유형은 **25/25개 모두 같은 값**, 워크북과 자습도 **25/25개 모두 같은 값**이다. 앞 네 종의 5문항 반복 단위는 4/5/3/3/11, 워크북·자습은 4/5/4/5/11이다. 오른쪽 풀이 칸으로 폭이 좁아지면서 그림 발문과 긴 발문에서만 차이가 생겼다.

### 해석과 인수

‘차이를 크게 못 느낀다’는 관찰과 맞닿는 구현은 있다. 번호 모양·색·선택지 규칙·글꼴 팩은 여섯 모두 같고, 네 종은 같은 문제의 text-y도 전부 같다. 반면 지면이 동일한 것은 아니다. 머리 정보 구조와 높이가 다르고, 워크북·자습은 풀이 칸이 본문 폭과 총 쪽 수까지 바꾼다. **비교의 중심을 색이나 번호 장식보다 문항 구조·풀이 공간에 두는 근거**로 사용할 수 있으나, 새 템플릿 형태는 이 측정 작업에서 정하지 않았다.

증거는 [하네스 README](../../../../scripts/qa/print-templates/README.md)의 실행법으로 재생한다. 첫/마지막 여섯 종을 나란히 본 [첫 쪽](../../../../scripts/qa/print-templates/evidence/contact-first.png) · [마지막 쪽](../../../../scripts/qa/print-templates/evidence/contact-last.png), [전체 수치·소스 지문](../../../../scripts/qa/print-templates/evidence/metrics.json), [픽셀 비교](../../../../scripts/qa/print-templates/evidence/pixel-comparisons.json), [잉크 검사](../../../../scripts/qa/print-templates/evidence/capture-ink-checks.json), [DOM snapshot](../../../../scripts/qa/print-templates/evidence/rendered-pages.json)을 보존했다. PNG 12장은 개별 template-first/last 이름으로 같은 폴더에 있다. 12장 모두 1,001개 이상의 어두운 픽셀 조건을 통과했으며, 실제 범위는 **1,823–89,561개**다. 정통 첫 쪽·자습 마지막 쪽과 여섯 종 contact sheet를 육안 확인했다. 문항 번호 1–25의 누락·중복 없음, 페이지 이미지 로드 검사, 브라우저 pageerror 없음도 확인했다. 실물 프린터 검수나 2단·OCR·영어·답지까지 검증했다는 뜻은 아니다.

snapshot은 부모 스키마 `styles` + 템플릿별 `first`/`last`/`items`와 호환된다. first/last는 실제 document wrapper와 A4 루트를 포함한다. `documentClass`/`documentStyle`, 순수 A4 `firstSheet`/`lastSheet`도 별도로 남겼다. `items`는 숨은 측정 호스트와 미리보기 중복 없이 export 지면의 실제 25개 문항만 번호순으로 담는다. CSS의 글꼴 URL은 data URI, 그림은 inline SVG이며 캡처 전용 화면 숨김 CSS는 제외했다. 상속된 폰트 변수는 wrapper와 `:root` bridge로 보존한다.

측정 도중 메모리 보류 지시를 준수했고, 재개 후 기동마다 3GiB 조건을 확인했다. 초기 빈 PNG와 빈 폰트 조회는 증거로 채택하지 않고 모두 수정 캡처로 덮어썼다. 작은 Vite root의 index.html 자동 의존성 탐색으로 transitive CJS 오류를 해결했다. 성공 실행은 `finally`에서 Chromium·Vite를 닫고 종료했다. 부모는 이후 Wire 브라우저 단계를 시작할 수 있다.
