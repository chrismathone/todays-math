## 방법

1. **원본 찾기** — DB `source_file`(G: 경로)을 SSD(`/Volumes/새 볼륨/{중등,고등}교과서/`)로 옮기고, 이관과 **같은 가르기**
   (`scripts/import/textbook/` 의 `segment` · `extract` — 고치지 않고 불러 쓴다)를 다시 돌려 외부 열쇠
   `tb-<sha1(경로)[:16]>-<구역>-<번호>` 를 다시 만들었다. 12,301 열쇠가 전부 다시 나왔다.
2. **원본 읽기** — 이관은 한컴 COM 으로 만든 HWPX 변환본(저장소 밖 · 이 기계에 없다)을 읽었다. 여기서는 CLAUDE.md 9번
   (한컴 창 자동화 금지) 때문에 **HWP 이진 판을 직접 읽는 판**(`hwp5_flow.py` — OLE · 레코드 · 표 칸 · 수식 · 그림 자리)을 새로 썼다.
3. **뼈대** — 한글 수식 스크립트와 LaTeX 를 같은 꼴로 편다(`skeleton.py`). 위첨자 · 아래첨자 · 분수 선은 표지(ˆ ˍ ⁄)로
   남긴다 — Codex 1회차가 «`x²→x₂` · `1/2→12` 가 같음으로 통과»를 반례로 보였다. 그림 자리 · D-164 «오른쪽 → 다음 그림» · D-161 이름은 접는다.
4. **견주기** — 낱말 차이마다 까닭을 붙인다(`compare.py`). 수 · 문자 · 부호 · 부등호 · 뜻 기호가 바뀌거나 물음 문장이 빠지면 «다른 문항».
   면제(머리글 · 단원 제목 · 표 칸 · 이웃 문항 글)는 **근거가 있을 때만** — 파일의 제목 낱말 · 찾은 문단 앞뒤 40 문단의 표 칸 ·
   바로 이웃 번호의 DB 글. 판정은 모든 차이로 하고, 원장에는 보기용으로 앞의 12개만 남긴다.
5. **정답** — 원본 빠른 정답 칸 → 없으면 풀이 끝의 값. 부호 · 부등호 · 첨자를 지킨다(`−3 ≠ 3`).
6. **자리** — 이관 가르기와 따로, DB 글의 줄을 원본 문단에서 찾아 앞의 번호를 읽었다(판정에는 안 쓴다 — 맞음 10,875 · 어긋남 15 · 못 읽음 1,229, 어긋남은 손으로 봐 대조기 쪽 헛짚음).

- 뼈대가 첨자 · 분수 구조와 부호 · 부등호를 지우고 있었다 → 표지로 남기고 뜻 기호의 변경 · 삭제는 «다른 문항».
- 경계 면제가 «같은 파일 부분 일치 92점»만 봤다 → 이웃 번호 · 묶음 지시문 범위 · 다음 번호 못 찾음의 근거를 요구.

- «글만 고침»은 면제가 아니다(조건 · 목표가 바뀔 수 있다) → B 로 남김.
- 정답 «다름»은 3분류(최종값 대응 · 글자만 · 근거 없음) — 첫째만 같음으로 올린다.
