# 초5·초6 C형 개념 문항 교정

기준 커밋: `4a6aae41f975d93295cec5834927ab467c05be09`. 원 감사 입력 129개와 코디네이터가 추가로 요청한 두 항목, 총 131개를 모두 종결했다: **수정 127개, 근거 있는 유지 4개**. 추가 변경은 `e5-2-2-1-xc3`, `e5-2-2-3-xc4` 두 개이다. 두 정의는 약분 가능 조건을 본문에 남기고 같은 짧은 나눗셈 답을 묻게 정렬했다. 수정은 소유한 네 은행 파일의 definition에 한정했다.

## 주요 교정

- 분수 덧셈·뺄셈의 동일한 학생 문장에 연산을 명시했다(`e5-1-5-1-c1`, `e5-1-5-3-c1`).
- 각기둥·각뿔의 요소 수 공식은 입체·연산·요소 이름을 남기고 수만 묻는다.
- 둘레와 넓이, 앞·옆에서 본 쌓기나무 개수 등 가능성 전체를 비우던 문항은 조건을 고정하고 '항상 같은 것은 아니다'와 실제 반례·이유로 설명한다.
- 자연수 경계·포함 여부·범위에 들어가는 수가 한 개 이상이라는 조건, 0·1·양수 조건, 선택한 밑면, 90도 회전 방향을 명시했다. 비례배분은 두 항이 같은 경우 차 0도 설명한다.
- 초5 문장에 새로 쓰던 문자 k는 제거했다. 쌓기나무 층수는 일반적인 층으로 유지하며 이상 조건만 묻는다.

유지한 항목은 분모를 더하거나 빼지 않는 설명(`e5-1-5-1-xc7`, `e5-1-5-3-xc6`), 기타 비율 합산(`e6-1-5-1-xc25`), 반올림 후 값이 같을 수 있음(`e6-2-2-4-xc17`)이다. 답의 동의 표현과 설명 단서는 별개 수학적 정답으로 보지 않았다.

## 독립 검토와 수용 근거

Codex가 원문·수정문·학생 문장·기대 답을 모두 읽었다. 구독 Claude CLI(opus, high)를 빈 격리 cwd와 도구 금지 조건으로 호출했다. 첫 가림 검토는 43개씩 세 묶음, 수정 후 가림 검토는 40개, 9개, 3개, 1개였으며 경계 역추적 문항 한 개를 추가로 재검토했다. 완성 정의는 43개씩 세 묶음, 최종 수정 11개(추가 두 항목 포함)는 최신 가림 답을 제공해 다시 검토했다. 이후 코디네이터 요청에 따라 경계 역추적 문항은 양 끝을 포함한 범위의 연산을 묻도록 고치고 새 가림 답과 최신 정의로 다시 pass를 확보했다. **131개 현재 정의 모두 정확한 after 정의를 읽은 최신 pass와 현재 학생 문장에 대한 가림 풀이를 확보했다.** 입력·원응답·메타데이터는 전부 함께 보존했다.

Claude가 제시한 유효한 반례는 수정했다. 같은 넓이·다른 둘레에서 '같을 수도 있다', 비어 있는 수의 범위의 경계 비유일성, 소수로 끝나지 않는 1/3, 문자 k의 학년 수준, 부사 '함께'에 '쉽게'도 들어가는 문제를 수용했다. 단위분수와 기약분수의 경쟁은 약분 행위로 빈칸을 옮겼으며 1/1도 기약이라는 사실을 최종 검토에서 확인했다. 일반어 '수·값'이나 활용형·동치식은 다른 수학 개념으로 세지 않았고, 모서리 길이를 면의 변 길이로 표현한 답도 같은 의미로 기록했다. 투표 수로 의미 판정을 대체하지 않았다.

## 검증

- 감사 sourceHash 129개와 추가 항목의 원본 객체 지문 두 개를 원래 전체 concept 객체의 SHA-256과 대조했고, 기준 은행·입력의 원문과 정확히 일치했다.
- 실제 로드된 은행에서 개념 2621행, ○×·적용·그림 3059행을 기준과 비교했다. ID·순서·level·section·term·example·givenCase 및 기타 필드는 모두 보존됐다.
- 모든 원장 ID를 정확히 한 번 포함하고 수정 127개 모두 exact before/after로 기록했다. 실제 splitBlankSentence·정의 스키마와 strict KaTeX 115개 수식 검사를 통과했다.
- 초5·초6 전체 은행을 대단원 단위로 비교한 동일 학생 문장·서로 다른 답 충돌은 0개이다. 추가한 두 기약분수 문항은 문장과 답이 같고 예제가 다른 동일 개념이므로 기존 ID·배치를 보존했다.
- 최종 관련 기존 시험 네 파일: 110개 통과, 실패 0. 수정 중 넓은 여섯 파일 실행도 404개 통과했다. 네 TS 파일 ESLint 및 git diff --check 통과. 전체 저장소 typecheck는 실행하지 않았다.
