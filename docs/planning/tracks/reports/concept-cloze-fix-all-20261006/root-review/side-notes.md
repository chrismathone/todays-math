# 복습 오답 검토에서 발견한 원천 문장 의견의 처리

독립 [Claude 오답 응답](../srs-traps/srs-traps-context-20261006-1919-raw.md)의 별도 의견 9개를 리드가 읽었다. 실제 대상·조건이 빠진 두 정의는 추가로 고쳤으며 [추가 변경 원장](changes.json)에 포함했다. 초6 각뿔의 첫 초안은 학년 밖 평면 표현과 선분·옆면이라는 경쟁 답이 있어 채택하지 않았다. 두 번째 초안도 모양의 상위 분류명이 참이 되는 점을 지적받아, 주어진 조건으로 정해지는 입체도형의 이름을 묻는 최종 문장으로 바꿨다. 그 최종 문장은 답을 숨긴 검토와 완성 정의 검토를 모두 통과했다. 초4 길이 환산은 기준 단위 m를 명시한 문장을 두 검토에서 통과했다. 모든 초안 입력과 원응답을 보존했다.

다른 의견의 처리도 기록한다. 초3의 '직각인 꼭짓점'은 직각이 있는 꼭짓점을 뜻하는 관용 표현이며 옳은 지시 대상이다. 직각삼각형 두 개로 만든 사각형은 각의 성질을 기준으로 직사각형임을 묻고, 정사각형은 그 특수한 경우다. 두 직선의 수직 관계를 직각이라고 표현하는 답과 0.01a·a/100의 동치 답은 같은 의미의 답으로 구별한다. 초6 반올림 예는 첫 문장의 반올림 조건이 뒤의 예에도 이어지며 둘째 자리 반올림이 원래 수와 같아도 오류가 아니다. 같은 모양을 묻는 문장에서의 오답 칩 충돌은 해당 칩을 거절해 해결했다. 중1 묶음과 OX의 난이도 차이는 기존 필드이며 이번 문장 명료성 교정에서 난이도·묶음 배치를 바꾸지 않는다.

이 기록은 별도 의견을 모두 수학 오류로 확정했다는 의미가 아니다. 새 의미를 채점 코드에 추가하거나 학생 기록을 수정하지 않았다.
