# 초3~중3 개념백지 문장 교정과 적용

2026-10-06. 학생지에서 대상·조건·연산을 알 수 없던 C형 문장을 고치고 공용 은행, 교재 제작 원고와 복습 개념에 연결했다. 이전 전수 감사의 394건, 추가 충돌 5건과 복습 검수에서 발견한 조건 누락 2건을 모두 처리했다. **395건은 교정했고, 6건은 문항별 근거를 확인해 유지했다. 미처리 항목은 0건이다.** 기존 지적이 철회된 항목의 명료성 보완도 포함하므로 395건을 모두 확정된 수학 오류로 세지 않는다.

학생에게 인쇄되지 않는 소제목이나 앞 문제에 기대지 않도록 각 문장에 필요한 대상과 범위를 남겼다. 예를 들어 초4의 “10000은 □이다”는 “10000은 가장 작은 □ 자리 수이다”로, 초5의 서로 같던 덧셈·뺄셈 문장은 각 연산을 명시하는 문장으로 바꿨다. 중2 삼각형의 중심은 선의 종류와 중심 이름을 함께 가리던 구성을 고쳤다. 같은 뜻의 낱말과 동치인 수식은 다른 개념 답과 구별해 검토했다.

## 검토 근거

계획을 Claude가 독립 검토한 뒤 초3~4, 초5~6, 중1~3을 Orca Codex 작업으로 나눴다. 작업자는 변경 전후와 학생 문장을 읽었고 Claude는 빈칸 답을 숨긴 문장과 완성 정의를 검토했다. 반례와 경계 조건은 수정 후 재검토했다. 리드는 작업자 변경 393문장을 다시 읽고 중3 한 문장의 풀이 목표를 추가로 명시했다. 복습 검수에서 발견한 초4 환산 단위·초6 각뿔의 조건 누락도 고쳤다. 이 세 문장의 최종 학생 문장과 완성 정의는 각각 독립 검토를 통과했다. 추가 의견의 처리 근거는 [원천 의견 처리](root-review/side-notes.md)에 있다.

- 학년별 변경·유지 이유와 독립 응답: [초3~4](e3e4/report.md), [초5~6](e5e6/report.md), [중1~3](m1m2m3/report.md).
- 최종 문장·학생용 문장·기대 답: [적용 원장](applied-changes.json), [집계](summary.json).
- 리드의 추가 교정 및 원응답: [추가 교정](root-revisions.json), [독립 응답](root-review/).

사용자가 승인한 Codex·Claude 방식이다. Grok 검토 또는 은행 9,119개 전체에 대한 두 모델의 전수 검토를 수행했다는 의미는 아니다. 이번 교정 범위는 현재 C형을 지원하는 초3~중3이며 성취기준 전수 대조는 포함하지 않는다.

## 공용 데이터와 교재 연결

변경한 것은 선언된 395개의 `definition`이다. ID·개념명·소단원·난이도·문항 순서·예제·○×·적용·그림 문항은 그대로다. 선언된 문장만 이전 글로 되돌리면 전체 은행이 기준 해시와 정확히 일치하는지 검사했다. 검사 결과는 [검증 기록](validation.json)에 있다.

개념백지와 교재 개념 조회, 복습 명제는 모두 새 정의를 읽는다. 기본 은행의 정의를 사용하는 정적 교재 대사 **83곳**도 동기화했고 [변경 대사](manuscript-changes.json)에 이전·새 글과 원천 ID를 기록했다. 교재 교정 원장은 총 147곳, 그중 은행 정의 동기화는 102곳이다. 일곱 학년의 materializer 결과와 커밋할 JSON은 모두 같으며 원천 원장도 재계산 결과와 같다. 최초 교재의 기준 해시와 v15 원본 대화는 보존된다.

빈칸 위치를 바꾸면서 기대 답의 원문이 달라진 항목은 321개다. 그 ID는 [집계의 `changedAnswerIds`](summary.json)에 남겼다. 개념 ID와 학생 기록을 유지했고 기록 재저장·숙달 초기화는 수행하지 않았다. 새로 구성하거나 출력하는 개념백지와 새 교재 원고에 적용된다. 기존 인쇄 코드의 내용 변경 감지와 교재의 확인 후 내용 변경 검사, 발행본의 고정된 스냅샷은 기존 동작을 유지한다. 이미 배포한 PDF나 발행본을 소급해서 고치지 않는다.

복습용 오답은 새 문장 문맥에서 다시 판단해 별도 [오답 검수 기록](srs-traps/README.md)에 보존했다. 후보 67개 중 받음 45개·거절 22개이며, 바뀐 문맥 10개와 사라진 판정 4개를 두 모델이 독립적으로 읽었다. 두 모델의 의견이 다른 하나는 보수적으로 거절했다. 추가로 고친 두 원천 문장은 활성 오답 표에 속하지 않으며 최종 은행으로도 후보·판정 검증을 통과했다. 스케줄·세션 규칙·학생 데이터·서비스 플래그를 변경하는 작업은 아니다.

초4 `e4-2-6-1-xc23`의 원문은 다각형 이름을 둘레로 정한다는 수학 오류여서 [정오표 후보](errata-candidates.json)에 따로 기록했다. 발행본에서의 사용 여부를 확인한 기록은 없으므로 특정 발행본에 오류가 있다고 단정하지 않는다.

## 검증

모든 수정 문장 395개를 실제 `ConceptBlankPaper`로 인쇄 매체에서 렌더했다. 학생지·채점표 **432쪽** 전체에서 넘침·수식 오류·빈칸 표기 누출은 0건이었다. 학년별 첫 학생지와 채점표 14장을 리드가 시각 확인했다. 중3·초4·초6은 최종 추가 교정 후 다시 검사했고 기존 실물 지적의 회귀 검사 3쪽도 통과했다. [인쇄 측정](print-verification.json)에 학년별 수량이 있다.

초기 통합의 은행·파서·조판·인쇄 코드·복습 원천과 상태 검사 13파일 228건이 통과했다. 교재 대본·원천 원장·개념 연결·복구·정확 선택 검사 5파일 51건, 발행 시험지의 고정 자료 검사 16건, 교재 형식 보존·보기 그림 연결 검사 9건도 통과했다. 복습 오답의 원천·그룹·API 연결 검사 6파일 75건이 통과했다. 통합 검사의 문항별 반복 검색은 소단원별 실제 페이지 조회로 바꾸어 전체 교정 문장의 검증을 유지했다. 최종 추가 교정과 최신 복습 화면 병합 뒤의 검사 결과는 [최종 검사 기록](final-checks.json)에 있다.
