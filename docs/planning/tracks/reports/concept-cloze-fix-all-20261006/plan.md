# 전 학년 개념백지 문항 교정·적용 계획

사용자 지시: “완전 수정하고 적용”. 이전 감사의 최종 원장 394개(확정 143, 추가 검토 173, 지적 철회 78)를 모두 처리하고, 필요한 교정을 공용 은행과 교재 원고에 적용한다. 승인된 Codex·Claude 교차 검토를 사용한다.

## 완료 조건

- 143개 확정 결함을 해소하고, 173개 추가 검토 항목에 문항별 최종 결론을 남긴다. 모호한 문항은 조건·대상·연산·응답 범위를 명시해 고친다. 단순 길이나 정상적인 동의 표현만으로 문항을 바꾸지 않는다.
- 철회한 78개도 처리 원장에서 누락하지 않는다. 관련 문항을 함께 고칠 필요가 있으면 추가 ID와 이유를 명시한다. 보고서 수치를 채우기 위한 일괄 치환은 하지 않는다.
- 모든 변경 전·후 문장과 학생용 빈칸·기대 답을 Codex가 읽고, Claude가 독립 검토한다. 남은 반례를 고쳐 재검토한다. 미해결 지적을 완료로 표시하지 않는다.
- 공용 `definition`을 완성했을 때 정상 개념 설명이어야 한다. C형 빈칸의 질문 범위를 분명히 하고 A/B/D형과 SRS에서도 올바른 개념으로 남긴다.
- 기존 ID·문항 순서·소단원·난이도·개념명·예제·다른 문제 유형을 보존한다. 학생 숙달 기록과 발행본을 덮어쓰지 않는다. 새 수학 개념이나 학년 밖 용어를 전제로 추가하지 않는다.
- 기본 은행에서 바뀐 정의를 교재 제작의 정적 대본에 동기화한다. 변경 대사는 교정 원장에 기록하고 최초 원고 해시를 보존한다. 보강 은행은 교재 대본 생성 원천이 아니지만 개념 조회·백지·SRS는 새 정의를 읽는지 검증한다.
- 기존 선택의 재구성, 옛 인쇄 코드의 변경 감지, 학생지와 채점표의 빈칸 수, 교재 초안의 원천 변경 감지와 발행본 고정을 검사한다. 여러 학년의 실제 인쇄 지면을 렌더해 넘침·수식 오류를 확인한다.
- 최신 원격을 병합하고 관련 검사와 정상 pre-push를 통과시켜 main에 푸시한다. 배포 완료를 확인한다. 완료·병합·깨끗함·실행 종료가 확인된 Orca 워크트리만 가지를 보존하고 정리한다.

## 작업 분할

Orca Codex 워크트리 세 개가 초3~4, 초5~6, 중1~3의 서로 다른 은행 파일을 담당한다. 각 작업은 자기 학년의 수정 원장과 문항별 처리 결과를 기록한다. 리드는 사전 계획의 Claude 검토, 통합 검토, 교재 대본·교정 원장 동기화, 은행 검토 기록, 회귀 검사, 인쇄·배포 확인을 담당한다. 공유 node_modules·Prisma 클라이언트는 재생성하지 않는다.

초3~중3 C형 은행이 이번 범위다. 초1~2·고등 C형, 다른 문항 형식의 전수 재저작, 성취기준 전수 검증을 수행했다고 표시하지 않는다. 문항 오류를 학생의 지식 결손으로 바꾸지 않는다.

의미 판단은 근거가 있는 검토 기록으로 남기고, ID·원문·변경 범위·빈칸 수·원고 일치는 코드로 대조한다. 기존 TypeSafe 지침의 state·confidence 원칙을 따른다. 제품 AI 연동이나 채점 정책의 새 설계를 추가하지 않는다.

## Claude 계획 검토에 따른 보완

본문과 충돌하는 경우 이 보완 절이 우선한다.

1. 착수 전 감사 기준과 현재 원문의 해시를 대조한다. 각 변경의 소비처(C형·다른 백지 형식·SRS·교재 대본)를 검증하고, 독립 예제·○× 등의 모순이 실제 발견되면 추가 문항 ID와 근거를 원장에 올려 함께 고친다.
2. 답이 같은 표현 명료화와 빈칸·기대 답이 달라지는 교정을 구별해 ID별로 기록한다. 기존의 개념 자체를 다른 개념으로 교체하지 않는다. SRS는 동일한 개념 ID의 새 문장으로 다음 복습을 구성하며, 예전 답안·복습 기록을 새 문항으로 소급 재채점하거나 초기화하지 않는다.
3. 394개 모두 수정 또는 근거 있는 유지로 종결한다. 확정 지적도 재검토에서 잘못된 것으로 판명되면 근거를 남겨 철회한다. 어느 한 검토자라도 제기한 유효한 반례가 남으면 교정을 다시 작성한다. 실제 미해결 문항이 남은 상태로 완료·배포하지 않는다.
4. Claude의 첫 검토는 **기대 답·개념 소제목을 주지 않고 학생 문장만** 읽어 빈칸을 복원한다. 근거 있는 유지로 처리할 문항도 포함한다. 이후 기대 답과 완성 정의를 제공해 서로 다른 참인 답(순서를 바꾸는 경우 포함), 정답 노출, 0·1·도형의 포함 관계·연산의 정의역 등 반례를 검사한다. 같은 뜻의 다른 표현은 인정한다. 실제 C형은 개념 소제목을 인쇄하지 않는다.
5. 학년별 원고를 통합해 같은 개념의 정의와 용어를 대조한다. 이번 교정은 기존 은행의 해당 학년 용어를 사용하고, 새 용어가 필요하면 기존 설명으로 풀어 쓴다. 교육과정 판별·전수 대조를 수행했다고 주장하지 않는다.
6. 변경 문항을 **학생지와 채점표 모두 전부** 인쇄 매체로 렌더해 넘침·수식 오류·빈칸 수를 확인한다. 전체 A/B/D형은 기존 검사를 함께 돌린다.
7. 옛 인쇄 코드는 기존 `bankChanged` 경고를 유지하고, 새로 열거나 출력하는 저장 선택은 새 은행으로 구성한다. 발행본은 원문을 보존한다. 이번 교정은 문항 명료성 교정이며, 발행본의 수학 오류가 실제 확인되면 해당 항목을 정오표 후보로 따로 기록한다. 이미 인쇄된 종이·PDF나 기존 학생 답안을 조용히 바꾸지 않는다.
