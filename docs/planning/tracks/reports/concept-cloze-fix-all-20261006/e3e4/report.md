# 초3·초4 C형 문장 교정 결과

기준 커밋: `4a6aae41f975d93295cec5834927ab467c05be09`. 원 입력 146개와 리드가 추가한 대단원 충돌 2개를 모두 처리했다. **147개 정의 수정, 1개 유지, 미해결 0개**이다.

| 학년 | 처리 | 수정 | 유지 |
| --- | ---: | ---: | ---: |
| 초3 | 62 | 61 | 1 |
| 초4 | 86 | 86 | 0 |
| 합계 | 148 | 147 | 1 |

`changes.json`에는 실제로 바뀐 정의의 정확한 원문·최종문, 모든 ID의 처분과 구체적 이유, 검토 입력·원응답·메타데이터 경로를 기록했다. 기본 은행 수정은 8개, 보강 은행 수정은 139개다. 추가 ID는 `e4-2-1-3-xc5`, `e4-2-1-4-xc7`이다.

## 주요 교정

- `e3-1-1-3-xc25`: 십의 자리가 처음부터 0인 `302-115`에서는 일의 자리로 빌리는 데 이미 두 번의 받아내림이 필요하다. 빼어지는 수의 십의 자리 숫자가 0이 아니라는 조건을 명시하고 횟수만 묻는다.
- `e3-2-5-1-xc6`: 같은 컵을 같은 횟수로 부었다는 사실만으로 그릇의 들이가 같지는 않다. 매번 가득 담은 컵을 남김없이 붓고 두 그릇이 꼭 맞게 가득 찬다는 조건을 보인다.
- `e4-2-4-4-xc13`: 사다리꼴에 직사각형을 포함하는 은행의 기존 정의에 맞춰, 직사각형이 아닌 사다리꼴에 직각이 있을 때의 개수를 묻는다.
- `e4-2-6-1-xc23`: 다각형 이름을 둘레로 정한다는 잘못을 바깥 변의 개수로 바로잡았다. 원문은 수학 오류이므로 이미 발행된 자료가 있다면 리드의 **정오표 후보**이다.
- 추가 두 문항: 덧셈·뺄셈을 학생 문장에 각각 명시해 같은 대단원의 동일 문장 충돌을 없앴다. 가분수로 바꾸는 방법을 보존하고 그 분수 종류를 묻는다.

유지한 `e3-1-6-1-xc2`는 “똑같이 나눈 조각은 모양과 {크기}가 같아 서로 포개면 꼭 겹친다.”이다. 포개면 꼭 겹친다는 문장의 조건이 크기를 고정한다. 가림 풀이와 완성 정의의 독립 검토에서도 같은 답과 유지 근거를 확인했다.

## 수용 근거

Codex가 모든 원문·수정문을 읽고 Claude 구독 CLI로 독립 검토했다. 첫 검토는 학년·대단원·학생 문장만 제공하고 용어·소단원·기대 답은 가렸다. 다음 검토에는 정확한 현재 정의, 완성 문장, 기대 답, 가림 응답과 원 지적을 함께 제공했다. 유효한 반례·모호한 응답·수학적 설명의 누락을 수정한 뒤 재검토했다. 동의 표현, 같은 지시 대상, 동치 수식과 같은 답의 순서 교환은 서로 다른 오답으로 취급하지 않았다.

`review-coverage.json`은 **현재 학생 문장**에 대한 가림 검토와 **정확한 현재 정의**에 대한 최종 pass를 148개 모두 연결한다. 이는 검토 버전의 누락·혼동을 막는 대조이며 모델 투표로 의미 판단을 대신한 것이 아니다. 모든 검토의 입력·원응답·메타데이터를 이 폴더에 보존했다.

검증은 실제 실행한 은행과 `splitBlankSentence`를 사용했다. 문장 계약, 핵심어, 수식 괄호 및 strict KaTeX 검사를 통과했다. 기준 은행과 대조하여 ID·배열 순서·난이도·단원·용어·예제·givenCase 및 모든 OX·적용·그림 행이 그대로임을 확인했다. 처리 목록 밖의 2,631개 개념과 다른 형식 3,842개 행에는 변화가 없다. 초3·초4 대단원 기준의 동일 학생 문장·다른 답 충돌도 없다. 자세한 결과는 `acceptance.json`에 있다.

관련 기존 검사 4개 파일의 **103개 테스트**, 편집한 TS 네 파일의 **ESLint**, `git diff --check`를 통과했다. 최종 실행 로그도 함께 보존한다.

## 범위와 리드 후속

이번 작업은 초3·초4의 지정된 정의와 추가 두 정의만 교정했다. 전 학년 교육과정 전수 대조를 수행했다고 주장하지 않는다. 기존 학습 기록·학생 답안·발행본을 바꾸거나 소급 재채점하지 않았다. 교재 대본 동기화, 전체 병합 검사, 학생지·채점표 인쇄 검증, 발행본 정오표 판단, main 게시·배포는 리드의 통합 작업이다.
