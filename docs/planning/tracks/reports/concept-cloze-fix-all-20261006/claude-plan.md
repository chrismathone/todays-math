**판정: 조건부 찬성.** 범위 한정, 일괄 치환 금지, 미해결을 완료로 표시하지 않는 원칙, 발행본 고정은 타당하다. 다만 아래 원칙 다섯 개를 고치고 검증 여덟 개를 추가해야 합의할 수 있다. 문항과 원장은 보지 못했고 계획문만 검토했다.

## 위험한 원칙 (수정 필요)

1. **"다른 문제 유형 보존"과 "공용 definition 변경"이 충돌한다.** 정의가 바뀌면 같은 정의를 쓰는 A/B/D형의 정답, 오답지, 예제가 틀어질 수 있다. 변경 정의마다 소비처 목록을 만들고, 충돌하면 보존하지 말고 추가 ID로 원장에 올려야 한다. 결함 원인이 개념명이나 예제에 있을 때도 같다.
2. **ID를 보존하면서 기대 답이 바뀌는 경우의 처리가 없다.** 변경을 "표현 명료화(답 동일)"와 "빈칸·기대 답 변경"으로 나눠야 한다. 후자는 기존 SRS 기록이 사실상 다른 질문에 대한 기록이 된다. 새 정책을 설계하지 않더라도 해당 ID 목록은 사용자 결정 사항으로 보고해야 한다.
3. **"확정 143개 해소"가 수정을 강제한다.** 교정 중 지적 자체가 오류로 드러나면 근거와 함께 철회로 재분류할 수 있어야 한다. 173개의 결론은 닫힌 집합(수정 / 근거 있는 유지 / 범위 밖 이관)으로 두고, 유지에도 근거를 요구해야 한다.
4. **종결 규칙과 배포 게이트가 없다.** Codex와 Claude가 합의하지 못한 문항을 어떻게 처리할지 정해야 한다. 미해결이 남을 때 원문 유지 후 목록화해 배포할지, 배포를 막을지도 명시해야 한다.
5. **발행본 고정이 알려진 수학 오류를 학생 손에 남긴다.** 모호함이 아닌 수학적 오류가 들어간 발행본 목록을 따로 뽑아 정오표 여부를 사용자가 결정하게 해야 한다. 옛 인쇄 코드는 감지 후 동작도 정해야 한다. 옛 채점표가 틀린 문항은 학생 오답으로 기록되면 안 된다.

## 누락된 검증

- **가림 풀이:** 검토자가 기대 답을 가린 채 학생용 문장만 보고 빈칸을 채운다. 기대 답과 다르지만 수학적으로 옳은 답이 나오면 미해결이다. 변경 전후 비교만 읽는 검토로는 모호성을 잡지 못한다.
- **정답 유일성:** 순서가 바뀌어도 되는 빈칸과 교과서가 허용하는 동의 용어를 채점표가 처리하는지 확인한다.
- **정답 누설:** 명시화하며 추가한 조건이나 개념명이 빈칸 답을 드러내지 않는지 확인한다.
- **경계·반례:** 완성 정의마다 0, 1, 포함 관계(정사각형과 직사각형, 사다리꼴의 "한 쌍이라도")를 대입한다. 조건을 덧붙이다 정의가 좁아져 틀리는 경우를 따로 본다.
- **학년 간 일관성:** 워크트리가 학년대로 나뉘어 같은 개념(각, 평행, 비율, 평균 등)이 다르게 교정될 수 있다. 리드가 교차 대조하고, 하위 학년 정의가 상위 학년에서 거짓이 되지 않는지도 본다.
- **용어 판정 기준:** 성취기준 전수 검증을 하지 않더라도 "학년 밖 용어"를 판정할 기준 문서는 필요하다. 학년별 적용 교육과정 판과 교과서 용어를 고정해야 한다. 2026년 기준으로 중3만 2015 개정이라 판이 섞인다.
- **착수 전 원문 대조:** 감사 시점 원문과 현재 은행 원문이 일치하는지 먼저 확인한다. 다르면 해당 지적은 재판정한다.
- **렌더 범위:** "여러 학년" 표본으로는 부족하다. 길이가 늘었거나 수식이 바뀐 변경 문항은 학생지와 채점표 모두 전부 렌더해야 한다.
