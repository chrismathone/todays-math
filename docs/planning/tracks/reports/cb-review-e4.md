## 0. 일하는 법 (이 트랙에서 정한 것 — 브리프 안에서)

- 소단원 하나씩: 스크래치 덤프(원장의 남은 줄 + 보강 파일의 원문 줄 + 외부 검토 의견) → 편집 도구로 문항마다 고침 → 고친 줄을 B · C · D 로 다시 읽기 → 남은 외부 검토 문항은 `keep --id … --note` → 훑는 줄은 `keep --section … --screen`.
- **사례 표지(CASE)를 다는 선** — 브리프 §3.1′ 를 이렇게 읽었다:
  - 단다: 뜻 문장이 **아무 수나 골라 든 사례 하나**인 카드(«$35214$ 읽기» · «만 원을 내고 $6000$원짜리를 살 때의 거스름돈» · «$3$만과 $5$만 사이를 $4$칸으로 나눈 한 칸»). 답이 낱말이어도 단다(«이천만을 $2000000$으로 쓴 잘못» → {하나 모자란}).
  - 안 단다: **수 자체가 개념**인 카드 — 자리값 · 단위 사이의 관계($10000$은 $100$이 $100$개 · 억은 만의 $10000$배 · $9999$보다 $1$ 큰 수) · 정의에 고정된 수(직각 $90^\circ$ · 삼각형 세 각의 합 $180^\circ$) · 보편 진술(빈칸이 수여도 «$10$배» · «네 자리»처럼 규칙의 수).
- **용어에 조건을 싣는 꼴** — «(주어진 수 · 식) + 무엇을 하기»(«$10000$이 $40$개인 수 쓰고 읽기»). 답은 싣지 않는다.
- **답이 새는 문장**(굵은 글이 용어에 그대로 보이는데 이름이 아닌 것)은 ⑴ 빈칸을 뜻의 다른 곳으로 옮기거나 ⑵ 용어에서 답을 뺀다(«네 자리마다 바뀌는 단위» → «새 단위(만, 억, 조)가 붙는 자리 간격»).
- 수식 뒤 조사는 자(`notation.ts`)가 **마지막 숫자의 소리**로 잰다 — `$1000000000000$`(일조) 뒤는 «을»이어야 초록이다(원래 뜻 문장도 «은»).
