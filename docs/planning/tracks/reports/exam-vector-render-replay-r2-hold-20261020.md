# U51 R2 — 후보 JSON 결합 시점의 추가 보류

R1에서 확인한 SVG 결합/스냅샷 교체와 spec 재읽기 문제는 R2에서 차단했다. 읽은 spec 바이트의 해시를 확인한 뒤 같은 바이트를 파싱하고, 실제 CLI와 현재 작업트리의 코드 위치를 맞추는 검사도 추가했다. 관련 Node 12파일 148개와 lint, 실제 기존 strict 렌더러의 정상 두 그림, 별도 변조 그림의 보류 및 SVG 교체 대조의 거부를 확인했다. 이 근거는 수학·학년·권리 승인이 아니다.

독립 작업자는 별도 제어와 실제 렌더러로 **후보 JSON 자체의 읽기/해시 재읽기 사이 교체**를 추가 발견했다. ID·본문·답이 다른 새 후보 파일 해시를 기록하면서 이전 파싱 결과의 ID와 digest로 `reproduced`를 반환할 수 있었다. R2도 기술 보류다. 기존 후보의 자연 발생 오류나 실제 자료 손상을 주장하는 것이 아니라, 독립 작업자의 소유 복사본에서 교체 시점을 제어한 재현이다.

독립 봉인 `3115bfd405722b4b2cde745ebec21fc09fd06f55`의 `own-report.json`과 `own-semantic-race-finding.json`, 처음 실패한 대조와 이어진 제어 기록을 그대로 옮겨 해시를 확인했다. [전송 원장](../../../../.qa-artifacts/exam-resume-20261008/engine-upgrade-20261019/vector-replay-independent-transport-r2.json)과 [자체 재현](../../../../.qa-artifacts/exam-resume-20261008/vector-replay-code-audit-20261020-r2/own-semantic-race-finding.json)을 보존한다. 정상 대조 수를 전체 완료로 확대하지 않는다.

다음 수정은 공통 binder에서 후보 JSON의 같은 원시 바이트를 파싱·해시하고, 생성 기록도 같은 원시 바이트에 결합하는 것이다. R2 코드를 먼저 체크포인트로 보존한 다음 새 버전에서 제어·실제 렌더·독립 검수를 다시 진행한다. 현재 선택본 134·수학/학년 133의 정본은 유지하며, 새 경신 7·8번은 별도 작업 초안이다. 최종 승인·적재 가능·DB 쓰기는 모두 0이다.
