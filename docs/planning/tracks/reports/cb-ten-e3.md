- 기계 검산: 스크래치 검산기(저장소 밖)가 숫자를 다시 계산한 문항 수 — 물음의 계산식을 다시 계산해 답과 견주었거나, 뜻 · 예 · ○× · 까닭 · 적용 안의 등식(`A=B`)을 다시 계산했다.
- 손 검산: 답이 있는 적용 · 예 가운데 검산기가 다시 계산하지 못한 것(낱말 답 · 어림 · 자리 · 잘못 찾기 · 문장제) — 쓸 때 손으로 계산했고, «다시 읽음»은 대단원을 끝낸 뒤 그 목록을 다시 계산하며 읽은 수다.
- 틀려서 고친 것: `e3-1-1-1-xa2`(`$402+375$` 의 답을 쓰는 중에 잘못 적어 `$777$` 로 고침) · 누출 10글자 1건(`e3-1-1-3-xo16` 문장을 고쳐 씀).
- 1-2: 큰따옴표 글에 TeX 를 넣어 역슬래시를 잃은 줄 4(`e3-1-1-1-xc22` 는 1-1 커밋에 이미 실려 `$square$` 로 찍히던 것 — 표기 자는 «square» 를 글자로 읽어 0건이었다) → 모두 `r` 글로 고치고, 스크래치 관문에 «큰따옴표 속 역슬래시 · 수식 속 맨 명령어(`square` · `mathrm` …)» 검사를 더했다.
  도형 말(«네 각이 모두 직각인 사각형» · «마주 보는 변의 길이가 같» · «네 변의 길이가 모두 같은»)이 교재 문장과 10글자 창으로 겹쳐 25칸을 고쳐 썼다.
- 1-3: 1-3-2 상 개념이 하나 모자라 더함 · 누출 10글자 1칸 고쳐 씀.
- 1-4: 검산기가 `e3-1-4-4-xo3` 까닭의 틀린 식(`$4\times4+3=7$` → `$1\times4+3=7$`)을 잡아 고침.
- 1-5: 단위 · 시간 검산기를 따로 만들어(양을 읽어 합 · 차 · 바꾸기를 다시 계산) 167개를 쟀다 — 어긋남 20개는 모두 손으로 보아 거짓 경보(«$6\,\mathrm{cm}\ 12\,\mathrm{mm}$ 로 써야 한다» 같은 표기 함정 · 몇 배 물음)였다.
  용어 칸에 수 · 단위를 글자로 쓴 46칸(«1cm 어림 기준» …)을 KaTeX 로 고쳤다. 원래 문항과 같은 용어 1칸(«시간끼리 빼기»)을 바꿈.
  🔴 고치는 도중 스크래치 치환 스크립트가 `String.replace` 의 `` $` `` 를 «앞부분»으로 풀어 파일 앞부분이 한 번 더 들어갔다 — 커밋 전에 사본을 걷어 복구했고(HEAD 대비 덧붙임만 남음을 확인), 이후 치환은 `split/join` 만 쓴다.
- 1-6: 크기 비교 검산기(분수 · 소수 값을 읽어 «더 큰 · 가장 작은 · 작은 수부터»를 다시 정함)로 31개를 쟀다 — 어긋남 2개는 «숫자 카드로 만든 수» 물음이라 거짓 경보.
  분수 뒤 조사를 분자 소리로 고침 9칸(`$\frac{7}{9}$는` → `은` · `$\frac{3}{8}$로` → `으로` · `$\frac{1}{6}$으로` → `로` …) · 용어의 단위 글자 7칸을 KaTeX 로.
  학년 밖이 되지 않게 분수의 덧셈 · 뺄셈 꼴은 «조각 수 세기»로, 소수의 차는 «$0.1$이 몇 개 많은가»로 물었다.
