## 화면

네 안은 같은 안 2 다. SRS 현황의 «교육과정 연결도» 펼침이고, 학생을 고르지 않아도 열린다. 새 메뉴는 없다. 차이는 행의 글자 위계와 밀도뿐이다. 학생 확인, 복귀, 공급 카드는 네 안에서 같은 기존 크롬이다.

확인 플레이어는 빵부스러기 «초5 · 1학기 · 분수의 덧셈과 뺄셈», 표시 «기억을 꺼내는 복습», 제목 «대분수의 뺄셈» 이다. 복귀는 «초5 · 2학기 · 분수의 곱셈», «차근차근 새 학습», 제목 «(분수)×(자연수)의 계산» 이다. 복귀 문장은 «분수의 뺄셈 확인 범위를 본 뒤, 분수의 곱셈을 다시 학습해요.» 라서 보통 복습 뒤에도 맞다.

새 문제가 없으면 탐험 홈과 추천 학습 모두, 시작 단추 앞에 «새 문제를 준비하지 못했어요. 선생님께 알려 주세요.» 가 있고 시작은 꺼진다. 확인 문제만 없으면 «확인 문제를 준비하지 못해 분수의 곱셈 학습을 이어 갑니다.» 와 켜진 시작이 있다.

교사 근거 네 줄은 학생을 고른 경우에만 붙는다. 최근 완료된 첫 통과 둘, 확인의 직접 실패와 다시 풀 시기 보류, 공급이 부족할 때와 목표만 있을 때, 자동 확인을 끄거나 계획을 바꿔도 이미 열린 탐험은 그대로라는 내용이다. 점수, 확률, 단원 숙달, 학생 합산은 없다.

영역 선택지는 수와 연산, 변화와 관계, 도형과 측정, 자료와 가능성뿐이다. 고등학교 분류 칸 이름은 편집분류다. 중학교 3학년 자리는 공식 학년이 아니다. 시범 소단원은 5-2-2-1, 5-2-2-2, 5-1-5-4, 5-1-5-3 이다. M3-R02 는 자동으로 내지 않는다. 다시 볼 후보는 «보이는 후보 2 / 9» 이고 진단이 아니다. 각 단원 행은 `aria-expanded` 를 가진다.

토큰은 `D:\todays-math\src\app\globals.css` 의 `--learn-*` 와 05 §8.9, 2026-09-23 글자 14·12·18·24, 컨트롤 44px, 모서리 8px 이다. 새 색은 없다. 왼쪽 색 막대는 없다. 손가락 커서는 단추와 링크에만 있다.
