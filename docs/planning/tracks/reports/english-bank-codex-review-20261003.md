# Codex 자료은행 검토 — 합의 전 의견

## 코드에서 확인한 조건

1. `EnglishMaterial`·`EnglishQuestionSet`은 시험 삭제에 종속된다. 독립 보관은 새 지문 루트가 필요하며 기존 시험 자료를 은행처럼 나열하는 것으로 끝내면 안 된다.
2. `src/app/api/english/exams/[id]/sets/route.ts`는 시험 행을 잠근 뒤 `clientKey`로 중복 저장을 막는다. 은행 참조 검증과 사용 이력 기록도 같은 트랜잭션에 있어야 한다. 현재 재시도 본문 비교는 meta를 제외하므로 은행 원문 ID·개정이 달라진 재시도를 같다고 취급하지 않도록 보완한다.
3. `EnglishMakerView.tsx`는 실패한 저장의 시험·조건·초안을 묶어 보존한다. 은행에서 넘어온 지문이 기존 작성 중 초안을 조용히 덮거나, 시험 전환이 재시도 대상 시험을 바꾸면 안 된다.
4. `englishMetaFromConditions`는 원문 변형에만 `sourcePassage`를 저장한다. 은행 자료를 사용한 경우에는 제작 방식에 관계없이 서버에서 확인한 원문 사본과 개정 참조를 남겨야 한다. 은행을 불러온 뒤 입력문을 바꾸면 원문 그대로 사용했다고 기록하지 않는다.
5. 목록에서 파일 bytes와 모든 지문 본문을 전송하지 않는다. 제목·학년·출처·미리보기·단어 수·개정·갱신 시각을 보내고, 상세에서 본문을 읽는다. 정렬 동률은 ID로 안정화한다.
6. 새 메뉴는 옛 영어 전체 차단 의도를 유지하고 듣기 시범 허용을 우회하지 않는다. 지문 가져오기에는 은행 권한과 원본 자료 경로 권한을 함께 확인한다. `requireEnglishSession`의 관리자 예외만 믿지 말고 새 은행 경로의 승인 상태·허용 메뉴도 실제 세션에서 확인한다.

## 저장·제작 제안

- 지문 루트, 불변 개정, 생성한 세트와 사용 개정의 연결을 구분한다. 은행 삭제는 보관 해제이며 사용한 원문 개정과 이미 만든 세트는 남긴다.
- 모든 수정은 CAS로 충돌을 알린다. 가져오기는 서버에서 읽은 원본으로만 생성하고, 소유자·원본 종류·원본 ID·선택한 본문 종류·내용 해시로 중복 요청을 찾는다. 출처가 다른 동일 본문은 후보만 알리고 자동 병합하지 않는다.
- 검색은 서버에서 소유 범위를 먼저 적용한다. 본문 해시 정규화는 줄바꿈·유니코드·공백 정리 정도로 제한하고 실제 저장 원문은 보존한다.
- 18,000자를 넘는 원문은 은행에 보관할 수 있으나 제작 진입을 막고 발췌해 별도 지문으로 등록하도록 안내한다. 자동 잘림이나 뒤늦은 저장 실패로 처리하지 않는다.
- 기존 자료 가져오기의 출처·재사용 정보는 미확인이다. 제작 전 이용 근거와 용도를 교사가 확인한다. 원문 보관 동의와 AI 입력 허용을 같은 의미로 취급하지 않는다.

## 듣기·그림 제안

- 자체 듣기 세트는 기존 runtime과 상세·검수·수업을 재사용한다. 새 은행 검색 응답을 추가하되 기존 `/sets` 배열 응답을 몰래 페이지 객체로 바꾸지 않는다.
- EBS 항목은 서버 측 공식 카탈로그 참조다. 직접 제작 세트로 변환하거나 이미지·음원을 재호스팅하지 않는다.
- 공식 고1 2026년 2회 문제지에서 개별 그림 보기(1번), 표(10번), 공통 상황 그림(15번)이 확인된다. [EBSi 문제지](https://wdown.ebsi.co.kr/engexam/2026/2026_eng_02_go1/2026_eng_02_go1_question_ZS1MSRWS.pdf). 따라서 선택지 이미지와 공통 시각 자료를 구분한다.
- 현재 교사·학생·초안 계약은 `{id,text}` 선택지뿐이다. 이미지 필드를 추가하는 일에는 저장·해시·검수 무효화·발행 사본·학생 projection·인증 파일 응답·화면·인쇄가 함께 필요하다. 일부만 추가하고 그림 문항 지원 완료라고 표시하지 않는다.
- 사물·장소·행동 삽화는 생성 도구로 준비하고 지도·표·시계는 결정적인 데이터와 코드 도식으로 만든다. 보기 번호는 화면이 붙이며, 파일명·프롬프트·대체 설명으로 정답 근거가 새지 않게 한다. 설명은 이미지 내용을 동등하게 전달하며 정답 번호나 대본 인용을 붙이지 않는다.
- 첫 그림 시범은 기존 자작 샘플의 실제 대본에 대응하는 문항으로 만들고 교사 미리보기에서 검수한다. 그림 5개가 보기라면 스타일과 정보량이 같아야 한다. 학생 발행은 위 경로 검증이 끝난 뒤 연다.

## 필요한 검증

실제 격리 PostgreSQL에서 동시 수정·동시 가져오기·시험 삭제 후 은행 보존·은행 보관 해제 후 과거 세트 보존·권한 범위를 확인한다. 브라우저에서는 시험이 없는 상태의 은행, TXT·기존 자료 가져오기, 검색·페이지 이동, 제작 왕복과 저장 재시도, EBS 링크, 기존 듣기 열기, 모바일과 키보드를 확인한다. 그림은 정답 공개 전 응답·이미지 응답·해시 변경·검수 무효화를 별도로 검증한다.
