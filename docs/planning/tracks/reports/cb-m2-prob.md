## 검산과 추가 검토

예 $4$개와 적용 $4$개, 총 $8$개의 수치 답을 모두 손으로 계산하고, 가능한 결과를 직접 열거하는 별도 스크래치로 기계 검산했다. 기계 검산 $8$개·손 검산 $8$개·틀려서 고친 답 $0$개이다. 저장된 답도 계산 결과와 직접 대조했다.

| id            | 손 검산                                        | 결과 열거 검산                                                      |
| ------------- | ---------------------------------------------- | ------------------------------------------------------------------- |
| `m2-09-04-c2` | $\frac{1}{6}+\frac{1}{3}=\frac{1}{2}$          | 겹치지 않는 $1$가지와 $2$가지를 전체 $6$가지에서 세어 $\frac{3}{6}$ |
| `m2-09-04-c3` | $\frac{1}{2}\times\frac{1}{6}=\frac{1}{12}$    | 동전·주사위의 $12$가지 중 $1$가지                                   |
| `m2-09-04-c5` | $\frac{2}{3}\times\frac{1}{2}=\frac{1}{3}$     | 공을 구별한 비복원 순서 $6$가지 중 $2$가지                          |
| `m2-09-04-c6` | $1-\frac{1}{2}\times\frac{1}{2}=\frac{3}{4}$   | 두 번의 명중·실패 $4$가지 중 $3$가지                                |

| `m2-09-04-a2` | $\frac{3}{5}\times\frac{3}{5}=\frac{9}{25}$    | 공을 구별한 복원 순서 $25$가지 중 $9$가지                           |
| `m2-09-04-a3` | $\frac{3}{5}\times\frac{2}{4}=\frac{3}{10}$    | 공을 구별한 비복원 순서 $20$가지 중 $6$가지                         |
| `m2-09-04-a4` | $1-\frac{1}{3}\times\frac{1}{4}=\frac{11}{12}$ | 두 사람의 확률을 같은 가능성의 결과로 나눈 $12$가지 중 $11$가지     |

○× 수치 문장도 별도로 $3$개 검산했다. `o1`은 $\frac{1}{2}\times\frac{1}{2}=\frac{1}{4}$로 참, `o2`는 $\frac{1}{6}+\frac{1}{6}=\frac{1}{3}\ne\frac{1}{36}$로 거짓, `o4`는 $\frac{1}{2}\times\frac{2}{3}=\frac{1}{3}\ne\frac{1}{6}$로 거짓이다. `o3`의 참 판정도 유지했다. 당첨 제비를 뽑았다면 당첨 제비 수가 줄고, 꽝을 뽑았다면 당첨 제비 수는 그대로이므로 기존 까닭의 단정만 고쳤다.

나머지 조건 검토:

- `c1`·`c2`: 함께 일어나지 않는 두 사건에 대해서만 각각의 확률을 더하도록 제한했다.
- `c4`: 전체 개수만 같다는 이유로 같은 확률을 단정하지 않도록, 공의 구성 복원과 매번 같은 추출 가능성을 명시했다.
- `c5`: 모든 공의 색이 같다면 비복원이어도 같은 색의 확률이 $1$로 유지된다. 서로 다른 색이 섞여 있다는 조건과 방금 뽑힌 색이라는 대상을 넣었다. 전체 $n$개 중 그 색이 $k$개이고 $1\le k<n$이면 $\frac{k-1}{n-1}<\frac{k}{n}$이므로 수정 문장은 성립한다.
- `c6`: 여러 시행의 실패 확률을 곱하려면 시행 결과가 서로 영향을 주지 않아야 한다. 뜻과 예 양쪽에 조건을 넣었다.
- `c7`: 두 사람의 성공 확률을 $p$, $q$라 하면 한 사람만 성공할 확률은 $p(1-q)+(1-p)q$이다. 각 곱셈에는 서로 영향이 없다는 조건이 필요하고, 두 경우는 동시에 일어나지 않아 더할 수 있다. 분모가 $1$부터 $8$인 확률 조합 $1936$쌍도 결과 열거와 공식이 모두 일치했다.
- `a2`·`a3`: 복원 여부를 유지하면서 매번 각 공이 같은 가능성으로 뽑힌다는 조건을 명시했다. 비복원 추출에 독립 조건을 붙이지 않았다.

블록의 개념 $7$개·○× $4$개·적용 $4$개와 예 $4$개를 모두 다시 읽었으며, 위 수정 이후 추가 조건 누락은 없음이다. 보강 `m2-plus.ts`의 같은 소단원도 읽고 표현을 대조했다.
