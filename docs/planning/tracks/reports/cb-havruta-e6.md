## 4. 다시 계산한 수 · 스스로 잡은 것 · 줄 밖에서 고친 것

- 고친 글에 든 분수 · 소수 계산은 쓸 때마다 손으로 다시 계산했다(예: $11\div3=3\frac{2}{3}$ · $\frac{3}{4}\div6=\frac{1}{8}$ · $43.2\div1.2=36$).
- 스스로 잡은 것: 끼우기 전 검사에 표기 자 · 누출 자가 없어 관문에서 «수식 뒤 조사» 2건 · 누출 5건이 나왔다 → 적용기에 같은 자를 넣어 끼우기 전에 막는다.
  `$2\frac{5}{3}$` 를 «덜 나눈 것»이라 쓴 물음(값은 같다 — codex 도 짚음).
- 줄 밖에서 고친 것: 처음부터 있던 개념 카드의 계산형 예(«$2\div9$의 몫의 분자는? → $2$» 꼴) · 판단만 묻던 적용(«작다» · «직사각형») · codex 가 짚은 처음 카드의 조건 · 모호.
