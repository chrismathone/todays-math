- **범위 확인**: 1-3-3 `xc20` · `xo21`(«0을 계속 내려도 나누어떨어지지 않는 나눗셈도 있다») — 처음부터 있던 카드 · ○× 다. codex 가 «끝없이 이어짐은 중학 순환소수와 닿는다 — 확인 필요»라 했다. 초6 2학기 «몫을 반올림하여 나타내기»가 이 사실을 쓰므로 두었다. 같은 까닭으로 내가 쓴 적용 `xa21`(같은 나머지가 되풀이된다)과 1-3-5 `xo21` 은 뺐다.
- **범위 확인(받아 고침)**: 1-5-3 `c1` 의 «부채꼴»(중학 용어를 답으로 요구) · 1-6-1 `c4`(부피 · $\mathrm{cm}^3$ 가 다음 소단원에 처음 나온다) · 1-6-3 `xa21`(소수 ÷ 소수는 2학기).
- 원장 줄이 없는 처음 문항(수가 안 든 ○× · 답에 수가 없는 적용)에도 되풀이 · 판단만 묻는 것이 많다. 뺄 수 없어 다시 쓰고 있는데, **줄 밖 문항을 빼도 되게**(원장에 줄을 더하는 길) 하면 codex 의 «삭제» 지적을 그대로 받을 수 있다.
- 1-5 는 띠그래프 ↔ 원그래프가 나란한 단원이라 **소단원을 건너 같은 판단**이 많다(«합은 100%» · «전체 수를 모르면 실제 수를 모른다» · «눈금 간격이 같아야» · «크기를 바꾸어도 비율은 같다»). 소단원 안에서는 한 곳에만 두었지만, 소단원을 건넌 것은 처음 카드가 양쪽에 다 있어 남아 있다 — 시험지를 대단원으로 뽑으면 겹쳐 보일 수 있다.

## 6. 원장님께 물을 것

- **원기둥 옆면의 넓이**: 원래 은행 2-6-2 에는 «옆면 넓이 = 가로 × 세로» 계산 줄이 여럿 있었다. 개념으로 다시 쓰며 «옆면의 넓이를 (밑면의 둘레)×(높이)로 구할 수 있는 까닭» · «전개도 넓이의 합 = 겉면의 넓이»를 넣었더니 codex 가 «원기둥의 겉넓이는 초등에서 다루지 않는다 — 확인 필요»라 해서 다른 판단(«맞붙는 두 변» · «겹쳐 그리면 안 되는 까닭»)으로 바꿨다. 초6 개념 백지에서 원기둥 옆면의 넓이를 물어도 되는지 정해 주시면 그에 맞추겠다.
- **«모선»**: codex 가 «모선은 중학 용어»라며 2-6-3 · 2-6-4 의 적용 셋을 짚었다. 지금 교과서(초6 2학기 «원뿔 알아보기»)가 모선을 가르치고 원래 카드 `c5` 도 모선을 정의하므로 받지 않았다 — 교과서와 다르면 알려 주시면 고치겠다.
