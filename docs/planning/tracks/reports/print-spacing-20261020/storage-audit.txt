4. 프리셋 글

현재 count일 때 1단당 N문항만 추가(:41), spacing 값/단계 자체와 스마트 표시는 없음. 새 필드는 저장되어도 요약 글에 자동으로 나타나지 않음. 스마트 표시와 수동 단계 표시를 원하면 별도 분기 필요.
