## 검증과 범위

- A4 793.70 × 1122.52px (96dpi), 좌우 15mm / 상하 12mm: 제품 `A4_DIM`, `printPagePadding('normal')`와 같은 값.
- 정답 12px / 1.8: 현재 `AnswerPage` 값. 제목 18px, 머리 아래 16px, 하단 쪽수 11px도 현재 값에서 출발했다.
- DB 없는 자체 제작 25문항의 정답: 객관식 13개와 단답·분수·식·복수 답 12개. 50·100문항은 이 25개를 반복한 스트레스 표본이며 실제 시험 기록이 아니다.
- 답과 예시 해설은 제품의 `fractionViewFor` → `MathText` / `SolutionText`를 직접 import해 렌더했다. 중1 표본이라 가분수는 그대로다.
- 4안 × 3개 길이 = 12개 사례를 브라우저에서 실제 높이로 나눴다. 표 행을 자르지 않고, 표가 끝난 뒤 예시 해설을 붙인다. 해설은 첫 3개만 표시하며 모든 해설의 실제 쪽수를 주장하지 않는다.
- 25문항의 A/B는 표+예시 해설 1쪽, C/D는 2쪽이다. 50·100문항의 쪽수와 넘침은 JSON에 보존한다. 현재 표본에서 페이지 세로 넘침 없음.
- 정답지의 모든 정답을 먼저 모으므로 채점표가 길면 먼저 여러 쪽에 걸쳐 끝내고 해설이 이어진다. 설명 묶음이 남은 공간에 들어가지 않으면 다음 쪽으로 보낸다. 실제 제품 구현에서는 전체 해설도 개별 문항 단위로 `measure`에 연결해야 한다.
- 저장한 HTML은 렌더된 DOM과 KaTeX 글꼴을 포함하며 서버 없이 연다. 화면에서 원래 A4 크기, 인쇄에서 A4 쪽 단위로 본다. 작은 창은 가로 스크롤로 원래 지면 폭을 보존한다.
- 제품 `src/**` 변경 없음. 구현·Hi-fi·실물 인쇄 검수는 선택 뒤 차례다.
