## 용어 대응과 문항 검토

교재와 교육과정의 소단원 구성이 다른 부분은 뜻에 맞춰 연결했다.

- 각기둥⑴·⑵ → 1-2-1·1-2-2, 각뿔⑴·⑵ → 1-2-4·1-2-5.
- 직육면체 부피 비교와 부피 구하기 → 1-6-2, 단위 관계 → 1-6-3.
- 분모가 같은 분수 나눗셈의 두 소단원 → 2-1-1.
- 수를 적은 위 모양 → 2-3-4, 층별 모양 → 2-3-5.
- 원주·지름의 관계와 원주율 → 2-5-1.

저장소 밖 스크래치 검사에서 교재의 `(파일, 소단원, 용어)` 82건을 각각 은행의 대응 소단원·용어와 대조했다. 모든 대응이 존재하며, 같은 이름인 밑면·옆면·높이도 입체별로 따로 확인했다. `기호`·`기타` 갈래는 계약이 허용하는 정의·방법·성질·단위 등으로 맞췄다.

적용 56개의 답과 ○×의 까닭을 직접 검토했다. 수치 계산 43개는 스크래치에서 Python `Fraction`·`Decimal`로 다시 계산하고 은행의 답 문자열까지 대조해 모두 통과했다. 예를 들어 5/6÷4=5/24, 3/5÷2/7=21/10, 7.3−0.6×12=0.1, 72의 5:3 배분=45와 27, 2×(3×4+4×5+3×5)=94, 6×6×3.14=113.04이다. 온전한 조각 수·남는 양·반올림은 각각 구별했다.

## 그림과 지면 검토

27개 그림은 도형·측정·그래프·공간 소단원마다 하나씩 배치했다. SVG는 저장소 안의 고정 데이터이며, 원본 교재 그림을 사용하지 않았다. 이름표는 도형 오른쪽 별도 영역에 놓고 연결선을 이름표 5px 앞에서 끝냈다. 숨은 모서리·뒤쪽 원호·접는 선·높이를 점선으로 구별했고, 높이에는 직각 표시를 넣었다. 원기둥·원뿔·구의 타원은 짧은 반지름/긴 반지름=0.15를 사용했다.

Playwright와 설치된 Edge의 headless 모드로 **브라우저 한 개**를 사용해 학생용 27장·채점용 27장, 개별 PNG 54장과 모아보기 6장을 만들었다. 모아보기 여섯 장에서 **그림 27종의 학생용·채점용 모두** 눈으로 확인했다. 이름표와 선·글자의 겹침, 정답 이름의 SVG 노출은 없었다. 원 넓이 비교 문항의 긴 줄 이름 두 개는 짧게 다듬어 불필요한 줄바꿈을 없앴다.

뜻 문장 198개는 본문 폭 567px(약 150mm), 바탕 16px(12pt), 줄높이 27px에서 핵심어를 굵게 처리해 측정했다. **최대 2줄, 2줄 초과 0개**이다. 이는 은행의 스크래치 검수이며 제품 지면 전체의 쪽 나누기나 실물 인쇄까지 확인했다는 뜻은 아니다.

검수 산출물은 저장소 밖 `C:\Users\user\AppData\Local\Temp\cb-e6-preview\`에 있다. `student-1.png`부터 `student-3.png`까지, `key-1.png`부터 `key-3.png`까지가 모아보기이고, 각 문항 ID 뒤에 `-student.png`·`-key.png`를 붙인 파일이 개별 그림이다. `definition-lengths.json`에 문장 줄 수가 기록되어 있다. 공유 검증 잠금 안에서 렌더링을 마치고 브라우저와 잠금을 모두 해제했다.
