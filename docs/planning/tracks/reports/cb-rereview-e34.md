- **옮길 장면이 이미 ○× · 적용 · 다른 예에 있던 것 열** — 뜻의 특정 장면을 예로 옮기거나 예를 다시 쓸 때, 그 장면이 같은 소단원에 벌써 있으면 새 장면으로 바꿨다:
  `e3-1-3-4-xc19`(↔ `c2` 예) · `e3-1-5-2-xc3`(codex 가 권한 수 ↔ `xc2` 예) · `e3-2-6-2-xc11`(↔ `xo12`) · `e3-1-6-4-xc9`(↔ `xo5`) · `e3-2-1-4-xc18`(↔ `xa19`) ·
  `e3-2-2-4-xc5`(↔ `xc3`) · `e3-2-3-3-xc13`(↔ `xa13`) · `e3-2-5-5-xc16`(↔ `c1` 예 · `xo18`) · `e4-1-3-3-xc11`(↔ `xa12`) · `e4-2-3-2-xc20`(↔ `xo21`).
- **갈래(`kind`)** 하나: `e3-1-6-4-xc15` 성질 → 방법(새 글이 방법이다).

보고만 하는 것(지적이 없어 그대로 둔 것):

1. 고친 예가 쓰던 장면이 같은 소단원에 **전부터** 한 번 더 있는 것 — 답만 고친 문항이라 장면은 안 바꿨다:
   `e3-2-4-1-xc5` 예($10$개를 $2$개씩) ↔ 적용 `xa16` · `e3-2-1-4-xc23` 예(카드 $4$, $3$, $2$, $1$) ↔ ○× `xo24` · `e4-2-3-2-xc25` 뜻($0.9$, $0.85$, $0.123$) ↔ ○× `xo26`(묻는 것은 다르다).
2. `e4-1-1-2-xc1` 의 예의 답이 «…이기 때문이다» 문장 꼴이다(«만의 묶음이 $3$개이기 때문이다» · 폭은 13.7em 으로 든다) — 지적 밖이라 두었다.

## 6. 리드 · 원장님께 물을 것

1. **(나)로 용어에 특정 장면을 실은 카드 다섯** — 초3 `1-5-1-xc24`(연필) · `1-5-3-xc5`(교실 문) / 초4 `1-1-3-xc17`($5555000$ 의 두 자리) · `1-1-6-xc28`(십만의 자리 $9$) · `2-3-2-xc25`($0.9$, $0.85$, $0.123$).
   일반 진술이 그 소단원의 다른 카드와 같은 말이 되어 지시서의 둘째 길로 갔다. 사례 표지는 달지 않았으니(지시서) A 채점표에 그대로 실린다 — 소단원 이름만 보고 떠올리기 어려운 장이다.
   빼거나 표지를 다는 것은 내 손 밖이라 리드 판단에 둔다.
2. **`e4-1-1-2-xc1` 안 받음** — «몇 = 한 자리 수»로 읽었다. 다시 걸리면 용어를 «만이 $1$개부터 $9$개까지인 수 쓰기»로 바꾸면 끝난다(뜻 문장은 이미 그렇게 쓰여 있다).
3. **규칙 찾기 예 셋의 닫기**(`e4-1-6-1-xc16` · `xc17` · `e4-1-6-2-xc11`) — codex 의 반례(«$2$, $3$, $4$를 되풀이해 더한다면»)는 억지에 가깝지만 한 마디로 닫히길래 닫았다.
   대신 물음이 규칙을 먼저 말해 주어(«더하는 수가 $2$, $3$, $4$로 바뀐다. 이 규칙이 이어질 때») 규칙을 «찾는» 맛은 줄었다. 과하다고 보시면 물음만 되돌리면 된다(답은 안 바꿨다).
4. **`e4-1-3-7-xc14`** — 물음을 «작을 수 없는 까닭»으로 바꿨다. 원래 물음(«$20$이 실제 몫보다 큰 까닭»)을 살리려면 답이 «$31\times20$이 $598$을 넘어서»(이 사례의 검산)가 되는데,
   그러면 카드의 개념(어림한 방향)이 예에서 빠진다. 어느 쪽이 나은지는 원장님 취향에 걸린다.
5. **`npx prettier --check`** — 이 기계의 워크트리는 CRLF 로 풀려서 지시서의 명령 그대로는 고치기 전에도 빨강이다(§0). 다른 트랙도 같은 것을 볼 것이다.
