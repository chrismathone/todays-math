# 인재원 범용 교재 스튜디오 제작 지시서

작성일: 2026-10-03 / 버전: 1.0

함께 읽기: `01_todays-math_교재_QR영상_연동지시서.md`, `03_공통데이터계약_및_통합검수.md`

## 1. 완성할 제품

학년·학기·권차·수록 단원을 선택하고, 개념·대화·문제를 편집하면 **인재원에서 실제 수업에 사용할 수준의 교재**를 동일한 디자인 체계로 제작하는 스튜디오를 만든다. 학생용, 정답·해설, 양면 펼침면 미리보기, 원고 패키지를 출력한다.

문제는 todays-math의 정확한 문항을 가져오고, 교재 문제별 QR에는 해당 판본의 해설영상 주소를 연결한다. 개념 예습영상과 문제 해설영상은 별도로 관리한다.

현재 중2 1학기 1권의 제목만 바꾸는 기능은 범용화로 인정하지 않는다. 반대로 학년 선택 UI가 있다는 이유로 모든 학년의 원고가 완성되었다고 표시하지 않는다. 템플릿 지원, 원고 준비, 문항 확보, 교열 완료, 영상 준비 상태를 구분한다.

## 3. 범용화 구조

최소한 아래 책임을 분리한다. 파일명은 제안이며 기존 프로젝트에 맞게 조정한다.

| 계층 | 책임 |
| --- | --- |
| 교재 설정 | 학교급·학년·학기·권차·교육과정·판본·인쇄 옵션 |
| 교육과정 목록 | 단원·소단원·성취 목표·선수 연결, 검증 출처 |
| 원고 | 대화·개념·예제·활동·문항 참조·해설 참조 |
| 문항 어댑터 | todays-math 계약과 기존 `[[LaTeX]]` 원고 변환 |
| 조판 코어 | 페이지 배치, 홀짝, 풀이 공간, 머리글·바닥글 |
| 디자인 토큰 | 색·글꼴·글자 크기·간격·선·카드·말풍선·캐릭터 |
| 내보내기 | PDF, 단일 HTML, JSON/ZIP, 매핑표, 검증 결과 |

`app.js`, `full.js`, `chapters.js`의 `중등 수학 2-1-1`, `수와 식`, `U01-U06`, 특정 개념 ID, 문항 번호 가공 로직을 찾아 교재 설정과 데이터로 이동한다. 기존 디자인을 전부 새 UI로 다시 그리는 것부터 시작하지 않는다.

확인할 기존 파일:

- `manuscript.json`, `manuscript.js`: 원고의 입력·브라우저 전달 형식
- `app.js`, `full.js`, `chapters.js`: 본문·개념·유형·대화·표지 조판
- `styles.css`, `editorial.css`, `full.css`, `chapters.css`: 편집 디자인과 인쇄 규칙
- `content/pagination.py`, `content/section_extensions.py`: 페이지 홀짝·분량 조절
- `build_full.py`, `sync_manuscript.py`: 원고 재생성과 직접 편집 반영
- `inline.cjs`, `print_full.mjs`: 오프라인 HTML과 PDF 생성
- `verify_studio.mjs`, `verify_content.py`, `verify_pilot.py`: 기존 검증

직접 편집한 JSON을 `build_full.py`로 조용히 덮어쓰지 않는다. 생성 원본과 편집 초안의 관계, 저장 시각, revision, 재생성 영향을 UI에 표시한다. 파일을 불러왔다는 이유로 현재 수정본을 잃게 하지 않는다.

## 4. 교재 설정과 권 분할

필수 설정:

- 학교급, 학년, 학기, 교육과정 버전, 교재명, 부제, 권차, 판본
- 수록 단원·소단원·순서·단원별 목표와 선수 개념
- 교재 구성 모드: 통합형 / 개념 중심 / 유형 중심
- 목표 분량, 단원별 예상 분량, 문제 수·난도·학습 단계 배분
- 인쇄 용지·제본 안쪽 여백·표지 포함 방식·본문 시작 면
- 개념영상 표시와 문제영상 QR 표시 정책

**현재 중2 1학기는 3권이며 코드는 `2-1-1`, `2-1-2`, `2-1-3`이다.** `2-1`, `2-2`, `2-3`으로 학기와 권차를 혼동하게 만들지 않는다. 학교급을 내부 키에 포함하여 초2와 중2가 충돌하지 않게 한다.

기존 다음 권 구성안은 `2-1-2 부등식과 연립방정식`, `2-1-3 일차함수`다. 이는 구성안이며 원고가 완성된 것으로 표시하지 않는다. 실제 단원 배분은 해당 교육과정과 수업 진도에 따라 편집 가능하게 한다.

초등은 한 학기를 3권으로 나누는 요구가 있었고, 중등은 후속 요청에서 3권으로 구체화되었다. 분할 수를 코드에 고정하지 않고 설정으로 둔다.

분량의 기준점은 약 216쪽, 보통 조정 범위는 ±20쪽 정도다. 이는 권장값이며 하드 제한이 아니다. 실제 목표는 200쪽 안팎 이상의 충분한 학습량이지만, 내용이 적거나 많으면 조정할 수 있다. 기존 259쪽을 목표값에 맞추려고 강제로 줄이지 않는다. 표지·앞부분·본문·해설의 쪽수를 각각 표시한다. 단원별 분량도 균등 분배하지 않는다.

초기 범용 적용은 현재 실제 자료가 있는 초등·중등 범위부터 검증한다. 고등 확장을 막지 않는 구조는 가능하지만 검증하지 않은 범위를 완성품으로 표시하지 않는다. 교육과정 단원표는 구현 시 공식 자료와 대조하고 출처·확인일·적용 학년을 기록한다.

## 5. 학습 구성

원하는 방향은 개념의 숲·유형의 나무의 학습 구조와, 가우스 샘플에서 선호한 **단원 도입의 충분한 대화 수업**을 함께 살리는 것이다. 경쟁 교재의 문장·문제·삽화·지면을 그대로 옮기지 않는다. 제공된 기존 인재원 원고와 독자 제작 콘텐츠, 이용 가능한 문항을 사용한다.

기본 단원 구성은 아래와 같다. 모든 단원에 같은 페이지 수를 강제하지 않는다.

| 구획 | 들어갈 내용 |
| --- | --- |
| 단원 도입 펼침면 | 단원명, 질문, 필요한 삽화, 목표, 선수 개념, 학습 경로 |
| 단원을 여는 수업 | 선생님·학생의 연속 대화로 개념을 발견하는 과정 |
| 개념 이해 | 정의·의미·표현·조건·대표 예제·오개념·직후 확인 |
| 개념 정리 | 개념학습 → 핵심어 빈칸 → 통문장 설명의 3단계 |
| 기본 확인 | 한 개념을 직접 적용하는 짧은 문제 |
| 유형 연습 | 유형 설명·대표 예제·풀이 전략·유사·변형·적용 |
| 실전문제 | 유형을 섞어 판단하고 적용하는 문제 |
| 오류 점검·서술형 | 틀린 이유, 조건 누락, 풀이 설명, 학생의 말로 정리 |
| 누적 복습·단원 마무리 | 선수 개념과 기존 학습을 다시 확인하고 점검 |

기존 인재원 구획명은 우선 유지한다. `개념 마스터`, `유형 마스터`, `내신 마스터`라는 3분류는 사용하지 않는다. 내부 enum은 표현과 분리하여 향후 문구가 바뀌어도 데이터가 깨지지 않게 한다.

### 개념 원고의 최소 구조

개념 하나마다 목표, 선수 개념, 정의·원리, 성립 조건, 예와 반례, 대표 예제, 직후 확인문제, 자주 하는 실수, 학생 설명 질문을 다룬다. 주제상 불필요한 항목은 생략 사유를 남길 수 있지만 개념 이름과 수식 하나만 놓고 완성으로 취급하지 않는다.

숫자만 바꾼 문제 반복으로 분량을 채우지 않는다. 계산, 분류, 비교, 조건 판단, 표현 변환, 오류 설명, 적용 문제를 단원 성격에 맞게 구성한다. 난도와 학습 단계는 다른 축으로 저장한다. `기본 확인`이라고 모든 문항을 같은 난도값으로 바꾸지 않는다.

### 3단계 개념 정리와 자기점검

- 개념학습에는 기존 1-4회 점검을 유지할 수 있다.
- **핵심어·빈칸 암기와 통문장 암기에는 1-4회 동그라미 체크를 넣지 않는다.**
- 통문장 3단계가 빠지면 안 된다. 핵심어만 채우고 끝내지 않는다.
- 자기점검은 기존처럼 가능한 한 한 줄로 배치한다. 읽을 수 없는 글자 크기로 줄이지 말고, 내용상 필요할 때만 두 줄을 허용한다.
- 자기점검·장식·라벨은 선의 교차점 위에 겹쳐 놓지 않는다. 지면의 고정된 기준 위치와 간격을 사용한다.

## 6. 도입 대화와 캐릭터

각 단원 시작에 짧게는 1-2쪽, 내용이 많으면 4-5쪽 안팎의 **연속된 수업 대화**를 작성한다. 여러 개념 옆에 짤막한 한두 줄 말풍선을 붙이는 것으로 대체하지 않는다.

대화 흐름은 상황·질문 → 학생의 예상 또는 오개념 → 예를 이용한 확인 → 이유 설명 → 개념 정리 → 학생의 재설명으로 구성한다. 학생은 항상 정답만 말하지 않으며, 질문과 수정 과정이 학습에 기여해야 한다. 의미 없는 감탄·칭찬·인사로 페이지를 늘리지 않는다.

스타일:

- 카카오톡처럼 좌우 화자가 분명한 말풍선 배치. 수업에 맞는 독자적인 지면으로 디자인한다.
- 작은 프로필 원이나 이니셜 대신 선생님·학생의 얼굴이 보이는 인물 삽화 사용.
- 여자 선생님을 유지한다. 기본·질문·생각·이해 등 표정을 문맥에 맞춰 선택한다.
- 민서·지호의 캐릭터 정체성과 화자 방향을 유지한다. 오른쪽 지호는 왼쪽 말풍선을 보게 한다.
- 얼굴만 방향을 바꾸며 수식·말풍선 글자까지 반전하지 않는다. 반전 적용이 중복되지 않게 한다.
- 같은 단원의 대화 글자 크기와 패널 시작선은 통일한다.
- 말풍선의 폭·꼬리·패딩·윤곽을 정교하게 조정한다. 단순 직사각형 상자를 반복하는 수준으로 후퇴하지 않는다.
- 수식은 말풍선 안에서도 KaTeX를 사용한다.

`자, 이제 놀라운 수학의 세계로 떠나볼까요?`, `정말 훌륭한 질문이야!` 같은 과장된 상투 표현을 반복하지 않는다. 예를 들어 `분모에 2와 5만 남는지 먼저 보자.`, `약분하기 전의 분모만 보면 될까요?`처럼 실제 수업에서 쓸 법한 문장을 사용한다.

하단 여백이 크면 대화의 편집 밀도·말풍선 간격·페이지 분할을 먼저 조정한다. 짧은 대사를 큰 상자로 늘려서 빈 공간을 가리지 않는다. 원래 4쪽인 대화 뒤에 홀짝을 맞춘다는 이유로 읽을거리 한 쪽을 추가하지 않는다.

## 7. 편집 디자인과 수식

목표는 실제 판매되는 개념·유형 교재에 가까운 편집 완성도다. 기존 v15의 지면을 기준으로 색, 글자 위계, 번호, 선, 배지, 유형 설명, 여백을 일관되게 만든다. 화면용 대시보드 카드 디자인을 책 지면에 그대로 이식하지 않는다.

### KaTeX

- 문제와 설명에서 수학적 의미를 갖는 숫자·분수·문자식·부등식·지수는 수식 데이터로 유지한다.
- 쪽수, 연도, 문항 식별 번호 등 편집용 숫자까지 무조건 KaTeX로 바꾸지는 않는다.
- 원문 LaTeX, 의미 단위의 수식 토큰, 표시 옵션을 분리한다. 수식 안에 코드 주석을 넣지 않는다.
- 분수의 분자·분모가 일반 숫자에 비해 지나치게 작지 않도록 기존 `\displaystyle` 처리 또는 동등한 스타일을 유지한다.
- 분수 높이를 확보하고 줄 간격·말풍선·문항 행을 함께 조정한다. 잘림을 숨기기 위해 수식을 이미지로 바꾸지 않는다.
- 렌더 오류·지원하지 않는 명령·넘침은 해당 문항과 페이지에 연결하여 표시한다.

### 도형

- 정확한 도형·그래프·좌표·길이·수치는 검증 가능한 SVG 등으로 그린다. 이미지 생성으로 정확한 수학 도형을 만들지 않는다.
- 도형 라벨은 흰 사각 배경 대신 얇은 흰색 외곽선으로 가독성을 확보한다.
- 도형 밖의 불필요한 `?`나 의미 없는 장식 라벨을 넣지 않는다. 문항의 실제 조건이라면 보존한다.
- 도형과 선택지의 연결·원본 비율·인쇄 크기 정보는 03번 계약대로 유지한다.

### 삽화

표지·단원 도입·캐릭터처럼 품질 개선에 도움이 되는 곳에는 이미지 생성을 적극 활용할 수 있다. 필요한 이미지 생성은 이미 사용자에게 승인된 방향이다. 단, 쪽수나 빈 공간을 채우기 위해 자동 삽입하지 않는다.

생성 이미지에 정확한 수식과 긴 한글 본문을 맡기지 않는다. 장식 이미지 위에 텍스트를 별도 조판한다. 수학 역사 일화를 넣는 경우 시대·복식·도구가 설명과 맞아야 한다. 일화의 사실 확인 출처와 이미지 제작 프롬프트를 기록한다.

## 8. 홀짝·펼침면 규칙

**홀수는 오른쪽, 짝수는 왼쪽이다.** 단원 시작은 짝수·왼쪽과 다음 홀수·오른쪽의 2쪽 펼침면으로 구성한다.

개념 이해, 개념 정리, 기본 확인, 유형 연습, 실전문제, 오류 점검, 서술형, 누적 복습, 단원 마무리 등 주요 구획은 현재 기준처럼 **짝수·왼쪽 시작**으로 통일한다. 모든 작은 개념·문항·개념 정리의 하위 단계마다 새 펼침면을 강제하지 않는다.

계산 기준은 표시한 쪽번호 문자열이 아니라 실제 제본될 본문의 페이지 순서다. 표지를 별도 출력할 때는 본문 시작 면 설정을 따로 둔다. PDF 첫 페이지, 표지, 표시 쪽번호를 혼동해 전체 홀짝이 뒤집히지 않게 한다. 기존 판본은 현재 물리적 순서를 보존한다.

홀짝을 조정하는 우선순위:

1. 같은 구획 안의 문항 배치와 풀이 공간을 조정한다.
2. 기존 문항의 재배치로 구획 분량을 정리한다.
3. 실제 학습상 필요한 확인·적용·복습 문항을 보강하거나 중복 문항을 줄인다. 연결된 문항을 가져오거나 새 원고 문항의 연동 상태를 표시한다.
4. 필요할 때만 해당 단원과 관련된 짧은 읽을거리·활동을 사용한다. 사실 확인과 교열을 거친다.

빈 페이지, 목적 없는 반쪽 지면, 과도하게 큰 풀이 공간, 관계없는 삽화로 홀짝을 맞추지 않는다. 조판 엔진이 원고를 몰래 생성하거나 확정된 문제를 삭제하지 않는다. 해결이 안 되면 편집 제안과 충돌 위치를 표시하고 초안 편집으로 해결한다.

대화의 초안 분량이 홀수여서 다음 구획의 시작 면이 어긋나면 먼저 대화 재배치와 내용 밀도를 조정한다. 현재 4쪽 대화처럼 이미 조건을 충족한 경우는 그대로 둔다.

## 9. 정렬·풀이 공간·하단

- 머리글·본문 시작·문항 번호·지문 기준선·풀이 시작·풀이 종료·하단 안내·쪽번호의 공통 기준선을 둔다.
- 같은 펼침면의 같은 형식은 좌우 문항 행을 대응시킨다. 준비학습도 예외가 아니다.
- 문항 번호는 정해진 번호 영역에서 일관되게 정렬한다. 한 자리와 세 자리 번호가 이유 없이 한쪽으로 몰리지 않게 한다.
- 풀이선의 기본 간격은 현재 7mm를 유지하고 설정값으로 관리한다. 같은 열·같은 형식의 선 시작점과 너비는 통일한다.
- 오른쪽 문제가 짧고 왼쪽에는 도형이 있으면 행의 전체 높이는 맞추되 오른쪽 문제에는 풀이선을 더 제공한다. 흰 공간으로만 남기지 않는다.
- 단답·분류 문제는 짧은 답안 공간을, 계산·서술 문제는 필요한 풀이 공간을 준다. 모든 문제의 풀이선 개수를 같게 만들지 않는다.
- 공간 추가는 해당 문제 영역 안에서 수행하며 다음 행·자기점검·하단 안내·QR을 침범하지 않는다.
- 같은 단원·템플릿의 대화 하단 안내와 자기점검은 공통 기준선에 배치한다. 기존 A4 기준 안내선은 위에서 270mm인 위치를 참고하되 실제 인쇄 안전영역과 검증 결과를 따른다.
- 쪽번호는 홀수 오른쪽, 짝수 왼쪽이다. 단원명·로고·장식선도 대응되게 배치한다.
- 제본 안쪽 여백은 홀수의 왼쪽, 짝수의 오른쪽이다. 안쪽 여백을 바깥 여백보다 넓게 조정할 수 있게 한다.

## 10. 스튜디오 편집 기능

필수 화면과 동작:

1. **교재 만들기·열기**: 교재 설정, 기존 판본·초안 구분, 템플릿 선택.
2. **단원 구성**: 목록에서 선택·순서 변경·권별 배분·예상 분량 확인.
3. **원고 편집**: 대화 화자·표정, 개념 항목, 예제, 단계별 문제 구성 편집. 원시 JSON만 제공하지 않는다.
4. **문항 가져오기**: todays-math 출제 결과·선택 문항 또는 내보낸 패키지 가져오기. 코드·내용·도형·연결 상태 표시.
5. **영상 연결 상태**: 개념 예습과 문항 해설의 준비·검수·게시·누락 상태를 분리 표시.
6. **실제 지면 미리보기**: 왼쪽 짝수·오른쪽 홀수, 학생용·정답해설 전환, 페이지·단원 이동.
7. **검수 목록**: 오류를 누르면 해당 문항·원고·페이지로 이동.
8. **저장과 내보내기**: 초안 저장, 복제, 판본 고정, JSON/ZIP, PDF, 오프라인 HTML.

메뉴와 교재 생성 버튼은 실제로 동작해야 한다. 데이터가 없는 학년은 필요한 원고·문항 상태를 설명한다. 중2 원고를 다른 학년 이름으로 바꿔서 보여주지 않는다.

오프라인 HTML에서 저장한 JSON은 파일 자체가 자동 변경된 것으로 표현하지 않는다. 파일 불러오기 후 적용·저장 상태를 명확히 한다. 새 교재 설정·문항 ID·영상 연결·표정·정렬 옵션이 저장 후 재열기에서도 보존되어야 한다.

## 11. QR 조판

- 문제별 QR은 해당 문항의 영역에 배치하고, 개념영상 QR과 시각적으로 구별한다.
- QR 아래 또는 옆에 `해설영상`과 교재 문항 번호를 표시한다. 필요하면 짧은 문항 코드를 보조 표기로 사용한다.
- 여러 문제의 QR을 서로 혼동하도록 한곳에 몰아 넣지 않는다. 작은 확인문제가 많은 지면은 연결 의미가 분명한 배치를 제공한다.
- 최초 인쇄 검수에서는 전체 QR 외곽 크기 약 20-24mm를 시작값으로 삼는다. 이는 고정 표준이 아니라 테스트할 설계값이다. 실제 데이터 길이·모듈 수·인쇄 크기와 스캔 결과로 조정한다.
- QR 주변 최소 4모듈의 여백을 확보하고 선·풀이칸·장식과 겹치지 않게 한다. 검정 QR과 밝은 단색 배경을 기본으로 하고 중앙 로고는 넣지 않는다.
- 스튜디오가 QR의 URL을 임의 생성하지 않는다. 서버가 발급한 판본·배치별 주소를 사용한다.
- 서버에 연결되지 않은 문항은 QR 미연결 상태를 표시한다. 개발용 주소·가짜 영상 URL을 발행본에 넣지 않는다.

모든 문항에 영상이 있어야 발행 가능한 `영상 필수` 모드와, 일부 영상 준비 중인 상태를 명시하는 `영상 선택` 모드를 구분한다. 문제별 해설이 필수인 범위는 누락 시 발행을 막는다. 영상 선택 모드라도 잘못된 QR이나 다른 문제 연결은 허용하지 않는다.

## 12. 원고 생성과 교육 내용 검증

원고 생성 요청은 실제 단원·목표·선수 개념·학년 어휘·학습 단계·문항 목록을 포함한다. AI가 문항 숫자를 임의 변경하거나 기존 코드에 새로운 문제를 붙이지 못하게 한다.

생성 결과는 구조 검증 → 수식 렌더 검증 → 계산·조건 검증 → 교사 교열 순서로 처리한다. 정답 계산은 가능한 경우 정수·분수·기호 연산 등 결정적인 코드로 검증한다. AI의 자기평가만으로 정답 검증 완료를 표시하지 않는다.

검산 불가 항목, 서술형 복수 답안, 교육과정 확인 필요 항목은 별도 표시한다. 전체 자동 검산 통과와 전체 원고 교열 완료를 구분한다. 영상 대본·교재 해설·문제 조건의 숫자가 일치하는지 함께 확인한다.

## 13. 검증과 납품

03번 통합 검수를 수행하고 다음을 추가 확인한다.

### 기존 판본 회귀

원고 내용과 문항 연결을 바꾸지 않는 최초 이관 단계에서 259쪽·1,039문항과 기존 해설이 보존되는지 확인한다. 이후 QR 추가나 승인된 편집으로 쪽수가 변하면 변경 이유와 페이지 이동표를 기록한다. 259쪽을 맞추기 위해 문제가 잘리는 것을 허용하지 않는다.

수식 오류, 이미지 누락, 문항 누락·중복, 페이지 넘침, 가로 넘침, 글자 겹침이 없어야 한다. 자동 영역 검사는 모든 페이지에 적용하고, 단원 도입·대화·개념·준비학습·유형·도형·서술형·해설·마지막 페이지 및 오류 의심 페이지는 이미지로 확인한다.

### 범용성

- 중2 1학기 1권의 기존 원고를 정상 로드한다.
- 다른 초등 학년의 실제 검수 가능한 짧은 단원과 다른 중등 단원의 짧은 원고를 같은 템플릿으로 조판한다.
- 교재명을 바꿔도 본문에 `중2`, `수와 식`, `2-1-1`이 잔존하지 않는다.
- 화자·표정·수식·SVG·QR·판본·표시 번호를 저장하고 다시 열어 동일하게 복원한다.
- 원고가 없는 학년은 미작성으로 표시하며 기존 원고를 대체 표시하지 않는다.

### 인쇄와 전달

글꼴·이미지·KaTeX 렌더가 준비된 뒤 PDF를 만든다. A4 100% 인쇄, 브라우저 기본 머리글·바닥글 제거, 배경 그래픽 설정을 안내한다. 표지 분리 여부와 양면 제본 방향을 PDF 정보에 포함한다. 인쇄소의 묶음 쪽수 조건이 있으면 별도 출력 옵션으로 다루며 내용 없는 페이지를 본문에 몰래 끼우지 않는다.

납품물:

- 범용 스튜디오 소스와 실행 설명
- 기존 원고 이관본과 호환 어댑터
- 학생용 PDF, 정답·해설 PDF, 펼침면 미리보기
- 원고·자산·문항·영상 연결을 포함한 내보내기 패키지
- 문항 코드 ↔ 교재 번호 ↔ 판본 ↔ 페이지 ↔ QR 매핑표
- 레이아웃·수식·내용·연결 검수 보고서
- 템플릿 지원 학년과 실제 완성 원고 범위, 실제 영상 검증 여부

보고할 때 `완성`이라는 한 단어로 묶지 않는다. 스튜디오 기능, 해당 권 원고, 문항 연결, 영상 준비, 실제 인쇄 검수를 각각 구분해 설명한다.
