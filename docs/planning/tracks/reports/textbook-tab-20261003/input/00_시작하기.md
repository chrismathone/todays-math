# 인재원 교재 제작·todays-math 연동 — Codex 전달 묶음

작성일: 2026-10-03 / 지시서 버전: 1.0

## 목적

todays-math에서 선정·출제한 **정확히 같은 문제**를 인재원 교재에 싣고, 인쇄된 QR을 스캔하면 **그 판본의 해당 문제 해설영상**을 볼 수 있게 한다. 기존 고품질 교재 스튜디오는 학년·학기·권차가 바뀌어도 같은 편집 체계로 제작할 수 있도록 범용화한다.

이 묶음은 구현 지시서다. 연동 기능, 실제 영상, 전체 학년 원고가 구현·제작되었다는 의미가 아니다.

같은 Codex 작업이라면 세 문서를 모두 읽힌다. 작업을 나눠 전달하더라도 03번은 반드시 양쪽에 함께 제공한다. 서로 다른 문제 ID, 판본, QR 주소 체계를 만들지 않는다.

## 함께 제공할 기존 자료

- 저장소: <https://github.com/chrismathone/todays-math>
- 기준 소스 압축파일: `인재원_KaTeX_교재조판기_v15.zip`
- 기준 지면: `인재원_수학_2-1-1_수와식_학생용.pdf`
- 기준 해설: `인재원_수학_2-1-1_수와식_정답과해설.pdf`
- 비교용: `인재원_2-1-1_홀짝구성_미리보기.pdf`

소스 내부의 폴더명이 `인재원_KaTeX_교재조판기_v11`로 남아 있을 수 있다. 폴더명만 보고 구버전으로 판단하지 말고 README·원고·캐릭터 이미지·검증 기록을 확인한다. 확인한 최신 상태는 여자 선생님이 등장하는 학생용 259쪽, 해설 87쪽, 예제 포함 1,039문항이다.

원본 가우스 샘플·개념의 숲·유형의 나무 파일이나 이전 대화에 붙인 이미지가 현재 작업환경에 없다면, 실제로 본 것처럼 서술하지 않는다. 제공된 v15 지면과 02번에 명시한 확정 요구사항을 기준으로 진행한다. 원본 자료가 없다는 이유로 가능한 코드·데이터 작업까지 멈추지 않는다.

목표는 todays-math의 동일 문항을 인재원 교재에 조판하고, 교재 문제별 QR에서

## 권장 구현 순서

1. 저장소 현재 상태와 기존 스튜디오 기준 지면을 확보하고, 03번 계약을 확정한다.
2. 서버에서 문항 조회·확정본 저장·내보내기 기능을 만들고 스튜디오가 읽게 한다.
3. 기존 원고를 손실 없이 이관하고, 학년·학기·권차 및 단원 구성을 데이터로 분리한다.
4. 실제 연결된 문항으로 짧은 단원 하나를 끝까지 조판한다.
5. 문제별 영상과 고정 QR 주소, 로그인 후 복귀, 예습 범위 접근을 연결한다.
6. 기준 교재 전권의 회귀 검수와 서로 다른 학년의 조판 검수를 수행한다.

저장소를 별도로 나누는 것부터 시작하지 않는다. 기본안은 todays-math 안에 교재 관리·영상 연결을 두고, 기존 조판 코어를 재사용 가능한 모듈로 분리하는 것이다. 오프라인 파일 입출력은 보조 경로로 유지한다.
