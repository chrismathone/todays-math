## 통합 과정에서 수정한 결함

- 새 판본 복사가 선택한 `blankForms`를 누락하던 문제: 선택값과 과거의 필드 부재를 각각 보존한다.
- 새 판본 복사가 개념의 파생 식별자에 자기 식별자를 넣던 문제: 원래 개념 파생 관계를 보존하고 판본 계보는 기존 판본 필드에 유지한다. 실제 사전검사 실패를 먼저 재현했다. 자기 참조 검사 자체는 유지한다.
- 구획 저장이 개념·백지 선택까지 저장한 것으로 표시하던 문제: 각 저장 대상의 상태를 구분하고 목록 이동 전에 필요한 개념 저장을 수행한다. 이동 취소는 편집 내용을 유지한다.
- 다시 연 교재의 기존 개념백지 연결이 편집 화면에서 빠지던 문제: 저장된 연결을 별도 목록으로 보여 주고 교사가 명시적으로 재확인한다. 본문 변경은 대기 중인 확인을 해제하며, 거절은 이전 확인 요청으로 덮이지 않는다. 확인만 변경한 이동과 409 충돌 시 편집 보존도 검사했다. 저장되지 않은 형식·난이도 값을 만들어 넣지 않는다.
- 학습 기록을 사용하는 새 교재 경로 3곳을 기존 SRS 격리 검사 허용 목록에 정확히 추가했다.
- 최신 EYWA 담당·수강 관계를 교재 배정·개념 기록·재출제·학생 QR 권한에 연결했다. 쓰기 전에 동기화하고 같은 트랜잭션에서 현재 관계를 다시 확인한다. 권한 철회 뒤 재전송도 차단하며, 책 소유권과 이미 확정된 문항은 유지한다.

## 남아 있는 자료와 실물 확인

다운로드 자료에서 v13 학생용 PDF와 기획 자료를 확인했지만 v15 편집 가능한 ZIP/HTML 원본은 확보하지 못했다. v15 전권 이관·쪽수·문항 수 전수 검증을 완료했다고 표시하지 않는다. 실제 게시 영상 재생·교체, 다른 학년 실제 원고, 실물 인쇄와 휴대폰 QR 스캔도 아직 검수하지 않았다.
