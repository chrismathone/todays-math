# 교과서 문항으로 본 생성 엔진의 빈 곳 (2026-10-08)

원장님 요청: «교과서 문제 추출이 끝나면 추출한 교과서 문제들을 바탕으로 우리 문제 생성 엔진을 업그레이드 할 수 있는 부분은 업그레이드할것».
이 문서는 그 **첫 단계 — 무엇을 고칠지 재는 일**이다. 엔진 코드와 DB 는 건드리지 않았다. 모든 수는 이 문서 끝 «부록 A»의 방법으로 실제로 돌려서 얻었다.

## 요약 (5줄)

1. 교과서 12,281문항 가운데 엔진이 있는 과목(중1·중2·공통수학1)이 9,462문항이고, 중1·중2 107차시 **전부**와 공통수학1 51차시 중 49차시에 엔진 유형이 붙어 있다 — 대응은 엔진 등록부의 `grade + unitSection` 이 단원 시드의 `grade + section` 과 글자 그대로 같은 것으로 맺었다(엔진 1,673유형 전부 맞음).
2. 엔진이 **과목째 없는** 곳은 공통수학2 · 대수 · 미적분1 · 확률과 통계 · 기하 — 159차시 2,819문항(교과서의 23%)이고, 그 가운데 86%(2,437문항)는 그림이 없다.
3. 엔진이 있는 차시의 빈 곳은 «내용»보다 **«묻는 꼴»**이다 — 보기에서 판단해 고르는 문항이 1,494(엔진 과목의 16%)인데 그 꼴을 한 번이라도 내는 엔진 유형은 1,673개 중 47개이고, «다음 중 계산이 옳지 않은 것은?» 같은 계산 판정형(212문항)은 엔진 유형이 0이다.
4. 서술형 231문항과 «⑴ ⑵ …» 소문항 묶음 997문항도 엔진에 대응하는 꼴이 없다(서술형은 2026-08-27 «발문만 바꾼 파생 금지» 뒤 새 생성기가 아직 없다).
5. 공통수학1 의 «유형 0» 차시 둘은 생성기가 없는 게 아니라 같은 꼴의 유형이 이웃한 «(1)» 차시에 붙어 있고, 행렬 단원은 교과서 162문항 중 75문항이 2×2 가 아닌 크기를 쓰는데 엔진 표본은 36개 중 32개가 2×2 만 쓴다.

## 3. 상위 빈 곳 10곳 — 표본과 새 생성기 제안

각 차시에서 교과서 문항을 «같은 차시 엔진 표본과 글이 덜 닮은 순»으로 10~30개, 무작위로 4~8개 읽었다(부록 A-4 · 엔진 유형이 0 인 차시는 전부). «엔진이 덮는다»는 판단은 그 읽기에서 나왔다. 제안마다 **그림 필요**를 따로 적었다 — 그림이 꼭 필요한 것은 §3.11 에 모았다.
