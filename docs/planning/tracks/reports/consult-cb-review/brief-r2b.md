# 검산 요청 1/2 — 리드가 고친 개념 백지 문항 55개의 «전 → 후» (한국어로 · 파일 수정 금지 · 마크다운 90줄 이내)

너는 한국 초 · 중학교 수학(2022 개정)을 아는 독립 검토자다. 학원의 종이 회상 시험 «개념 백지»의 고정 문항 은행에서 외부 검토가 오류 · 결함으로 짚은 문항을 리드(Claude)가 고쳤다.
**하나하나 다시 계산해** 틀린 것 · 어색한 것 · 고치다 새로 생긴 오류를 찾아라. 동의만 하는 답은 쓸모가 없다.

표기: `$...$` 는 KaTeX, `{ }` 는 학생이 채우는 빈칸의 답(채점표에서는 굵게). 「example」은 개념 지도에 **용어와 함께** 찍히는 예 물음 → 답(뜻 문장은 학생에게 안 보인다), 「why」는 ○× 의 까닭, 「definition」은 뜻 문장(문장 빈칸 형식에서는 이 문장만 찍힌다 — 용어는 안 찍힌다), 「term」은 용어다.

검산할 것: ① 수 · 식 · 답이 맞는가 ② 도형이 실제로 있을 수 있는가(삼각형 넓이 ≤ 두 변의 곱의 반 · 내접원 반지름 ≤ 둘레/(6√3) …) ③ ○× 의 참 · 거짓이 고친 문장과 맞는가 ④ 그 학년 말로 읽히는가 ⑤ 예 물음만 보고 풀 수 있는가.

합의된 방침(지켜야 하는 것): 문항의 뜻을 지키며 최소로 고친다 · 초4 뛰어 세기는 «받아올림이 없을 때 …» 틀 · ○× 는 답을 뒤집지 않고 문장을 고쳐 참 · 거짓을 깨끗하게 · 해설만 고치는 문항은 정답을 지킨다.
