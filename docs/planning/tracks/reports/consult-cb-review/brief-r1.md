# 협의 요청 — 개념 백지 은행 전수 검토의 처분 방침 열 가지 (한국어로 · 파일 수정 금지 · 마크다운 150줄 이내)

너는 한국 초 · 중학교 수학(2022 개정)과 종이 시험 채점을 아는 독립 검토자다. 아래 안건마다 **하나의 안을 고르고**(섞어도 되면 섞은 꼴을 적고),
까닭을 3줄 안으로 적어라. 리드(Claude) 초안에 동의하지 않으면 **왜 틀렸는지**를 먼저 적어라 — 동의만 하는 답은 쓸모가 없다.
원장님이 «grok 과 합의를 도출해서 진행하라»고 하셨다. 둘이 같은 안이면 그대로 가고, 갈리면 리드가 네 까닭을 읽고 다시 정한다.

## 배경 — 개념 백지가 무엇인가

- 학원에서 쓰는 **종이** 회상 시험이다. 자동 채점은 없다 — 교사가 «채점표»를 보고 손으로 ○ × 를 친다.
- 은행은 고정 문항 32,646개(초3~중3, 소단원 360개). 소단원마다 개념 · ○× · 적용이 난이도 하 · 중 · 상 **10개씩**(시험이 잠근다) + 그림 246개.
- 개념 한 장의 칸: **용어**(보이는 글자 40자 이내) · 갈래 · 난이도 · **뜻 문장**(160자 이내, 핵심어 1~4곳을 `{ }` 로 감쌈) · 선택 **예**(물음 80자 · 답 60자).
- 한 장이 형식 넷에 같이 쓰인다. 학생이 **보는 것**과 채점표:

| 형식 | 학생지에 찍히는 것 | 채점표 · 채점 안내 |
|---|---|---|
| A 완전 백지 | 소단원 이름뿐. 떠올려 쓴다 | 고른 개념의 용어 + 뜻 문장(핵심어 굵게). 안내: «굵은 핵심어가 다 있으면 ○, 하나 빠지면 △, 없으면 ×» |
| B 용어 → 뜻 | **용어만** + 쓰는 줄. 머리 지시 «용어를 보고 뜻을 문장으로 쓴다» | 용어 + 뜻 문장. 안내: «문항 하나가 한 개. 뜻은 굵은 핵심어가 다 들어가야 ○» |
| C 문장 빈칸 | **뜻 문장만**(핵심어 자리가 빈칸). 용어는 안 찍힌다 | 안내: «빈칸 하나가 한 개. 굵은 글이 빈칸의 답» |
| D 개념 지도 | 가지마다 **용어 + 예 물음**. 뜻 칸은 빈 줄 | 뜻 문장 + 예의 답. 예가 없는 가지는 «학생이 든 예가 뜻에 맞으면 ○» |

- 고정 규칙: 문항 id · 소단원 · 번호는 안 바꾼다(빼야 하면 그 자리에 빈 표지를 남긴다). 수 · 단위 · 식은 모두 KaTeX. 교재 문장을 옮기지 않는다.
- 은행은 두 겹이다 — 처음 쓴 3,217개(소단원당 개념 2개쯤)와, «난이도별 10개씩»을 채우려고 나중에 더한 **보강 29,429개**. 보강의 개념은 상당수가
  «일반 제목 + 구체 계산 한 문장» 꼴이다(같은 개념을 난이도를 달리해 다시 묻느라).

## 검토가 찾은 것 (외부 전수 검토 2,997건 / 고유 문항 2,984개 + 인쇄 검토 + 리드의 대조)

- 확정 수학 오류 29 · 해설만 보완 16 · 조건 · 발문 보완 596 · **형식 · 채점 불일치 1,280** · 후보(확정 아님) 468 · 권고 409 · 선택 개선 199.
- 리드가 다시 셌다: 형식 문제로 걸린 고유 문항 ≈ 1,700 · 문항 자체의 문제 ≈ 1,213 · 난도 메타 62.
- 개념 의견 1,957건 가운데 **1,191건은 제안이 «원문 뜻 문장을 빈칸으로 찍어라»** — 곧 이미 있는 C 형식이다. C 로는 멀쩡한 문항이라는 뜻이다.
- 개념 10,800개 가운데 핵심어에 숫자가 든 것 4,317개(그중 용어에도 숫자가 있는 것 550). 숫자가 있다고 다 결함은 아니다(«받아내림: 윗자리의 1개를 10개로»는 보편 사실).

형식 문제의 실제 꼴(용어 → 뜻 문장):
1. «몫 찾기» → `$35\div5$의 몫은 곱셈식 $5\times\square=35$에서 $\square$에 알맞은 수와 같으므로 {$7$}이다.` — B 에서 학생은 «몫 찾기»만 본다.
2. «단위가 있는 곱» → `$4\,\mathrm{m}$의 $0.3$배는 {$1.2\,\mathrm{m}$}이다.`
3. «필요한 최소 점수» → `세 과목 평균이 $90$점 이상이 되려면 두 과목이 $88$점, $86$점일 때 남은 과목은 {$96$점} 이상이어야 한다.`
4. «서로의 수선» → `직선 가가 직선 나의 수선이면 직선 나도 직선 가의 {수선}이다.` — 핵심어가 용어에 이미 있다(베끼면 통과 · 이런 의견 72건).
5. «수를 쓴 그림의 쓸모» → `위에서 본 모양에 수를 쓰면 가려진 쌓기나무까지 {빠짐없이} 알 수 있다.` — 빈칸이 일상어다(6건).
6. (보편 — 결함 아님) «받아내림» → `어느 자리에서 뺄 수 없으면 {윗자리의 $1$개}를 그 자리의 {$10$개}로 바꾸어 쓴다.`

## 안건 1 — 형식 문제(B · A · D 가 용어만 보이는데 채점은 뜻 문장의 핵심어)를 어떻게 푸나

(가) **채점 안내 문구만** 고친다 — «뜻이 맞으면 ○, 굵은 글은 본보기». 은행 0건 수정. 학생지는 그대로라 «단위가 있는 곱»만 보고 쓰는 것은 남는다.
(나) **용어 칸에 조건을 싣는다** — «단위가 있는 곱» → «$4\,\mathrm{m}$의 $0.3$배 구하기», «몫 찾기» → «$35\div5$의 몫을 곱셈식으로 찾기». 뜻 문장은 그대로라 C 지면은 안 바뀐다. 용어만 ≈1,700개 수정.
(다) 예시형 개념은 **C 에만** 쓰고 B · A · D 에서 뺀다(개념 칸에 표지 하나 추가). B 의 «소단원마다 난이도별 10개»가 깨진다.
(라) 계약을 바꿔 **B 전용 물음 칸 + 채점 기준 칸**을 따로 둔다(인쇄 검토의 장기안). 10,800개에 칸을 채워야 한다.
(마) 용어는 두고 **뜻 문장을 일반 진술로** 다시 쓴다 — «길이에 수를 곱하면 곱에도 {같은 단위}를 붙인다». 개념 시험다워지지만 C 지면이 바뀌고 문장 ≈1,700개를 새로 쓴다.
리드 초안: **(가) + (나)**. (가)는 바로, (나)는 학년 트랙에서. (마)는 일반 진술이 한 문장으로 자연스러운 문항에 한해 작업자가 고를 수 있게 할지 — 의견을 달라.
같이 답할 것: 꼴 4(핵심어가 용어에 이미 있음)와 꼴 5(일상어 빈칸)는 (나)로 안 풀린다 — 어떻게 하나(빈칸 자리를 옮긴다 / 용어를 바꾼다 / 둔다).

## 안건 2 — (나)를 한다면 범위

(가) 외부 검토가 짚은 ≈1,700개만. (나) 핵심어에 숫자가 든 4,317개를 전부 «용어만 보고 핵심어를 쓸 수 있나»로 한 번씩 판정하고, 못 쓰는 것만 고친다.
리드 초안: **(나)** — 검토는 표본이 아니라 전수였지만 그 판정 기준이 검토자마다 달랐다(초3 은 154건, 초5 는 416건, 중3 은 0건을 이 꼴로 잡았다). 판정 규칙 한 줄로 다시 훑는 편이 고르다.
판정 규칙 초안: «용어를 읽은 그 학년 학생이, 다른 정보 없이, 굵은 핵심어를 쓸 수 있는가. 보편 상수 · 정의의 수(직각 $90^\circ$, $1\,\mathrm{km}=1000\,\mathrm{m}$)는 쓸 수 있다고 본다.» — 고칠 곳이 있으면 고쳐 달라.

## 안건 3 — 채점 안내 문구((가)의 실제 글)

지면 문구는 간결 · 사무적이어야 한다(느낌표 · 이모지 없음). 지금 → 초안:
- B: «문항 하나가 한 개. 뜻은 굵은 핵심어가 다 들어가야 ○.» → «문항 하나가 한 개. 굵은 글은 본보기 답이다 — 같은 뜻이면 다른 말 · 다른 식도 ○.»
- A: «… 굵은 핵심어가 다 있으면 ○, 하나 빠지면 △, 없으면 ×.» → «… 굵은 글의 뜻이 다 있으면 ○, 하나 빠지면 △, 없으면 ×. 말이 달라도 뜻이 같으면 있는 것으로 본다.»
- C 는 그대로(빈칸의 답). 다만 한 줄 더: «같은 뜻의 다른 말 · 같은 값의 다른 꼴도 ○.»를 넣을지.
더 나은 글이 있으면 써 달라. C 에 한 줄을 넣는 것에 찬반.

## 안건 4 — C 에서 용어가 숨으면 답 방향을 못 정하는 문장 (4묶음 10문항 · 외부 검토가 못 잡음)

(가) 뜻 문장 안에 목적을 넣는다(«가장 큰 조사값을 찾으려면 …»). (나) 그대로 두고 C 채점 안내에 맡긴다.
리드 초안: **(가)** + 같은 소단원에서 «빈칸을 비운 글이 같고 답이 다른» 문장을 막는 자동 시험.

## 안건 5 — D 의 예 물음이 숨은 뜻 문장에 기댄다

(가) 예 물음에 조건을 다시 써 넣는다. (나) 그런 예는 뺀다(빈 예 칸 — 학생이 예를 든다). (다) 80자 안에 들어가면 (가), 아니면 (나).

## 안건 6 — 난이도 메타

(가) 그대로 둔다(이번 범위 밖 · 기록만). (나) 실제 난도로 다시 매기고, 모자라는 칸은 새 문항을 쓴다(초4 · 초6 합쳐 최대 118 소단원 × 1~2문항).
리드 초안: **(가)** — 난이도 딱지가 틀려도 지면의 수학은 맞고, 외부 검토 스스로 «학생 수행 자료로 후속 검증»이라 적었다.

## 안건 7 — 후보 · 권고 · 선택 개선(합 1,076건)까지 이번에 하나

(가) 필수(확정 · 조건 보완 · 형식)만. (나) 전부 원문과 대조해 «고침 / 기각(까닭)»을 기록한다 — 필수를 먼저 내보내고 이어서. (다) 후보는 목록만 남긴다.
리드 초안: **(나)**. 기각의 기준 초안: 교과서 관행으로 이미 정해지는 조건(0 이 아닌 수로 나눈다 · 각기둥은 직각기둥 · 공정한 주사위)은 문항마다 덧붙이지 않는다 — 글자 상한과 초등 가독성이 먼저다. 동의하는가, 어디에 선을 긋겠는가.

## 안건 8 — 그림의 «금색» 지시 (27개 그림)

지면은 금색(#A57F00)과 먹색 두 색이다. 학원 프린터는 흑백이 흔하다 — 금색은 중간 회색으로 찍힌다. 물음이 «금색 선분의 이름을 쓰시오» 꼴이다.
(가) 27개를 하나씩 보고, **색 말고 단서가 없는 것만** 고친다: 그 선을 굵게 하거나 점선으로 하고 물음을 «굵은 선분»으로. (나) 27개 모두 기호(ㄱ, ㄴ)를 붙이고 물음을 기호로. (다) 그대로(이름표 지시선이 닿아 있으면 충분).
리드 초안: **(가)**. 물음의 말은 «금색» 대신 무엇이 좋은가(«굵은» · «색칠한» · «표시한»).

## 안건 9 — 확정 오류 가운데 고치는 방식이 갈릴 셋

9a. 초4 뛰어 세기 일곱 장: `$10000$씩 뛰어 세면 {만의 자리} 숫자가 $1$씩 커진다.`(천 · 십만 · 억 · 조 · 백억도 같은 꼴). 외부 검토: «9 → 0 올림에서 거짓». 교과서도 이 문장을 쓴다.
 (가) 둔다(교과서 관행). (나) 한마디 조건을 붙인다 — 어떤 말로? (다) 외부 제안처럼 «90000 에서 뛰어 세면?» 문제로 바꾼다(문항의 뜻이 바뀐다).
 리드 초안: **(나)** — `…{만의 자리} 숫자가 $1$씩 커진다($9$ 다음에는 윗자리로 올라간다).` 다만 `$9$인 자리에서 일어나는 올림`(십만의 자리가 9 → {백만의 자리} 숫자가 1 커진다)은 백만의 자리도 9 인 경우가 남는다 — 네 문장을 달라.
9b. 중2 ○×: `$x-2\le a$를 만족하는 자연수가 없으면 $a<1$이다.` 지금 답 ×(까닭 «$a<-1$이어야 한다»). 논리로는 $a<-1$이면 $a<1$이므로 **참**이다. 외부 검토: 답을 ○ 로 뒤집어라.
 (가) ○ 로 뒤집는다. (나) 문장을 고쳐 × 를 지킨다 — `…자연수가 없으면 $a\le-1$이다.` × · 까닭 «$a=-1$이면 $x\le1$이라 $x=1$이 해다. $a<-1$이어야 한다». (다) 문장을 `$a<-1$이다`로 고쳐 ○.
 리드 초안: **(나)** — «약한 조건이라 참»은 ○× 로 재기에 나쁜 문장이고, 경계값을 묻는 원래 뜻이 산다.
9c. 초4 어림: `어림한 수가 실제 수에 가까울수록 어림한 곱이 실제 곱에 {가깝다}.` 반례 — 실제 $100\times100$ 에서 $80\times125=10000$(정확)인데 더 가까운 $90\times110=9900$.
 (가) «한 수만 어림할 때» 조건을 붙인다. (나) «대체로»를 붙인다. (다) 둔다.
 리드 초안: **(가)** — `곱하는 두 수 중 하나만 어림할 때, 어림한 수가 실제 수에 가까울수록 …`. 초4 에게 과한가.

## 안건 10 — 초3 처음 은행의 «예» 56개

초3 처음 은행은 소단원마다 첫 개념의 «예»가 **그 소단원 적용 문항을 글자 그대로 옮긴 것**이다(56/56). 그래서 «선분» 가지의 예가 «끝점이 하나이며 한쪽으로 계속 뻗는 곧은 선의 이름을 쓰시오 → 반직선»이다. 외부 검토는 5건만 잡았다.
(가) 56개를 다 읽고 그 개념의 예가 아닌 것만 새 예로 바꾼다. (나) 56개 모두 그 개념에 맞는 새 예로 쓴다(D 의 예와 C 의 적용이 같은 물음이 되지 않게). (다) 어긋난 것은 예를 뺀다.
