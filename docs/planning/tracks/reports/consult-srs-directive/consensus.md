  **조건이 차는 것은 «재논의의 개시»이지 구현 승인이 아니다.** 본 학생 수를 같이 적는다(소수의 반복 관찰을 전체로 일반화하지 않는다).

## 4. 다음 일감 — S5 (아직 안 했다)

지시서: `docs/planning/tracks/briefs/srs-retry-solution.md`. 요지 —

- 중등 은행 날의 **재도전에도 «아직 모르겠어요»**를 보인다. 한 바퀴 = 남은 문항을 각각 한 번 시도하는 것이고 «모르겠어요»도 그 시도로 센다.
- **두 바퀴** 뒤에도 남은 문항은 **학생이 요청하면** 풀이를 연다(서버가 이미 내려주는 `solution` 을 그린다). 풀이를 본 것만으로 해결 처리하지 않는다. 칸은 미해결 0 일 때만.
  개념 날의 «세 바퀴»와 숫자가 다르다 — **은행 한정 두 바퀴 예외**임을 글로 남긴다(codex).
- 간격(기억)은 첫 풀이에서 이미 정해졌다 — 안 바뀐다. 풀이를 연 뒤의 성공은 «도움 후»다.
- «도움 후»의 저장: **지금 세션 꼴에 이미 있는 상태값으로 가를 수 있을 때만** 저장한다. 새 칸 · 새 표가 필요하면 저장하지 않고 화면에서만 가르고(codex), 영구 저장은 원장님께 따로 여쭌다(grok).
- 🔴 **학생 화면이 바뀐다**(재도전의 단추 · 풀이가 서는 자리) — 시안 절차(D-07)를 따른다. 그래서 리드가 바로 구현하지 않았다.
- 하지 않는 것: 별도 실습 모드 · 여섯 구간 · 활동 중 힌트 사다리 · 공방 단계 추가 · 답안별 표나 칸 · 교사 화면.
