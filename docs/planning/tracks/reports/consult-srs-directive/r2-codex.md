**고른 묶음: P2 — 보류하고 재개 조건을 다시 건다.**

- 공방 한정안은 교육적으로 타당하지만, 기존 결정을 바꿀 사용 근거는 아직 없다. 다음 일감으로 확정하기보다 막히는 지점과 소요 시간을 먼저 확인한다.
- 기존 조작 활동은 유지한다. «합치기»를 넣는 것은 새 학습 단계이므로, 단계 재편만으로 분량이 줄어든다고 단정할 수 없다.
- 재개 조건은 **S1·S5 배포 후 관찰한 공방 시작 10회 중, 재도전 뒤에도 진행하지 못하거나 풀이를 요청한 경우가 2회 이상**으로 제안한다. 2÷10=20%이며, 기존 문서의 불명확한 20%를 새로 정의하는 변경이다.
- 완료하지 못한 회차도 포함해 소요 시간·막힘을 수동 관찰한다. 교사 화면이나 DB 추가에 의존하지 않는다. 배포 2주 뒤 표본이 부족하면 관찰 계획을 재검토하며, 조건 충족은 **재논의 개시**이지 구현 승인이 아니다.

**가장 큰 위험:** 소수 학생의 반복 관찰을 전체 학생의 요구로 일반화하는 것. 관찰한 학생 수도 함께 밝혀야 한다.

**물음 1:** 공방 확장은 기존 활동을 대체하는 방식으로만 하고, 관찰한 기존 하루 임무의 소요 시간 중앙값을 넘으면 단계나 문항을 줄인다.

**물음 2:** S5는 멈추지 않고 «도움 후»를 현재 화면에서만 구분하되 독립 숙달 산정에서 제외한다. 영구 저장이 필요해질 때 새 칸의 승인을 별도로 요청한다.
