# 합의 요청 — 학생 SRS 2회차: 갈린 셋(S2 · S3 · S4) (2026-10-03 밤)

너는 독립 검토자다. 1회차 결과:

| 안건 | 리드 | 검토자 A | 검토자 B | 결과 |
| --- | --- | --- | --- | --- |
| S1 «아직 모르겠어요» 결함 | ㉮ | ㉮ | ㉮ | **빈 답을 «모름 = 그 활동의 오답»으로 받는다**(3:0) |
| S5 중등 은행 재도전 | ㉯ | ㉯ | ㉯ | **재도전에도 «모르겠어요» · 두 바퀴 뒤 남은 문항은 학생이 요청하면 풀이**(3:0) |
| S2 활동 도중의 힌트 | ㉯ 공방 안에서만 | ㉯ | ㉮ 지금대로 | 2:1 |

**코딩 에이전트에 넘길 첫 일감**은 두 검토자가 따로 적었는데 **같다**: S1 + S5 만. 실습 모드 · 공방 확장 · 답안 기록 · 교사 화면은 넣지 않는다. 이것은 정해진 것으로 둔다.

남은 것은 S2 ~ S4 — **그 다음에 무엇을 하는가**다. 서로의 논거를 읽고 다시 골라라.

## 배경(1회차 요청서에서 변하지 않은 사실의 요약)

- 학생 화면 `/learn` 의 수학 탐험: 하루 한 임무(개념 날 15활동 · 은행 날 10 ~ 12문항 · 기억 복습 날). 분수 통분 카드 하나에만 **공방**(조작 활동 여섯 단계: 예상 → 조각 나누기 → 조각 크기 맞추기 → 규칙 찾기 → 새 분수 확인 둘 → 끝)이 있고, 오늘의 탐험 안에서 그 개념을 배우는 도중에 뜬다.
- 외부 지시서는 별도 «실습 모드»(20 ~ 25분 · 여섯 구간) · 활동 중 «조작 힌트 → 설명 → 새 문제» 사다리 · 최초 응답 / 도움 후 성공 / 전이의 분리 기록을 요구한다.
- 이미 내려진 결정: 통합 탐험 결정문(2026-09-26 — «시작 메뉴를 만들지 않는다 · 조작 활동은 같은 틀 안에서 · 하루 한 묶음 · 답이나 해설을 자동으로 공개하지 않는다») ·
  27번 문서(2026-10-01 — «활동 중 힌트 단계 · 도움받은 성공: 하지 않는다» · «답안별 기록 표: 지금은 안 한다(3:0) — 교사 화면을 2주 쓴 뒤 20% 조건으로 다시 연다»).
- 운영 자료: 2026-10-01 기준 학생 상태 1행 · 개념 카드 기록 0건. 교사가 탐험 기록을 보는 화면은 main 에 없고 작업이 멈춰 있다.
- 새 화면은 시안 선택 뒤에만 구현한다(D-07). 공유 DB 에 칸 · 표를 더하는 일은 원장님께 다시 여쭌다. 저장 꼴을 바꾸면 두 번 배포.

## 1회차의 논거

**㉯ 쪽(공방 한정으로 연다 · 공방을 키운다 · 공방 세션 안에 최소 기록)**
- 조각 크기를 직접 견주는 도움은 공방의 발견 활동에 맞고, 정답 · 완성된 식을 드러내지 않고도 줄 수 있다. 도움을 거친 결과는 독립 숙달의 증거로 쓰지 않고 새 문제를 혼자 풀게 한다.
- 다만 이것은 27번 문서의 «활동 중 힌트 금지»에 **공방 한정 예외를 만드는 결정**이다 — 충돌이 없다고 처리하면 안 된다.
- 이미 같은 개념의 조작 활동이 있으니 별도 진입보다 통합 탐험 결정에 맞는다. 통분한 조각을 합치고 잘못된 덧셈(분모를 더함)과 견주는 일은 지금 공방에서 자연스럽게 이어진다.
  기능을 덧붙이기보다 기존 단계와 겹침을 줄여 다시 짠다. 시간은 실제 사용으로 잰다. 새 화면은 시안 절차를 따른다.
- 최소 기록은 채점하는 단계의 첫 응답 · 도움 사용 여부 · 새 문제의 독립 성공만. 채점하지 않는 «예상» 단계에 정오 판정을 새로 붙이지 않는다. 27번 문서의 기록 보류에 대한 **제한적 변경**이다.
- 위험: 조작 안내가 사실상 답을 알려 줘 이해를 과대평가한다 · 공방이 길어져 하루 분량(15활동 + 공방)이 과해진다 · «최소 기록»이 전체 답안 수집으로 번진다.

**㉮/㉰ 쪽(지금대로 · 보류 · 안 한다)**
- 9월 26일 · 10월 1일의 결정을 바꿀 **사용 증거가 없다**(학생 상태 1행 · 카드 기록 0건). 공방의 조각 나누기 · 크기 맞추기처럼 활동 자체인 조작은 지금 자리에 둔다.
- 별도 진입과 여섯 구간은 기존 결정과 충돌한다. 기존 공방을 키우는 안도 **재기 전에** 길이와 단계가 늘어난다. 지금 공방에는 «합치기»와 «두 갈래 확장»이 없다 — 곧 «키운다»는 새 단계를 만드는 일이다.
- 기록이 거의 없는 지금 표를 열어도 판단할 행이 없다. 개념 카드는 이미 첫 바퀴만 간격을 늘린다.
- 위험: 조각이 안 맞는 학생의 다음 도움이 재도전 뒤의 해설뿐이다 · 보류하는 동안 통분 공부는 «합치기»와 «분모를 더하는 오답의 견주기» 없이 남는다 ·
  27번 문서의 재개 조건(교사 화면 2주 · 20%)이 **멈춰 있는 교사 화면에 묶여 있어 계산되지 않는다.**

## 물음 — 묶음으로 고른다

- **P1 방향을 정하고 조건부로 착수** — S2 ㉯ · S3 ㉯ · S4 ㉯ 를 **다음 일감의 방향**으로 정한다. 착수 조건: (a) S1 + S5 가 나간 뒤 (b) 공방 확장의 시안을 먼저 고른 뒤 (c) 27번 문서에 «공방 한정 예외»를 글로 남긴 뒤.
  사용 자료를 기다리지 않는다.
- **P2 보류하고 재개 조건을 다시 건다** — S2 ㉮ · S3 ㉰ · S4 ㉰. 지금은 S1 + S5 뿐. 재개 조건을 **계산할 수 있는 것**으로 다시 적는다(무엇으로? — 답에 적어라).
- **P3 섞는다** — 셋 가운데 일부만 연다(어느 것을 · 왜).

그리고 어느 묶음이든 답하라:
1. 공방을 키운다면 **하루 분량**(개념 15활동 + 공방)이 과해지지 않게 하는 규칙 하나.
2. S5 의 «도움 후»를 지금 세션 저장에 담을 수 없으면(새 칸이 필요하면) 어떻게 하나 — 멈추고 묻는가, 저장하지 않고 화면에서만 가르는가.
