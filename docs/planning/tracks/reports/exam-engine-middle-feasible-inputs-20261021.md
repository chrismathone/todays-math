# 중2 엔진의 조건 성립과 지수 문자 분리 (2026-10-21)

[다른 세션의 결함 인계](../brief-engine-handoff-display-20261021.md) 중 M8·M9·M19·M20을 생성 코드에서 수정했다. 기존 출제 문항·은행·학생 기록과 다른 세션의 지면/서술형 검수 묶음은 수정하지 않았다. 수학 조건이 바뀌는 새 생성 버전이며, 기존 행을 같은 ID로 다시 만드는 지면 보정 작업이 아니다.

| 인계 | 수정 | 확인한 범위 |
|---|---|---|
| M8 | 작은 삼각형의 둘레를 `2×AD + 1~10`으로 뽑는다. | 한 변 AD와 나머지 두 변이 실제 삼각형을 이루는 구성 가능성, 닮음비와 둘레의 유일성 |
| M9 | 두 변의 차보다 크고 합보다 작은 밑변만 뽑고, 외분 선분도 양의 정수가 되도록 한다. | 비어 있지 않은 48개 선택 범위·171개 정수 조합, 엄격한 삼각부등식과 B–C–D 순서 |
| M19 | 원래 범위에서 세 변과 내접원 반지름이 모두 일치하는 18개 튜플을 선택한다. | 세 변이 정하는 실제 넓이·반지름의 정확한 정수 항등식. 검사용 공식을 학생 풀이에 넣지 않는다. |
| M20 | 밑의 a/b 또는 x/y와 지수의 미지수 m/n/k를 분리하고, 밑의 값에 관계없이 등식이 성립한다고 명시한다. | 두 밑 문자 쌍·64개 지수 입력 조합에서 계수와 지수의 유일성, 음수·0을 포함한 독립 대입 |

M19의 변형 공간은 18개로 제한된다. 더 큰 묶음을 만들 때 잘못된 조건이나 중복을 채워 넣지 않는다. 기존 세트 생성기의 공간 부족 예외는 유지했다. M20의 기존 식 간단히 하기 분기는 바꾸지 않았다. 학생용 해설은 기존의 닮음·비례식·내심에서 변까지의 거리·지수법칙을 사용하며, 새 공식·삼각비·로그·미분을 요구하지 않는다. 이것만으로 적용 교육과정과 단원 전체를 승인하지 않는다.

독립 검수자의 **수정 전 실제 생성 120개**에서는 M8 21/30, M9 17/30, M19 30/30의 조건 오류와 M20 문자 충돌 12건의 비유일성이 확인됐다. 같은 120개 씨앗으로 수정 후 다시 생성했을 때 M8·M9·M19 각각 30건과 M20의 지수 입력 15건은 대상 검사를 통과했다. 나머지 식 간단히 하기 15건은 그 독립 검토의 전체 계산 재인증 대상이 아니다. 원문 기출의 답을 맞춰 본 결과나 새 수작업 쌍둥이의 blind 승인이 아니다.

parent의 별도 발문 파서 회귀 8개는 수정 전 모두 실패하고 수정 후 모두 통과했다. 유형마다 실제 API 씨앗 100개와 강제 매개변수 373조합을 생성하며, 내부 `facts`나 생성기 정답을 계산 oracle로 쓰지 않는다. 기존 수작업 검수 수에 이 출력·반복을 합산하지 않는다. 저장소 정식 회귀 파일은 ES2017 설정에 맞춰 `BigInt(n)` 표기를 쓴 복사본이다.

현재 확장 회귀 9파일, 변경 파일 TypeScript·ESLint는 메모리 하한 때문에 **실행 대기**다. 시작 전 검사에서 차단되어 통과로 세지 않았다. 기존 단항식 검산기는 새 문자 분리를 반영해 네 밑 문자와 다섯 대입점을 모두 검사하도록 강화했다. 이 체크포인트는 한정 수학 검사 통과이며 전체 엔진 검증 완료가 아니다.

네 family의 버전을 바꿔 examStudy의 새 recipe와 추적 메타데이터에 연결했다. 일반 `engine-mid:` 적재기의 과거 외부 ID 표기는 이 변경으로 새 판을 자동 구분하지 않는다. **기존 ID의 자동 재생성·덮어쓰기나 refresh 실행을 승인하지 않으며**, 향후 적재는 새 ID/판 구분과 별도 구체 범위·학년·권리·검수 원장이 필요하다. 이 세션에서 적재기·운영 DB를 실행하지 않았다.

학년·권리·실제 출처·native/public 승인은 별도 관문으로 유지한다. 실제 작성178/정본선택174/수학·학년173/최종·적재 가능0은 과거 정본 v50의 집계이며 새로 늘리지 않았다. 새 집필·그림·imagegen·DB 쓰기·배포는0이다. M31의 대각선 없는 경계 그림은 별도 준비 사본에서 검토 중이고, M28은 실제 소유 파일과 조건/그림 불일치를 확인한 상태다.
