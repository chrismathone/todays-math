## 구현 전 고칠 것 (codex §6 을 채택 — 리드 안과 겹치고 더 구체적)
공통: **첫 쪽에 문장 · 요약 · 재시험 · 문의 자리를 먼저 확보하고, 넘치는 것은 오답 행만 다음 쪽으로**(기존 `exam-report-wrong-table-consensus.md`). 지금처럼 재시험 · 문의가 통째로 2쪽으로 밀리면 안 된다. 글자 축소 · 말줄임으로 한 장을 맞추지 않는다. 긴 문장을 무조건 한 장에 싣는 보장은 하지 않는다(남은 자리 실측).
- H1: 위 공통 규칙.
- 편지형: 머리 예약(48.8mm)과 점수 · 맞힌 수 간격을 실제 높이에 맞춰 줄인다 — 점수 글자는 키우지 않는다. 오답은 행만 부록.
- 정오 격자형: **전체 문항 ○ · ✕ 격자**(번호 자리 고정)로 바꾸고, 틀린 문항의 단원 · 유형 설명은 따로. ✕ · 두꺼운 테두리의 오답 강조를 낮추되 번호 · 기호 · 글자만으로 정오가 구별되게(흑백). 고친 뒤 다시 잰다.
- 장부형: 긴 오답 표가 이름표 열까지 폭을 쓰게, 원장님 문장 가독(9pt 밀도 완화), 문의 한 줄만 다음 쪽으로 가는 일 방지.
- 보류(입력 화면 변경이라 이번 범위 밖): 문장 칸에서 «잘한 것 / 보완할 것 / 다음 할 일»을 구별해 쓰게 하는 것 — 원장님께 따로 묻는다. 없는 강점을 지어내지 않는다.
