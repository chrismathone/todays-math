# 도형 편집기·모눈 엔진 이관 체크포인트

math-figure-editor 전달 1·2차에서 모눈 배경·편집 조작, 긴 벡터/선분/호와 수식 칩, Enter 없이 놓는 한글 수식 변환, 엔진 escape 초기화 개선을 반영했다. [적용·제외 지침](../../figure-editor-import-20261021.md)에 항목별 판단을 기록했다. SourceD 저장소는 읽기만 했고 실제 입력 13파일을 해시와 함께 QA 사본으로 보존했다.

모눈은 정사각형·양수·유한한 칸, 1~60 정수 칸으로 제한한다. 잘못된 data-grid로 실제 도형이 숨지 않게 하고, 도형을 덮는 데 60칸을 넘으면 자동 늘리기를 막는다. 배경 변경으로 도형·라벨을 이동하지 않는다. 자동 gridSnap·모델 교체·불확실 지적 삭제 후 자동 통과·마지막 대조 생략은 적용하지 않았다.

브라우저 초기 두 실행은 QA 입력 도구의 선택/입력 API 문제로 완료되지 않았고 결과·진단을 보존했다. 이 과정에서 실제 제품의 긴 라벨 조각이 거절되는 결함을 확인해 두 경로를 고쳤다. MathJax의 내부 SVG 그리기 요소만 허용 목록에 더하고 이벤트·외부 URL·스크립트·이미지 차단은 유지했다. 마지막 8화면 실행은 오류 0이며 콘솔의 favicon 404 한 건은 별도 기록했다. 관련 테스트 초기 실패, TypeScript QA ambient 누락, 카탈로그 최초 차이와 RAM 사전 중단도 이력에 남겼다. 스킵을 통과로 세지 않는다.
