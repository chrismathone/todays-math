# M5·M18 산점도 자료 비교 지원

`generateMiddleSet`은 발문만 보고 중복을 골랐다. 좌표 목록을 제거할 예정인 산점도에서 이 규칙을 그대로 쓰면, 발문은 같고 그림의 자료만 다른 두 문항을 채울 수 없다. 실제 유형 11의 서로 다른 생성 결과 두 개에 같은 발문을 주어 기존 코드의 재시도 소진을 재현했다. 수정 후 두 문항을 채운다.

비교 범위는 `3-2|상자그림과 산점도|06~12,14,15`의 정확한 9개 키다. 발문·순서가 정해진 두 축 이름·수치순으로 정렬한 점 자료를 함께 비교한다. 정답·해설·facts·장식·점 배열 순서·축 표시 간격은 새 자료의 근거가 아니다. 다른 유형과 13번은 기존 발문 비교를 유지한다. 저장 필드나 공개 응답 계약은 추가하지 않았다.

지원 범위에서 잘못된 그림 종류·버전·빈 축 이름·비수치/비유한 좌표·빈 칸이 있는 배열·점 개수 범위 위반·중복 점은 오류로 돌린다. 이 9유형은 한 점이 한 관측값이며 같은 위치에 겹친 사람을 표시하지 않는 계약이다. 이를 중복 관측을 허용하는 다른 유형에 확장하지 않는다. 축 범위와 렌더 가능성은 별도 렌더 검증 대상이며 이 비교 함수가 승인하지 않는다.

현재 발문·숫자·그림 생성은 바꾸지 않았다. 변경 전 공개 생성 출력 288개와 같은 모듈의 범위 밖 출력 80개, 세트 43개를 채집하고 수정 후 전체 객체가 일치함을 확인했다. 실제 엄격 SVG 9개도 변경 전 증거로 보존했다. 새 검사 36개를 포함한 관련 6파일 227개가 통과했고, 변경 TypeScript 3루트와 ESLint 3파일의 오류·경고는 0이다. 전체 프로젝트 타입 검사나 인쇄 품질 승인 수치는 아니다.

최초 채집 실행은 Windows 절대 경로 include 상태에서 진행되지 않아, 해당 실행 자식임을 확인한 Node 프로세스만 중단했다. 원인 전체를 확정하지 않는다. 상대 경로 include로 바꾼 다음 채집은 2.4초에 통과했다. 최초 회귀 실행의 실제 중복 오류와 아직 만들지 않은 fixture 오류를 보존했고, fixture 채집 후의 재실행에서는 의도한 중복 오류 1개만 남았다. 이후 수정과 빈 칸 배열 보강을 거쳐 관련 검사가 통과했다. 실제 실행·소스 해시는 `.qa-artifacts/exam-resume-20261008/engine-upgrade-20261019/m5-scatter-input-20261021-r1/`에 있다.

독립 작업자는 현재 소스를 읽고 Python 설계 증거를 검사했다. 이 검토를 독립 TS/API 실행이나 실제 SVG 측정으로 세지 않는다. 현재 좌표 목록의 순서를 발문에서도 바꾸면 전체 발문이 달라지므로, 점 배열 정렬만으로 그 경우까지 합쳐지지는 않는다. 좌표 목록을 정규식으로 지우는 처리는 하지 않았다. 다른 호출 경로인 결합형 세트도 이 변경으로 고쳤다고 주장하지 않는다.
