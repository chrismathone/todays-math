## 학년 관문과 엔진 작업

2025 중3은 2015 개정 적용 대상이다. 일반 중학교의 [교육부 적용 시기](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=0404&opType=N&s=moe&statusYN=W)의 단계 적용을 읽고 판단했다. 최초 참고 링크93457은 특수교육 고시이므로 일반 중학교 근거에서 정정했다. 2022 개정으로 재발행하는 경우에는 별도 목표 교육과정으로 새로 검수한다. 성취기준의 `9수`는 학년군 근거이므로 그것만으로 세부 학년·선수 개념을 승인하지 않는다.

교육과정 작업자는 공식2015 PDF와2020 수정 수학 HWP에서 이 배치에 쓰는 성취기준28개와 제한문구8개를 대조했다. 새 후보의 학생용 풀이 전체 검토와2025까지의 개정 고시 전수 감사는 완료로 주장하지 않는다. 범일중 PDF의 머리말2025/바닥글“26년”, 파일명 학교/문서 익명 학교 표기의 관계는 출처 검토 원장에 보류한다. 이를 근거 없이2026 시험 또는2025 완전 확정으로 바꾸지 않는다. 두 경우 모두 중3 적용 판본은2015이나 실제 시험 연도/학교의 내부 메타데이터는 확인이 필요하다.

도형을 그리는 개발 코드의 좌표/삼각 계산과 학생에게 요구하는 방법을 구분한다. 개발 검산에서 정답을 얻어도 학생용 해설이 사인/코사인 법칙·헤론·근과 계수 관계·벡터·덧셈/반각 공식·미적분·로그·행렬·라디안을 필요로 하면 중3 후보를 통과시키지 않는다. 기존 `solver_rules.json`의 검출은 보조이며 성취기준·학년·필수 방법의 의미 검토를 대체하지 못한다. 특히7·11·14·19번의 수선/합동/피타고라스 풀이를 따로 확인한다.

[현재 계약 감사](exam-twin-contract-audit-20261008.md), [다음5편 조사](exam-twin-next-five-20261008.md), [교육과정 근거](exam-twin-curriculum-20261008.md)를 함께 읽는다. 기존 transform의 `verified`는 원문 재계산 비교라 새 쌍둥이의 독립 정답/학년 검증으로 쓰지 않는다. DB 원본을 요구하는 adopt와 원문·크롭을 넣는 loader는 그대로 쌍둥이 저장기로 쓸 수 없다.

계약 감사에서 후속 적재의 추가 차단 조건을 확인했다. 현행 출처 해석은 `transformed + originProblemId:null`을 교재 이관본으로 표시하고, `figureSource:"image"`도 현재 serializer/배지의 입력에 전달되지 않는다. 외부 기출 참고 쌍둥이의 `exam_twin` 관계와 새 이미지 출처를 저장→serializer→배지→필터까지 연결하는 변경이 필요하다. 존재하지 않는 원문 FK를 만들거나 원문 DB 행을 가짜로 넣어 우회하지 않는다. 현재 계획의 `transformed/null`은 원장용 제안이며 이 호환 문제 해결 전에는 운영 적재하지 않는다.

27개 엔진 개선 후보(U01~U27)에 실제 코드 위치·검증·의존 단계·미구현 상태를 연결했다. 구현 완료는0이다. 이 목록은 이번 계약 감사의 범위이며, 추출하지 않은1,715편의 유형을 모두 분석했다는 뜻은 아니다. 후속 추출에서 얻는 유형·조건·그림 근거를 계속 추가한다.

후속 엔진 작업은 구조/소재/표현/역추론 템플릿과 수학 제약, 정확한 정답/풀이, 다중 그림/선택지 그림·원/접기/영역 작도, reviewed image 자산+math facts 결합, metadata→저장→조회→필터/UI, seed/자산/spec/digest 재현성, 실패/보류 분류와 학년 관문을 포함한다. TypeSafe/Jev는 현재 클라이언트로 좁은 분류·근거 비교·불명 라우팅을 설계하며 계산/해시/ID 검사는 코드가 한다. [Choice](https://docs.typesafe.ai/primitives/choice.md)와 [Confidence](https://docs.typesafe.ai/confidence.md), [계층 분류](https://docs.typesafe.ai/cookbooks/hierarchical_classification.md) live 문서를 읽었다. 모델 확률을 수학 정답·교육과정 승인·권리 허가로 취급하지 않는다.
