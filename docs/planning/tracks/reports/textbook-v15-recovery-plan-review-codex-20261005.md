## 실행상의 추가 확인

- 구조 계약의 공통 파일은 조율 담당이 소유해야 한다. 기능별 모듈을 먼저 만들어 renderer·CSS·pagination 통합 단계에서 충돌을 해결한다.
- 원본 PDF에는 없는 쉬어가기를 같은 디자인 통과로 표결하지 않는다. 연령·주제·이미지·문장 길이·생각 나누기 품질을 별도 판단한다.
- 실문항의 정답·해설과 합성 QA의 자리표시자를 구분한다. 코드 보존 검사와 내용 검수를 혼동하지 않는다.
- 운영 로그인 검사와 QR 권한은 실제 관문으로 남기되, 격리 DB 실험 성공을 운영 실행 증거로 확대하지 않는다.

Claude·Grok의 독립 지적을 반영한 최종 후보를 받은 후 파일 전체와 같은 해시를 다시 확인해 APPROVE/REVISE를 기록한다. 이번 REVISE는 계획 보완에 관한 것이며 앱 구현의 실패/완료 표결이 아니다.
