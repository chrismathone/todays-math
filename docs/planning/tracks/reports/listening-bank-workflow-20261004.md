# 듣기은행 원본 등록·시험지 구성 — 2026-10-04

사용자 요청은 EBS 출처 링크 확인을 넘어 실제 전국 듣기평가·모의고사 파일을 보관하고 은행 안에서 듣는 것이다. 회차 전체와 문항별 담기를 모두 지원하며, 교재 생성 버튼 정렬과 가져오기 폼도 함께 수정한다.

## 구현

- 듣기은행에서 MP3/WAV와 문제지·정답·대본 PDF를 등록한다. 그림 보기와 표는 문제지의 문항별 PNG로 보존한다. 모의고사는 1~17번만 읽는다. 없는 정답과 음원 구간을 추정하지 않는다.
- 실제 평가 음원에 맞춰 제한을 64MiB·30분으로 확장한다. 기존 청크 전송, 원본 해시 검사, 재생용 PCM 검증은 유지한다.
- 음원 보관과 시험지 구성은 같은 계정별 약 2GiB 한도를 사용한다. 원본·재생 파일 합계를 계산하며, 한도를 넘으면 저장 전에 거절한다.
- 은행 상세에서 직접 재생하고 여러 자료의 회차 전체 또는 선택 문항을 담는다. 개별 선택은 교사가 지정한 전체 문항 음원 구간을 사용한다. 선택한 구간만 합치고 번호·보기 ID·근거 구간을 재구성한다.
- 새 시험지는 원본과 별도로 저장한다. 출처와 이용 범위 확인 후 학생용·교사용 초안 인쇄를 제공한다. 정식 발행·학생 배정에는 기존 검수 절차를 적용한다.
- 문항 그림을 포함한 자료 하나는 3MiB로 제한해 다시 편집할 수 있도록 한다. HTTP 요청은 4MiB 이내이며, 발행 이력처럼 커질 수 있는 응답은 JSON 스트림으로 전달한다. [Vercel의 요청·응답 제한과 스트리밍 안내](https://vercel.com/kb/guide/how-to-bypass-vercel-body-size-limit-serverless-functions)를 반영한다.
- 출처 선택을 바꿔도 검색 필드 위치를 유지한다. 고2·고3 공식 페이지 주소를 허용한다.
- 교재 생성 버튼은 설정 아래 오른쪽에 정렬한다. 가져오기는 데스크톱 한 줄, 좁은 화면 두 줄로 배치한다.

## 실제 원본과 검증

원본은 이 작업 공간의 `output/listening-assessments/2026-2/`에 중1~고3 각 4개 파일로 준비했다. 고1 2026년 9월 학력평가 원본은 `output/listening-assessments/2026-09-mock/고1/`에 있다. 각 manifest는 실제 출처 URL, 파일 크기와 SHA-256을 기록한다. 바이너리를 Git에 넣거나 운영 DB에 자동 업로드하지 않았다. 기존 자료의 이용 허락 상태를 임의로 변경하지 않는다.

실제 문제지 137문항을 읽고 전국 평가 정답 120개를 독립 추출 결과와 비교했다. 7개 MP3가 엄격 형식 검사를 통과했고, 고1 전국 평가와 학력평가 전체 음원이 실제 PCM 디코딩을 통과했다. 최대 재생 길이는 30분 제한 이내다.

검증 증거는 `.qa-artifacts/listening-import/source-verification-20261004/`에 보존한다. 일반 테스트는 계약·이미지·PDF 경계·음원 제한·등록 실패 복구·장바구니·학생 정보 분리·HTTP 경계·교재 폼을 확인한다. 별도 로컬 PostgreSQL에서 원본 권한, 변경된 원본 거절, 음원 복제·선택 구간의 실제 PCM 바이트, 인쇄 권한을 검증했다. 운영 DB를 테스트에 사용하지 않는다.
