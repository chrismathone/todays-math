PDF의 물리 페이지는 파일 첫 장을 1로 센다. 아래의 인쇄 페이지는 문서 바닥에 찍힌 수다. 중학교 기준이 시작하는 물리 32쪽은 인쇄 28쪽이며, 제목은 `[중학교 1~3학년]`이다. **`[9수...]`는 중1~3 학년군이므로 그것만으로 정확한 중3 단원·학기나 선수 학습을 승인하지 않는다.**

HWP는 기존 설치 Python `olefile`로 OLE 스트림을 읽었다. `FileHeader` byte 36의 압축 플래그에 따라 `BodyText/SectionN`을 raw DEFLATE로 풀고, 태그 67 `PARA_TEXT`의 UTF-16LE 성취기준 문단을 읽었다. JSON의 레코드 번호는 스트림의 모든 HWP 레코드를 1부터 센 값이며, offset은 비압축 스트림에서 레코드 헤더 시작 위치다. GUI·COM·데스크톱 입력을 사용하지 않았다. 코드 번호는 문서에서 추출한 것만 기록했다.

이 매핑에 쓰는 28개 성취기준의 코드와 문구, 제한 문구 8개가 2015 PDF와 2020 수정 HWP 양쪽에서 일치했다(공백 정규화). 수정 HWP의 중학교 기준 61개 전체를 JSON에 기록했다. 59개는 PDF의 한 페이지 안에서 문단 전체가 공백 정규화 후 일치했다. 나머지 `[9수02-08]`은 따옴표 글리프 차이, `[9수05-03]`은 페이지를 넘어가는 행으로 별도 기록했다. 둘은 이 문항 매핑에 사용하지 않았다. 이것은 **수학 별책의 확인한 부분에 대한 대조**이며 2025까지의 모든 부분 개정 고시 전체를 감사했다는 뜻은 아니다.

7번의 삼각비 재구성, 11·14번의 보조 도형, 19번의 높이 풀이 등은 **확인한 성취기준과 원문 기하 관계에서 도출한 전문가 추론**이다. 공식 문서가 이 개별 문항을 승인했다는 의미가 아니다. 7번은 공식의 관계 배제 조항과 평가 의도의 충돌 가능성이 있어 특히 자동 통과시키지 않는다. 14번은 반각 공식을 피하는 경로가 있어도 도형/계산의 복잡도와 원래 난이도를 별도 심사한다.

## 6. 전체 후보에 연결할 필수 판정

아래는 부모 작업에서 연결해야 하는 검토 요건이며 이 보고서가 운영 검수 기능을 구현했다는 뜻은 아니다.

1. 참고 연도와 **재발행 목표 연도·학년·교육과정·학기**를 각각 기록한다. 정확한 Unit의 학년/학기와 실제 live family를 현재 스냅샷에서 확인한다.
2. 필수 절차/선수 개념을 성취기준·제한 조항에 대조하고, 현재 생성기 규칙의 파일·함수·내용 해시와 연결한다. 제목이나 소단원명만 같은 것은 충분하지 않다.
3. **발문·모든 보기·그림/그래프 의미·표기·정답 형식·학생 해설·필수 풀이·선수 개념** 각각을 심사한다. 오답 보기에도 학년 밖의 표기/개념을 소개하지 않는다.
4. 금지 방법을 필수로 요구하는 후보는 승인·적재·출제 대상에서 제외한다. 범위가 불명확하거나 리뷰어가 합의하지 못하면 `pending`이다. 대상 학년의 정당한 풀이가 없으면 제외한다.
5. 독립 수학 검산과 교육과정 심사를 별도 판정으로 남긴다. 검산자가 상위 도구를 사용한 결과가 맞아도, 학생 풀이의 방법 적합성을 따로 확인해야 한다.
6. 새 조건/보기/그림/해설이 바뀌면 새 문항 ID·해시로 다시 검토한다. 옛 검증 21개나 원문의 성취기준 매핑을 새 후보 통과 기록으로 이월하지 않는다.

## 7. 미해결 항목과 보존 경계

- **현행 Unit·live family·생성기:** 부모 작업의 최신 스냅샷과 소스 규칙 심사 필요. 기존 16개 분류 제안·5개 보류를 현재 승인으로 복원하지 않는다.
- **정확한 학년/학기:** 공식 문서는 중1~3 학년군이다. 현행 단원과 수업 순서 증거를 함께 확인하기 전에는 `[9수...]`만으로 허용하지 않는다.
- **개별 새 문항:** 새 본문/도형/보기/답/해설을 만들거나 전수 심사하지 않았다. 모든 새 후보의 승인 값은 pending이다.
- **부분 개정의 전체 이력:** 2015-74와 수정 수학 2020-236의 해당 코드·제한은 대조했다. [2022-2호 고시 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=90411&lev=0&m=0404&s=moe), [국가교육위원회 2024-1호](https://www.ne.go.kr/user/bbs/BD_selectBbs.do?q_bbsDocNo=20240927163706792&q_bbsSn=1016) 등 이후 고시를 포함하는 전체 이력은 최종 발행 전에 별도 확인해야 한다. 검색된 원문 존재를 모든 조항 검토 완료로 세지 않았다.
- **참고 연도/학교:** 원문 PDF의 머리말은 2025, 바닥글은 `26년 2학기 중간고사 대비`다. PDF의 학교는 익명 표기 `BI중`, 추출 메타데이터는 범일중이다. 부모가 원본 경로·대조 원장으로 연도·학교 진위를 재확인해야 한다. 2025와 2026 중3은 모두 2015 적용이므로 현재 개정 구분은 같지만 출처 메타데이터 충돌은 미해결이다.
- **도형 누락:** `drafts.json` 21개 모두 `hasFigure=false`지만 2·4·5·6·9·10·11·12·13·14·15·16·17·19·20·21번은 도형을 사용하고 10번은 표도 필요하다. 원문 문항 페이지 1~4를 시각 확인했지만 새 도형 제작/검수 완료는 아니다. 특히 15번의 작은 측정 라벨은 재제작 시 해상도 높은 근거와 대조한다.
- **7번/14번:** 7번은 삼각비 관계의 평가 의도, 14번은 접기·대수 계산의 복잡도에 대한 교과 검토가 필요하다. 전문가 풀이 경로 제안 자체로 이 보류를 없애지 않는다.
- **답 오라클 배제:** `drafts.json`에는 기존 answer/solution 필드가 있고 PDF 5쪽은 답 부록이다. 초기 PDF 구조 확인 중 5쪽 텍스트 일부가 노출되어 답 부록임을 확인했으나, 해당 페이지·텍스트는 매핑 근거에서 제외했다. 제안 판단에는 `content`, 출처 메타데이터와 1~4쪽의 문항/도형을 사용하며, 기존 답을 수학적 타당성이나 학년 허용 오라클로 사용하지 않았다.

원본·옛 산출물·부모/다른 세션 파일은 수정하지 않았다. 유료 API, 설치, Prisma 생성, DB 쓰기/apply, 잠금 해제, 배포, 푸시를 수행하지 않았다. JSON의 문항 번호 1~21 유일성, 코드의 공식 문서 실재, 관련 기준·제한 문구 대조, 입력 파일 해시 불변과 커밋 경로 범위를 점검했다. **SETUP 근거가 확보됐으며, 최종 요구로 검증된 쌍둥이는 여전히 0개다.**
