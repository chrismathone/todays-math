# 1차 보강 실행 중 발견한 출력·적재 관문 보완

승인된 계획 R2의 SHA와 첫 파동의 75발문·27문형·최대 138행 범위를 유지한다.
최초 wave1 및 wave1-r2 원장으로 쓴 DB 행은 0개다. 이전 원장은 보관하고 최종
wave1-r3 목록·UUID 원장에 대해서만 Claude의 별도 최종 승인을 받는다.

실제 글꼴의 제품 TestPrint 검수에서 초4 사다리꼴 17행 묶음의 8번 해설이
세 번째 단으로 밀려 A4 밖에서 사라졌다. 서술형 12행 묶음도 같은 문제가 있었다.
이를 해결하기 위해 계획의 출력 UI 제외 범위에 다음 한 가지 예외를 추가해
최종 내용·배치 승인과 함께 검토한다. 두 단·CSS·토큰·문제지 형태와 정답지
장당 최대 8항목은 유지하고, 글꼴이 준비된 실제 DOM에서 넘친 해설만 다음
장으로 분리한다. 계산 중 인쇄 버튼은 비활성화된다. 교사용 해설·채점 기준을
줄여 감추지 않으며, 실제 글꼴·전체 후보를 다시 검사한다. 실물 인쇄는 대기다.

Claude의 독립 풀이 75개와 작성자 답은 모두 일치했다. 사각형 가/나 표현과
작은 화단 상황을 고쳤고, Q03의 해설은 가능한 나머지 다섯 값을 이차방정식으로
각각 확인하도록 보완했다. 재검토에서 지적된 1x 표기·조사와 루브릭의 일반 조건
허용·변형별 조건 대응도 수정한다. 최초 blind 답안은 고치지 않는다.

Claude가 확인한 기존 일괄 계획의 승인 우회도 차단한다. 새 초4/중3 문형이
전역 등록되면서 과거의 넓은 선택 계획에도 들어가기 때문에, legacy apply는
실제 생성 결과가 이 21문형이나 native 영역을 포함하면 DB 조회 전 중단한다.
드라이런과 이전 문형만 선택하는 동작은 유지하고 실제 과거 두 계획으로 검사한다.
최종 적재는 기존 ID·내용 대조, 커밋된 UUID 원장, 정확한 배치 SHA와 Claude 승인,
한 트랜잭션·되읽기·참조 보호를 갖춘 verified 경로로만 실행한다.
