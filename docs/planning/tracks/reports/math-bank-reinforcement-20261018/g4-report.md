**검증 결과.** 순수 메모리 Vitest 새 26검사와 기존 초4 문형·초5 그림 문형·유한 공간·난이도 128검사가 통과했다(총 154). 새 문형마다 결정적 100씨앗, 정수 경계 5씨앗, RNG 값 0·0.5·1−EPSILON을 검사해 독립 검산은 972회다. 생성기의 facts/정답/해설을 oracle로 되부르지 않고 발문의 수치와 조건을 다시 읽어 좌표/변 집합/쌍 열거/각 완전탐색/카드 재고 완성 열거로 답을 구성했다. 해설에 표시된 정수 계산식도 별도로 계산했다. 정답을 변조한 9개 대조군은 모두 검출되었다.

변경 전 230차시·기존 2,476문형을 3씨앗으로 생성한 7,428개 출력 SHA-256 `7a90f427dda912d3cb4ac8037ae45dd6ed9c3aa7387e011a55ea9a52920b3554`가 변경 후에도 일치했다. 기존 생성기·RNG·그림 등록부의 바이트 해시도 일치했고 기존 부족한 유한 공간 목록은 그대로였다. 새로운 전체 등록은 2,485문형이다. 공유 DB의 초5 그림 42행 원장 `559774350`을 건드리지 않았다.

최종 27원형의 본문·정답·해설과 원시 파생 54행에 실제 MarkdownRenderer/renderMathHtml을 적용했고 raw/red/merror는 0이었다. 실제 parseProblemContent로 조건 보존·선택지 5개·수치 동치 중복 없음·유일 정답을 검사했다. 27원형은 PaperProblemView와 인쇄 ProblemBody에도 넣었으며 입력에 정답/해설과 고유 교사용 표식을 전달해도 학생 본문에 표식이 나오지 않았다. 기존 JaseupTemplate/A4Page 양식으로 14쪽을 만들고 네트워크를 차단한 로컬 Chromium에서 27본문과 표시 텍스트의 A4 경계 넘침 0을 확인했다. [14쪽 연락 시트](g4-a4-contact.png)를 육안 확인했고 긴 문항이 있는 4·13쪽도 원 크기로 확인했다. 실물 인쇄는 하지 않았으므로 **물리 인쇄 상태는 대기**다. 양식이나 UI는 수정하지 않았다.

정적 검사는 소유 파일/의존만 포함한 scoped TypeScript 검사와 focused ESLint가 통과했다. 테스트는 프로젝트의 loadEnv/setup 설정을 사용하지 않고 `envDir:false`, `setupFiles:[]`, node 환경인 별도 설정으로 실행했다. 명령은 `env -i`를 사용하며 `.env`를 읽거나 복사하지 않는다. fetch는 테스트에서 금지했고 새 서버·유료 API·공유 DB·push·배포·main 병합은 실행하지 않았다. 의존성은 허용된 Desktop node_modules 심볼릭 링크만 사용했다.

**정확한 선택 계약.** 공통 `seedBase=20261043`, `seed=seedBase+variant*1009`이며 원형 최종 variant는 0·1·2, exact seed는 `20261043 / 20262052 / 20263061`이다. 사다리꼴 여분은 variant 3·seed `20264070`이며 적재하지 않는다. [g4-candidates.json](g4-candidates.json)의 allowlist는 단원별 `grade/chapter/sections/formIds/perTier:3`을 제공한다. forms는 2-2-3 `[31,32]`, 2-2-5 `[33,34]`, 2-4-2 `[35,36]`, 2-4-4 `[37,38,39]`뿐이다. 이 metadata는 loader의 쓰기 관문을 대신하지 않으며 root가 실제 frozen 선택자와 내용 digest 관문을 구현해야 한다.

[g4-recommended-selection.json](g4-recommended-selection.json)은 externalId 정렬 순서의 권고 50행과 `unitId/familyKey/questionType/difficulty/payloadSha256`을 담았다. payload digest는 계획 §6.1의 UTF-8 JSON.stringify([content,answer,solution,figureSvg??null]) 규칙이다. 이 권고 파일의 바이트 SHA-256은 `10b1686594d73b67ac52178a6a59f52444ba02d82a76d0ccac37017b90a3418f`이다. 이 파일은 **전역 root 배치/최종 승인 목록이 아니다.** [g4-hold-candidates.json](g4-hold-candidates.json)은 원시 54행 중 보류 4행의 exact externalId·formId·familyKey·payload/content digest·수학적 이유와 root/C의 48행 대안 정책을 기록했다. f33의 예각 두 값 객관식은 모든 오답의 첫 값이 발문 후보 밖이어서 개념 적용을 우회한다. f39의 세 객관식은 최대값이 모든 보기에 고정되어 미확인 조건으로 상한을 추론하는 행동을 평가하지 못하며, 한 씨앗은 최소값>최대값인 보기까지 포함한다. 기존 derive나 RNG는 바꾸지 않았다.
