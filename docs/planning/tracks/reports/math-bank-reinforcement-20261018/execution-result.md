## 함께 막은 문제와 남은 범위

과거 일괄 계획으로 새 문형을 승인 없이 적재하는 우회를 차단했다. 같은 외부 키라도
내용이 다르면 쓰기 전에 중단한다. 서술형은 독립 이름 공간과 부분점수 기준을 사용한다.
긴 빠른 정답 상자로 해설이 사라지던 문제는 실제 넘침을 다음 장으로 분리해 해결했다.
[실행 범위 예외](execution-addendum.md)에 근거를 남겼다.

실물 인쇄는 미실시이며 `/dev/print-check` 세 항목은 **대기**다. 본문·해설 Noto Serif KR은
적재됐고 sans 머리글은 폴백을 사용했다. 이 검수는 인증 계정의 브라우저→API 전체 경로나
실제 프린터를 대신하지 않는다. 출력 코드의 로컬 main 통합과 운영 배포도 구분한다.

이번 작업은 승인된 첫 파동이다. 고등 8문항 미달 54차시, 중3 단일 차시 20문항 다양성,
다른 학년 서술형·교과서 지정 복습 쌍 보강은 남아 있다. 공식 성취기준 전수 대응이나
측정된 학습 효과를 주장하지 않는다.
