- A: 초4 4차시에 새 문형 9개 · 발문 27개 이상, 54행 이하.
- B: 중3 4차시에 새 유형 12개 · 발문 36개 이상, 72행 이하.

## 실행할 때 지켜야 할 관문 (이 계획에 이미 있는 것을 다시 적음)

1. §6.1 의 여섯 관문을 구현하고 테스트로 고정하기 전에는 DB 에 쓰지 않는다.
2. 적재 직전에 대상 8차시의 DB 기준선을 다시 읽는다(초5 42행 원장 `559774350` 은 보존한다).
3. Claude 가 실제 후보 전부의 내용 · 채점 기준 · 렌더와 배치 목록을 검토하고, 최종 승인 JSON 에 배치 SHA 를 적는다. 그 SHA 와 다르면 `--apply` 는 거부한다.
4. 적재는 root 한 곳에서 `ALLOW_SHARED_IMPORT=1` 과 `--apply` 를 함께 줄 때만 한다. 미통과 문항은 격리하고, 수를 채우려 관문을 낮추지 않는다.
5. 실물 프린터 검수가 없으면 `/dev/print-check` 는 «대기»로 둔다.
6. 승인 뒤 범위나 관문을 늦춰야 하면 새 판본을 다시 검토받는다(§5 L106-107).
