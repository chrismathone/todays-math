# 제곱근표 입력 역추론 — 유한 생성과 검수 전용 관문

제곱근표에서 계산 결과를 구하는 방향을 뒤집어, 양수의 제곱 관계와 계산된 근삿값을 조건으로 표의 입력을 찾는 `study-middle-inverse-root-table`을 구현했다. 기존 노변 문항의 질문 방향에서 확인한 공백을 다루며, 새 추상 요구 `number.inverse-root-table`은 기존 요구 순서 뒤에 추가했다. 순수 수학 문제에 불필요한 생활 소재를 붙이지 않았다.

유한 범위는 서로 다른 표 3개 × 양수 b 3개 × 선택 열 5개인 **45조합**이다. 표의 다섯 소수 입력과 소수 셋째 자리 근삿값을 새로 계산하고, `a²=x/100`과 b의 제곱, `100a+b`를 표의 근삿값으로 계산한 결과를 제시한다. 학생은 양의 제곱근·소수 연산·배율 관계로 표의 열을 되찾는다. 각 열의 결과가 달라 답은 유일하다. seed와 형식을 조합 수에 곱하지 않으며 단답형만 지원한다.

정수 제곱 경계를 이용해 표의 반올림을 재계산한다. 정확한 `a=√x/10`과 표를 이용한 근삿값 `s/10`을 본문·해설에서 구별한다. 본문·표·양수 조건·배율·관측 결과·해설·정답·매개변수·형식·난도 제안이 현재 템플릿과 일치하는지 검사한다. 내부 계산의 BigInt 알고리즘을 학생 풀이로 요구하지 않으며 프로젝트의 ES2017 컴파일 기준도 유지했다.

실제 캡처된 Unit UUID `28032bdd-3db3-4788-9e7a-2f1909233fdb`와 캡처 해시, 개념·풀이·변형 근거를 연결했다. `liveFamilyKey=null`, 출처 동일성·권리·유사성·native provenance·등록은 보류다. 제안한 2025 출처/2026 연습은 2015 중3이며, 2027 중3의 2022 교육과정 배치는 별도 근거가 필요하다.

공개 생성 전에 고정 release hold를 적용한다. 요구가 일치하면 ID·버전·native/component 라벨·신뢰도·승인 플래그를 바꿔도 차단한다. 목록에 노출하지 않고 coverage는 unavailable이며 재현 manifest에 정책 버전 r2를 반영했다. 기존 중1 학년 강제 제외가 이보다 먼저 실행된다. 내부 factory 등록을 출제·권리·live family 승인으로 해석하지 않는다.
