# 검산한 문항과 도형 렌더의 데이터 소유권 보완

[최신 역할 분담](../brief-exam-engine-ownership-20261020.md)에 따라 생성 엔진만 수정했다. 이미 출제된 문항·DB·다른 컴퓨터의 지면/서술형 첫 묶음은 수정하지 않는다. 실제 작성178/정본선택174/전체수학·학년173/최종·적재0은 이전 집계 그대로다. 새 수작업 문항·blind 승인·그림·imagegen 수는 늘리지 않는다.

독립 사전 점검 af3c3ce83은 신뢰된 factory/prepare의 실수로 생길 수 있는 세 결함을 합성 사례로 재현했다. 검산 뒤 렌더 콜백이 본문·답·해설·도형/매개변수를 바꿀 수 있었고, factory의 객체·중첩 참조 재사용이 앞선 후보를 바꾸며, 보관한 렌더 참조로 반환 결과의 중첩 값도 바꿀 수 있었다. 실제 은행 문항이나 DB 손상을 확인한 결과는 아니다.

이제 factory 반환값을 즉시 별도 사본으로 만들고 깊이 동결한 뒤 검산한다. canonical 매개변수와 실제 객관식 파생 draft도 분리·보호한다. 렌더 콜백에는 또 다른 읽기 전용 사본을 넘기고, 결과의 중첩 데이터는 호출자가 소유하는 사본으로 반환한다. factory 원본을 동결하지 않아 객체 재사용 자체는 계속 가능하다. 일반 JS의 비엄격 모드에서는 쓰기가 예외 대신 무시될 수 있으나 검산값은 바뀌지 않는다. 임의 악성 함수/proxy/accessor에 대한 보안 sandbox를 주장하지 않는다.

최초 복사 구현은 식별자용 정렬 직렬화를 재사용해 필드 순서를 바꿨고 확장 검사421개 중8개가 실패했다. 기존 일부 검증기가 매개변수·채점표 JSON의 순서를 비교하기 때문이다. 기존 검증기를 느슨하게 하지 않고, 순서를 보존하는 유한/plain 값 그래프 복사로 수정했다. 순환·비유한 수·지원 밖 prototype·undefined/빈 배열 칸은 보류하며, 객체의 선택적 undefined 필드는 생략하고 공유된 비순환 참조는 각각 분리한다. 최초 실패와 제한된 R1 독립 통과85검사, 순서 결함의4사례/10검사 추가 기록을 모두 보존한다.
