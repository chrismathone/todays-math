# 1차 — Claude(리드)의 답 · codex · grok 의 답을 보기 전에 적었다 (2026-10-01)

1. **묶음 구조 — A 바탕 + 누출 세트에서만 C 로 가르는 단추.**
   근거: 원 지문으로 새는 답은 묶음 둘이면 끝난다. B 는 안내 쪽이 매번 한 장 더 나오고, 갈라 주지 않으면 지금과 같아 «부탁»으로 돌아간다(앞선 협의에서 기각된 모양). D 는 종이와 배부 횟수가 가장 많아 여섯 문항 세트에 과하다.
   위험: A 만으로는 변형끼리의 짝이 60% 세트에 남는다 — 그래서 2번이 중요하다.
2. **누출의 기본값 — 알리기만.**
   근거: 검사는 글자 그대로만 본다(정밀 · 재현을 사람 눈으로 아직 안 댔다). 기본으로 가르면 세트의 60% 가 세 번 배부가 되어 수업이 끊기고, 선생님이 되돌리기를 습관처럼 누르면 알림 자체가 무시된다. 알림 줄은 근거 구절을 보여 주고 한 번에 가를 수 있게 한다.
   위험: 알림을 안 읽으면 짝이 그대로 나간다. 교사용 지면 머리에도 같은 줄을 찍어 종이에서 한 번 더 보이게 한다.
3. **묶음 이름 — 화면은 «변형용 · 독해용», 종이의 딱지는 «1차 · 2차».**
   근거: «변형용»은 교사의 말이라 학생 종이에 찍을 까닭이 없고, «A · B»는 순서를 말해 주지 않는다. «1차 · 2차»는 배부 순서가 곧 이름이다. C 로 가르면 «1차 · 2차 · 3차»로 자연히 는다.
   위험: 화면과 종이의 이름이 달라 혼동 — 화면에 «변형용(1차)»처럼 같이 적는다.
4. **배부 순서 안내 — 인쇄 화면 + 교사용 지면 머리.** 안내 쪽 한 장은 넣지 않는다(종이 · 학생에게 섞여 나갈 위험).
5. **문항 번호 — 세트 번호 그대로.** 교사용 정답 · 해설의 번호와 맞아야 채점이 된다. 묶음 안에서 다시 매기면 교사용과 어긋난다.
   위험: 변형용이 «3번»부터 시작해 학생이 1 · 2번이 빠졌다고 묻는다 — 딱지 옆에 «3~5번»을 적는다.
6. **답 표기란 · 세트 코드 — 나중에.** 사진 채점은 범위 결정 전이고 판독 정확도를 안 쟀다. 지면을 바꾸면 실물 검수가 다시 필요한데, 쓸지 모르는 칸으로 검수를 두 번 하게 된다. 실제 사진 2~3장으로 먼저 잰다.
7. **어법의 밑줄 — 그린다.** 꺾쇠가 종이에 찍히는 것은 결함이다. `<u>` 와 `</u>` 만 밑줄로 바꾸고 다른 꺾쇠는 글자로 둔다(글을 HTML 로 넣지 않는다). 밑줄이 줄바꿈에서 끊겨도 번호 ①~⑤ 가 밑줄 앞에 붙어 있게 한다. 화면 편집기 · 교사용 · 품질 검사가 같은 표기를 같은 뜻으로 읽는지 확인한다.

**다음 단계에서 달리해 보일 것**: ① 머리 딱지의 모양과 자리(«1차 · 3~5번») ② 알림 줄 — 도구 줄 아래 한 줄 / 지면 옆 주석 / 누출 문항 옆 표시 ③ 교사용 머리의 배부 · 누출 줄.
**가장 약한 고리**: 2번. «알리기만»은 읽지 않으면 아무 일도 안 한다.
