# 조사 브리프 — «오늘의 영어» 외부지문 내신 문제생성기 품질 초고도화

너는 조사·설계 자문이다. **코드 수정 금지(읽기만).** 웹 검색을 적극적으로 써라. 한국어로 답하라.

## 제품 현황 (저장소: 현재 폴더)
- 한국 수학·영어 학원 원장이 쓰는 서비스. 영어 쪽은 «외부지문 내신 대비» — 학교 시험 범위의 지문(교과서·모의고사·외부지문)으로
  한국 중·고 내신형 문항(주제 · 내용 일치 · 어법 · 빈칸 추론 · 문장 삽입 · 서술형 · 원문 복원)을 만든다.
- 만들기 세 길: ① ChatGPT 요청문 복사→결과 JSON 붙여넣기 ② 규칙 기반 원문 복원(빈칸) ③ DeepSeek(deepseek-v4-pro, 추론형) 직접 생성.
- 읽을 파일: `src/lib/ai/prompts/englishExam.ts`(프롬프트 v1) · `src/lib/english/validate.ts`(검증기) · `src/lib/english/generate.ts`
  · `src/lib/english/chatgpt.ts` · `src/lib/english/cloze.ts` · `src/contracts/english.contract.ts` · `docs/planning/25-english-studio.md`.
- 지금 검증기는 **모양**만 본다: 보기 5개·중복 없음·정답 1~5·근거가 지문의 연속 인용·요청 문항수/유형. **정답이 유일한가, 오답이 그럴듯한가,
  어법 문항의 오류가 진짜 하나인가, 문장 삽입 자리가 유일한가, 난이도가 맞나** 는 아무것도 안 본다. 호출은 한 번(생성만), 자기검증 단계 없음.

## 물음 (각각 근거 URL 을 달아라)
1. **한국 내신·수능 영어 문항 유형별 출제 원리와 «좋은 문항» 기준** — 평가원 수능 영어 출제 매뉴얼/학업성취도, 내신 변형문제 업계(쎈·
   마더텅·이투스 외부지문, «변형문제» 업체들) 관행. 유형별(주제/제목/요지, 내용 일치, 어법, 어휘, 빈칸, 순서, 삽입, 요약, 서술형) 매력적 오답 설계 원리.
2. **LLM 으로 독해 객관식 문항 생성 품질을 높이는 최신 연구/실무(2023~2026)** — distractor generation, answerability/유일정답 검증
   (solver 로 풀어 보기), self-critique/검증 에이전트, LLM-as-judge 루브릭(IWF 문항작성 결함 목록 등), 난이도 제어(CEFR, 어휘 수준·Lexile),
   교육 측정(IRT) 관점, 오답 매력도. 논문 이름·연도·핵심 수치.
3. **유형별 결정적(비AI) 검증** 가능한 것 — 예: 어법 밑줄 5개가 지문에 실제로 있고 정답 밑줄만 원문과 다르다, 문장 삽입의 주어진 문장이
   지문에서 빠져 있고 자리 번호가 5개다, 빈칸 정답이 원문 구절과 일치한다, 원문 유지 모드 대조, 가독성 지수, 어휘 등급(교육부 기본어휘) 등.
4. **파이프라인 설계 제안** — 생성→(결정적 검사)→독립 풀이자(다른 모델)로 풀기→판정자 루브릭→수정 1회 같은 구조의 비용/지연
   (DeepSeek v4-pro 한 번 40초~2분 · ChatGPT 경로는 사람이 복붙)을 고려한 우선순위. ChatGPT 붙여넣기 경로에도 적용할 수 있는 방법.
5. 이 저장소 코드에 대해 **구체적 변경안**(파일·함수 단위) 상위 10개를 우선순위·기대효과·위험과 함께.

결과는 마크다운 하나로. 확실하지 않은 것은 «확인 못 함»이라 적어라. 지어낸 논문·수치 금지.
