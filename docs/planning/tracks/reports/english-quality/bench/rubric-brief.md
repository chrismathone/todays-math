# 채점 설계 검토 요청 — 영어 내신 문항 생성 모델 벤치마크 (한국어로, 짧게, 파일 수정 금지)

한국 중·고 영어 내신 «외부지문 문제 생성기»의 생성 모델을 비교한다. 생성 후보 19개(codex 7 · claude 4 · grok 4 · gemini 4),
과제 3개(원문 유지 고2 심화 / 새 지문 중3 표준 180단어 / 원문 변형 고1 표준) × 6유형(주제 · 내용 일치 · 어법 · 빈칸 추론 · 문장 삽입 · 서술형) 각 1문항.
생성 프롬프트는 제품 프롬프트 v1 그대로(JSON 객체 하나: title, passage, questions[type,prompt,options(5),answer "1"~"5",explanation,evidence]).
채점관은 grok · codex · claude 세 AI(각 최상위 모델, 생성 모델 이름은 가림).

## 초안 점수표 (문항 0~100)
- D1 형식·구조 15% (결정적): 제품 검증기 통과 + 유형 구조(어법 ①~⑤ 표지 · 오답 밑줄이 원 지문에 있음 / 삽입 ①~⑤ 표지 · 보기=자리 / 빈칸 표지 하나 /
  서술형 채점 요소 ≥2 / 내용 일치 한국어 보기·발문에 일치/불일치 / 주제 영어 보기) + IWF 표면(최장 보기 단서 · all/none of the above · 오답에만 절대어) — 통과 비율.
- D2 정답 타당성 30% (눈가림 풀이): 채점관 3이 정답·해설을 못 보고 지문+발문+보기로 풂 → 키와 일치한 비율. 각자 «다른 보기도 동등하게 정답 가능» 표시 시 0.5.
- D3 지문 의존도 10%: 같은 셋이 지문 없이 풂 → 추측 정답률 g. D3 = 1 − max(0, g − 0.2)/0.8.
- D4 루브릭 45% (채점관 3, 정답·해설 보고, 1~5): 정답 유일·정확 / 오답 매력도(서술형은 채점 기준 명확성) / 유형 충실도(한국 내신 관행) / 발문·해설 품질 / 난이도·학년 적합.
- 서술형은 D2·D3 없음 → D1 20% + D4 80%.
- 지문 점수(세트당): 채점관 1~5 — 영어 품질 · 학년 수준 · 내신 지문다움 + 결정적(요청 단어 수 ±25%, 원문 유지 일치, 변형은 원문 8-gram 중복 < 30%).
- 세트 = 문항 평균 80% + 지문 20%. JSON 못 읽으면 세트 0. 제품 검증기 거절은 «채택률» 열로 따로.
- 모델 점수 = 세트 셋 평균. 표: 모델별 총점 · 유형별 · 축별 · 채점관별 · 지연 · 자기 채점 제외 점수(자기 계열 채점관 빼고 평균).

2. 가중치 제안(근거 한 줄씩).
3. 채점관 셋의 불일치를 어떻게 처리할지(중앙값? 평균? 신뢰도 보고 방법 — Krippendorff α 등).
4. 과제 3 × 6유형(모델당 18문항)이 순위를 가르기에 충분한가 — 표본 한계와 신뢰구간 보고법.
5. 빠진 객관적 축이 있으면 추가(예: 해설의 근거 인용 정확도, 보기 길이 균형, 정답 번호 분포).
