# 개념 백지 은행 내용 검수

«개념 백지»는 학원에서 쓰는 A4 개념 학습지다. 학생은 용어의 뜻을 쓰거나, 뜻 문장의 빈칸(핵심어)을 채우거나, ○×를 고르고 까닭을 쓰거나, 짧은 적용 문제를 푼다.
문항은 고정 은행이고 사람이 손으로 썼다. 2022 개정 수학 교육과정(초3~중3)에 맞춰야 한다. 수식은 KaTeX(`$...$`)로 그려지므로 `$`, `\frac` 같은 마크업은 결함이 아니다.

항목 꼴(한 줄에 하나):
- `C id [난이도·종류] 용어: … | 뜻: …(핵심어는 { } — 학생지에서 빈칸이 된다) | 예: 물음 → 답`
- `O id [난이도] 문장: … | 답: ○/× | 까닭: …`
- `A id [난이도] 물음: … | 답: …`
- `F id [난이도] 그림 물음: … | 그림 속 빈 이름표 답: … | 줄: 줄 이름 → 채점 기준` (그림은 글로 안 보이니 그림과의 일치는 판단하지 마라)
- `## 학년 › 대단원 › 소단원` 이 그 아래 항목의 자리다.

## 찾을 것 — 실제 결함만
1. **수학 오류**: 틀린 정의 · 틀린 성질 · 틀린 답 · ○× 답이 거꾸로 · 까닭이 답을 뒷받침하지 않음 · 계산 실수.
2. **답이 하나로 안 정해짐**: 빈칸 핵심어를 문장만으로 정할 수 없거나 다른 말도 맞는 경우(채점이 흔들린다) · 적용 물음의 답이 여럿.
3. **교육과정 어긋남**: 그 학년 · 그 소단원에서 아직 안 배우는 용어 · 기호 · 방법을 쓴다 · 다른 소단원 내용이 섞였다 · 2022 개정에서 빠진 용어.
4. **학생이 오해할 문장**: 뜻이 모호하거나 틀리게 읽히는 문장 · 초등에 너무 어려운 말.
5. **표기**: 수식 마크업이 깨져 그대로 찍힐 자리(짝 안 맞는 `$`, 잘못된 명령) · 같은 소단원 안에서 같은 것을 다르게 부름.

문체 취향 · «더 좋게 쓸 수 있다» 수준은 적지 마라. 확신이 없으면 «확인 필요»로 낮춰라.

## 답의 꼴
결함마다 표 한 줄: `| id | 심각도(높음/중간/낮음) | 종류(1~5) | 무엇이 문제인가 | 고칠 안 |`. 높음 = 수학이 틀렸거나 답이 틀림. 결함이 없으면 «없음» 한 줄.
