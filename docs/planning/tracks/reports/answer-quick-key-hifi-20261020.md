## 측정 요점

30개 판 모두 번호 누락·순서 변경 0, 셀 가로 넘침 0, 페이지 세로 넘침 0, 외부 HTTP 요청·브라우저 오류 0. 해설 포함판은 해당 문항 수만큼 해설이 있고, 정답만 판에는 해설이 없다. 첫 쪽·이어지는 마지막 쪽의 머리, 번호, 분수, 병합, 해설 시작을 캡처로 검토했다.

## 실제로 고친 것

- 두 줄 답에서 한글 단어가 중간에 갈리지 않도록 단어 단위 줄 바꿈을 적용했다.
- H2의 긴 답은 최소 두 칸을 확보했다. 처음에는 두 줄 허용만으로 긴 답이 한 칸에 머물렀다.
- 25번을 열 소문항 곱셈 답으로 늘려 2·3·5칸의 차이를 확인했다. 이 답은 Vite에서 제품 `fractionViewFor → MathText`로 새로 조판한 뒤 Hi-fi에 포함했다. 기존 Wire는 변경하지 않았다.
- 캡처할 때 비교 창의 스크롤·클리핑을 해제하고 A4 크기를 유지했다. 파일의 비교·쪽 이동 화면은 그대로 보존했다.

## 데이터·범위·재현

- 나머지 24개 답은 Wire B에서 제품 렌더러로 조판한 DOM을 그대로 사용한다. HTML의 `captured`에 원본 경로·커밋·SHA-256과 25번의 교체 원문을 보존했다.
- 50·100문항은 같은 25개 답을 반복한 스트레스 표본이다. 분수·식·두 값·단위·긴 문장과 열 소문항 답을 포함한다. 학생·문제은행·DB·외부 API를 사용하지 않았다.
- 해설 문장은 자체 제작했다. 해설의 정답 수식은 표와 같은 MathText DOM이다. 새로 SolutionText를 실행한 결과라고 주장하지 않는다.
- 답의 글자 수 대신 실제 조판 폭과 높이를 비교한다. 번호순을 유지하고 행 단위로 쪽을 넘긴다. 해설 제목은 첫 해설과 묶고 나머지는 문항 단위로 넘긴다.
- A4 793.7008 × 1122.5197px, 좌우 15mm·상하 12mm, 정답 12px·1.8. 기본은 55% 보기, 100% 보기와 쪽 이동·판별 인쇄 버튼을 제공한다.
- 재검증: `node scripts/qa/print-templates/review-quick-key-hifi.mjs --resume-after-lead-release`. 한 브라우저·한 컨텍스트씩 15번 열어 30개 판을 확인하며, 기동 전·다음 사례 전 메모리 3GiB를 확인한다.
- `src/**` 변경·설치·DB·푸시 없음. 정답만 판의 제품 적용은 원장님 선택 전이며, 실제 제품 `measure` 연결과 실물 인쇄 검수는 선택 뒤 차례다.
