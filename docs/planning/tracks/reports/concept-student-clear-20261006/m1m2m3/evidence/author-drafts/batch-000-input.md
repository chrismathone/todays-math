계획만 작성한다. source의 term은 실제 B에 보이는 제목이다. C의 실제 학생 문장은 studentC이며 답은 answers다. definition의 {내용}은 빈칸 정답이다(LaTex 명령의 중괄호와 구분). source의 section/정의/정답/예시는 학생에게 보이지 않는 근거다. B 질문 자체에 조건, 기호의 뜻, 답할 범위를 넣어야 한다. 표준 수학 용어는 집중된 정의 질문도 가능하지만 여러 개념인 경우 어떤 관계를 묻는지 특정한다. 일반적인 개념을 단순 산수 하나로 축소하지 않는다. 예시가 있어야 알 수 있다면 적절한 구체 예를 질문 안에 넣고 exampleNeeded를 true로 표시한다. 그림은 없으므로 필요한 도형의 점 순서, 길이, 각과 점의 위치를 질문에 밝힌다. 함숫값은 해당 함수와 x값이 반드시 제시되어야 한다. 기대 답을 질문에서 먼저 말하지 않는다.
B는 각 ID마다 bDecision(rewrite/keep/exclude), bPrompt(완전한 학생 질문), bAnswer(질문에 정확히 맞는 모범답), bGoal(학습 목표), bReason(이 원문에 왜 이 판단을 했는지 구체 이유)을 만든다. 제목만 있는 원문의 거의 모든 B는 rewrite가 정상이다. 반복·유용하지 않은 형식은 물리 삭제 대신 exclude로 기록하고 exclusionReason에 어떤 형식의 어떤 중복인지 명시한다. exclude에도 향후 사용할 수 있는 bPrompt/bAnswer 제안은 작성하되 왜 현재 형식에서는 제외하는지 적는다. 학생용 이름을 다듬을 때만 studentLabel을 넣는다.
C는 cDecision(keep/rewrite/exclude), cReason을 쓴다. 학생 문장이 분명하고 유용한 짧은 비교·계산/단어 빈칸이면 유지한다. 무조건 전부 바꾸지 않는다. 실제 지칭 대상이 없거나 숨은 제목 없이는 상황을 모르는 경우, 너무 긴 임의 키워드, 중학교 학생도 어려운 메타 언어, 문장범위가 모호한 경우만 고친다. rewrite면 cAfter(빈칸 답을 {내용}으로 표시한 완전한 정의 문장)와 cAnswers 배열을 반드시 준다. source의 수학적 사실과 범위를 보존하며 기호 조건을 빠뜨리지 않는다. 계산값만 암기하는 무의미한 빈칸으로 바꾸지 않는다. 한 문항에서 조건과 결론을 모두 숨기지 않는다. 답을 문장 다른 곳에서 그대로 베끼게 하지 않는다. 서로 다른 수학 답을 동의어라 하지 않는다. 정확한 동의어만 synonyms에 [{answer,accept:[...] }]로 기록하며 없음이면 생략한다. C에서 제외할 경우 exclusionReason에 C 제외임을 명시한다.
유용성 판단은 해당 학년 학생의 실제 독해 기준이다. 질문 밖의 교사 설명을 요구하지 않는다. 예: 나누는 수를 곱하여 원래 수로 돌아간다 같은 추상 복원 문장을 맥락 없이 승인하지 않는다. 단원의 나머지 질문에 이미 나왔다는 이유로 지칭 설명을 생략하지 않는다. 질문을 읽었을 때 답이 숫자/이름/관계/이유 중 무엇인지 알 수 있어야 한다.
