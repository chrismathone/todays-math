모든 행의 원문 B 제목/정의/C 학생 문장과 현재 질문을 실제로 읽는다. 각 개념의 일반 설명이 주로 하는 역할 learningRole을 definition/procedure/reason/application/naming 중 하나로 정한다. roleReason은 이 개념의 실제 내용을 짚는 짧은 구절이다(보통 6–18글자, 형식 pass 금지). 원본 kind로 기계 분류하지 말고 학습 내용과 학생이 답하는 질문을 함께 고려한다.
