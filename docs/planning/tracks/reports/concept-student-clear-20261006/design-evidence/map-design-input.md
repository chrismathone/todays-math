개념백지의 학생 관점 설계를 독립적으로 검토하라. 기존 모호한 B 제목만 제시하는 형식은 구체적인 bQuestion {prompt, answer, requiredIdeas:[{anyOf:string[]}]}로 바꿨고, C는 일반 학습 설명 definition과 별도의 clozeQuestion을 쓴다. 전 학년 실제 질문은 독립 블라인드와 원문/답/기준 검토가 진행 중이다. 구 동결 지면은 당시 내용을 보존한다.

추가로 D 개념 지도에도 같은 구조 원인이 남는다. 예: 가지에 '분모와 몫', '조각의 개수만 견주기'라는 제목과 '뜻' 빈 줄, '예' 칸만 있으면 무엇을 쓰라는 것인지 어렵다. 일반 개념 설명은 A 자유 회상·교재 학습 설명·SRS에 보존해야 하며, 임의의 숫자 사례 설명으로 모두 바꾸면 안 된다.

구조 선택을 판단해줘. 선택1: 새 D의 가지에는 같은 개념에서 이미 검토한 B 물음을 그대로 제시하고 '답/까닭' 칸을 둔다. 채점표도 그 B 질문의 답과 의미 기준을 쓰고 요구하지 않은 예 칸은 없앤다. B에서 실제 제공 그림이 없거나 중복 등으로 제외한 항목은 새 D에서도 제목으로 임의 출제하지 않는다. 개념 ID·일반 설명·학생 기록은 그대로다. 새 D는 긴 물음과 쓰기 공간이 필요하므로 한 페이지에 2개 가지(기존 가운데 허브·좌우 가지 틀)까지만 배치하면 계약 상한 B 물음/답 각240자의 글도 안전하게 들어간다. 기존 동결 D는 최대6가지·뜻/예 채점 그대로 유지한다. 페이지가 기존보다 늘어나는 비용이 있다.

선택2: D는 공식/익숙한 개념명과 일반 정의를 쓰는 형식으로 제한하고, 편집 조각 제목만 새 D에서 제외한다. 이 방법은 어떤 용어가 실제 익숙한 이름인지 전 ID의 별도 판단을 요구한다. 단순 문자열이나 kind 값으로 자동 판정하면 안 된다. 예: '받아올림'은 방법이지만 익숙한 개념이고 '분모와 몫'은 교육과정 개념명이라고 보기 어렵다.

1) 현재 사용자 요구('모든 내용을 갈아엎더라도 학생이 무엇을 쓸지 명확하고 학습에 도움이 되게')에 어떤 선택이 적합한지 권고. 2) 선택1이면 질문과 맵이 교육적으로 무의미한 장식이 되는 문제, 페이지 증가, legacy/정답 대응, 형식 제외에 관해 필수 보강. 3) 기존 B/C 내용 승인 재사용이 가능한지(질문 자체는 동일), 추가로 검토해야 할 항목. 짧게 답하고 실제 학생 학습 효과를 입증한 것처럼 말하지 말라. 구현은 아직 안 했다.
