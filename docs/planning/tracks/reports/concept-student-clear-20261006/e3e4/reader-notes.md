# 초3·초4 원문 검토 메모

기준: `13bf05dce`, 입력 `D:/tmp/concept-student-clear-20261006/e3e4.json`. 운영 변경 없이 제안만 기록한다. 격리 Claude CLI는 초안 작성 보조이며 최종 독립 검토를 대신하지 않는다.

원문의 `{답}` 표시는 B 정의와 C 실제 문장을 함께 읽기 위한 공통 표기다. 읽기 도구는 답 표시만 □로 바꾼 결과가 `studentC`와 정확히 같을 때만 정의 한 줄로 공유해서 보여 주고, 다르면 `ACTUAL C`를 따로 출력한다. 감사 원장에는 압축하지 않은 원문 두 문자열과 원문 답을 모두 보존한다.

개별 검토에서 먼저 확인한 사항:

- 입력 순서는 e3 기본 194개 → e4 기본 145개 → e3plus 984개 → e4plus 1456개다. ID를 학년별로 다시 정렬하지 않는다.
- 받아올림·받아내림·곱셈 올림에는 ‘윗자리’만 가리는 긴 이름보다 해당 자리의 묶음 수를 어떻게 바꾸는지 묻는 B가 유용하다. C의 일의 자리·십의 자리, 10·100, 큰·작은 관계는 대부분 짧고 분명하다.
- 원문 인덱스 47·594의 나눗셈 확인은 사용자에게 거절된 분수 문장의 자연수 버전이다. 제목/정답이 숨겨졌을 때 나누어지는 수를 복원하게 하지 말고, 실제 식과 확인 식을 함께 제시한다.
- 인덱스 40·576·585·596·608·611은 같은 나눗셈식의 두 뜻이나 곱셈과의 연결을 가리킨다. 전체, 한 사람 수, 사람 수/묶음 수를 구체 사탕/사람 상황으로 지정해야 한다. 특히 `□`·세모 등 별도 미지수 기호를 불필요하게 추가하지 않는다.
- 인덱스 500·507·512·515·527·532·534·555·560·1081·1107의 붙이기·접기·복합도형 세기는 그림 또는 구체 위치를 확인해야 한다. ‘두 개를 붙인다’만으로 결과 모양이 정해지지 않는 배치는 제안에서도 남기지 않는다.
- 인덱스 820의 ‘똑같이 나눈 조각은 모양과 크기가 같아 꼭 겹친다’는 같은 크기의 부분이 반드시 같은 모양이라는 잘못된 일반화다. 같은 모양으로 포개지는 것은 확인 가능한 충분한 경우이고 필수 조건은 아니다. B/C를 크기 기준으로 수정하고 동형 그림만으로 일반화하지 않는다.
- 인덱스 828은 정사각형의 중심을 지나는 직선이면 같은 크기로 둘로 나뉜다는 목표로 읽힌다. 가운데가 어느 점인지 지정한 그림이 필요하다.
- 인덱스 1040의 최대 몫을 다시 계산하면 `999÷9=111`이고 990~998의 몫은 110이므로 999가 유일한 답이다. 앞선 중간 보고에서 이 경계를 잘못 계산해 답 범위 문제로 지적한 것은 철회한다. 제안에서 불필요한 ‘나누어떨어짐’ 조건을 추가하지 않는다.
- 인덱스 1218·1270의 1 L·1 kg 경계는 단위 선택의 편의 기준이며 절대 규칙이 아니다. 특정 물건에 편한 단위를 고르는 질문으로 좁히거나 해당 형식에서 제외한다.
- 큰 수의 단위 읽기·기호 읽기는 C의 짧은 회상 목표가 될 수 있지만 B에서 일반 설명 범위를 억지로 만들지 않는다. 서로 다른 자리의 값이 달라지는 이유, 네 자리씩 끊는 이유, 같은 자릿수에서 높은 자리부터 비교하는 이유는 설명형 가치가 있다.
- 각도기 눈금·접기·선 이름 문제는 그림이 없는 학생에게 그림의 문자·방향·표시를 상상하게 하지 않도록 B 질문 안에 조건을 포함한다. C의 짧은 범위(90보다 크다/작다, 예각/둔각)는 유지한다.
- 초4 규칙 찾기에서는 수 배열·도형 배열·달력 규칙을 실제로 주지 않은 ‘앞뒤 수를 보고’ 문장이 반복된다. 설명 B에는 실제 짧은 배열과 답할 범위(다음 수와 변화, 시작 수와 순서 등)를 제시하고 C에는 뜻 없는 ‘규칙’, ‘말’, ‘문장’ 빈칸을 회상 성취로 세지 않는다.
- 도형 이동에서는 모양·크기·방향·위치를 구별한다. 오른쪽 뒤집기/왼쪽 뒤집기의 모양이 같아도 위치는 같지 않을 수 있고, ‘밀었다’와 ‘한 변만 옮겨 새 사각형을 만들었다’는 서로 다른 일이다. 인덱스 2530은 후자의 구성 문제로 읽어야 한다.
- 막대·꺾은선그래프의 단위·눈금·실제 수량 비교는 가치가 있다. ‘문장으로 쓴다’, ‘말로 나타낸다’, ‘읽기 쉽다’ 같은 출력 형식/권고 자체가 빈칸 답인 항목은 C에서 제외 또는 자료가 있는 해석 문제로 개정한다.
- 인덱스 2442의 수직인 두 직선을 지나는 다른 직선과 만든 작은 각 합 90°는 원문에 도형 관계가 있지만 학생이 글로만 두 각을 식별하기 어렵다. 직각 안쪽에 한 반직선을 그린 그림/구체 수를 필요 사례로 남긴다.
- 인덱스 2493은 수선의 발이 양쪽으로 놓이는 경우 두 수선 길이가 같아도 평행이라고 단정하지 않는 한 방향의 판정이다. 원문의 ‘길이가 다르면 평행이 아니다’는 보존하고 역을 제안 질문의 답으로 만들어서는 안 된다.
- 인덱스 2762·2771은 정육각형 120°·정오각형 108°를 문제 안에 제공해야 하며 초4가 정다각형 각도 공식을 이미 안다고 가정하지 않는다.

전수 읽기 범위(0부터 세는 원문 인덱스, 겹치는 재읽기 포함): 0–193, 74–338, 204–229, 339–566, 567–818, 819–1109, 1110–1322, 1323–1571, 1572–1814, 1815–2091, 2092–2421, 2237–2268, 2422–2671, 2672–2778. 출력 중 생략된 범위는 겹치는 후속 읽기로 보충했다. 실제 C는 공통 표기와 원문 studentC의 일치 여부를 함께 확인했다.

이 메모는 최종 집계가 아니며 `audit.json`과 `README.md`가 전체 범위·결정·남은 확인을 기록한다.
