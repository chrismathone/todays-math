# 같은 크기로 나누기: 독립 피드백과 직접 판단의 차이

계획 검토 기록이며 배포 승인이나 원래 독립 응답의 수정이 아니다. 대상은 `e3-1-6-1-c1`(sourceIndex84), 현재 worker fingerprint `e0486e8865ec`이다. 전체 해시와 원응답은 `resume-current-independent-feedback.json`의 해당 이벤트와 `audit.json`에서 추적한다.

현재 B는 다음과 같다.

> '전체를 똑같이 나눈다'는 것은 어떻게 나누는 것인지, 색종이 한 장을 $4$조각으로 나누는 경우를 예로 들어 설명하세요.

참고답은 “나누어진 네 조각의 크기가 모두 같도록 나누는 것이다. 조각의 모양까지 꼭 같아야 하는 것은 아니다.”이다. 필수 의미는 하나이며, 대안은 “나눈 네 조각의 크기가 모두 같아야 한다.”와 “색종이 한 장을 크기가 같은 네 부분으로 나눈다.”이다. 모양이 달라도 된다는 추가 설명을 학생의 필수 답으로 강제하지 않는다.

현재 C는 “한 전체를 나눌 때 각 부분의 □가 같도록 나눈다.”이고 답은 `크기`이다. 원래 정의의 표적도 부분의 크기이며, 모양이 꼭 같아야 한다는 별도 조건은 없다.

독립 응답은 참고답의 두 번째 문장을 삭제하라고 제안하면서, 초3의 똑같이 나누기를 “모양·크기가 같게 나누는 것”으로 가르치는 문맥과 충돌할 수 있다고 말했다. 원응답은 보존한다. 직접 독자의 판단은 같은 크기를 같은 덮는 양으로 읽는 현재 색종이 문맥에서 그 추가 모양 조건은 필요조건이 아니라는 것이다.

같은 작은 정사각형12칸으로 된 색종이를 다음처럼 네 부분으로 나누어 확인할 수 있다. 표의 모든 칸은 같은 크기이고 같은 숫자의 칸을 한 조각으로 묶는다.

| | | | |
|---|---|---|---|
|1|2|2|3|
|1|2|3|3|
|1|4|4|4|

네 조각은 각각 같은 칸3개를 덮는다.1과4는 곧은 세 칸,2와3은 꺾인 세 칸이므로 모두 같은 크기이지만 모양은 모두 같지 않다. 조각은 겹치지 않으며 버린 칸이나 빈칸이 없다. 이는 직접 만든 수학적 반례이며 외부 문제를 이식한 것이 아니다. 초3 학생에게 이 반례를 쓰려면 동일한 칸 크기와 조각 경계를 보이는 새 그림을 마련해야 한다.

[기존 참고 확인 기록](reference-note.md)은 [Mathbus 초3 학습자료](https://mathbus.co.kr/library/data/mathbus_65_6.pdf)의 인쇄면166–167을 직접 읽은 기록을 남겼다. 이 자료는 같은 크기라는 학년 표현을 확인하는 참고이며 모든 교과서의 관례를 전수 확인한 근거가 아니다.2026-10-07 재접속에서는 PDF 열기는 성공했으나 web screenshot은 cache miss로 실패했다. 이 문서가 새 원본 시각 재검증을 완료했다는 뜻으로 쓰지 않는다.

Root에 요청하는 판단은 실제 크기 문맥과 위 반례를 읽고 이 지문을 새 독립 검토에 넘기는 것이다. 추가 문장이 교육적으로 불필요하다고 판단할 수는 있으나, 모든 같은 크기 조각은 같은 모양이라는 주장으로 수정하지 않는다.
