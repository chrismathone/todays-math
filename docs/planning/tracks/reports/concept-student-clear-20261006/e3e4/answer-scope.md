# 답의 범위와 동의어를 구별하는 기준

이 보고서는 채점 구현을 변경하지 않는다. B의 `bRequiredIdeas`는 질문이 실제로 요구한 내용만 확인하는 기준이다. 같은 뜻의 쉬운 설명, 문제 조건에 맞는 다른 풀이, 수의 올바른 다른 표기를 문장 암기 부족으로 처리하지 않는다. C의 키워드 칩·동의어 반영은 최종 독립 검토 후 별도로 결정한다.

| 경우 | 같은 뜻으로 볼 수 있는 답 | 서로 다른 역할·판단으로 남길 답 |
|---|---|---|
| 같은 전체의 단위분수 비교 | 작다·더 작다, 줄어든다·작아진다처럼 문장 문법에 맞는 동일 관계 | 분모가 작다와 분수가 작다는 서로 다른 사실이며 방향이 반대일 수 있다. |
| 정해진 자리의 값 | ‘십의 자리’와 문맥상 ‘십 자리’ 같은 명칭 | ‘윗자리’는 상대적 위치다. 일의 자리에서 십으로 올리는 경우와 십에서 백으로 올리는 경우의 답을 무조건 합치지 않는다. |
| 몫 확인 | `6×7=42`와 `7×6=42`, 6을 7번 모아 42 또는 7개씩 6묶음이라는 의미에 맞는 설명 | 나누어지는 수·나누는 수·몫은 서로 다른 역할이다. 같은 식에 나온다는 이유로 동의어로 취급하지 않는다. |
| 같은 분모 덧셈 결과 | 값만 구하는 B에서 `3/9`와 `1/3`은 같은 수의 표기다. 약분을 아직 배우지 않은 학생에게 `1/3` 표기를 요구하지 않는다. | 분모를 그대로 두는 절차를 설명해야 하는 물음이라면 ‘9를 그대로 두고 조각 수를 더한다’는 이유가 별도로 필요하다. 수치 동등성과 같은 절차의 설명을 섞지 않는다. |
| 길이의 답 | 값만 요구하면 1 cm와 10 mm는 같은 길이다. 문제에 m로만 쓰라는 조건이 있으면 그 단위로 쓴 답이 요청 범위다. | ‘cm’와 ‘mm’는 이름의 동의어가 아니라 다른 단위다. 단위 변환의 수를 함께 확인한다. |
| 삼각형 분류 | 정삼각형은 이등변삼각형에도 포함된다. 어느 조건으로 분류했는지 설명하게 하는 B에서는 질문에 맞는 포함 관계 설명을 허용한다. | 두 이름은 동의어가 아니다. ‘같은 두 변이 있다’에서 정삼각형이라고 단정할 수 없고, ‘세 변이 모두 같다’는 구체 분류 이름을 확인하는 C에서는 목표 명칭과 더 넓은 참인 분류를 구별한다. |
| 사각형 분류 | 정사각형은 직사각형·마름모·평행사변형·사다리꼴 조건을 모두 만족한다. 전체 이름을 묻는 질문이면 여러 답을 허용한다. | 네 이름은 동의어가 아니다. 평행한 변 두 쌍만 안다고 정사각형이라고 할 수 없다. 예각·둔각이 있는 평행사변형을 직사각형으로 채점하지 않는다. |
| 같은 크기로 나누기 | 부분들의 크기가 같다는 설명 | 꼭 겹치는 모양은 같은 크기를 확인하는 한 방법이다. 같은 크기인 모든 부분이 반드시 같은 모양이라는 답은 일반화 오류다. |
| 그래프 비교 | 같은 실제 수량, 눈금의 크기를 반영한 값과 그 이유 | 막대의 길이·칸 수·수량은 조건 없이 같은 말이 아니다. 다른 눈금의 두 그래프를 길이만으로 견주지 않는다. |

제목이 학생에게 숨겨지는 C에서는 같은 문장에 들어갈 수 있는 참인 여러 이름이 생길 수 있다. 그런 경우 다른 참인 이름을 거짓 동의어로 넣어서 해결하지 말고, 실제로 확인할 성질이나 답의 범위를 더 구체화하거나 해당 C형에서 제외한다. B에서도 질문에 없는 ‘공식 이름’, ‘정확한 교과서 문장’, 불필요한 전체 계산을 필수 답으로 추가하지 않는다.
