# ‘똑같이 나누기’ 표현의 확인

인덱스 820의 검토에 참고한 [Mathbus 게시 초3 1학기 학습자료](https://mathbus.co.kr/library/data/mathbus_65_6.pdf)는 인쇄면 166에서 “똑같이 나눈 것 (= 같은 크기로 나누는 것)”으로 설명한다. 도형의 모양도 반드시 같아야 한다는 추가 조건은 이 설명에 없다. 페이지 166–167의 해당 단원 그림과 풀이를 직접 확인했다.

이 자료는 초3에서 쓰는 ‘같은 크기’라는 표현을 확인하는 참고다. 모든 교과서나 교육과정 성취기준을 전수 확인했다는 증거로 쓰지 않는다. 크기가 같은 부분이 서로 다른 모양일 수 있다는 수정 제안은 같은 크기의 작은 칸 3개씩으로 이루어진 곧은 조각과 구부러진 조각을 만들어 비교하는 별도 예로 확인할 수 있다. 그림을 쓸 때 작은 칸의 크기가 같고 겹침이나 빈틈이 없음을 표시한다.

원문의 출처는 baseline 개념 은행이며 이 외부 자료의 문제·문장·그림을 새 문항으로 이식하지 않는다. 원본 PDF와 렌더링은 읽기만 하고 보고서에 배포하지 않는다.

확인 일시: 2026-10-06 21:23 KST. 다운로드 바이트 수: 9,450,293. 직접 확인한 PDF 인덱스: 0–1(인쇄면 162–167, 170–171이 한 PDF면에 배치됨).

[국립국어원 한국어기초사전의 수사 천](https://krdict.korean.go.kr/kor/dicSearch/SearchView?ParaWordNo=17167)은 일천을 유의어로 기록한다. 따라서 일천이라고 하지 않는다는 초안의 모든 맥락을 막는 표현은 보통 읽기에서는 일을 생략한다고 좁히는 것이 적절하다고 판단했다. 이는 사전의 단일 수사 관계에서 얻은 편집 판단이며, 31511의 전체 복합 읽기 또는 일십의 인정 범위를 이 한 항목으로 확정하지 않았다. 학교의 보통 읽기 약속과 문맥상 같은 값을 가리키는 다른 읽기를 구별하여 독립 검토할 항목으로 남긴다.
