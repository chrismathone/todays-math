# 질문 구조 구현과 내용 검토 상태

이 문서는 진행 기록이다. 전 학년 교정·운영 적용 완료 보고가 아니다.

2026-10-06 학생 사진으로 드러난 제목만 있는 B와 상황 없는 C를 수정한다. 초3~중3의 9,119개 개념 ID는 유지한다. Orca의 초3·4, 초5·6, 중학교 작업은 원문 읽기와 구체 문항 초안을 작성하며, 리드 작업 공간에서 공용 계약·출제·인쇄·교재를 연결한다. 기준 원문은 `13bf05dce`의 은행이며 이후 main의 교재 열기 해시·영어 작업 변경도 통합한다.

현재 구현은 B 물음·참고 답·의미 기준, C 문장·빈칸별 인정 답, 질문 판과 형식별 제외 사유를 저장한다. 현재 은행에 적용하는 적재기는 전 ID 결정이 없으면 중단한다. 구 동결 payload는 당시 제목·문장·답을 유지한다. 자동 고르기와 화면의 수량은 형식별 출제 가능 재고를 사용한다. 정확한 ID+형식 선택은 제외된 형식을 거절한다. 교재에서 여러 형식을 선택하면 항목의 지원 형식에 연결하며, 선택한 모든 형식에서 사용할 수 없는 항목을 임의 대체하지 않는다.

학생지·채점표·분할 비용·빈칸 집계는 해당 질문을 읽는다. 질문만 변경해도 지면 지문이 바뀌는 검사를 포함했다. 형식 코드와 개념 ID, 이력 저장 구조, SRS 일정·숙달 정책은 변경하지 않았다. 일반 학습 설명의 실제 교정은 별도로 검토·연동해야 한다.

- 학생 활동 화면의 투영은 별도로 당시 제목·설명을 읽고 있었다. 이를 동결된 새 물음으로 연결하고 C에 정답이 될 수 있는 편집 제목을 보내지 않도록 고쳤다. 질문 구조와 학생 투영의 2개 파일 14개 검사 통과. 긴 TeX 물음은 길이가 제한된 제목 대신 질문 조각으로 전달한다.
- 학년별 구조 표본의 실제 Edge 인쇄 검사는 28쪽에 넘침·수식 오류·마크업 누출·콘솔 오류 0건이었다. 첫 시도에서는 수식 마크업을 렌더된 글과 직접 비교한 테스트 선택자가 실패해 선택자를 바로잡았다. 다음 시도에서는 테스트 지면의 아이콘 요청으로 추정되는 404 콘솔 오류가 기록되어 하네스에 명시적인 데이터 아이콘을 넣었고, 재검사에서 모든 콘솔 오류가 없어졌다. 오류를 무시하는 필터는 추가하지 않았다. 캡처는 전수 교정 승인이 아닌 구조 표본이다.
- 직접 `tsc`를 실행한 두 시도는 Node의 4GB 기본 힙 한도에서 종료됐다. 저장소의 공식 `type-check` 명령은 이미 8GB를 지정하고 있다. 같은 8GB 설정의 전역 타입 검사는 통과했으며, 최신 병합·내용 적용 뒤에는 공식 명령과 정상 pre-push 검사를 사용한다.

원문·입력·모델 응답·사용량·판정은 `design-evidence/`에 보존한다. 이후 코호트 검토는 해당 입력 전체의 SHA-256과 행별 지문을 저장하여 검토한 내용과 적용할 내용을 맞춘다. 모델의 판정·자동 형식 검사·실제 학생의 학습 효과를 동일시하지 않는다.

남은 작업은 전 ID의 최종 형식 결정과 채점 범위 보강, 변경 질문의 독립 검토, 일반 설명 교정의 교재·SRS 연동, 학년별 실제 인쇄 확인, 최신 main 통합·정상 푸시·운영 배포 확인이다. 내용 표가 완성되기 전에는 운영 은행에 연결하지 않는다.

## 2026-10-07 연결 구현 보강

- 새 D 지도는 같은 단원의 검토된 B 물음을 두 가지씩 표시하고 물음마다 답을 쓴다. 옛 동결 D는 뜻·예 여섯 가지 구성을 유지한다. 제외한 B 항목은 새 D에도 쓰지 않는다. 새 질문과 옛 제목 자료를 한 지도에 섞지 않는다. 계약 상한 배치 표본의 실제 인쇄와 학생·교사 캡처를 확인했다. 이는 지도 형식의 추가 학습 효과를 입증한 것이 아니다.
- 자동 교재는 핵심 개념 ID/순서를 원천으로 사용하되 질문을 동결할 때 현재 은행 payload를 읽는다. 일반 학습 설명과 단원 열기 원천 해시는 평가 필드에 종속시키지 않는다. B/C의 지원 항목 모두에 source↔frozen 해시 일치를 검사한다.
- 신규 교재 질문은 교재 소유의 strict `conceptQuestions` v1에 물음·참고 답·필수 의미를 명시 복사한다. 학생 Render DTO는 모든 블록의 해당 노드를 제거하고 별도 `questionRows`에 ID/물음만 복사한다. 블록 계약은 허용 활동·단계·본문 일치를 검사하고, 참조 검사도 질문/키/ID가 실제 동결 B와 다르면 거절한다. UI에서 지면에 반영되지 않는 질문 본문을 수정할 수 있는 것처럼 표시하지 않는다.
- 신규 준비 학습은 B를 사용하며 C를 임의로 B로 바꾸지 않는다. 아직 배우지 않았다면 모르겠다고 적을 수 있다. 책 없이 답 쓰기·설명 활동·단원 개념 확인 모음은 같은 물음을 다시 연습한다는 조건을 지면과 안내에 명시한다. 자동 교재의 확인 모음을 실제 가지 지도와 동일시하지 않는다. C는 일반 정의와 별도의 검토 문장/제목/지시문을 사용한다. 선택한 질문 활동에 문항이 없으면 오류를 반환한다.
- Claude 설계 검토 3회에서 나온 답 차단 범위, 동결 v1 독립성, 형식 제외, 가짜 본문 수정, 제목과 지시문 불일치, 질문과 frozen 대응 문제를 수정했다. 마지막 검토는 세 보강 후 합의할 수 있다는 조건부 결론이며 그 세 조건을 구현·검사했다. 원응답은 `textbook-question-design*` 증거로 보존한다.

구조 구현, 저작 초안, Codex의 최종 직접 읽기, 독립 모델의 해시별 검토, 실제 학생 효과는 각각 다른 증거다. 모델 검토 횟수에는 바뀐 ID의 재검토가 포함되며 전수 최종 승인 수가 아니다. 현재 운영 은행 내용에는 아직 이 질문 표를 연결하지 않았다.
