# 워크시트 C 인정 답의 의미

현재 Dispatch ctx_8787d65a5eef에서 `orca orchestration ask`로 코디네이터에게 확인한 답변:

> 입력 의미 동치를 보존하세요. C의 acceptedAnswers는 교사가 학생의 자유 입력을 읽는 참고 대안이며 문장에 기계적으로 치환하거나 문자 일치로 채점하는 규칙이 아닙니다. 같은 개념을 정확히 설명하는 합동/모양과 크기가 같은 같은 서술형 대안, 비교 대상이 분명한 큰/큰 수 같은 입력을 조사 중복 때문에 틀렸다고 처리하지 않습니다. canonical 학생 문장과 canonical 정답은 자연스럽게 유지합니다. 다른 범위인 크다/크거나 같다, 직사각형/정사각형 같은 상하위 개념은 의미 동치로 넣지 마세요. SRS general 정의·칩·typed 판정 계약으로 이 C 대안을 자동 확장하지 않습니다.

이 확인에 따라 수치·단위 입력뿐 아니라 정확히 같은 의미의 서술형 입력도 보존한다. 이번 재개에서 조사 형태만을 이유로 줄인 세 항목의 대안을 원래 의미대로 복원하며, 단위가 있는 답을 문자 대입의 중복으로 배제했던 중간 기록 역시 역사로 보존한다. 원주(길이)와 둘레(테두리), 큰 범위와 크거나 같은 범위처럼 실제 다른 개념·범위는 계속 구분한다.
