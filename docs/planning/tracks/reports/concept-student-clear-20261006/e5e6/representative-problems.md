# 초5·초6 대표 제안 — 원문과 학생 지면을 구분하기

이 파일은 초기 제안의 기록으로 보존한다. 현재 문항·답·기준은 [final-representative-problems.md](final-representative-problems.md)와 [audit.json](audit.json)을 사용한다. 아래 표현을 최종 제안 위에 덮어쓰지 않는다.

모든 예는 `13bf05dce`의 실제 개념 ID에 연결된 적용 전 초안이다. 아래 C 수정은 별도 빈칸 평가문항이며, 일반 학습 설명을 계산 예로 대체하는 제안이 아니다. 전체 원문·답은 `evidence/source.json`, 현재의 개별 수정 기록은 `codex-overrides.json`에서 확인한다.

## 초5: 반올림한 결과가 같은 수의 범위

ID `e5-2-1-6-c3`의 원문 B 제목은 ‘반올림한 값이 같은 수의 범위’이고, 실제 C는 ‘같은 자리까지 반올림하여 같은 값이 되는 수는 그 값에서 나타낸 자리의 □ 이상, 반 단위를 더한 수 미만이다.’이다. 기대 답 ‘반 단위를 뺀 수’는 구할 자리·기준 값·답의 단위가 모두 추상적이다.

**B 제안:** 자연수를 반올림하여 십의 자리까지 나타냈더니 50이 되었습니다. 가능한 자연수의 범위를 ‘이상’과 ‘미만’을 써서 나타내고, 양쪽 경계의 수를 포함하는지 설명하시오.

**B 모범답안:** 45 이상 55 미만이다. 45는 50으로 반올림되므로 포함하고, 55는 60이 되므로 포함하지 않는다. 가능한 자연수는 45부터 54까지다. 이 문제는 범위와 경계 포함 여부를 확인하며, 일반적인 반올림 설명은 별도로 유지한다.

**C 제안:** 반올림하여 십의 자리까지 나타내면 50이 되는 자연수의 범위는 □ 이상 □ 미만이다. 답: 45, 55.

## 초5: 약수와 배수를 한 곱셈식에서 설명하기

ID `e5-1-2-2-c1`은 원문 C ‘$3\times7=21$에서 $3$과 $7$은 $21$의 □이고, $21$은 두 수 각각의 □이다.’가 이미 구체적이고 짧다. C는 유지한다.

**B 제안:** 두 자연수를 곱한 식에서 곱한 두 수와 그 곱은 서로 약수와 배수로 어떤 관계인지 쓰시오. 그리고 $6\times8=48$에서 그 관계를 말하시오.

**B 모범답안:** 곱한 두 수는 그 곱의 약수이고, 곱은 두 수 각각의 배수다. $6$과 $8$은 $48$의 약수이고 $48$은 $6$의 배수이면서 $8$의 배수다. ‘약수’와 ‘배수’의 자리를 바꾸어 쓴 답은 서로 다른 수학적 관계이므로 동의어로 인정하지 않는다.

## 초6: 분수의 나눗셈을 곱셈으로 확인하기

ID `e6-2-1-1-xc14`의 실제 C ‘구한 몫에 나누는 분수를 곱하면 □가 되어야 한다.’는 원문에 식이 없어 초6 학생이 세 역할의 이름만 복원해야 한다. 사용자가 지적한 바로 그 문장이다.

**B 제안:** $\frac{3}{4}\div\frac{1}{4}=3$이 맞는지 곱셈으로 확인하려고 합니다. 확인할 곱셈식을 쓰고, 왜 그 곱셈으로 확인할 수 있는지 설명하시오.

**B 모범답안:** $3\times\frac{1}{4}=\frac{3}{4}$이다. $\frac{1}{4}$씩 세 번 모으면 처음 양 $\frac{3}{4}$이 되어, 나누는 양이 처음 양에 세 번 들어감을 확인할 수 있다. 특정 용어 ‘나누어지는 분수’를 그대로 쓰는 것은 필수 답 요소가 아니다.

**C 제안:** $\frac{3}{5}\div\frac{1}{5}$의 몫을 2라고 쓴 답을 확인하면 $2\times\frac{1}{5}=$ □이다. 곱한 결과가 나눗셈식의 맨 앞 수 $\frac{3}{5}$보다 작으므로 몫 2는 틀렸다. 답: $\frac{2}{5}$. 원래 식에 없는 곱한 양을 구하므로 처음 분수를 그대로 복사할 수 없다. $0.4$·$\frac{4}{10}$은 같은 값이고, $\frac{3}{5}$·$\frac{1}{5}$는 다른 값이다.

## 초6: ‘조각의 개수만 견주기’라는 제목을 실제 물음으로

ID `e6-2-1-1-xc15`의 편집 제목은 물음과 답 범위가 없다. 원문 정의는 분모가 같으면 한 단위분수의 크기가 같아 개수로 비교할 수 있다는 내용이다.

**B 제안:** $\frac{4}{7}\div\frac{2}{7}$에서 몫을 분자끼리 나누어 구할 수 있는 까닭을, 두 분수가 각각 $\frac{1}{7}$이 몇 개인지로 설명하시오.

**B 모범답안:** $\frac{4}{7}$은 $\frac{1}{7}$이 네 개, $\frac{2}{7}$는 두 개다. 한 조각의 크기가 같아 네 개인 양 안에 두 개인 양이 몇 번 들어가는지 $4\div2$로 비교할 수 있다. 이 질문의 필수 답 요소는 같은 단위와 개수의 관계이며, 질문하지 않은 공식의 이름은 요구하지 않는다.

## 초6: 유용한 짧은 C 비교 유지

- `e6-2-1-1-xc11`: $0$보다 큰 두 분수에서 나누어지는 분수가 나누는 분수보다 □ 몫은 $1$보다 작다. 답: **작으면**.
- `e6-2-1-1-xc12`: $0$보다 큰 두 분수에서 나누어지는 분수가 나누는 분수보다 □ 몫은 $1$보다 크다. 답: **크면**.

두 문장 모두 원문 그대로 유지한다. 질문에 필요한 조건과 비교할 대상이 있고 답이 짧다. ‘작은/큰’이라는 사용자 예와 같은 비교 목표이지만, 원문 문장의 연결에는 ‘작으면/크면’이 맞으므로 단어만 맞바꾸지 않는다.

코디네이터의 독립 blind 검토가 두 문장의 반대 관계를 관찰했지만, 코디네이터는 사용자가 허용한 이 짧은 비교 두 문장을 그대로 보존하도록 확정했다. 이 관찰을 삭제나 별도의 인접 배치 제한으로 바꾸지 않는다.

## 독립 blind 검토 뒤의 ‘분모와 몫’ C 수정

`e6-2-1-1-c3`의 첫 제안은 두 식이 ‘모두 3÷2로 계산되므로’라고 말해 답 ‘같다’를 알려 주었고, ‘몫은 □’에는 값 3/2도 참인 답이었다. 실제 지면만 본 독립 검토에서 드러난 결함이므로 첫 제안을 수정한다.

**C 수정 제안:** $\frac{3}{5}\div\frac{2}{5}$와 $\frac{3}{7}\div\frac{2}{7}$은 분자들은 그대로 두고 같은 분모만 함께 바꾼 두 식이다. 이 두 식의 몫이 서로 다르다는 말은 □.

답은 ‘틀리다’이고, ‘옳지 않다’·‘맞지 않다’도 같은 판단이다. 이제 값 3/2는 물음의 답 유형과 맞지 않고, 질문이 두 식을 3÷2로 바꾸는 방법이나 몫의 같음을 미리 말하지 않는다. B의 관계 설명 질문과 일반 학습 설명은 별도로 유지한다. 이 수정안도 최종 적용 전 독립 검토 대상이다.

## 초6: 일반 설명의 사실 오류와 C 계산을 별도 교정

ID `e6-1-5-3-xc27`의 원문은 ‘사람 수의 차를 전체 수로 나누면 두 항목의 백분율의 차가 된다’고 한다. 나눈 값은 **비율의 차**이므로, 백분율로 나타내는 100배 변환과 기호가 빠져 있다.

**일반 설명 `coreAfter` 제안:** 같은 원그래프에서 두 항목의 사람 수의 차를 전체 사람 수로 나누면 두 항목의 비율의 차가 된다. 이 값을 백분율로 나타내려면 $100$을 곱하고 $\%$를 붙인다. 이는 두 항목의 백분율을 빼서 구한 차와 같다.

**B 제안:** 전체 $40$명의 원그래프에서 두 항목의 사람 수가 $18$명과 $10$명입니다. 각 항목의 백분율과 두 백분율의 차를 구하시오. 사람 수의 차를 이용해 두 백분율의 차를 구하는 방법도 설명하시오.

**B 모범답안:** $45\%$와 $25\%$이고 두 백분율의 차는 $20\%$이다. 사람 수의 차 $8$을 전체 $40$으로 나눈 $0.2$에 $100$을 곱해 $20$을 구한 뒤 $\%$를 붙인다. 초6 학생에게 ‘퍼센트포인트’라는 새 용어를 정답으로 요구하지 않는다.

**C 제안:** 전체 $40$명인 원그래프에서 두 항목의 사람 수가 $18$명과 $10$명이다. 두 항목의 백분율의 차는 $(18-10)\div40\times100=$ □ $\%$이다. 답: $20$.

## 그림이 꼭 필요한 초5 제안은 B/C 제외

`e5-1-6-4-xc17`의 평행사변형 자르기와 `e5-1-6-5-xc14`의 마름모 넓이 설명에는 실제 도형이 필요하다. 각각의 구체적인 질문·답·SVG는 연구 제안으로 보존한다. 확정된 B/C 계약은 글·수식 전용이므로 현재 두 형식에서는 제외하고, 일반 학습 설명과 ID·이력은 보존한다. 이 제안을 그림 없이 적용해서는 안 된다.
