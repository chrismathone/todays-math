# 템플릿 Wire 검토 — 2026-10-20

상태: **구조 정의 완료 / 실측·HTML 생성·시각 검증 대기**. 리드가 메모리 여유 부족으로 Vite·크로뮴·측정의 새 실행을 보류하도록 지시했다. 실행 재개 연락 전까지 제품 코드나 측정 수치를 지어 채우지 않는다.

## 방향과 여섯 이름의 대응

| 안 | 한 줄 | 구별에 힘을 주는 곳 | 선택 뒤 영향 |
|---|---|---|---|
| A | 여섯 종이 양식의 원형을 크게 가른다. | 영역 머리 / 학교 정보표 / 안내 머리 / 좌우 풀이 / 개념과 모눈 / 유형 반복 | 이름과 선택 여섯 유지. 개별 본문 구조 관리. |
| B | 시험·과제·자습 세 쓰임 안에 두 세부형씩 둔다. | 답 기록 / 서술 줄 / 배부 안내 / 수업 확인 / 읽기·풀기 / 재풀이 | 선택 메뉴의 묶음 변경. 종이의 수기 칸이며 서버 기능 추가는 아님. |
| C | 겹치는 이름을 합쳐 네 가지로 줄인다. | 시험 / 안내 / 풀이 / 개념 | 평가원+정통, 워크북+유형 통합. 저장 프리셋의 호환은 선택 뒤 설계. |
| D | 머리를 공통으로 두고 종이 배분으로 구별한다. | 문항 밀도 / 답 줄 / 전달 여백 / 풀이 폭 / 개념 높이 / 재풀이 하단 | 공통 머리 유지, 여섯 본문 배분 관리. |

각 방향에서 기존 여섯 템플릿의 한 줄 정체성은 `scripts/qa/print-templates/directions.mjs`에 모두 명시했다. C의 여섯 대응은 네 실제 지면으로 합친다. 어떤 안도 현재 템플릿 키를 삭제하거나 바꾸지 않았다.

## 잠정 리드 추천

**A.** 원장님의 문제 제기인 «템플릿 사이 차이를 느끼기 어렵다»에 직접 답한다. 이름을 줄이거나 메뉴를 바꾸는 별도 결정 없이, 문항을 읽고 쓰는 방식까지 다른 여섯 지면을 비교할 수 있다. 단, 실측 결과와 실제 Wire를 눈으로 확인한 뒤 추천을 확정한다.
