## 2. 세운 셋 — 무엇이 마디를 열고 무엇이 굳히나

### 1-3-3 (나눗셈의 몫을 곱셈식으로 구하기) 심화중

```
[실물] 쿠키는 한 봉지에 $9$개씩 담으면 남는 것 없이 $2$봉지가 됩니다. 같은 쿠키를
   처음과 다른 수씩 남김없이 다시 담았더니 한 봉지의 수와 봉지 수가 모두 한 자리
   수였고, 봉지 수가 한 봉지의 수보다 적었습니다. 다시 담을 때 한 봉지에 넣은 수는? → $6$
   해설: $9\times2=18$ … 곱이 $18$ 인 곱셈식 가운데 처음 $9$개씩이 아닌 것은
        $2\times9,\ 3\times6,\ 6\times3$ … 봉지 수가 적은 것은 $6\times3$ 하나뿐 …
```

**사다리 한 칸이 «발문이 둘째 나누는 수를 주는가»로 갈린다** — 지금 심화하가
「$2$개씩 $9$묶음 → **$3$개씩** 다시 묶으면?」이라 그 수를 준다. 지면의 수가
**심화하 3개 · 심화중 2개**이고, 시험이 그것을 잠근다.

**중이지 상이 아닌 까닭 (D-115 ⑾)** — 해설이 짝을 **늘어놓되 계산하지 않는다.**
거르는 데 더 계산이 안 든다(눈으로 견준다). 물결 2 의 `2-2-3 심화중` 이 후보
$61,62,63$ 을 늘어놓는 것과 **같은 모양**이고, 열거 판정기에도 안 걸린다(6.3% =
파일럿 2-1-4 하나뿐).

### 2-5-3 · 2-5-6 (들이·무게의 합과 차) 심화중 / 심화상

```
[심화중] 한 통에 $1\,L\ 850\,mL$ 씩 들어 있는 간장을 몇 통 사서 한 냄비에 모두
   부었더니 $9\,L\ 250\,mL$ 가 되었습니다. 산 통은 몇 개인지?                    → $5$
   해설: mL끼리만 봅니다 … mL 자리는 차례로 $850,\ 700,\ 550,\ 400,\ 250$ …
        $250$ 인 것은 $5$ 번째뿐 … 확인하면 $850\times5=4250$, $1\times5=5$ …

[심화상] 한 병에 $1\,kg\ 900\,g$ 씩 들어 있는 밀가루를 여러 병 모아 한 들통에 모두
   담았더니 $7\,kg$ 보다 많고 $8\,kg$ 보다 적었습니다. 담은 병은 몇 개인지?      → $4$
   해설: … 처음 한 개는 $1900\,g$, $2$개까지 담으면 $1900+1900=3800$,
        $3$개까지 $3800+1900=5700$, $4$개까지 $5700+1900=7600$,
        $5$개까지 $7600+1900=9500$ … 이 사이에 있는 것은 $7600\,g$ 하나뿐 …
```

**중·상을 가른 축이 «자리 성질이 무엇을 자르나»다.** 중은 합을 «몇 L 몇 mL» 로 주므로
**작은 자리 끝자리**만 보면 후보가 하나로 줄고(큰 자리를 끝까지 안 센다 → D-115 ⑾ 로 중),
상은 합을 **범위로만** 주어 작은 자리가 지면에 **아예 없어** 그 성질이 한 후보도 못 자른다
→ 그릇 수를 하나씩 **실제로 만들어** 견주어야 한다. 두 갈래가 **구성상 안 섞인다.**

열거 판정기 실측이 그 갈림을 다시 보인다 — **심화중 6.3%**(내 것 0) · **심화상 75.0%**
(내 것이 늘어놓는다 — 그 갈래에서는 **정상**이다, 전 학년 실측 81.0%).
