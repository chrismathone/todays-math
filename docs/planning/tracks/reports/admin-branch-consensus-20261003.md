# 관리 콘솔·지점 관리 3자 합의

2026-10-03. 대상: [최종 계획](../../admin-branch-upgrade-20261003.md). 사용자 지시: Claude·Grok과 계획을 검토해 3자 합의 후 실행.

## 검토 방법

Codex가 실제 코드와 운영 DB 읽기 전용 익명 집계를 근거로 초안을 작성했다. 연결된 구독 CLI의 Claude와 Grok에 같은 초안을 보내 독립 검토를 받았다. 1차 의견 차이를 명시적으로 조정한 수정안을 두 모델에 다시 전달했으며, 둘 다 필수 차단 사항 없음으로 승인했다. 외부 검토자는 제공된 명세·근거를 검토했고, 저장소 전체 검증이나 구현 테스트 통과를 주장하지 않았다.

| 검토자 | 실제 모델 | 1차 | 최종 |
| --- | --- | --- | --- |
| Codex | 현재 작업 세션 | 초안 작성·실제 코드 대조 | APPROVE — 사용자 범위·저장값 보존·인가 경계 확인 |
| Claude | claude-opus-5-5 | REVISE, 필수 보강 7건 | APPROVE, 필수 차단 사항 없음 |
| Grok | grok-4.7-build | REVISE, 필수 보강 5건 | APPROVE, 필수 차단 사항 없음 |

Grok의 첫 호출은 검토 결론 대신 추가 탐색을 시도하다 최대 턴에 도달했다. 이는 합의 근거로 사용하지 않았다. 저장소 밖의 빈 작업 폴더에서 제공 명세만 검토하도록 다시 호출한 성공 응답과 최종 승인만 기록했다. 실행 원본은 로컬 `.qa-artifacts/branch-admin/`에 보관한다.

## 합의된 선택

- Wire A: 지점 목록 → 지점 상세 → 계정·사용 메뉴 관리. H1: 기존 관리 콘솔 디자인 유지.
- 최고관리자 콘솔의 계정 관리 위치를 옮긴다. 지점 원장에게 최고관리자 API 권한을 새로 주지 않는다.
- 실제 업무 메뉴는 지점·개인·기존 시범 제한의 교집합. 원장 직책으로 전부 허용하지 않는다. 최고관리자의 운영 복구 경로는 별도 권한이다.
- 개인 설정을 별도로 보존해 지점 메뉴 재활성화 시 복구한다. 원장 2명의 개인 차단값이 모두 없다는 실측에 따라 불필요한 초기화는 하지 않는다.
- 지점 필수 범위로 계정·집계를 조회하며 미소속 진입점·승인 대기 수를 유지한다.
- revision 조건부 변경과 같은 트랜잭션의 감사 기록, 개인 수정·비밀번호 재발급의 최신 시각·소속 비교로 충돌을 처리한다.
- 이번에 다루는 branch·user 두 테이블의 공개 클라이언트 접근을 닫는다. 서버 역할을 검증한 뒤 RLS·권한 회수를 적용한다.
- 기존 eywa 정책, 마지막 원장 보호, 소유권 판정, 학생 과제·배치는 보존한다. DB 먼저·검증 후 코드 반영, 지정한 migration 하나만 적용한다.

이 합의는 구현 명세 승인이다. 구현·회귀·브라우저·배포 검증 결과는 완료 보고서에 별도로 기록한다.
