## 바로잡은 사실

Codex 가 코드를 대어 찾았고, 리드가 다시 확인했다.

1. **자동 넘김은 «맞혔을 때만»이 아니었다.**
   - 조건 `hasFeedback && instantAnswer && !followUp` 에 정답 검사가 없다(`StudentCoursePractice.tsx` 402~406행).
   - `followUp` 은 첫 풀이에만 생긴다(`retryIndex === null` — 332행).
   - 그래서 **회차 끝 재도전에서는 보기 · 터치 문제를 틀려도 1.2초 뒤 넘어간다.** 계획서 §3.2 의 «틀리면 학생이 눌러야 넘어간다»와 어긋나는 결함이다. Q2 와 같이 고친다.
2. **`state.history` 는 최근 30회만 남는다**(`courseAutomation.ts` 476행). 그래서 «첫 학습 회차인가»는 history 로 정하지 않는다.
   - 대신 `learner.progress[sectionId].completedSessions` 를 쓴다. 자르지 않고 계속 쌓이며, 회차를 마칠 때 1 씩 는다(`progress.ts` 495행).
   - 학습 회차를 여는 때 이 값이 있으면 «다시 배우는 날», 없으면 «처음»이다.
   - 끝내지 못한 회차는 세지 않으므로, 그 다음 날은 다시 «처음»으로 카드가 뜬다. 끝까지 못 본 학생에게는 맞는 동작이다.
3. **진도 통과는 단순 정답률 80% 가 아니다.**
   - 자동 채점 문항은 힌트 없는 정답이 80% 이상이어야 하고, 자기 평가 문항은 모두 정답이면서 힌트를 썼어야 한다(853행).
   - 다음 날에도 복습 · 선수 확인이 먼저 올 수 있다.
4. **진도판 테마는 그림 테마 다섯에 `classic` 기본 판이 더해진 여섯 값이다**(`journeyThemes.ts`). 길잡이는 기본 판에서도 확인한다.
5. **리드의 요청서 잘못.** Q3 은 미결이 아니었다. 원장님이 10-19 에 codex 추천대로 정하셨다(계획서 §2 결정 7). 합의는 같은 결론이다.

## 맞춘 까닭

**Q2** 는 셋이 갈렸다.

- 셋의 공통점: 1.2초는 흐름은 좋지만 초5 학생이 «맞았다»를 보고 넘어가기에는 짧다(Gemini). 넘기는 속도는 학생이 정할 수 있어야 한다(Codex). 맞힌 문제마다 단추를 누르게 하면 흐름이 끊긴다(리드).
- 그래서 C 를 고른다. 맞힌 문제만 약 2초 뒤 넘기고, 그 사이 Enter · 누르기로 바로 넘길 수 있다. 운영체제의 «움직임 줄이기»를 켠 학생은 단추로 넘긴다.
- 틀린 문제는 어느 단계에서도 자동으로 넘기지 않는다. 위 사실 1 의 결함을 함께 고치는 것이다.

**4a** 는 2 : 1 로 A 다.

- 원장님 말씀이 «처음에 스스로 선택»이다.
- Codex 의 B(«나중에»)가 걱정한 것은 고르기가 공부를 막는 일이다. 그 걱정은 «저장이 실패해도 막지 않는다 · 고른 길잡이는 그날 화면에 둔다»로 받는다.
- 고르기는 누르기 한 번이다.

**Q3** 의 Gemini 안 C(2학기 전 범위 카드까지를 «끝»으로)는 받지 않는다. 다만 그 뜻은 받는다. 계획서 §4 의 11/3~11/9 «나머지 2학기 카드»는 그대로 목표로 둔다.

## 할 일

**속(Claude)**

1. **다시 배우는 날 표지.** 학습 회차의 공개 응답에 «이 소단원을 전에 끝낸 적이 있다»를 머리글로 요청한 화면에만 싣는다. 옛 화면은 응답을 엄격하게 읽기 때문이다.
2. **길잡이 선택 칸.** 학생 기록에 둔다. 순서는 다음과 같다.
   - 읽는 쪽 커밋을 먼저 낸다.
   - 운영 Ready 를 확인한다.
   - 쓰는 쪽(저장 API · 응답)을 낸다.

**화면(codex)**

1. 예습 카드: 첫 학습 회차에만 자동으로 띄우고, 다시 배우는 날에는 «개념 다시 보기» 단추를 둔다.
2. 자동 넘김: 맞혔을 때만 약 2초로 하고, 움직임 줄이기를 켠 학생은 단추로 넘긴다. 재도전 단계의 오답 자동 넘김을 고친다.
3. 길잡이:
   - 고르기 쪽을 만든다(넘김책 한 쪽 · 다섯 나란히 · 폰 두 열).
   - 두 자리에 그림을 넣는다(첫 화면 안내 · 하루 마침 축하 · 보상).
   - 흰 바탕 PNG 를 투명 webp 로 만든다.
   - 테마 여섯(`classic` 포함)에서 본다.
