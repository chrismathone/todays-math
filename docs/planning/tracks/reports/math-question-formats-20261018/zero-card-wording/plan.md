# 0을 포함한 카드 발문 8행의 명사 수정

Claude의 추가 실문항 검토에서 `mid:2-2|경우의 수|11`의 카드 표기 범위가 0부터 시작하면서 이를 자연수라고 부르는 오류를 확인했다. 이 보완은 원래 17행 도형 수정의 고정 범위를 확장하지 않는 별도 작업이다.

해당 문항류의 기존 8행만 대상으로, 발문 첫머리의 카드에 적힌 수를 가리키는 `자연수가`를 `숫자가`로 고친다. 뽑은 카드로 만드는 양의 자연수, 보기·정답·해설·그림·문항 ID·코드·출처·검수·작성 시각은 모두 유지한다. 아직 전체 형식 묶기 전이므로 group key는 NULL 그대로다. 학생 기록과 기존 시험 내용을 재작성하지 않는다.

기본 실행은 읽기 전용 준비다. 실제 8개 ID와 모든 필드의 사전 값·변경 후 digest를 얼린 뒤 별도 Claude 승인을 커밋해야 한다. 적용 때 런타임 참조 열을 다시 찾고 관련 표를 잠근 상태에서 참조 0, 전체 행 일치, 문항류의 추가·삭제 0을 확인한다. 하나라도 달라지면 8행 모두 중단한다. 적용은 전체 행 CAS와 readback을 한 트랜잭션으로 처리하고, 같은 승인으로 재실행하면 0행 수정이다.

새 후보의 같은 명사 오류는 생성기에서 수정하고, 최종 보강 후보는 새 소스와 backfill 이후의 전체 baseline으로 다시 준비해 따로 승인받는다. 원래 17행 승인·1차 108행 원장·이전 보강 도구의 한도는 변경하지 않는다.
