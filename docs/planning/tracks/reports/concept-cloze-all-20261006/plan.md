# 전 학년 개념백지 C형 물음 명료성 감사

사용자 요청: 초6 사진 문항 교정에 이어 전 학년에서도 학생이 무엇을 써야 하는지 불분명한 문항을 확인한다. 이번 단계는 원고 감사이며 제품 문항을 일괄 교체하지 않는다.

## 범위와 기준

현재 은행의 초3~중3 기본·보강 개념 전체를 대상으로 한다. 초1~2와 고등학교의 C형 은행은 이 시스템에 없으므로 검토 완료에 포함하지 않는다. 다른 형식의 계산·○×·그림 문항과 교육과정 성취기준 전수 대조는 별도다.

- 학생지에 실제 남는 문장과 대단원 맥락으로 답의 종류·범위를 정할 수 있는가.
- 조건·범위·긴 절차가 통째로 가려져 임의의 참인 말을 쓰게 되지 않는가.
- 서로 뜻이 다른 답도 맞는데 정답지에 한 가지 문구만 기대하지 않는가. 동의 표현은 결함으로 세지 않는다.
- 완성 문장에 수학적 반례가 있거나, 한 문장 안에서 정답을 그대로 알려 주는가.
- 답이 길거나 빈칸에 조건이 있다는 사실만으로 결함으로 분류하지 않는다. 질문이 그 조건 자체를 명확히 묻는다면 성립할 수 있다.
- C형 학생지는 개념 소제목을 힌트로 표시하지 않는다. 같은 대단원의 모든 문항이 한 시험지에 함께 실린다고 가정하지 않는다.

## 실행

1. 실제 은행·제품의 빈칸 파서로 전 항목을 추출하고 ID·원문 해시·학생 문장·기대 답을 기록한다. 길이 등 기계적 신호는 후보로만 사용한다.
2. Orca Codex 작업을 초3~4, 초5~6, 중1~2로 분할한다. 리드는 중3과 교차 검토·집계를 맡는다. 진행 중 초4 후반 701개(11~18 묶음)는 리드가 추가 분담했고, 초3~4 보고서에 실제 검토자별 ID를 구별해 기록한다. 90개 이하 묶음을 읽고 실제 읽은 ID를 남긴다. 전수 정독이 끝나지 않았으면 읽지 않은 범위를 명시한다.
3. 문제 지적마다 학생 문장, 답, 서로 다른 성립 답 또는 수학 반례, 고쳐야 할 이유, 수정 방향을 기록한다. 확정 결함과 판단 보류를 구별한다.
4. Claude가 학년별 대표 지적과 경계 사례를 독립 재검토한다. 초기 표본에서 확정·보류 경계의 의견 차이가 확인되어, 1차 Codex 지적 393개 전체와 미지적 대조 표본 36개로 교차 검토를 확대했다. 이는 모든 9,119개 문항의 두 모델 전수 검토가 아니다. 판정이 갈린 항목은 근거를 비교해 남긴다. 앞서 받은 Codex·Claude 진행 승인을 이 후속 감사에도 적용한다.
5. 코드로 누락·중복 ID와 원문 해시를 대조한 뒤 학년별 결과·우선순위·남은 범위를 보고한다. 자동 선별과 정독 범위, 교차 검토 범위를 각각 표시한다.
6. 감사 도구·보고서를 main에 병합하고 푸시 직전에 원격을 다시 통합한다. 완료·병합·깨끗함·실행 종료가 확인된 워크트리만 가지를 남기고 정리한다.

TypeSafe 프로젝트 지침과 현재 문서의 [state](https://docs.typesafe.ai/concepts/state), [confidence](https://docs.typesafe.ai/confidence)를 확인했다. 집계와 ID 대조는 코드가 맡고, 의미 판단과 불확실성은 근거를 붙인 별도 기록으로 남긴다. 제품 AI 연동이나 채점 정책을 추가하지 않는다.
