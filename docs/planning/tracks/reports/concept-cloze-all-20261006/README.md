# 전 학년 개념백지 C형 문장 검토 결과

2026-10-06. 현재 은행의 **초3~중3 기본·보강 개념 9,119개, 빈칸 12,468개**를 검토했다. 학생이 무엇을 적어야 하는지 정하기 어려워 **수정이 필요한 문항 143개**, 교사 판단이나 추가 확인이 필요한 문항 **173개**를 남겼다. 이번 작업은 점검과 수정 방향 정리이며, 제품 문항·교재 원고·학생 기록은 변경하지 않았다.

‘수정 필요’는 이번 검토 기준에서 확인한 문항 결함이다. 실제 학생의 결손 진단이나 공식 교육과정 판정이 아니다. ‘추가 판단’에는 표현 개선 후보, 관례로 답을 추론할 수 있는 경계 사례, 정답 노출에 따른 평가 효용 문제가 포함된다. ‘철회’는 처음 지적했다가 재검토에서 제외한 78개만 뜻한다. 나머지 미지적 문항 전체를 두 모델이 모두 검증했다는 뜻은 아니다.

**초1~2와 고등학교의 C형 은행은 현재 시스템에 없어 검토 대상에 포함하지 않았다.** 계산·선택·○×·그림 등 다른 문항 형식, 실제 학생 답안 조사, 성취기준별 전수 대조도 이번 범위에 포함하지 않았다.

표의 수식은 읽기 쉽게 정리했으며, 정확한 학생 문장·기대 답·원문 해시는 [최종 문항 원장](findings.json)에 있다.

핵심 문제는 답의 길이 자체보다 **대상·연산·조건까지 빈칸으로 가려 서로 다른 참인 답을 허용하는 것**이다. C형 학생지는 개념 소제목(`term`)을 표시하지 않고 대단원 단위 제목을 사용하므로, 숨겨진 소제목이나 앞 문제를 읽었다는 가정으로 질문을 보완할 수 없다. 확인한 구현은 `src/components/concept-blank/paper/StudentBody.tsx`의 `ClozeBody`와 `src/lib/concept-blank/compose.ts`의 제목 구성이다.

## 검토 과정과 판단 기준

1. 제품의 빈칸 파서를 사용해 모든 문장의 학생용 텍스트와 기대 답을 추출했다. 길이·빈칸 비율 같은 기계적 신호만으로 결함을 확정하지 않았다.
2. Codex가 9,119개 전체를 읽고 393개를 지적했다. 초3~4, 초5~6, 중1~2는 Orca 병렬 세션으로 나눴고, 리드는 중3과 초4 후반을 읽었다. 검토한 ID와 묶음은 학년별 1차 기록에 남겼다.
3. Claude가 **1차 지적 393개 전부와 미지적 대조 표본 36개**, 총 429개를 독립 검토했다. 처음에는 대표 표본으로 시작했으나 판정 차이가 있어 지적 전체로 확대했다. 대조 표본에서 `e6-2-2-3-xc25` 한 개를 추가 발견했다. 따라서 최종 원장은 철회 항목을 포함해 394개다.
4. Codex 리드가 Claude의 전체 응답과 학생 문장을 대조해 최종 분류했다. 의견이 다른 항목은 [최종 조정 기록](adjudication.json)에 근거를 남겼다. 의견 차이가 해소되지 않은 경계 사례를 합의된 확정 결함으로 세지 않았다.

표준 정의를 복원할 수 있는 문항은 빈칸 답이 길다는 이유만으로 결함으로 세지 않았다. 동의어·동치인 수식도 서로 다른 개념 답과 구별했다. 단순히 같은 문장 뒤에 정답이 반복된 사례는 주로 추가 판단으로 분류했다. 최초 판단과 예시는 삭제하지 않고 보존했으므로 **수정 대상을 고를 때는 1차 기록이 아닌 `findings.json`의 `status`를 사용한다.**

사용자가 승인한 Codex·Claude 검토 방식으로 진행했다. Grok 검토나 9,119개 전체에 대한 두 모델 전수 검토를 수행했다는 의미는 아니다.

## 수정 우선순위와 연계 원칙

- 먼저 `confirmed` 143개의 대상 누락, 같은 문장에 다른 답, 조건·결론 동시 가림을 고친다. 연산·대상·범위는 본문에 남기고 학생에게 요구하는 답의 종류를 분명히 한다.
- `needs_review` 173개는 문항별 근거를 보고 결정한다. 단순 문자열 규칙으로 한꺼번에 교체하지 않는다. 장문 설명을 평가하려는 경우에는 짧은 단어 빈칸과 다른 응답 형식을 검토한다.
- 실제 수정 시 기존 개념 ID를 유지하고, 개념백지와 교재 제작에서 사용하는 원고·동기화 해시·학생지·정답지를 함께 검증한다. 이번 보고서의 수정 방향은 최종 교정 원고가 아니다.
- 모호한 문항의 오답을 학생의 개념 부족으로 바로 확정하지 않는다. 선수 복습·맞춤 문제 제시와 연결하려면 문항 명료성과 학생 답안 근거를 함께 확인해야 한다.
