OS `prefers-reduced-motion: reduce`를 OR로 읽는다. 같은 화면의 설정 변경,

기기 설정은 학생 기록이나 SRS 계약에 들어가지 않는다.

코스 자동 넘김은 이 구독을 쓰지 않고 OS만 별도로 읽었다. 탐험은 저장 응답을
받은 뒤 공통 설정과 관계없이 보상 효과와 같은 1,200ms 타이머로 다음 상태를
그렸다. 따라서 앱 reduce/OS full에서 두 화면이 자동으로 넘어갔다.

- 코스: 기존 `useLearningMotion().reduceMotion`을 사용한다. 정답·선택형/터치형·
  후속 풀이 없음 등 기존 조건을 보존하며, 앱/OS 어느 쪽이라도 reduce면 자동
  이동하지 않는다. 다음 단추·Enter·2초 타이머는 한 번만 진행한다.
- 탐험: 이미 저장한 응답의 **화면 이동만** 보류한다. 정답만 2,000ms 뒤 진행하고,
  기존 확인 단추 자리에 같은 스타일의 «다음 문제»·Enter를 연결했다. 자동 대기
  중에도 수동으로 즉시 넘길 수 있다. 줄이기 변경 시 타이머가 취소되며 단추는
  남는다. 줄이기를 끄면 새 2초 대기를 시작한다.
- 첫 오답의 다시 풀기·두 번째 오답의 풀이·«알겠어요» 저장 흐름은 그대로다.
  오래된 응답에 오답 피드백만 있는 경우도 자동으로 넘기지 않는다.
- 나가기·언마운트는 남은 탐험 이동을 버린다. 다음 문제로 간 뒤에는 이전
  타이머가 다른 상태를 넘기지 않도록, 보류한 콜백을 실행 전에 비운다.
- 직접 입력/자기 확인의 기존 수동 다음, 교사의 자동 학습 설정·회차 시작 조건은
