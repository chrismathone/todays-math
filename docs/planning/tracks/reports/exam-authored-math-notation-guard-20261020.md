# 제작 수식의 명령 기호 손실 보류

노변 21번 새 초안의 수식 목록에서 `\sqrt`·`\ldots` 일부의 역슬래시가 빠졌다. 수식 렌더러는 `sqrt2` 등을 문자 변수의 곱으로 해석해 오류 0을 반환했지만 실제 화면은 의도한 제곱근 목록이 아니었다. 직접 화면 확인에서 발견했고, 실패 r1을 보존한 채 새 ID·본문 digest의 r2를 만들었다. 독립 풀이자에게는 고친 r2만 제공했다.

동일한 제작 실수를 줄이기 위해 `authoredMathNotation.mjs`를 추가했다(U47). 달러 기호로 구분된 수식 안에서 역슬래시 없이 쓰인 알려진 `sqrt`·분수·말줄임 명령 후보를 찾는다. 일반 본문과 의도적인 TeX 텍스트 묶음은 구별하고, 경고에 학생 면·토큰·위치를 남긴다. 이 규칙은 전체 TeX 문법·수학 의미·그림 문자의 검증기가 아니며 자동 수정도 하지 않는다.

새 검수 묶음을 만들 때 경고가 있으면 학생 버전을 고치기 전 봉인을 차단한다. 기존 잘못된 초안은 바이트를 바꾸거나 읽기를 막지 않고, 이전 보고서의 true 플래그만으로 수학·학년·내용 통과 수가 늘지 않도록 한다. 출처·권리·유사성·native·분류의 기존 관문도 유지한다. 이 보류가 없는 것만으로 수학·학년 검수를 승인하지 않는다.

회귀 검사에는 실제 누락 사례, inline/display 수식, 여러 줄, 분수와 근호, 일반 본문, 텍스트 묶음과 중첩 괄호, 이스케이프 달러, UTF-16 위치, 과거 true 보고서, 파일을 바꾸지 않는 freeze 차단을 포함했다. 관련 Node **10파일 130검사 통과**, 실패·건너뜀 0이다. [실행 증거](../../../../.qa-artifacts/exam-resume-20261008/engine-upgrade-20261019/authored-notation-validation-r1.json)는 소유 코드의 전후 해시와 현재 125개 선택본·새 2개 작성본에 경고가 없고, 실패 21번 r1의 네 누락을 실제로 검출했음을 기록한다. 전체 앱 검사로 확대하지 않는다.

새 학생 버전과 정답·해설은 별도의 새 독립 풀이·현재 보고서에 연결한다. 이 코드 보강은 문항·그림·자료표 수에 추가하지 않는다. 운영 쓰기·배포·승인 관문 해제는 없다.
