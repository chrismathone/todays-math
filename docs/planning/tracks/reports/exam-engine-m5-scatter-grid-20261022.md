# M5·M18 선택형 정수 모눈 렌더

`elem-1/scatterPlot`에 선택 항목 `gridStep`을 구현했다. 이 항목을 생략하면 기존 렌더 경로를 그대로 실행한다. 기존 산점도 9개는 Python 원본 SVG와 실제 앱 엄격 렌더 SVG에서 각각 변경 전 바이트를 유지했다. 현재 문형의 발문·수치·정답·해설·어댑터는 바꾸지 않았으며 좌표 목록도 남아 있다.

선택형 경로는 모눈 간격·두 축 범위·주 눈금을 유한한 정수로 받고, 모눈 간격이 범위와 주 눈금을 정확히 나누는지 확인한다. 모든 점은 두 축 최솟값에서 출발한 교점에 놓인 서로 다른 정수 좌표여야 한다. 점을 옮기거나 반올림하지 않는다. 축마다 최대 40칸, 최소 화면 칸 폭 8을 적용하며 담을 수 없는 비율·밀도는 거부한다. 0.01 단위로 고른 같은 칸 크기를 가로·세로에 사용하므로 직렬화된 칸도 정사각형이다. 주 눈금만 숫자를 표시한다. 이 기능은 소수 모눈 전반을 지원한다는 계약이 아니다.

축 이름은 그림 위·아래 별도 줄에 둔다. 과목과 단위를 오른쪽 여백에 몰아 넣어 그림이 지나치게 좁아지는 것을 피한다. 출력 위치의 글자 상자끼리, 점끼리, 점과 글자 사이의 간격을 검사한다. 폭 표 기반의 한글 상한 검사를 실제 브라우저 글꼴 실측이라고 부르지 않는다. 글자나 점이 들어가지 않으면 범위·자료·숫자 눈금을 조용히 바꾸지 않고 오류로 돌린다.

첫 후보는 모눈 그룹을 잘못된 `data-grid="1"`과 여러 선 요소로 출력해 실제 보안 정제에 걸렸다. 기존 보안 규칙을 유지하고, `graph_scene.grid_svg`의 **위치·칸 크기·칸 수 6개 값과 단일 path 배경**을 공유하도록 수정했다. 정제기·vendor·기본 graph 렌더는 변경하지 않았다. 실제 공개 렌더 시험 10개와 관련 7파일 190개, Python 11개 시험 메서드가 통과했다. 변경 TypeScript 1루트와 ESLint 1파일 오류·경고도 0이다. 카탈로그는 실제 허용 키와 함수 설명에서 재생성했다.

음수 세 자리 눈금을 10 간격으로 준 기술 견본은 글자 간격 검사에서 거부됐다. 이 실패를 보존하고 10 간격 거부를 검사에 남겼다. 별도의 20 간격 견본은 좌표 복원 검사를 통과했다. 사용자에게 주어진 10 간격 자료를 엔진이 임의로 20으로 바꾼 것이 아니다. 처음 PNG 도구는 로컬 Node 패키지가 없어 실패했으며 설치하지 않았다. 기존 vendor의 `svg_to_png_bytes`를 사용했고, 투명 PNG와 흰 배경 미리보기 사본을 구분해 보존했다.
