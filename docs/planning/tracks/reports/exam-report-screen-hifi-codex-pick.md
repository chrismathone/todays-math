**추천: H1 «상태 배지 · 문장 아래».**

원장님이 고른 A의 작업 순서를 가장 그대로 유지한다. 왼쪽에서 점수·확정 상태를 훑고, 오른쪽에서 지면을 확인한 뒤 문장을 쓰고 확정한다. 문장 칸이 미리보기 아래의 온전한 폭을 사용하므로 옆 칸을 확보하려고 지면이나 글 칸을 좁히지 않는다. 반 전체 설정·인쇄와 학생 한 명의 확정도 자리가 분리된다. 저장 실패와 다시 확정 안내는 입력·실행 단추 가까이에 남는다. 기존 작업실의 글꼴·제목·단추와 같은 위계다.

| 안  | 약점                                                                                                                                                          |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| H1  | 문장을 쓰려면 미리보기 아래로 내려갈 수 있다. 긴 지면 띠와 짧은 높이에서 입력·확정까지의 거리를 실제 화면으로 확인해야 한다.                                  |
| H2  | 점수는 세로로 비교하기 쉽지만 상태를 글자로만 구분해 다시 확정 대상이 덜 두드러진다. 좁은 목록에서는 세 열의 이름·상태가 서로 폭을 쓴다.                      |
| H3  | 지면과 문장을 함께 보기 좋지만 두 칸의 폭을 동시에 확보해야 한다. 사이드바·브라우저 확대가 있는 작업실에서는 아래 배치로 바뀌는 폭을 확인해야 한다.           |

학생이 많으면 어느 안이든 공용 고르기 창을 쓴다. 문장 없이 확정·확정 전 인쇄 허용·기본 인쇄 범위는 이미 정해진 조건으로 유지했다. 지면 모양은 모든 안이 같은 H1이다.

이 선택은 코드·구조 검토에 따른 형태 의견이다. Chromium 실행·로컬 서버·Safari 접근이 차단되어 실제 브라우저 육안 비교와 문장 상한 실측을 끝내지 못했다. **180자는 비교용 임시값이며 최종 상한의 추천이 아니다.** 상세 제약과 자체 글꼴을 포함한 실측 자의 사용법은 시안 폴더의 README에 기록했다. 지시서의 실측 완료나 운영 화면 승인을 대신하지 않는다.
