
## 문 36 — 행렬 · ㉰ 긴 해설 · 객관식 · `engine-high:공통수학1|행렬|11|s20261008|v10|객관식` · 심화하

```
행렬 $A=\begin{pmatrix}0&1\\-1&-1\end{pmatrix}$에 대하여 행렬 $A+A^{2}+A^{3}+\cdots+A^{11}$의 모든 성분의 합을 구하시오.

② $-3$
③ $-1$
④ $-2$
⑤ $0$
```

답: ④

```
$A^{2}=\begin{pmatrix}0&1\\-1&-1\end{pmatrix}\begin{pmatrix}0&1\\-1&-1\end{pmatrix}=\begin{pmatrix}-1&-1\\1&0\end{pmatrix}$
$A^{3}=A^{2}A=\begin{pmatrix}-1&-1\\1&0\end{pmatrix}\begin{pmatrix}0&1\\-1&-1\end{pmatrix}=\begin{pmatrix}1&0\\0&1\end{pmatrix}=E$
$A+A^{2}+A^{3}=A+A^{2}+E=\begin{pmatrix}0&0\\0&0\end{pmatrix}=O$이므로
$A+A^{2}+A^{3}+\cdots+A^{11}=A+A^{2}=\begin{pmatrix}-1&0\\0&-1\end{pmatrix}$
따라서 모든 성분의 합은 $-1+(-1)=-2$
```
