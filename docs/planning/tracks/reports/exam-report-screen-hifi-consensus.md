## 2차 — codex 가 실측을 보고 H3 로 옮겼다

**합의: H3 «문장 옆에서 쓰기»** + H1 의 목록 배지 줄 · 위쪽 인쇄 묶음. 구현에서 지킬 것:
1. 나란히 놓는 기준은 오른쪽 칸의 **내부 가용 폭**(썸네일 최소 폭 + 간격 + 문장 칸 320px)으로 — 1040 × 760 에서도 확정 단추까지 첫 화면에 드는지 다시 잰다. 그보다 좁으면 H1 배치.
2. 문장 상한 180자는 임시값 — 실제 H1 지면(자체 글꼴 PDF)의 줄바꿈 · 넘침으로 재서 정한다. 작은 썸네일에서 못 읽는 것은 지면 띠의 «크게 보기».
3. «이 학생 확정»은 문장 저장을 포함한다고 문구로 밝히고, 저장이 실패하면 확정하지 않는다.
