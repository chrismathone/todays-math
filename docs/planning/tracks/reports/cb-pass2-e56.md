### 자가 재지 않아 따로 본 것

- **단위 · % · 기호로 끝나는 수식 뒤 조사** — `josaFaults` 의 판정 밖이다. 읽는 소리로 맞췄다: 미터 · 리터 · 퍼센트 · 도 · 네모 · 세모는 받침 없음, **킬로그램만 받침**(`$9\,\mathrm{kg}$을`).
- **핵심어 괄호 바로 뒤 조사**(`{$\frac{1}{4}$}을`) — 자는 괄호를 걷고 재므로 같은 규칙으로 맞췄다.
- 수식 밖에 남은 영문자 · 기호를 전부 뽑아 봤다 — 남은 것은 항목 이름 A/B/C 와 글 쌍점(«예:» · «원주율:») · 구분 빗금(«A / B / C»)뿐이다.

## 5. 어떻게 했나

- 파일을 통째로 다시 쓰지 않았다. 스크래치 스크립트가 TypeScript 구문 나무에서 «읽는 글» 문자열(개념 · ○× · 적용 · 그림 물음 · 그림 줄)만 골라 수식 밖 글을 바꾸고, `id` · 소단원 열쇠 · SVG · 이름표는 건너뛴다.
- 소단원 묶음으로 나눠 넣었다 — 묶음마다 바뀐 줄을 전부 읽고 자를 돌렸다: e5 841 → 672 → 508 → 315 → 76 → 0 / e6 751 → 577 → 371 → 182 → 0.
- 기계가 틀린 곳은 손으로 고쳤다: 잘못 묶인 나열 3곳(`$6$과 $3,\ 8$과 $5$` 같은 것) · 대분수를 감싼 괄호 1곳 · 식 밖에 홀로 남은 ○ 1곳 · 낱말 식 8곳 · 등식 끝 세는 말 3곳 · 기호 «:» 4곳 · 홀로 선 단위 1곳.
- 스크립트는 세션 스크래치 폴더에 있고 저장소에 넣지 않았다(제 은행 파일과 보고서만 고친다).
