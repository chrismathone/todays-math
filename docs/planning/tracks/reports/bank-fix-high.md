## 지적별 수정과 TDD

### HIGH-EQ-001 — 여러 가지 방정식 14, mode 2

씨앗 150은 두 식이 `x²+kx−3k=0`, `x²−k²−5k=0`이고 기존 답은 4였다. k=0에서는 두 식이 모두 x²=0이므로 서로 다른 공통근은 역시 하나이고, 실제 답은 0과 4 두 개였다.

- 일치하는 k=R에서 판별식이 0인 매개변수 조합만 제외했다.
- 기존 검산에서 일치하는 식을 무조건 제외하던 조건을 삭제했다. 두 식의 차를 이용해 실수 k 후보를 빠짐없이 구하고, 복소수까지 포함한 근 집합의 교집합을 센다.
- 시험: `highEquations.test.ts`의 `HIGH-EQ-001: 씨앗 150을 포함한 300판에서 일치하는 중근까지 세어 k가 하나다`.
- 수정 전 `[0,4]`로 빨강 → 수정 후 초록 → 가드 한 줄을 되돌리니 같은 두 답으로 빨강 → 복구 후 초록.
- 형제 검토: 같은 t14의 mode 0은 발문이 서로 다른 두 방정식을 명시하며, mode 1은 두 일차항 계수가 서로 다르게 생성된다. 추가 수정이 필요하지 않았다.

### HIGH-ALG-001 — 인수분해 04, mode 1

씨앗 113의 발문을 실제로 전개하면 계수 해 `(3,1,3)`과 `(1/3,9,3)`이 모두 가능하고, 묻는 값은 각각 1과 19/3이다. 정수 조건만으로도 충분하지 않다. `(x+y+1)(x−y−1)`은 `(a,b,c)=(1,1,−1)`과 `(−1,−1,−1)`을 모두 허용하고 a+b−c는 각각 3, −1이다.

- 주어진 인수형의 두 실수 계수 후보는 `(a,b,c)`와 `(b/c,ac,c)`이다. h=cg일 때 둘 다 가능하며, 이때 묻는 값이 달라지는 조합만 제외한다.
- **코디네이터 승인**: 계수 해의 개수가 아니라 묻는 값의 유일성을 기준으로 한다. 씨앗 86처럼 계수 해가 둘이어도 목표값이 같은 정상 문항은 그대로 둔다. 난수는 기존 식 선택까지 소비한 뒤 잘못된 조합만 제외한다.
- 기존 검산의 `a,b=1..3` 정수 격자를 제거했다. 발문의 이변수 다항식 계수를 추출하고 이차방정식을 풀어 모든 실수 계수 해를 구한 다음, 각 해에 목표식을 대입한다.
- 시험: `highFactor.test.ts`의 `HIGH-ALG-001` 두 시험(300판의 목표값 유일성, 정수 조건 반례).
- 수정 전 씨앗 113에서 `1 ≠ 19/3`으로 빨강 → 수정 후 초록 → 가드 한 줄을 되돌리니 같은 반례로 빨강 → 복구 후 초록.
- 형제 검토: t04 mode 0·2는 인수분해된 식 자체가 답이다. 인수의 순서가 달라도 같은 다항식이므로 같은 유일성 결함이 아니다.

### HIGH-ALG-002 — 다항식의 연산 07, mode 1 및 mode 2/v0

씨앗 26은 합 1, 제곱합 3, 곱 4를 제시하고 제곱들의 합에 −7을 답했다. 이 조건을 만족하는 실수 세 수는 없다.

- 합 s, 두 수씩 곱의 합 e2, 곱 e3가 정해졌을 때 삼차식 `t³−st²+e2·t−e3`의 판별식이 음수인 조합을 제외했다. 판별식이 0인 중근은 허용한다.
- 같은 전제를 쓰는 **mode 1의 두 갈래와 mode 2/v0**를 함께 고쳤다. 합·제곱합만 주는 mode 0과 합이 0인 mode 2/v1은 기존의 실수 존재 조건으로 충분하다.
- 시험: `highPolyOps.test.ts`의 `HIGH-ALG-002: 씨앗 26을 포함한 300판의 모든 조건을 만족하는 실수 세 수가 있다`.
- 시험은 생성기의 판별식 공식을 복사하지 않는다. 발문을 읽어 삼차함수의 극대·극소값을 확인하고 세 구간에서 실근을 직접 찾아, 주어진 조건과 정답에 대입한다. 여섯 갈래 모두를 밟았는지도 센다.
- 수정 전 빨강 → 수정 후 초록 → mode 2/v0 가드만 되돌리니 씨앗 0에서 빨강 → mode 1 가드만 되돌리니 씨앗 4에서 빨강 → 둘 다 복구 후 초록.

### HIGH-ALG-003 — 이차방정식 02, mode 0

씨앗 1에서 k=0이면 `x−1=0`으로 차수가 1인데 발문은 모든 실수 k에서 이차방정식이라고 불렀다.

- 발문을 «x에 대한 방정식»으로 바꿨다. 정답·해설·수치·난수 호출은 그대로다.
- 시험: `highQuadEq.test.ts`의 `HIGH-ALG-003: 300판에서 k=0의 차수와 모든 k의 공통근 조건이 발문과 맞다`.
- 발문의 식을 읽어 a,b를 연립방정식으로 유일하게 구하고, k=0을 포함한 값에서 차수와 주어진 근을 검사한다.
- 수정 전 k=0의 차수 `1 ≠ 2`로 빨강 → 수정 후 초록 → 문구를 되돌리니 같은 이유로 빨강 → 복구 후 초록.
- 형제 검토: 이차방정식 06의 항상 중근인 꼴과 항등식 03의 매개변수와 무관한 근인 꼴은 x²의 계수가 항상 1이다. 같은 누락이 없었다.

## 원장님께 물을 것

- 인수분해 04의 일부 정상 문항은 가능한 계수 해가 둘이어도 목표값은 하나다. 정상 산출 보존을 우선해 해설의 «따라서 a=…, b=…, c=…»를 유지했으나, 이는 유일한 계수 해로 읽힐 수 있다. 예: 씨앗 86의 `(a,b,c)=(1,2,1)`과 `(2,1,1)`. 추후 해설을 «한 가지 인수분해에서 …이고, 다른 경우도 구하는 값은 같다»처럼 보완할지 확인이 필요하다.
- 그 밖에 이번 범위에서 확정하고 미수정으로 남긴 수학 결함은 없다. DB 적재·원본 색인 추출기·타 트랙 자료는 이번 작업 범위 밖이다.
