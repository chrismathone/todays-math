# 연산 유형 미리보기 전환 회귀 수정

2026-11-14, `2144f4bef51d67b427095548858c518cb8ace06a` 위에서 확인했다.

숫자 유형의 미리보기가 열린 상태에서 바로 도형 유형으로 포인터를 옮기면
다음 미리보기가 열리지 않았다. 이전 카드의 document pointermove 리스너가
React effect 정리 전에 실행되면서 새 카드에 예약한 타이머까지 취소했다.
열기를 예약한 카드 ref를 함께 확인해 이 전환을 유지한다. 카드 밖으로
계속 이동하면 예약을 취소하며 기존 Escape·클릭·스크롤·필터 변경 처리는 유지한다.

- 수정 전 회귀 테스트: 6개 통과, 새 직접 이동 테스트 1개 실패.
- 수정 후 컴포넌트 테스트: 8개 통과. 직접 이동과 예약 중 영역 이탈을 추가했다.
- 변경한 두 파일 ESLint와 `git diff --check` 통과.
- 실제 React 컴포넌트를 띄운 격리 Chromium에서 숫자 → 도형 직접 hover,
  키보드 초점·Tab 이동, Escape 닫기를 확인했다. 1697×875와 390×844에서
  도형 tooltip은 화면 안에 있었고 초점 카드의 `aria-describedby`와 연결됐다.
- 같은 격리 화면에서 저장 형식 v1/v2의 읽기 전용 문서 미리보기와 정답이
  변조된 payload의 차단 안내를 확인했다. 런타임 오류와 fixture 변경은 없었다.
- 숫자 예시까지는 무거운 도형 모듈 요청이 없고 도형 예시를 열 때 요청됐다.
  문서 미리보기 모듈도 해당 문서를 열 때 요청됐다.
