# 극값 관계 역추론 U49 · 인쇄 조건 검산 분리 U50

최댓값과 최솟값의 차이를 결과로 묻는 방향을 뒤집어, 일부 자료와 그 차이를 주고 지워진 최솟값을 복원하는 내부 factory를 구현했다. `number.inverse-extreme-range`를 53번째 요구 유형으로 추가하고 기존 52개 순서는 보존했다. `study-middle-inverse-extreme-minimum`은 유한 영역 24개 문장과 6개 정확한 답을 만든다. 엔진 조합을 수동 작성 문항이나 새 blind 풀이 수에 더하지 않는다.

공개된 네 수 중 첫 수가 최댓값임을 정수 경계로 확인하고, `최솟값 = 최댓값 − 주어진 차이`로 복원한 뒤 실제로 나머지 모든 수보다 작은지 확인한다. 제4자료가 양수인 4조합과 음수인 20조합을 모두 검토했다. 일반 함수의 극값 정리나 고등 무리부등식은 쓰지 않는다. 실제 캡처 Unit UUID `28032bdd-3db3-4788-9e7a-2f1909233fdb`와 제곱근·실수 대소·근호 계산 선수 근거를 연결했다. 2025 출처·2026 중3 연습은 2015 교육과정의 해당 학습 이후 조건이며, 2027 중3/2022 교육과정의 배치는 보류다. 실제 live family와 출처 동일성·권리·유사성·native 승인은 별도 보류다.

생성기와 검산기의 계산 경로를 감사하면서 두 factory의 검산기가 생성기의 답을 다시 참조하는 결합을 발견했다. 보존한 v1의 정상 출력 69개(최솟값 24·제곱근표 45)는 모두 맞았다. 그러나 메모리에서 생성기 답만 0으로 바꾼 실험에서는 잘못된 69개 답이 통과했다. 이는 실제 69개 출력이 오답이었다는 뜻이 아니며, 기존 정상 답 검사만으로 발견하지 못한 검산 독립성 결함이다.

두 factory를 v2로 올렸다. 최솟값 검산은 실제 인쇄된 최대항·차이의 근호 계수와 상수항을 읽어 직접 뺀다. 제곱근표 검산은 인쇄된 결과에서 유일한 열을 찾고 그 열의 실제 입력 셀과 답을 비교한다. 표 반올림은 생성기의 제곱근 탐색과 별개로 BigInt 제곱 중점 부등식을 검사한다. 현재 본문·답·해설·매개변수·형식·난도·도형은 보존한 v1의 69개와 정확히 같으며 버전과 검산 경로만 달라졌다. 정규 본문·해설의 일치는 여전히 검토한 유한 문장과 비교하므로, 임의의 새 해설을 증명하는 일반 수학 채점기로 확대하지 않는다.

독립 Codex 작업자는 실제 현재 소스 16개의 전후 해시를 확인하고 정상 69개, 변조 1,332개, 재현성·복사 격리·요청 주입·과거 버전 digest 대조를 자체 코드로 실행했다. 같은 답 0 변조 69개와 표 반올림을 1 올린 45개는 v1에서 허용되지만 현재 v2에서는 전부 거부됐다. 표의 225개 셀은 Decimal/Fraction 계산과 독립 제곱 중점 증명으로 확인했다. 이 실험은 명시적인 제한 registry와 mock을 사용했으며 실제 DB·HTTP 인증·전체 registry·native 인쇄 경로 실행이 아니다. 과거 digest 대조도 현재 정책에 v1 버전 자료를 재구성한 실험으로 범위를 기록했다.

두 factory는 계속 내부 검토 전용이다. 호출자가 ID·버전·형식·승인·신뢰도·native 표시를 바꿔도 공개 라우팅의 고정 보류가 남는다. 독립 감사의 두 family·네 형식 56대조는 factory 호출 0, 제한 catalog 비노출·coverage 불가를 확인했고, 중1 요청의 학년 강제 제외가 우선한다. 이 검사로 학년·권리·출제를 승인하지 않는다.

부모 검사는 v1 관련 14파일 266개 통과 후, 실제 v2 변경의 2파일 17개 및 타입·lint를 다시 통과했다. 파일별 최신 집계가 14파일 266개이며 현재 버전으로 한 번에 14파일을 재실행했다는 뜻은 아니다. 소유 코드의 전후 해시를 보존했다. 검증 안내기의 절대·상대 경로 별칭 확인 오류는 시험 시작 전 실패로 남겼고, 정규화한 경로로 별도 새 실행을 통과했다.
