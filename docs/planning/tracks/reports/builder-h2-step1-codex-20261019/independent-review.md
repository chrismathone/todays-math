## 실행 범위와 공유된 검증 결과의 구분

독립 실행은 기존 설치된 TypeScript/React/jsdom/Testing Library를 이용한 **메모리 전용 DOM 재현**이었다. 소스 변환·모듈 로딩을 메모리에서 수행하고 허용한 시안·순수 계산·공용 선택기·시드만 읽었다. fetch 호출은 0이었다. CSS는 클래스명으로 대체했고 native dialog는 shim을 사용했다. 따라서 이 독립 실행을 실제 브라우저의 폭 측정·focus trap 통과 근거로 확대하지 않는다.

다음은 사용자가 전달한 **주 에이전트의 검증 결과**이며, 독립 검토자가 다시 실행한 결과와 구분한다.

- 전용 19시험과 전체 type-check 통과.
- 10/18 standalone과 현재의 1440/390px 대조: 기존 8화면 DOM 동일, H2-2 전체 PNG SHA256 동일.
- 1440/1050/1040/768/390/320px 및 짧은 높이의 560조합 1차 실측: 오류 0.
- native modal Tab/Shift+Tab·Escape·초점 복귀 검사를 추가하여 최종 재실행 중.

마지막 native modal 재실행의 최종 종료 결과는 이 보고서 작성 시점에 전달받지 않았다. 이것을 실패나 잔여 결함으로 단정하지 않는다. Chromium에서 Tab 경계에 잠시 body가 activeElement로 관측되는 것만으로 modal 이탈 결함을 확정하지 않으며, 다음 Tab의 modal 복귀와 실제 배경 조작 가능 여부를 함께 확인해야 한다.
