# 관리 콘솔 후속 수정 · 영어 탭 점검 (2026-10-04)

## 사용자에게 보인 문제와 원인

- 계정 상세 저장의 403: 운영 오류 기록의 실제 응답은 ‘연동 계정의 소속과 관리 권한은 연결 관리에서 확인해 주세요.’였다. 클라이언트가 모든 403을 로그인 오류 문구로 덮어쓰고 개인 메뉴 편집까지 잠갔다.
- 반·학생 연결: 운영 DB에 교사 담당 관계와 학생 수강 관계가 있는데 계정 상세에는 자료와 활동 기록만 표시됐다. 관리 동기화 반의 소유자와 담당 교사는 다를 수 있다.
- 영어 화면 탭: 자료은행과 문제 만들기는 밑줄 형태, 듣기는 테두리 버튼 형태였다. 사용자는 듣기의 테두리 버튼을 기준으로 통일하도록 지정했다.
- Pretendard preload: 브라우저가 사용 지연 경고를 표시했다. 경고 자체는 API 실패와 별개이며 실제 사용 여부를 검증한 뒤 변경을 판단한다.

## 반영

- 계정 응답에 서버가 계산한 `branchAssignmentLocked`를 제공한다. 현재 관리 연동이 소속·직책을 관리하면 해당 선택기를 잠그고 변경 위치를 설명한다. 이름·이메일·개인 메뉴 편집은 유지한다.
- 계정 설정/비밀번호의 업무 제한은 `ACTION_NOT_ALLOWED`로 구분하고 서버의 이유를 표시한다. 실제 인증·관리 권한 거절의 복구는 유지한다. 기존 연동 잠금, 마지막 원장 보호, 소속·수정 시각 충돌 검사는 그대로 적용된다.
- 계정 상세에 `반·학생` 탭을 추가한다. 반과 학생은 독립적으로 20개씩 읽고, 로딩·빈 목록·오류·재시도를 구분한다. 계정 또는 지점 전환 시 이전 응답이 새 목록에 섞이지 않는다.
- 조회 API는 최고관리자 전용 `GET /api/admin/users/[id]/relations?branchId=UUID|unassigned&kind=classes|students`다. 현재 지점과 대상 계정의 소유 또는 유효한 담임·수업 담당·열람 위임 관계를 함께 검사한다. 학생은 현재 수강 관계로 조회해 다중 반 학생을 한 번만 집계한다. 같은 지점·연동 ID, 날짜, 종료·퇴원·휴원 조건을 검사한다.
- 관계 열람은 저장된 상태만 읽으며 원본 동기화나 권한 갱신을 실행하지 않는다. 학생 비밀번호·로그인 ID·원본 보고서 등 불필요한 정보는 조회하지 않는다. 계정 사용 설정과 실제 접속 가능 여부를 구분해 설명한다.
- 공통 `EnglishTabs.module.css`로 자료은행·문제 만들기·듣기의 높이 44px, 반경 8px, 선택한 탭의 파란 테두리/글자와 옅은 배경을 통일한다. 기존 탭·버튼 의미, 키보드 이동, 저장 중 이동 제한은 유지한다.
- DB 스키마 변경과 운영 데이터 수정은 없다.

## 검증

- 통합 main: 계정 편집·직렬화·비밀번호·지점 배정·새 관계 조회·기존 상세 UI 등 9파일 147개 통과.
- 별도 관계 작업: 테넌트/관리 관계/UI 11파일 174개, API/관문/계정 접근 3파일 49개 통과.
- 별도 영어 작업: 관련 UI 7파일 122개, 브라우저 탭 상태 9개와 320px 줄바꿈 확인. Pretendard의 실제 사용자 정의 글리프 사용 확인.
- `npm run build`: Next.js 16.3.0 Turbopack 컴파일·전체 타입·페이지 생성 완료.
- 별도 실제 PostgreSQL + 운영 모드 브라우저: 대상 교사의 반 3개·고유 학생 32명, 학생 20/12 페이지, 다른 지점 요청 404, 공유 반 담당 관계와 다중 반 학생 확인. 소속/직책 선택기는 잠기고 이름/개인 메뉴는 계속 편집 가능. 데스크톱·390px 모바일 문서 넘침 없음.
- 운영 빌드 브라우저: 계정 제목의 실제 사용자 정의 `Pretendard Variable` 글리프를 CDP로 확인. 7초 관찰 중 console 및 Chrome Log의 경고 0개. 로더의 preload는 의도한 글꼴에 적용되어 있으므로 유지했다. 사용자가 본 일시적 경고를 모든 네트워크·브라우저 조건에서 재현하지 않았다는 한계는 남는다.
- 자료은행·듣기 선택 탭의 실제 계산 결과는 모두 높이 44px, 반경 8px, 동일한 파란 테두리/글자와 옅은 배경. 클릭 시 기존 `aria-selected`/`aria-pressed` 상태 전환 확인.
- 근거는 로컬 `.qa-artifacts/branch-admin/followups-browser-result.json`, `build-followups.log`, `screens/followups-*.png` 및 별도 Orca 작업 검증 자료에 보존했다.
