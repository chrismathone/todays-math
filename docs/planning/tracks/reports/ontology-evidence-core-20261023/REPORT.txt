Model boundary
Same provider configuration, allowlist, API transport, admission, privacy filter,
20-second signal, max output 700, singleAttempt and suppressUpstreamDetails.
The prompt contains bounded aliases (at most 64 code facts) and allowed references,
not student/teacher identity, raw session IDs, exercise text, answers or solutions.
The model selects only fact/evidence/candidate IDs and a closed intent. The parser
rejects unknown fields/IDs, duplicates, missing citations, mismatched snapshot,
ineligible candidate endorsements, code fences and contradictory selections.
The composer only returns canonical snapshot.facts entries, never model prose,
numbers, relations or a repaired selection. Shared structural/reference validation
runs before projection delivery, prompt generation, selection and composition.
Catalog membership and strict typing are NOT semantic relevance/completeness proofs.

Context can cite a source-backed observation without endorsing candidates. Explanatory
facts for ineligible candidates have no endorsement candidateIds. No-record/plan
context facts remain selectable independently of candidate eligibility. Unsupported
date/section/diagnostic questions have a code-owned scope-limitation fact; the model
cannot issue a date calculation, dynamic database query or new relationship.

Concurrency and authorization
V2 alone reads current uncached local user/branch menu/status/role/session facts before
learning records. JWT admin normalization is matched exactly and existing menu/route
policies are reused. A narrow read-only ownership adapter reuses legacyClassInScope,
membershipAllows, currentClassGrantAllows, currentEnrollmentWhere and accountUsable
with current local class, membership and enrollment rows. No source refresh or
synchronization writer was added or forced. Existing common authentication may still
perform its own established synchronization; this feature does not create that work.

After inference the endpoint rechecks current authorization, ownership/enrollment,
student class/branch, class owner/grade/permission context, revision and stored course.
Revocation returns safe 403/404, including a sessionVersion change. Still-authorized
record/context change returns 409 CONFLICT with no stale data. Time alone does not
conflict: the first now is frozen for the observation window and new asOf-dependent
snapshot hashes are not compared. Admission releases after success, parse/provider
failure, timeout, cancellation, authorization denial and conflict. There is no automatic
model POST or retry. The final local reads are not an atomic transaction with response
delivery, and upstream managed-source changes are only as current as local leases.
