교과서 잠금475문항 복구 경로 검토 — 2026-10-09

결론: 교정·기존 사유 재검토 후보369건, 새 발문·조건·보기 재작성 후보61건, 그림·원본 대응 추가 검토45건이다. 합계475건이며 출제 승인 또는 사용 가능 확정 수가 아니다.

검토 방법과 한계
475행의 본문·정답·해설·그림 개수·기존 사유를 순서대로 읽고 개별로 경로를 분류했다. 키워드 빈도만으로 분류하지 않았다. 모든 수학 정답과 모든 그림의 최종 출제 검증은 별도 단계다.
원본 HWP 및 모든 이미지에 대한 재검토를 완료하지 않았다. 기존 사유가 현재 본문과 어긋난 경우도 있다. 그림 검토45건은 폐기 판정이 아니다.
사용자가 허용한 이미지 생성은 복구 경로를 늘린다. 새 조건·새 그림은 새 출제문항으로 추적하고, 정답에서 추정한 조건을 원래 사실처럼 복원하지 않는다.

대표 발견
- J10102-A61-001: 정답 없음 사유와 달리 현재 정답6과 해설이 있다.
- J10605-A77-001: 수학 검토자가 실제 그림을 확인한 결과 현재48+8π가 맞고, 이전 사유80+8π가 틀렸다. 해설 보강 후보.
- HC10230-A03-001 / J10201-B08-001: 4지선다만으로⑤누락을 확정하지 않는다.
- HC20208-A07-001 / HPS0101-A32-001 / J20903-A83-001: 수치 배열이 다르거나 음수라는 이유만으로 잘못 옮긴 오답이라고 확정하지 않는다.
- HC20209-A08-001 / HC20311-A04-001 / J20903-A18-001: 현재 정답 유일성이 없어 새 질문·조건·보기가 필요하다.
- HPS0202-A15-001: 복원추출 명시 필요. HPS0304-A30-001:0<p<1 명시가 없으면 p=0도 식을 만족한다.
- J20103-A91-001:3.141592…만으로 비순환임을 단정할 수 없다.
- J20903-B39-001: 카드쌍을 균등 선택하는 경우와 만들어진 두 자리 정수를 균등 선택하는 경우의 표본공간은 다르다.

실행 시 경계
1. 수정된 본문·정답·해설·그림을 묶어 버전/검토키를 새로 만든다. 원문에 없던 조건과 선택지는 새 출제 문항으로 추적한다.
2. 정답 계산 외에 모든 보기의 참/거짓, 정의역, 정답 개수, 단위를 검사한다. 실제 출력에서 빈칸·수식·그림 표지·정답 노출을 확인한다.
3. 그림은 기존 자산 재연결·무관 자산 제외를 우선 검토한다. 새 그림은 점·선·수치·번호와 조건을 검증한다.
4. 이 보고서는 잠금 해제 명령이나 승인 기록이 아니다. DB와 앱은 수정하지 않았다.
