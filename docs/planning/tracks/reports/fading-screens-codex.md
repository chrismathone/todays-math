# «오늘의 기억» 학생 화면 — 시안 반영·검증

2026-10-06 · Codex ① · `srs`

학생 앱, 메모리 측정 화면, 작업실 미리 보기 알맹이를 구현했다. 덧붙임 1~3을 반영해 시안의 짜임과 부품을 맞췄다. 학생 화면의 규칙·일정·숫자는 `src/lib/fading`과 계약을 그대로 사용한다. [목록·단원·통계](fading-catalog-stats-codex.md)는 리드가 Codex ③에 분담했고 [교사 Wire 5안](fading-teacher-wire.md)은 별도 Codex가 완료했다.

둘째 대조 뒤 홈 정리(13:04 판): 첫날·다 한 날에는 안내·첫 개념 또는 다음 복습·자율 학습까지만 그리고, 추가 지표 격자·빈 대기열·단계 타일·PC 기록 영역을 싣지 않는다. «개념 강의»·«영어듣기»는 맨 아래에 둔다. 매일·밀림·복귀 홈은 이전 구성을 유지한다. `first-side-by-side.png`와 `done-side-by-side.png` 두 그림만 다시 받았다. 변경 뒤 두 상태×네 폭의 **8장면**에서 넘침·작은 컨트롤·작은 글자·수식 잘림·주 단추 가림·콘솔 오류가 모두 0이었다(`measurements-first-done.json`). 자기 시험은 **20개 통과·1개 제외**: 리드 지시로 Codex ③이 고치는 «복습일 전의 연습…» 시험은 수정하거나 실행하지 않았다. 변경 파일 ESLint 0.

## 보는 주소

- `http://localhost:3443/dev/fading`: 2단계부터 조작하는 실제 앱.
- `?scene=step1|step2|step3|step4|rating`: 정독·소거·백지·평가.
- `?scene=first|daily|done|backlog|return`: 첫날·평소·완료·밀림·복귀 홈.
- `?scene=risk-colors`: 실제 로컬 일정에서 나온 위험 세 단계의 표시 대조.
- `?scene=catalog|stats|offline|loading`: 목록·통계·연결 끊김·불러오는 중.
- `?scene=save-error|conflict`: «아직 모르겠어요» 뒤 저장 실패/409와 재시도.
- `?concept=<표본 id>`: 계산 표본으로 같은 장면을 연다.
- `?preview=1`: 390px 작업실 미리 보기 알맹이, 저장되지 않음.
- `/learn/fading`: 제품 학생 페이지. 서버 문이 꺼지면 404, 켜졌을 때도 학생 세션과 첫 비밀번호를 확인한다.

학생 메뉴 넷은 복습·소거·목록·통계다. 홈의 강의·영어듣기 카드와 학습 전환을 제공하고 풀이 중에는 탐색을 접는다. 기존 `StudentMobileNav`는 이 경로에서만 접는다. 작업실 메뉴에는 배선하지 않았다.

## 부품 값과 반응형

앱의 CSS 모듈 안에만 v2 값을 둔다. 바탕 `#f8f9ff`, 연한 면 `#eff4ff/#e5eeff`, 남색 `#080c21/#1e2238`, 초록 `#006c4a`, 민트 `#82f5c1`을 쓴다. 카드 8~14px, 빈칸·칩 8px, 아래 판 16~18px 모서리와 작은 그림자를 시안에 맞췄다. 제품 Pretendard와 시스템 Consolas를 쓰며 외부 글꼴·아이콘 요청은 없다.

문장 줄 높이는 **1.7**, 빈칸의 44px 누르는 영역과 여백이 해당 줄의 높이를 만든다. `keep-all + anywhere`로 한글 낱말을 유지한다. 폰은 아래 네 탭·세로 풀이, 768~1023px는 위 탭·세로 풀이, PC는 위 네 탭·두 단·네 단계 띠·고정 주 단추다.

위험 표시의 80%/60% 문턱은 `riskAppearance.ts` 한 곳의 **색 표시 상수**다. 복습 순서·정책을 바꾸지 않는다. 로컬 날짜만 옮겨 받은 86%·76%·15%에서 빨강(`#ba1a1a`)·주황(`#ffb95f`)·회색(`#c7c5cd`)을 확인했다.

수식은 제품 `ExplorerMath` 경로를 쓰는 `FadingMath`로 그린다. 작은 수식 글자도 실제 DOM에서 12px 바닥을 맞춘다. 그림의 원래 10/11px 글자도 이 앱 안에서 12px로 올렸다. 용어 설명은 마지막 용어부터 접어 두 줄에 맞추며 수식 중간을 자르지 않는다.

## 규칙·저장 검증

학생 API 소스는 `state/act/catalog/concept` 네 메서드만 알고 성공 응답을 계약으로 확인한다. 서버 실패 문구를 그대로 보여 주며 연결 끊김 문구는 한 곳이다. 실패한 저장 본문과 평가 요청 번호를 그대로 재시도한다. 409는 `state()`로 맞춘다.

채점은 `startFadingSession/finishReading/placeChip/giveUpStep/allowedRatings/closeWithRating`, 칩은 `chipTray`, 빈칸은 `erasedTargets`를 쓴다. 받은 traps를 항상 같이 넘긴다. 마지막 칩을 맞게 넣으면 아래 주 단추가 열리고, 주 단추로 단계를 마친 뒤에만 대조로 간다. 4단계의 틀림은 이 단추를 기다리지 않고 즉시 `miss`를 보낸다.

그림은 서버가 `fadingFigureMap`으로 고른 내용을 메모리 소스에 넘긴다. 정독과 완료 뒤 대조에서만 이름표 답이 DOM에 있고 2~4단계는 빈 점선 상자다. 그림 없는 개념에는 판이 없다. 연습은 읽기만 하며 어떤 행동도 보내지 않는다.

자기 시험 **4파일 21개 통과**. 틀림 유지·즉시 miss, 기준안 공개와 다음 단계에서 제거, 같은 단계/칩 차례 재진입, 409 맞추기, 응답을 잃은 동일 평가 요청, 복습일 전 연습, 첫날·완료·밀림·복귀 홈, 용어 누출, 추가 칩, Enter 조작, 수동 단계 마치기, 그림 이름표, 서버 문 404, API 응답·실패 계약을 확인했다. 수동 완료 변경 전 RED와 변경 뒤 GREEN도 로그로 남겼다.

ESLint 자기 파일 오류·경고 **0**. 지정 파일 어포던스 **통과**. 전체 타입 검사(힙 8GB)는 자기 오류 **0**, 범위 밖 듣기 JSON 누락 1건(`src/lib/english/listening/runtime/bank.ts:10`)이다. 전체 `lint:affordance`는 자기 오류 **0**, 범위 밖 기존 `ListeningBankMaterial.module.css:129` 1건이다. 리드와 덧붙임 3이 두 기존 오류를 별도로 기록하고 자기 파일 0이면 인수하도록 정했다.

## 실제 네 폭 측정

은행 2,040개에서 **11개**를 계산으로 뽑았다. 표적 최다 13·최소 3, 명제 최장 223자, 칩 최장 62자, 수식 표적 최다 9개, 같은 글 표적, 추가 칩, 이름표 최다 그림과 그림 없는 개념, 일반 표본이다. 실제 내용·함정·그림을 메모리 소스에 넣었다.

페이지·콘솔 오류 **0**, 외부 리소스 요청 **0**. 원시 수치·표본·캡처·실패 경위·검사 로그는 `.qa-artifacts/fading-screens/`에 있다. 설치된 agent-browser가 없어 기존 Playwright를 헤드리스로 사용했다. 새 서버를 띄우거나 기존 서버를 끄지 않았다.

## 남은 것·경계

리드의 최종 비교 그림 검토와 원장님의 교사 Wire 선택을 기다린다. 교사는 B안 추천이며 Hi-fi·작업실 메뉴 배선은 다음 단계다. 미리 보기 알맹이는 서버에서 concepts·traps·figures·today를 내려주면 쓸 수 있다. 실제 학생 API/공유 DB/서버 플래그는 실행하지 않았다. 생산 환경 검증은 이번 범위에서 하지 않았다.

기존 SRS·탐험·관문·Prisma·환경 파일·패키지·전역 디자인 문서는 수정하지 않았다. 전체 시험·변이 실험·Git 쓰기는 하지 않았다. 이 작업의 파일은 모두 미커밋이다.
