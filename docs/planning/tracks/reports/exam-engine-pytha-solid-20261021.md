# 피타고라스의 주어진 길이 표시와 공간 검산 경계

두 엔진 결함을 수정했다. 피타고라스 10번은 발문이 주지 않은 파생 길이 CA를 표시하던 대신
실제 주어진 CB·AB만 표시한다. 공간 검산은 잘못된 수치·퇴화 평면과 실패 뒤 남는 검산 등록을
차단하고, 한 번만 순회하는 조건 입력도 목록과 같은 방식으로 검사한다. 이미 출제된 문항·DB는 수정하지 않았다.

## U68 — 주어진 길이만 표시

대상은 `src/lib/middle/m2Pytha.ts`의 `2-2|피타고라스 정리|10`과 두 유형이 공유하는
`figAltitude`다. 이전에는 본문이 CB=a, AB=c를 주는데 그림은 CA=b, CB=a를 표시했다.
새 그림은 CB=a, AB=c만 표시한다. 09는 원래 주어진 CA·CB를 유지한다.
좌표·보조선·직각 표시·발문·정답·학생 해설·RNG 소비는 그대로다. 원래 CRLF도 유지했다.

examStudy의 10번 family ID는 유지하고 version을
`20261021-given-only-altitude-dimensions-r1`로 올려 구버전 recipe와 구분한다.
일반 engine-mid loader의 기존 ID가 이 revision을 포함한다는 뜻은 아니다. 기존 ID 재생성/갱신/적재는
수행하지 않는다. 새 적재는 별도 버전·새 ID·검수 원장이 필요하다.

## U69 — 공간 검산에서 잘못된 증거와 오래된 성공 차단

`vendor/figure-engine/core/figure_solid.py`의 `verify_solid`만 수정했다.
나머지 공개 계산 함수·클래스 정의는 바꾸지 않았다.

- 라벨·좌표·허용오차·주요 중간값이 유한해야 한다. 길이는 양수, 선분과 원래 다각형은 비퇴화,
  정사영 넓이는 음수가 아니어야 한다. 이 helper가 계산하는 선-평면/평면 사이 각은 0~90도다.
- 평면은 유한한 기준점과 단위 법선을 가진 `Plane`이어야 한다. 법선의 norm=1 판정은
  rel/abs 1e-9다. 임의 법선을 조용히 정규화해서 다른 입력으로 승인하지 않는다.
- 함수 진입 시 이전 등록을 삭제한다. 조건 iterable을 수집하는 도중 실패해도 과거 성공이 남지 않는다.
- 7개 조건 묶음을 한 번 tuple로 수집해 입력 검증·계산·선택적인 투영 검사가 같은 자료를 본다.
  잘못된 조건이 검증 루프에서 소비돼 실제 계산에서 사라지지 않게 한다.

| 검사 | 결과 | 해석 |
| --- | --- | --- |
| 독립 적용 전 조사 | 47항목 중 20통과·27실패 | 정상 9개 통과. 잘못된 입력 22개를 허용하고 재시도 5개가 이전 등록을 남겼다. |

## 적용 범위와 남은 관문

두 수정 모두 엔진·내부 제작 도구의 개선이다. 새 3D 선수 개념을 학생 문제에 허용하거나 전체 공간
기하·일반 수학을 증명한 것이 아니다. 중첩 점/다각형/계수는 기존 Sequence 계약을 유지하며
임의 callback sandbox를 제공하지 않는다. 극단적으로 큰 수의 비유한 계산은 보류/거부만 검증했다.
단위 법선을 요구하는 공개 계산 helper의 계약 자체를 자동 보정하지 않는다.

검산 등록은 여전히 scope/key 이력이며 SVG/본문과 수학 조건의 완전한 해시 증명은 아니다.
현재 후보·본문·답/해설·도형·독립 검산과 학년/권리/내용 상태를 별도로 연결해야 한다.
운영 적재·DB/학생 기록 수정·배포 0, 기존 82잠금/영구 제외/보정 원장과 v50 문항 집계 유지.
그림 contact/실행 예제는 기술 QA이며 승인된 문항/그림 수가 아니다.
