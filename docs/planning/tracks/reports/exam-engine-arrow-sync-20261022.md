## 결과와 경계

`graph_scene.py`의 연결/축 화살표, `elementary.py`의 오른쪽·위·아래 연결 화살표, `figure_assets.py`의 양방향 치수 화살표를 `g[data-arrow=end|both]`로 명시한다. 편집기는 번호를 매기기 전에 원래 촉을 전용 SVG marker로 옮겨 선과 촉을 하나의 요소로 다룬다. 원래 촉의 좌표·색·크기와 선 끝 밖으로 나온 거리, 양 끝 촉을 유지한다. 치수 글자는 별도 요소로 남는다.

일반 선과 삼각형의 근접성으로 화살표를 추측하지 않는다. 표시 없는 과거 저장본과 별도 곡선 지시선은 그대로다. 해당 생성 경로에서 새로 만든 그림부터 표시가 붙으며, 저장된 문항을 일괄 재생성하거나 덮어쓰지 않는다.

현재 `figureSvgEditing.ts`의 모눈/그림 조각 검증과 안정 번호 계약을 유지했다. native SVG 정제기는 `g`의 `data-arrow` 두 값만 추가로 허용한다. marker·외부 참조의 서버 입력 허용 범위는 늘리지 않았고, 더 엄격한 기존 정사각형 모눈 검사는 보존했다.
