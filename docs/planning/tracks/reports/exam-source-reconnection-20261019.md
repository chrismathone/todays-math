# Exam source reconnection — 2026-10-19

Implemented `scripts/import/exam-twin/sourceIdentity.mjs`, an offline deterministic source-byte checkpoint reusable by the exam twin tooling. It accepts one or more existing manifest paths; supports sourceFiles, inputs, and the Bumil source-files array with its explicit current_path. It reads only explicit paths, hashes exact raw bytes, checks expected SHA256 and optional byte count, records manifest digests, retains duplicate entries, and reports duplicate-byte groups. No name-based joining or relocation guessing occurs. CLI exit codes: 0 all byte matches, 1 source validation failures, 2 malformed manifests/arguments. Example: `node scripts/import/exam-twin/sourceIdentity.mjs <manifest.json> ...`.

Limits default to 512 entries and 256 MiB per source. File handles are closed; non-files, oversized inputs, read errors and metadata changes during reading fail closed. File metadata checks reduce concurrent-write risk; this is a point-in-time observation, not a filesystem lock or guarantee against subsequent changes. Content pair identity is always unconfirmed and content certification is explicitly not performed, including when a HWP and PDF have identical hashes.
