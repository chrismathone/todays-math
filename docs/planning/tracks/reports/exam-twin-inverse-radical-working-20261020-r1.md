# 正수 근호 배율 역추론 계산 도구 — 중간 기록

U57을 별도 오프라인 저작·검산 도구로 구현했다. `sqrt(mk)=a sqrt(m)`, `sqrt(s)=b/(c sqrt(s))`, `ab=R`에서 양수인 a/b/k와 양의 정수 m/s/c를 명시해야 한다. BigInt 분수로 b, a, k를 순서대로 복원하고 양의 근 가지·분모·대입 관계·존재/유일성을 확인한다. 양수 조건과 모순되는 0/음수의 곱은 해 없음으로 남기며, 퇴화된 근호·분모나 범위 밖 입력은 거부한다.

현재 새 대구동 q03의 인쇄된 세 조건을 추출해 계산한 결과가 저자 풀이와 일치했다. 이 재생은 저자 검산이며 독립 학생 풀이를 대신하지 않는다. 실제 독립 풀이 2개는 worker `efc733df1`, 부모 `f64005819`에 저자 공개 전에 봉인했고, 현재 전체 검수 중이다. 기존 v41의 선정160/독립 수학·학년159와 별도 초안2의 구분을 유지한다.

Node 16파일 179개와 관련 lint가 통과했다. 한 시험 안의 1,296개 구성된 유리수 증인은 부모 계산 검사이며, 새로운 독립 코드 검수나 문항 수로 세지 않는다. 별도 코드 검수는 대기 중이고 운영 앱의 공개 template/family에는 연결하지 않았다. 함수의 계산 성공은 학생 방법·학년·교육과정·권리·적재 승인이 아니며 해당 출력은 모두 false다. 기존 91개 엔진 파일과 현재 후보 바이트는 변경하지 않았다.

2025+ 중3의 기존 목록에서 미시도 준비 후보 79편을 명시 계획으로 고정하고 로컬 격리 추출을 이어간다. 각 편의 개별 추출 보류는 다른 편의 진행을 막지 않는다. 이 범위는 10/03 목록의 일부이며 전체 N드라이브·모든 학년·중복 제거·구성요소 검수 완료를 뜻하지 않는다. 새 Git 대상에는 코드·변형물·집계 증거만 포함하고 원문과 보정 사본은 로컬에 보존한다.
