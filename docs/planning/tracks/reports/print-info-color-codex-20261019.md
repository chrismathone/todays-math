### 첫 쪽·빈 값·수기 칸

- 일반 문제지는 첫 쪽에 상세 머리를 출력한다. 연산 출력은 회차마다 첫 쪽의 상세 머리와 정보줄이 다시 나오며, 이후 쪽은 회차 머리를 유지한다. 전용 개념·목표·전략도 상세 첫 쪽 조건을 따른다.
- `WorksheetPrint`는 문자열의 앞뒤 공백과 빈 문자열을 정리한다. 제목은 공통 제목 상태를 사용하고 비었으면 «오늘 수학 학습지», 과목은 «수학», 학년은 선택 문항의 학년, 날짜는 한국 날짜의 오늘 값으로 보충한다. 따라서 유형명이 빈 문자열이라는 이유로 실제 공통 출력에서 제목 대체가 막히는 것은 아니다.
- 템플릿의 `??` 대체값은 학교 `○○고등학교`, 학원 `수학 학원`, 시간 `50분`, 총점 `100` 등을 사용할 수 있다. 미입력 항목도 항상 빈 지면이 된다는 뜻은 아니다. 출제자·학기 등은 빈 값이면 정보줄에서 빠진다.
- 날짜 표시는 입력값이나 오늘 날짜가 있어도 꺼진 상태에서는 출력하지 않는다. 학생이 손으로 적는 «날짜 ______»는 시험일 메타와 다른 칸이다.
- 정통의 학생 학년·반·번호·이름, 모던의 반·번호·성명·감독, 워크북·유형의 이름 밑줄 등은 수기 칸이다. 출제자 입력을 감독 칸에 넣는 식으로 의미를 바꾸지 않았다.
- 시험 종류는 **기존** `src/contracts/sheetTag.contract.ts`에 «지면에 찍지 않고 양식(W6)에 담지 않는다»고 명시된 관리 태그다. `PrintMeta`에 없는 값이며, 현재 미출력은 배선 오류가 아니다. 마지막 추가 지시는 이를 바꾸는 새 요구로, 모든 제안 지면에 반영했다.

## 2. 색상 전수 감사와 실제 수정

기본 `PrintOptions.color`는 남색 `#1B2A4E`이며 별도 선택색 여덟 개를 합쳐 아홉 개다. `tokens.ts`의 템플릿별 기본 강조색 표가 현재 패널 선택 시 자동 적용되는 것은 아니다. 입력 색은 템플릿 전환 시 유지된다.

| 템플릿 | 선택색이 실제로 닿는 곳 | 검정·중립색으로 고정된 곳 |
|---|---|---|
| 평가원 | 문항 번호의 대비 보정 글자 + 공통 정보줄 | 영역 표·제1교시 경계·제목·바닥선·본문·단 구분선 |
| 정통 | 문항 번호의 대비 보정 글자 | 시험 정보표 전체 경계·회색 라벨 면·제목·학생표·점수표·유의사항·바닥글 |
| 모던 | 머리 아래 굵은 선, 평가 딱지 테두리, 학기·정보 라벨·문항 번호·쪽수의 대비 보정 글자, 공통 정보줄 | 학교명·주 제목·본문·학생표 경계·점수칸 회색 면·얇은 구분선 |
| 워크북 | 학원 첫 글자 로고 면, 번호 상자 면, 풀이 라벨의 대비 보정 글자, 공통 정보줄 | 큰 단원 띠는 검정; 문항 카드·풀이 점선·공책 줄·바닥글은 중립색 |
| 자습 | 개념 상자 테두리·왼쪽 굵은 선, 자습/개념/번호/내 정답/메모 라벨의 대비 보정 글자, 공통 정보줄 | 따뜻한 종이 바탕·주 제목·본문·모눈·정답칸·풀이칸 경계 |
| 유형 | 번호 상자 테두리, 번호·핵심 전략 라벨·PROGRESS의 대비 보정 글자, 진도 막대의 채운 면, 공통 정보줄 | 큰 PATTERN 띠는 검정; 전략 구분선·본문·빈 진행 막대·PG 쪽수는 중립색 |

따라서 «글자만 바뀐다»는 관찰은 특히 평가원·정통의 큰 틀에는 부합한다. 다만 다른 양식은 기존에도 선·번호 면·진도 면에 색이 있어, C5를 일괄적인 «글자색만» 구현으로 재현하지 않았다.

`readablePaperColor`는 sRGB 상대 휘도로 기본 종이 `#FCFCF8`와 글자 대비 4.5:1을 확인한다. 충분하면 선택색을 유지하고, 부족하면 검정 또는 흰색 방향으로 최소한 혼합하여 읽을 수 있는 색을 만든다. 밝은 종이에서는 검정 방향으로 어두워진다. `inkOnColor`는 채운 면 자체의 선택색을 유지하면서 그 위 글자에 검정/흰색 중 더 높은 대비를 고른다. 장식 선·면의 색까지 모두 어둡게 바꾸는 함수가 아니다.

### 수정한 것과 수정하지 않은 것

- **기존 자리의 배선 누락: 발견 0건.** 따라서 새 정보 자리를 제품에 추가하거나 모든 템플릿을 같은 구성으로 바꾸지 않았다.
- **기존 공통 정보줄의 글자 대비 수정 1건:** `ExamDetails`가 `options.color`를 직접 글자색으로 사용하던 예외를 `readablePaperColor(options.color)`로 바꿨다. 출력 필드·위치·조건·공간은 그대로다. 사이언·주황·노랑 등 밝은 색의 정보 글자만 읽기 쉬워진다. 정통에는 해당 정보줄이 없어 이 수정의 영향이 없다.
- 제품의 날짜 숨김·빈 값·제목 대체·관리 태그·수기 학생칸은 기존 계약을 유지했다. 새 시안의 시험 종류 출력과 안내 문구는 마지막 추가 지시를 따른다. 템플릿별 위치는 시안에서 고른 뒤 제품에 적용하므로 현재 제품 태그 안내를 미리 바꾸어 실제 출력과 어긋나게 하지 않았다.
- `AnswerPage`는 별도 정답지이며 일부 번호가 선택색을 직접 사용한다. 워크북의 검정 띠 위 일부 회색 수기 라벨도 기존 대비의 별도 검토 대상이다. 이번 수정으로 전체 정답지·모든 기존 템플릿 텍스트의 접근성을 인증하지 않는다.

## 3. Hi-fi 비교 페이지

진입: `/dev/print-color-hifi`. 개발·시험 환경에서 열리고 production에서는 404다. 화면은 자체 작성한 예시 문항 4개와 가상 입력값만 사용한다. 저장·세션·API·DB 의존성이 없으며, 별도 UI 검증 스크립트로 Next나 업무 서버 없이도 렌더된다.

구현: `src/app/dev/print-color-hifi/{page.tsx,PrintColorHifi.tsx,ColorPaper.tsx,fixtures.ts,PrintColorHifi.module.css}`. C1~C4 지면은 이 디렉터리 안의 시안 전용 구성이다. A4 크기·인쇄 토큰·실제 `ProblemBody` 수식 렌더러를 사용하며 제품용 템플릿과 저장 옵션은 확장하지 않았다. C5는 실제 여섯 템플릿을 사용하며 이번 정보줄 대비 수정까지 반영한 현재 상태다.

| 안 | 색상 적용 범위 | 정보 배치 |
|---|---|---|
| C1 머리띠·구획선 | 머리 경계·큰 구획선에 선택색, 문항·번호는 검정 | 아래 템플릿별 제안 구성 |
| C2 머리 면·번호 | 머리 면·번호 상자를 선택색으로 채움; 면 위 글자는 검정/흰색 대비 선택 | 같은 제안 구성 |
| C3 모든 선·옅은 면 | 표·문항·풀이칸 선에 동계색, 정보 면에 옅은 색 | 같은 제안 구성 |
| C4 진한 바탕·옅은 면 | 읽기 쉬운 진한 동계색 머리·번호 + 옅은 정보 면 | 같은 제안 구성 |
| C5 현재 적용 비교 | 현재의 글자·선·작은 면 적용과 검정 틀 | 1절의 현재 실제 구성 |

각 안마다 남색·사이언·주황 3장과 현재 선택색의 회색조 1장을 그린다. 템플릿 여섯 개를 선택해 **컬러 90조합 + 회색조 30장**을 확인할 수 있다. 지면 아래 «지면 크게 보기»와 상단 C1~C5·색상·회색조 조작은 실제로 동작한다. 회색조는 CSS 변환 미리보기이며 프린터의 토너·드라이버 효과를 측정한 것이 아니다.

### 서로 다른 템플릿별 제안 구성

화면에 현재 구성과 나란히 실었다. 총점·학교·시간 등 생략한 정보는 숨은 데이터만 남기는 것이 아니라 C1~C4의 지면에도 출력하지 않는다. 아래 항목에 더해 **시험 종류는 여섯 양식에 공통으로 표시**한다.

| 양식 | C1~C4에 싣는 항목 | 실제 제안 지면의 자리 |
|---|---|---|
| 평가원 | 제목·학교/기관명·학년·과목·학기·시험일·시험 시간·총점 | 영역 머리 오른쪽 시험 종류 + 제목 + 시험 정보 두 줄; 출제자 생략 |
| 정통 | 제목·학교/기관명·학년·과목·학기·시험일·시험 시간·출제자·총점 | 표 제목 옆 시험 종류 + 시험 정보표 + 학생·점수 수기칸 |
| 모던 | 제목·학교/기관명·학년·과목·학기·시험일·총점 | 학교 머리 오른쪽 시험 종류 + 제목 + 짧은 정보줄; 시간·출제자 생략 |
| 워크북 | 제목·학원명·강사명·학년·과목·시험일·유형명·핵심 전략 | 단원 띠 오른쪽 시험 종류 + 학원 머리 + 유형·전략 상자; 학교·학기·시험 시간·출제자·총점 생략 |
| 자습 | 제목·과목·시험일·오늘의 목표·개념 정리 | 자습 머리 오른쪽 시험 종류 + 학습 제목 + 목표 + 개념 상자; 학교·학년·학기·시간·점수 등 생략 |
| 유형 | 제목·학년·과목·유형명·핵심 전략 | 제목 옆 시험 종류 + 유형 띠 + 전략줄; 기관·학기·날짜·시간·출제자·점수 생략 |

제안의 워크북 유형·전략 상자는 현재 워크북에 없던 새 자리의 예다. 자습·유형은 이미 성격에 맞는 목표·개념·유형·전략 자리를 유지하면서 공통 정보 과다 노출을 덜었다. 모든 양식에 이 전용 칸들을 복제하지 않았다.

### 입력 패널 두 안

- **P1 미사용 칸 비활성 — 기본안:** 입력값을 보존한 채 전체 항목을 보이고, 미출력 칸을 흐리게 표시하며 실제 `disabled`로 입력을 막는다. «이 양식에는 찍히지 않음»과 양식의 성격에 따른 짧은 까닭을 상시 표시한다. 보조문구는 입력의 접근 가능한 설명에도 연결했다.
- **P2 쓰는 칸만 표시 — 비교안:** 선택한 템플릿의 제안 항목만 입력칸으로 보인다. 아래에 생략 항목 이름을 모아 알린다.

두 안 모두 양식을 왕복해도 입력을 잃지 않는다. 시험 종류 선택에는 옛 «지면에 찍히지 않습니다» 안내를 사용하지 않고, 모든 제안 양식에 표시·«없음»이면 생략한다고 알린다. 패널의 생략 표시는 C1~C4 제안 기준임을 명시하여 C5의 현재 구성과 구분한다. C5는 기존 구현의 미출력 상태를 비교용으로 유지한다.

## 4. 검증과 증거

- 렌더 시험: 새 시안의 모든 C1~C4 × 6양식 × 3색에서 구성표와 실제 필드의 일치, 문항 4개 보존, 시험 종류 표시 확인. 여섯 제안 양식 모두 «없음» 생략도 검증했다. C5는 실제 템플릿의 기존 기본 정보·전용 항목과 대조했다.
- 상호작용 시험: P1 기본 선택·비활성·까닭, P2 숨김, 양식 전환 후 값 보존, 자습 전용 칸, 날짜 숨김, 시험 종류 변경·없음을 확인했다.
- 관련 시험은 인쇄 패널·미리보기·연산 묶음·지면 배치·저장 양식 계약·PDF 복제/분할·검수 목록까지 **10개 파일 88개 통과**했다.
- `npm run type-check`, 변경 TSX/TS/CSS 연관 파일의 ESLint, 전체 `npm run lint:affordance`, `git diff --check`를 통과했다. 전체 저장소 ESLint·전체 시험 실행이나 production 배포를 수행한 것으로 확대하지 않는다.
- 대비 시험: 기존 번호 대비 시험에 공통 정보줄 9색을 추가했다. 흰 종이·따뜻한 종이에서 4.5:1 이상이고 날짜 숨김도 유지한다.
- 브라우저: `node scripts/qa/print-info-color-hifi.mjs`. 컬러 90조합·회색조 30장, 1440/390/320px 18개 화면 조합에서 페이지 가로 넘침·지면 내부 넘침·문항 누락 0건, 페이지 오류 0건, API/외부 요청 0건. 실제 A4 지면 크기를 측정했고 P1/P2·값 보존·색상 선택·회색조·print media를 확인했다.
- 실제 Next.js 16.3.8 개발 경로는 webpack으로 실행하여 HTTP 200을 확인했다. Playwright에서 hydration 후 기본 비활성 입력과 시험 종류 변경을 확인했고, 제안 지면 17곳(확대 1 + 비교 16)의 변경 반영·페이지 오류 0·API 요청 0을 기록했다. 로컬 확인 주소는 `http://127.0.0.1:3219/dev/print-color-hifi`다.
- 스크린샷에서 정통·자습 5안 비교, 유형 C4 사이언, 320px 상세, P1 비활성 패널을 직접 검토했다.
- 실물 프린터 검수는 **대기**다. `src/app/dev/print-check/items.ts`에 `print-info-color-20261019`를 추가했다. 제품 정보줄의 밝은 글자와 시안의 색·회색조 선/면을 구분해 확인하도록 적었다.

재현 스크립트는 `node_modules` 심볼릭 링크의 실제 경로도 Vite 읽기 허용 목록으로 해석한다. 초기 검증 하네스의 폰트 경로·doctype·선택기 문제를 고친 뒤 다시 실행한 성공 결과만 최종 증거로 사용했다.

증거는 Git에서 제외된 `.qa-artifacts/print-info-color/`에 있다:

- `browser.json`: 18개 화면 조합의 A4·넘침·문항 수 측정.
- `comparison-{평가원,정통,모던,워크북,자습,유형}.png`: 양식별 5안×3색·회색조 비교.
- `detail-{양식}-320.png`: 320px 상세.
- `C4-cyan-detail.png`, `C4-cyan-gray-detail.png`, `C4-print-media.png`: 확대·회색조·인쇄 미디어.
- `panel-P1.png`, `panel-P2.png`: 두 입력 패널.
- `next-route.json`, `next-route-hydrated.png`: 실제 Next 경로·hydration·기본 비활성·시험 종류 변경 증거.

독립 감사자는 작업을 마쳤고 터미널을 종료했다. 감사 worktree는 깨끗하며 새 커밋이 없다. 기준 커밋 `86fb78a67`이 현재 로컬 `main`에 포함되지 않아, «미병합 worktree를 지우지 않는다»는 지시에 따라 worktree와 브랜치를 보존하고 Orca 상태를 완료로 표시했다. 본 작업도 커밋 금지 지시에 따라 현재 브랜치의 변경 파일로 남겼다.

시안 선택 전 제품 적용은 하지 않았다. 브리프의 완료 범위는 감사·기존 자리 확인/수정·비교 시안·검증·보고서이며, 새 지면 디자인의 실제 제품 적용은 이후 선택된 안을 대상으로 진행한다.
