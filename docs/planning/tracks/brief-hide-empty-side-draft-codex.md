# 빈 «현재 시험지» 카드 숨기기 (원장님 2026-10-20 확정)

새로고침하면 빈 시험지로 시작한다(그대로 — 마지막 작업을 자동으로 열지 않는다). 그런데 옆 메뉴 «현재 시험지 0문항 · 편집 이어가기» 카드가 방금 만든 시험지가 사라진 것처럼 보인다 → **담은 문항이 0이면 카드를 숨긴다.** 지난 시험지는 «내 시험지»에서 연다.

리드가 이미 넣은 것: `src/components/unified/UnifiedWorkspace.tsx` 카드 조건에 `(selected.length > 0 || view === "studio")` — 문제 추출은 담은 것이 자기 장바구니에 있고 이 카드로 편집에 보내므로 거기서는 보인다.

## 할 일
1. 이 조건 때문에 `src/__tests__/components/UnifiedWorkspace*.test.tsx` 12개가 실패한다(빈 시험지에서 카드 · «편집 이어가기»를 눌러 편집 화면으로 가던 시험). 하나씩 보고 둘로 가른다:
   - **시험 준비만 그 길을 쓴 것** → 시험이 다른 정상 길(시험지에 문항을 담은 뒤 카드, 또는 해당 화면으로 직접 이동)로 같은 것을 검증하게 고친다. 검증 대상(단언)은 약하게 만들지 않는다.
   - **실제 사용자 길이 끊기는 것**(빈 시험지에서 편집 화면 · 출력 · 다른 기능으로 갈 길이 이 카드뿐인 경우) → 보고하고, 조건을 그 경우만큼 넓힌다(새 단추 · 새 모양은 만들지 않는다 — D-07).
2. 새 시험: 빈 시험지(시험지 만들기 · 홈 등)에서는 카드가 없고, 한 문항이라도 담으면 생기고, 문제 추출 화면에서는 보인다. 영어에서는 지금처럼 안 뜬다.
3. 관련 시험 전부 · `npm run type-check` · 변경 파일 eslint · `npm run lint:affordance`. DB · 커밋 금지. 보고서 `docs/planning/tracks/reports/hide-empty-side-draft-codex-20261020.md`(12개 각각 어느 쪽이었는지).
