## 2. 물결 2B — v2 마크 문법 4종 (선행: **도형엔진-v2채색 병합** — 같은 파일)

세션 1개(claude). 소유: `vendor/figure-engine/core/figure_scene.py` +
`src/__tests__/unit/figureMarks.test.ts` + probe.

스키마(하위 호환 — 기존 배열형 spec 은 그대로 동작해야 하고, 테스트로 잠근다):

```jsonc
"segments": {
  "AB": ["A","B"],                                  // 기존형 그대로
  "AC": {"points":["A","C"], "ticks":2},            // 같음 표시 1~3
  "l1": {"points":["P","Q"], "parallel":1},         // 평행 » 1~2
  "BD": {"points":["B","D"], "dashed":"5 4"}
},
"angles": {
  "a": {"vertex":"C","points":["A","D"],"arcs":2},  // 이중 호
  "r": {"vertex":"T","points":["O","P"],"right":true} // 직각 기호(호 대신 사각형)
}
```

구현 지침: tick/평행 표시는 선분 중점에 수직 짧은 획(간격 3px), 직각 기호는
꼭짓점에서 두 변 방향 사각형(한 변 ≈ 호 반지름의 0.55) — **원본 지면(RPM 2-2
합동 단원)을 렌더해 크기·획 굵기를 대조**한다. `regions`(v2채색 산출)와 키가
겹치지 않는지 병합 후 스키마 전체를 다시 읽고 시작.
검증: 실증 렌더 4종(이등변 tick·이등분선 이중호·사다리꼴 평행·내접원 직각) 스크린샷
+ 하위 호환(기존 실증 스펙 전량 무변화 — 예전 SVG 와 바이트 대조) + 변이 3+.

완료되면 2A-중2기하의 «2B 대기 목록» 유형을 이어서 낸다(같은 세션 연장 가능).

## 3. 물결 2C — `linearGraph` kind (선행: **도형엔진-입체kind 병합** — 같은 파일)

세션 1개(claude). 소유: `scripts/figure/elem_advanced.py` +
`src/__tests__/unit/figureLinearGraph.test.ts`.

```jsonc
{"version":"elem-1","kind":"linearGraph",
 "lines":[{"slope":2,"yIntercept":-1,"label":"y=2x-1"}],   // 1~3개
 "xRange":[-4,4], "yRange":[-4,4],
 "marks":[[1,1]], "grid":false}
```

문법(교과 좌표평면 — RPM 2-1 일차함수 단원 원본 렌더로 대조): 축 화살촉 · 원점 O ·
정수 눈금 짧은 획(숫자는 -1·1 등 필요한 곳만) · 직선은 범위 경계까지 · 두 직선
교점 유형 지원. **`marks` 의 점이 직선 위에 있지 않으면 던진다**(검산 겸용).
D-70 정신 그대로: 못 담으면(기울기 극단 등) 조용히 구겨 넣지 말고 던진다.
검증: 실증 렌더 4종(양/음 기울기·절편·두 직선 교점) + 변이.

완료되면 함수 유형(함수와 함숫값·그래프와 기울기·활용 ~15)을 이어서 낸다 —
소유 `src/lib/middle/m2Func.ts` + 테스트.
