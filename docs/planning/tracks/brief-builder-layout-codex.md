## 1. 2단계 «문항 검토» — 이전 · 다음 단추는 왼쪽 열에만

- 지금 «이전: 범위 설정 / 다음: 양식 구성·출력»이 두 번 있다: 왼쪽 열 아래(안내 «양식 구성·출력으로 이동할 수 있습니다.» 상자와 함께, ~2149~2190행)와 오른쪽 문항 목록 끝(`s.reviewFooterNav`, ~2466행 — 주석 «원장님 2026-10-20 목록 끝에서도 3단계로»).
- 원장님: **왼쪽에만 남긴다.** 오른쪽 목록 끝의 `reviewFooterNav` 와 그 CSS 를 걷는다. 왼쪽 단추의 동작 · 막힘 판정 · `aria-describedby` 는 그대로.
- 왼쪽 열이 따로 스크롤되므로 단추가 늘 보이는지(긴 목록 · 짧은 창 1366×768) 확인한다.

## 2. 3단계 «양식 구성 · 출력» — 왼쪽 양식 창 높이를 오른쪽 미리보기에 맞추기

- 지금: 왼쪽 «서식 설정 / 문제 순서» 창이 내용 높이에서 끝나(캡처에서 화면 중간쯤) 오른쪽 미리보기 열보다 훨씬 짧다. 창 안에 작은 스크롤이 따로 있다.
- 원장님: **창 크기에 따라 오른쪽과 높이를 맞춘다.** 왼쪽 창이 오른쪽 미리보기 열과 같은 위 · 아래 끝을 갖고, 넘치는 내용은 왼쪽 창 안에서 스크롤한다(페이지 전체 스크롤과 겹치지 않게). 2단계의 «열마다 따로 스크롤»(`useBuilderScrollFrame`)과 같은 방식을 먼저 찾아 쓴다.
- 왼쪽 창은 다른 화면과 공유하는 부품일 수 있다(`src/components/unified/WorksheetEditor.tsx` · `print/PrintOptionsPanel.tsx`) — **시험지 만들기 안에서만** 바뀌게 한다(다른 화면 · 작업실의 같은 부품은 그대로). 비슷한 화면은 한 방식으로(CLAUDE.md 절대 규칙 11) — 새 틀을 따로 짓지 말고 2단계의 틀을 넓힌다.
- 잴 것: 1280×720 · 1366×768 · 1920×1080 에서 왼쪽 창 아래 끝 = 오른쪽 미리보기 열 아래 끝(±2px) · 페이지 가로 넘침 0 · 이중 스크롤 막대 없음. 창 크기를 바꾸면 따라온다.
