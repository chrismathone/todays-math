## codex ③ — 목록 · 단원 · 통계

- codex ① 의 전달: `ExplorerMath → MathText → MarkdownRenderer` 는 `inline` 이어도 **바깥 `div`** 를 낸다. `p` 안에 넣으면 React 의 중첩 경고가 난다 — 수식이 들 수 있는 이름 · 미리보기는 `p` 대신 `div` 로 감싼다. 렌더러는 범위 밖이라 고치지 않는다.
- 위 표의 «줄바꿈» 규칙은 목록 · 단원 · 통계에도 같다.
- `tsc` 의 범위 밖 1건(`src/lib/english/listening/runtime/bank.ts` — 다른 세션이 지운 JSON)은 알고 있는 것이다. 자기 파일 0 이면 통과다.
