## 2. 지킬 것

- **교사 화면(`src/components/fading/teacher/**`) · `/dev/*` · 교사 API 는 그대로** — 같은 낱말이 교사에게는 필요하다. 공용 부품이면 학생 쪽에서만 숨기는 선택 인자로.
- 서버 · 계약 · 저장 꼴 · 일정 계산(`src/lib/**` · `src/contracts/**` · `src/app/api/**`) 불변. 날짜 말은 화면의 표기만 바꾼다.
- `05-design-system` §17(오늘의 기억 v2)의 짜임은 그대로 — 낱말과 칩만 걷는다. 빈자리가 어색하면 간격만 맞춘다.
- TDD — RTL 로 학생 화면에 걷은 낱말이 없고 교사 화면에는 남아 있음을 둘 다 확인한다. 기존 시험이 그 낱말을 붙잡고 있으면 학생 쪽만 고친다.
- 정션 `node_modules` · `npm install` / `prisma generate` 금지 · 전체 `type-check` 는 끝에 한 번(알림) · 단위마다 커밋 · **푸시하지 않는다**.
- 다 되면 커밋 · 바꾼 파일 · 걷은 낱말 목록(자리마다) · 남긴 것과 까닭 · PC 1366 / 폰 390 캡처.
