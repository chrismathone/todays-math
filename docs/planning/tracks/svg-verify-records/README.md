`feat/figure-svg-verify` 를 닫으면서 여기로 옮겼다 — 판정은 파일로 남아야 하고,
채팅 스크롤백은 창이 닫히면 사라진다(CLAUDE.md 2026-08-21).

## 이 기록을 읽을 때 조심할 것

CLAUDE.md 2026-08-20·21 이 잰 것이 그대로 여기에 적용된다.

- **판정자마다 지어냄이 다르다.** 같은 모집단에서 codex 0건 · gemini 12.8% ·
  안티그래비티는 9건을 걸었는데 **9건 다 거짓**이었다. 그러니 「결함 N건」을
  숫자 그대로 읽지 말고 **어느 판정자였나**를 함께 보라.
- **「결함 0」이 곧 깨끗함은 아니다.** 양성 대조군만 대면 재현율만 재고 지어냄은
  구조적으로 0 이 된다 — 음성 대조군(깨끗하다고 이미 확인한 시트)을 함께 대야 한다.
- **「그 시트를 정말 봤나」는 시트 색인으로 셀 수 있다**(`scripts/qa/reports/svg-sheets.json`,
  로컬 산출물). 판정 파일의 번호 집합과 대 보면 지어냄이 한 줄로 드러난다.
