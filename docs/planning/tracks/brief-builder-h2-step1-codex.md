# 시험지 만들기 — H2 확정 · 1단계 «차근차근» 변형 (원장님 2026-10-19)

원장님: «H2 로 갈까? 근데 1단계일 때 좀 더 담백했으면. **범위 선택 전에 상세 범위 보여주지 말 것. 차근차근 다음 범위로.**»

- **2단계(문항 검토)는 H2 그대로 확정.** 손대지 않는다.
- **1단계(범위 설정)만** H2 모양(촘촘한 목록 · 직각 구획 · 수평선 · 16px 내부 여백)을 바탕으로 변형 **4안(S1~S4)** 을 같은 시안 화면에 더한다. 경로 `/dev/exam-builder-simple-hifi` 의 새 절 `#H2-step1` (기존 H1~H4 는 그대로 둔다).

## 공통 규칙 (네 안 모두)
- 처음 화면에는 **학년·과정 고르기만** 보인다. 단원 · 차시 · 소단원 같은 상세 범위 목록은 앞 단계를 고르기 전에는 **그리지 않는다**(735개 범위 목록을 먼저 깔지 않는다).
- 학년 → 단원(대단원) → 차시(세부 범위) 순서로 하나 고르면 다음 단계가 열린다. 앞 단계를 바꾸면 뒤 단계는 다시 고른다.
- 고른 범위는 오른쪽(또는 아래) 출제 범위 칸에 쌓이고 문항 수를 정한다 — 기존 H2 의 칸 · 동작 그대로.
- 담백하게: 설명 문구 최소, 장식 · 색 면 · 배지 최소. 숫자는 필요한 곳만(차시 옆 «N갈래» 정도).
- 출처는 Wire A 확정대로 «전체 / 교과서만» 한 줄. 출제 조건 줄 · 제목 칸은 지금 H2 에 있는 대로.
- 다음 단계로 못 가는 까닭 안내는 H2 의 자리 그대로.
- 문구는 간결 · 사무적(D-08). 마우스 어포던스 규칙(D-30). 긴 목록 고르기는 공용 `PickerDialog` 를 쓸 수 있으면 쓴다(D-159 — 쓰는 안과 안 쓰는 안을 갈라도 된다).

## 네 안의 차이 (예시 — 더 나은 갈래가 있으면 바꿔도 된다, 넷은 서로 확실히 달라야 한다)
- S1 단계 열: 학년 | 단원 | 차시 세 열이 왼쪽부터 하나씩 열린다(파일 탐색기식).
- S2 한 열 차례: 한 칸에서 학년 → (고르면 접혀 한 줄 요약) → 단원 → 차시 순으로 아래로 이어진다.
- S3 경로 줄: 위에 «학년 › 단원 › 차시» 경로 줄, 아래 목록은 지금 단계 것 하나만.
- S4 고르기 창: 화면에는 «학년 · 단원 · 차시» 세 줄과 [고르기] 단추만, 누르면 PickerDialog 로 단계 고르기.
