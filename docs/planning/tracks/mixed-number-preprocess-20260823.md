# 전처리가 지면의 수를 고쳐 쓴다 — 가분수 → 대분수 (2026-08-23)

> 발견: 물결 3 `3A-통계유형` 세션이 **미리보기를 눈으로 보다가** 찾았다.
> 구의 부피 공식 `\dfrac{4}{3}\pi r^3` 가 지면에 `1\frac{1}{3}\pi r^3` 로 나갔다.
> 이 문서는 그 결함이 **그 세션만의 것이 아님**을 전수로 재어 둔 것이다.
>
> 계량기: `npx tsx scripts/qa/census-mixed-number.ts [--db|--middle|--elem]`

## 1. 무엇이 일어나는가

`src/lib/math/textPreprocess.ts` 의 `improperToMixed` 가 **화면·지면 렌더 경로**
(`MarkdownRenderer` · `renderMathHtml`)에서 수식을 고쳐 쓴다. **DB 값은 그대로인데
종이에 다른 수가 찍힌다.**

| | 전 | 후 |
|---|---|---|
| ① 가분수 → 대분수 | `f(x)=x^3-\dfrac{3}{2}x^2+1` | `f(x)=x^3-1\dfrac{1}{2}x^2+1` |
| ② 정수로 접힘 | `(평균)=\dfrac{355}{5}=71` | `(평균)=71=71` |

②는 **해설의 한 단계가 통째로 사라진다.** 계산 과정을 보여 주려고 쓴 식이
「$71=71$」이 되어 문장이 말이 안 된다.

### 2.1 초등에서는 문제 자체가 부서진다

초3 「가분수를 대분수로 나타내시오」 유형은 **10건 전량**이 지면에서 제 답을 보여 준다.

```
발문 전: 다음 가분수를 대분수로 나타내시오.  $\frac{23}{4}$
발문 후: 다음 가분수를 대분수로 나타내시오.  $5\dfrac{3}{4}$      ← 정답
```

발문이 곧 정답이다. **생성기 쪽에서는 못 피한다** — 그 유형은 발문에 가분수가
있어야 성립한다.

## 3. 왜 지금까지 안 보였나

- **DB 를 봐도 안 보인다.** 저장된 값은 멀쩡하다. 바뀌는 것은 **렌더 경로**뿐이라,
  본문을 세는 지표는 구조적으로 0 이다.
- **KaTeX 는 초록이다.** `1\frac{1}{3}\pi` 는 유효한 수식이라 렌더 실패도, 붉은
  글씨도 없다. 2026-08-16 「KaTeX 가 초록이라고 지면이 멀쩡한 게 아니다」와 같은 자리다.
- **결함이 스스로 신고하지 않는다.** 수학적으로 «같은 값»이라 검산도 통과한다.
  2026-08-21 「`\frac{}{2}` → `\frac{0}{2}`」와 **같은 부류** — 전처리가
  «에러를 막는 일»을 넘어 **값을 고쳐 쓰는** 자리다.

## 4. 규칙의 전제가 뒤집혀 있다

주석은 이 규칙을 「한국 **중·고등** 교과 관행」이라고 적어 두었다. 그런데 대분수는
**초등(3~5학년) 표기**이고, 중학교부터는 문자가 들어오면서 `2\frac{1}{2}` 가
「2 곱하기 1/2」로 읽힐 수 있어 **가분수를 쓴다.** 규칙이 옳다고 주장하는 바로 그
자리에서 틀렸다.

## 5. 결정 — 자동 변환을 껐다 (2026-08-24 원장님 확정)

> 원장님: **「중등은 대분수 변환하지 말 것」**

렌더 경로(`MarkdownRenderer`·`renderMathHtml`)에는 **학년이 없다.** 그래서 「중등만
끄기」는 학년을 화면 전체에 배선해야 한다. 그리고 초등·고등에서도 그 규칙은 옳지
않았다 — 초3 「가분수를 대분수로 나타내시오」는 **10건 전량**이 발문에 정답을 찍었고,
고등은 `x^3-\dfrac{3}{2}x^2` 가 `x^3-1\dfrac{1}{2}x^2` 로 나갔다.

그래서 **자동 변환 자체를 없앴다**(`f797eb60`). 되살리려면 **학년을 아는 자리**에서만
켜야 한다 — 옛 구현은 git 에 있다(`git show aed9b430:src/lib/math/textPreprocess.ts`).

  제품을 거치지 않고 확인해야 한다(그렇게 안 짰다가 빨갛게 났다).

  나가고 있었다. 지면이 달라진 게 아니라 **답이 원래 모양으로 돌아왔다.**
