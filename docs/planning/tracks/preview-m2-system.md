    두 식을 연립하여 풀면 $x=-3$, $y=6$이다.
- **문제** (hard) 연립방정식 $\begin{cases}0.\overline{7}x+0.\overline{7}y=0\\0.\overline{4}x+0.\overline{1}y=-1\end{cases}$ 의 해를 구하시오.

  - **풀이** 순환소수를 분수로 고치면 $0.\overline{7}=\dfrac{7}{9}$, $0.\overline{4}=\dfrac{4}{9}$, $0.\overline{1}=\dfrac{1}{9}$이다.

### 20 지수법칙을 이용한 연립방정식  `여러 가지 연립방정식의 풀이`

- **문제** (hard) $x$, $y$가 자연수일 때, 두 등식 $2^{x}\times2^{y}=256$, $5^{x}\div5^{y}=625$ 를 모두 만족시키는 $x$, $y$의 값을 각각 구하시오.
  - **답** $x=6$, $y=2$
  - **풀이** 지수법칙에 의하여 $2^{x}\times2^{y}=2^{x+y}$, $5^{x}\div5^{y}=5^{x-y}$이다.  
    $256=2^{8}$, $625=5^{4}$ 이므로 $x+y=8$, $x-y=4$이다.

- **문제** (hard) $x$, $y$가 자연수일 때, 두 등식 $3^{x}\times3^{y}=2187$, $5^{x}\div5^{y}=125$ 를 모두 만족시키는 $x$, $y$의 값을 각각 구하시오.

    작년의 남학생 $200$명이 $4\%$ 늘었으므로 올해의 남학생은 $200+8=208$(명)이다.

- **문제** (hard) 두 상품 $\mathrm{A}$, $\mathrm{B}$의 원가의 합은 $12600$원이다. 상품 $\mathrm{A}$는 원가의 $10\%$, 상품 $\mathrm{B}$는 원가의 $30\%$의 이익을 붙여 정가를 정하고 두 상품을 모두 팔았더니 전체 이익이 $2340$원이었다. 상품 $\mathrm{A}$의 원가를 구하시오.
