## 2. 검산을 어떻게 했나 — 「지면에 인쇄된 식을 다시 푼다」

생성기는 계약대로 **답을 먼저 정하고** 식을 짓는다. 시험은 반대로 간다:
`src/__tests__/unit/middleM2System.test.ts` 안에 **유리수 산술 2변수 다항식 파서**를
따로 두고, **발문에 인쇄된 식을 파싱해서 다시 푼다.** 제품 코드를 부르지 않으므로
생성기와 공유하는 규칙이 없다.

- **부등식**: 파싱 → 독립 풀이 + **경계값 양옆을 실제로 대입**(해 쪽 참·반대쪽 거짓).
- **연립방정식**: 파싱 → **크라메르 공식** + 답을 **두 식에 되대입** + 계수 행렬식 ≠ 0.
- **보기 유형**: 인쇄된 보기 다섯을 하나씩 파싱해 **정의를 적용**하고 답 letters 를 다시 만든다.
- **활용**: 발문이 말하는 상황을 **전수 탐색**으로 다시 풀고 **유일한지** 센다.
  개수·나이·금액이 자연수인지(되대입해서 말이 되는지)도 같이 본다.
- **파서 자체의 눈금**: 양성 대조군(괄호 전개·분수·소수·순환소수·지수·부등호 뒤집기)과
  **음성 대조군**(참인 대입은 참, 거짓인 대입은 거짓 · 모르는 명령은 던진다 ·
  행렬식 0 이면 던진다)을 둘 다 시험에 박았다.

그래서 **「값은 맞는데 인쇄가 틀린」 경우도 빨개진다** — 계약이 겨눈 자리다.

## 3. 값 검사가 못 보는 것 — 지면 냄새 훑개

값이 맞아도 흉한 글자는 위 검산으로 구조적으로 안 잡힌다. 그래서 시험에
**냄새 훑개**를 따로 두었다(유형마다 씨앗 40 × 변형 3):
`+-`·`--` · 계수 `1x`/`0x` · 지수 `^1`/`^0` · `+0` · **`\lex` 처럼 부등호에 글자가 붙은 것** ·
빈 괄호 · **수식 안 한글**.

⚠️ 「수식 안 한글」은 정규식 하나로 못 센다 — `$…$ 한글 $…$` 의 **가운데 토막**까지
걸린다. 짝지은 블록만 본다.

**이 훑개가 실제로 둘을 잡았다**: 순환소수 해설의 `1x`, 득점 감점 해설의 `1y`.

## 4. 눈으로 봐서만 나온 것

`docs/planning/tracks/preview-m2-system.md`(유형 30 × 씨앗 3)를 **읽어서** 찾은 것들.
시험은 전부 초록이었다.

1. **`\le x` 가 `\lex` 로 붙는다** — `relTex()` 가 꼬리 공백 없이 `\le` 를 돌려주는데
   뒤에 `x` 가 오면 KaTeX 가 모르는 명령이 되어 **붉은 글자로 지면에 나간다.**
   부등호 문자열에 꼬리 공백을 박고, 냄새 훑개에 그 모양을 넣었다.
2. **부등식 05 의 해설이 뒤집힌 사슬을 찍었다** — `$15>-5x\ge 30$`(성립할 수 없는 사슬).
   값 검사는 답만 보므로 못 본다.
3. **수식 안에 한글** — `$(일차식)>0$`.
4. **`$-3$로 나누면`** — 도구격 조사가 「으로」여야 한다(삼·육·십 뒤).
5. **해설에 마크다운 `**둘 다**`** — 렌더러가 처리하지 않아 별표가 그대로 나간다.
6. **`0.\overline{9}`** — $0.\dot9=1$ 이라 순환소수 문제로 성립하지 않는다.
   순환마디를 $9$ 와 서로소인 숫자로 좁혀 **기약이 아닌 $\dfrac69$** 도 같이 막았다.
7. **`2^{1}`** — 지수 $1$ 이 지면에 찍힌다. 지수 차를 $2$ 이상으로.
8. **조건이 사실상 없는 발문** — 가로 $15\,$cm 인데 「둘레가 $26\,$cm 이상」.
9. **같은 분모 두 개** — 「계수가 분수인」 유형에 `\dfrac{x+1}{2}+\dfrac{x-5}{2}`.
10. **약분되는 계수** — `4x+2y=20`.
11. **같은 순환소수를 해설에 두 번** 적었다.
12. **「$1$ 을 곱하여」** 라는 해설 단계.

## 5. 변이 시험 — 20개 전량 빨강

`python scripts/qa/mutate-m2-system.py` · 지문은 `scripts/qa/probe-m2-system.ts`.
판정은 3단(⑴ 파일이 바뀌었나 ⑵ **산출물이 바뀌었나** ⑶ 그제서야 시험이 빨개지나).

1차는 **18/20** 이었고, 나머지 둘이 값어치 있는 것을 알려 줬다.

- **[1] 부등식 03 이 «초록 ← 가드가 아니다»였다.** 이 유형의 답은 **인쇄된 부등식에
  대입해서** 얻는다. 그래서 부등호를 잘못 인쇄해도 **답과 서로 어긋나지 않는다** —
  어긋나는 것은 **해설이 유도한 범위**뿐이다. 시험이 해설을 따로 풀어 대조하게 고쳤다.
  («답이 발문에서 나오는» 유형은 답·발문 대조가 구조적으로 눈이 먼다.)
- **[10] 은 두 번 거부됐고, 두 번 다 하네스가 옳았다.**
  ㉠ 「앵커 0개」 — prettier 가 `def(...)` 를 여러 줄로 펴며 들여쓰기를 6칸 → 8칸으로
     바꿨다(**커밋(포맷) 뒤에 앵커를 다시 세는 것이 순서다**).
  ㉡ 「산출물이 그대로」 — `if (det === 0)` 만 껐더니 **아무 일도 안 일어났다.**
     무작위 계수가 우연히 행렬식 0 이 되는 일이 표본에 없어서다. 둘째 식을 첫째 식의
     **두 배로 못 박아** 반드시 그 자리에 닿게 한 뒤 가드를 껐더니 빨개졌다.
     ⑵ 단이 없었으면 **멀쩡한 가드를 의심하고 고치러 갔을 것이다.**
