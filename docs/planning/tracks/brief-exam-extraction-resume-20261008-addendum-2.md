# 추가 지시 2 — 준비 완료 후 실제 제작 재개

2026-10-08 사용자: **«그렇게 해»**. 최초 요청의 재개 세팅은 완료됐으며, 이제 앞선 최종 방향으로 실제 작업을 이어간다. `brief-exam-extraction-resume-20261008-addendum-1.md`의 발문/소재/표현/질문 대상 전환과 강한 학년·교육과정 제한을 모두 유지한다.

## 실행 범위

- 준비표/계획 보고서에서 멈추지 않고 새 문항의 본문·답·해설·도형/이미지·메타데이터와 독립 검산을 실제로 제작한다.
- 첫 대상은 범일중 21문항이다. 준비 보고서의 권장 출발점 2·3·15·21번에서 새 본문을 만들고, 검증 가능한 문항부터 진행한다. 5개 분류 보류와 출처/학년의 불명 사항은 근거를 확인하며 정리한다. 확정하지 못한 사항을 완료로 바꾸지 않는다.
- 필요한 새 후보 계약, 변형/도형/검수 자료의 버전·해시 연결, 실제 후보 dry-run과 유효성 차단 경로를 구현한다. 준비 패키지 검사의 통과를 완성 후보 검사로 재사용하지 않는다.
- 새로운 발문/소재/표현/역추론으로 같은 수학 개념과 핵심 관계를 자연스럽게 표현한다. 원문과의 구체적인 차이·학교명 치환·실제 출처·새 ID를 연결한다.
- 그림은 문제은행 기준으로 전량 재제작한다. 엔진으로 가능한 도형은 기존 경로를 재사용하고, 어려운 이미지/삽화는 imagegen의 기본 내장 도구로 실제 자산을 만든 뒤 새 수학 조건과 함께 검수한다.
- 새 문제와 새 그림만을 기준으로 답·해설을 생성하고 별도 독립 검산한다. 해당 학년 밖 개념·표기·학생용 풀이법은 제외하며 범위 불명은 보류한다. 원문 기반 21개 검산 기록은 새 쌍둥이의 승인 근거가 아니다.
- 첫 배치의 실제 품질/그림/학년/메타데이터/권리 검토 결과를 남기고, 다음 5편 및 남은 2025+ 추출 후보를 같은 기준으로 이어간다. 보류 자료는 사유와 재개 조건을 분리해 기록한다.
- 추출이 마무리되면 교육과정·유형·조건/정답·풀이·도형·imagegen을 활용한 이미지 문항·메타데이터/검색·생성/검수 안정성에서 도움이 되는 가능한 엔진 개선을 실제 구현/검증한다. 준비 단계에서 확인한 개선 후보 27개는 출발점이며, 그 목록만으로 범위를 고정하지 않는다.

## 작업 방식과 적용 경계

분리 가능한 독립 작업은 AGENTS의 Orca/Codex 방식으로 나눈다. 작업 중인 main/다른 세션과 원본 산출물은 보존하고, 각 작업의 파일·계약·완료 증거를 명확히 둔다. 진행은 실제 작성/그림/검산/검수 상태로 집계한다.

이번 지시는 실제 제작·추출·필요한 코드/엔진 구현과 검증을 진행하라는 확인이다. 기존 82행의 출제 잠금이나 경산여19 영구 제외를 해제할 권한으로 해석하지 않는다. 운영 DB 삭제/재적재·원장 없는 변경을 수행하지 않으며, 실제 공유 적재가 필요할 때는 최신 메타데이터/중복/검수/권리 상태·되돌리기 원장과 해당 쓰기 범위를 확인한다. 푸시 직전 원격 fetch/통합/관련 검증 규칙도 유지한다.
