# Hi-fi 시안 고침 (원장님 2026-10-20 «시안 눌러도 모눈종이 안 바뀌는데?»)

`/dev/descriptive-paper-hifi` (3034 서버 · 이 작업트리).
리드가 브라우저로 확인한 것:
1. 일반 문항(객관식 · 단답) 아래의 풀이 공간 `.scratch`(16px 모눈)가 A~E 어느 안에서나 같다 — 화면에서 가장 큰 모눈이라 «안이 안 바뀐다»로 보인다. **선택한 안의 답란 모양(A 줄 · B 옅은 모눈 · C 점선 · D 빈칸+기준선 · E 번호 구획+줄)을 일반 문항 풀이 공간에도 똑같이 적용**해서, 한 안 = 시험지 한 벌의 같은 모양이 되게 한다(간격 · 선 굵기는 안 정의 그대로).
2. B안에서 소문항 칸 분할 답란(`[data-answer-split="true"] .writingArea`)의 모눈이 사라진다 — `.answerSpace[data-answer-split="true"] .writingArea { background: … }` 단축 속성이 `background-image` 를 지운다. 모든 안 × 분할/통 답란 × 학생/교사 × 일일/확인/기출에서 선택한 모양이 실제로 그려지는지 고친다.
3. 위 둘을 **계산된 스타일이 아니라 픽셀로** 잰다: 실제 Chromium 으로 안마다 같은 위치의 답란 · 일반 풀이 공간을 잘라 이미지 차이를 비교하는 검사(A~E 서로 다름 · 분할 칸에도 모양이 있음)를 스크립트로 남기고 결과 표를 보고서에.
4. 흑백 미리보기 · PDF 에서도 같은지 확인. 넘침 0 유지.
제품 코드 무변경 · 커밋 금지. 보고서는 기존 hifi 보고서에 «고침» 절로 덧붙인다.
