# 지시서 — 초5 SRS 혼자 공부 화면 Hi-fi 시안 · E «펼친 책» (codex, 2026-10-19)

원장님이 Wire 5안(`docs/design/mockups/srs-e5-wire-20261019.html` — 당신이 만든 것) 가운데 **E 펼친 책**을 고르셨다(2026-10-19 밤).
다른 안에서 가져올 것은 없다. 계획서 `docs/planning/srs-e5-30day-plan-20261019.md` §2 의 결정 8 · §3.2 · §3.4 · §3.6 · §3.7 을 먼저 읽는다.
D-07 둘째 단계 — **Hi-fi 4~5안**(05-design-system §0-3). 화면은 codex, 속은 Claude(`AGENTS.md` «Student SRS redesign»). 이 일은 **화면 시안만**이다.

## 1. 고정된 것(E 의 구조 — 안끼리 바꾸지 않는다)

| 화면 | E 의 구조 |
| --- | --- |
| A. 첫 화면 | 펼친 두 면. 왼쪽 면 «오늘 공부»(초등 5학년 · 제목 · 단원 · 길잡이 자리 · 시작 단추 **하나**), 오른쪽 면 «나의 수학 여정»(진도판 테마 그림 · 단원 길 넷, 지금 자리 표시). 하루 마침이면 왼쪽 면이 «오늘 한 것 · 내일 할 것 · 보상 그림»으로 바뀐다 |
| B. 틀렸을 때 | 문제가 위, 풀이가 **아래로 이어진다**. 첫 오답은 «다시 해 볼까요» + 보기 **표시 순서만** 섞음(3·4·5·6 → 6·5·3·4). 두 번째 오답 · «아직 모르겠어요»면 풀이가 펼쳐진다 — 풀이는 두 단(왼쪽 글, 오른쪽 그림) · «이 문제는 다음 복습에서 다시 만나요.» · «알겠어요»를 눌러야 다음(자동 넘김 없음). 은행 문제와 개념 카드(맞다/아니다) 둘 다 |
| C. 예습 카드 | 두 면. 왼쪽 «뜻 · 그림»(소수의 곱셈 뜻 + 10×10 모눈 넓이 모형), 오른쪽 «함께 풀어 봐요 · 따라 풀어 봐요»(0.2 × 0.3 = 0.06 · 1.2 × 0.4 입력 · 확인) → «문제 풀기» |

글 · 숫자는 Wire 와 같은 실제 제품 값을 쓴다(은행 문항 «42, 44, 45, 38, 36 중에서 44 이하인 수는 모두 몇 개입니까?» · 개념 카드 `g5-decimal-multiply` 의 뜻 · 예 · 참거짓).

## 2. 안끼리 가를 것(예 — 더 나은 축이 있으면 바꿔도 된다)

- **종이의 정도**: 실제 책(가운데 접힘 그늘 · 쪽 모서리 · 책갈피 끈 · 쪽 번호) ↔ 평평한 두 판을 선 하나로 나눔.
- **테마의 양**: 진도판 테마 그림(`public/images/journey/*.webp` — 숲 · 바다 · 하늘 · 우주 · 도형, D-149)을 오른쪽 면 가득 ↔ 머리띠 · 테두리 조각만 ↔ 여정 면에만. 공부 화면(B · C)에 테마가 얼마나 들어오는지가 안마다 다르게.
- **폰(390)에서 두 면을 다루는 법** — Wire 의 대가(«폰에서는 한 면씩 쌓여 펼친 책 구도가 약해진다»)를 안마다 다르게 푼다: 위아래로 쌓기 ↔ 면 넘기기(왼쪽 면 / 오른쪽 면 표 · 옆으로 밀기) ↔ 접힌 책(위 면은 요약 한 줄, 누르면 펼침) 등.
- **풀이의 모양**: 같은 면의 아랫단 ↔ 책에 끼운 쪽지 ↔ 다음 쪽으로 이어짐(위아래 연결이라는 E 의 구조는 지킨다).
- **길잡이 · 보상 자리**의 크기와 위치.

## 3. 그림

- **수학 그림은 진짜 SVG 로, 수가 정확하게** 그린다 — 점선 상자 금지:
  - 0.2 × 0.3: 한 변 1인 정사각형 10×10 모눈, 가로 0.2(2칸) × 세로 0.3(3칸) = **6칸** 칠함, 작은 한 칸 0.01.
  - 44 이하: 수직선에 36 · 38 · 42 · 44 · 45 표시, **44 는 채운 점**(포함), 왼쪽으로 화살표, 45 는 범위 밖.
  - 초등 엔진 그림 규칙(D-61 · `docs/planning/09-figure-engine-guide.md` §4 재발 금지)을 참고한다 — 라벨이 선에 겹치지 않게.
- 진도판 테마 그림은 있는 webp 를 그대로 쓴다(시안 HTML 에서 상대 경로).
- 길잡이 캐릭터 · 보상 그림은 **자리 상자 + 이름표 + 안마다 그림 방향 한 줄**(이미지 생성은 Hi-fi 를 고른 뒤 그 안의 방향으로 한다). 이미지 생성 도구를 쓸 수 있으면 안마다 길잡이 초안 한 장을 **시안 폴더에만** 넣어도 된다 — `public/` 에 넣지 않는다.

## 4. 지킬 것

- 학생 화면의 확정 토큰 위에서 짓는다 — 새 색은 안의 이유가 있을 때만, 대비를 재서:
  `src/app/globals.css` 의 `--learn-*`(잉크 `#172b4d` · 코발트 `#3159df` · 맞음 `#1d7550` · 모서리 14/10px) ·
  05-design-system §8.16(선택됨 코발트 차오름) · §8.18(번호 키캡 — 마우스 기기에서만) · §8.19(문제 머리 «이름 + 갈래 딱지») · §8.20(별) ·
  `src/components/math-explorers/math-explorers.module.css` · `src/components/math-srs/daily-journey-board.module.css`.
- 화면 글꼴은 Pretendard 하나(책 느낌을 명조로 내지 않는다 — 명조는 지면에만).
- 05 §0 금지 목록(AI 공장식 스타일) · D-08(느낌표 · 이모지 없음, 학생 말은 지금처럼 «~해요») · D-30(누르는 것만 손가락 · hover).
  학생에게 어른 말(추가 확인 · 대조 · 분량 · 배정 · 소단원 번호 · 난이도 글자)을 보이지 않는다(§3.6).
- 책장 넘김 같은 움직임은 짧게, `prefers-reduced-motion` 이면 끈다.
- PC 1366 · 폰 390 둘 다, Wire 와 같은 상태들(첫 화면 시작 전 / 하루 마침 · 틀렸을 때 풀기 전 / 첫 오답 / 두 번째 오답 · 모르겠어요 / 다음 · 예습 처음부터 / 0.48 확인).
  지난번처럼 Edge/Playwright 로 가로 넘침 · JavaScript 오류 · 보기 값 보존을 확인하고 결과를 시안 바닥에 적는다.
- 제품 코드는 고치지 않는다. 산출물: `docs/design/mockups/srs-e5-hifi-20261019.html`(안 탭 · 화면 A/B/C · 안마다 «무엇이 다른가 · 대가» 두 줄) + `docs/design/mockups/srs-e5-hifi-shots/`.
- 이 가지에 **단위마다 커밋**, **푸시하지 않는다**(리드가 검수해 병합). `npm install` · `prisma generate` 를 돌리지 않는다.
- 다 되면 마지막 응답에 파일 경로 · 커밋 · 안마다 한 줄 요약 · **원장님께 물을 세부**(05 §0-3 «세부 디테일은 항상 질문» — 단추 문구 · 위치 · 폰 넘김 방식 등)를 적는다.
