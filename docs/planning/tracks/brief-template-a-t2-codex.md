# 지시서 — 템플릿 A · T2 를 제품 여섯 양식에 넣기 (codex, 2026-10-20 저녁)

원장님 선택(2026-10-20):
- 방향은 템플릿 **A · 여섯 원형을 분명하게**(Wire).
- Hi-fi 는 **T2 · 분명한 머리와 번호**(`docs/design/mockups/print-templates-hifi-20261020.html`).

**순서:** 지금 하는 H2 시험 고침(연산 정답지 · 항목 수)을 먼저 끝내고 보고한 뒤에 시작한다.

## 1. 할 것

- 제품 `src/components/unified/print/templates/*Template.tsx` 여섯 개와 그 머리 · 번호 부품에 Hi-fi T2 를 옮긴다.
  - 평가원: 영역 제목 · 2단
  - 정통: 학교 정보표
  - 모던: 안내 머리 · 넓은 1단
  - 워크북: 오른쪽 풀이
  - 자습: 개념 상자 · 모눈
  - 유형: 전략 상자 · 촘촘한 반복
- T2 의 공통 시각 언어를 그대로 쓴다: 남색 윗선 · 번호 테두리 · 옅은 본문/쓰기 선 · 글자색 `#0e0e10` / 남색 `#1b2a4e`.
- **같은 문제는 같은 뷰:** 문항 조판(수식 · 분수 · 보기 · 그림)은 지금 렌더러 그대로다. 양식은 머리 · 틀 · 번호 · 쓰기 공간만 바꾼다. 미리보기 · 인쇄 · PDF · HWPX 수집이 같은 DOM 을 지난다.
- **저장 키는 바꾸지 않는다:** 프리셋 키(`pyeongga` · `jeongtong` · `modern` · `workbook` · `jaseup` · `yuhyung`)와 `PrintOptions` 꼴을 그대로 둔다. 새 저장 칸이 꼭 필요해지면 멈추고 보고한다(읽는 쪽 먼저 규칙).
- **쪽 나눔:** 여백 작업(`pack.ts` 균등 몫 · 스마트)이 main 에 있다. 새 머리 높이 · 쓰기 공간이 측정(`useMeasuredPages`)에 그대로 잡히는지, 25문항 전체 쪽에서 넘침이 0인지 실제 Chromium 으로 잰다(1단 · 2단, 짧은 문항 · 긴 문항이 섞인 표본).
- **Hi-fi 에 없는 세부:** 둘째 쪽 머리, 학교 정보표에 칸이 비었을 때, 자습 개념 상자에 내용이 없을 때 등이다. 짐작해서 정하지 말고 보고서의 «원장님께 물을 것»에 적는다(D-07 — 세부는 항상 질문). 그 자리는 지금 동작을 유지한다.

## 2. 지킬 것

- **TDD:** 양식별 RTL(머리 · 번호 · 쓰기 공간 표지)을 먼저 쓴다.
- **기존 빨간 시험:** `JeongtongHeader` · `mathgenTemplates` 3 은 main 에서 원래 빨갛다. 이번에 양식을 다시 짜면서 시험의 기대(학교명 표시 등)가 맞는지 보고, 고친다면 까닭을 보고에 적는다.
- **`/dev/print-check`:** 양식마다 또는 한 묶음으로 항목을 더한다(상태 «대기»). 완료 조건은 실물 프린터다.
- **메모리:**
  - vitest · Vite · Chromium 을 띄우기 전에 남은 메모리 3GB 이상인지 본다.
  - 전체 type-check 는 끝에 한 번만 돌린다. 돌리기 전에 다른 `tsc --noEmit` 이 도는지 보고, 돌고 있으면 끝날 때까지 기다린다.
  - 쓰고 바로 끈다.
- **금지:** `npm install` · `prisma generate` 를 하지 않는다.
- **커밋:** 단위마다 커밋한다. 푸시하지 않는다.
- 이 지시서를 `docs/planning/tracks/brief-template-a-t2-codex.md` 로 복사해 첫 커밋에 넣는다.
