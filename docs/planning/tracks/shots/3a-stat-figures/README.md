## 무엇을 확인했나

- **그래프는 viewBox 폭이 전부 240** — 지면 등급(mid)이 흔들리지 않는다(09 §4-24 ㉠).
  표는 내용에 따라 134~218 로 다르다(그건 `table` 의 설계다).
- 히스토그램은 **틈이 없고** 경계값이 눈금이며, 찢긴 계급은 **물결선**으로 갈린다
  (막대를 안 그리면 「도수 $0$」과 구별되지 않는다).
- 도수분포다각형은 **양끝이 도수 $0$ 으로 닫힌다**. 넓이 유형은 `bars:true` 로
  히스토그램을 깔아 「넓이가 같다」가 눈에 보인다.
- KaTeX 붉은 글씨 $0$ · 페이지 오류 $0$ (렌더 스크립트가 세어 찍는다).

## 다시 만드는 법

```bash
npx tsx scripts/middle/gen-cli.ts --section "히스토그램" --count 8 --seed 20260823 \
  --html C:/tmp/hist.html
# 그 HTML 을 브라우저로 열어 보면 된다 (이 PNG 는 playwright 로 전체 페이지를 찍은 것).
```

씨앗을 바꾸면 다른 문항이 나온다 — 여기 실린 것은 `--seed 20260823` 의 앞 여덟이다.
