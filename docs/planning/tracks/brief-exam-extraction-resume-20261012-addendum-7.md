# 추가 지시 7 — 기출 원문 잠금과 워크트리 정리

2026-10-12 사용자는 기출 엔진으로 원문 저작권 위험을 줄이려는 목적이므로 DB에 올린 기출 원문을 닫으라고 명시했다. 이후 동의하고 완료 작업의 워크트리를 닫고 정리·삭제하면서 진행하라고 요청했다.

- 원문 기출의 직접 사용을 차단한다. 원문 자료를 내부 개념·출처 참고로 보존하는 것과 출제·학생용 직접 사용을 구별한다. 쌍둥이의 구조/소재 변경이나 저작권 승인을 자동으로 확정하지 않는다.
- 2026-10-12 04:23:29 UTC 최신 읽기 전용 DB 관측에서 `source=past_exam` 101행은 모두 `direct_use_allowed=false`였다. 이번 잠금 변경 필요 행은 0이며 DB 쓰기는 0이다. 기존 보호 82행과 보정 원장 3개의 내용·잠금도 일치했다. 최신 읽기 증거는 `.qa-artifacts/exam-resume-20261008/past-exam-closure-inventory-20261012.json`이다.
- 생성/쌍둥이 문항의 검수·권리·교육과정 관문은 기존대로 유지한다. 원문 삭제·재적재·잠금 해제·학생 기록 삭제나 배포를 이 지시에서 확대 추론하지 않는다.
- 워크트리 정리는 실제 실행 중인 작업, 미커밋/미추적 자료, 통합된 커밋과 원격 보존을 확인한 뒤 한다. 브랜치와 미추적 검수 증거는 별도로 보존한다. 현재 기출 주 작업과 새 풀이/검수 작업의 활성 작업트리는 유지한다.
- 기존 main 통합 완료 작업부터 정리한다. 완료된 기출 보조 작업은 이미 공개된 기출 feature 체크포인트에 통합된 증거를 보존하고, 최신 정리 요청의 범위로 완료 워크트리를 제거한다. 이것은 feature를 main에 병합하거나 배포하는 지시가 아니다. 진행 중/미통합/미보존 변경을 삭제하지 않는다.
- 공유 `node_modules` 정션의 대상, N 원본, 옛 산출물과 외부 Root 소유 자동 재개 controller는 건드리지 않는다. 검사·원장·원격 체크포인트와 실제 쌍둥이 제작/독립 검수/엔진 작업을 계속한다.
