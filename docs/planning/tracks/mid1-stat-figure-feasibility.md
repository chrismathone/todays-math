## 실렌더에서 본 것 (판정 근거 상세)

1. **`table` 열 넘침** — `cw = min(56, (240-16)/cols)` 고정이라 8자 계급 라벨이
   확실히 넘친다. viewBox 를 키우면 안 된다(§4-8 — 글자가 본문보다 작아진다).
   고치는 방향은 **열마다 내용 폭 기반 배분**(합계는 240 유지).
2. **`barChart` ≠ 히스토그램** — 초등 막대그래프 문법(틈·색·값 표시)이 그대로다.
   특히 막대 위 값 숫자는 «일부가 보이지 않는 히스토그램» 유형에서 **답을 노출**한다.
3. **`lineChart` ≠ 도수분포다각형** — 교과 도수분포다각형은 양끝 계급 밖에서
   0 으로 내려와야 하고 점이 계급 **중앙** 위에 선다.
4. **v2 평행선·각 표시 즉시 사용 가능** — points/segments/angles 만으로 렌더됐다.
5. **입체·전개도 kind 는 이미 초등 트랙이 원장님 육안까지 통과**시킨 것들이다
   (09 §4-12~4-23 불변식 내장) — 중1 발문에 그대로 쓸 수 있다.
