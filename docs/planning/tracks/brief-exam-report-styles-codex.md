6. **장부형** — 가는 선 · 촘촘한 줄 · 기록지 같은 빽빽한 표.

## 2. 지킬 것 (모든 후보)
- 같은 내용 · 같은 입력: `StudentExamReport` + 출력 선택(틀린 문항 · 재시험 · 원장님 문장 · 반 평균). 담는 정보는 H1 과 같다 — 더하거나 빼지 않는다. 등수 · 백분위 · 종합 점수 없음(23 · 계획서 §10).
- **흑백 인쇄 · 복사에서 읽힌다** — 색으로 잘함/못함을 가르지 않는다(틀린 것은 굵기 · 밑줄 · ✕). 배경 인쇄가 꺼져도 숫자 · ○✕ 가 남는다.
- 글꼴은 자체 글꼴 둘뿐: 명조 `Noto Serif KR` · 고딕 `Pretendard`(+ KaTeX). 9pt 미만 금지. A4 세로.
- 05 §0 금지 목록(AI 공장식 — 그라데이션 · 둥근 카드 범벅 · 이모지 · 장식 아이콘)을 지킨다. 문구는 간결 · 사무적(D-08).
- 상태 · effect · DOM 측정 없이 그린다(서버 HTML 과 같은 결과) — H1 부품 `src/components/exam-report/` 의 방식 그대로. 틀린 문항이 많을 때(10 · 16 · 20개)의 처리도 후보마다 보인다(합의: 넘치면 다음 쪽으로 이어서 — `docs/planning/tracks/reports/exam-report-wrong-table-consensus.md`).

- 🔴 **원장님 «100점 만점에 몇 점인지는 넣자. 전부 다»** — H1 을 포함한 **모든 스타일**에 «N점 / 100점 만점»을 보인다. 배점 합이 100 이 아닌 시험 · 배점 없는 시험(만점 = 문항 수)은 100점으로 환산(반올림 · 정수)하고 원래 값(«20문항 중 16문항» 또는 «85점 중 70점»)을 옆에 작게 둔다. 환산은 순수 함수 하나(시험 · 경계값: 0 · 만점 · 나누어떨어지지 않음)로 — H1 부품도 그 함수를 쓰게 고친다. 결시는 점수 없이 «결시».
- 🔴 **원장님 «월말평가 추세선도 필요하면 넣고»** — 지난 월말평가 점수의 흐름(100점 환산 · 최근 6회까지)을 작은 꺾은선으로. **2회 이상 쌓였을 때만** 그린다(1회면 칸 자체를 뺀다 — «기록 없음»을 적지 않는다). 흑백 · 점에 숫자 표기 · 세로축 0~100 고정(눈금을 늘려 작은 차이를 크게 보이지 않는다) · 결시 회차는 점 없이 끊고 «결시». 출력 선택에 «월말평가 추이» 켜고 끄기를 더한다(기본 켬). 후보마다 자리를 정한다. 이 단계에서 실제 이력 읽기는 짓지 않는다 — 뷰모델에 선택 칸(`history?: { date, title, score100 | null }[]`)만 더하고 픽스처로 그린다(실제 읽기는 고르신 뒤).
- 🔴 **원장님 «보고서 내부 콘텐츠를 원하는 종류만큼 선택해서 페이지 구성을 커스텀»(2026-10-18)** — 성적표는 **블록의 순서 있는 목록**이다. 원장님이 블록을 고르고 순서를 정하면 지면이 그 차례로 채우고 쪽이 차면 다음 쪽으로 넘긴다(블록을 쪼개지 않는다 · 표 블록만 줄 단위로 이어진다 — 표 넘침 합의). 자유 배치는 없다. **스타일은 같은 블록 목록을 그리는 «옷»** — 그래서 후보마다 **모든 블록**의 모양을 정한다.
  블록(초안): `score`(N점 / 100점 만점) · `correctCount` · `markGrid`(문항별 ○✕) · `wrongTable`(번호 · 단원 · 유형) · `wrongSolutions`(문제 · 정답 · 해설 — 쪽이 는다) · `trend`(월말평가 추이) · `classAverage` · `retries` · `reviewUnits`(다음에 다시 볼 단원 — 틀린 단원에서 덜 맞힌 차례로 최대 3) · `teacherNote` · `academyHeader`(학원 이름 · 머리 문구) · `footer`(연락처 줄). 한 회차 단원별 정답률 그래프는 넣지 않는다(23 §4).
  입력 = `{ blocks: BlockId[] (순서) , header, footer }` + 리포트. 블록 목록 · 쪽 채우기는 **스타일과 무관한 순수 함수 하나**(블록 높이는 스타일이 낸다)로 두고 시험으로 잠근다. 미리보기에 블록 구성 예 셋(요약 한 장 · 풀이 포함 · 숫자만)을 토글로. 블록을 고르고 순서를 바꾸는 «성적표 틀» 화면은 이번에 짓지 않는다(Wire 부터).
