## 최종 변형 방향

**같은 수학 개념과 핵심 풀이 원리를 쓰되, 발문 구조・소재・수학 표현・질문 대상의 전환을 통해 원본과는 다른 문제로 읽히게 만든다.** 원문을 그대로 떠올리기 어려운 새 문항이 목표이며, 새 문항의 한국어를 일부러 어색하게 만들라는 뜻으로 해석하지 않는다.

- 단순 숫자·학교명 교체 중심의 최소 변경 계획을 수정한다. 숫자·이름 교체는 보조 작업이며 그것만으로 새 변형 기준을 통과시키지 않는다.
- 발문 구조를 바꿀 때는 조건을 제시하는 순서, 자료의 조직/제시 방식, 묻는 대상/방식 등을 새로 설계한다. 문장 순서만 뒤집거나 동의어만 치환한 결과를 충분한 구조 변경으로 세지 않는다.
- 소재를 바꿀 때는 원문의 고유한 상황·등장 대상·행동·단위·표/그림 구성을 새로운 자연스러운 상황으로 전환한다. 학교 이름 하나만 다른 학교 이름으로 바꾸는 것은 소재 전환 완료가 아니다.
- 구조 변경과 소재 전환 중 해당 문항에 적합한 방법을 선택하고, 필요한 경우 둘을 함께 쓴다. 추상적인 순수 수학 문항에 부자연스러운 생활 소재를 강제로 붙이지 않는다.
- 평가 개념, 교육과정, 핵심 풀이 원리와 목표 난이도를 유지한다. 새로운 독해 부담이나 추가 선수 개념 때문에 다른 수준의 문제로 바뀌지 않았는지 확인한다.
- 바뀐 조건에서 해의 존재/유일성, 단위, 수치, 보기의 정오, 그림 관계를 다시 계산한다. 원문 답·해설·그림은 참고 증거이며 새 문항의 정답 판정 기준이 아니다.

## 표현 전환과 질문 대상 전환 — 후속 사용자 예시

사용자는 추가로 대수적 표현을 기하학적 표현으로 바꾸거나 길이를 두 점으로 표현하는 방법, 그리고 최댓값/최솟값의 차이를 묻는 문제를 같은 관계에서 최솟값을 역으로 묻는 문제로 바꾸는 방법을 제시했다.

### 수학 표현 전환

- 같은 수학 관계를 대수식에서 도형의 길이/넓이/좌표 관계로 나타내는 등, 표현의 틀을 바꿀 수 있다.
- 길이는 두 점 사이 거리 또는 선분의 길이로 표현할 수 있다. 두 점/선분 자체와 길이의 수치 값을 혼동하지 않고 기존 조판/도형 표기 규칙을 따른다.
- 기하학적 표현으로 바꾸면서 양수 길이/넓이 조건, 정의역, 부호, 좌표 위치, 단위 같은 추가 제한이 생기면 원문과 새 문항의 허용 범위를 대조한다. 음수도 허용하는 대수 변수를 그대로 양수 길이로 바꿔 동치라고 판단하지 않는다.
- 새 표현 때문에 다른 선수 개념이나 추가 작도 지식이 필요해지면 원래 교육과정/목표 난이도와 비교해 조정한다. 표현만 돌려 썼다는 이유로 권리 검토를 통과시킨 것으로 간주하지 않는다.

### 질문 대상 전환 / 역방향 구성

원래 관계가 `M - m = R`(최댓값 M, 최솟값 m, 차이 R)일 때:

- 원래 묻기: 최댓값과 최솟값에서 차이 `R`을 구한다.
- 새 묻기: 최댓값 `M`과 목표 차이 `R`을 알려 주고, 그 관계를 만족하는 최솟값 `m`을 구한다.
- 검산: 새 문항을 직접 풀어 `m = M - R`을 확인하고, 실제 자료/함수/집합에서 그 최솟값과 최댓값이 함께 성립하는지 다시 확인한다.

차이가 음수가 되거나, 함수의 범위/자료 조건에서 구한 최솟값이 존재하지 않거나, 서로 다른 조건/매개변수가 여러 해를 만들면 문항을 다시 구성한다. 같은 답안 숫자를 원문에서 가져온 것으로 검산을 대신하지 않는다.

이 원리를 다른 문항에도 적용한다. 결과를 바로 묻는 대신 그 결과를 만족시키는 입력·조건·매개변수를 묻는 방향으로 구성할 수 있다. 관계를 역으로 풀 때 해의 존재/유일성·분모 0·제곱/제곱근의 부호·범위 같은 조건을 검증한다. 원문에 필요한 개념과 핵심 관계를 유지하되 수치 답과 풀이 설명은 새 문항 기준으로 다시 만든다.

## 학년/교육과정 범위는 필수 통과 조건

사용자: **«대신 해당 학년이 절대 배우지 않는 건 강력히 배제해야 함»**.

이 조건은 발문/소재/표현/질문 대상의 변형보다 우선한다. 원문에 들어 있거나 답을 더 쉽게 구한다는 이유로 해당 학년에서 배우지 않는 개념·표기·방법을 들이지 않는다.

- 문항의 실제 학년·과목·학기·학교급과 **참고 시험 연도에 적용된 교육과정**을 먼저 확인한다. 2015/2022 개정 적용 시기를 모든 학년에 동일하게 가정하지 않는다. 이후 다른 교육과정으로 재발행할 때는 목표 교육과정을 별도 기록하고 재검수한다.
- 허용 근거는 적용 교육과정/성취기준과 해당 Unit/live family 및 검토한 생성 규칙에 연결한다. 원본 학교의 출제, 다른 학년 엔진의 존재, 모델의 높은 확률은 해당 학년 허용의 근거를 대체하지 않는다.
- 검사 범위는 발문·보기·도형/그래프의 의미와 표기·정답 형식·해설·필수 풀이 절차·사전 개념까지 포함한다. 답이 맞아도 학년 밖 방법으로 작성된 해설은 통과시키지 않는다.
- 대수→기하 표현 전환, 질문 대상 역전 등으로 추가 선수 개념이나 더 높은 수준의 방정식/작도/함수 해석을 요구하게 되면 다시 구성한다. **대상 학년의 정당한 풀이가 없는 후보는 제외**한다.
- 학년 밖의 개념/필수 방법이 확인되면 승인/적재/출제 대상에서 강하게 제외한다. 적용 범위 근거가 불명확하거나 리뷰어가 합의하지 못하면 `pending`/보류로 두고, 확인 없이 통과시키지 않는다.
- 독립 검산/검수는 수학적 정확성과 교육과정 적합성을 별도로 판정한다. 상위 학년 도구로 편하게 계산한 검산 결과만으로 학생용 해설의 적합성을 확인했다고 보고하지 않는다.

엔진 업그레이드에도 동일한 범위 제한을 둔다. 새 발문/소재/질문 방식・도형・이미지 템플릿마다 대상 학년·교육과정·필수 개념을 명시하고, 후보 선택과 최종 채택 때 범위 위반이 통과하지 못하도록 연결한다. 그림이나 새 소재가 추가된 문항도 예외가 아니다.

## 문항별로 남길 근거

1. 원문과 새 문항에 공통인 평가 개념·핵심 풀이 원리와 기존 Unit/live family 대응.
2. 선택한 변형 방식: 발문 구조 / 소재 전환 / 대수↔기하 등 표현 전환 / 질문 대상·역방향 전환 / 필요한 조합.
3. 원문의 조건 제시·질문·상황에서 새 문항으로 바뀐 구체적인 차이. 원문/변형물은 별도 ID와 해시로 추적한다.
4. 새 답·해설·도형/이미지·학교명 치환·문항별 메타데이터와 독립 검산/검수 기록.

6. 대상 학년·교육과정과 허용 성취기준/단원 근거, 본문·그림·정답·학생용 풀이 전체의 학년 적합성, 위반/불명 항목의 제외/보류 사유.

원래 정해 둔 **정답/해설 전량 재생성, 도형 전량 재제작, 필요 시 imagegen, 학교명 교체, 메타데이터 철저 부여, 추출 후 엔진 전반 및 이미지 문제 지원 개선**은 모두 유지한다.
