# 지시서 덧붙임 1 — 학생 앱의 겉모습을 시안에 맞춘다 (codex ①)

2026-10-06 · 리드 → codex ① · 원장님이 `/dev/fading` 을 직접 보시고 하신 말씀: **«디자인이 wire라서 그런가? 내가 올린 시안과 전혀 다르네»**.

원장님의 첫 말씀은 «완전히 이 시안대로 움직일 수 있게 개편»이었다(정본 §0-1). 지금 화면은 색 값은 시안의 것이지만 **짜임 · 밀도 · 부품의 생김새가 시안과 다르다** — Wire 로 보일 만큼 성기다.
지시서 4절의 «어떻게 보이게 할지는 codex 가 정한다»를 이렇게 좁힌다: **통일안이 빼라고 한 것(정본 §3 · §5 · §6 · §13)과 속의 규칙(지시서 3절) 말고는, 시안의 짜임을 부품 단위로 그대로 따른다.**
새로 지어내지 않는다. 시안에 있는 화면은 시안대로, 시안에 없는 화면(지시서 2.1 의 «우리가 맞추는 것»)만 같은 말씨로 짓는다.

## 글꼴

시안은 Inter + 라벨의 고정폭 느낌 + 수식. 외부 요청은 0 이어야 하므로 저장소에 이미 있는 글꼴과 시스템 글꼴로 가장 가깝게 맞춘다.

2. 화면마다 **시안 PNG 와 우리 캡처를 390 폭에서 나란히** 놓은 그림을 `.qa-artifacts/fading-screens/compare/` 에 둔다(PC 는 1280). 보고서에는 화면마다 «시안과 같은 것 · 통일안 때문에 다른 것 · 아직 못 맞춘 것»을 표로.
3. 속의 규칙과 지시서 6절의 측정 기준은 그대로다(44px · 12px · 넘침 0 · 용어 규칙 · 칩 표시 금지 · 숫자는 받은 값).
