## 2. 지킬 것

- **서버 · 계약 · 저장 꼴은 고치지 않는다**(`src/lib/**` · `src/contracts/**` · `src/app/api/**`). 화면에 필요한 값이 응답에 없으면 지어내지 말고 보고한다.
- 교사 화면 · `/dev/*` 측정 화면은 그대로(학생 화면에서 걷은 통계는 교사 쪽에 이미 있다).
- D-30(누르는 것만 손가락 · `npm run lint:affordance`) · D-08(느낌표 · 이모지 없음) · `prefers-reduced-motion` · §8.16 선택됨 · §8.18 키캡은 그대로.
- TDD — 바꾸는 동작마다 RTL 시험을 먼저(시작 단추가 `plan.next` 를 시작한다 · 하루 마침 문구 · 걷은 칸이 학생 화면에 없다 · 폰 표 넘김). 기존 시험이 옛 단추 문구를 붙잡고 있으면 새 확정(§8.25)에 맞춰 고치고, 커밋 메시지에 적는다.
- 정션 `node_modules` 작업트리다: `cmd /c mklink /J node_modules D:\todays-math\node_modules` 로 잇고, **`npm install` · `prisma generate` 를 돌리지 않는다.** dev 서버는 `next dev --webpack`(정션이면 Turbopack 이 죽는다). `.env` 가 없다 — 화면 확인은 RTL · 서버 없는 측정 화면으로, 실제 서버가 필요하면 리드에게 묻는다.
- 관련 시험만 돌리고, **전체 `npm run type-check` 는 끝에 한 번**(6.5GB 를 쓴다 — 돌리기 전에 터미널에 한 줄 알린다). `npm run lint` 도 끝에.
- 이 가지에 **단위마다 커밋**(신원 `chrismathone@gmail.com` / `SUN` 을 `git config --local` 로), **푸시하지 않는다** — 리드가 검수해 병합 · 배포한다.
