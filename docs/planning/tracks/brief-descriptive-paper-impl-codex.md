시안: `/dev/descriptive-paper-hifi` 의 **B 옅은 모눈**(작업트리 `/Users/pss/Desktop/creative/today-desc-wire` 미커밋 — 코드 · 보고서 `docs/planning/tracks/reports/descriptive-paper-hifi-codex-20261020.md` 를 읽어 그대로 옮긴다). 고정 짜임: 일일 · 확인 = 문제 바로 아래 답란(4mm 옅은 모눈, 높이 = 채점 기준 수 × 기준당 줄 수 × 줄 높이), 기출형 = 문제지 그대로 + 별도 서술형 답안지(D-119 ⑹), 소문항 ⑴⑵⑶ 칸 분할(마지막 칸 여유), 배점은 서술형에만 번호 옆(D-163), 교사용 채점표 한 쪽(기준 □ · 기준별 점수 · 합계 · 선행 오류 원칙).

## 1. 제품 구현
- 서술형 문항(nativeDescriptive r2 · 주 저자 조립 결과, `src/lib/engine/descriptiveAuthor/`)이 기존 시험지 출력 경로(일일 · 확인 템플릿, 기출형)에 실릴 때 위 짜임으로 그려지게. 답란은 **공용 부품**(예: `src/components/print/WritingArea` — 이름은 기존 규칙에 맞춰)으로 만들어 나중에 개념 백지가 그대로 쓸 수 있게 설계한다(모눈 · 줄 · 빈칸 모양, 높이 규칙, 분할 칸, 머리표를 속성으로).
- 일반 문항의 풀이 공간도 B 안처럼 같은 4mm 옅은 모눈으로 맞출지는 **지금 제품의 풀이 공간 모양과 비교해 차이를 보고만**(바꾸지 않는다).
- 미등록 시연 문항(`rectangleDemo`)으로 학생용 · 교사용 렌더 시험 · 실제 Chromium PDF(A4 넘침 0) · 흑백.
- `/dev/print-check` 에 «서술형 답란 B — 일일 · 확인 · 기출 답안지 · 교사용» 항목 **대기** 추가(실물 검수 필요).
- 출제 경로(시험지 만들기 · 자동 출제)에서 서술형이 뽑혀 들어오는 배선은 이번 범위 밖(등록 · 적재 전). 렌더 경로만.

`docs/planning/26-concept-blank.md` · 개념 백지 지면(`src/components/...concept-blank` · print-check 항목)을 읽고: 답란 모양 · 높이 규칙 · 머리말 · 채점 칸이 서술형 B 와 어디가 같고 다른지 표. 공용 답란 부품을 개념 백지가 쓰게 하면 지면이 어떻게 바뀌는지(쪽 수 · 높이 · 실물 검수 다시 필요 여부)와 선택지 2~3개(답란만 공유 / 머리말까지 / 그대로 둠) — 원장님이 고를 수 있게.
