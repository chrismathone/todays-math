    따라서 다면체는 오각기둥, 칠각뿔, 오각뿔대, 육각뿔대의 $4$개이다.

### 02 다면체의 면의 개수  `다면체`

- **문제** (easy) 다음 다면체의 면의 개수의 합을 구하시오.  
    
  팔각기둥, 오각뿔, 십각뿔대
  - **답** $28$
  - **풀이** 팔각기둥의 면의 개수는 $10$, 오각뿔의 면의 개수는 $6$, 십각뿔대의 면의 개수는 $12$이다.  
    따라서 합은 $10+6+12=28$이다.
- **문제** (easy) 팔각뿔대는 몇 면체인지 구하시오.
  - **답** $10$면체
  - **풀이** 팔각뿔대의 옆면은 $8$개이고 밑면은 $2$개이므로 면의 개수는 $8+2=10$이다.  
    따라서 $10$면체이다.
- **문제** (easy) 면의 개수가 $7$인 각기둥의 밑면은 몇 각형인지, 그 변의 개수를 구하시오.
  - **답** $5$
  - **풀이** 밑면을 $n$각형이라 하면 면의 개수는 $n+2$이므로 $n+2=7$에서 $n=5$이다.  
    따라서 밑면은 오각형이고 변의 개수는 $5$이다.
### 03 다면체의 모서리 꼭짓점의 개수  `다면체`

- **문제** (easy) 십각뿔대의 꼭짓점의 개수를 $a$, 칠각기둥의 모서리의 개수를 $b$라 할 때, $a+b$의 값을 구하시오.
  - **답** $41$
  - **풀이** 십각뿔대의 꼭짓점의 개수는 $20$이므로 $a=20$이다.  
    칠각기둥의 모서리의 개수는 $21$이므로 $b=21$이다.  
    따라서 $a+b=20+21=41$이다.
- **문제** (easy) 오각뿔대의 꼭짓점의 개수를 $a$, 오각뿔의 꼭짓점의 개수를 $b$라 할 때, $a+b$의 값을 구하시오.
  - **답** $16$
  - **풀이** 오각뿔대의 꼭짓점의 개수는 $10$이므로 $a=10$이다.  
    오각뿔의 꼭짓점의 개수는 $6$이므로 $b=6$이다.  
    따라서 $a+b=10+6=16$이다.
- **문제** (easy) 팔각뿔대의 모서리의 개수를 $a$, 사각뿔의 모서리의 개수를 $b$라 할 때, $a+b$의 값을 구하시오.
  - **답** $32$
  - **풀이** 팔각뿔대의 모서리의 개수는 $24$이므로 $a=24$이다.  
    사각뿔의 모서리의 개수는 $8$이므로 $b=8$이다.  
    따라서 $a+b=24+8=32$이다.
### 04 다면체의 면 모서리 꼭짓점의 개수의 활용  `다면체`

- **문제** (mid) 면의 개수가 $13$인 각뿔의 모서리의 개수를 $a$, 꼭짓점의 개수를 $b$라 할 때, $a-b$의 값을 구하시오.
  - **답** $11$
  - **풀이** 밑면을 $n$각형이라 하면 각뿔의 면의 개수는 $n+1$이므로 $n+1=13$에서 $n=12$이다.  
    따라서 $a=2\times12=24$, $b=12+1=13$이므로 $a-b=24-13=11$이다.
- **문제** (mid) 모서리의 개수가 $27$인 각뿔대의 면의 개수를 $x$, 꼭짓점의 개수를 $y$라 할 때, $x+y$의 값을 구하시오.
  - **답** $29$
  - **풀이** 밑면을 $n$각형이라 하면 각뿔대의 모서리의 개수는 $3n$이므로 $n=9$, 즉 구각뿔대이다.  
    따라서 $x=11$, $y=18$이므로 $x+y=11+18=29$이다.
- **문제** (mid) 모서리의 개수가 $15$인 각기둥의 면의 개수를 $x$, 꼭짓점의 개수를 $y$라 할 때, $x+y$의 값을 구하시오.
  - **답** $17$
  - **풀이** 밑면을 $n$각형이라 하면 각기둥의 모서리의 개수는 $3n$이므로 $n=5$, 즉 오각기둥이다.  
    따라서 $x=7$, $y=10$이므로 $x+y=7+10=17$이다.
