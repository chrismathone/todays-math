# 성적표에서 풀이를 뺀다 (원장님 2026-10-19)

원장님: «보고서에 풀이는 필요 없고, 다른 보고서들 살펴봤으면 알 거 아냐.» — 학원 성적표(학부모용 보고서)는 점수 · 정오 · 단원별 성취 · 추세 · 선생님 의견이 중심이고 문항 풀이는 싣지 않는다.

## 할 일
1. **스타일 후보 화면** `/dev/exam-report-styles`: 구성에서 «풀이 포함»을 뺀다(남는 것: 요약 한 장 · 숫자만). 블록 목록에서 «틀린 문항 풀이» · «오답 풀이» 블록 제거. 후보 설명 · 약점 문구에서 풀이 언급을 고친다(예: 큰 숫자형 약점). 틀린 문항 **표**(번호 · 단원 · 학생 답/정답 등 풀이 없는 표)는 남긴다.
2. **제품** — 지금 main 의 성적표 화면 · 지면에 있는 «요약 + 틀린 문항 풀이»(형식 `M1`, `ExamReportWorkspace.tsx` · `ExamReportPaper.tsx` · `paperHtml.ts` · 계약 `examReport.contract.ts`)를 **고를 수 없게** 한다. 
   - 이미 저장된 M1 선택값 · 확정해 보관한 PDF 는 깨지지 않게: 저장값이 M1 이면 요약 한 장으로 읽는다(보관된 PDF 파일은 그대로 둔다). 계약의 M1 값을 지울지 남길지는 호환을 우선 — 남기되 새로 고를 수 없게.
   - 반 전체 인쇄 · 미리보기 · 쪽 나눔 시험을 새 기준으로 맞춘다. `src/app/dev/print-check/items.ts` 의 풀이 쪽 관련 항목은 정리.
3. 화면 문구는 간결 · 사무적(D-08). 풀이를 빼는 것 말고 모양을 바꾸지 않는다.
4. 관련 시험 · `npm run type-check` · 변경 파일 eslint · `npm run lint:affordance`. DB 쓰기 · 커밋 금지. 보고서 `docs/planning/tracks/reports/exam-report-no-solutions-codex-20261019.md`.
