2026-10-23. 사용자 요청: 매쓰플랫·매쓰홀릭을 로그인한 상태에서 조사하고, 실제 채점·학습지 생성을 시험한 뒤 우리 웹앱에 구현한다. 작업·빌드 공간은 외부 새 볼륨에 둔다.

## 조사 범위와 근거

전수 점검의 단위는 **교재 선택 → 정답 확인 → 배정 → 채점 → 재채점 → 오답 선택 → 출력**의 기능과 상태다. 모든 출판사의 모든 판본·문항을 확보했거나 검증했다는 뜻이 아니다. 관찰한 기능, 실제 저장한 결과, 아직 실행하지 못한 분기를 구별한다.

- 매쓰플랫: [시중교재](https://teacher.mathflat.com/lesson-preparation/workbook/public-workbook), 로그인한 교사 UI. 내장 TEST 학생에 새 교재를 배정해 확인했다.
- 매쓰홀릭: [교재 채점](https://teacher.matholic.com/textbook-mark/markable-textbook-list), 별도 코덱스시험 학생으로 교재 채점 1/2 → 오답·유사 2문항 학습지 → 출력 미리보기 → 교사 채점 50점 저장까지 확인했다. [상세 점검표](../research/commercial-workbooks-20261023/matholic-audit.md)에 관찰·실행·미확인 분기를 구분했다.
- 우리 앱: 기준 HEAD `34742b2f02456930d911e60a69ee020ccee56d64`의 코드·계약·스키마·테스트 정적 조사. 기존 수업, 시험 채점, 고정 오답 변형, 교재 제작, 출력, 권한을 대조했다.

## 구현 결정

기존 `Textbook*`은 우리 앱에서 제작한 교재와 QR 발행 기록이고, `TestResult`는 문제은행 시험의 채점 기록이다. 시중교재의 쪽·문항 번호만 가진 정답표는 별도 도메인으로 저장한다. SRS/탐험 기록과 결합하지 않는다.

첫 전달은 교사가 쓸 수 있는 전체 경로를 완성한다.

| 기능 | 구현 범위 | 완료 증거 |
|---|---|---|
| 교재와 정답 등록 | 교재명·출판사·학년·교육과정·정확한 판본·ISBN(선택), 출처, 정답 검토 상태; CSV/TSV 입력 검증 | 동일 번호의 권/절/쪽/소문항 구별, 중복과 빈 답 오류/미확보 표시 |
| 정답 개정 | 정답표의 고정 버전, 기존 과제의 고정 사본 보존 | 새 정답 등록이 예전 채점 근거를 바꾸지 않음 |
| 과제 배정 | 접근 가능한 반과 명시적으로 선택한 학생, 정확한 문항 목록, 기한(선택) | 다른 반 학생 거절, 수신자와 문항 수 확인 |
| 채점 | 정답·오답·미채점, 일부 저장, 교사용 정답 표시, 저장 후 재조회 | 새로고침 유지, 재채점 이력, 중복 요청과 동시 편집 충돌 검사 |
| 오답노트 | 저장된 오답에서 작성, 원래 오답 사건 보존, 정정/복습 메모, 할 일·완료 | 교정해도 최초 기록 유지, 학생·교재·문항 연결 확인 |
| 출력 | 교재·판본·쪽·번호와 풀이 공간을 가진 참조형 오답노트 | A4 미리보기와 인쇄, 학생용 기본 출력에 정답 미포함 |
| 실습 | 직접 작성한 실습 교재·학생과 동일 도메인 규칙의 로컬 저장소 | 운영 학생/DB 변경 없이 전체 흐름 재현 |

범용 수식 자동채점, 원문 문제 재인쇄, 쌍둥이/유사문제, 학생 답안 제출은 해당 데이터·정답 유형·검증 계약이 있는 범위에서만 후속 연결한다. 정답표만으로 이 기능들이 확보된 것으로 표시하지 않는다.

## 데이터와 권한

- 독립적인 교재·정답 개정·과제·채점 이력·오답노트 레코드와 엄격한 계약을 추가한다. 기존 보관함의 알 수 없는 종류나 `app_setting`에 끼워 넣지 않는다.
- 교사 `teaching` 권한과 현재 반/학생 범위를 서버에서 검사한다. 저장·재시도·출력 때도 재검사한다. 브라우저 DB 역할은 새 테이블을 직접 읽거나 쓸 수 없다.
- 정답표는 출처와 검토 상태를 가진다. 없는 답을 틀림으로 채우거나 AI 생성 답을 출판사 정답이라고 표시하지 않는다.
- 과제에는 정확한 판본·정답 버전·문항 사본이 고정된다. 재채점은 이력을 남긴다. 미채점은 0점/오답과 구별한다.
- 변경 요청은 요청 식별자와 예상 버전으로 중복과 충돌을 처리한다. 실패 시 화면 입력을 보존한다.
- 현재 교재별 확보 범위를 표시한다. 전체 시중교재 등록 완료라는 문구나 가짜 수량을 쓰지 않는다.

- 화면: 별도 Orca Codex 작업 공간, 교사 화면·인쇄·메뉴 연결·컴포넌트 테스트 소유

## 검증과 전달

계약/도메인 테스트 → API 권한·충돌 테스트 → 컴포넌트 테스트 → 통합 타입·빌드 확인 → 내부 브라우저에서 실습 흐름과 좁은 화면·출력 확인 순서로 검증한다. DB 마이그레이션은 로컬 SQL 검증을 먼저 마친다. 실제 운영 적용·데이터 등록 여부는 코드 완성과 별도로 기록한다.

사용자는 **출판사 공개 정답지를 조사해 확보 가능한 교재부터 등록**하도록 선택했다. 첫 확보 자료는 비상교육의 개념플러스유형 라이트 초등수학5-1(22개정), ISBN979-11-7316-537-5의 공식 정답과풀이 PDF72쪽이다. 초기 구조화 등록은 개념책1단원8~26쪽을 실제 PDF와 대조하며, 제공되는 전체 PDF와 검토·등록한 문항 범위를 구별한다. 출처 URL·파일 해시·PDF 쪽·누락 이유를 함께 보관하고, 복습책/평가책이나 미검토 단원을 등록 완료로 표시하지 않는다.
