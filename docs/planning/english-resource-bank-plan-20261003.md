# 오늘의 영어 — 지문은행·듣기은행

2026-10-03. 사용자 요청: 수학 문제은행처럼 영어 듣기 자료와 외부지문을 찾아 다시 쓸 수 있는 은행. **기존 코드 조사에 따른 제안이며, 은행 기능을 구현·배포한 상태는 아니다.**

## 사용 흐름

원문 자료를 한 번 등록하고 학년·출처·제목으로 찾는다. 자료를 열어 확인한 뒤 지문은 문제 만들기로, 듣기는 기존 제작·검수·수업 화면으로 이어진다. 같은 자료로 만든 여러 문제 세트를 확인할 수 있다. 이번 시험과 연결하지 않아도 원문을 보관할 수 있다.

메뉴는 `자료은행 → 지문 / 듣기` 탭을 추천한다. 사용자는 두 메뉴를 따로 두는 안과 비교 중이다. **메뉴 이름·배치는 미확정**이며 내부 저장 단위를 결정하는 조건은 아니다. 만들어진 문제 세트는 기존 `문제 보관함`에서 관리한다.

## 은행별 내용

| 항목 | 지문은행 | 듣기은행 |
| --- | --- | --- |
| 기본 단위 | 제목·원문·출처를 가진 지문 한 편 | 같은 음원·대본을 사용하는 듣기 자료 묶음 |
| 넣는 경로 | 직접 붙여넣기, TXT, 기존 시험 자료/문제 세트에서 가져오기 | 직접 올린 음원·대본, 자체 제작 Kokoro 자료, 공식 자료 링크 |
| 먼저 제공할 검색 | 제목·원문 검색, 학년, 출처 | 제목 검색, 학년, 출처, 연도·회차 |
| 미리보기 | 원문·단어 수·출처·관련 문제 세트 | 재생·길이·대본·문항·검수 상태 또는 공식 출처 링크 |
| 주요 행동 | 이 지문으로 문제 만들기 | 자료 열기·검수·수업에서 쓰기 |
| 다음 확장 | 주제·문법 태그, 해석, 자료 묶음 | 문항 유형, 재생 구간·받아쓰기, 자료 묶음 |

처음부터 자동 난이도 점수·CEFR·성적 예측을 붙이지 않는다. 학년은 교사가 지정한 대상, 단어 수·길이는 코드로 계산한 값이다. AI 판정이 필요한 태그나 난이도 추천은 별도 검토 시 프로젝트 TypeSafe 기준을 따른다.

## 현재 코드가 지원하는 것과 부족한 것

- `EnglishMaterial`과 `EnglishQuestionSet`은 `examId`가 필수이고 시험 삭제에 연쇄 삭제된다. 전 시험 검색만 붙여서는 독립 지문은행이 되지 않는다. `prisma/schema.prisma`의 해당 모델과 `src/app/api/english/exams/[id]/materials/route.ts`를 확인했다.
- 원문은 시험 자료의 `content`와 문제 세트의 `passage` 두 곳에 있다. 파일의 `bytes`를 목록으로 가져오지 않는다. PDF·DOCX 업로드는 현재 원문 텍스트가 없어 자동으로 지문으로 사용할 수 없다. 첫 단계에서 OCR 완료처럼 표시하지 않는다.
- `EnglishStudio`는 시험이 있어야 제작·보관함을 보여 주고, `EnglishMakerView`는 고른 시험의 텍스트 자료를 사용한다. 은행 조회는 시험 없이 열고, 문제 제작을 시작할 때 대상 시험을 고르게 바꿔야 한다.
- 변형 문제 세트의 `passage`는 원문과 다를 수 있다. `meta.sourcePassage`가 있는 자료는 원문 후보와 제작 지문을 구분해서 가져오고, 없는 옛 자료는 교사가 확인하기 전 원문으로 자동 분류하지 않는다.
- 자료 30,000자·문제 세트 24,000자·생성 입력 18,000자로 상한이 다르다. 은행에서 제작 화면으로 넘길 때 초과 여부를 알리고, 본문을 조용히 잘라 저장하지 않는다. V2의 원문 ID·버전 개념을 맞추되 현 V1 저장 API에 V2 문서를 그대로 넣지 않는다. [10개 파일 조사](tracks/reports/english-passage-bank-audit-20261003.md)
- `EnglishListeningSet`은 이미 독립 소유 루트이고 `examId`가 선택값이다. 기존 소유·지점·파일·검수·발행 기능을 재사용한다. 현재 목록은 최대 200개이므로 은행 검색은 서버 필터·페이지 나누기를 추가해야 한다.
- EBS 링크 자료는 `teacher_authored` 듣기 세트로 저장할 수 없다. 공식 출처 목록은 별도 참조 항목으로 두고, 우리 소유 음원·검수된 자체 자료와 상태를 구분한다.
- 영어 자료를 수학 `Problem` 또는 일반 `WorkspaceDocument/Asset`에 넣지 않는다. 기존 영어 도메인과 소유 권한 체계를 유지한다.

## 보관과 재사용 규칙

1. **시험과 독립:** 지문 원문은 독립 소유 데이터를 갖는다. 원문은행 항목을 삭제해도 이미 만든 시험지와 문항은 보존한다. 반대로 시험을 삭제해도 은행 원문은 남는다.
2. **원문 버전:** 제목·출처와 본문 개정 이력을 구분한다. 문제 세트에는 제작에 사용한 원문 ID·버전과 본문 사본을 기록한다. 원문을 수정해도 과거 시험지가 바뀌지 않는다.
3. **중복:** 같은 소유 범위에서 정규화한 본문의 해시로 완전 중복 후보를 표시한다. 출처가 다른 자료를 자동 병합하거나 소유가 다른 교사의 원문 존재를 드러내지 않는다.
4. **이용 범위:** 기존 시험 자료에 출처·재이용 정보가 없으면 ‘미확인’으로 가져온다. 무료 공개를 복제·변형·학생 배포 허용으로 바꾸지 않는다. 공식 링크 항목은 EBS에서 열고, 우리 서버 재호스팅이나 AI 입력에는 사용하지 않는다.
5. **기존 자료 가져오기:** 사용자가 고른 자료/세트에서 원문을 복사하고 원래 참조를 기록한다. 반복 실행에 같은 항목이 계속 생기지 않게 한다. 기존 시험이나 문제 세트는 이동·삭제하지 않는다.
6. **권한:** 교사는 자기 자료, 지점 관리자는 기존 정책의 해당 지점 범위, 서비스 관리자는 기존 관리자 범위다. 검색·상세·내려받기·가져오기 모두 같은 범위를 검사한다. ‘자료은행’이라는 이름으로 전체 공유를 자동 허용하지 않는다.
7. **듣기 재사용:** 같은 대화의 문항은 음원·대본 공개 단위를 유지한다. 일부만 먼저 공개해 나머지 답이 노출되지 않게 한다. 기존 교사 검수와 발행 관문을 우회하지 않는다.

## 첫 구현 범위

| 단계 | 작업 | 완료 근거 |
| --- | --- | --- |
| B0 화면 결정 | 기존 교사 A·H1을 바탕으로 은행 검색·상세 구조와 메뉴 위치 결정 | [Wire 4안](../design/mockups/english-resource-bank-wire.html)에서 선택한 흐름 기록. 기존 듣기 작업대의 승인을 재요청하지 않음 |
| B1 은행 저장·조회 | 독립 지문 원문/개정/사용 참조, 기존 자료 가져오기, 자체 듣기 목록·EBS 참조 목록 조회 | 시험 없이 조회, 학년·출처 검색, 소유 범위, 중복 가져오기 검사 |
| B2 제작 연결 | 지문에서 기존 문제 만들기로 연결, 원문 버전 추적, 듣기는 기존 열기·검수·수업 연결 | 지문 선택→문제 생성/편집→저장→같은 원문에서 만든 세트 목록의 왕복 |
| B3 운영 반영 | 선택한 화면 구현, 접근권한 전환, 마이그레이션·운영 반영 순서 검증 | 기존 영어·수학 회귀 검사, 모바일·키보드 검증, 운영 자료 보존 확인 |

DB 변경이 필요한 부분은 독립 지문 저장과 참조다. 기존 세트/시험을 제자리에서 대량 재작성하는 방식은 피한다. 구체적인 마이그레이션·되돌리기 절차와 영향 행 수는 적용 전에 실제 변경안으로 검토한다.

첫 버전 이후의 후보는 즐겨찾기·폴더, 여러 지문의 일괄 구성, 태그 추천, Kokoro 자동 제작 작업이다. 초기 은행 완료를 위해 전부 묶지 않는다.

## 이미 준비된 콘텐츠

- 자체 듣기 샘플 3개: Kokoro-82M v1.0 로컬 생성, 각 40~44초·3문항. 운영 사이트에 교사 청취용 초안 등록 및 파일 재생 검증 완료. 사람 청취 검수·학생 배정은 미실시. [샘플 결과](../listening-samples/20261003/README.md)
- EBS 공식 링크 192회: 중1~3 126회, 고1~3 66회. 음원 192개, 문제지·정답·대본·ZIP 각 120개. 원본을 서비스에 재업로드한 수치가 아니다. [카탈로그](../listening-samples/ebs-catalog-20261003.html)
- 기존 영어 지문은 코드상의 저장 위치를 확인했다. 운영 DB에서 전수 추출·은행 이관을 실행한 상태는 아니다.

## 화면 결정의 범위

듣기 작업대의 기존 교사 A·학생 B·H1 선택은 유지한다. 새 은행의 검색·목록·상세 배치는 새로운 사용 흐름이므로 [CLAUDE.md](../../CLAUDE.md)의 “Wire → Hi-fi … 확정 전 구현 금지” 규칙에 따라 검토 가능한 시안을 먼저 준비한다. 이번 시안은 기능 배치 비교용이며 실데이터 저장·수업 배정을 수행하지 않는다.
