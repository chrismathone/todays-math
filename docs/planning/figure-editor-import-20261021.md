# math-figure-editor 개선 이관

외부 정본 `D:/math-figure-editor/docs/export/todays-math/README.md`의 1·2차를 읽고 현재 todays-math 코드에 맞춰 반영했다. 외부 저장소는 읽기만 했으며, 사용한 13파일의 실제 바이트·해시와 패치를 별도 QA 폴더에 보존했다. 원래 문항·학생 기록·운영 DB는 수정하지 않는다.

| 전달 항목 | 이번 반영 | 판단과 경계 |
| --- | --- | --- |
| ★1 모눈 배경 | 적용·보강 | graph-1 `grid`, 카탈로그, 배경 한 층, 편집기 모눈 조작·부족 경고. 실제 도형은 칸 수 변경으로 이동·변형하지 않는다. 잘못된 숫자·범위·배치는 거절하거나 잘못된 메타데이터만 걷어 기존 도형을 편집할 수 있게 한다. |
| ★2 라벨 | 적용·보강 | 벡터·선분·호 틀, 두 조판기의 대문자 도형명 정자·긴 표시, 소문자 벡터 유지. `root2`는 Enter 없이 놓아도 변환한다. 변환 경고는 변환한 값에 묶어 유지하고 수식 칩은 필요할 때만 MathJax를 읽으며 실패하면 원문을 표시한다. |
| ★3 선택 prop | 적용 | `initialNotice`, `redrawStage`는 선택이며 생략 시 기존 동작. 저장 계약에 새 상태를 쓰지 않는다. |
| ★4 escape | 적용 | SAX 모듈을 불러오던 escape를 같은 치환 함수로 교체했다. 특수문자·사용자 엔티티는 표준 함수와 비교했다. |
| ◆1 모눈 실측·좌표 안내 | 다음 범위 | 참조 코드는 보존했지만 현재 서버 지휘 경로에는 아직 연결하지 않았다. 비교 이미지는 서버의 기존 브라우저가 만드는 구조다. 입력 크기·격자 오탐·좌표계·원본/재작도 표시를 먼저 검증해야 한다. 픽셀 실측은 보조 정보이며 수학 정답·학년·원본 동치의 근거가 아니다. |
| ◆1 자동 gridSnap | 자동 적용 제외 | 선분·다각형 꼭짓점의 무조건 격자점 이동은 원래 수학 관계를 바꿀 수 있다. 실제 중점이나 반 칸 좌표도 존재하므로, 새 조건의 검산 없이 자동 보정하지 않는다. |
| ◆2 REVIEW_FOCUS | 안전한 부분 적용 | 명세로 고칠 수 없는 서식만을 이유로 재작도하지 않도록 짧게 지시한다. 화살촉의 유무·방향, 판독 불가·겹침·잘림은 계속 검사한다. 작은 위치 차이를 일률적으로 허용하지 않는다. |
| ◆3 작업별 모델·강도 | 제외 | 현재 프로젝트의 선택·라우팅을 유지한다. 외부 앱의 고정 모델·강도를 복사하거나 유료 경로로 바꾸지 않는다. |
| ◆4 reviewFilter | 승인 경로 적용 제외 | 무조건적인 부분문자열 삭제는 부정문·혼합 문장의 실제 수정 지시도 지울 수 있다. 불확실·확인 필요를 제거한 뒤 false를 true로 올리는 제안은 채택하지 않았다. 모델의 true도 지적이 남으면 false이며, 원래 지적을 보존한다. 지시문만 명확히 했다. |
| ◆5 마지막 대조 생략 | 제외 | `figureReview`는 실제 원본·렌더 대조를 담는 초안 계약이다. 마지막 시도를 포함해 대조를 유지하며, 확인하지 않은 결과를 통과로 저장하지 않는다. |
| ○ detect·브라우저 지휘자 | 참조 | 기존 탐지·크롭·서버 취소·타임아웃·비교 브라우저 계약을 대체하지 않는다. |
| ○ WebP·초기 화면 분할 | 참조 | 브라우저에서 서버로 업로드하는 독립 앱과 구조가 다르다. 이번에는 이미지 형식·초기 화면·폰트를 바꾸지 않는다. |
| ✕ 전역 CSS·Vercel·UUID·앱 제한 | 제외 | 독립 앱 전용 변경을 들이지 않는다. |

모눈은 유한한 양수 정사각형 칸, 가로·세로 각각 1~60 정수 칸이다. 서버는 루트의 첫 그리는 자식인 변환 없는 g와 path 한 개만 배경으로 허용한다. 편집기는 잘못된 data-grid만 제거하여 일반 도형을 숨기지 않는다. 임의 path의 수학적 내용까지 이 메타데이터 검사가 인증하는 것은 아니다. 60칸으로 도형 전체를 덮을 수 없으면 늘리기 단추를 막고 한도를 표시한다. 격자점 위치와 기존 라벨은 칸 수 변경으로 옮기지 않는다.

원래 전달 앱의 끝점 6/12→12/12, 작도 23초→8~17초는 전달자의 관찰이며 여기서 재현했다고 주장하지 않는다. 우리 측 별도 라벨 모듈 초기화 검사(새 프로세스·각 5회 교대, 모듈 compile/exec 범위)의 중앙값은 약 94ms→26ms였다. 앱 전체·AI 응답·새 그림 생성 시간의 측정은 아니다.

검증 원장과 초기 실패·보강 이력은 `.qa-artifacts/exam-resume-20261008/engine-upgrade-20261019/figure-editor-import-20261021-r1/`, 독립 검토는 `figure-editor-import-audit-20261021-r1/`부터 `…-r4/`에 보존한다. 최초 정적 감사의 8개 모눈 계약 반례와 후속 DOM 감사의 소수 칸 수 3개 반례는 보강 후 거절됐다. 외부 필터의 혼합 문장 반례도 보존한다. 도형 엔진의 `figure_scene.py`·`figure_solid.py`와 M28·피타고라스 모듈은 이 체크포인트에서 바꾸지 않았다.

실제 브라우저 검사 중 긴 벡터·호·선분이 원문으로 남는 결함을 발견했다. MathJax가 길이를 늘릴 때 쓰는 내부 SVG를 두 조판기의 허용 그리기 요소에 추가하되 이벤트·외부 참조·실행 요소 차단은 유지했다. 실제 조판과 악성 내부 SVG 반례를 포함한 관련 검사 9파일 90개, 범위 TypeScript 20파일, ESLint의 현재 변경 5파일 및 기존 결과와 해시가 같은 15파일이 통과했다. 실제 Root 편집기를 별도 로컬 픽스처로 띄운 8개 화면 크기에서 원문 TeX 없음·칩 조판·모눈 8→12칸 변경·도형 좌표 보존·화면 내 대화상자를 확인했다. 작업실 전체·인쇄·실제 학생 문항 검증은 아니다.

후속 사용자 지시는 새 `06-engine-all.patch`의 엔진 통합과 지정 6종 출력의 바이트 일치를 요구한다. 이 체크포인트의 1·2차 이관과 별도 단계로 추적한다. 앞선 3차 정적 검토의 보류·제외는 당시 판단이며 최신 명시 지시를 대신하지 않는다. 통합 때 앞선 검산 보강과 `clear_angle_labels`를 보존하고, 원근 표시의 화면 좌표는 수학적 직각·학년 승인으로 세지 않는다.

자동 문제 출제의 학년·적용 교육과정·학생 풀이·선수개념 관문, 권리·유사성 상태, 소스/후보/그림/검수 해시 연결은 그대로 필요하다. 편집 도구가 벡터나 근호를 표현할 수 있다는 사실은 어떤 학년의 문항으로 허용한다는 뜻이 아니다. 기존 작성·검수 문항 집계를 이 기술 검증 횟수로 늘리지 않는다.
