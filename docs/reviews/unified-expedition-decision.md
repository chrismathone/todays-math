## 학생에게 보이는 구조

`로그인 → 탐험판 → 오늘의 탐험 → 같은 틀의 학습·재도전 → 탐험판에서 한 칸 이동`

- `/learn`이 유일한 게임 홈이다. 초등·중등·개념 엔진은 각각 독립 앱으로 노출하지 않는다.
- 첫 화면에 단원명·오늘의 분량과 주 실행 버튼 하나를 표시한다. 320×600에서도 버튼이 보인다.
- 하단은 **탐험·도감·강의**다. 문제 화면에서도 유지하고 답안 영역을 그 바로 위에 고정한다.
- 학년·단원 설정, 개념 도감, 별·상자·기지는 같은 게임의 보조 화면이다. 기억·회복·통분 공방 시작 메뉴는 만들지 않는다.
- 조작 활동은 해당 개념의 학습 도중 같은 틀 안에서 등장한다. 새로운 프로그램이나 장소로 이동시키지 않는다.
- 강의는 기존 학생별 자료를 연결한다. 카드와 영상의 대응을 추측해 자동 연결하지 않는다.

## 하루 학습과 진도

- 학생당 열린 오늘의 탐험은 하나다. 시작 시 서버에서 종류·단원·원본 세션·목표를 확정한다. 설정 변경이나 다른 엔진 완료로 이를 대체할 수 없다.
- 하루에 원래의 온전한 학습 묶음 하나를 배정한다. 개념 15활동에 문제은행 하루 분량을 무조건 더하지 않는다.
- 단원·기억·선수개념 학습은 패키지의 5개념×3활동을 유지한다. 보통 연습은 실제 문제은행을 사용한다. 새 단원의 개념과 필요한 복습은 같은 탐험 흐름의 다른 날에 만난다.
- 진행 중 학습을 먼저 이어 간다. 새 단원은 개념을 먼저 만나고, 만기 기억 복습·회복 학습이 연속으로 일반 연습을 밀어내지 않도록 선택 규칙을 제한한다.
- 은행에 연결되지 않은 중등 개념은 개념 활동으로 안내한다. 690개 고정 활동을 생성형 문제은행으로 표현하지 않는다.
- 전체 보드의 한 칸은 오늘의 탐험과 필요한 재도전을 모두 해결했을 때만 얻는다. 엔진별 완료 날짜의 합집합은 과거 이력 이관에만 쓰며 새 칸의 근거로 쓰지 않는다.
- 자정을 넘겨도 열린 탐험을 버리거나 재생성하지 않는다. 실제 완료한 한국 날짜에 최대 한 칸을 기록한다.
- 지난 칸 재풀이는 원래 단원을 유지하며 별·상자·기억 간격·누적 진도를 변경하지 않는다.

## 채점·재도전·보상

- 하나만 고르는 답은 즉시 제출한다. 정의 조립과 복수 선택은 수정할 수 있게 확인 버튼을 둔다.
- 정오답은 짧은 오버레이로 알려 주며 답이나 해설을 자동으로 공개하지 않는다. 문제 전환은 책장 넘김 효과를 쓴다.
- 첫 풀이 후 오답을 모아 재도전한다. 개념 학습의 자동 재도전 세 바퀴 이후에도 남은 문제는 완료로 꾸미지 않는다. 학생이 요청하면 해설 모달을 열고, 남은 문제만 명시적으로 다시 도전할 수 있게 한다.
- 최초 정답 통계와 재해결은 구분한다. 재도전 재개·중복 요청으로 별이나 복습 간격을 반복 증가시키지 않는다.
- 별·상자는 기존 일회성 조건을 유지한다. 추가 학습은 하루 칸을 추가하지 않는다. 기지 성장은 게임 안에서 모은 별로 한다.
  **→ 2026-09-28 개정(D-144, 원장님 위임 · 리드·codex·grok 합의)**: 칸을 얻는 그 한 번에 한해, 그 미션의 카드 레벨 별이 3보다 적으면 3까지 채운다(«한 칸 보장» — 은행 날 3). 칸이 하루 하나라 보장도 하루 한 번이다.
  카드 레벨 · 상자 · 설계도의 일회성, 지난 칸 재풀이 · 재도전 재개 · 중복 요청이 별을 늘리지 않는 것, 추가 학습이 칸을 늘리지 않는 것은 그대로다. 기지는 3 · 6 · 12 뒤로 한 단계마다 12, 끝이 없다.

## 출시 확인

확정된 학습의 변경 방지, 중복 제출, 날짜 경계, 오답 잔존, 이전 칸 재풀이를 서버 시험으로 확인한다. 모바일에서는 실제 Chromium/WebKit의 320·390·430px 화면에서 시작 버튼, 고정 답안 영역, 내부 스크롤, 오버레이, 같은 프레임의 조작 활동을 직접 확인한다.
