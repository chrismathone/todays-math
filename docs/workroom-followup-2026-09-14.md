# 작업실 공간 활용과 Mathgen 서식 복원

## 원본 대조

이전 dev 작업실은 문제은행·로컬 크롭·간단한 시험지 편집을 연결한 구현이었다. Mathgen 전체를 그대로 이식한 상태가 아니었으며, 원본의 인쇄 서식과 세부 설정이 누락되어 있었다.

원본 기준은 `F:/Mathgen/src/components/print/PrintOptionsPanel.tsx`, `templates/`, `src/stores/wizardStore.ts`와 인쇄 레이아웃 라이브러리다. 상세 복원 범위와 차이는 [서식 복원 보고서](mathgen-format-restoration.md)에 기록한다.

## 공간 활용

- 홈의 데스크톱 본문은 화면 아래까지 이어진다. 빈 작업실에서는 파일 가져오기 영역이 남는 높이를 쓰고, 최근 작업이 있으면 목록이 그 높이를 쓴다.
- 파일 가져오기 영역 전체에서 클릭·드롭할 수 있다. 장식용 공정 설명은 제거했다.
- 학년 버튼의 160px 너비 제한과 큰 왼쪽 간격을 제거하고 초등·중등 행을 같은 열에 맞췄다.
- 최근 작업은 최대 8개에 바로 접근하며 목록 안에서 키보드로 스크롤할 수 있다. 긴 시험지 제목이 옆 패널을 덮지 않도록 열의 최소 너비도 제한했다.
- 낮은 화면에서는 필요한 만큼 세로로 스크롤한다. 휴대폰에서는 데스크톱 높이를 강제하지 않는다.

## 자료 제작 초기화

파일 가져오기 옆에 **새로 시작**을 추가했다. 실제 작업이 있으면 확인 창을 보여 주며, 취소하면 크롭과 검수 내용을 유지한다. 초기화 대상은 현재 자료 제작의 원본·크롭·검수 상태이고, 시험지에 이미 담은 문항은 유지한다.

읽는 중인 PDF·이미지와 렌더링도 취소한다. 이전 작업의 늦은 응답이 초기화한 화면에 되돌아오지 않도록 처리했다. 자세한 내용은 [자료 제작 초기화 보고서](studio-start-over.md)를 참조한다.

## 통합 앱에서 확인한 내용

- 서식: Mathgen 원본의 평가원·정통·모던·워크북·자습·유형 6종과 5개 폰트 조합, 강조 색상, 시험지 정보, 쪽 여백, 1·2단, 단 구분선, 간격·문항 수 배치, 정답·빠른 정답 설정을 복원했다. 설정은 작업 저장·JSON 내보내기·다시 불러오기에 포함된다.
- 시험지 설정: 서식 설정과 문제 순서 탭으로 나누고 데스크톱에서 화면 높이를 활용한다. 좁은 화면에는 미리보기 바로가기를 제공하고, 지면은 기본 너비 맞춤으로 표시한다.
- 인쇄: 글꼴과 그림을 불러온 후 실제 높이로 A4 페이지를 계산한다. 서식을 바꾸는 동안 이전 지면의 준비 상태로 인쇄하지 않도록 막았다. 모던 서식의 고정된 2025년 예시 문구도 실제 제목·학기로 바꿨다.

- 홈: 1920·1440·1366·1100·1051·1024·390·360px 너비에서 가로 넘침 없음. 빈 홈의 높이 활용, 가져오기 영역의 모서리 클릭, 학년·검색 이동, 10개 저장 작업 중 최근 8개 표시·스크롤·열기 확인.
- 자료 제작: 1440·1366·1100·820·390·360px에서 초기화 버튼 접근과 가로 넘침 확인. 취소·Escape의 작업 보존과 포커스 복원, 확대 상태 초기화, 담은 문항 보존, 지연 PDF 응답 무효화, 실제 PDF 재가져오기·초기화, 전역 검색 확인. 브라우저 오류 없음.
- 6개 서식 각각에 실제 문제은행 문항·초등/중등 분수·크롭 이미지 11문항을 배치했다. 누락·지면 넘침이 없고 PDF로 저장한 6개 파일의 첫 페이지를 렌더링해 확인했다. 폰트 실제 로드, 정답·해설/빠른 정답 전환, 설정 저장·복원·내보내기, 원문 분수 보존도 통과했다.
- 관련 테스트 9파일 100개와 수정 코드 ESLint가 통과했다. 이어지는 dev 구독 AI 연결을 포함한 최종 빌드는 후속 검증에 기록한다.

검증은 독립된 Chromium 컨텍스트에서 수행했다. 실제 사용자 브라우저의 저장 데이터, 문제 DB, 계정·반 데이터는 변경하지 않았다. 실행 기록과 화면은 Git에서 제외된 `.qa-artifacts/workroom-hifi/home-space*`, `studio-reset*`, `reset-toolbar-*`에 있다.
