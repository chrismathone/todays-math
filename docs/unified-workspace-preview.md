# 오늘의수학 통합 작업실 미리보기

개발 서버에서 `/dev/unified`를 연다. 화면 및 전용 API는 `NODE_ENV=development`에서만 열리며, 운영 빌드에서는 404를 반환한다.

## 선택한 작업실형 HiFi

`/dev/unified`와 `?design=1`은 선택한 작업실형의 고도화 화면이다. 기본 화면에는 시안 선택 막대를 표시하지 않는다.

- 고정 작업 메뉴, 현재 시험지, 저장 상태, Ctrl/⌘ K 빠른 실행과 Ctrl/⌘ S 저장을 공통 셸에 배치했다. URL 해시로 화면을 직접 열고 브라우저 뒤로 가기로 이동한다.
- 홈의 검색·학년 바로가기는 실제 문제은행에 연결된다. PDF·이미지는 홈의 가져오기 또는 드롭으로 자료 제작에 바로 연다.
- 담은 문제와 제목·1/2단·정답지 설정을 600ms 후 자동 저장한다. 새로고침하면 마지막 시험지를 복구하고, 최근 작업·내 시험지에서 여러 작업을 다시 연다. 문제 제거는 알림의 되돌리기로 복원한다.
- 저장 공간 부족·손상된 저장소·다른 탭의 충돌은 현재 편집 내용을 보존하고 새 시험지/불러오기 전환을 막는다. 오류에서 작업 파일을 내려받을 수 있다. 이전 `today-math-unified-draft-v1`은 삭제하지 않고 새 `today-math-workspace-drafts-v1`로 이관한다.
- 홈의 수업 현황은 익명일 때 내부 로그인으로, 로그인했을 때 본인 반·학생 수 및 최근 반 진도로 연결한다. 미리보기용 `/api/dev/unified/overview`는 읽기 전용이다.
- 모바일은 하단 6개 작업 메뉴와 그 위의 문제 바를 사용한다. 홈에서는 현재 시험지를 먼저 이어갈 수 있도록 순서를 바꾼다.

## 보관한 다섯 가지 디자인 시안

`/dev/unified?design=compare`에서 구조를 비교하고, 상단 01~~05 버튼으로 실제 화면을 전환한다. 02~~05는 해당 번호로 직접 열 수 있다. 비교 화면 안에서 시안 전환은 담은 문제와 진행 중인 자료 작업을 유지한다. 비교 화면의 기존 저장 방식과 선택한 작업실형의 자동 저장은 별개다.

| 번호 | 시안            | 화면 구조                                                        |
| ---- | --------------- | ---------------------------------------------------------------- |
| 01   | 통합 작업실     | 고정 사이드바, 문제 검색·학년 선택, 진행 중인 시험지와 수업 관리 |
| 02   | 문제 탐색       | 상단 내비게이션, 대형 검색, 학년별 분류 목록과 시험지 요약       |
| 03   | 시험지 스튜디오 | 아이콘 메뉴, 자료 탐색, 중앙 시험지 캔버스, 오른쪽 문서 설정     |
| 04   | 수업 플래너     | 주간 날짜 선택, 시간별 수업 목록, 수업 준비 노트                 |
| 05   | 자료 제작 보드  | 상단 내비게이션, 모으기·다듬기·완성하기의 3단계 보드             |

04의 수업 일정은 화면에 명시한 **시안용 예시**다. 실제 반과 학생은 공통 수업 관리에서 로그인 후 확인한다. 03의 초기 시험지에는 실제 문제은행 문항을 담기 전 예시로 표시한다. 다섯 시안의 문제은행·자료 제작·출력·수업 관리 기능은 공통 컴포넌트를 사용한다.

## 연결된 흐름

- 오늘의 작업: 실제 공용 문제은행의 출제 가능 문항 수, 작업 시작점.
- 문제은행: 기존 출제 자격 규칙으로 조회하는 학년·단원·난이도·검색·페이지 이동, 문제 담기.
- 자료 제작: 브라우저에서 이미지/PDF 읽기, 페이지 이동, 수동 크롭, 본문·정답·해설 편집, 이미지/텍스트 선택.
- 공통 출력: 두 출처의 문제를 함께 구성, 순서 변경·제거, 1단/2단, 정답·해설지, 브라우저 인쇄/PDF 저장, JSON 작업 파일.
- 수업 · 학생 관리: 작업실 내부 로그인·회원가입, 기존 ClassManage의 반·학생 등록/조회와 진도 관리, MainScreen의 수업 진행 화면. 외부 로그인 페이지로 이동하지 않는다.
- 작업 저장: 선택한 작업실형은 시험지를 자동 저장하고 복구한다. 원본 업로드 파일과 아직 시험지에 담지 않은 크롭은 새로고침 후 복구되지 않는다.

문제은행은 `db`와 `problemEligibleWhere()`를 재사용하며, 자료 제작과 시험지 저장은 브라우저에서 처리한다. 수업 관리는 서버 세션 확인 후 기존 본인 소유 반·학생 API를 사용한다. 실제 반·학생을 등록하는 동작은 기존 API에 저장된다. 검증에서는 인증된 데이터를 모킹해 실제 DB 변경을 하지 않았다. 수식과 그림은 기존 `ProblemContent` 렌더러를 사용한다.

수업 진행 화면의 더 깊은 테스트 생성·검수·인쇄 링크는 기존 경로를 유지한다. 이 하위 화면들까지 공통 셸로 이식한 것은 아니다. 기본 MainScreen의 운영 내비게이션은 유지하고 통합 화면에서만 `embedded` 모드를 사용한다.

## 표기 규칙

초등의 정수 가분수는 표현 단계에서 대분수로 바꾼다. 중등 이상은 원문 그대로다. 가분수·대분수 변환 연습, 기존 대분수, 중첩 분수 등 의미가 달라질 수 있는 구문은 보존한다. 저장되는 원문은 바꾸지 않으며, 이미지 속 수식에는 적용하지 않는다.

## 아직 이식하지 않은 기능

Mathgen의 AI OCR·해설 생성·도형 재생성, testchange의 HWP/HWPX 변환 엔진, 변환 작업 서버 저장·재개, 문제은행 등록과 학생 배부는 후속 통합 대상이다. 미리보기는 이 작업을 완료한 것처럼 표시하지 않는다. 현재 PDF 출력은 브라우저 인쇄 경로이며 Mathgen 서버 조판과 동일성을 보증하지 않는다. 실물 인쇄 검수는 별도다.

## 검증 기록 (2026-09-13)

- 공용 DB 조회 99,128문항. 초5·기본 필터는 5,108문항, 존재하지 않는 검색어는 0문항으로 확인.
- 1440px 및 390px 브라우저 화면에서 가로 넘침·페이지 오류 없음.
- 문제은행 담기 → 출력, 드래그·키보드 크롭, 실제 PDF 가져오기, 편집 문항 재반영, 저장·복원 확인.
- 초등 대분수·중등 원문 및 원본 문자열 보존을 브라우저에서 확인. 관련 단위 테스트 4건 통과.
- 인쇄 PDF 2쪽을 렌더링해 문항·정답지 잘림 여부 확인. 실제 종이 인쇄 검수는 수행하지 않음.
- 변경 파일 ESLint·타입 검사 및 `npm run build` 통과. 기존 `tier-bench/g4`의 광범위한 파일 추적 경고는 남아 있음.
- 화면·인쇄 캡처와 실행한 검증 스크립트는 로컬 `.qa-artifacts/unified-preview/`에 보관.

### 다섯 시안 추가 검증

- 모든 시안의 1440px·390px 화면에서 가로 넘침 및 44px 미만의 표시된 버튼 없음. 브라우저 페이지 오류 없음.
- 다섯 시안 모두 수업 메뉴에서 내부 로그인 표시, 시안 전환 후 문제 선택 유지, 첫 화면 검색·학년 선택의 실제 API 연결 확인.
- 새 Studio 화면에서 실제 PDF 가져오기, 드래그/키보드 크롭, 초등 대분수·중등 원문, 원문 보존, 편집 문항 ID 갱신, 저장·복원 통과.
- TeachingView/embedded MainScreen/teaching API와 기존 수업 관리 회귀 테스트 57건 통과. 익명 401·운영 404, 로그인 실패·성공, 회원가입, 탭 상태 유지 확인. 인증 브라우저 검증은 HTTP 모킹을 사용했다.
- 시안 및 내부 로그인 캡처와 브라우저 측정은 `.qa-artifacts/five-designs/`에 보관.
- 최종 병합 후 기본 `npm run build`(Prisma 생성 + Turbopack + TypeScript) 통과. 통합 인증·embedded 화면·API·분수 테스트 20건을 추가 재실행해 통과했다.
- 별도 작업 트리의 webpack 빌드는 기존 `dev/exam-hifi/ExamHifi.module.css`의 전역 `:root` 때문에 실패했다. 프로젝트 기본 빌드 도구는 Turbopack이며, 실제 루트 개발 서버의 PDF 경로는 별도 우회 없이 통과했다.

### 작업실형 HiFi 검증

- 드래프트 저장·복구·마이그레이션·용량 부족·다중 탭 충돌·수업 현황의 인증/소유권·분수 규칙 테스트 65건 통과.
- 실제 DB 학년 검색→문제 담기→자동 저장, 새로고침 후 제목·단수·정답지 복구, 제거/되돌리기, 새 시험지와 기존 시험지 전환, JSON 작업 파일 왕복 확인.
- 홈에서 실제 PDF 가져오기→영역 지정→크롭→시험지 합치기→A4 2쪽 출력 확인. 별도 드래그 크롭 흐름에서 초등 대분수, 중등 원문, 원문 보존과 편집 문항 갱신 재확인.
- 390px·820px·1440px에서 실제 화면을 확인했다. 모바일 메뉴를 가리던 개발 표시기를 비활성화하고 문제 바 위치·홈 카드 줄바꿈·터치 영역을 보정했다.
- 검증 스크립트·화면 캡처·인쇄 파일은 `.qa-artifacts/workroom-hifi/`에 보관한다. 실제 계정 가입이나 반·학생 DB 변경은 수행하지 않았다.

### 공간 확보 및 편집 작업 검증

- 홈의 제목·날짜·장식 소개·분수 안내를 제거했다. 52px 상단바 바로 아래에 검색과 현재 작업을 배치하고 화면 너비를 사용한다.
- 왼쪽 메뉴는 72px 아이콘 메뉴로 접고 펼칠 수 있으며 브라우저에 선택을 기억한다. 활성 메뉴의 세로 강조선을 제거했다.
- 원본을 연 자료 제작 화면은 큰 제목·단계 막대·안내문 대신 압축 도구막대를 사용한다. 좌표는 기본 접힘, 검수 패널은 독립 접기, 작업 영역 확대와 전체 페이지 맞춤을 지원한다.
- 1440×900에서 원본 영역은 기본 846×643px, 왼쪽 메뉴 접기 후 1014×643px, 양쪽 패널 접기 후 1334×643px, 확대 모드에서 1414×703px로 확인했다. 좌표 편집·자르기·확대 종료·초등/중등 수식·메뉴 상태 복구를 실제 브라우저로 검증했다.
- 접기 버튼은 사이드바 상단 로고 옆에 두고 툴팁과 Ctrl/⌘+\\를 지원한다. [Notion의 사이드바 안내](https://www.notion.com/en-gb/help/navigate-with-the-sidebar), [Atlassian의 내비게이션 안내](https://support.atlassian.com/navigation/docs/navigation-best-practices/)에서 화살표·단축키·사용자 제어 방식을 참고했다.
- 파일 선택은 기본 260px, 최대 300px로 제한하고 나머지 도구막대를 페이지 이동·확대·영역 지정에 배정한다.

### 공통 서식과 브랜드

- UI 글자 크기는 보조 정보 12px, 본문·버튼·입력 14px, 영역 제목 18px, 화면 제목·주요 수치 24px의 네 역할로 관리한다. `Workroom.module.css`의 `--text-*` 변수를 각 화면에서 재사용한다. 로고, 축소된 문서 그림, 문제·수식과 인쇄 지면은 자체 비례를 유지한다.
- 일반 버튼은 높이 44px, 모서리 8px, 글자 14px/600, 줄 높이 1.4를 사용한다. 너비는 문구와 배치에 맞게 두며 동일 너비를 강제하지 않는다. 여러 줄의 메뉴·문제 카드에는 내용에 필요한 높이를 유지한다.
- 390px 모바일에서 크롭·좌표와 담기·내보내기를 두 줄로 배치해 버튼이 겹치지 않는다. 빈 시험지의 두 시작 버튼은 서로 다른 자연 너비에서 높이 44px·모서리 8px를 확인했다.
- 책과 더하기를 결합한 로고를 작업실·기존 헤더·인증 화면에 적용했다. `public/brand/brand-board.html`에서 일반·역상·단색 로고와 워드마크를 확인할 수 있다.
- `favicon.ico`(16/32/48px), `icon.svg`, `apple-icon.png`(180px)와 브랜드 파일의 익명 GET/HEAD 접근을 지원한다. 역할별 경로 제한 테스트 14건과 브랜드 적용 관련 회귀 테스트 23건 통과. 실제 HTTP 응답 200 및 이미지 MIME 유형도 확인했다.
